## Admitted local-separator class

A local-separator grammar is one whose parse tree follows a serial or balanced
decomposition of the four recursive addition graphs. At each separator it may
use one or more of the following already-declared operators:

1. **Explicit provenance:** store or stream one alternative, parent edge, lift
   path, or facet annotation per exact source derivation.
2. **Endpoint-state scan:** retain only distinct intermediate endpoints and
   inspect a separator support by equality/hash tests during each target query.
3. **Preprocessed sum index:** replace the scan by a target-independent data
   structure that returns exact source preimages of a five-term sum.
4. **Algebraic aggregate:** combine source branches into a product/norm,
   resultant/common-factor object, quotient/moment vector, or dense elimination
   object and recover sources from that aggregate.

The theorem is exhaustive only for this frozen operator list. A new succinct
source-unranking primitive is outside the list and remains open by design.

## Lemma 1: explicit local provenance reaches `B^3`

There are `Theta(B^3)` canonical signed three-source multisets. Cancellation,
repetition, infinity, and sign-fixed exceptional strata contribute lower-order
subfamilies and must still be retained. If a serial grammar stores one exact
parent alternative for each `PREFIX3` derivation, its traffic is

```text
Theta(B^3) = N^0.6.
```

Endpoint collisions do not delete parent alternatives because the output must
invert biconditionally to source identities. The same charge appears in a
balanced `2+3` split when the three-source side is explicit. This closes
operator 1 at setup exponent `s=3>2.25`.

On a generic low-additive-energy factor-base control, the noncancelling
three-source endpoint support itself is also `Theta(B^3)` up to lower-order
collisions. That support statement is model-bound; the provenance count above
does not depend on endpoint injectivity.

## Lemma 2: endpoint-state scanning misses the query gate

Suppose exact parents are omitted and only separator endpoints are retained.
The most favorable balanced local scan keeps one pair-sum side of size
`Theta(B^2)` and asks whether each endpoint has a compatible three-source
completion for the target. If no target index or algebraic aggregate is used,
the declared equality/hash scan inspects `Theta(B^2)` separator states per
target:

```text
q = 2 > 1.25,
campaign work = Omega(B * B^2) = Omega(B^3) = N^0.6.
```

Scanning the three-source side is worse. A serial forward scan reaches the same
or a larger support before imposing the final target. This is a lower bound for
the declared scan operator, not for every possible indexed query algorithm.

Moreover, endpoint-only acceptance is not yet a relation row. Recovering exact
parents after a hit requires either an explicit parent list (operator 1), a
preprocessed source index (operator 3), or an algebraic source splitter
(operator 4).

## Lemma 3: replacing the scan is exactly the open index problem

A target-independent structure that maps a public target to exact five-source
preimages is a source-reporting five-term sum index. The explicit `A_2/A_3`,
offline six-list meet-in-the-middle, and current `kSUM`-Indexing substitutions
were instantiated in `compressed_navigator_gate_v1.md`:

| control | setup in `B` | query/campaign bottleneck |
|---|---:|---:|
| store `A_2`, scan `A_3` | `2` | per query `3` |
| store `A_3`, scan `A_2` | `3` | campaign `3` |
| offline six-list MITM | `3` | campaign `3` |
| 2026 five-source `kSUM` theorem | best offered `4.5` | preprocessing `5` |
| asymmetric theorem with `q<=1.25` | best offered `4.75` | query at most `1.25` |

Thus no checked index supplies the P1515 rectangle. This is a comparison against
known constructions, not a data-structure lower bound. A new field-coordinate
sum index with exact source reporting is precisely one surviving operation; it
cannot be assumed as free grammar navigation.

## Lemma 4: known algebraic aggregates route to frozen controls

For the recursive-`S3` chain, the checked local aggregates have already been
classified:

1. Multiplying source-transition factors and eliminating the shared endpoint
   yields the P1510/P1513 product, selector norm, common-factor, or equivalent
   source-marked circuit controls. Their declared standard representations incur
   cubic degree, leaf traffic, or base-field coordinates before exact source
   splitting.
2. Expanding coefficients, Macaulay multiples, quotient traces, or supplied
   moments yields the P1514 dense-elimination and moment-constructor controls.
3. Replacing source branches by explicit squarefree facets, lift paths, or
   annotations returns to the P1515-R1 universal facet-deck negative.

Calling these objects grammar nonterminals or shelling certificates does not
change their charged representation. A structurally new factored arithmetic
circuit with output-sensitive exact unranking is outside this lemma and remains
open.

## Theorem: known local separator operators miss P1515

Within the admitted local-separator class, every source-complete recursive-`S3`
grammar takes one of four routes:

```text
explicit provenance  -> B^3 setup/traffic,
endpoint scan         -> B^2 per target,
preprocessed index    -> no checked construction in the P1515 rectangle,
known aggregate       -> P1513/P1514/R1 frozen controls.
```

The first two routes have proved scoped exponent failures. The third and fourth
routes supply no passing known operation. Therefore no admitted known local
operator produces a source-biconditional grammar with `s<=2.25,q<=1.25`.

This theorem does **not** say that every local grammar falls into the named
representations. It says that any successor outside them must exhibit the new
indexing or arithmetic operation explicitly and pay for its construction,
query, source inverse, and memory.

## Surviving mechanism

The only P1515 successor not semantically absorbed by the controls is now:

```text
a target-independent finite-field coordinate router that represents local
source branches nonlocally, answers a target in B^(1.25+o(1)) work after at most
B^(2.25+o(1)) setup, and unpacks exact all-strata sources without a B^3 table,
P1513 norm/common factor, or P1514 dense quotient.
```

The load-bearing evidence must be one explicit identity or recurrence for the
recursive-`S3` coefficient family. Squarefreeness, shellability, low polynomial
degree, or a supplied source oracle is not that identity.
