## Common subgroup field and unramified boundary

Let `K` be a complete discretely valued field with residue characteristic `p`,
let `E/K` have good reduction, and let

```text
H=<P> subset E[N],
N prime,
N!=p,
Q=[x]P,
x!=0 mod N.
```

Choose `y` with `xy=1 mod N`. Multiplication maps are defined over `K`, so

```text
Q=[x]P,
P=[y]Q,
K(P)=K(Q)=K(H)=:F.
```

This is equality inside the fixed algebraic closure. It is stronger than equality
of degrees or an abstract isomorphism. Any field invariant attached only to one
nonzero generator is constant across `H-{O}`.

Because `N` is invertible in the valuation ring, good reduction makes `E[N^m]`
finite etale and inertia acts trivially on it for every `m>=1`. Thus the full
order-`N` torsion tower is unramified at the residue prime. Its positive upper and
lower ramification groups are trivial. The unramified Frobenius action may still be
nontrivial, but it is curve/torsion data shared by every nonzero generator; it is
not a scalar label.

## Full division-fiber reconstruction

Let `a>=1` with `gcd(a,N)=1`, and choose `b` with

```text
a*b=1 mod N.
```

The point

```text
h_a(Q)=[b]Q in H
```

is public and satisfies `[a]h_a(Q)=Q`. Hence

```text
[a]^(-1)(Q)=h_a(Q)+E[a].
```

The field generated by the complete fiber is exactly

```text
K([a]^(-1)(Q))=F(E[a]).
```

One inclusion follows from the displayed translate. The reverse inclusion follows
because differences of two fiber points recover `E[a]`, while the sum of any fiber
point and its known torsion offset recovers `h_a(Q)` and hence the common field `F`.
The same statement applies layer by layer to any public sequence of coprime
division maps, including `a=p^m` because `N!=p`.

If `a=N^m`, multiplication by a nonzero `x mod N` is an automorphism of
`E[N^(m+1)]`. It maps the complete fiber above `P` bijectively to the complete
fiber above `Q`, with inverse given by an integer inverse of `x mod N^(m+1)`.
The generated fields are again equal. This case has no zero branch in `H`, so its
selected-branch orientation is treated separately below.

## Selected-branch torsion-offset normal form

For `gcd(a,N)=1`, every selected point `R_a(Q)` has a unique decomposition

```text
R_a(Q)=h_a(Q)+T_a(Q),
T_a(Q) in E[a].
```

Over the common subgroup field `F`, this gives the exact field equality

```text
F(R_a(Q))=F(T_a(Q)).
```

Indeed each side constructs the other by adding or subtracting the public point
`h_a(Q)`. Therefore every ramification index, residue degree, inertia/decomposition
group, break, conductor, discriminant, Herbrand function, and eligible field-of-norms
object of the selected branch is an invariant of the torsion offset `T_a(Q)`.

This normal form distinguishes two operations that the root hypothesis had left
combined:

1. local ramification can partition or label the fixed set `E[a]`; and
2. a selector must decide which member of that fixed set to attach to `Q`.

The first operation is target independent. All possible scalar dependence is in
the second operation.

## Affine branch-label theorem

There is a coordinate-free exact label for every coprime division branch. Define

```text
theta_Q:[a]^(-1)(Q) -> E[a],
theta_Q(R)=[N]R.
```

The image lies in `E[a]` because `[a][N]R=[N]Q=O`. For `T in E[a]`,

```text
theta_Q(R+T)=theta_Q(R)+[N]T.
```

Since `gcd(N,a)=1`, multiplication by `N` is an automorphism of `E[a]`.
Consequently `theta_Q` is an affine bijection. The public zero branch has label

```text
theta_Q(h_a(Q))=O.
```

Thus choosing one point of the division fiber and choosing one torsion label are
the same operation, with no loss or compression. A ramification break observed
after selecting a point can only describe the already selected label.

The link to scalar digits is equally exact. If branches above `P` and `Q` were
aligned by

```text
R_a(Q)=[x]R_a(P),
```

then

```text
theta_Q(R_a(Q))=[x]theta_P(R_a(P)).
```

For a label of order `d|a`, a tiny torsion DLP would return `x mod d`. This is a
valid positive instrumentation control, but it exposes the circularity: the aligned
branch is already a residue oracle.

## Why nonzero scalar equivariance is not well-defined

The public point `Q` determines `x` only modulo `N`. The integers `x` and `x+N`
name the same point. A rule

```text
Q=[x]P -> [x]theta_P
```

is independent of the integer representative only if

```text
[N]theta_P=O.
```

But `[N]` is an automorphism of `E[a]`, so this forces `theta_P=O`. Equivalently,
the only everywhere well-defined scalar-equivariant coprime branch is the public
zero branch `h_a`, which returns no digit.

One may impose the canonical integer representative `0<=x<N` and then define a
nonzero aligned label. Doing so is logically valid, but computing that label from
`Q` is exactly computing `x mod d`. The representative convention does not create
an algorithm for the residue it names.

This is a no-go for exact scalar-equivariant torsion labels. It does not prove that
every nonhomomorphic coordinate function on the `N-1` public points is hard.

## Ramification-only selector theorem

Let `rho(T)` be any tuple of local-field invariants constructed from `F(T)/F`:
ramification groups or breaks, valuations, residue degree, conductor, discriminant,
Herbrand data, normal closure, or a functorial invariant of an eligible tower.
The selected-branch normal form gives

```text
rho(R_a(Q)/F)=rho(T_a(Q)/F).
```

The multiset `{rho(T):T in E[a]}` is independent of `Q`. Hence:

- a unique ramification extremum selects the same torsion offset for every target;
- a fixed Frobenius eigenspace, canonical subgroup, connected/etale component, or
  valuation stratum is likewise target independent; and
- if several offsets share the selected data, resolving the tie as a function of
  `Q` is a new nonramification orientation rule.

For `a=p^m`, ramification of the connected/formal torsion may distinguish orders,
valuations, or canonical-subgroup levels. Translation by `h_a(Q)` still reduces
the branch field to `F(T)`. A rule that aligns `T_a(Q)=[x]T_a(P)` could reveal
`p`-adic information about the canonical representative of `x`, including its
`p`-adic valuation, but selecting that aligned coefficient is the forbidden digit
operation. Ramification itself supplies only the target-independent strata.

## Order-N division branches

For `[N^m]R=Q`, the full fiber has `N^(2m)` branches and is unramified at the
residue prime. If `R_m(P)` is one branch, then `[x']R_m(P)` lies above `Q` for
every lift

```text
x'=x mod N.
```

There are `N^m` such residues modulo `N^(m+1)`. The input point supplies no rule
for choosing one. Selecting the ordinary integer representative of `x`, or any
compatible `N`-adic lift, is precisely a scalar-orientation choice. Complete branch
materialization costs `N^(2m)` points; a compact selected branch is not ruled out,
but it must provide the missing lift law rather than credit unramified field data.

The Kummer-cocycle and repeated-prime orientation lanes record this same boundary.
An order-`N` division point can carry a linear cocycle only after the division lift,
torsion basis, and quotient orientation are supplied and charged.

## Field-of-norms category correction

The classical Fontaine-Wintenberger construction applies to infinite APF extensions;
the strongest familiar examples are deeply or totally ramified `p`-adic towers. An
unramified order-`N` torsion tower should not be assigned a classical field of norms
without first checking the APF hypotheses. This is a category correction to broad
informal wording, not an escape from the no-go.

For every eligible APF sub-tower built from `p`-power torsion offsets, the branch
normal form gives finite layers `F(T_m)` independent of the target. Functoriality of
the field-of-norms construction then preserves that target independence. If the
selected offsets vary with `Q`, their selection law, not the field-of-norms functor,
is the scalar-sensitive operation.

## Named selector screen

### Public zero and fixed-offset branches

- `h_a(Q)=[a^(-1) mod N]Q` is public, canonical, cheap, and has label zero.
- `h_a(Q)+T_0` for a public torsion point `T_0` has a fixed label and returns no
  scalar information.
- Selecting the least-ramified, least-valued, canonical-subgroup, or fixed-Frobenius
  offset is another fixed-offset rule unless an additional target-dependent tie
  breaker is supplied.

### Coordinate and polynomial root ordering

A lexicographically least root, least residue coordinate, chosen embedding, or
software root number can define a set map `Q -> T_a(Q)`. Such rules are generally
not invariant under equivalent curve models, field presentations, or root
permutations. More importantly, no checked rule has a proved transformation law or
typed inverse to `Z/NZ`. Once the offset is computed, the ramification wrapper can be
removed without changing the map. This is an arbitrary small-range point feature,
not a ramification digit theorem.

### Frobenius, canonical subgroups, and pairings

Frobenius can orient eigenspaces of `E[a]` in special split cases, and local geometry
can identify a canonical `p`-power subgroup. These operations choose a torsion module
or line. They do not choose the coefficient `[x]T_P` on that line. A Weil or Tate
pairing can read the coefficient once aligned torsion points are supplied, but the
alignment is the missing branch label and may also move the DLP into a roots-of-unity
group.

### Masking and repeated moduli

Querying a genuine residue oracle on `Q+[t]P` would support standard hidden-number or
CRT reconstruction. The audit does not dispute that consequence. It finds no way to
construct the oracle: for each small modulus `a`, the required aligned branch is
exactly the corresponding torsion label. Using many small coprime moduli can keep
raw torsion enumeration small, so enumeration cost alone is not a universal no-go;
the missing typed selector remains decisive.

## Independent findings

1. `K(P)=K([x]P)=K(H)` for every nonzero `x mod N` reconstructs exactly.
2. Good-reduction order-`N` torsion is unramified because `N!=p`; its Frobenius
   data is shared curve/torsion data.
3. Full coprime division fibers generate `F(E[a])`, and complete order-`N`
   division fibers are generator invariant.
4. Every coprime selected branch is the public zero branch plus one torsion offset,
   and its field over `F` equals the offset field.
5. The map `R -> [N]R` is an affine bijection from the fiber to `E[a]`; selecting
   a branch and selecting its orientation label are equivalent operations.
6. A nonzero law `theta_Q=[x]theta_P` is not well-defined from `x mod N` because
   `[N]` is invertible on `E[a]`. Imposing an integer representative makes the
   label exactly the desired residue oracle.
7. Pure ramification, canonical-subgroup, Frobenius-stratum, and field-of-norms
   selection is target independent; a target-dependent tie breaker is external
   orientation data.
8. Order-`N` division requires choosing a lift of `x mod N` to a higher
   `N`-power modulus and has no ramification break at the residue prime.
9. Coordinate root ordering and arbitrary compact nonhomomorphic offset maps remain
   unclassified, but no checked one has a typed scalar law or complete sub-rho path.
