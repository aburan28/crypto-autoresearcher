### 0.2 Tracked objects shared across entries, and the lossy-projection test

Three objects carry the slice. The §2 test is applied to each here and **re-applied per entry**,
because the honest global statement is that the wire stream is *not* lossy relative to
`(secret, randomness)` jointly — it is lossy relative to the secret once the randomness is
quantified out, and relative to every named field individually. A slice-level hand-wave would be
exactly the repackaging rule 4 forbids.

**TO-WIRE.** The map
`(sk, m_1..m_q, r_1..r_q) ↦ Σ_q` = the byte stream a passive observer receives over `q` signings
under one key, decomposed into its named fields. At NIST-I, per signature that is
`(E_aux, n_bt, r_rsp, M_chl, chl, hint_aux, hint_chl)` = `64 + 1 + 1 + 64 + 16 + 1 + 1` = **148
bytes**, plus a one-time `pk = (E_pk, hint_pk)` = `64 + 1` = **65 bytes** (all figures relayed from
`H-SQISIGN-c0488f`; see CEILING-S3(iii)).

- *Lossy?* Not against `(sk, r)` jointly — `Σ_q` is a deterministic function of them and, for a
  fixed message stream, is close to injective in `r`. **It is lossy against `sk` alone**, and every
  entry below exhibits the fibre of its own projection rather than inheriting a slice-level claim.
  S3-9 computes one such fibre exactly (`2^{f−1}` pairs `(d, det M_sk)` consistent with the public
  key, of which `≈ 2^{e_rsp−1}` distinct values of `d`, i.e. *every* admissible `d`).
- *Propagates?* Yes: `Σ_{q+1}` is `Σ_q` concatenated with one more block, and every entry's
  statistic is defined per-block and aggregated, so one-step propagation is definable and
  measurable — the §1 axis-2 requirement.
- *Not a change of coordinates?* Established per entry, not here.

**TO-CLOSURE.** `Σ ↦ cl_C(Σ)` = the **cost-annotated poly-time closure**: the set of pairs
`(derived quantity, charged cost of deriving it)` reachable from `Σ`. Introduced and defended in
**S3-5**; consumed by S3-8 and S3-9. The concrete demonstration that this is not pedantry is in
the corpus already: `H-SQISIGN-c0488f` STEP 7 records that SQIsign verification
(Algorithm 4.9 lines 24–26) computes a `(2,2)`-isogeny chain whose codomain is `F_1 × F_2` with
`F_1 ≅ E_com` — **so the commitment curve `E_com`, which is the exact symbol
`IDEA-20260805-bb4bf8`'s entire mixing analysis is about, is never transmitted and lives only in
the closure.** A screen run on the wire format does not see the object the zero-knowledge argument
is about.

- *Lossy?* Yes, and in the direction that matters: `cl_C` retains a *finite named list with costs*
  and discards the derivations, the intermediate state, and the ordering. It is **not**
  information-lossy (data processing: `S(cl(Σ)) = S(Σ)`), and S3-5's content is precisely that
  Stage A of `B3-1` is closure-invariant while Stage B is not.
- *Not invertible:* the same annotated list arises from every `Σ` in its poly-time equivalence
  class, which is exactly the equivalence S3-5's known-answer gate exercises.

**TO-LOCUS.** For an intermediate value `v` of an isogeny computation, the **membership indicator**
`1[v ∈ L]` of its intended algebraic locus `L` — `L` = the supersingular Montgomery coefficients on
the curve side, `L` = a fixed maximal order (or a prescribed-norm shell in it) on the quaternion
side. Used only by **S3-6**, and explicitly **not** a projection of TO-WIRE: nothing about `v` is
published, which is why S3-6 is a statement about self-checking structure and not about disclosure.

- *Lossy?* Maximally: one bit retained, `≈ 2·log2 p` bits discarded. The fibre over `1` has size
  `|L| ≈ p/2` (Montgomery coefficients of supersingular curves) inside an ambient `p^2`; the
  discard is structural because `L` is a *density-`1/(2p)` arithmetic subset* of the ambient, not a
  sublattice or a coordinate subspace. The asymmetry S3-6 is about is that the corresponding
  quaternion-side locus **is** a lattice, so the same indicator is identically `1` there — a
  discard of measure zero, i.e. a change of coordinates. Naming that difference is the entry.

## 1. The ten ideas

### S3-1. The verification accept-fibre: count the kernel of the verifier on the *encoding*, and price strong unforgeability at exactly the hint's speed benefit

**Tracked object + what it discards.** The **accept-fibre** `A(pk, m) = { s ∈ {0,1}^{8·SIGBYTES} :
Verify(pk, m, s) = 1 }` for a fixed honestly signed `(pk, m)` — projected to its **cardinality**
and to a *named decomposition* of that cardinality into per-field factors. The projection
`s ↦ |A|` discards the signatures themselves, the isogenies they encode, and the message; it
retains one integer. The discard is structural, not a change of coordinates: `|A|` is invariant
under every relabelling of the encoding that preserves the verification predicate, so the fibre map
is constant on an equivalence class whose size is exactly what is being counted. Nothing about
`A(pk,m)` for one `(pk,m)` recovers a single accepted string.

**Mechanism.** A byte-budget certificate (`IDEA-20260805-244f78`) proves the field list sums to
`SIGNATURE_BYTES`. It says **nothing** about how many of those `8·148` bit-strings the verifier
accepts, and that number is the strong-unforgeability (SUF) content of the encoding. Decompose it:

- **Hint bytes (`hint_aux`, `hint_chl`), the live axis.** `H-SQISIGN-c0488f` §C records that
  Algorithm 2.2 `TorsionBasisFromHint(A, e, h)` **with `h = 0` re-runs `TorsionBasisToHint`** and
  recovers the correct basis, while `h ≠ 0` is used directly. Therefore, for every hint whose true
  value `h_true ≠ 0`, **both `h_true` and `0` produce the same basis and the same verification
  outcome.** Two accepted values per hint byte, two hint bytes in the signature.
- **`M_chl` scaling — derived here to be CLOSED, and the derivation is part of the entry.** The
  verifier (Algorithm 4.9 lines 24–26, relayed) checks isotropy of
  `((4P_chl, 4P_aux), (4Q_chl, 4Q_aux))`. The **aux components are the deterministic basis of
  `E_aux`** and are not encoded, so a generator base-change `U ∈ GL_2(Z/2^{e})` that would preserve
  the kernel must act on the aux side too — and any `U ≠ I` replaces `(P_aux, Q_aux)` by a pair
  that is no longer the deterministic basis, which the verifier reconstructs independently. The
  naive `2^{4(e_rsp−2)}` malleability orbit therefore collapses to `U = I`. **This negative is the
  reason the entry is worth writing:** the one axis that would have been a 500-bit finding is dead
  by a two-line argument, and what remains is small, exact, and checkable.
- **`chl`, `r_rsp`, `n_bt`, `E_aux`** are consumed by the verification equation and are pinned by
  it (Stage 0 confirms per field).

**Prediction (numeric).** `|A(pk, m)| = 2^{#\{hint bytes with h_true ≠ 0\}}`, hence generically
**4** — exactly **2 bits of encoding malleability at every parameter set** — unless verification
rejects a hint that disagrees with the recomputed value. With `h` a retry index over `1..127`
capped to `0`, `Pr[h_true = 0] ≈ 2^{-7}`, so `E[|A|] = 4·(1 − 2^{-7})² ≈ 3.938`. Consequence,
stated at its true tier: **EUF-CMA is untouched; bit-string uniqueness is not.** And the repair has
an exact price — rejecting a non-canonical hint costs one `TorsionBasisToHint` call per hint, which
is *precisely* the work the hint exists to save. **Strong unforgeability costs exactly the hint's
speed benefit, to the operation.**

**Minimal discriminating test (with known-answer gate).** Zero curve arithmetic; a reading task
plus a 40-line fibre counter.
(1) **Stage 0 gate:** re-quote Algorithms 2.1, 2.2 and 4.9 from a filed source and reconstruct the
byte budget; the reconstruction must land within 1 byte of the independently reported 212 (§0.4) or
the field list is incomplete and the entry halts.
(2) Build a *model verifier*: a Python function over the field list that marks each field
`pinned` / `free` / `two-valued`, and multiply out `|A|`.
(3) **Known-answer gate, and it must run first:** point the identical counter at two encodings whose
answer is known in advance — ECDSA **with** low-`s` enforced (`|A| = 1`) and ECDSA **without**
(`|A| = 2`, the classical `(r, ±s)` malleability). A counter that does not return exactly 1 and 2 is
broken instrumentation and no SQIsign number may be reported.
(4) Report `|A|` per parameter set with the per-field decomposition.

**Falsifier (reachable, and numeric).** (F1a) Algorithm 4.9 recomputes each hint and rejects on
mismatch ⇒ the hint axis contributes factor 1, `|A| = 1`, **the encoding is canonical and the entry
closes as a clean negative** — which is the more likely outcome and is fully usable. (F1b) The
model verifier's `|A|` disagrees with a directly enumerated `|A|` on a toy encoding ⇒ the model is
not the verifier and the count is void. (F1c) The `M_chl` collapse argument is wrong because the
aux basis is *also* signer-chosen ⇒ the orbit re-opens and the finding is `2^{4(e_rsp−2)}`, which
must then be reported with the *reason* it is not a forgery (same kernel ⇒ same map ⇒ no new
message).

**Charged cost.** Machine model: single classical core, RAM. Implementation ≈ 150 lines. Compute:
seconds; no isogeny arithmetic, no memory beyond the field table, no preprocessing, no oracle
queries, no data. Human cost is the binding resource: one careful reading of three algorithms.
Nothing here is amortised across parameter sets — each is read separately, and that is charged as
3× the reading.

**Kills-it-early.** Ten minutes: find the line of Algorithm 4.9 that consumes `hint_chl`. If it
feeds `TorsionBasisFromHint` and the result is *used* rather than *checked*, the two-valued axis is
live; if the basis is recomputed and compared, `|A| = 1` and the entry is finished.

**Ceiling.** `medium`. It is a documentary/arithmetic statement about a published encoding, with no
attack, no exponent, and no security claim. **`medium` is the ceiling precisely because the object
is real (a shipped wire format) rather than a toy** — and it still cannot rise above that, because
`|A| > 1` is a statement about bit-strings, not about unforgeability of messages.

**Risk band.** `conservative`.

**Nearest prior-art neighbour.** `IDEA-20260805-244f78` —
`byte_budget_completeness_certificate|sum_of_declared_component_encodings_equals_...|inventory_acceptance_gate`.
**Why it is not that:** 244f78 certifies that the *inventory* is complete by summing declared
encodings; S3-1 takes a complete inventory as given and counts the *kernel of the verification
predicate* on it — a quantity a complete byte budget constrains in no way at all.

### S3-2. `n_bt` as a published coincidence counter between a public challenge and a secret-dependent response, with a derived geometric null

**Tracked object + what it discards.** The **empirical law of the published one-byte integer
`n_bt`** across a transcript batch under one key, conditioned on nothing, and its two-sample
comparison across keys. The projection `signature ↦ n_bt` discards `E_aux`, `M_chl`, `chl`, and
every curve and isogeny in the signature, retaining **8 bits per signature out of 1184**. The
discard is structural: the fibre over a fixed `n_bt` value is `≈ 2^{1176}` of the signature space
and is not a coordinate subspace — `n_bt` is a *combinatorial coincidence count* between two walks,
so no invertible map takes it back to either walk. This is the cheapest projection of TO-WIRE that
still has a derivable null.

**Mechanism.** `H-SQISIGN-c0488f` records `n_bt` as a published, **required**, one-byte signature
field. A "backtracking" counter in a Fiat–Shamir isogeny signature counts how many leading steps of
the response chain coincide with (the dual of) the challenge chain — i.e. it is a **direct
measurement of an interaction between a public, hash-determined object and a secret-dependent
object**, published in clear, once per signature. The null law is forced by graph geometry, not
fitted: for an `ℓ = 2` graph, if the response's first step is uniform among the two non-backtracking
neighbours then `Pr[n_bt ≥ k] = 2^{-k}` and `E[n_bt] = 1`; if backtracking is permitted and the step
is uniform among all three neighbours then `Pr[n_bt ≥ k] = 3^{-k}` and `E[n_bt] = 1/2`. Stage 0
decides which; **both are exact numbers written before any data exists.**

Why this is not `IDEA-20260805-2a669e`: 2a669e's object is an *invisible* acceptance indicator that
tilts a *latent* commitment measure, and its whole difficulty is that the abort is never observed.
`n_bt` is observed, in the clear, in every signature. No conditioning argument is needed and none is
used.

**Prediction (numeric).** (a) Pooled across keys, `Pr[n_bt ≥ k]` matches the derived geometric law
with the derived ratio (`1/2` or `1/3`) to within sampling error. (b) The discriminating prediction:
the per-key ratio `c(key)` is **constant in the key**. A key-dependent shift `ε` in `c` is detectable
with `Θ(ε^{-2})` signatures by a two-sample test on one byte each — so at `ε = 2^{-5}` roughly
`10^3` signatures suffice, **with zero curve arithmetic on the analyst's side**. That is the
cheapest transcript statistic this program can name, and the corpus has never named it.

**Minimal discriminating test (with known-answer gate).** Toy scale, pure Python, `p ∈ {2^{11},
2^{13}, 2^{15}}` on the `F_{p^2}` 2-isogeny graph (`Φ_2` roots; `|V| ≈ p/12`).
(1) **Stage 0:** re-quote the definition and semantics of `n_bt` and `r_rsp` from a filed source.
If `n_bt` is a deterministic function of public data, the object does not exist and the entry
closes in one reading — pre-declared as a real outcome.
(2) Build two toy signers emitting the same field list. **Arm A ("translation-shaped"):** compose
the secret path, the commitment path and the hash-derived challenge path, then reduce the composite
to a non-backtracking cyclic path of the prescribed length, and publish the number of cancelled
leading steps. **Arm B ("simulator-shaped"):** choose a uniformly random non-backtracking path of the
prescribed length from `E_chl` and derive the rest backwards. Arm B is the null object
`GOAL-SQISIGN-001.next_action` requires *before* approval, and it is built first.
(3) **Known-answer gate, run before anything else:** a *planted* signer that draws `n_bt` from a
geometric law with a deliberately key-dependent ratio `c(key) = 1/2 ± δ` for
`δ ∈ {0, 2^{-3}, 2^{-5}}`. The estimator must recover `δ` inside its stated CI at each level and
must return "no effect" at `δ = 0`. An estimator that fires at `δ = 0` or misses `δ = 2^{-3}` is
void and no measured number is reported.
(4) Two keys, identical message stream, `N ∈ {10^3, 10^4}` signatures, pre-registered two-sample
test at `α = 0.01`, three replicates with declared seeds.

**Falsifier (reachable, numeric).** (F2a) Pooled `Pr[n_bt ≥ k]` deviates from **both** derived laws
by more than the sampling band at all three primes ⇒ the semantics of `n_bt` were mis-read and the
entry halts at Stage 0 rather than reporting a "surprise". (F2b) The two-sample test shows no
across-key effect at `ε ≥ 2^{-5}` in 3/3 replicates ⇒ **the channel carries less than 5 bits of
signal per `10^3` signatures at toy scale**, recorded as a bounded negative with its power stated,
not as "no leakage". (F2c) Arm A and Arm B give indistinguishable `n_bt` laws ⇒ the toy signer is
not translation-shaped and the instrument, not the scheme, is what was measured.

**Charged cost.** Machine model: single classical core. Graph construction at `p = 2^{15}`:
`|V| ≈ 2730` vertices, `≈ 8190` edges, `sympy`-free root-finding over `F_{p^2}` — minutes and
`< 100 MB`. Signing arm: path composition and reduction is `O(len)` per signature; `10^4`
signatures × 3 primes × 3 replicates × 2 arms ≈ `2·10^5` signings, budget **≤ 3 CPU-hours, hard
cap**. Storage: `10^4 × 148` bytes per arm — negligible, and **charged as negligible rather than
ignored**. No oracle, no preprocessing, no quantum resource, no QRAM.

**Kills-it-early.** Before writing the graph builder: read what `n_bt` counts. If it is bounded by
a public parameter and determined by `chl` alone, `H(n_bt | public) = 0` and the entry is dead in
an hour.

**Ceiling.** `toy`. The strongest supportable statement is about the two toy signers at
`p ≤ 2^{15}`, and by CEILING-S3(ii) it is never a zero-knowledge bound.

**Risk band.** `high_risk` — the object may not exist (F2a/Stage 0 kills it outright), and its most

### S3-3. The simulator's output alphabet: a quantifier-*domain* audit of which published symbols the zero-knowledge statement actually quantifies over

**Tracked object + what it discards.** The **pair of symbol sets** `(W, S)` where `W` = the fields
the real signer emits on the wire and `S` = the symbols the claimed simulator's statement
constructs — projected to the **set difference `W \ S`**. This discards every distribution, every
value, and every parameter: it retains a finite set of field names. The discard is structural
because `W \ S` is invariant under any reparametrisation of the fields' contents and cannot be
inverted to recover a single byte; two schemes with identical `W \ S` may have wildly different
laws, which is the point — this object is upstream of all distributional work in the slice.

**Mechanism.** A zero-knowledge or simulatability statement is a statement about *some* tuple. A
wire format is a statement about *all* transmitted bytes. If the theorem quantifies over
`(commitment, challenge, response)` as mathematical objects while the wire carries seven symbols,
then the fields in the difference are **emitted but unsimulated**, and a theorem about the tuple
does not, as stated, cover the transcript an adversary sees. This is
`docs/inventor-protocol.md` §8's quantifier-order audit turned ninety degrees: not "in what order
are the quantifiers", but **"over what domain does the outer quantifier range"**. The corpus has
applied the order audit to reduction *inputs* (`IDEA-20260805-d66193`, `B3-4`) and never to a
simulator's *output alphabet*.

**Prediction (numeric).** `W \ S ⊇ {n_bt, r_rsp, hint_aux, hint_chl}` — **4 symbols, 4 bytes, 32
bits per signature**. Over a `q = 2^{64}` signing budget that is `2^{69}` emitted-but-unsimulated
bits. **This is not a leak claim and must never be written as one**: unsimulated is not the same as
informative, and `H-SQISIGN-c0488f` already proves `I(hint ; φ_sk | E) = 0` for the hint bytes.
The claim is about **what the theorem covers**, and its consequence is bookkeeping: any comparison
of a measured transcript bound against the scheme's `λ` must state which alphabet the bound is over.

**Minimal discriminating test (with known-answer gate).** Zero compute; pure reading and set
arithmetic.

(2) Compute `W \ S` and `S \ W` (the second is also informative: a simulator that constructs a

(3) **Known-answer gate — two poles, both mandatory, both run before SQIsign.** Pole (+): Schnorr

**Charged cost.** Machine model: none (reading). Implementation: none. Compute: none. Storage:

### S3-4. `hint_pk` as a free estimator of the key-generation *marginal*: the conditional-zero result says nothing about it

**Tracked object + what it discards.** The **pushforward of the key-generation output measure
under the public hint function** `g : A ↦ (h_A, h)`, i.e. the law of `hint_pk` over independently
generated public keys. `g` discards the curve entirely: its fibre over a hint value has size
`≈ |{supersingular A}| / 256 ≈ p/512`, exponentially large in `log p`. The discard is structural
because `g` is a *residuosity-and-search* functional — `h_A` is a quadratic character and `h` is a
first-hitting index of a non-residuosity condition — and no invertible map takes 8 bits back to a
Montgomery coefficient. It is also, uniquely in this slice, **free**: the bytes are already
published and the estimator costs one table update per key.

**Mechanism.** `H-SQISIGN-c0488f` §C proves `I(hint_pk ; φ_sk | E_pk) = 0` **exactly**, because
`hint_pk = g(A_pk)` for a public `g`. That is a statement about the *conditional*. It says nothing
whatever about the **marginal** law of `hint_pk` over keys, and the marginal is a computable
functional of the KeyGen output measure on the supersingular set: `Law(hint) = g_*(Law(E_pk))`.
Determinism, which makes the conditional channel empty, is exactly what makes the marginal a
**faithful, zero-cost probe of KeyGen's uniformity** — the same property read in the opposite
direction. The reference law is derivable and, at toy scale, **exactly computable by enumerating
the supersingular set and applying `g` to every element**, so the null is not a model but an exact
finite object.

**Prediction (numeric).** Under a KeyGen output uniform on supersingular curves:
`Pr[h_A = 1] = 1/2` up to the deviation of the quadratic character on the supersingular subset from
its value on `F_{p^2}` — and the *size of that deviation is itself the interesting exactly
computable quantity at toy scale*. For the retry index, `Pr[h = k] = (1 − θ)θ^{k}` with `θ`
determined by the density of the non-residuosity-and-on-curve condition, plus an atom at `h = 0`
of mass `≈ θ^{128}` from the cap. **Discriminating prediction:** the exactly enumerated reference
law and the empirical law over honest keys agree within a pre-registered total-variation threshold;
a deviation beyond it is a **measurable key-generation non-uniformity observable from public keys
alone, with no isogeny computation and no secret**.

**Minimal discriminating test (with known-answer gate).** Toy scale, `p ∈ {2^{11}, 2^{13},
2^{15}}`, pure Python.
(1) Enumerate the supersingular `j`-invariants via `Φ_2` from a known supersingular start; lift to
Montgomery coefficients; apply `g` to every one. This is the **exact reference law**, not an
estimate — the entire population is enumerable at these sizes (`|V| ≈ 170 / 682 / 2730`).
(2) Sample `N` keys from a toy KeyGen (random ideal → walk of prescribed length) and compare the
empirical hint law against the exact reference by total variation and χ², three replicates,
pre-registered `α`.
(3) **Known-answer gate, two rungs.** (i) Apply `g` to uniformly random elements of `F_{p^2}` (not
restricted to supersingular): `Pr[h_A = 1]` must be `1/2 ± O(N^{-1/2})` exactly, because exactly
half of `F_{p^2}^*` are squares. If it is not, `g` is mis-implemented. (ii) A **planted
non-uniform KeyGen** that restricts the walk to a sub-region of the graph must be flagged at a
pre-registered effect size; a probe that cannot see a planted restriction cannot see an accidental
one.

**Falsifier (reachable, numeric).** (F4a) The **exact reference law at toy scale is far from the
uniform-ambient prediction** — e.g. `Pr[h_A = 1]` on the supersingular subset differs from `1/2` by
more than `3/√|V|` at 2 of 3 primes ⇒ the calibrated null must be the enumerated law, not the
analytic one, and the analytic prediction is withdrawn (a correction, and a cheap one). (F4b) The
probe's power is too low to matter: detecting a bias `ε` needs `Θ(ε^{-2})` **independently
generated public keys**, and real deployments do not publish `2^{20}` keys — so the honest ceiling
is `ε ≳ 2^{-5}` at any realistic key count, and if the pre-registered threshold is below that the
entry is **charged into irrelevance and must say so**. (F4c) The planted-restriction rung is not
flagged ⇒ the probe is void.

**Charged cost.** Machine model: single classical core. Enumeration at `p = 2^{15}`: `≈ 2730`
vertices, seconds. Sampling: `N = 10^4` toy keys × 3 primes × 3 replicates, minutes. Memory:
`O(|V|)` — a few MB, charged. **The resource that actually binds is data, not compute**: the
estimator's resolution is set by the number of *available public keys*, which is an external
quantity the experiment cannot buy, and pretending otherwise would be exactly the uncharged
resource rule 6 calls a defect.

**Kills-it-early.** Thirty minutes: enumerate the supersingular set at `p = 2^{11}` and histogram
`g`. If the exact reference law is already within noise of the analytic one, the calibration is
free and the entry proceeds; if it is not, the entry's value moves to the *calibration itself* and
the KeyGen comparison is secondary.

**Ceiling.** `toy`. No statement about SQIsign's real key distribution follows; the deliverable is
a calibrated instrument plus an exactly enumerated reference law at three toy primes.

**Risk band.** `conservative`.

**Nearest prior-art neighbour.** `IDEA-20260805-c4ae3d` —
`...|hint_pk_deterministic_zero_mutual_information|...`. **Why it is not that:** c4ae3d establishes
`I(hint ; φ_sk | E_pk) = 0`, a conditional statement, and uses it to close the per-key auxiliary

### S3-5. Stage A is closure-invariant, Stage B is not: the disclosure screen must run on the **cost-annotated poly-time closure**, not on the wire format

**Tracked object + what it discards.** `cl_C(Σ)` — the set of pairs `(derived quantity, charged
cost)` reachable in polynomial time from a published surface `Σ` (TO-CLOSURE, §0.2). The map
`Σ ↦ cl_C(Σ)` discards the *derivations*, the *order* in which quantities are obtained, and the
encoding of `Σ` itself, retaining a finite annotated list. It is **not** information-lossy — by
data processing, `S(cl(Σ)) = S(Σ)` — and that is the entry's content, not a defect: **Stage A of
`B3-1` is invariant under the map and Stage B is not**, so the two stages live on different objects
and `B3-1` runs them both on the wrong one. The projection is not invertible (the same annotated
list arises from every surface in a poly-time equivalence class), which is exactly what the
known-answer gate exercises.

**Mechanism.** `B3-1`'s screen has Stage A (residual entropy `|S(Σ)|`) and Stage B (does `Σ`
determine an instance of a **named, cited** poly-time-solvable problem). A *named constructor* is
an algorithm with a **typed input signature**; matching it is a question of *form*, not of
information. Two failure modes follow immediately and neither is in `B3-1`:

- **False negative (form-blindness).** Take SIDH's surface `Σ = (E_0, E_1, d, φ(P), φ(Q))` and
  re-encode as `Σ' = (E_0, E_1, d, φ(P), φ(P+Q))`. This is an **invertible** change of basis —
  identical information, one subtraction apart — but a literal type match against "images of a
  basis" can fail on `Σ'`. A screen returning `SAFE` on `Σ'` is broken, and this is the gate below.
- **False positive (cost-blindness).** Run the screen on the *unannotated* closure and every
  surface becomes `FATAL`, because "the constructor's input is derivable" is true whenever the
  constructor's input is *determined* — including when deriving it is the hard problem. The
  concrete instance is in this corpus: `H-SQISIGN-c0488f` STEP 7 observes that the Kani
  construction **already runs, inside SQIsign's verifier, on published data**. A closure screen
  without costs would call that `FATAL`; with costs, the derived quantities are free and carry zero
  conditional entropy, so the verdict is `SAFE`.

**The repair.** Screen `cl_C(Σ)`, and let Stage B match only on quantities whose charged derivation
cost is **below `min(KN-TECH-057 baselines)`** at the parameter set in question. The threshold is
the only place a baseline enters this slice, and it enters as a *constant*, never as an attack
route (OL-2). The demonstrative payoff is already available: the commitment curve `E_com` — the
exact symbol `IDEA-20260805-bb4bf8`'s mixing analysis is about — is **not transmitted** and appears
only in the closure, at cost = one verification. **A complete byte inventory does not contain the
object the zero-knowledge argument is about.**

**Prediction.** The wire-format screen and the closure screen **disagree on at least one surface**,
and the smallest witness is the basis-change pair `(Σ, Σ')` above. Further: the ordering
`SAFE ⊂ UNDECIDED ⊂ FATAL` is preserved under closure for Stage A and **not** preserved for Stage
B, so `B3-1`'s three-valued verdict is not a function of `Σ` alone but of `(Σ, encoding)` — a
well-definedness defect, which is a stronger and cheaper criticism than any measurement.

**Minimal discriminating test (with known-answer gate).** Zero compute; algebra and one small
table.
(1) Build a four-row surface table: `Σ_SIDH` (basis images, known `FATAL` — used only as a
known-positive control, OL-1); `Σ'` (invertible re-encoding, above); `Σ''` (images under one
unknown *common* scalar, recovery = a DL in `μ_N` with smooth `N`, cost `polylog`);
`Σ'''` (images masked by an unknown `2×2` matrix, recovery cost `≈ |GL_2(Z/N)| ≈ N^4`).
(2) Run `B3-1`'s screen as written on each; run the cost-annotated closure screen on each; tabulate.
(3) **Known-answer gate, mandatory and first:** `Σ'` **must** be `FATAL` under any admissible
screen, because it is one subtraction from `Σ_SIDH`. A screen that returns `SAFE` on `Σ'` is
form-blind and its every other verdict is void. Symmetrically, `Σ'''` **must not** be `FATAL`
without the `N^4` cost being stated in the verdict.

**Falsifier (reachable).** (F5a) The wire-format screen and the closure screen **agree on all four
rows**, and no fifth row can be constructed on which they disagree ⇒ the correction is vacuous,
`B3-1` stands as written, and this entry closes as a clean negative — a fully usable outcome.
(F5b) The cost annotation cannot be assigned because "the cost of deriving `X` from `Σ`" is not
well-defined without fixing an algorithm ⇒ the repair is ill-posed and must be recorded as
`UNDECIDED`, not as an improvement. (F5c) The threshold `min(KN-TECH-057 baselines)` is itself
conditional (the `F_p` figure assumes unproven subgraph mixing) ⇒ every closure verdict inherits
that conditionality and **must carry it in the verdict string**, not in a footnote.

**Charged cost.** Machine model: none. Implementation: none beyond a four-row table. Compute: none.
The costs that must be charged are the *screen's own*: the annotation step requires naming an
algorithm and its resources for every derived quantity, and an entry that leaves one unannotated
has re-introduced exactly the `REDUCTION_REQUIRES_UNCHARGED_ORACLE_OR_FULL_END` failure `EV-SSI-004`
names.

**Kills-it-early.** One paragraph, zero compute: apply `B3-1`'s Stage-B table to `Σ'`. If it
matches row (i) — "isogeny with known degree matrix between known abelian varieties given a
specifiable kernel" — then `B3-1` is already form-robust on the only witness this entry can

**Ceiling.** `control`. It is an instrument correction. It produces no attack, no measurement, and

function of the object it claims to screen.

### S3-6. Algebraic-locus membership as a built-in fault checksum, and the curve/quaternion asymmetry that prices SQIsign's fault surface

**Tracked object + what it discards.** TO-LOCUS (§0.2): the one-bit indicator `1[v ∈ L]` that an
intermediate value lies in its intended algebraic locus. On the curve side `L` = supersingular
Montgomery coefficients, `|L| ≈ p/2` inside an ambient `F_{p^2}` of size `p^2`, density
`≈ 1/(2p)`. On the quaternion side `L` = a fixed maximal order `O` with a `Z`-basis, and a
coefficient perturbation keeps `v ∈ O` **identically**. The discard is `2 log2 p − 1` bits on the
curve side and is structural, because supersingularity is an arithmetic condition of vanishing
density and not a sublattice; on the quaternion side the "discard" is of measure zero, i.e. the
projection there **is** a change of coordinates — and that contrast is the entry.

**Mechanism.** Isogeny arithmetic has a property no lattice or symmetric primitive has: its state
space is a **vanishing-density subset of the ambient field**, and membership is *cheaply testable*.
A single-bit perturbation of a curve coefficient therefore leaves the intended locus with
probability `1 − O(1/p)`, and — crucially — the property **propagates**: applying a 2-isogeny
formula to a non-supersingular curve yields a non-supersingular curve, so **one supersingularity
test at the end of a chain detects a fault anywhere in it**. The quaternion side of SQIsign — KLPT,
ideal arithmetic, `RandomEquivalentPrimeIdeal`, Cornacchia — has no such structural checksum: a
perturbed quaternion element is still a quaternion element in the same order, and the only
redundancy available is an explicit norm check that must be paid for.

**Prediction (numeric).** (a) The probability that a uniformly random single-bit flip of a
supersingular Montgomery coefficient yields a supersingular curve is `≈ 1/(2p)` — at NIST-I
(`p ≈ 2^{250.3}`) that is `≈ 2^{-251.3}`. (b) The detection cost is **one** supersingularity test
per chain, `O(log p)` `F_{p^2}`-operations, versus `O(1)` per isogeny step — so end-of-chain
detection is a `Θ(log p / len)` relative overhead, not a per-step one. (c) On the quaternion side
the same indicator has detection probability **exactly 0**, and the cheapest structural substitute
is a reduced-norm recomputation costing `Θ(1)` multiplications per checked value. **Conclusion,
stated as a structural asymmetry and not as an attack:** SQIsign's fault-detection surface is
concentrated entirely on the side of the computation that has *no* free checksum, and that side is
the one SQIsign has more of than any other candidate.

**Minimal discriminating test (with known-answer gate).** Toy scale, pure Python, no fault
hardware, no implementation of SQIsign.
(1) At `p ∈ {2^{11}, 2^{13}, 2^{15}}` enumerate the supersingular set. For each supersingular `A`
and each bit position, flip and test supersingularity; measure the empirical hit rate and compare
to `1/(2p)`.
(2) Repeat with the coefficient held **projectively** as `(A : C)`, flipping bits of `A` and of
`C` separately. This is the entry's real risk: real implementations store `(A_{24} : C_{24})`, and
a flip in `C` may map to a different representative of the *same* curve.
(3) **Known-answer gate, three rungs, all before any reported number.** (i) Flip **zero** bits: the
measured membership rate must be exactly `1.000`. (ii) Flip a bit of a **known ordinary** curve
coefficient: the rate must be the ambient-density value, not `1`. (iii) Apply the identical harness
to a quaternion element in a `Z`-basis of an order: the measured membership rate must be exactly
`1.000` **for every flip** — this rung is the asymmetry, and if it does not return `1.000` the
harness is testing the wrong locus.
(4) Charge the countermeasure: count `F_{p^2}` operations for one end-of-chain supersingularity
test versus one chain, at three chain lengths.

**Falsifier (reachable, numeric).** (F6a) The projective arm shows a membership rate `≫ 1/(2p)` —
e.g. `> 2^{-4}` at `p = 2^{15}` — because many `(A : C)` perturbations land on the same curve ⇒
**the free checksum is an artifact of the affine representation and does not exist in the
representation implementations actually use.** This is the most likely way the entry dies and it is
the reason step (2) is not optional. (F6b) Supersingularity fails to propagate through the isogeny
formulas as claimed (some formula maps an ordinary input back into the supersingular locus) ⇒
end-of-chain detection is unsound and the cost claim (b) collapses to a per-step one. (F6c) The
quaternion rung returns anything other than `1.000` ⇒ locus mis-specified, no asymmetry claim.

**Charged cost.** Machine model: single classical core. Enumeration + flips at `p = 2^{15}`:
`2730` curves × `2·15` bit positions × 2 representations ≈ `1.6·10^5` supersingularity tests, each
`O(log p)` field operations — minutes. Memory `O(|V|)`. **No fault-injection hardware is used or
priced**; the entry makes a statement about *detectability*, and the cost of *causing* a fault is
explicitly outside its charge and outside its claim. No oracle, no preprocessing, no quantum
resource.

**Kills-it-early.** Twenty minutes: flip bits of the projective `(A : C)` pair at `p = 2^{11}` and
count how many land on the same curve. If a constant fraction do, the checksum is affine-only and
the entry is finished before the asymmetry is written down.

**Ceiling.** `toy`. The measured rates are toy-scale; the density argument extrapolates as
*arithmetic*, not as an experimental finding, and the entry may not be cited as a statement about
any implementation's fault resistance.

**Risk band.** `conservative`.

**Nearest prior-art neighbour.** `B3-2` —
`disclosure_projection_lattice_C0..C7_...|constraint_rank_minus_mask_dimension_r-m|composition_compatibility_is_not_safety`.
**Why it is not that:** `B3-2`'s projections are of **disclosed** data and are chosen by the
protocol designer; S3-6's projection is of an **internal, never-published** intermediate value and
is chosen by the fault model, so it is a statement about self-checking algebra rather than about
disclosure — and its verdict is a *countermeasure price*, not a safety ordering.

### S3-7. The second published curve: extend the cancellation audit to `E_aux`, where the identity does not obviously hold, using the theorem-dead response arm as the negative control

**Tracked object + what it discards.** The **coincidence partition** of the multiset of published
curve symbols across a batch of `q` signatures under one key: the partition of `{1..q}` induced by
"which signatures published the same curve". Applied separately to the `E_aux` stream and to the
verifier-derived response-codomain stream. The projection `(curves) ↦ (partition)` discards *which*
curves — it is invariant under every relabelling of the vertex set — and retains only the
block-size profile. The discard is structural and this is the sharpest instance in the slice: the
fibre over a partition is the set of all labelled curve assignments with that block structure,
of size `≈ n^{#blocks}`, and **no invertible map recovers a `j`-invariant from a partition**. That
relabelling-invariance is also what makes the null exactly Poisson rather than model-dependent.

**Mechanism.** `IDEA-20260805-18a4d4` proves, by `I·conj(I) = n(I)·O` and triviality of scalars on
ideal classes, that `[conj(J_i)·J_j] = [conj(I_{ψ_i} I_{φ_i})·I_{ψ_j} I_{φ_j}]` — the secret
cancels **exactly**, so every pair statistic on **response codomains** is secret-independent at
every parameter, with no heuristic. Coincidence of two response codomains is exactly the event
"that connecting class is trivial", so **the response arm is dead by theorem**. That is not a
reason to stop; it is a free, exact, theorem-backed **negative control**, and this corpus has never
had one.

The live question is whether the identity extends to the **second published curve symbol**.
`E_aux` is not the codomain of `J_i`: it is the codomain of a *complementary* isogeny whose degree
is chosen by the signer to complete the higher-dimensional representation, i.e. its degree is a
function of `deg φ_rsp` and hence of the signer's *representative choice*, not of the class. The
cancellation argument, as written, does not cover it. **Higher-dimensional structure enters here
strictly as an analysis instrument** (OL-9): the entry uses the fact that a second curve exists and
why, and computes nothing in dimension 2.

**Prediction (numeric).** Under a batch of `q` signatures on a graph with `n ≈ p/12` vertices, the
number of coincident pairs in each stream is Poisson with mean `C(q,2)/n` — at `p = 2^{15}`
(`n ≈ 2730`) and `q = 200`, mean `≈ 7.29`. **Response arm:** the observed count must be
Poisson(7.29) and **must not depend on the key** — that is the theorem, and any across-key
dependence there is an instrument failure, not a finding. **`E_aux` arm:** if the cancellation
extends, the same Poisson law and the same key-independence; if it does not, an across-key
difference in the coincidence rate that is *absent* in the response arm. **The paired design is the
whole point: one arm has a proof attached and the other does not, and they are measured with the

### S3-9. The pairing-relation rank ledger: the public Weil relations are rank-deficient by exactly one, uniformly in the number of signatures

unknowns and stops. **Push the accounting through and it becomes a rank statement with a sharp
number.** Given `w`, for each unit `u ∈ (Z/2^f)^×` the value `d ≡ w·u^{-1}` is determined; the
constraint `d < 2^{e_rsp}` selects a fraction `2^{e_rsp − f} = 2^{-e_chl}` of the `2^{f−1}` units,

### S3-10. Does the secret key hold anything beyond the public curve? A derived `O(1)`-bit ceiling on `H(d | E_pk)`, and the lane it closes

**Tracked object + what it discards.** The **conditional law of the secret degree given the public
curve**, `Law(d | E_pk)`, and its entropy `H(d | E_pk)`. The map `(I_sk, E_pk) ↦ (nrd(I_sk), E_pk)`
discards the ideal, its generators, the isogeny, and the whole representative structure, retaining
one integer and one curve. The discard is structural: the fibre over `(d, E_pk)` is the set of all
left `O_0`-ideals of norm `d` in the class of `E_pk`, and even when that set is small the *ideal*
is not recoverable from `(d, E_pk)` by any map — recovering it is the ideal-to-isogeny problem.
Retaining the integer alone is therefore a genuine collapse, not a coordinate change.

**Mechanism.** `H-SQISIGN-c0488f` §D relays Section 3.1.6.2: KeyGen samples `I_sk` of norm `D_mix`
and replaces it by the output of `RandomEquivalentPrimeIdeal`, whose norm is "approximately
`√p`". The Deuring correspondence puts the left-ideal class set of `O_0` in bijection with
supersingular `j`-invariants, so **the class is determined by `E_pk`**. The only entropy the secret
can hold beyond `E_pk` is therefore the **choice of representative** within the class — and, if the
prime-norm reduction is (near-)deterministic given the class, that entropy is nearly zero.

Count it. For prime `ℓ`, the number of left `O_0`-ideals of norm `ℓ` is `ℓ + 1`, spread over
`h ≈ p/12` classes, so the expected number in a *given* class is `≈ 12(ℓ+1)/p`. Summing over primes
`ℓ ≤ X`:

> `E[#{prime-norm ideals of norm ≤ X in a fixed class}] ≈ (12/p)·Σ_{ℓ ≤ X} ℓ ≈ 6X² / (p·ln X)`.

At `X = √p` this is `12 / ln p` — **`0.069` at NIST-I** (`ln p ≈ 173`). Solving
`6X²/(p ln X) = 1` gives `X ≈ √(p·ln p / 12) ≈ 3.8·√p`, i.e. `log2 X ≈ e_rsp + 1.9`. So the
*smallest* prime norm in a random class sits about **1.9 / 2.2 / 2.4 bits above `2^{e_rsp}`** at
NIST-I / III / V, and the number of prime norms inside any window of width `b` bits above the
minimum is `O(2^{b})·(small constant)`.

parameter set**, whatever the acceptance window, provided the window is a few bits wide.

guidance says surviving information must live in **representative-sensitive** functionals. This
count says **the representative carries at most a handful of bits given the curve** — so that whole
lane has an information ceiling of a few bits before any statistic is designed. **A ceiling
argument whose expected verdict is CLOSED, stated as one.**
