## Falsifiable hypothesis

A deliberately nonfaithful x-coordinate relation language that does not primitive-positive define signed elliptic addition admits a genuinely non-affine weak-near-unanimity (WNU) operation preserving a sparse x-factor base. A separate public cocycle then lifts every accepted quotient assignment to all exact signed point sources, enabling complete relation collection and masked target descent with time and memory exponents below rho and BSGS.

## Mechanism-new operation

The operation is **nonfaithful x-only WNU closure followed by an all-sign-strata algebraic lift**. Unlike IDEA-146, the basic language omits any relation from which the signed addition graph can be primitive-positive defined. The removal test is simultaneous proof of nondefinability, non-affine WNU preservation, and a source-biconditional sign lift. Merely changing the CSP solver or hiding the same faithful addition graph is a control.

The first theorem-only producer receipt closes the natural full-`S3` realization.
Four adjacent Kummer states primitive-positive interpret one oriented group element,
and seven ternary x-only atoms define faithful addition on those encodings. The second
receipt proves that any full affine `S_m` relation for fixed `m>=5` primitive-positive
defines affine `S3` using only nonzero public pins; a local extension over the four
missing window values restores the same modular-averaging contradiction. The third
receipt closes strict affine `S4` with a two-atom chain and 33 nonzero public pins.
The fourth receipt proves that a fixed proper subset of signed summation branches
is not lift-invariant on an x-only quotient. It also corrects the model boundary:
the ambient no-go does not by itself close a WNU defined only on the induced sparse
factor-base template. Such an induced WNU is useful only with a charged implicit
support/witness router; explicit endpoint-labelled template access has `B^m` size.
The survivor is therefore an induced-template router plus WNU and exact source lift,
a genuine lift-invariant tuple predicate with the same complete access path, or a
different non-WNU operation.

## Assumptions

1. Public `E/F_p`, prime-order `<P>` of order `N`, target `Q=[x]P`, and x-factor base `F_x` of size `B=N^beta` are frozen.
2. One target-uniform x-only signature handles repetitions, infinity, tangencies, and all sign classes without defining signed `Add`.
3. A constant-arity non-affine WNU preserves every basic relation and `F_x`.
4. A public cocycle lifts each quotient solution to every exact signed point tuple with no source table.
5. Setup, failed queries, lift branches, output, rank, factor logs, descent, verification, and bit memory are charged.

## Full rho/BSGS cost model

Pollard rho costs `N^(1/2+o(1))` time with constant state; BSGS costs `N^(1/2+o(1))` time and memory. Let quotient/WNU setup cost `N^a,N^a_m`; reciprocal relation and target densities be `N^delta,N^delta_t`; one quotient query plus exact lift cost `N^q,N^q_m`; output and target ambiguity exponents be `o,u`; and factor-log linear algebra cost `N^ell,N^ell_m`. With `B=N^beta`, the complete exponents are

`lambda=max(a,beta+delta+q+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Promotion requires both exponents at most `0.45`; quotient correctness alone has no performance meaning.

## Likely fatal obstruction

The producer theorems prove that full ternary Kummer/Semaev and every full affine `S_m` for fixed `m>=4` recover the faithful-addition obstruction using only nonzero public constants and nonzero intermediate states. A fixed proper sign-branch family is not a well-defined x-only relation. Restricting to the induced factor-base template avoids the ambient interpretation only formally unless a compact support and witness operation replaces its `B^m` explicit template.

## Proof track

Exhibit one explicit signature, prove nondefinability of signed addition, construct a non-affine WNU preserving the sparse base, prove an all-strata source biconditional, and derive `lambda,mu<=0.45` through blind descent.

## Disproof track

Derive signed addition from the lift, prove every preserving operation affine, find one lost or false source stratum, expose `B^m` ancestry, or prove either complete exponent at least `0.5`.
