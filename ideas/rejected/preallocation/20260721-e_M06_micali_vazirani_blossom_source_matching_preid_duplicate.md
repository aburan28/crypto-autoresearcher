## Mechanism-new operation

Micali-Vazirani grows alternating search structures and handles blossoms to find maximum matching in a supplied general graph. It counts only if edges are endpoint-derived and a matching is biconditional with, and decodes to, a complete signed elliptic relation; applying the native method to a supplied graph, sequence, matrix, distribution, score array, or source catalogue is a duplicate/control.

## Likely fatal obstruction

The algorithm changes the matching solver, not the construction of the graph. Any faithful edge set contains pairwise source compatibility; sparse pair edges admit spurious five-way recombination, while preventing it restores tuple-sized gadgets. A maximum matching is not a target relation, and blossom contraction does not create missing occurrence labels. This is a solver substitution.
