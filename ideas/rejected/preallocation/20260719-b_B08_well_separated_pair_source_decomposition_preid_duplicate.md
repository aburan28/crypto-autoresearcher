## Falsifiable hypothesis

Embed public partial elliptic sums into fixed-dimensional Euclidean space, build a well-separated pair decomposition (WSPD), and search only `O(B^2)` cluster pairs for the exact complementary endpoint. The decomposition preserves exact signed source labels under restrictions and gives complete sub-rho descent.

## Mechanism-new operation

The native operation covers all pairs of a supplied fixed-dimensional point set by linearly many well-separated cluster pairs. It counts only if a public embedding makes geometric separation exact and target-uniform for elliptic equality rather than approximate proximity.

## Assumptions

1. A fixed-dimensional, bounded-distortion public embedding makes exact elliptic complement equality local in WSPD cells.
2. Approximate cluster representatives can be refined to an exact occurrence without reopening all pairs.
3. Embedding, split tree, restrictions, refinements, output, rank, logs, descent, and memory are charged.
4. The same decomposition serves calibration and fresh blind targets with all charts.
5. No explicit pair table, source-fitted metric, post-hoc nearest-neighbour selector, or uncharged refinement is admitted.

## Likely fatal obstruction

WSPD compresses proximity in a supplied low-dimensional metric. Exact elliptic group equality is a rare algebraic predicate with no proved Lipschitz locality; forcing zero approximation error or verifying every candidate reopens the explicit pair search. This merges with IDEAs `143/326/350/359/393` and the earlier WSPD pre-ID control.

## Proof track

Give a faithful fixed-dimensional endpoint embedding, prove exact cell-level biconditional and bounded refinement under restrictions, and close the complete descent costs.

## Disproof track

Construct two equally separated configurations with different exact complement bits, show dimension/distortion grows, or charge refinement above the caps.

## Positive and negative controls

- Positive: a supplied Euclidean point set with a unique exact near pair.
- Negative: same WSPD summaries with one equality toggled, no-hit inputs, adversarial restrictions, chart collisions, and blind targets.
- Baselines: IDEAs `143/326/350/359/393`, explicit all-pairs, Query2P1, rho, BSGS.

## Quantitative promotion and falsification gates
