## Mechanism-new operation

The Lindstrom-Gessel-Viennot mechanism uses a determinant and sign-reversing cancellation to enumerate nonintersecting path families in a supplied weighted DAG. It counts only if the DAG and weights are endpoint-derived, nonvanishing is exact in the base field, and a term lifts to labelled elliptic sources; applying the native method to a supplied graph, sequence, matrix, distribution, score array, or source catalogue is a duplicate/control.

## Likely fatal obstruction

The determinant compresses path families only after an acyclic weighted network and its path sums are available; those arcs encode the missing compatibility state. In the ECDLP base field, signed families can cancel even when sources exist, so determinant nonzero is not an exact existence bit. Self-reduction requires repeated source-addressable restrictions, and retaining a term's occurrence labels restores the source catalogue. This is a determinant aggregate/representation merge.
