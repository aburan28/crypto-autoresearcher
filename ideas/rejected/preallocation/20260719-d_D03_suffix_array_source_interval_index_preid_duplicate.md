## Falsifiable hypothesis

Encode each signed partial-sum trace as a target-independent word whose suffixes share long public endpoint prefixes. A suffix array plus LCP/range-minimum intervals would answer exact restricted target-pattern existence and locate one source occurrence, enabling factor-log relations and fresh blind descent below rho and BSGS.

## Mechanism-new operation

Suffix arrays lexicographically sort all suffixes of a supplied text so pattern matches occupy contiguous intervals. It counts only if a sub-gate public text is biconditional with every elliptic source tuple and supports source restrictions; serializing an explicit tuple language or changing only the string index is a control.

## Assumptions

1. There is an injective, target-independent word encoding of all signed elliptic addition strata with bounded total text length.
2. Text construction, sorting, suffix/LCP state, pattern compilation, restrictions, source positions, replay, rank, logs, descent, bit time, and memory are charged.
3. Lexicographic intervals preserve group-sum equality and repeated/tangent/vertical/infinity semantics exactly.
4. One frozen text serves known-log and fresh scalar-blind targets without embedding target or scalar labels.
5. No explicit `B^3`/`B^5` source text, FM-index rename, post-hoc selector, or dense resultant is admitted.

## Complete factor-base-to-target-descent path

1. Freeze curve, decks, charts, alphabet, serialization, restrictions, pattern compiler, and verifier.
2. Construct a target-independent text and suffix/LCP state within `B^(9/4+o(1))` without materializing source tuples.
3. Compile known-log targets to exact patterns, answer every restricted existence query, and replay five verified occurrences.
4. Collect at least `B` independent rows, preserve dependencies/failures, and solve factor-base logarithms.
5. Reuse unchanged state for fresh scalar-blind `Q+[t]P`, recover a tuple, remove `t`, and verify `[x]P=Q`.
6. Charge serialization, sorting, indexing, all negative intervals, output, rank, logs, descent, verification, bit operations, and memory.

For explicit scalar semantics, write each recovered factor-base occurrence as `A_i=[alpha_i]P` with sign `epsilon_i in {+1,-1}`. A known-log relation target `R=[kappa]P` yields the checked row `sum_i epsilon_i alpha_i = kappa (mod N)`. Source replay uses at most `5 ceil(log_2 B)+O(1)` charged positive-parent/negative-child restriction queries plus singleton checks. For a fresh masked target `R=Q+[t]P=[x+t]P`, a verified tuple yields `x=sum_i epsilon_i log_P(A_i)-t (mod N)`; the final check is `[x]P=Q`. Every failed restriction branch and scalar verification is charged.

## Full rho/BSGS cost model

Let `a,a_m` charge construction/storage of the complete public text, suffix array, LCP/RMQ state, and source-position satellites; let `q,q_m` charge target-pattern compilation, every restricted interval search, negative branch, bisection, and replay. Let `delta,delta_t` be reciprocal verified relation/target success, `o` output, `r` verified independent-rank credit, `u` ambiguous suffix intervals plus any restriction rebuild, and `ell,ell_m` factor-log time/state.

With `B=N^beta`, `beta=1/5`, require `lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`, `mu=max(a_m,q_m,beta+o,ell_m,u)`, `0<=r<=o`, setup/state `<=B^(9/4+o(1))`, fresh construction/search/replay work `<=B^(5/4+o(1))`, and `lambda,mu<=0.45`. Pollard rho time and BSGS time/memory are `0.50` controls. Full source-text length and target/restriction rebuilds are charged, not treated as preprocessing advice.

## Likely fatal obstruction

A suffix array accelerates pattern search only after a text exists. A text containing every accepting trace and source position is the missing source catalogue; coarser endpoint tokens collide on different source occurrences and elliptic addition is not free-monoid concatenation. This merges with IDEAs `073/084/120/371/397` and pre-ID `A06/A12/B05`.

## Proof track

Give a bounded endpoint-only serialization theorem, exact target-pattern biconditional, restriction-stable interval queries, and a source-position inverse, then close the full descent cost.

## Disproof track

Exhibit source-sized text length, two source languages with the same public suffix intervals but different witnesses, or a chart where concatenation loses group semantics.

## Positive and negative controls

- Positive: a supplied planted source text with exact pattern intervals and source positions.
- Negative: equal endpoint-token strings with different occurrence ancestry, absent patterns, arbitrary restrictions, exceptional charts, and blind targets.
- Baselines: IDEAs `073/084/120/371/397`, pre-ID `A06/A12/B05`, explicit tuple serialization, P1553 R4, rho, BSGS.

## Quantitative promotion and falsification gates

- Promote only with sub-gate endpoint-only text construction, exact all-strata patterns, charged occurrence replay, `1,000` independent rows, `100` blind descents, and `lambda,mu<=0.45`.
- Falsify on one source-bearing text symbol/position, one pattern/source mismatch, target rebuild, cap violation, or complete exponent `>=0.50`.
