## Falsifiable hypothesis

Serialize target-compatible endpoint transitions as a pattern and factor-base transition decks as a text. KMP prefix failure links would skip impossible overlaps while preserving an exact match position whose ancestry replays a signed source tuple for relations and blind descent below rho and BSGS.

## Mechanism-new operation

KMP preprocesses a supplied pattern's border/failure function and scans a supplied text without rechecking characters. It counts only if pattern and text are endpoint-derived before source incidence is known, symbol equality is exact relation compatibility, and a match position returns labelled factor occurrences. Searching an enumerated source text is a control.

## Assumptions

1. Target-independent text and target-compiled pattern cover all signed and exceptional strata exactly.
2. Text/pattern generation, prefix table, every symbol comparison, restrictions, locate/replay, rank, logs, descent, bit time, and memory are charged.
3. A substring match is biconditional with a valid five-source tuple, not only an endpoint word collision.
4. Failure links preserve occurrence ancestry and arbitrary source restrictions.
5. Text state is reusable for fresh blind targets without target-specific source enumeration.

## Complete factor-base-to-target-descent path

1. Freeze curve, decks, charts, alphabet, text/pattern serialization, prefix/tie rules, restrictions, and verifier.
2. Build target-independent text/index within B^(9/4+o(1)) without enumerating source transition words.
3. For R=[kappa]P, scan exact restricted patterns, replay labelled A_i,epsilon_i in at most 5 ceil(log_2 B)+O(1) queries plus failed siblings, verify sum_i epsilon_i A_i=[kappa]P, and record sum_i epsilon_i y(A_i)=kappa.
4. Collect at least max(d_FB+32,1,000) verified rows, require rank d_FB, preserve failed matches/dependencies, and only then solve factor logs.
5. Reuse unchanged text for R=Q+[t]P, recover a match, compute x=sum_i epsilon_i log_P(A_i)-t, and verify [x]P=Q.
6. Charge text/pattern construction, prefix tables, every scan/comparison, restrictions, locate/replay, rank, logs, descent, scalar checks, bit complexity, and memory.

## Full rho/BSGS cost model

Let L_T,L_P be text/pattern lengths, C_sym exact symbol construction/comparison work, Q_R restrictions, and C_inv match-to-source inversion. KMP costs Theta((L_T+L_P)C_sym) for supplied strings and O(L_P) prefix state, plus storage/access for the text. Set a=log_N(T_text+L_T C_sym), a_m=log_N(L_T+L_P), q=log_N(Q_R((L_T+L_P)C_sym+C_inv+T_restrict)+T_replay), and q_m=log_N(L_T+L_P+M_inv). With beta=1/5 and delta,delta_t,r,o,u,ell,ell_m:

lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)

mu=max(a_m,q_m,beta+o,ell_m,u), 0<=r<=o.

Require setup/state <=B^(9/4+o(1)), complete fresh work <=N^(0.25+o(1))=B^(5/4+o(1)), lambda,mu<=0.45, and four increasing-B one-sided 95% bounds. Rho and BSGS are 0.50.

## Likely fatal obstruction

KMP skips comparisons only after both strings exist. A faithful text is the source catalogue; coarse symbols create false matches and lose occurrence ancestry. Arbitrary restrictions change the text, and the failure table supplies no unknown-match discovery beyond scanning. This merges with IDEA-084 and pre-ID A06/A12.

## Proof track

Construct endpoint-only sub-gate strings with a match/source biconditional stable under restrictions and close locate, replay, rank, and descent costs.

## Disproof track

Show a text symbol or comparison requires a source tuple, or give equal serialized strings with different valid occurrence ancestry.

## Positive and negative controls

- Positive: supplied strings with one planted labelled match.
- Negative: equal endpoint symbols with incompatible ancestry, repetitive worst cases, empty/singleton restrictions, exceptional and blind targets.
- Baselines: IDEA-084, pre-ID A06/A12, explicit text search, P1553 R4, rho, BSGS.

## Quantitative promotion and falsification gates

- Promote only with endpoint-only text/pattern, exact restriction-stable match/source inversion, rank d_FB, 100 blind descents, both caps, and lambda,mu<=0.45.
- Falsify on one source-derived symbol, false match, restriction rebuild beyond cap, or complete exponent >=0.50.
