## Likely fatal obstruction

Delaunay structure is defined for a supplied metric point set and preserves geometric proximity, not elliptic sum equality. No known low-dimensional endpoint feature map makes compatible five-tuples local. Storing source feature points and cell backpointers is the source catalogue, while exact high-dimensional complexes can have prohibitive size.
