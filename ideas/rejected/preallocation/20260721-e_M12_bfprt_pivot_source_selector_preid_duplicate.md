## Falsifiable hypothesis

For generic prime-order `E(F_p)`, one can assign public scores to partial source states, use BFPRT median-of-medians partitioning to select a promising quantile deterministically, and recurse until an exact signed relation occurrence remains. The target-uniform operation supports exact arbitrary restrictions, at least `max(d_FB+32,1000)` verified independent rows of rank `d_FB`, complete factor logs, and 100 fresh blind descents with complete time and live-memory exponents below rho and BSGS.

## Mechanism-new operation

BFPRT/PICK selects an order statistic in linear comparisons from a supplied comparable array. It counts only if the candidate array and score order are endpoint-derived without source enumeration and selected quantiles preserve every exact relation under restrictions; applying the native method to a supplied graph, sequence, matrix, distribution, score array, or source catalogue is a duplicate/control.

## Assumptions

1. A subgate endpoint-derived stream contains all relevant partial sources with public scalar-blind scores.
2. Every nonempty restricted fibre has a uniform score gap placing a valid source in the selected quantile.
3. Partitioning and discarding never remove the sole valid occurrence or exceptional stratum.
4. The selected item retains occurrence-distinct signed source provenance.
5. Input generation, comparisons, recursion, failures, rank, logs, descent, and memory meet the full gates.

## Likely fatal obstruction

BFPRT reduces comparisons only after the candidate array and total-order scores exist. Producing that array is the source enumeration, and no public scalar-blind score has a proven gap separating a rare relation from invalid partial states. Selecting a quantile is a post-hoc selector/parameter change; it does not certify empty restrictions or construct source provenance.
