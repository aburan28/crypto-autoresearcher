## Falsifiable hypothesis

Compile partial signed decompositions into a capacitated network whose integral s-t flows are exactly target relations; Dinitz blocking flows would recover a source, complete logs, and descend blind targets below rho/BSGS.

## Mechanism-new operation

Dinitz builds residual level graphs and blocking flows on a supplied network. It counts only if public endpoints create all vertices/arcs/capacities and flow paths are biconditional with relations; max flow on explicit compatibility is a solver control.

## Assumptions

1. A compact target-uniform network represents all and only signed sources.
2. Arcs/capacities are endpoint-derived, not source advice.
3. Restrictions update the network within the query cap.
4. Integral flow paths lift to exact occurrences and absence is exact.
5. Construction, phases, replay, rank, logs, descent, bit time, and memory are charged.

## Full rho/BSGS cost model

For V vertices and E arcs, charge T_graph+O(V^2 E) general time and O(V+E) state: a=log_N(T_graph+V^2E), a_m=log_N(M_graph+V+E), q=log_N(Q_R(V^2E+C_path)+T_replay), q_m=log_N(V+E+M_path).

For B=N^beta, beta=1/5, let delta,delta_t be reciprocal verified-hit densities, r independent-rank credit, o output, u ambiguity/rebuild/error overhead, and ell,ell_m factor-log time/state:

lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)

mu=max(a_m,q_m,beta+o,ell_m,u), 0<=r<=o.

Require setup/advice/state <=B^(9/4+o(1)), complete fresh work/workspace <=N^(0.25+o(1))=B^(5/4+o(1)), and lambda,mu<=0.45. Rho expected time and BSGS time/memory are 0.50. Four increasing B values require one-sided 95% upper bounds below empirical gates.
