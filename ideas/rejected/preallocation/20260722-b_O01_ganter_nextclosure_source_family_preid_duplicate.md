## Falsifiable hypothesis

For a generic prime-order curve, public endpoint restrictions define a compact formal
context whose NextClosure intents are exactly the nonempty five-source fibres. Lectic
enumeration and restriction replay would return signed factor-base occurrences for
relations and fresh masked targets with complete time and memory exponents at most `0.45`.

## Mechanism-new operation

NextClosure obtains the next closed attribute set from a supplied closure operator in
lectic order. It counts here only if the context and closure queries are derived from
public endpoints without source incidence, and closure is biconditional with exact
restricted target existence plus one occurrence-labelled inverse. Enumerating concepts
of a supplied relation table is a control.

## Assumptions

1. The object-attribute context is target-independent, endpoint-derived, and inside the setup cap.
2. Closure distinguishes all signed, repeated, tangent, vertical, identity, and infinity strata.
3. Every nonempty restricted fibre corresponds to a replayable closed-set branch.
4. All-negative closure queries and lectic skips are charged.
5. Byte-identical state supports known-log rows and fresh scalar-blind masked targets.

## Complete factor-base-to-target-descent path

1. Freeze `B=N^(1/5)`, five signed decks, all exceptional strata, context encoding, closure oracle, lectic order, restrictions, and independent point verifier.
2. Build target-independent context/state within `B^(9/4+o(1))`; forbid source tables, target-trained attributes, dense resultants, scalar labels, and hidden Query2P1 calls.
3. For each known-log target, answer exact restricted existence, replay actual signed occurrences, and retain a row only after point equality verification.
4. Collect at least `max(d_FB+32,1000)` verified rows, require rank `d_FB`, and solve every factor-base logarithm with all failures charged.
5. Reuse identical state for fresh `R=Q+[t]P`, replay a tuple, compute `x=sum epsilon_i log_P(A_i)-t mod N`, and verify `[x]P=Q` on 100 blind targets.
6. Charge construction, closure calls, skipped intents, output, ambiguity, density, rank credit, factor-log algebra, blind descent, bit complexity, and peak live memory.

## Full rho/BSGS cost model

For `beta=1/5`, let setup/state be `N^a,N^a_m`; relation and target reciprocal
densities `N^delta,N^delta_t`; query/workspace `N^q,N^q_m`; rank credit
`N^r`; output `N^o`; ambiguity `N^u`; and factor-log costs `N^ell,N^ell_m`.

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`, with `0<=r<=o`.

Promotion requires `lambda,mu<=0.45`, setup/state `<=B^(9/4+o(1))`, and fresh
work/workspace `<=B^(5/4+o(1))`. Pollard rho expected time and BSGS time/memory
have exponent `0.50`.

## Likely fatal obstruction

NextClosure consumes a supplied incidence context and closure operator. Constructing a
context whose closure answers the elliptic target equation is the missing predicate;
ordinary closure preserves implications, not rare target-labelled equality or occurrence
ancestry. Explicit contexts materialize the source family and can contain exponentially
many concepts.

## Proof track

Prove an endpoint-only context of bounded size whose closure is subset-stable and
biconditional with every all-strata target fibre, together with a charged signed inverse.

## Disproof track

Exhibit equal contexts with different target fibres, one source-derived incidence bit, an
exponential concept family, a lost occurrence, a restriction rebuild, or exponent `>=0.50`.

## Positive and negative controls

- Positive: a supplied toy context with one occurrence-labelled closed intent.
- Negative: equal closures with different source families, an empty target fibre, repeated occurrences, and fresh blind targets.
- Baselines: explicit context enumeration, P1553 R4/Query2P1, rho, and BSGS.
- All controls are toy and model-bound; native correctness is not promotion evidence.

## Quantitative promotion and falsification gates

- Promote only after exact all-strata answers over four sizes, full row rank/logs, 100 blind descents, both resource caps, and `lambda,mu<=0.45`.
- Falsify on one supplied incidence bit, false empty/nonempty answer, lost sign/occurrence, cap failure, or complete exponent `>=0.50`.
