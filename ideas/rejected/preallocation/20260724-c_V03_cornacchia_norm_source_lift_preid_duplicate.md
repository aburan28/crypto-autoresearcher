## Falsifiable hypothesis

Each public endpoint compiles a small norm equation `u^2+d v^2=m` whose primitive
Cornacchia solution canonically encodes one signed factor-base tuple. Euclidean
descent from a root of `-d mod m` would return all occurrences, relation rank, and
blind descent within complete exponents `<=0.45`.

## Mechanism-new operation

Cornacchia turns a supplied modular square root into a short Euclidean remainder
chain and tests one norm residual. It becomes ECDLP-new only if endpoint data
construct `d,m` and the initial root without source information, and every primitive
norm representation has a canonical inverse to exact elliptic occurrences.

## Assumptions

1. Endpoint fibres admit bounded-size public norm instances without enumerated tuples.
2. Primitive norm solutions preserve signs, multiplicities, and empty fibres.
3. The modular root and Euclidean branch are canonical and target-independent.
4. Norm compilation, all roots, replay, rank, factor logs, and descent meet both caps.
5. No CM ideal or source dictionary silently carries the point labels.

## Likely fatal obstruction

Cornacchia solves a supplied binary norm equation. Constructing a point-faithful
norm instance already encodes the source fibre; an aggregate norm has many source
preimages, and choosing a modular root or CM ideal supplies the missing orientation.
The Euclidean backend does not create endpoint-to-source information.

## Proof track

Prove a public compact norm compiler, root-independent unique all-strata point lift,
complete solution enumeration, full rank/logs, blind descent, and both cost caps.

## Disproof track

Find equal norm instances with different source fibres, expose a source-labelled
ideal/root, show multiple primitive solutions collide, or reach exponent `0.50`.
