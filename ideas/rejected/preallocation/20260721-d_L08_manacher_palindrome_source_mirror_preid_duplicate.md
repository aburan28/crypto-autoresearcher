## Mechanism-new operation

The native operation reuses palindrome radii at mirror centers inside the current rightmost palindrome and expands only beyond its boundary. It counts only if a public endpoint serialization makes palindrome occurrence biconditional with a signed relation and supports exact restrictions; scanning a supplied source text is a control.

1. Endpoint data provides a scalar-blind text in which relation tuples and only relation tuples have the required mirror symmetry.
2. Text length and construction cost are below source scale.
3. Coordinate restrictions map to exact center/radius predicates without rebuilding the text.
4. Each accepted center/radius replays one occurrence-distinct signed tuple across all strata.
5. One target-independent text serves known-log relations and fresh masked targets.

## Likely fatal obstruction

Manacher accelerates recognition only after a linear text exists. Elliptic addition has inverse symmetry, but local palindromic equality is neither sufficient nor necessary for a five-source sum unless the serialization embeds source assignments and endpoint constraints. That text and the center-to-tuple map are the missing source catalogue; mirror radii do not provide arbitrary restriction support.
