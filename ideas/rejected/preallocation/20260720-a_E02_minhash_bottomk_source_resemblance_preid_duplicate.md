## Falsifiable hypothesis

Hash public endpoint features of each restricted partial-sum fibre and retain bottom-k minima. Shared minima between a target fibre and a factor-base compatibility set would estimate nonempty intersection; if a minimum also carries an exact occurrence, the same frozen sketches could collect independent relations and descend fresh masked targets below rho and BSGS.

## Mechanism-new operation

Min-wise hashing turns Jaccard resemblance of supplied sets into collision probability, while bottom-k sketches retain a small order-statistic sample. It counts only if the compared sets are constructed endpoint-only, a bounded sketch gives exact zero-versus-one intersection under arbitrary restrictions, and a collision returns signed source labels. Applying MinHash to explicit source sets is a control.

## Assumptions

1. Public feature sets are biconditional with signed elliptic source compatibility on all strata.
2. Set construction, hashing, permutation seeds, bottom-k state, restrictions, collision error, source satellites, replay, rank, logs, descent, bit time, and memory are charged.
3. Empty and singleton intersections are distinguished with zero error across every adaptive restriction query.
4. A collision identifies one point-faithful occurrence rather than only an endpoint feature.
5. One target-independent sketch family serves known-log and fresh blind targets without a source catalogue or target-trained hashing.

Let delta,delta_t be reciprocal verified relation/target densities, r independent-rank credit, o output, u collision/estimation ambiguity and repetitions, and ell,ell_m factor-log time/state.

Let the compared set sizes be n_1,n_2, union size U, accepting intersection size h, and retained bottom-k sample size k. Building reads at least n_1+n_2 records and stores Theta(k) ranks plus any source satellites, so a=log_N(T_set+Theta(n_1+n_2)), a_m=log_N(Theta(k)+M_satellite). ## Likely fatal obstruction

MinHash estimates overlap only after both sets have been supplied. Building those sets is Query2P1/source incidence, and a bounded random sketch cannot distinguish an empty intersection from a singleton with zero error for all restrictions. Retaining the singleton element and its source ancestry turns the sketch into an explicit source dictionary. This merges with IDEAS 344/347/374/380.
Within this cohort it also collides with E11: both hash a supplied source set/key stream, give only probabilistic membership evidence, and lack occurrence inversion.

## Proof track

Prove endpoint-only construction of sub-gate feature sets and a deterministic exact rare-intersection theorem for the retained minima, with a source inverse and complete descent.

## Disproof track

Give two feature-set pairs with the same retained minima but intersection sizes zero and one, or identify one feature/source satellite that requires tuple enumeration.

## Positive and negative controls

- Positive: supplied large-overlap sets with labelled shared minima.
- Negative: empty versus singleton intersections hidden above the bottom-k cutoff, equal endpoint hashes with different source ancestry, adversarial restrictions, absent and exceptional targets, and blind targets.
- Baselines: IDEAS 344/347/374/380, explicit set intersection, P1553 R4, rho, and BSGS.
