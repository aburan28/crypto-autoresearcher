## Falsifiable hypothesis

Stream target-independent public keys for signed partial elliptic sums through a Karnin–Lang–Liberty compactor. If rank intervals preserve every rare accepting endpoint under arbitrary source restrictions, a logarithmic number of quantile probes would locate one exact signed occurrence, provide rank-complete factor-base relations, and support fresh scalar-blind descent below rho and BSGS.

## Mechanism-new operation

The native operation recursively compacts ordered stream items by randomized parity choices while retaining a small weighted sample with additive rank guarantees. It counts only if the stream is constructed from public endpoint data before source incidences are known and the approximate rank interval implies exact restricted nonemptiness and occurrence replay. Compacting an already enumerated source stream is a control.

## Assumptions

1. A target-independent order places every accepting occurrence in a queryable interval on every signed and exceptional chart.
2. Stream construction, compactions, random bits, weighted samples, rank error, restrictions, misses, replay, rank, logs, descent, verification, bit time, and memory are charged.
3. The additive rank error is strictly below the minimum accepting multiplicity for every adversarial dyadic restriction.
4. One frozen sketch serves known-log relations and fresh scalar-blind Q+[t]P targets without target-trained rebuilds.
5. No explicit tuple stream, large-prime table, post-hoc selector, dense resultant, scalar labels, or uncharged source oracle is admitted.

## Complete factor-base-to-target-descent path

1. Freeze the curve, signed factor-base decks, exceptional charts, public key order, compaction randomness, restrictions, and verifier before any target.
2. Construct target-independent stream/sketch state within B^(9/4+o(1)) without enumerating source products.
3. For known-log R=[kappa]P, answer exact restricted nonemptiness, then replay five labelled occurrences by charged positive-parent/negative-child bisection and singleton verification.
4. For recovered labelled points A_i with signs epsilon_i, verify the point equality sum_i epsilon_i A_i=[kappa]P and record the linear equation sum_i epsilon_i y(A_i)=kappa (mod N) in the unknowns y(A)=log_P(A). Let d_FB be the number of distinct factor-log unknowns after cross-deck identifications and normalization; collect at least max(d_FB+32,1,000) verified equations and require coefficient-matrix rank d_FB before solving.
5. Reuse unchanged state for a fresh masked target R=Q+[t]P=[x+t]P, recover and verify a tuple, compute x=sum_i epsilon_i log_P(A_i)-t (mod N), and verify [x]P=Q.
6. Charge every stream item, compaction, failed restriction branch, rank interval, replay query, rank computation, factor-log solve, descent, scalar verification, bit operation, and peak byte.

Source replay is budgeted at most 5 ceil(log_2 B)+O(1) restriction queries plus all negative siblings and singleton checks.

## Full rho/BSGS cost model

For B=N^beta with beta=1/5, let a,a_m charge endpoint-item construction, total stream length, weighted samples, compaction levels, and restriction copies; q,q_m charge target-key compilation, every approximate-rank query, error amplification, dyadic bisection, and replay. Let delta,delta_t be reciprocal verified relation and target success, r verified independent-rank credit, o returned occurrences, u rank ambiguity plus retries, and ell,ell_m factor-log time and state.

Instantiate those exponents as follows. Let L be the number of generated stream records, K the number of retained weighted records, Q_R the total adaptive rank/restriction queries, C_rank one rank query, and C_exact the work needed to exactify a positive interval. With polylogarithms absorbed in o(1), T_build>=Theta(L), M_build>=Theta(K), a=log_N(T_build), a_m=log_N(M_build), q=log_N(Q_R(C_rank+C_exact)), and q_m=log_N(maximum live query/replay state). If L=B^gamma, merely reading the stream costs N^(beta gamma+o(1)). Singleton-versus-empty rank requires additive error epsilon L<1/2, hence epsilon=O(1/L); the KLL 1/epsilon scale then forces essentially linear retained information or an equally charged exactifier. The failure probability is global across all adaptive restrictions, not per query.

lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)

mu=max(a_m,q_m,beta+o,ell_m,u), with 0<=r<=o.

Require setup/advice/state <=B^(9/4+o(1)), fresh query/restriction/replay work <=B^(5/4+o(1)), and lambda,mu<=0.45. Pollard rho has expected time exponent 0.50; BSGS has time and memory exponents 0.50. The supplied stream length, failure probability needed across all restrictions, and exactification samples are charged.
Independently require every fresh masked-target rank/exactification/replay path to use <=N^(0.25+o(1))=B^(5/4+o(1)) work. Promotion also needs four increasing B values whose one-sided 95% upper confidence bounds keep the fitted build, state, fresh-work, and complete exponents below their gates.

## Likely fatal obstruction

KLL compaction begins only after ordered items are supplied; those items are the missing source incidence stream. Its additive rank error can erase the difference between zero and one accepting source in a restricted cell. Driving simultaneous error below one over all target and bisection queries requires retaining essentially exact ranks or enough samples/source labels to restore the catalogue. This merges with IDEAS 053/347/380 and pre-ID D02/D10 rather than removing P1553 R4.
Within this cohort it also collides with E12: both reduce retained memory only after a source-bearing stream exists and both lose a rare singleton unless retained state becomes linear.

## Proof track

Construct the stream endpoint-only and prove a simultaneous zero-error rank-gap theorem for every signed chart and restriction, then give a point-faithful inverse and close rank, logs, blind descent, and all costs.

## Disproof track

Exhibit one source-bearing update or two streams with the same admitted weighted sketch and different restricted singleton existence; alternatively show exactification exceeds either cap.

## Positive and negative controls

- Positive: a supplied ordered stream whose accepting interval has multiplicity far above the frozen error bound and whose labels replay exactly.
- Negative: an empty interval versus a singleton accepting interval with the same admitted sketch distribution, equal endpoint keys with different source ancestry, absent targets, exceptional charts, arbitrary restrictions, and fresh blind targets.
- Baselines: IDEAS 053/347/380, pre-ID D02/D10, exact order statistics over explicit tuples, P1553 R4, rho, and BSGS.

## Quantitative promotion and falsification gates

- Promote only with endpoint-only stream construction, simultaneous exact zero-versus-one restricted answers, all-strata occurrence replay, at least max(d_FB+32,1,000) verified equations of rank d_FB, 100 blind descents, both caps, and lambda,mu<=0.45.
- Falsify on one supplied source update, one indistinguishable empty/singleton restricted cell, target-trained rebuild, cap violation, or either complete exponent at least 0.50.
