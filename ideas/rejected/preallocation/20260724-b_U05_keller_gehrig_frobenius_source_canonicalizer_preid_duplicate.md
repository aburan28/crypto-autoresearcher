## Falsifiable hypothesis

An endpoint-derived relation operator admits a compact Frobenius companion decomposition whose
cyclic blocks retain exact signed source orbits. Keller–Gehrig canonicalization would replace a
source catalogue by a small invariant representation and support full descent below exponent `0.45`.

## Mechanism-new operation

The native operation uses fast similarity transformations to compute Frobenius/characteristic
structure of a supplied matrix. It counts as representation-changing for ECDLP only if the input
operator is endpoint-derived and the similarity gauge has a canonical exact source inverse.
Canonicalizing a source-labelled matrix or retaining its change-of-basis matrix is not new.

## Assumptions

1. Public endpoints compile the operator without source enumeration.
2. Frobenius blocks distinguish every restricted signed occurrence fibre.
3. A canonical gauge maps companion coordinates back to exact factor points.
4. Similarity transforms, basis traffic, replay, rank, logs, and descent satisfy both caps.
5. The compact form remains byte-identical and scalar-blind across fresh targets.

## Likely fatal obstruction

Frobenius form is a similarity invariant of a represented operator. Similarity deliberately
forgets the basis labels needed to identify factor points; retaining the transformation matrix
restores full source-scale state. Distinct source-labelled operators can be similar and have the
same companion blocks while requiring different occurrence replay.

## Proof track

matrix, or show canonical gauge inversion/complete work has exponent at least `0.50`.
