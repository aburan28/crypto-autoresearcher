## Likely fatal obstruction

Feynman–Kac starts with the process, killing rule, and terminal data. Finite-potential exponential weights are positive, so the original vanishing-potential phrasing cannot encode exact nonexistence; an exact zero must come from an absorbing boundary or zero terminal support, which is itself the missing completion predicate. A kernel conditioned on compatible partial sources is source-bearing, an endpoint-only expectation loses labels, and exact rare-event replay can require inverse-probability work or the full path graph.
