## Falsifiable hypothesis

Parameterize factor-base partial endpoints along a public mask variable, maintain a kinetic certificate set whose first failure marks exact five-source compatibility, and process only certificate events needed to replay independent relations and fresh blind targets below rho/BSGS.

## Mechanism-new operation

A kinetic data structure maintains a geometric attribute by scheduling failures of certificates for supplied trajectories. It counts only if trajectories and certificates are endpoint-derived without source pairs and every exact relation event is detected and labelled under restrictions.

## Assumptions

1. Public algebraic trajectories cover every signed/chart-complete relation event with bounded certificate multiplicity.
2. Trajectory construction, root isolation, event queue, certificate updates, simultaneous events, restrictions, source replay, rank, logs, descent, and memory are charged.
3. Certificate events do not require one trajectory/certificate per source tuple.
4. A frozen target-independent scheduler serves known-log and fresh scalar-blind targets.
5. No source-labelled trajectory, post-hoc event selector, approximate collision, or uncharged root solver is admitted.

## Likely fatal obstruction

Kinetic structures require supplied trajectories and certificates. A certificate for a specific compatibility event contains the source pair/tuple; coarser endpoint certificates have many simultaneous algebraic events and no point provenance. Root isolation and event count can reproduce dense resultants or `B^3/B^5` enumeration. This merges with IDEAs `326/350/352/369/376/393`.

## Proof track

Construct sparse endpoint-only trajectories/certificates, prove complete event/source bijection under restrictions, and close end-to-end costs.

## Disproof track

Find one source-bearing certificate, missed/simultaneous event ambiguity, event count above caps, or target-dependent rebuild.

## Positive and negative controls

- Positive: supplied moving points with labelled certificate failures.
- Negative: identical event times with different sources, no-event instances, exceptional charts, restrictions, blind targets.
- Baselines: IDEAs `326/350/352/369/376/393`, dense root enumeration, P1553 R4, rho, BSGS.
