## Falsifiable hypothesis

Compile signed factor-base decompositions into a public nonnegative weighted partial-sum graph, use Dijkstra label setting under every source restriction to find an exact endpoint path, replay its signed occurrences, and complete factor logs plus blind target descent below rho and BSGS.

## Mechanism-new operation

The native operation repeatedly settles the unsettled vertex with minimum tentative distance and relaxes outgoing arcs. It counts only if vertices, arcs, nonnegative weights, and source backpointers are constructed from the public endpoint without enumerating the source deck; running Dijkstra on a supplied partial-sum graph is a shortest-path control.

## Assumptions

1. A source-free endpoint compiler creates a graph whose paths are biconditional with all signed relation strata.
2. Public nonnegative weights induce a useful settlement order without scalar labels or target advice.
3. Source restrictions update the graph without source-sized rebuilding or lost paths.
4. Every settled target path replays one occurrence-distinct signed tuple with charged ambiguity.
5. One target-independent graph serves known-log relations and fresh scalar-blind targets.

## Likely fatal obstruction

Dijkstra saves no graph-construction cost: it begins after every relevant vertex, arc, weight, and relaxation interface exists. Elliptic compatibility is not known to admit a public nonnegative path metric whose shortest paths are exactly the signed decompositions. Materializing that graph is source traffic, while compressed or approximate adjacency loses all-negative correctness and occurrence provenance.
