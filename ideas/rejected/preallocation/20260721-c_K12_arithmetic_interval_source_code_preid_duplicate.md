## Likely fatal obstruction

Arithmetic coding compresses a supplied modelled sequence; it does not generate that sequence or its conditional probabilities. Exact ECDLP conditionals are counts of source completions, i.e. the missing restricted predicate. Distinct source paths require cumulative intervals and precision proportional to the information retained, while sequential decoding does not provide cheap fresh negative queries or occurrence random access.

## Proof track

Derive an endpoint-only conditional model, prove exact finite-precision separation and random-access restrictions, and give charged all-strata occurrence decoding.

## Disproof track

Audit every probability/model symbol, measure required precision and sequential reads, test empty/singleton restrictions, and falsify on source-derived conditionals, source-sized code state, or missing replay.

## Positive and negative controls

- Positive: supplied finite source models with exact rational probabilities and labelled code intervals.
- Negative: rare singleton symbols, zero-probability restrictions, duplicate paths, adversarial precision, and fresh targets.
- Baselines: Hu–Tucker, Lempel–Ziv, FM-index, explicit enumeration, P1553 R4, rho, and BSGS.

## Quantitative promotion and falsification gates
