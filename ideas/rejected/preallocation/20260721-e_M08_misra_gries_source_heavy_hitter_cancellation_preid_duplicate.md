For generic prime-order `E(F_p)`, one can stream endpoint codes of partial source completions through Misra-Gries decrement cancellation, retain a small candidate set of heavy endpoint labels, and verify/replay relation-bearing occurrences. ## Mechanism-new operation

Misra-Gries maintains counters for frequent values in a supplied stream by deleting groups of distinct items. It counts only if the stream is endpoint-derived below the caps and every exact relation label is guaranteed heavy under every restriction while occurrence provenance survives cancellation; applying the native method to a supplied graph, sequence, matrix, distribution, score array, or source catalogue is a duplicate/control.

## Assumptions

1. A public stream of partial completions is generated without enumerating source tuples.
2. Every nonempty restricted relation fibre produces a label above a uniform heavy-hitter threshold.
3. Counter cancellation cannot remove the only valid occurrence or merge signed/chart strata.
4. A retained label has a charged occurrence-distinct inverse to complete signed sources.
5. Second-pass verification, failed labels, rank, factor logs, descent, and memory meet the full gates.

## Likely fatal obstruction

Generating the completion stream already enumerates source state. More decisively, a valid generic relation is expected to be rare, so distinct-item cancellation can delete the only accepting label while preserving all heavy-hitter guarantees. Counters do not retain signed occurrences or certify zero support. This is a frequency-aggregate merge, not a source-return operation.
