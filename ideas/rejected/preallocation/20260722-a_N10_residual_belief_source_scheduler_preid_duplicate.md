Endpoint relation factors support asynchronous belief propagation in which residual-priority scheduling concentrates computation near the rare target-compatible source cluster. Certified residual termination and restriction replay would then provide full-rank relations and 100 blind descents below rho/BSGS.

## Mechanism-new operation

The screened operation maintains a priority queue keyed by message residual, repeatedly updates the largest-residual message, and propagates priority changes. It counts only if the factor graph/messages are endpoint-derived and exact, the schedule preserves completeness and occurrence provenance, and the entire compiler/message cost beats the gates.

## Likely fatal obstruction

Residual BP changes only the update order for an already supplied message system. It does not repair loopy inexactness, construct factors, certify emptiness, or invert aggregate beliefs to occurrences. Residual values themselves require candidate messages, and a target-focused queue can be post-hoc advice. This is a backend/scheduling substitution explicitly treated as a control.

## Proof track

Prove endpoint-only exact factors, a certified asynchronous fixed-point theorem with exact restrictions/source inverse, and a complete schedule-inclusive sub-rho descent.

## Disproof track
