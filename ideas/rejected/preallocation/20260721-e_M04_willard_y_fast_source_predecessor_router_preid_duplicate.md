## Falsifiable hypothesis

For generic prime-order `E(F_p)`, one can encode compatible partial sums as bounded-universe integers, store sampled representatives in a y-fast trie, and use predecessor intervals to locate exact restricted complements and signed occurrences. The target-uniform operation supports exact arbitrary restrictions, at least `max(d_FB+32,1000)` verified independent rows of rank `d_FB`, complete factor logs, and 100 fresh blind descents with complete time and live-memory exponents below rho and BSGS.

## Mechanism-new operation

A y-fast trie combines an x-fast representative index with balanced buckets to answer predecessor queries on supplied distinct integer keys. It counts only if keys and occurrence satellites are endpoint-derived without listing compatible partial sums and predecessor is exact relation-biconditional; applying the native method to a supplied graph, sequence, matrix, distribution, score array, or source catalogue is a duplicate/control.

## Assumptions

1. There is a public bounded-universe key preserving elliptic completion and every signed/chart stratum.
2. All inserted keys and representative hashes are constructed below the setup cap without source incidence.
3. One predecessor/successor interval decides exact restricted existence with no false positives.
4. Buckets retain occurrence-distinct source satellites and update cheaply under arbitrary restrictions.
5. Word operations, hashing failures, construction, replay, and blind-target placement are fully charged.

## Likely fatal obstruction

Y-fast performance starts after all exact keys are inserted. Compatible elliptic partial sums plus source satellites are precisely the missing catalogue; omitting satellites prevents replay, while inserting them restores pair/triple traffic. A fast predecessor query does not turn coordinate proximity into equality. This is a dictionary/backend substitution.
