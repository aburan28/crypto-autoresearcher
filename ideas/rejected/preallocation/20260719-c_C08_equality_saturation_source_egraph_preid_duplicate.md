## Falsifiable hypothesis

Encode all endpoint-preserving elliptic addition expressions in an e-graph, saturate public addition/exceptional-chart equalities, and extract a low-cost representative whose leaves expose an exact signed factor-base decomposition. Reuse the saturated graph for rank-complete relations and fresh blind descent below rho/BSGS.

## Mechanism-new operation

Equality saturation accumulates equivalent terms in e-classes without committing to a rewrite order, then applies an extraction cost. It counts only if the initial endpoint term and rewrite theory generate source leaves without receiving them and extraction is target-independent and charged.

## Assumptions

1. Public rewrite rules are complete for all signed, repeated, tangent, vertical, infinity, and nonreduced relation branches.
2. E-graph construction, matching, saturation, extraction, restrictions, source replay, rank, logs, descent, and memory are charged.
3. Saturation terminates or remains inside the state cap, and the cost function is not a post-hoc source selector.
4. The same frozen rewrite theory/state serves calibration and fresh scalar-blind targets.
5. No source-labelled seed term, explicit tuple rewrite, scalar rule, or dense resultant is admitted.

## Likely fatal obstruction

Equality saturation derives equivalents of supplied terms; it cannot create absent factor-point leaves. Adding tuple-producing rewrites encodes the source catalogue, while generic associativity/curve rules generate huge e-classes and retain many equivalent parses but no occurrence provenance. Extraction is a post-hoc selector unless its hit generation is charged. This merges with IDEAs `049/084/120/337/378` and pre-ID `B05/B06`.
