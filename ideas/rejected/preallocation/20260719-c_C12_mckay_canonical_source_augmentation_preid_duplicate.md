## Falsifiable hypothesis

Represent partial decompositions as public combinatorial objects, use McKay's canonical construction path to augment only one representative of each endpoint-preserving isomorphism class, and invert an accepted canonical object to exact signed factor points for relations and blind descent below rho/BSGS.

## Mechanism-new operation

Canonical augmentation generates objects inductively while rejecting noncanonical construction paths and isomorphs. It counts only if the public object class is compiled without source tuples, quotienting preserves occurrence identities needed for rows, and the surviving family is sub-rho.

## Assumptions

1. Every signed/chart-complete relation has a public finite object and canonical parent, and nonrelations do not.
2. Object construction, canonical labelling, automorphisms, augmentation, restrictions, source inverse, rank, logs, descent, and memory are charged.
3. Isomorphism quotienting does not merge factor-point labels or row orientations.
4. One frozen augmentation grammar serves known-log and fresh scalar-blind targets.
5. No supplied source object, explicit tuple augmentation, post-hoc canonical selector, or scalar-labelled decoration is admitted.

## Likely fatal obstruction

Canonical augmentation removes isomorphic duplicates after a generative object class and parent rule are supplied; it does not manufacture the rare accepting objects. Quotienting unlabelled objects loses factor-point provenance, while source decorations restore `B^m` labelled objects. Canonical labelling is a selector/backend, not a new endpoint predicate. This merges with IDEAs `073/120/343/377/394`.

## Proof track

Construct an endpoint-only compact object grammar, prove canonical acceptance/source bijection under restrictions, and close enumeration plus descent costs.

## Disproof track

## Positive and negative controls

- Positive: supplied graph classes with known canonical parents and labelled inverses.
- Negative: isomorphic unlabelled objects with different factor sources, asymmetric worst cases, exceptional charts, restrictions, blind targets.
- Baselines: IDEAs `073/120/343/377/394`, explicit tuple generation, P1553 R4, rho, BSGS.
