## Mechanism-new operation

Johnson computes Bellman-Ford potentials and reweights supplied arcs without changing path order. It counts only if graph/weights are endpoint-derived and paths are biconditional with relations; reweighting an explicit source graph is a control.

3. Restrictions update state within the query cap.
4. Shortest paths preserve exact occurrence provenance and exact absence.
5. Graph build, cycles, reweighting, replay, rank, logs, descent, bits, and state are charged.
