## Falsifiable hypothesis

Serialize public partial-sum endpoint labels in a target-independent sequence, build a wavelet tree, and use rank/select under dyadic source restrictions to decide exact target-label existence and replay a signed five-source tuple. The same index yields at least `B` independent rows and fresh masked-target descent with complete time and memory below rho and BSGS.

## Mechanism-new operation

The native operation is a hierarchical alphabet partition with succinct bitvectors supporting rank, select, and range restriction. It counts only if the indexed sequence is constructed from endpoints without enumerating the hidden accepting tuples; indexing a supplied answer catalogue is a duplicate/control.

## Assumptions

1. A target-independent endpoint sequence exists whose restricted symbol counts are biconditional with every signed/chart-complete five-sum query.
2. Sequence construction, bitvectors, updates, negative queries, source replay, rank, logs, descent, verification, bit time, and peak memory are charged.
3. The same frozen state serves known-log calibration targets and fresh scalar-blind `Q+[t]P` targets.
4. Arbitrary dyadic restrictions preserve exact existence; charged bisection plus singleton verification returns actual occurrences.
5. No scalar oracle, post-hoc selector, explicit `B^3` table, dense resultant, or uncharged source dictionary is admitted.

## Complete factor-base-to-target-descent path

1. Freeze curve, five signed decks, all repeated/tangent/vertical/infinity charts, representation, restrictions, and verifier before targets.
2. Construct target-independent state within `B^(9/4+o(1))` without materializing source products.
3. On known-log targets, answer exact restricted existence and recover five occurrences by charged `O(log B)` positive-parent/negative-child bisection and singleton verification.
4. Retain failures/dependencies, collect at least `B` independent verified rows, and solve factor-base logarithms.
5. Reuse unchanged state for fresh scalar-blind `Q+[t]P`, recover and verify a tuple, substitute logs, remove `t`, and verify `[x]P=Q`.
6. Charge construction, updates, misses, output, rank, logs, descent, verification, bit operations, and peak memory.

## Full rho/BSGS cost model

For `B=N^beta`, `beta=1/5`, setup `N^a,N^a_m`, reciprocal densities `N^delta,N^delta_t`, query `N^q,N^q_m`, verified-rank credit `N^r`, output `N^o`, ambiguity `N^u`, and factor logs `N^ell,N^ell_m`, use

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`, with `0<=r<=o`.

Require setup/state `<=B^(9/4+o(1))`, total fresh online restriction/bisection/verification `<=B^(5/4+o(1))`, and `lambda,mu<=0.45`. Pollard rho has expected time exponent `0.50`; BSGS has time and memory exponents `0.50`.

## Likely fatal obstruction

A wavelet tree compresses and queries a supplied sequence; it does not create the sequence's symbols or source satellites. Serializing every accepting partial sum is the missing source catalogue, while serializing only public endpoints leaves rank/select unrelated to exact five-sum existence. This merges with IDEAs `120/350/371/374` and pre-ID FM-index `A06`.

## Proof track

Give an endpoint-only serializer, prove exact restriction-stable rank/select biconditional and occurrence replay, then certify independent rank and the complete sub-rho bounds.

## Disproof track

Exhibit one source-bearing serialized token, one pair of decks with identical indexed sequence but different exact existence, or any state/query/complete exponent outside the gates.

## Positive and negative controls

- Positive: a supplied text with planted labelled symbols must pass native rank/select and replay.
- Negative: same indexed aggregate with different sources, absent targets, repeated/signed/chart exceptions, adversarial restrictions, and fresh blind targets.
- Baselines: IDEAs `120/350/371/374`, pre-ID `A06`, explicit pair/triple tables, Query2P1/P1553 R4, rho, and BSGS.

## Quantitative promotion and falsification gates

- Falsify on one supplied catalogue, one existence/source mismatch, one target-dependent rebuild, cap violation, or either exponent at least `0.50`.
