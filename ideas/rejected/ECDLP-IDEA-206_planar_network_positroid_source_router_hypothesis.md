## Falsifiable hypothesis

A target-independent fixed-width plabic network has boundary-measurement minors equal to the complete signed five-source elliptic relation fiber, and inverse boundary measurement recovers every factor-base path with multiplicity. Reusing the same network for known endpoints and blind masks yields full-rank factor logs and target descent below rho and BSGS.

## Mechanism-new operation

The proposed operation is **endpoint boundary measurement followed by positroid-cell path inversion**. It would change the representation from a dense source fiber to a bounded planar network, rather than merely solve the original equations. The current form is merged/rejected because a boundary-measurement inverse recovers edge weights of a supplied network, while assigning factor labels to paths materializes the source deck; generic Semaev fibers have no supplied fixed positroid cell or Plucker-compatible source biconditional.

## Full rho/BSGS cost model

Rho costs `N^(1/2+o(1))` time; BSGS costs that time and memory. Let setup be `N^a,N^a_m`; reciprocal relation and target densities `N^delta,N^delta_t`; boundary query plus exact path inverse `N^q,N^q_m`; independent rank gain/query `N^r`; output and ambiguity `N^o,N^u`; and factor-log linear algebra `N^ell,N^ell_m`. Then

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Promotion requires both exponents at most `0.45`; network gauge reduction without exact source output has no promotion value.

## Likely fatal obstruction

Boundary measurement aggregates weighted paths and is gauge invariant. A generic elliptic relation fiber need not satisfy one fixed positroid matroid, and a network that assigns distinct factor points to all paths must store the labels and middle transitions that the representation was meant to remove. Erasing those labels preserves minors but destroys exact ancestry.
