## Falsifiable hypothesis

Prolonging an endpoint-conditioned elliptic source system to an involutive differential system exposes symbol characters whose Spencer-cohomology decomposition canonically separates exact signed factor branches, enabling relation rows and blind fresh-target descent below rho and BSGS.

## Mechanism-new operation

The screened operation is **compile the endpoint fiber into a jet system, prolong it to formal integrability, decompose its Spencer symbol, and lift involutive symbol branches to exact factor points**. This is not a solver substitution: it asserts that formal compatibility itself supplies a source-labelled branch split before dense primary decomposition. Goldschmidt's criterion controls prolongations of a supplied differential system. Separately, the finite-etale screen uses vanishing relative cotangent data to show that the reduced zero-dimensional fiber has no intrinsic positive-order infinitesimal direction; this is our algebraic deduction, not a consequence attributed to Goldschmidt. Introducing source-separating auxiliary jets either reproduces the supplied primary/source algebra or materializes one jet branch per source. The operation therefore merges with IDEAs 109, 133, 152, 194, and 268 after construction, ancestry, and output are charged.

## Full rho/BSGS cost model

Let setup time and memory be `N^a,N^a_m`, factor-base size `N^beta`, reciprocal relation and target densities `N^delta,N^delta_t`, one compile/prolong/split attempt `N^q,N^q_m`, independent-rank gain `N^r`, output `N^o`, ambiguity `N^u`, and factor-log completion `N^ell,N^ell_m`. Then

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Here `q` includes the named operation, exact inverse, and independent verification; `o` includes every enumerated relation branch; `u` is only residual scalar ambiguity in target descent.

Pollard rho has expected time exponent `1/2` and negligible memory; BSGS has time and memory exponents `1/2`. Every jet coefficient, prolongation row, cohomology basis, branch label, failed lift, factor log, verifier call, and live byte is charged.

## Likely fatal obstruction

Formal integrability says that a supplied differential system has compatible prolongations; it does not choose roots of a finite algebraic fiber. On the reduced finite-etale stratum, vanishing cotangent data removes intrinsic infinitesimal directions, but this alone is not a general theorem about every auxiliary jet encoding. Any proposed nontrivial source-separating jet must therefore be constructed and charged; the supplied version restores the primary/source algebra, while compact symbol data forget branch ancestry. Thus the screened operation certifies consistency or reorganizes a supplied decomposition without creating the endpoint-to-exact-source map.

## Proof track

Prove a finite target-uniform symbol construction whose components are biconditional with all signed sources, give a canonical exact lift, and certify both complete exponents at most `0.45`.

## Disproof track

Show generic source fibers have identical or trivial Spencer data, exhibit branch collisions, prove the symbol/jet table or output has exponent at least `0.50`, or derive either complete exponent at least `0.50`.
