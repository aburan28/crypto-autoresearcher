## Mechanism-new operation

The screened operation is **construct an endpoint-definable incidence geometry, supply a generically stable group configuration, obtain the theorem's connected type-definable group/action, and hypothesize an algorithmic coordinatization that sections exact source fibers**. Wang's theorem is an existence/reconstruction statement from supplied generically stable configuration data; it is not a canonical endpoint algorithm or factor coordinator. Here the elliptic group and addition law are already public, while a distinguished generator, scalar orientation, and source section remain missing. Constructing a point-faithful generic configuration requires the same incidence oracle or source deck. ## Full rho/BSGS cost model

For setup `N^a,N^a_m`, factor base `N^beta`, reciprocal densities `N^delta,N^delta_t`, one structure/configuration/section attempt `N^q,N^q_m`, rank gain `N^r`, output `N^o`, automorphism ambiguity `N^u`, and factor-log completion `N^ell,N^ell_m`,

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Here `q` includes the named operation, exact inverse, and independent verification; `o` includes every enumerated relation branch; `u` is only residual scalar ambiguity in target descent.

Peak memory is included in `mu`; no table, representation, certificate, or output stream is free.

Pollard rho has expected time exponent `1/2` and negligible memory; BSGS has time and memory exponents `1/2`. Every definable relation, incidence query, canonical parameter, automorphism, branch, factor output, and live byte is charged.

## Likely fatal obstruction

The theorem supplies a connected type-definable group/action from the assumed configuration; it does not compute a canonical finite coordinator from an endpoint. In this application the elliptic group law is already known, while no generator coordinate or section of the many-to-one source map is selected. A configuration rich enough to identify individual factor tuples is an incidence/source oracle; a compact unmarked configuration is invariant under automorphisms and leaves scalar orientation unresolved.
