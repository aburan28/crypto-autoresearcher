## Likely fatal obstruction

The trace formula aggregates conjugacy and representation classes. A point-labelled factor tuple is not a stable orbital invariant. Refining test functions until one tuple is isolated imports the source witness or requires a source-sized family; evaluating the complete expansion materializes the same deck. Correct trace equality therefore does not create a source section.
