## Falsifiable hypothesis

Encoding endpoint source tuples as a finite-group action at a chosen cohomology prime `ell_HKR` allows Hopkins–Kuhn–Ravenel generalized characters on commuting `ell_HKR`-power tuples to separate and invert exact factor labels below rho and BSGS.

## Mechanism-new operation

The screened operation is **construct a finite source action, choose a cohomology prime `ell_HKR`, apply the HKR generalized-character map, perform commuting-`ell_HKR`-tuple tomography, and invert character values to exact elliptic factors**. Here `ell_HKR` is distinct notation from the finite-field characteristic `p`, the ECDLP subgroup prime `N`, and the factor-log cost exponent `ell` below. If `ell_HKR!=N`, the commuting `ell_HKR`-power interface does not directly resolve the `N`-primary source line. The case `ell_HKR=N` is allowed in principle and is not dismissed as prime-to-characteristic blindness; it still requires a compact endpoint-derived finite action/cohomology class, an oriented conjugacy-to-point inverse, and complete state and cost accounting. A materialized regular point-faithful action or full character table stores the source dictionary; a compact implicit action still lacks the oriented exact inverse, while conjugacy data aggregate labels. The operation merges with IDEAs 101, 127, 153, 179, 221, 270, and 272 after action construction and output are charged.

## Assumptions

3. Character tuples have a canonical exact factor inverse rather than only conjugacy-class recovery.

## Full rho/BSGS cost model

With setup `N^a,N^a_m`, factor base `N^beta`, reciprocal densities `N^delta,N^delta_t`, one action/character/inverse attempt `N^q,N^q_m`, rank gain `N^r`, output `N^o`, conjugacy ambiguity `N^u`, and factor-log completion `N^ell,N^ell_m`,

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Here `q` includes the named operation, exact inverse, and independent verification; `o` includes every enumerated relation branch; `u` is only residual scalar ambiguity in target descent.

Peak memory is included in `mu`; no table, representation, certificate, or output stream is free.

Pollard rho has expected time exponent `1/2` and negligible memory; BSGS has time and memory exponents `1/2`. Every group element, commuting tuple, character coefficient, table entry, conjugacy branch, output factor, and byte is charged.

## Likely fatal obstruction

HKR characters reorganize supplied group actions into conjugacy-class functions at a chosen cohomology prime. For `ell_HKR!=N`, the native commuting-`ell_HKR` interface misses the `N`-primary source line unless an additional cross-primary encoding is supplied. For `ell_HKR=N`, no such blindness claim applies, but the proposal still lacks the endpoint-to-action/cohomology-class constructor and a canonical oriented inverse from conjugacy data to exact factor points. A materialized regular source-faithful action/table already names each tuple; a compact implicit action still lacks the inverse, while compact class data identify only orbits.

## Positive and negative controls

- Positive control: a supplied small finite group with independently known HKR character table and conjugacy classes.
- Negative controls: `ell_HKR!=N` cyclic actions, `ell_HKR=N` regular actions with permuted point labels, compact implicit actions without an oriented inverse, source-indexed character tables, rho, and BSGS.
