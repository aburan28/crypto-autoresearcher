## Falsifiable hypothesis

The constructible function of an exact restricted relation fibre has a compact Chern–Schwartz–MacPherson class whose localized components canonically identify one rational occurrence-labelled source under all restrictions and fresh targets below the frozen gates.

## Mechanism-new operation

The screened operation is **push the relation-fibre indicator through MacPherson's natural transformation, localize the resulting characteristic cycle/class to a component, and invert that component to one exact factor tuple**. It is distinct from Euler-transform and intersection-form owners only if class construction and localization retain point provenance without a source-labelled stratification.

1. The complete finite-deck relation fibre is compactly constructible as a scheme/constructible function from endpoints alone.
2. Its CSM class has subgate representation and a target-uniform point-localizing decomposition.
3. Pushforward/localization handles signed charts, singular, tangent, vertical, infinity, repeated, and nonreduced strata exactly.
4. Arbitrary dyadic restrictions update the class without rebuilding a source stratification.
5. Fibre construction, class arithmetic, localization, source lift, output, rank, factor logs, blind descent, verification, bit time, and memory are charged.

## Likely fatal obstruction

MacPherson's transformation pushes constructible functions to aggregate homology/Chow classes. Many different finite point configurations have the same class, and a smooth zero-dimensional fibre records degree rather than preferred occurrence labels. A localization fine enough to distinguish each factor point is a source-labelled stratification; constructing it enumerates the fibre. Signed cancellations and pushforward further lose provenance. This merges with IDEAs 080, 222, 232, 249, and 265 unless a new canonical point-section theorem is proved.

## Proof track

Construct the fibre and CSM data from endpoints, prove a point-faithful restriction-stable localization/inverse on every stratum, and derive complete exponents at most `0.45`.

## Disproof track

Produce two restricted fibres with identical CSM data but different occurrence-labelled points, or show that every point-faithful localization lists the source stratification.

## Positive and negative controls

- Positive: supplied stratified zero-dimensional schemes with externally labelled points and independently computed CSM classes.
- Negative: equal-degree permuted point sets, cancelling strata, smooth fibres with no distinguished point, arbitrary restrictions, all signed strata, and blind targets.
- Baselines: IDEAs 080/222/232/249/265, exact point enumeration, Query2P1, rho, and BSGS.

## Quantitative promotion and falsification gates

- Promote only with an endpoint-only point-faithful CSM inverse, exact restricted lift, `1,000` independent rows, `100` blind descents, frozen state/query caps, and `lambda,mu<=0.45`.
- Falsify on one equal-class/different-source pair, a source-labelled stratification, one missed stratum, source-sized localization, or either exponent at least `0.50`.
- Correct class computation on a supplied toy scheme is only a control.
