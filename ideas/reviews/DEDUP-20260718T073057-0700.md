## Semantic gate

Each candidate was normalized as

`public input -> new mathematical operation -> output object -> exact source return -> relation rows -> factor logs -> fresh masked-target descent -> scalar verification`.

A candidate was rejected or merged if its new noun concealed an occupied operation, if
its transform began only after the source object was supplied, if it returned only an
aggregate invariant or certificate, or if the complete charged time or memory exponent
failed the promotion cap.  Same-field isogenies, solver substitutions, parameter changes,
explicit large-prime tables, post-hoc selectors, dense resultants, and relation-only
certificates were controls, never novelty evidence.

The common complete cost envelope used by this cohort is

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Here setup, relation and target densities, query/source-inverse work, rank gain, source
output, target ambiguity, factor-log completion, verification, and peak memory are all
charged.  Rho has expected time exponent `1/2`; BSGS has time and memory exponents
`1/2`.  Promotion requires both complete exponents at most `0.45`; a measured or proved
exponent at least `0.50` falsifies the frozen arm.  Every possible future finite check is
`toy`; every extrapolation is `heuristic` and `model-bound`.

construct the transform from known-log endpoints without source advice; recover and
verify exact signed point tuples; obtain independent rows and factor logs; run the same
operation on fresh masked targets; and accept only `[x]P=Q`.  Every record charges setup,
representation state, success density, source output, rank loss, factor logs, target

is confined to `ideas/artifacts/ECDLP-IDEA-<NNN>/`; none of those twelve artifact roots
exists.  The paths are theorem or verifier plans, not produced evidence.
