## 2. Exact objective and quantitative rectangle

Let `G=<P>` have prime order `N=p^(1+o(1))`, let

```text
B = N^(1/5),
F_1,...,F_5 subset G,
|F_i| = Theta(B),
```

and use signed, coloured, target-independent factor decks. A fixed target has expected
constant five-source mass because `B^5/N=1`. Relation collection needs `Theta(B)`
independent known-log target rows. Equivalently, after adding a known-log target deck
`T` of size `B`, the campaign is the six-list zero-sum problem

```text
A_1 + A_2 + A_3 + A_4 + A_5 - R_j = O.          (1)
```

There are `B^6/N=B` expected coloured solutions. A direct `3+3` separator costs
`B^3=N^0.6`, while the complete promotion cap is `N^0.45=B^(9/4)`. The campaign
therefore needs an encoding-specific `B^(3/4)` exponent improvement over that explicit
separator. With target-independent setup and state at most `B^(9/4)`, one fresh masked
target query must cost at most `B^(5/4)=N^0.25`, because `B` relation targets then cost
at most `B^(9/4)` in total.

For setup `N^a,N^a_m`, reciprocal relation and target densities
`N^delta,N^delta_t`, one target query `N^q,N^q_m`, independent-rank gain `N^r`,
source output `N^o`, ambiguity `N^u`, and factor-log completion
`N^ell,N^ell_m`, the frozen complete gates remain

```text
lambda = max(a, beta+delta+q-r+o, ell,
             delta_t+q+o+u, beta)

mu     = max(a_m, q_m, beta+o, ell_m, u),

beta = 1/5,
lambda <= 0.45,
mu <= 0.45.                                      (2)
```

The favorable router rectangle grants `a,a_m<=0.45`, `q,q_m<=0.25`, constant
per-target output and ambiguity, and factor-log completion at most `0.45`. It still
requires measured independent rank and the identical scalar-blind masked-target path.

## 4. Strongest apparent survivor: `2+2+2` Abel-Jacobi incidence

The only formulation that sharpened the frontier during this rerank is an exact
pair-bivector incidence representation of (1). It is mathematically useful, but it is
not mechanism-new.

Put the sixth colour deck equal to the signed known-log targets. For a zero-sum
six-tuple, use the degree-six line bundle `O_E(6O)` and a public basis of its six
sections. Let

```text
v(A) in k^6
```

be the evaluation row. On the distinct-point stratum, the Abel-Jacobi evaluation
theorem gives

```text
A_1+...+A_6=O
iff det(v(A_1),...,v(A_6))=0.                    (3)
```

Confluent jets give the corresponding length-six statement on repeated strata.
Pair the colours as `(1,2)`, `(3,4)`, `(5,6)` and build

```text
X_12 = {v(A_1) wedge v(A_2)} subset Lambda^2(k^6),
X_34 = {v(A_3) wedge v(A_4)} subset Lambda^2(k^6),
X_56 = {v(A_5) wedge v(A_6)} subset Lambda^2(k^6).   (4)
```

Each family has at most `B^2` labelled elements in the fixed 15-dimensional space
`Lambda^2(k^6)`, and (3) becomes the trilinear incidence

```text
x wedge y wedge z = 0.                            (5)
```

The three explicit pair decks fit inside the `B^(9/4)` state cap and retain their
source pairs. The missing operation is now precise: locate a zero of (5) over three
special `B^2` Pluecker families in total `B^(9/4)` campaign work and `B^(5/4)` fresh
target work, without testing or materializing the relevant pair-pair incidences.

### Independent red-team reconstruction

1. **The predicate is exact but support-supplied.** Once six rows are chosen, the
   determinant or wedge costs constant field work. It does not choose the rows.
2. **The explicit source state is not compressed below pairs.** P1506 proves that the
   canonical coefficient basis of a source-labelled pair wedge has dimension
   `binom(B,2)`. Equation (4) is exactly that pair surface, repeated three times.
3. **Generic incidence sampling remains too sparse.** For a supplied `(x,y)`, equation
   (5) is one hyperplane query against the third `B^2` family. In the random large-field
   control, a pair has expected incidence mass `B^2/p=B^-3`; even an ideal constant-cost
   nonempty-hyperplane oracle needs `B^3` random pair trials for constant success. This
   is a model control, not a lower bound for the special elliptic families.
4. **Direct algebra does not improve the count.** Enumerating pair pairs costs `B^4`;
   storing all resulting hyperplanes or coefficients exceeds the rectangle. Low-rank
   wedge evaluation only accelerates a supplied test. A point-hyperplane data structure
   would still need an explicit special-family batching theorem.
5. **All-strata replay is harder, not easier.** Ordinary wedges annihilate repeated
   identical rows. Occurrence-coloured copies and confluent jets can restore correctness,
   but retain source-sized pair state and introduce no locator gain.
6. **The route is already occupied.** P1539 identifies the evaluation minor with
   coloured elliptic 5SUM and explicitly records the wedge/Pfaffian and `2+3` controls.
   P1506 identifies the pair wedge with the full source-pair surface. IDEA-052 owns the
   source-labelled wedge hypothesis; IDEA-071 owns determinant/displacement reporting;
   IDEAs 255-257 own incidence-form, circuit-polynomial, and colourful-matroid
   reformulations. IDEA-280 owns supplied-circuit exterior sieving.

## 5. Current positive-algorithm controls

The current primary-literature screen found no published operation entering the frozen
rectangle.

- Dinur and Golovnev, [Improved Time-Space Tradeoffs for
  3SUM-Indexing](https://arxiv.org/abs/2512.04258), give `T*S=n^2.5` for 3SUM-indexing
  in the state range between approximately `n^1.5` and `n^1.75`, and extend the method
  to kSUM-indexing. P1539's six-list specialization still requires substantially larger
  advice than `B^(9/4)`. If (4) is viewed as 3SUM over pair-list size `n=B^2`, the
  available state is only `B^2.25=n^1.125`, below that improved range.
- Kirkpatrick, Kuszmaul, Mathialagan, and Vassilevska Williams,
  [Preprocessed 3SUM for Unknown Universes with Subquadratic
  Space](https://arxiv.org/abs/2602.11363), use quadratic preprocessing and obtain
  query `n^(1.5+epsilon)` with a space tradeoff. At `n=B^2`, quadratic preprocessing is
  `B^4`, already outside the campaign gate.
- Kasliwal, Polak, and Sharma,
  [3SUM in Preprocessed Universes: Faster and
  Simpler](https://arxiv.org/abs/2410.16784), also use quadratic preprocessing and
  `n^1.5` query for subset universes. The model and costs do not supply exact
  source-labelled elliptic target inversion inside the required rectangle.

These are positive algorithm comparisons, not conditional or unconditional lower
bounds. The literature screen also found no current classical prime-field ECDLP result
that supplies the missing six-list source locator; absence from this screen is not an
impossibility claim.
