## Semantic rule

A candidate survives only if its semantic fingerprint introduces a mathematical
operation that removes a recorded obstruction and includes source recovery. Same-field
isogeny variants, solver substitutions, parameter or factor-base changes, explicit
large-prime tables, post-hoc selectors, dense resultants, relation-only certificates,
and a new name for an existing trace/orbit/support object are duplicates or controls.

A downstream backend does not supply novelty by itself. In particular, Coppersmith,
Pfaffians, ROABPs, exterior algebra, sparse interpolation, stabilizer simulation, sparse
resultants, and border rank count only when paired with an explicit elliptic identity,
representation change, or implicit oracle that removes the named ledger obstruction and
returns actual factor-base atoms.
