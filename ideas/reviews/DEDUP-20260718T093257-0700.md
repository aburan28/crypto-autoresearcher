## Semantic gate and complete cost envelope

Every proposal was normalized as

`public endpoint -> new mathematical operation -> exact signed source return -> independent relation rows -> factor logs -> fresh masked-target descent -> scalar verification`.

A new noun, representation, identity, or solver was not credited unless it removed the
recorded endpoint-to-source obstruction.  Same-field isogeny variants, solver
substitutions, parameter changes, explicit large-prime/source tables, post-hoc selectors,
dense resultants, and relation-only certificates were treated as duplicates or controls.
Supplied matrices, tensors, matroids, circuits, varieties, forms, moments, lifts,
unfoldings, and point dictionaries were charged as source state.

The common complete cost envelope is

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Pollard rho has expected time exponent `1/2`; BSGS has time and memory exponents
`1/2`.  Promotion requires both complete exponents at most `0.45`; an established
exponent at least `0.50` falsifies the frozen arm.  Every possible finite check is
`toy`; every extrapolation is `heuristic` and `model-bound`; all novelty language is
`novelty-unverified`.
