## Common decision gate

Every candidate had to supply the complete chain

`public endpoint -> exact signed sources -> independent relation rows -> verified factor logs -> fresh masked target -> scalar -> [x]P=Q`.

For setup `N^a,N^a_m`, reciprocal base/target densities `N^delta,N^delta_t`, one
query plus exact source inverse `N^q,N^q_m`, independent rank gain `N^r`,
output/ambiguity `N^o,N^u`, and factor-log costs `N^ell,N^ell_m`, the matched model was

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Promotion required both exponents at most `0.45`; values strictly above `0.45` and
below `0.50` were inconclusive, while either exponent at least `0.50` falsified a
sub-rho/sub-BSGS claim. Source output, setup, rank loss, factor logs, target descent,
verification, extension fields, ambiguity, and peak memory were never free.
