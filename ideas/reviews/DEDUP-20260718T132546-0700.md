## Complete common cost envelope

Let B=N^beta. Let setup time and memory be N^a,N^a_m; reciprocal relation and
target densities N^delta,N^delta_t; one named operation, exact inverse, and
independent verification cost N^q,N^q_m; independent-rank gain be N^r; every
enumerated relation branch contribute N^o; residual target-only scalar ambiguity
be N^u; and factor-log completion cost N^ell,N^ell_m.

Every candidate and cohort contract uses exactly:

    lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)
    mu=max(a_m,q_m,beta+o,ell_m,u)

The relation term excludes u because every enumerated relation branch is charged in
o; u is reserved for residual target ambiguity. Pollard rho has expected time
exponent 1/2 and negligible memory. BSGS has time and memory exponents 1/2.
Promotion requires both complete exponents at most 0.45. A proved complete exponent
at least 0.50, source/output/state at that scale, dependence on source-labelled input,
or failure on one required source stratum falsifies the frozen arm. Values strictly
between 0.45 and 0.50 are inconclusive and non-promoting.

All construction, precision, extension, representation, state, branch, output,
rank, factor-log, descent, verification, bit-operation, and peak-live-memory costs
are charged. Any prospective finite check is toy; every extrapolation is heuristic
and model-bound.

## Complete factor-base-to-target-descent path

Every record preserves the complete seven-stage path:

1. Freeze the curve, subgroup, factor base, source equations, named-operation
   compiler, auxiliary choices, masks, tie rules, and independent verifier.
2. Apply the endpoint-only constructor to random known-log relation endpoints
   without source advice, enumeration, target-selected parameters, or post-hoc
   selectors.
3. Return every accepted branch as exact signed factor points, retain ambiguity,
   and independently verify each relation.
4. Collect independent rows, charge rank loss, solve the full factor-log system,
   and independently verify every recovered factor log.
5. Apply the identical frozen constructor and inverse to fresh masked targets
   Q+[t]P, with hidden masks and no known-log-only path.
6. Retain every surviving branch, substitute verified factor logs, remove the
   mask, and return every complete factorization or scalar residue.
7. Accept only x satisfying [x]P=Q, charging setup, operation, density, output,
   factor logs, descent, verification, time, and peak memory.

Correctness of a supplied transform, relation validity, or a toy scalar does not
complete this path.
