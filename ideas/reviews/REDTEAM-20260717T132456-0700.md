## Cost-model and experimental concerns

- Applicability density was under-specified in several reviewed drafts. A method that
  works only for favorable covers, pairing environments, trace directions, torsors, or
  smooth order chains cannot be generalized to arbitrary prime-field inputs.
- Memory stated in algebraic “words” can undercharge extension-degree, number-field,
  coefficient, and precision bits. Promotion models must use bit memory or explicitly
  include the word-size exponent.
- Toy ladders between roughly 10 and 44 bits do not by themselves justify asymptotic 95%
  exponent claims. Fits require a preregistered finite-size correction, holdout/sensitivity
  analysis, and the label `model-bound` even when a slope gate passes.
- One false witness first invalidates an implementation. It falsifies a mathematical
  correctness claim only after the implementation and test oracle are independently
  validated.
- Positive controls that inject a decomposition, auxiliary point, favorable branch, or
  easy algebraic model validate only the downstream pipeline.
