## Semantic exclusion rules

The screen rejects or treats as a control every proposal whose only change is:

- a same-field isogeny, curve model, solver, term order, parameter, or factor-base choice;
- an explicit large-prime/source table, hidden scalar coordinate, fixed-curve advice,
  post-hoc selector, or target-specific dictionary;
- a dense resultant, supplied quotient algebra, generic factorization, linear pencil, or
  rank routine applied after the relation/source object exists;
- an aggregate trace, moment, spectrum, regulator, sheaf invariant, skeleton, certificate,
  or count without an exact scalar-blind source inverse;
- a decoder, proof system, CSP, knowledge compiler, or data structure whose input is the
  missing received word, local view, witness, completion relation, or source fiber; or
- local correctness without the complete relation-to-rank-to-factor-log-to-blind-descent
  path and fully charged rho/BSGS comparison.

A future successor needs a new mathematical operation that removes the named obstruction,
not a stronger parameter promise or a request that the missing oracle exist.

Pollard rho remains `N^(1/2+o(1))` expected time with constant state; BSGS remains
`N^(1/2+o(1))` time and memory. Setup/advice, input representation, inverse density,
failed queries, source output, relation rank, factor-log linear algebra, blind descent,
conversion/orientation, verification, serialized bytes, and peak bit memory are charged.

Promotion would require both at most `0.45`; one source error or a complete bound at least
`0.50` closes the stated arm. Since all twelve are semantic merges or exact scoped
negatives, no promotion gate was reached.

For `145`, Cheon's `d | N-1` control is admitted only when `Z`, `[x]Z`, and `[x^d]Z`
are in the same order-`N` group with the required orientation maps. With
`d=N^kappa`, `chi=max((1-kappa)/2,kappa/2)` before conversion/readout costs; fixed
`d=2` gives `chi=1/2`. A quadratic center output alone lacks `[x]Z`. A scalar quadratic
return is solved directly with at most two candidates and is not a Cheon speedup.
