## Common complete cost envelope

Let `B=N^beta`. Let setup time and memory be `N^a,N^a_m`; reciprocal relation and
target-success densities be `N^delta,N^delta_t`; one named operation plus exact source
inverse cost `N^q,N^q_m`; independent-rank gain be `N^r`; source output and target
ambiguity be `N^o,N^u`; and factor-log completion be `N^ell,N^ell_m`.

Every candidate uses the exact complete envelopes

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Pollard rho has expected time exponent `1/2`; BSGS has time and memory exponents
`1/2`. Promotion requires both complete exponents `<=0.45`. An established complete
exponent `>=0.50`, source/output/state of that scale, a missing source stratum, or
dependence on source-labelled input falsifies the frozen arm. Costs strictly between
`0.45` and `0.50` are inconclusive and non-promoting.

All coefficients, precision bits, extension fields, matrices, circuit gates, algebra
basis elements, enumerator terms, kernel entries, global/local classes, branches,
representations, output tuples, failed targets, rank defects, factor logs, verifier
calls, bit operations, and live bytes are charged. Every possible finite cohort check
would be `toy`; every projection remains `heuristic` and `model-bound`.

1. Freeze the curve, subgroup, factor base, source equations, named-operation compiler,
