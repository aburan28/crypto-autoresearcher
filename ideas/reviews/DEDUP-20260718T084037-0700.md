## Semantic gate

Every proposal was normalized as

`public input -> new mathematical operation -> exact source return -> relation rows -> factor logs -> fresh masked-target descent -> scalar verification`.

A new noun, representation, or inversion theorem was not credited unless it supplied an
endpoint-only constructor, exact signed point-source inverse, independent full-rank rows,
factor-log completion, identical blind target descent, and complete sub-rho time and
memory.  Same-field isogeny variants, solver substitutions, parameter changes, explicit
large-prime/source tables, post-hoc selectors, dense resultants, and relation-only
certificates were controls.  Supplied graphs, ideals, matrices, spectral data, functor
values, algebras, tensors, strata, and point dictionaries were charged as source state.

The common complete cost envelope is

`lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Rho has expected time exponent `1/2`; BSGS has time and memory exponents `1/2`.
Promotion requires both complete exponents at most `0.45`; an established exponent at
least `0.50` falsifies the frozen arm.  Every possible finite check is `toy`; every
extrapolation is `heuristic` and `model-bound`; novelty is `novelty-unverified`.
