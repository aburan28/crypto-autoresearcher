## Deduplication rule

Candidates were compared by mathematical operation and information flow, not
by terminology. A solver replacement, parameter change, same-field isogeny,
explicit large-prime table, post-hoc selector, dense resultant, or
relation-only certificate was treated as a duplicate or control unless a new
operation removed the recorded endpoint-to-source obstruction. An invariant
that merely counts or classifies the target fiber was not treated as an exact
source return.

Four late boundaries were applied explicitly:

- P1522 closes fixed lift-invariant branch deletion and leaves only an explicit
  induced-template support/witness router under the frozen setup/query bounds.
- P1523/IDEA-057 proves that an exact globally composable bucket label on the
  prime-order group is constant or injective; nonhomomorphic, list-restricted,
  approximate, or support-changing corrections remain outside that theorem.
- P1524 removes raw pairwise Kummer trace/norm as the obvious nonhomomorphic
  exception: it is the monic `S3` branch polynomial, and source-complete
  aggregation is the existing resultant/norm backend. A list-specific
  support-changing router remains outside the scoped negative.
- P1525 proves for IDEA-001's declared exact linear one-witness API that
  incidence rank is `S=|mF|`, explicit component memory has `M>=S`, and
  favorable attempt work has `T>=B*N/S`, hence
  `max(T,M)>=sqrt(B*N)=N^0.6` at `beta=1/5`. This is a resource tradeoff, not a
  standalone time or Shoup-style lower bound; nonlinear implicit-batch/multirow
  routing requires a new operation and ID.

## Cost and path audit

Each record freezes `E,P,N,Q,F,B=N^beta`; applies its operation to known-log
endpoints; verifies exact all-source output; collects rank `B`; solves and
independently verifies factor logs; applies the identical operation to a fresh
masked target `Q+[t]P`; removes the mask; and verifies `[x]P=Q`. Setup, relation
density, query, output, rank, target ambiguity, descent, verification, time, and
peak memory are all charged against Pollard rho and BSGS.

For the common exponent notation the complete model is

`lambda=max(a,beta+delta+q+o,ell,delta_t+q+o+u,beta)`

`mu=max(a_m,q_m,beta+o,ell_m,u)`.

Promotion requires both exponents at most `0.45`; values strictly between
`0.45` and `0.50` are inconclusive; either exponent at least `0.50`, a missed or
false source, hidden source advice, or omitted path cost falsifies the scoped
version. No candidate reached a promotion gate.
