## Frozen route and complete cost envelope

Every proposal was normalized to:

```text
public endpoint
  -> named operation
  -> exact signed source points
  -> independently verified relation rows
  -> verified factor-base logs
  -> identical fresh masked-target descent
  -> exact [x]P=Q verification
```

Let setup time and memory be `N^a,N^a_m`; factor-base size `N^beta`; reciprocal
relation and target densities `N^delta,N^delta_t`; one named operation, exact inverse,
and verification cost `N^q,N^q_m`; independent-rank gain `N^r`; all enumerated output
`N^o`; target ambiguity `N^u`; and factor-log completion `N^ell,N^ell_m`.

Every cohort record and lane contract uses exactly:

```text
lambda=max(a,beta+delta+q-r+o,ell,delta_t+q+o+u,beta)
mu=max(a_m,q_m,beta+o,ell_m,u)
```

Pollard rho has expected time exponent `1/2` and negligible memory; BSGS has time
and memory exponents `1/2`. Promotion requires both complete exponents at most `0.45`,
1,000 independently verified rows and 100 blind descents at each large size, and exact
all-strata source return. A proved complete exponent at least `0.50`, source-labelled
input, source-sized state/output, or one missing stratum falsifies the frozen arm.
Values strictly between `0.45` and `0.50` are inconclusive and non-promoting. Every
prospective finite check is `toy`; extrapolation is `heuristic` and `model-bound`.
