## Semantic novelty gate

A candidate survives only if it names a new mathematical operation that removes a
recorded obstruction, produces exact factor-base sources, reaches individual target
descent, and remains potentially sub-rho after all setup, trial, output, calibration,
linear-algebra, descent, verification, and memory costs are charged. Same-field
isogenies, solver substitutions, parameter or factor-base changes, explicit large-prime
tables, post-hoc selectors, dense resultants, relation-only certificates, and faster
evaluation of an unchanged search surface are duplicates or controls unless the proposed
operation proves a new obstruction-removing biconditional.

The common accounting template is

`T = C_setup + (B/pi_rel)(C_trial + C_report + C_source) + C_LA(B)
     + C_descent/pi_desc + C_verify`,

with `B=N^beta`. Every exponent and all peak memory must beat the matched `N^(1/2)`
Pollard-rho and BSGS boundary; a fast kernel is insufficient.
