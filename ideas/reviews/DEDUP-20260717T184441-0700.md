## Semantic novelty gate

A candidate receives an ID only when it states an operation distinct enough to audit.
It remains active only if the operation removes a recorded obstruction, outputs exact
factor-base sources, supplies `B=N^beta` independent rows and factor logs, reaches an
individual blind target, and can plausibly beat both rho and BSGS after setup, trials,
output, calibration, rank, linear algebra, descent, verification, and peak memory are
charged.

Same-field isogenies, solver substitutions, parameter changes, explicit large-prime
tables, post-hoc selectors, dense resultants, relation-only certificates, and faster
reporting of the same search surface were treated as duplicates or controls unless a
new mathematical operation proved an obstruction-removing biconditional.

The common accounting surface was

`T = C_setup + (B/pi_rel)(C_trial + C_report + C_source) + C_LA(B)
     + C_descent/pi_desc + C_verify`,

with every time and peak-memory exponent compared against the matched `N^(1/2)`
Pollard-rho and BSGS boundaries.
