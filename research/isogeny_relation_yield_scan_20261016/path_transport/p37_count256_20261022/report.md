# P37 endpoint-256 public targetwise count control (2026-10-22)

This is an observation-only implementation control. It asks whether the complete signed source `low_x` base and its saved transport through all 256 degree-7 edges give identical exact ordered three-point counts on the same 128 public target scalars. These points are excluded from graph-wide discovery and confirmation inference.

## Observations and limits

The [source counts](source.count) and [transported counts](transported.count) are byte-identical, SHA-256 `f799d1cd80cdacd125d4ad0e1681ce5e704da836c569b3e12b11763ba144d473`; that digest matches the earlier P37 index-4 and index-24 controls. All **128/128** targetwise ordered counts agree. Seven targets are nonempty, with **48 ordered relations** total: indices 9, 27, 32, 104, 117, and 127 have six each; index 18 has twelve. The [comparison record](comparison.json) reports `status: pass`. The [SVG](counts.svg), regenerated by [render_graph.py](render_graph.py), plots both recorded count sequences.

The source counter meter recorded **8.26 s wall**, **2.52 s user CPU**, **0.07 s system CPU**, and **289,718,272 bytes maximum RSS**; the transported counter recorded **5.79 s wall**, **3.38 s user CPU**, **0.09 s system CPU**, and **289,701,888 bytes maximum RSS**. Both had zero swaps. Raw meters are [source](source.time.stderr) and [destination](transported.time.stderr). These host-contended values are descriptive and do not support a relative speed claim.

This control checks targetwise equality for exactly these 128 public points and the endpoint-256 saved base. The same counter implementation ran at both endpoints; equality alone does not certify its completeness at full group size. The independent small-group exhaustive oracle and prior first-check control have narrower counter scope. The post-freeze discovery stream, native-base yield comparison, useful-rank replay, and full same-point ECDLP costs remain unmeasured. The existing `../chain.svg` and study `../../graph.svg` show path geometry but no count series, so this report carries the new visual without changing those graphs.
