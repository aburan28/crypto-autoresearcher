collector output, independent count output, solve JSON, and a changed-scalar
negative fixture are retained in the adjacent directories.

`solve.py` was run with `sage -python` and arguments `--input`, `--collector`,
`--count`, `--gx 5 --gy 1`, each public Q coordinate, and `--out`. The
collector and count files were generated by the existing compiled Rust and
C++ oracles from the saved input files. `check.py` was run separately with
the same three input paths and `--solve`. Replacing scalar 7 by 8 in a copy
caused `check.py` to exit nonzero with `independent Sage Q-scalar equation
failed`. The table records software-control observations, not full graph
solver performance. The `timings_seconds` in each solve JSON cover only
internal phases and exclude process startup, base construction, target
generation, map transport, and rho.
