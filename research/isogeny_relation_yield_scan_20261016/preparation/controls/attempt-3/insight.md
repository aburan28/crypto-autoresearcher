# Two-edge transported-base implementation control — 2026-10-16

**Question.** Does the archived degree-7 map transport the complete source `low_x` base and four fixed, planted relation targets consistently through the first two edges of each P29/P37 path?

**Method and scope.** `transport_two_edges.py` reconstructs the saved kernel-selected Sage isogeny and canonical codomain isomorphism. It maps every signed source-base point; compares full-base cardinality and digests; checks the dual relation on the generator, the first 16 signed base points and four control targets at each edge; and counts unordered triples from the first 16 signed points with independent `harness.toycurve` arithmetic. The four targets are sums of the fixed triples `(0,2,4)`, `(1,3,6)`, `(0,5,10)`, `(2,7,14)`. Their planted nature makes this a positive map/base control, not an unbiased relation-yield sample. The graph files, point counts and kernel polynomials are bound in `result.json`.

**Exact successful command.** From repository root: `gtimeout 600 sage -sh -c 'DOT_SAGE="$PWD/research/isogeny_relation_yield_scan_20261016/preparation/.sage" python3 research/isogeny_relation_yield_scan_20261016/preparation/transport_two_edges.py' > research/isogeny_relation_yield_scan_20261016/preparation/controls/attempt-3/result.json 2> research/isogeny_relation_yield_scan_20261016/preparation/controls/attempt-3/stderr.log`. Exit code 0. Sage 10.10.rc0; no scientific target or seed was used. The untracked `.sage` directory is a local cache. CPU time, peak memory, processor pinning and full shell wall time were not captured; `result.json` records Python monotonic elapsed seconds within the control.

**Observed.** P29 mapped 512 signed points, P37 mapped 3,200, at each of the two edges. The codomain points were distinct, nonidentity points; each edge matched the saved image generator and had 21 passing dual checks. Independent triple counts were `[1,1,1,1]` at the source and at both transported vertices for each stratum. P29 total script time was 1.93 s and P37 was 360.79 s (measured within this control; not an algorithm comparison). The direct P37 map cost makes a full-walk point-by-point check expensive, motivating fixed check vertices and a streamed/checkpointed implementation.

**Earlier attempts.** The first invocation failed immediately because `sage_version` was imported from `sage.all`; `sage.version.version` fixed the import. Attempt 2 was manually interrupted during all-point dual replay on the larger base; its saved stderr and empty result file remain in `../attempt-2/`. The change for attempt 3 evaluates each base point through the forward map once and limits direct dual replay to a fixed sample. Neither interruption is mathematical evidence.

**Interpretation and limits.** This supports the first two edge maps and positive targetwise equality on the stated 16-point subbase. It does not establish targetwise equality for the full fixed discovery stream, relation yield on any graph vertex, matrix rank, an ECDLP cost, or a relative advantage. Next, freeze the check-index set and replay full discovery targets on transported bases using a bounded streamed implementation; preserve the native bases as separate comparisons.
