== The algorithm ==
Operations and comparisons on elements of the [[multiplicative group of integers modulo n|multiplicative group of integers modulo p]] <math>\mathbb{Z}/p\mathbb{Z}</math> are implicitly mod ''p''.

'''Inputs''':
* ''p'', a prime
* ''n'', an element of <math>\mathbb{Z}/p\mathbb{Z}</math> such that solutions to the congruence ''r''<sup>2</sup> = ''n'' exist; when this is so we say that ''n'' is a [[quadratic residue]] mod ''p''.

'''Outputs''':
* ''r'' in <math>\mathbb{Z}/p\mathbb{Z}</math> such that ''r''<sup>2</sup> = ''n''
'''Algorithm''':
# By factoring out powers of 2, find ''Q'' and ''S'' such that <math>p-1=Q 2^S</math> with ''Q'' odd
# Search for a ''z''  in <math>\mathbb{Z}/p\mathbb{Z}</math> which is a quadratic non-residue
#* Half of the elements in the set will be quadratic non-residues
#* Candidates can be tested with [[Euler's criterion]] or by finding the [[Jacobi symbol]]
# Let
#:<math>\begin{align}
  M &\leftarrow S   \\
  c &\leftarrow z^Q \\
  t &\leftarrow n^Q \\
  R &\leftarrow n^\frac{Q+1}{2}
\end{align}</math>
# Loop:
#* If ''t'' = 0, return ''r'' = ''0''
#* If ''t'' = 1, return ''r'' = ''R''
#* Otherwise, use repeated squaring to find the least ''i'', 0 &lt; ''i'' &lt; ''M'', such that <math>t^{2^i} = 1</math>
#* Let <math>b \leftarrow c^{2^{M-i-1}}</math>, and set
#*:<math>\begin{align}
  M &\leftarrow i    \\
  c &\leftarrow b^2  \\
  t &\leftarrow tb^2 \\
  R &\leftarrow Rb
\end{align}</math>

Once you have solved the congruence with ''r'' the second solution is <math> -r \pmod p</math>. If the least ''i'' such that <math>t^{2^i} = 1</math> is ''M'', then no solution to the congruence exists, i.e. ''n'' is not a quadratic residue.

Solving the congruence ''r''<sup>2</sup> ≡ 5 (mod 41). 41 is prime as required and 41 ≡ 1 (mod 4). 5 is a quadratic residue by Euler's criterion: <math>5^{\frac{41-1}{2}} = 5^{20} = 1</math> (as before, operations in <math>(\mathbb{Z}/41\mathbb{Z})^\times</math> are implicitly mod 41).

# <math>p-1 = 40 =  5 \cdot 2^3 </math> so <math>Q \leftarrow 5</math>, <math>S \leftarrow 3</math>
# Find a value for z:
#* <math>2^{\frac{41-1}{2}} = 1</math>, so 2 is a quadratic residue by Euler's criterion.
#* <math>3^{\frac{41-1}{2}} = 40 = -1</math>, so 3 is a quadratic nonresidue: set <math>z \leftarrow 3</math>
# Set
#*<math>M \leftarrow S = 3</math>
#*<math>c \leftarrow z^Q = 3^5 = 38</math>
#*<math>t \leftarrow n^Q = 5^5 = 9</math>
#*<math>R \leftarrow n^{\frac{Q+1}{2}} = 5^{\frac{5+1}{2}} = 2</math>
# Loop:
#* First iteration:
#** <math>t \neq 1</math>, so we're not finished
#** <math>t^{2^1} = 40</math>, <math>t^{2^2} = 1</math> so <math>i \leftarrow 2</math>
#** <math>b \leftarrow c^{2^{M-i-1}} = 38^{2^{3-2-1}} = 38</math>
#** <math>M \leftarrow i = 2</math>
#** <math>c \leftarrow b^2 = 38^2 = 9</math>
#** <math>t \leftarrow tb^2 = 9 \cdot 9 = 40</math>
#** <math>R \leftarrow Rb = 2 \cdot 38 = 35</math>
#* Second iteration:
#** <math>t \neq 1</math>, so we're still not finished
#** <math>t^{2^1} = 1</math> so <math>i \leftarrow 1</math>
#** <math>b \leftarrow c^{2^{M-i-1}} = 9^{2^{2-1-1}} = 9</math>
#** <math>M \leftarrow i = 1</math>
#** <math>c \leftarrow b^2 = 9^2 = 40</math>
#** <math>t \leftarrow tb^2 = 40 \cdot 40 = 1</math>
#** <math>R \leftarrow Rb = 35 \cdot 9 = 28</math>
#* Third iteration:
#** <math>t = 1</math>, and we are finished; return <math>r = R = 28</math>

Indeed, 28<sup>2</sup> ≡ 5 (mod 41) and (−28)<sup>2</sup> ≡ 13<sup>2</sup> ≡ 5 (mod 41). So the algorithm yields the two solutions to our congruence.
