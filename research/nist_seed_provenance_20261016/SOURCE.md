# Source of this bundle

These files are copies of `research/nist_seed_provenance_20261016/` in
aburan28/crypto (branch `claude/nist-seed-provenance`), made on 2026-10-16 so
that ledger records here can cite them from this repository. That
directory is the source of truth. It also holds the native Rust receipt
(`src/cryptanalysis/nist_seed_provenance.rs`), the candidate enumerator
(`examples/nist_seed_candidates.rs`), the census driver (`census.sh`) and the
plotting source (`plot_streams.py`), which are not copied here.
