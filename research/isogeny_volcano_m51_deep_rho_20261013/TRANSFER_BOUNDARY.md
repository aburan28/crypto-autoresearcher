# Transfer boundary and open obligations

This benchmark contains no transfer.  It compares independently constructed
native endpoints under one action.  The order lattice is context, not an
executable path supplied to the rho core.

For the selected P/B pairs, discovery supports a rational cyclic kernel and
codomain endpoint identification.  That is not yet a serialized, normalized
group-homomorphism evaluator usable by this benchmark.

The edge certificate binds the raw coefficients `parent_b -> bottom_b`.  The
benchmark applies one common Frobenius exponent to those two raw coefficients.
The canonical `bottom_orbit_rep` is retained only as a bottom-population
identity and is not used in place of `bottom_b`.  This preserves which certified
edge is being measured, but it supplies neither a point map nor evidence that a
walk-work difference transfers across the edge.

## Cost separation

| Phase | Benchmark treatment |
|---|---|
| Endpoint discovery and certification | Bound by source hashes; not charged as per-target rho work |
| Native generator/table setup | Repeated natively; invocation count and wall seconds recorded; group-operation count not instrumented |
| Native planted target `Q=kP` | Constructed on every curve; excluded from current operation count |
| Collision walk | `walk_ops` primary, with additions/doublings and field-action primitives separate |
| Scalar recovery and `kP=Q` verification | Correctness gate; operation count excluded |
| Isogeny construction/evaluation/dual/recovery | Not present and not assigned zero cost |

Consequently a favorable endpoint association would motivate a separate map
construction and fully priced transfer trial.  It would not make the source
curve transfer-weak by itself.

The primary design shares scalar and numeric walk streams across all four arms
as a common-random-number amendment to the earlier nonfrozen arm/domain-separated
blueprint.  This controls stochastic variation; it does not transport points or
make trajectories identical.  Because calibrated row weights differ by arm,
only `B-P` is exactly target-paired at the estimator level.  The other contrasts
are balanced CRN comparisons, with equal-row sensitivity kept descriptive.

The conditional setup lane is triggered only after a passing A/A gate and an
estimable primary family, when at least one of the nine simultaneous 95%
intervals strictly excludes zero and has `|estimate| >= 0.5` bit.  If run, it
tests all nine contrasts over the fixed 97-model panel under 16 fresh
SHA-derived roots, with the original primary root added only as a descriptive
matched bridge.  Conditional on the frozen exchangeability/sign-symmetry model,
the n=16 model-based/asymptotic family reports directional persistence (the
simultaneous interval excludes zero in the primary direction) and practical
persistence (the entire interval is at or beyond +/-0.5 bit), each as complete,
partial, or none.  Exhausting all `2^16` signs removes multiplier Monte Carlo
error but is not exact finite-sample randomization inference.  The follow-up's
sparse fixed panel and fresh streams define a different estimand from the
primary calibrated population, so non-persistence cannot uniquely identify a
setup-root accident.  It does not establish a conductor mechanism, identify a
weak curve, create an isogeny evaluator, or price transfer.

The selected 32-edge result has a point estimate and descriptive heterogeneity,
not a confidence interval for that finite selected set.  Any primary
simultaneous interval is instead conditional on the stated modeled
pilot-excluded population and exchangeability assumptions.  Neither kind of
summary resolves within-parent child heterogeneity.

This directory is endpoint-bound and frozen but remains unlaunched at the
freeze point.  It contains no admitted scientific timing or endpoint result,
so none of the open obligations above has been discharged yet.
