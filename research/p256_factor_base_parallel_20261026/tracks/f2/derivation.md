# F2 second-pass completeness and scope

Task TASK-20261026-e8fd72; derived prospectively, before second-pass data.

## Full generic fibre

The frozen chain has separable degree N=65,536 and a rational cyclic kernel
generated by K of exact order N. Its frozen offset P has terminal Q=Phi(P)
with Q_y nonzero. Therefore the coset P+jK, 0 <= j < N, contains exactly N
points and closes after N additions. Its x coordinates are distinct: an
equality between distinct coset x values would give P+jK=-(P+lK), hence
Q=-Q, contradicting Q_y nonzero. The degree-N x map gives the matching
upper bound. This is the PKM section 3.4 coset lemma applied to exact inputs.

The producer traverses that coset with affine formulas. A separate checker
reconstructs it in Jacobian coordinates, verifies exact K order, all row
indices, all coordinates, closure, distinctness and every lift decision.
Full per-point 16-step map evaluation is not claimed; the coset proof plus
frozen exact map/kernel/offset identities supplies membership.

At p=3 mod 4, compute w=a^((p+1)/4) for a=x^3-3x+b. Then w^2 is either a
or -a for nonzero a. In the latter case w^2=-a proves a is a nonsquare,
since -1 is a nonsquare. The separate replay instead applies Euler's
criterion to every rejected coordinate. Accepted points get a separate
curve-equation check and canonical positive-half sign.

The target group-order certificate checks prime p and r, a nonzero standard
G on the nonsingular curve, [r]G=O with affine and Jacobian formulas, and
that the exact Hasse interval contains precisely one multiple of r. Lagrange
then forces #E(Fp)=r. Every rational affine lift is consequently in the
order-r subgroup. There is no separate [r] multiplication per accepted lift;
that omission is explicit. FLINT primality results are not portable proof
objects.

## Complete signed three-summand search

For each frozen canonical matched base F of size M, form S=F union -F with
2M distinct points, retaining a fixed index order. The producer stores every
unordered pair (i,j), i <= j, keyed by P_i+P_j, including infinity and
repeated indices. For each k it looks up Q-P_k and retains the stored pair
only if j <= k. Each unordered signed triple i <= j <= k is therefore
visited and returned exactly when its sum is Q. Repeated coordinates,
repeated points and inverse-pair cancellations are not discarded.

The separate oracle iterates i <= j and computes Q-P_i-P_j using Jacobian
formulas. It checks that this point is a base member with index k >= j.
This independently characterizes the identical complete unordered solution
set without using the producer's pair table or affine group arithmetic.
Every returned solution is separately summed in the oracle.

The implemented reference explicitly enumerates the signed base and
O(M squared) pair states, storing O(M squared) producer entries. It does not
provide the implicit-chain solver sought for large factor bases. Counts of
the two different traversal shapes are not comparable full field-operation
costs. Historical construction, file I/O, hashing/compression, target
attachment, independent rank and linear algebra remain outside a total-cost
measurement.

## Input selection and controls

Use the exact first-pass sorted accepted-x prefix, with M=26 at raw size 64
and M=121 at raw size 256, in all three families. The predicate includes raw
membership, target lifting and prefix selection. Auxiliary generic membership
rejects finite poles; kernel-domain membership intentionally maps to infinity
and is a different predicate. No spurious finite-fibre pole is accepted by
ignoring that distinction.

Both unplanted targets are fixed hash-to-point outputs independent of the
selected base family. Their search failures, if any, are exact facts about
two fixed targets and these six bases, not a relation-yield estimate.
Constructed distinct-coordinate and cancellation targets exercise the same
solver paths. Corrupt target y, an omitted first coset row and completion-
guard failures must be rejected. First-pass inputs are immutable.

## Transfer and claim boundary

The auxiliary order p+1 and target order r are coprime and their traces
differ. Coordinate reinterpretation is not group transport. Neither exact
fibre incidence nor the finite-domain solver supplies a P-256 DLP transfer,
general distribution theorem, asymptotic improvement, formal certificate,
canonical independent review or official scientific transition.
