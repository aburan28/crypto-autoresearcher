The assertion was changed to check degree 475 and an upper bound on support. No first-attempt controls JSON exists.

The 108-byte [partial output](sage_replay_failed_partial.txt.gz) is preserved in lossless gzip; `gzip -dc sage_replay_failed_partial.txt.gz` reproduces its raw SHA-256 `9822709ff8b8ca57ccd01ec413beb90519b156baa8b53aeb934708818dc938ad`. The checker now converts that Sage integer to a Python `int`; a subsequent invocation wrote the complete replay to a fresh path after the partial file was moved aside.

Neither failure is counted as an invalid point, missing relation, or negative result for the factor-base idea. The initial terminal tracebacks were observed in the execution session; the partial file is the durable raw output available from the second failure.
