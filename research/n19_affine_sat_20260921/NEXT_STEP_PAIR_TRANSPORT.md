# Proposed next control: canonical pair sums with exact witness transport

This is a design candidate for Coordinator ranking, not an approved experiment or a new speed claim. It builds on the existing positive relative-Frobenius support and IDEA-20260921-0d2a43. Novelty is unverified; the aim is a complete measured query and witness-recovery control, not to rename prior compression.

For the accepted N19 base B, let A be the automorphism set {epsilon*tau^j : epsilon in{+1,-1},0<=j<19}. B is invariant under A. Define canon(S) as the least full point encoding among gamma(S), gamma in A, retaining the chosen transporter gamma. This is an orbit representative, not a quotient group operation: never add canonical representatives as if their classes formed a group.

Enumerate each unordered pair of base orbits i<=j by fixing its supplied representative P_i and varying every signed conjugate of P_j. This requires10*38=380anchored additions for four orbits. For each S=P_i+P_j', compute C=gamma_S(S) and store a checked normalized pair (gamma_S(P_i),gamma_S(P_j')) whose sum is C. Deduplicate equal C without discarding the witness. Treat infinity separately and retain deterministic tie-breaking for shorter orbits.

For an exact-three query Q, enumerate P in B and form the actual point R=Q-P. Compute C=gamma_R(R) and look up C. If a stored pair U+V=C exists, return (gamma_R^(-1)(U),gamma_R^(-1)(V),P) and check base membership and the exact group identity. All transformations remain inside B. No discrete-log map is required.

Correctness obligations are short but explicit: common signed Frobenius sends every pair in a fixed orbit pair to an anchored pair, so the table contains every orbit of B+B. Conversely a canonical match transports a real stored pair back to the actual R. Equality of canonical points alone is insufficient without the inverse transporter. Repeated summands, opposite points, zero sums, signs, Frobenius orientation and stabilizers must be included in finite controls.

The archived N19 checks found11097distinct pair sums including infinity for each of the selected, prior and null bases. Every nonzero subgroup point has a38-element signed Frobenius orbit, and B+B is invariant. Hence the corresponding canonical pair-image cardinality is deduced to be(11097-1)/38+1=293. This is a mathematical deduction from existing finite measurements, not a measured implementation of the proposed table. The current P7 native baseline enumerates all11628unordered point pairs; its observed complete-worker median is about48.5ms.

The cost tradeoff is unresolved. Construction and storage may fall, but every query needs canonicalization and a successful query needs exact inverse transport. CPU-efficient normal-basis rotation and conversion would need their own controls and fully charged preprocessing. Compare whole cold construction/query/replay, memory and data together. Do not infer a time gain from293keys, and do not carry an N19 result to N53 or fullIC without measurement. The generic PairSumTable inspected in the archived IC source also enumerates all point pairs; that read does not establish what every specialized IC fast path does.

A bounded successor should compare this witness-bearing direct lookup with the existing expanded native table on the identical base and target panel, first reproducing all6909target-orbit outcomes at N19. The same exact support can then serve as the control for conditional backward SAT propagation. If computing the target join already finds a witness, credit that work to direct query preprocessing; SAT cannot claim it as a pruning gain. The existing three bases with equal pair-image cardinality but different triple coverage are useful controls.

Proof-search-map draft: baseline reproduction is identical native MITM and exact group replay; collision control is a canonical match with deliberately wrong inverse transport, which must be rejected; quantifiers fix curve/base/table before Q; method ceiling is finite cold cost and exact witness retrieval. This is a coordinate-dependent canonicalization with explicitly priced transport, not a new algebraic group action or exponent result. The cheapest falsifier is a mismatch against complete N19 pair/triple membership, or canonicalization cost exceeding construction savings.

Provenance: internal. Inputs are accepted RUN-KIC-234d11 geometry/coverage and the completed-but-censored SAT pilot RUN-KIC-859f34. The latter's independent review/disposition is tracked separately. Prior positive relative-pair support is identified by IDEA-20260921-0d2a43; no priority or scientific-status transition is made here.

An optional implementation refinement is to canonicalize only the x-orbit for unsuccessful lookups. On this curve a nonzero x has exactly two rational lifts differing by negation, and B is sign-closed. Store the normalized pair's sum sign information, and resolve the target's y/sign alignment only after an x-key hit, then replay the complete group witness. This can avoid y-coordinate normalization on misses. It is exact only with the sign-restoration check and explicit infinity handling; an x match without that transport is not yet a decomposition. Any normal-basis conversion tables, rotation-minimum search, successful-hit lift and validation remain charged. This refinement is not implemented or timed here.
