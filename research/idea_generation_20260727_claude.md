### 3.1 F1 — FEASIBLE INTERPOLATION / witnessing extraction of a discrete-log bit from a refutation

**Area:** logic-and-proof-complexity. **Family verdict recorded in the run snapshot:** `BARRIER-ONLY` (bare label — this family's verdict record carries no supporting text, which is itself a gap and is flagged in §5.4). **Idea.** Feasible interpolation is the one mechanism in proof complexity that *outputs an algorithm* rather than a bound: from a refutation of `A(u,y) AND B(u,z)` with disjoint private variables it extracts a small circuit that decides, on the shared variables `u`, which conjunct is false. Encode ECDLP as the disjoint pair `x < n/2` versus `x >= n/2` and the extracted interpolant is a top-bit DL oracle; `log2 n` iterations give the full logarithm.

#### Group A — conservative extensions

##### `RESINTERP-SIZE-A1` — Refutation-size + extraction-blow-up meter on the ECDLP top-bit disjoint NP pair, with a smooth-order positive control

- **Mechanism.** Build the propositional disjoint pair A(u,x_A) = 'x_A P = Q and x_A < n/2' versus B(u,x_B) = 'x_B P = Q and x_B >= n/2', shared variables u = bits of (Q_x,Q_y), private variables x_A, x_B disjoint. The pair is genuinely disjoint because log_P Q is unique mod n, so A and B are never both satisfiable and the conjunction is refutable. Resolution has feasible interpolation (Krajicek 1997) with circuit size linear in refutation size, so a refutation of size S yields a circuit C(u) that outputs the top bit of log_P Q; log2(n) evaluations of C in a halving descent recover x completely. Measure S(p) empirically via DRAT proof logging, and separately measure the actual gate count of the extracted C, on three curve arms.
- **Semantic fingerprint.** algebraic object: the propositional CNF disjoint pair over bit-blasted F_p arithmetic and a double-and-add ladder for [x]P; public ops: resolution steps (CDCL search, DRAT-checked); hidden structure: whether the injectivity of k -> kP admits a short propositional proof; info discarded: all curve/algebraic structure (everything is bit-level), the factor base, the group law as an algebraic object; info retained: the refutation DAG and the interpolant extractable from it; relation primitive: NONE — the family collects no relations at all; compression primitive: Krajicek interpolant extraction (refutation DAG -> Boolean circuit), blow-up linear in S; rank mechanism: NONE — there is no relation matrix and no linear algebra stage; descent mechanism: binary search on the residue interval [0,n) driven by log2(n) evaluations of the extracted interpolant (a bit-oracle descent, not a large-prime graph descent); dominant cost exponent: sigma = log_p S(p), the refutation-size exponent — rho is crossed iff sigma < 1/2.
- **Dominant exponent (author's claim).** sigma = log_p S(p), the refutation-size exponent. rho is crossed iff sigma < 1/2 (single-target, 256-bit: S < ~2^119.8). Predicted measured value sigma ~ 0.8-1.0 at toy scale; predicted asymptotic sigma >= 1.
- **Adversarial verdict.** **REJECTED-exponent-neutral**
- **Killer objection.** The extracted interpolant C(u) depends only on (E,P,n) and never on Q, so the construction is a preprocessing attack with advice S and online time O(log n) - the identical resource charged by BAR-AMORT-D2 / Corrigan-Gibbs-Kogan ST^2 = Omega(eps*N). Its declared cost axis (refutation SIZE) is already occupied in resolution by RESOLUTION-WIDTH-A3/D2 via Ben-Sasson-Wigderson (width-to-size is one theorem's two sides), and its headline novelty claim ('first candidate in 95 files with no relation primitive and no rank mechanism') is refuted by grep: 11 denominator files carry candidates with that same fingerprint shape.

##### `NSINTERP-SIZEDEGREE-A2` — Size-degree tradeoff audit: the corpus's own conjectured PC-degree bound is too weak to bound the interpolant, and therefore too weak to close the extraction lane

- **Mechanism.** Nullstellensatz and Polynomial Calculus admit feasible interpolation (Pudlak-Sgall), so a PC refutation of the split-variable decomposition pair yields an interpolant circuit of size polynomial in the refutation SIZE, not its degree. The corpus's existing barrier POLYCALC-D2 conjectures a PC DEGREE lower bound d = Omega(L^{1/2}) on the decomposition ideal. Converting degree to size requires the Impagliazzo-Pudlak-Sgall size-degree tradeoff, size >= exp(Omega((d - d_0)^2 / n_vars)). Instantiate it: if the encoding carries n_vars = Theta(L) Boolean variables and d = Theta(L^{1/2}), then (d - d_0)^2 / n_vars = Theta(L)/Theta(L) = Theta(1), and the implied size bound is exp(Omega(1)) — a constant, i.e. VACUOUS. The corpus's degree barrier sits exactly at the threshold where the standard degree-to-size conversion returns nothing.
- **Semantic fingerprint.** algebraic object: the m=5 Semaev decomposition ideal already frozen in-ledger, in its PC/NS propositional encoding; public ops: PC derivations (multiply by variable, linear combination); hidden structure: the gap between refutation degree and refutation size in the specific encoding used; info discarded: the geometry of the variety (only the monomial count survives); info retained: n_vars, d_0 (max initial degree), and the conjectured d; relation primitive: NONE (this is an audit of an existing barrier, not an engine); compression primitive: Pudlak-Sgall NS/PC interpolant extraction; rank mechanism: NONE; descent mechanism: NONE (no descent is defined — the candidate is deliberately INCOMPLETE as an algorithm); dominant cost exponent: none is implied — the finding is that no exponent follows from the existing degree bound.
- **Dominant exponent (author's claim).** None implied. The finding is precisely that the existing degree bound d = Theta(L^{1/2}) at n_vars = Theta(L) implies only exp(Omega(1)), so no size exponent and hence no interpolant-size exponent follows from it.
- **Adversarial verdict.** **REJECTED-duplicate**
- **Killer objection.** A null observation about the downstream implications of an unproven conjecture: it audits POLYCALC-D2's own conjectured PC-degree bound, finds the Impagliazzo-Pudlak-Sgall size-degree tradeoff gives exp(Omega(1)) = vacuous, and its literal content is therefore 'we cannot rule out small refutations' - which opens the lane rather than closing it. #### Group B — genuine representation changes

##### `DLPAIR-CANONICAL-B1` — ECDLP re-represented as a disjoint NP pair; the algorithm becomes a separator circuit and its cost becomes a proof length

- **Mechanism.** Replace the representation 'ECDLP is a search problem in a group' by 'ECDLP is the disjoint NP pair (U_lo, U_hi)', where U_lo = {(E,P,Q) : exists x < n/2 with xP = Q} and U_hi = {(E,P,Q) : exists x >= n/2 with xP = Q}. Both sides are in NP (the witness is x itself), and they are disjoint by uniqueness of the discrete log. An algorithm is then no longer a search procedure but a SEPARATOR: any circuit C with C = 0 on U_lo and C = 1 on U_hi is a top-bit oracle, and log2(n) of them give the full log. In this representation, for any proof system P with feasible interpolation, P-separability of the pair is EQUIVALENT to the existence of short P-proofs of the ECDLP tautologies; the algorithmic question becomes a proof-length question, and the family's objects are canonical pairs and reductions between disjoint NP pairs (Razborov; Glasser-Selman-Sengupta) rather than curves and factor bases.
- **Semantic fingerprint.** algebraic object: the disjoint NP pair (U_lo, U_hi) over ordinary prime-field curves, and the lattice of disjoint NP pairs under many-one reductions; public ops: pair reductions, and P-proofs in a fixed interpolating system; hidden structure: the position of the DL pair relative to the canonical pair of each proof system; info discarded: the group law, the coordinates, everything algebraic — only membership in two languages survives; info retained: separability status and the proof length that certifies it; relation primitive: NONE; compression primitive: the separator circuit itself (a one-bit compression of the whole instance); rank mechanism: NONE; descent mechanism: log2(n) separator evaluations under interval halving; dominant cost exponent: the separator-size exponent, rho crossed iff size < p^{1/2} / log2 p.
- **Dominant exponent (author's claim).** Separator-circuit-size exponent. rho crossed iff separator size < p^{1/2}/log2 p. No value is derivable from the representation change itself — the representation is exact, so it moves no exponent, and any value must come from A1's measured refutation size.
- **Adversarial verdict.** **REJECTED-exponent-neutral**
- **Killer objection.** Proof systems that HAVE feasible interpolation are weak, and there Krajicek's separator is a MONOTONE circuit while the DL top-bit predicate is not monotone. The corpus already logged exactly that self-defeat ('membership predicate is NOT monotone => vacuous/self-defeating', idea_generation_20260720_batch6.md line 60) and records it as the identical restricted-model collapse of nine prior C1 candidates. The representation change is exact, so it moves no exponent by construction.

##### `HERBRAND-DISJUNCTION-B2` — The DL algorithm re-represented as a Herbrand disjunction: a finite set of closed-form candidate terms rather than a search

- **Mechanism.** Represent 'for all Q in <P>, there exists x with xP = Q' as a first-order statement over the theory of E(F_p) and apply Herbrand's theorem: a proof yields a finite disjunction of TERMS t_1(Q), ..., t_k(Q) in the language (field operations, curve operations) such that OR_i (t_i(Q)P = Q) is valid. This is a genuine representation change — the algorithm becomes a finite list of closed-form rational functions of Q's coordinates, evaluated and tested, with no search at all. Cost = k evaluations plus k verifications. rho is crossed iff k < 0.886*sqrt(n) with each t_i cheap. The Herbrand width k is thus the entire cost, and the family's question becomes: how algebraically compressible is the map Q -> log_P Q?
- **Semantic fingerprint.** algebraic object: the Herbrand universe of terms over (F_p, +, *, curve group law) and the disjunction certifying DL totality; public ops: term evaluation over F_p; hidden structure: whether log_P admits a low-degree rational section on a positive-density subset; info discarded: the group's ordering and any bit structure — only algebraic closed forms survive; info retained: the disjunction width k and the maximal term degree d; relation primitive: NONE (no factor base — each term is a direct candidate for the log); compression primitive: the Herbrand disjunction itself, compressing an exhaustive search into k closed forms; rank mechanism: NONE; descent mechanism: NONE needed — the disjunction is the whole algorithm, evaluated in one shot per target; dominant cost exponent: tau = log_p k, the Herbrand-width exponent; rho crossed iff tau < 1/2.
