# Bounded execution wrapper control

- **Question:** Can the lower-level wrapper run the collector, independent count oracle, and Python verifier in sequence, retain raw files and resource observations, stop on failure, and refuse scientific mode without a digest-bound approval file?
- **Workload:** The 19-point, six-base-point control with all 18 nonidentity targets, a 60-second total wall watchdog and 1 GiB memory setting. The test uses `--control`, so none of these attempts is a formal endpoint trial. The source and binary hashes, exact commands, git state, logs, and result are in each attempt's files.
- **Attempts:** [Attempt 0](executor_20261015/attempt/receipt.json) failed when sandboxed macOS denied `psutil` access to child process memory. [Attempt 1](executor_20261015_retry1/attempt/receipt.json) failed because macOS rejected `RLIMIT_AS` in `preexec_fn`. [Attempt 2](executor_20261015_retry2/attempt/receipt.json) passed after local process-memory access was approved. [Attempt 3](executor_20261015_retry3/attempt/receipt.json) passed after adding explicit RSS sample counts and post-exit `ru_maxrss` comparison. [Attempt 4](executor_20261015_retry4/attempt/receipt.json) passed with git state and source digests recorded. [Attempt 5](executor_20261015_retry5/attempt/receipt.json) passed after binding the collector and independent-count source hashes. [Attempt 6](executor_20261015_retry6/attempt/receipt.json) passed on the current verifier with canonical row and rank statistics. Each attempt has its own input, manifest, command, wrapper logs, `events.jsonl`, phase stdout/stderr, and receipt; none was overwritten.
- **Interpretation:** The current wrapper passes the small-group control and binds all three component results. It records `completed_control`, not a scientific finding. The two failed attempts are infrastructure failures. The approved `EXP-*` admission file, dispatch ownership, actual post-freeze seed issue and commitment, full 32,768-target runs, complete per-phase resource measurements, and post-seal seed reveal are still outstanding.
- **Resource limit:** On Linux the wrapper sets `RLIMIT_AS`, a virtual-address bound stricter than RSS; on macOS it samples child RSS every 50 ms and checks the OS child maximum after exit. A fast process can finish between samples. The full-size macOS collector and count phases must each produce at least one live sample in scientific mode; otherwise the run is rejected. This is not a guarantee against an unsampled transient peak. The repository runner's own admission and machine safeguards still apply.
