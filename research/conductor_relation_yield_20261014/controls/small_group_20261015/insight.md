# Arity-3 collector implementation control

- **Question:** Does the Rust pair-sum collector return the complete multiset of three-point representations, including repeats and cancellation, on a fully enumerable group? Does the separate Python verifier accept the resulting target equations, reported triples, counts, and rank accounting?
- **Workload:** Short-Weierstrass curve `y²=x³+2x+2` over `F_17`, prime group order 19, generator `(5,1)`, three signed x-orbits (six factor-base points), all 18 nonidentity targets, `Q=[7]G`.
- **Baseline and candidate:** Independent Python ordered Cartesian-product enumeration and group law versus `collector.rs` pair-sum enumeration; `verify_collector.py` independently replays the candidate output. All three source hashes and the compiled binary hash are in [receipt.json](receipt.json).
- **Commands and environment:** Exact commands, start times, elapsed times, exit codes, compiler/Python/platform versions, dirty-tree state, raw child RSS field, and stdout/stderr digests are in the receipt. Compilation used `TMPDIR=/private/tmp`; an earlier default-scratch compilation failed with `No space left on device` and was not retained as a raw capture.
- **Raw measurements:** The compile and control commands exited 0. The test's [stdout](small_group_control.stdout) records the exhaustive pass; [stderr](small_group_control.stderr), compiler [stdout](compile.stdout) and [stderr](compile.stderr) are retained, including empty captures. The control compared every target's full unordered triple set, ordered multiplicity and useful count, checked all-target ordered conservation `|F|³`, and invoked the separate verifier's target and rank checks.
- **Cost:** Compile 2.687 s, control 0.520 s on the host named by the receipt. `peak_child_rss_raw=166232064` is the macOS `ru_maxrss` field over the child processes, not a per-process memory benchmark.
- **Interpretation:** This passes a bounded exactness control for the implemented collector and verifier. The P29/P37 target generator, full-size completeness check, resource-bounded launcher, and formal experiment admission remain open. The observed pass supplies no endpoint relation-yield measurement.

An expanded control was run after the test source changed; its separate [receipt](expanded_receipt.json), [stdout](expanded.stdout), and [stderr](expanded.stderr) are retained. It explicitly exercised both rank layouts: `Q=[7]G` in the base and `Q=[2]G` outside the base. Both verifier passes succeeded. The original source hashes and output remain bound to the first attempt.

It does not replace the required full-size equality check.
