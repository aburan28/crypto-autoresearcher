## Question and estimands

Does a native factor base on the floor of a large prime-conductor isogeny step produce a different **three-summand** relation yield from the crater, at fixed field, group order, target law, base cardinality and relation definition? The same analysis asks whether any observed change survives a random-point base and a coordinate-presentation null. The exact, targetwise equality of decompositions under an injective isogeny with a *transported* base is a correctness control, not a possible source of yield gain.

The oracle counts exact elliptic-curve group-law triples using a two-sum table. This isolates mathematical relation availability. It does not time a Semaev/Gröbner decomposition solver, and a rank increment alone does not certify completion of an index-calculus DLP pipeline.

For an endpoint `E`, a frozen set `F` of signed points and a uniformly sampled nonidentity target `R` in the prime-order group `G`, define `D_E(R)` as the number of **unordered multisets of three points** from `F` whose sum is `R`. Define an eligible useful triple as one with three distinct point IDs, no opposite pair, and a canonical nonzero unknown-column row after sign folding and elimination of known logs. Record separately (1) the primary useful nonempty-target indicator, (2) raw `1[D_E(R)>0]`, (3) raw and useful multiplicities, (4) the ordered-triple count, and (5) distinct verified matrix rows and rank increments over `F_r`. Retain repeated and cancellation triples in raw counts and the conservation check even though they do not count as useful rows. The raw ordered mean is exactly `|F|^3/r` over all `R in G`; it cannot by itself establish a curve advantage. Nonempty probability and useful-rank yield can differ even when that mean is fixed.

For each endpoint choose one sealed nonzero scalar `k` and publish `Q=[k]G`, where `G` is the certified generator. The relation collector sees `G` and `Q`, never `k`. Generate SHA-256-derived coefficients `(a_i,b_i)` with an endpoint-domain-separated stream, `a_i` uniform modulo `r` and `b_i` uniform in `1..r-1`; set `R_i=[a_i]G+[b_i]Q`. Reject duplicate or identity `R_i` with a recorded rejection reason until the target quota is full. Marginally, each retained target is uniform over the nonidentity subgroup, while every accepted relation has a known symbolic right side `a_i+b_i k`. The points are **native marginal samples**, since no explicit connecting point map is supplied. Constructed-solvable targets are correctness fixtures only and never enter the yield estimate.

## Primary protocol to freeze

1. **Bind inputs.** Store the exact curve/field/generator specifications, `r` primality and group-order checks, conductor certificates, source commits, and input digests. Confirm the two endpoints in each pair have the same `p`, trace and `r`, and that `gcd(ell,r)=1`.
2. **Factor bases.** On each native endpoint, take the first `B` distinct rational abscissae in increasing integer order, include both signs as distinct points, and reject identity. Use `B=256` for P29 and `B=1600` for P37. For a random-base control, draw field elements uniformly with rejection of modular-reduction bias, reject nonliftable or repeated x-values, and stop at exactly `B` distinct liftable x-values; include both signs. Use an independently domain-separated stream per endpoint and reuse that endpoint's native targets. This is a uniform sample of opposite-point orbits in a prime-order group, so its yield law is the same on either endpoint of a pair under abstract group isomorphism. Save complete point lists and hashes. The signed cardinality is `2B` in every arm.
3. **Targets.** After runner/verifier code and source hashes are frozen, obtain one 256-bit target root seed and a separate 256-bit verifier seed from OS entropy; commit their hashes, public `Q` coordinates and target-vector digests before collection. Derive each endpoint's nonzero `k` from the verifier seed. The collector receives `a_i,b_i,R_i` but cannot read the seeds or `k` while producing relations. Reveal seeds and `k` for replay only after collector output is sealed. This is process separation, not a cryptographic secrecy claim at these group sizes. Derive `32768` distinct nonzero `R_i=[a_i]G+[b_i]Q` per endpoint from a versioned SHA-256 stream separated by panel, endpoint, arm, draw kind, draw index and retry index. For modulus `m`, interpret each block as a 256-bit integer `z`; accept only `z < floor(2^256/m)*m`, then use `z mod m` (add one for a `1..m` range). Thus `a_i` is uniform modulo `r` and `b_i` uniform in `1..r-1` under the seeded-stream model. Record every duplicate-target and identity rejection. The random-base control reuses the same endpoint targets. Targets are native marginal samples on the two curves, not transported points. Keep separate planted-sum and isomorphic controls outside primary inference.
4. **Oracle.** Build an exact two-sum table for the complete signed base, retaining point multiplicity and original point IDs. For each target enumerate every third point, look up the residual, canonicalize a triple by sorted point IDs, and deduplicate. Recompute every admitted sum using an independent point-addition implementation or a separately checked path. Classify repeated-point and opposite-pair triples before useful-row counting. Count empty targets explicitly. At P37 the ordered pair table has at most `3200²=10,240,000` rows before compression; this and peak RSS are first-class feasibility metrics.
5. **Relations and rank.** Fold signs into coefficients in fixed x-columns. The generator x-value occurs inside each native first-`B` base, so its logarithm is known (`+1` for `G`, `-1` for `-G`): eliminate its coefficient from the unknown matrix and move it to the right side. Add one common `Q` column, unless `Q` is itself a base point, in which case merge the coefficients into that x-column. A triple for `R_i` gives factor-base coefficients, target coefficient `-b_i`, and right side `a_i` minus the eliminated known-log contribution. Do not introduce a column per target. Independently replay rows in the group and recompute rank modulo `r` at target prefixes `512, 2048, 8192, 32768`; `2048` is the common early-rank comparison. The planted `k` is used only by the post-run verifier. Report raw hits, duplicate rows, rank increments and cost per increment separately.
6. **Resource accounting.** Record setup, factor-base generation, pair-table build, every target probe, verification, deduplication and rank work, CPU/wall time, memory peak, failures and retries. A process watchdog and memory ceiling protect the host; they do not change the scientific sample count. A censored arm stays visible and yields no completed-arm-only advantage claim.

The exact m=3 occupancy calibration is **not** the ordered mean `|F|³/r` interpreted as a success probability. The ordered means for the two panel sizes are approximately 0.419 and 0.401. Permutations of a typical distinct triple account for six ordered representations. The rough random-group expectation for nonempty targets is therefore `1-exp(-|F|³/(6r))`, about 0.067 and 0.065, respectively. This approximation is for power planning only. Repetitions, opposite pairs and collisions are resolved by the oracle. At 32768 targets, occupancy near these values would yield about 2180 P29 and 2110 P37 occupied targets, while there are at most 256 and 1600 unknown columns after eliminating the known generator. Final rank can saturate, which is why the frozen prefix curve matters. At the 2048-target prefix the corresponding planning expectations are about 137 and 132 occupied targets. These are heuristic expectations, not measurements or power guarantees.

## Predeclared comparisons and interpretation

Primary contrasts are floor/crater ratios of **useful** nonempty-target yield within each frozen pair under native bases. For each of the four primary endpoints let `N=r-1`, `n=32768`, and invert the exact `Hypergeometric(N,K,n)` tails for the unknown count `K` of useful targets in the nonidentity group, at two-sided `alpha=0.0025`. For observed hit count `x`, use the smallest `K` with `Pr_K[X>=x] >= 0.00125` as the lower bound and the largest `K` with `Pr_K[X<=x] >= 0.00125` as the upper bound, with endpoint boundary conventions. Bonferroni gives at least 99% simultaneous coverage for the four endpoint fractions; form each ratio interval as `[L_floor/U_crater, U_floor/L_crater]`. If the crater lower bound is zero, report an unbounded ratio and an absolute difference instead; it cannot pass a finite-ratio lead gate. Keep exact counts, raw occupancy and random-base results. Independent marginal endpoint targets require two-sample intervals, not a paired bootstrap. Rank curves are separately reported at fixed prefixes, since final rank can saturate. The target-sampling intervals are conditional on these selected curves and fixed bases; they do not cover variation among all floor curves or conductor gaps.

The positive control must recover every planted triple and the same-curve independent oracle must agree on a fixed validation subset. The isomorphic-presentation control uses `u=2` in each prime field, with `x'=u²x`, `y'=u³y`, `a'=u⁴a`, `b'=u⁶b`; transported points, base and targets must conserve `D_E(R)` target by target. A separate **coordinate-sensitivity arm** rebuilds the first-`B` liftable-x native base on each transformed primary endpoint and probes the transported targets. This measures how much the native base changes under a coordinate presentation of the same curve; it is not an exact-equality control. A certified isogeny-map transport arm, if later implemented, must conserve each decomposition count under the transported base when `gcd(ell,r)=1`. Native bases need not conserve counts because they are different sets.

Nominate a fixed-pair native-base lead only if both simultaneous ratio intervals exclude one in the same direction, both observed point ratios differ from one by at least 20%, and all validity controls pass. The 20% point-estimate cutoff is a selection rule, not a guarantee of power at a true 20% effect. Report P29 E2/E3, the coordinate-sensitivity arms, random bases and rank-prefix curves even if they disagree; disagreement narrows interpretation rather than changing the primary target list. An interval containing one does not establish equality. If only one pair moves, report pair-specific heterogeneity. Even concordant pairs do not isolate conductor causality from model and base choice. A later claim about ECDLP cost needs a new certified pair, explicit map/dual and complete transfer, solver and recovery pricing.
