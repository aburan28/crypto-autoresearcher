# Next discriminator: the recovered certificate-search path

This is an implementation and protocol-completion checklist, **not an approved experiment or a claim that a runnable launcher exists**. The source audit has executed no named curve order.

The acquired artifact permits a new, concrete check of the optional-certificate explanation left open by the earlier Pocklington proxy. Complete a frozen executable protocol before launching it:

1. Bind ECPP V3.4.1 archive SHA-256 `0387e7d180e570d0cf1ff957ed281a46711fb20d50ae0b0669a01a3464d9160f`, original source/data inventories and every compatibility patch. Establish correct word width, calling convention, format strings and arithmetic on the actual host. Retain the original archive. Do not run its bundled historical binaries or use their shell scripts as a modern build recipe without inspection.
2. Resolve every input by full UID from the existing 21-curve traits. Use a fresh process and a declared initial RNG state for each order. Freeze all eleven omitted, eight same-field published and two larger-field published controls together. Do not tune the catalog, factoring tactics or per-case limit to observed labels.
3. The primary route keeps the complete supplied catalog, original factoring parameter table, proving phase enabled and the N−1/N+1 routes enabled. Any elliptic-curve-only route is a separately declared comparison, not an after-the-fact replacement of a failed primary route. Record serial/distributed and DEBUG configuration explicitly.
4. Controls must cover a known certificate, known small primes and composites, a forced search-exhaustion path, a missing-data path, malformed/incomplete certificates, an exception and a missing completion marker. Require a certificate and verification verdict; exit code or the word “prime” alone is insufficient. Preserve the legacy CLI's labels separately from validated classifications.
5. Fix a process watchdog and memory envelope for machine protection, one complete serial pass over the cohort, immutable per-case directories, raw stdout/stderr, exact commands, source/executable/input hashes and RNG state. Instrument catalog positions, recursive chain choices, attempted factoring routes, certificate output, failed phase, exit reason and resource measurements. A timeout, crash, missing file or portability failure is `INDETERMINATE`, never a weak-curve classification.
6. The first question is whether the supplied algorithm/call path separates all eleven omissions from published controls under one fixed configuration. All inputs are already certified prime: a zero or “composite” result here would identify legacy search/error behavior, not a newly discovered factor. Any split needs a repeated replay and independent validation. It would still not prove historical use or an ECDLP advantage.
7. If every input succeeds, retain the traces and reject only this artifact/configuration as a complete explanation. If any fails, identify and replay its exact mechanism before changing the configuration. If all eleven split, test the wider certified historical candidate cohort without retuning and obtain original-call provenance before attributing the rule to 1997.

The immediate missing implementation is a verified compatibility build and fail-closed launcher/checker, with the protocol and handoff committed under the repository's execution rules. Until those exist, the source path remains a hypothesis and the global historical-selection question remains open.
