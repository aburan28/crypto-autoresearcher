## Exact construction path and small controls

The opt-in [wide_tails.py](../../src/crypto_autoresearcher/index_calculus/wide_tails.py) stores little-endian `(x,code)` uint64 pairs. Each code preserves nondecreasing factor-base indices, first-positive sign convention, the negation pair and the sum's `y` bit. It charges each `(a,tail)` prepend once as an S3-equivalent solve, including infinity branches. The C++ [source](../../src/crypto_autoresearcher/index_calculus/wide_tails.cpp) uses `__uint128_t` for modular products and compiles cleanly; the current macOS host stalls fresh executables before `main`, including two independent hello controls. The [named obstruction](../../problems/native-builder-launch-hangs-before-main.md) records that limit.

The native control source was `#include <cstdio>\nint main(){std::puts("hello");return 0;}\n` in the pinned scratch `loader_probe/hello.cpp`. `/usr/bin/clang++ -std=c++17 hello.cpp -o hello-clang++` and `/usr/bin/c++ -std=c++17 hello.cpp -o hello-c++` each exited 0; Python `subprocess.run([binary], capture_output=True, timeout=5)` killed each after more than 5 seconds with no output. An outside-sandbox repetition of `hello-clang++` likewise timed out at 5 seconds. The new C++ tail binary produced no first instrumentation line; a one-second `sample` found 885 samples in `_dyld_start`, before opening its input. A previously pending trivial dynamic-library load later completed and returned 42; its elapsed time was not recorded, so a long startup delay remains possible. These are host-control observations, not a verdict on the C++ algorithm. [build-command.txt](build-command.txt) and its raw stdout/stderr record the current clean compile separately.

For this fixture `p<2^50`, the Numba path uses a binary64 quotient estimate and an exact signed 64-bit residual correction. Inputs and modulus are exactly representable; the two rounded operations induce absolute quotient error below 1/4, so the integer quotient differs from the exact floor by at most one. The low 64 bits of `ab-qp` recover the signed exact residual in `(-p,2p)`, within signed 64-bit range, and one correction yields the exact residue. No fast-math mode is enabled. This argument does not extend to arbitrary `p<2^63`.
