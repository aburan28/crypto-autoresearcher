## Implementation

- `monitor.py` samples the live root and recursively discovered children using the pinned Sage Python `psutil` 7.2.2. It resolves a root exit/zombie race by rechecking the child lifecycle, uses `null` for unknown RSS, and emits a distinct `infrastructure_monitor_error` for an unreadable live child. It retains the 8 GiB proposed sampled tree-RSS cap as a later protocol parameter; this task's synthetic tests use smaller local caps when needed. When the root exits, the watchdog enumerates the old private process group before signaling surviving descendants; inability to verify or signal a remaining group becomes an infrastructure fault.
- `phase.py` appends JSONL events with monotonic and wall timestamps, stream sequence, phase name, source SHA-256 and fsync on each event. A truncated final record is preserved and flagged with its raw hash. `instrumented_backend.py` marks input load, polynomial-ring and ideal construction, Gröbner, model count, root enumeration and response write. It preserves the frozen cap-before-variety logic and requires a future approved-launch hash binding at the CLI. It was not invoked on a polynomial system here.
- `driver.py` runs synthetic phases only and writes custody containing exact trace, stdout and stderr hashes; a future scientific launcher must supply admission and input/response bindings. The [prospective diagnostic design](diagnostic-design.md) prelists the three m=2 archived positives and a monitor-fault null control for Coordinator review. It is unapproved and contains no trial result.

## Scope and limits

The monitor measures *sampled* process-tree RSS. A short memory spike between samples can be missed; a child that deliberately leaves the private process group is outside this implementation's confinement assumption. An unparseable partial trace remains hash-bound but must be classified as incomplete telemetry. A failure of the trace storage itself is outside this in-process custody guarantee and requires the future external supervisor to preserve and classify the failure. The tests establish synthetic lifecycle behavior on this host, not solver feasibility or performance. The selected m=2 coset, random and small-x encodings have different archived input support, but input support does not establish observed Gröbner degree, sparsity during reduction, relation yield or runtime advantage. No end-to-end index-calculus cost or matched rho comparison is provided by this task.

The next scientific step requires a separate fresh-ID, Coordinator-approved diagnostic with independent polynomial and full-point checking and fixed limits. Even a checked m=2 positive result would leave natural relations, useful rank, linear algebra, target recovery, complete cold and online cost, and the m=2..8 comparison across prime, Koblitz and ordinary-binary curves open.
