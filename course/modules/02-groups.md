# Module 02 — Groups

> **Goal.** The language of symmetry and of every cryptographic
> structure: groups, subgroups, orders, cyclic groups, homomorphisms,
> kernels, quotients. Elliptic-curve points form a group; isogenies *are*
> group homomorphisms; a kernel *is* an isogeny's identity card.
>
> **Lab:** revisit [`lab01_arithmetic.py`](../labs/lab01_arithmetic.py) —
> everything there is secretly about the groups (ℤ/nℤ, +) and (ℤ/pℤ)^×.

## 1. Definition and first examples

A **group** (G, ∗) is a set with an operation satisfying:

1. **associativity**: (a∗b)∗c = a∗(b∗c);
2. **identity**: ∃e with e∗a = a∗e = a;
3. **inverses**: ∀a ∃a⁻¹ with a∗a⁻¹ = e.

If also a∗b = b∗a, the group is **abelian**. All groups in this course
are abelian and *finite*, and we usually write them additively
(operation +, identity 0, inverse −a, repeated operation n·a).

| Group | Elements | Operation | Order (size) |
| --- | --- | --- | --- |
| (ℤ/nℤ, +) | residues mod n | addition | n |
| (ℤ/pℤ)^× = F_p^× | nonzero residues | multiplication | p − 1 |
| (ℤ/nℤ)^× | residues coprime to n | multiplication | φ(n) |
| E(F_q) | curve points | chord-tangent (module 06) | ≈ q |

Non-example: (ℤ/nℤ, ×) for n > 1 — 0 has no inverse.

## 2. Order, subgroups, Lagrange

The **order of an element** g is the least k ≥ 1 with k·g = 0 (written
multiplicatively: gᵏ = 1); the cyclic **subgroup generated by g** is
⟨g⟩ = {0, g, 2g, …, (k−1)g}, of size k.

**Theorem (Lagrange).** If H ≤ G is a subgroup of a finite group, then
|H| divides |G|. In particular the order of every element divides |G|,
and |G|·g = 0 for all g.

*Proof idea.* The cosets a + H = {a + h : h ∈ H} partition G and all
have size |H| (the map h ↦ a + h is a bijection). ∎

Lagrange is the free theorem you will use constantly:

* g^(p−1) = 1 in F_p^× — that's **Fermat's little theorem** (module 04);
* N·P = O for every point P on a curve with N points — the check in
  lab 03;
* the possible orders of points on a curve of order 464 are exactly the
  divisors of 464.

## 3. Cyclic groups

G is **cyclic** if G = ⟨g⟩ for some generator g. Then G ≅ ℤ/nℤ with
n = |G|: cyclic groups are completely understood.

Facts you should be able to prove for G cyclic of order n:

* every subgroup is cyclic; there is exactly **one** subgroup of order d
  for each d | n;
* the number of generators is φ(n);
* the number of elements of order exactly d (for d | n) is φ(d).

A deep fact previewed here and proved in module 04: **F_p^× is cyclic** —
there is a "primitive root" g mod p with F_p^× = {1, g, g², …, g^(p−2)}.

## 4. Homomorphisms, kernels, images, quotients

A map f : G → H between groups is a **homomorphism** if
f(a + b) = f(a) + f(b). Then automatically f(0) = 0 and f(−a) = −f(a).

* **kernel**: ker f = {g : f(g) = 0}, a subgroup of G;
* **image**: im f = f(G), a subgroup of H;
* f is injective iff ker f = {0}.

**Quotient.** For a subgroup K of an abelian G, the cosets form a group
G/K with (a + K) + (b + K) = (a + b) + K.

**First isomorphism theorem.** G/ker f ≅ im f. For finite groups,
|G| = |ker f| · |im f|.

### The examples that matter here

* reduction ℤ → ℤ/nℤ: kernel nℤ, so ℤ/nℤ is literally a quotient;
* multiplication-by-m on an abelian group, [m] : g ↦ m·g; its kernel is
  the **m-torsion** G[m] = {g : m·g = 0}. On elliptic curves, E[m] is
  the leading actor of modules 07–10;
* squaring on F_p^×, x ↦ x²: the kernel is {±1}, so the image — the
  **quadratic residues** — has size (p−1)/2. Module 04 in one line;
* an isogeny φ : E → E′ (module 09) is exactly a homomorphism of curve
  groups given by polynomials; "E′ = E/K" for K = ker φ is this
  section's quotient, made geometric by Vélu's formulas.

## 5. Products and the structure of finite abelian groups

The **direct product** G × H has componentwise operations. The **Chinese
Remainder Theorem** (module 04) in group language:
ℤ/mnℤ ≅ ℤ/mℤ × ℤ/nℤ when gcd(m, n) = 1.

**Structure theorem.** Every finite abelian group is a product of cyclic
groups; it can be written uniquely as ℤ/n₁ × ℤ/n₂ × ⋯ with n₁ | n₂ | ⋯
(the **invariant factors**). The largest invariant factor is the
**exponent** — the lcm of all element orders.

For elliptic curves the theorem specializes dramatically (module 07):
**E(F_q) ≅ ℤ/n₁ × ℤ/n₂ with n₁ | n₂** — at most *two* factors. That
"rank ≤ 2" fact is why E[2] ≅ (ℤ/2)² gives exactly **three** order-2
subgroups, hence three 2-isogenies, hence the 3-regular graphs of
module 10.

## 6. Self-check

<details><summary><b>Q1.</b> Element orders in (ℤ/12ℤ, +)?</summary>

ord(k) = 12/gcd(k, 12): orders 1,12,6,4,3,12,2,12,3,4,6,12 for
k = 0..11. φ(12) = 4 generators: 1, 5, 7, 11.
</details>

<details><summary><b>Q2.</b> Show x ↦ x² on F_13^× has image of size 6,
and list it.</summary>

Kernel = {±1} (x² = 1 ⇒ (x−1)(x+1) = 0 in a field), so image has
12/2 = 6 elements: {1, 4, 9, 3, 12, 10} (squares of 1..6; squares of
7..12 repeat them in reverse).
</details>

<details><summary><b>Q3.</b> G = ℤ/2 × ℤ/8. What is its exponent? Its
invariant-factor form? How many elements of order 2?</summary>

Exponent lcm(2,8) = 8; already in invariant form n₁ | n₂ = 2 | 8.
Elements of order dividing 2: 2·2 = 4 (each coordinate 2-torsion), so
order exactly 2: three. Note: a *cyclic* ℤ/16 of the same size has only
one element of order 2 — counting 2-torsion distinguishes group shapes,
exactly how lab 03's `group_structure` works.
</details>

<details><summary><b>Q4.</b> Why does a group of prime order have no
interesting subgroups, and why do cryptographers care?</summary>

Lagrange: only subgroup orders are 1 and p, so every non-identity
element generates. Cryptographers pick prime-order (sub)groups so that
no attacker can project the discrete log into a small subgroup —
Pohlig–Hellman, lab 04 exercise 4.2.
</details>
