Orbit of g under multiplication mod n

Multiplication table of ℤ/nℤ

Hover the table: cell (row i, column j) shows i·j mod n. Prime n → every row is a permutation (a field). Composite n → flat stripes of repeated values and zero divisors. Modules 01–04.

The supersingular 2-isogeny graph over 𝔽p²

j ∈ 𝔽p² j ∈ 𝔽p (on the mirror axis) j = 0 / j = 1728 random walk

Controls

Every vertex is a supersingular j-invariant (⌊p/12⌋+ε of them, all in 𝔽p²); every vertex has three 2-isogenies. Conjugate j-invariants are drawn mirrored across the horizontal axis — Frobenius is a graph symmetry, and the 𝔽p-rational vertices sit on the mirror. Click a vertex; watch a walk mix. Modules 08–11.

Data and verification: course/labs/lab06_ss_graph.py (vertex counts match the Eichler–Deuring mass formula; every edge is a root of the modular polynomial Φ₂). Course text: course/modules/.
