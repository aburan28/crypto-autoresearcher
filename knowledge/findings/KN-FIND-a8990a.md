## The object

Let `E` be an elliptic curve over any field `K`, let `pi : E -> P^1` be the quotient
by inversion (the `x`-map), fix `m >= 3` and put `n = m-1`. Let `t_1,...,t_n` be
independent transcendentals, `L = K(t_1,...,t_n)`, and let `P_i` be the tautological
point with `pi(P_i) = t_i`. The object of study is

```
S_m(t_1, ..., t_n, T)  in  L[T],     deg_T = 2^{m-2}.
```

The only two properties of `pi` used anywhere below are:

- **(P1)** `pi` is finite separable of degree 2 and `K(E)/K(x)` is Galois with group
  generated by inversion;
- **(P2)** inversion is not the identity on `E`.

Both hold in **every** characteristic, including 2 and 3. That is why nothing below
excludes a characteristic, and why nothing below depends on the Weierstrass model.

## Theorem A (structure)

`S_m(t_1,...,t_n,T)` is separable of degree `2^{m-2}`. Its splitting field over `L` is
the function field of `E^n / Delta`, where `Delta` is generated by the **diagonal**
inversion, and

```
    Gal( S_m(t_1,...,t_n,T) / L )  =  (Z/2)^n / Delta  =  (Z/2)^{m-2},
```

acting **simply transitively** on the `2^{m-2}` roots. `K` is algebraically closed in
the splitting field, so

```
    arithmetic monodromy  =  geometric monodromy  =  (Z/2)^{m-2}.
```

The group is the same for every curve, every base field and every characteristic.

**The three steps.** (1) The roots are the `x`-coordinates of the signed sums
`eps_1 P_1 + ... + eps_n P_n` -- classical, immediate from the defining property of
`S_m`. (2) Hence the splitting field sits inside `K(E^n)`, which is Galois over
`K((E/+-)^n) = L` with group `(Z/2)^n`: it is the fibre product of `n` copies of a
degree-2 Galois cover, so its deck group is `(Z/2)^n` by Artin's theorem, with no
square-class computation. (3) The diagonal fixes every root since `x(R) = x(-R)`;
nothing else does, because a further coincidence forces
`sum_{i in S} eps_i P_i in E[2]` for a proper nonempty `S`, and the summation map
`E^n -> E` is a surjective homomorphism, so the preimage of the finite scheme `E[2]`
is a **proper closed** subscheme, which the generic point of the integral variety
`E^n` avoids. Because the group is abelian, the stabiliser of a root is normal, so
the root field is already the splitting field: **the cover is Galois.**

**Step (3) is the whole content.** If the signed sums could collide generically for
some curve, that curve would have smaller monodromy -- which is exactly the
exceptional locus `KN-OPEN-009` hunts. `CORR-20260807-652652` records that the earlier
sketch in `KN-FIND-a1f3c2` skipped this step.

## Theorem B (exact factorization law over `F_q`)

For `a in P^1(F_q)` define `c(a) = 0` if the fibre `pi^{-1}(a)` is `F_q`-rational,
`c(a) = 1` if it has no rational point, and `c(a) = *` if `a` is a branch point. For
`q` odd and `E : y^2 = f(x)`, `c(a) = (1 - chi(f(a)))/2` with `chi` the quadratic
character.

Let `a = (a_1,...,a_n) in F_q^n` be **good**: `S_n(a) != 0` and
`sum_{i in S} eps_i P_i not in E[2]` for every proper nonempty `S`. (The non-good
locus has `O_m(q^{n-1})` points.) Then `S_m(a,T)` is squarefree of degree `2^{m-2}`
and exactly one of:

```
  c(a_1) = ... = c(a_n)   ==>  2^{m-2} distinct LINEAR factors, roots the signed sums
  otherwise               ==>  2^{m-3} distinct irreducible QUADRATICS, no root in F_q
```

**No irreducible factor of degree >= 3 ever occurs; all factor degrees are always
equal; and the type depends on `a` only through the class of `(c(a_1),...,c(a_n))`
modulo global sign flip.** This is because the Frobenius element is that vector's
class, and a non-identity element of a **regular** permutation group is
fixed-point-free.

Exact class counts: the number of `a` in the class of `eps` (with `k` entries `+`) is
exactly `S^k N^{n-k} + N^k S^{n-k}`, where `S = #{a : c(a)=0}`, `N = #{a : c(a)=1}`.
The split density satisfies

```
  | (S^n + N^n)/q^n  -  2^{-(m-2)} |  <=  31 (m-1)^2 / (2^{m-1} q)   for q >= 9(m-1)^2,
```

and the **trace cancels at first order at every `m`** -- the `+-t/q` terms enter `S^n`
and `N^n` with opposite signs -- so the split density carries no first-order
information about the curve. At `m = 3` this recovers the `O(1/p)` (not `O(1/sqrt p)`)
density law of `KN-FIND-c41ea9`.

## Theorem C (factor-base locus)

If every `a_i` is the `x`-coordinate of an `F_q`-**rational** point and `a` is good,
then `S_m(a,T)` splits completely over `F_q`, at **every** `m`, with root set exactly
`{ x(eps_1 P_1 + ... + eps_n P_n) }`. Equivalently the decomposition group at every
such point is trivial: the factor-base locus lies inside the totally split locus.

## Corollaries worth keeping

- **Discriminant square class.** `disc_T S_m` is a **square** in `L` for every
  `m >= 4`, and a non-square at `m = 3` (where it equals `16 f(t_1) f(t_2)`). Reason:
  a non-identity element of the regular action is a product of `2^{m-3}`
  transpositions, even iff `m >= 4`. **So `m = 3` is the unique `m` at which the
  discriminant carries information, and the classical `m=3` identity is not the first
  case of a family but the exception.** Any statistic built on the discriminant's
  character is vacuous for `m >= 4`.
- **Branch locus, exactly.** Degree drops exactly on `S_{m-1}(a_1,...,a_n) = 0` (some
  signed sum is `O`); roots collide exactly when `sum_{i in S} eps_i P_i in E[2]` for a
  proper nonempty `S`, the case `S = {i}` being ramification of `pi`. At `m = 3` this
  is `{t_1 = t_2} union {f(t_1) f(t_2) = 0}` and nothing else -- verified to the exact
  point count.
- **Imprimitivity.** For `m >= 4` the group is abelian and regular of degree
  `2^{m-2} >= 4`, hence imprimitive; block systems correspond to subgroups. The
  resultant recursion already exhibits the sign-subgroup family, so the imprimitivity
  is the known recursive structure, not a new exploitable block system.
- **Irreducibility.** Transitivity re-derives the known absolute irreducibility of
  `S_m`. No novelty is claimed for it.

## Why this matters, and precisely how little it claims

**The census obstruction.** Any statistic of the form "factorization type / cycle type
/ Frobenius class of the summation fibre" is **identically constant** on the
factor-base locus, at every `m` and for every curve (Theorem C). A Chebotarev-style
generic-fibre census therefore cannot detect a relation-rate anomaly where relation
search operates -- not because the census is badly designed but because there is no
variation there. Combined with Theorem A (no curve has smaller monodromy) this closes
the *mathematical* content of the `KN-OPEN-009` relation-rate question at every `m`,
and it does so by derivation rather than by the census the goal's criterion asked for.

**Paired with conservation.** `KN-FIND-007` fixes the *mean* decomposition yield at
`binom(B+m-1, m)/N` for every factor base of size `B`. Together: mean yield is fixed
by a double count, and fibre arithmetic is fixed by complete splitting. What remains
free is coverage, multiplicity, relation rank, recognizability, and solve cost -- and
the cost of index calculus sits in the last two.

**THIS IS NOT AN ALGORITHM, and the reason is precise.** Theorem C is about solving
for the **last** coordinate given the other `m-1`. Its operational content -- pick
`m-1` factor-base points, compute `2^{m-2}` signed sums by group arithmetic, test
membership -- is exactly the step index calculus already performs, which is why the
system is posed in `m-1` unknowns. Relation search asks the **opposite** question: the
target is fixed and the other coordinates must be found *in the factor base*.
Complete splitting in the last variable gives that search no leverage whatsoever.

**No ECDLP claim of any kind.** No speedup, no security reduction, no new hardness
result, no change to any complexity estimate. Largest prime exercised is 1009 (10
bits).

## What is classical, and claimed as such

The definition and resultant recursion (Semaev 2004); the identification of the roots
as signed sums; `deg_T S_m = 2^{m-2}`; symmetry; absolute irreducibility; the
"solve for the last variable" step; and the conservation double count. What is offered
as possibly new is Theorem A, Theorem B, the discriminant corollary, and the synthesis.
