## Flagged for Coordinator attention

**KN-LIT-7564 (Wesolowski, `p^{1/3+o(1)}`) conflicts with the recorded baseline in
`KN-TECH-029` and `KN-TECH-050`**, which state the classical supersingular
isogeny-path complexity as `p^{1/2}`. Per `AGENTS.md`, corrections supersede rather
than overwrite and technique-record revisions are the Coordinator's call, so **no
existing entry was modified by this gather**. The tension is written into KN-LIT-7564's
"Relevance" section so a corpus grep surfaces it. The result is heuristic (smoothness
assumption), carries superpolynomial `o(1)` overhead, and needs `p^{1/3}` *memory* —
under the program's own full-cost accounting (`KN-TECH-035`) it is not a `p^{1/3}`
algorithm in any model that charges for storage. **No parameter set should be re-costed
on this basis.** It bears on `KN-OPEN-013`, not on the ECDLP.
