## Contribution
We build concurrently executable blind signatures schemes in the common reference string model, based on general complexity assumptions, and with optimal round complexity. Namely, each interactive signature generation requires the requesting user and the issuing bank to transmit only one message each.

## Key claims (as reported)
- We also put forward the definition of universally composable blind signature schemes, and show how to extend our concurrently executable blind signature protocol to derive such universally composable schemes in the common reference string model under general assumptions.
- While this protocol then guarantees very strong security properties when executed within larger protocols, it still supports signature generation in two moves.
