## Contribution
It is well-known that most cryptographic tasks do not have universally composable (UC) secure protocols, if no trusted setup is available in the framework. On the other hand, if a task like fair coin-tossing is available as a trusted setup, then all cryptographic tasks have UCsecure protocols.

## Key claims (as reported)
- What other trusted setups allow UC-secure protocols for all tasks?
- More generally, given a particular setup, what tasks have UC-secure protocols?
- We show that, surprisingly, every trusted setup is either useless (equivalent to having no trusted setup) or all-powerful (allows UC-secure protocols for all tasks).
- There are no “intermediate” trusted setups in the UC framework.
