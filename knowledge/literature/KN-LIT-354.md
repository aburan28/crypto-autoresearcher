## Contribution
Let H(N ) denote the Hurwitz class number. It is known that if p is a prime, then X H(4p − r 2 ) = 2p. √ |r|<2 p In this paper, we investigate the behavior of this sum with the additional condition r ≡ c (mod m).

## Key claims (as reported)
- Three different methods will be explored for determining the values of such sums.
- First, we will count isomorphism classes of elliptic curves over finite fields.
- Second, we will express the sums as coefficients of modular forms.
- Third, we will manipulate the Eichler-Selberg trace formula for Hecke operators to obtain Hurwitz class number relations.
