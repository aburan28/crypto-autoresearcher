## Reported result

For McEliece-like systems built from generalized Reed–Solomon secret codes and a masking matrix with row and column weight two, the authors give high-rate public-code distinguishers and a framework turning a sufficiently strong distinguisher into key recovery. The weight-two case is attacked using a cube-code distinguisher.

## Scope and evidence boundary

The secret code is GRS, not the binary Goppa secret code in Classic McEliece. The abstract does not give a universal concrete work factor or state that Classic McEliece is broken.

## Research follow-up

Reproduce the high-rate, weight-two regime and keep the structural distinguisher and actual key-recovery experiments separate.
