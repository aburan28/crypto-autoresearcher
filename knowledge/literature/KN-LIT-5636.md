## Contribution
A definition of online authenticated-encryption (OAE), call it OAE1, was given by Fleischmann, Forler, and Lucks (2012). It has become a popular definitional target because, despite allowing encryption to be online, security is supposed to be maintained even if nonces get reused.

## Key claims (as reported)
- We argue that this expectation is effectively wrong.
- OAE1 security has also been claimed to capture best-possible security for any online-AE scheme.
- We claim that this understanding is wrong, too.
- So motivated, we redefine OAE-security, providing a radically different formulation, OAE2.
