## Contribution

Prime-field ECDLP record on a 114-bit BN curve (j=0) using parallel rho with the sextic-twist/order-6 automorphism in the random walk and a client-server distinguished-point setup. Follow-ups by the same group: Miura et al., fruitless-cycle analysis for BN curves, ITC-CSCC 2019, doi:10.1109/ITC-CSCC.2019.8793449.

## Key claims (as reported)

- 114-bit prime-field ECDLP solved with ~2000 CPU cores in about 6 months (previous prime-field record: 112-bit secp112r1).

## Relevance to this program

114-bit BN-curve ECDLP via rho with the order-6 automorphism (~2000 cores, ~6 months): the largest random-instance prime-field ECDLP record found. Baseline for any prime-field record claim.
