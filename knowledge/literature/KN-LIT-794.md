## Contribution
The Mordell-Weil groups E(Q) of elliptic curves influence the structures of their quadratic twists E−D (Q) and the ideal class groups CL(−D) of imaginary quadratic fields. For appropriate (u, v) ∈ Z2 , we define a family of homomorphisms Φu,v : E(Q) → CL(−D) for particular negative fundamental discriminants −D := −DE (u, v), which we use to simultaneously address questions related to lower bounds for class numbers, the structures of class groups, and ranks of quadratic twists.

## Key claims (as reported)
- Specifically, given an elliptic curve E of rank r, let ΨE be the set of suitable fundamental discriminants −D < 0 satisfying the following three conditions: the quadratic twist E−D has rank at least 1; Etor (Q) is a subgroup of CL(−D); and h(−D) satisfies r an effective lower bound which grows asymptotically like c(E) log(D) 2 as D → ∞.
- Then for any ε > 0, we show that as X → ∞, we have 1 # {−X < −D < 0 : −D ∈ ΨE } ≫ε X 2 −ε .
- In particular, if l ∈ {3, 5, 7} and l | |Etor (Q)|, then the number of such discriminants −D for 1 which l | h(−D) is ≫ε X 2 −ε .
- Moreover, assuming the Parity Conjecture, our results hold with the additional condition that the quadratic twist E−D has rank at least 2.
