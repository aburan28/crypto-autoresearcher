## Contribution
Structured encryption (STE) schemes encrypt data structures in such a way that they can be privately queried. Special cases of STE include searchable symmetric encryption (SSE) and graph encryption.

## Key claims (as reported)
- Like all sub-linear encrypted search solutions, STE leaks information about queries against persistent adversaries.
- To address this, a line of work on leakage suppression was recently initiated that focuses on techniques to mitigate the leakage of STE schemes.
- A notable example is the query equality suppression framework (Kamara et al.
- CRYPTO’18 ) which transforms dynamic STE schemes that leak the query equality into new schemes that do not.
