## Contribution
We introduce the notion of Linear Integer Secret-Sharing (LISS) schemes, and show constructions of such schemes for any access structure. We show that any LISS scheme can be used to build a secure distributed protocol for exponentiation in any group.

## Key claims (as reported)
- This implies, for instance, distributed RSA protocols for arbitrary access structures and with arbitrary public exponents.
