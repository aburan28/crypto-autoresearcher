## Contribution
We present a universal framework for tamper and leakage resilient computation on a random access machine (RAM). The RAM has one CPU that accesses a storage, which we call the disk.

## Key claims (as reported)
- The disk is subject to leakage and tampering.
- So is the bus connecting the CPU to the disk.
- We assume that the CPU is leakage and tamper-free.
- For a xed value of the security parameter, the CPU has constant size.
