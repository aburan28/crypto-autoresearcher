## Contribution
Let l be a prime number and let F be a number field and E/F a non-CM elliptic curve with a point α ∈ E(F ) of infinite order. Attached to the pair (E, α) is the l-adic arboreal Galois representation ωE,α,l∞ : Gal(F /F ) → Z2l ⋊ GL2 (Zl ) describing the action of Gal(F /F ) on points βn so that ln βn = α.

## Key claims (as reported)
- We give an explicit bound on the index of the image of ωE,α,l∞ depending on how l-divisible the point α is, and the image of the ordinary l-adic Galois representation.
- The image of ωE,α,l∞ is connected with the density of primes p for which α ∈ E(Fp ) has order coprime to l.

## Relevance to this program
Relevant to pairing-based reductions and endomorphism speedups (MOV/Frey-Rück special cases, GLV/GLS) that bound which curve classes are safe baselines.
