## Contribution
Algebraic attack has recently become an important tool in cryptanalysing different stream and block cipher systems. A Boolean function, when used in some cryptosystem, should be designed properly to resist this kind of attack.

## Key claims (as reported)
- The cryptographic property of a Boolean function, that resists algebraic attack, is known as Algebraic Immunity (AI).
- So far, the attempt in designing Boolean functions with required algebraic immunity was only ad-hoc, i.e., the functions were designed keeping in mind the other cryptographic criteria, and then it has been checked whether it can provide good algebraic immunity too.
- For the first time, in this paper, we present a construction method to generate Boolean functions on n variables with highest possible algebraic immunity d n2 e.
- Such a function can be used in conjunction with (using direct sum) functions having other cryptographic properties.
