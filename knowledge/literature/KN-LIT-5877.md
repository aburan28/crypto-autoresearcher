## Contribution
In predicate encryption for a function f , an authority can create ciphertexts and secret keys which are associated with ‘attributes’. A user with decryption key Ky corresponding to attribute y can decrypt a ciphertext CTx corresponding to a message m and attribute x if and only if f (x, y) = 0.

## Key claims (as reported)
- Furthermore, the attribute x remains hidden to the user if f (x, y) 6= 0.
- We construct predicate encryption from assumptions on bilinear maps for a large class of new functions, including sparse set disjointness, Hamming distance at most k, inner product mod 2, and any function with an efficient Arthur-Merlin communication protocol.
- Our construction uses a new probabilistic representation of Boolean functions we call ‘one-sided probabilistic rank,’ and combines it with known constructions of inner product encryption in a novel way.
