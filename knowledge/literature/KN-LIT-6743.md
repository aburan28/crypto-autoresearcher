## Contribution
We address the problem of polynomial time solving univariate modular equations with mutually co-prime moduli. For a given system of equations we determine up to which size the common roots can be calculated efficiently.

## Key claims (as reported)
- We further determine the minimum number of equations which suffice for a recovery of all common roots.
- The result that we obtain is superior to Håstad’s original RSA broadcast attack, even if Håstad’s method is combined with the best known lattice technique due to Coppersmith.
- Namely, our reduction uses a slightly different transformation from polynomial systems to a single polynomial.
- Thus, our improvement is achieved by optimal polynomial modelling rather than improved lattice techniques.
