## Contribution
Sprout is a new lightweight stream cipher with shorter internal state proposed at FSE 2015, using key-dependent state updating in the keystream generation phase. Some analyses have been available on eprint so far.

## Key claims (as reported)
- In this paper, we extend the design paradigm in general and study the security of Sprout-like ciphers in a unified framework.
- Our new penetration is to investigate the k-normality of the augmented function, a vectorial Boolean function derived from the primitive.
- Based on it, a dedicated time/memory/data tradeoff attack is developed for such 79−x−y designs.
- It is shown that Sprout time, giv can be broken in 2  en c · (2x + 2y − 58) · 271−x−y -bit memory and 29+x+y -bit keystream, where x/y is the the number of forward/backward steps and c is a small constant.
