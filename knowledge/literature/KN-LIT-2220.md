## Contribution
We present a new class of signature schemes based on properties of certain bilinear algebraic maps. These signatures are secure against existential forgery under a chosen message attack in the standard model (without using the random oracle model).

## Key claims (as reported)
- Security is based on the computational Diffie-Hellman problem.
- The concrete schemes that we get are the most efficient provable discrete-log type signature schemes to date.

## Relevance to this program
Relevant to pairing-based reductions and endomorphism speedups (MOV/Frey-Rück special cases, GLV/GLS) that bound which curve classes are safe baselines.
