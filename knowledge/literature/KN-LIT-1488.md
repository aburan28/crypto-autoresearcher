## Contribution
For each n ≥ 1, we express the partition function p(n) as a CM trace on X0 (6) of the discriminant ∆n := 1 − 24n invariants of a weight 0 weak Maass function P that records where CM elliptic curves sit on X(1), together with their canonical first-order “CM tangent”, the diagonal local slope of the CM isogeny relation√on X(1) × X(1). In this viewpoint, we obtain a formula for p(n) (mod l), when l is inert in Q( ∆n ), as a Brandt-module pairing ⟨u∆n , vP ⟩ that is assembled from oriented optimal embeddings of Eichler orders.

## Key claims (as reported)
- For l ∈ {5, 7, 11} and j ≥ 1, we obtain a new proof of the Ramanujan congruences  p 5 j n + β5 (j) ≡ 0 (mod 5 j ),  p 7 j n + β7 (j) ≡ 0 (mod 7 ⌊j/2⌋+1 ),  p 11 j n + β11 (j) ≡ 0 (mod 11 j ), where βm (j) is the unique residue 0 ≤ βm (j) < mj with 24 βm (j) ≡ 1 (mod mj ).
- The key point is a bonus valuation that stems from the fact that the supersingular locus of X0 (6)Fl lies over {0, 1728} for l ∈ {5, 7, 11}.
- This special property, combined with the uniform growth of the λ-adic valuations of the number of oriented optimal embeddings, explains these congruences.
- More generally, we give a portable genus 0 template showing that the Watson–Atkin Ul -contraction works uniformly for suitable traces of singular moduli for genus 0 modular curves with l ∤ N .
