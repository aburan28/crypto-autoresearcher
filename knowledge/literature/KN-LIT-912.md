## Contribution
Hash functions map data of arbitrary length to data of predetermined length. Good hash functions are hard to predict, making them useful in cryptography.

## Key claims (as reported)
- We are interested in the elliptic curve CGL hash function, which maps a bitstring to an elliptic curve by traversing an inputdetermined path through an isogeny graph.
- The nodes of an isogeny graph are elliptic curves, and the edges are special maps betwixt elliptic curves called isogenies.
- Knowing which hash values are most likely informs us of potential security weaknesses in the hash function.
- We use stochastic matrices to compute the expected probability distributions of the hash values.
