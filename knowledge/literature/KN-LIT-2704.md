## Contribution
We work towards completely classifying all bielliptic Shimura curves X0D (N ) with nontrivial level N coprime to D, extending a result of Rotger that provided such a classification for level one. Combined with prior work, this allows us to determine the list of all relatively prime pairs (D, N ) for which X0D (N ) has infinitely many degree 2 points.

## Key claims (as reported)
- As an application, we use these results to make progress on determining which curves X0D (N ) have sporadic points.
- Using tools similar to those that appear in this study, we also provide a proof that there are no geometrically trigonal Shimura curves X0D (N ) with gcd(D, N ) = 1.
