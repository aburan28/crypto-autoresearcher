This paper presents the theoretical blueprint of a new secure token called the Externalized Microprocessor (XμP).

## Key claims (as reported)
- Unlike a smartcard, the XμP contains no ROM at all.
- While exporting all the device’s executable code to potentially untrustworthy terminals poses formidable security problems, the advantages of ROM-less secure tokens are numerous: chip masking time disappears, bug patching becomes a mere terminal update and hence does not imply any roll-out of cards in the field.
- Most importantly, code size ceases to be a limiting factor.
- This is particularly significant given the steady increase in on-board software complexity.
