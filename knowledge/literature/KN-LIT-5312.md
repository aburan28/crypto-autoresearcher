## Contribution
We study verifiable outsourcing of computation in a model where the verifier has black-box access to the function being computed. We introduce the problem of oracle-aided batch verification of computation (OBVC) for a function class F.

## Key claims (as reported)
- This allows a verifier to efficiently verify the correctness of any f ∈ F evaluated on a batch of n instances x1 , . . . , xn , while only making λ calls to an oracle for f (along with O(nλ) calls to low-complexity helper oracles), for security parameter λ.
- We obtain the following positive and negative results: – We build OBVC protocols for the class of all functions that admit random-self-reductions.
- Some of our protocols rely on homomorphic encryption schemes. – We show that there cannot exist OBVC schemes for the class of all functions mapping λ-bit inputs to λ-bit outputs, for any n = poly(λ).4
