## Key claims (as reported)
- The classical duplication formulas is an example of change of level algorithm to go from level n to level 2n.
- The main result of this paper states that there exists an algorithm to go from level n to level `n in O(ng `2g log(`)) operations in k.
- We deduce an algorithm to compute an isogeny f : A → B from the knowledge of (A, L , Θn ) and K ⊂ A[`] isotropic for the Weil pairing which computes f (x) for x ∈ A(k) in O((n`)g log(`)) operations in k.
