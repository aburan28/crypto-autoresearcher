## Contribution
We assume a scenario where an attacker can mount several independent attacks on a single CPU. Each attack can be run several times in independent ways.

## Key claims (as reported)
- Each attack can succeed after a given number of steps with some given and known probability.
- A natural question is to wonder what is the optimal strategy to run steps of the attacks in a sequence.
- In this paper, we develop a formalism to tackle this problem.
- When the number of attacks is infinite, we show that there is a magic number of steps m such that the optimal strategy is to run an attack for m steps and to try again with another attack until one succeeds.
