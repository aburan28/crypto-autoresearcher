## Contribution
Refines Honda–Tate from isogeny classes to endomorphism rings and
isomorphism types of abelian varieties over finite fields. Uses Tate’s
Hom–Tate-module isomorphism to describe which orders arise as End(A) and
which principally polarized isomorphism classes exist inside a given
isogeny class.

## Key claims (as reported)
- Building on Tate–Honda–Serre, classifies precise endomorphism rings and
  isomorphism types over finite fields (author’s own abstract on the NUMDAM
  record).
- Treats ordinary varieties specially; discusses polarizations / principal
  polarizations inside isogeny classes.
- References Deuring’s elliptic case and Tate/Honda as prerequisites; this
  paper is the standard “Waterhouse” citation in the elliptic-curve CM /
  endomorphism-ring literature.

## Relevance to this program
The reference behind “which orders occur as End(E/F_q)” for ordinary and
supersingular elliptic curves — the finite-field companion to Deuring
(KN-LIT-075) and the input to endomorphism-ring algorithms (KN-TECH-028).
Proposals that invent new End-ring constraints without checking Waterhouse
are likely duplicates.
