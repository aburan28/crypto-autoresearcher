## Contribution
The random oracle model (ROM) is an idealized model where hash functions are modeled as random functions that are only accessible as oracles. Although the ROM has been used for proving many cryptographic schemes, it has (at least) two problems.

## Key claims (as reported)
- First, the ROM does not capture quantum adversaries.
- Second, it does not capture non-uniform adversaries that perform preprocessings.
- To deal with these problems, Boneh et al.
- (Asiacrypt’11) proposed using the quantum ROM (QROM) to argue post-quantum security, and Unruh (CRYPTO’07) proposed the ROM with auxiliary input (ROM-AI) to argue security against preprocessing attacks.
