## Contribution
A k-collision for a compressing hash function H is a set of k distinct inputs that all map  to the same output. In this work, we show  1 (1− that for any constant k, Θ N 2 1 ) 2k −1 quantum queries are both necessary and sufficient to achieve a k-collision with constant probability.
