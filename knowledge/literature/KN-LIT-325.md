## Contribution
Given an elliptic curve E over a finite field Fq of q elements, we say that an odd prime l ∤ q is an Elkies prime for E if t2E − 4q is a square modulo l, where tE = q + 1 − #E(Fq ) and #E(Fq ) is the number of Fq -rational points on E; otherwise l is called an Atkin prime. We show that there are asymptotically the same number of Atkin and Elkies primes l < L on average over all curves E over Fq , provided that L ≥ (log q)ε for any fixed ε > 0 and a sufficiently large q.

## Key claims (as reported)
- We use this result to design and analyse a fast algorithm to generate random elliptic curves with #E(Fp ) prime, where p varies uniformly over primes in a given interval [x, 2x].
