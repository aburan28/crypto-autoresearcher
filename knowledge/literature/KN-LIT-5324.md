## Contribution
We propose a new decoding algorithm for random binary linear codes. The so-called information set decoding algorithm of Prange (1962) achieves worst-case complexity 20.121n .

## Key claims (as reported)
- In the late 80s, Stern proposed a sort-and-match version for Prange’s algorithm, on which all variants of the currently best known decoding algorithms are build.
- The fastest algorithm of Becker, Joux, May and Meurer (2012) achieves running time 20.102n in the full distance decoding setting and 20.0494n with half (bounded) distance decoding.
- In this work we point out that the sort-and-match routine in Stern’s algorithm is carried out in a non-optimal way, since the matching is done in a two step manner to realize an approximate matching up to a small number of error coordinates.
- Our observation is that such an approximate matching can be done by a variant of the so-called High Dimensional Nearest Neighbor Problem.
