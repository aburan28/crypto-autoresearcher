## Contribution
In symmetric secure function evaluation (SSFE), Alice has an input x, Bob has an input y, and both parties wish to securely compute f (x, y). We show several new results classifying the feasibility of securely implementing these functions in several security settings.

## Key claims (as reported)
- Namely, we give new alternate characterizations of the functions that have (statistically) secure protocols against passive and active (standalone), computationally unbounded adversaries.
- We also show a strict, infinite hierarchy of complexity for SSFE functions with respect to universally composable security against unbounded adversaries.
- That is, there exists a sequence of functions f1 , f2 , . . . such that there exists a UC-secure protocol for fi in the fj -hybrid world if and only if i ≤ j.
- The main new technical tool that unifies our unrealizability results is a powerful protocol simulation theorem, which may be of independent interest.
