## Contribution
At CHES 2010, the new block cipher PRINTcipher was presented. In addition to using an xor round key as is common practice for round-based block ciphers, PRINTcipher also uses key-dependent permutations.

## Key claims (as reported)
- While this seems to make differential cryptanalysis difficult due to the unknown bit permutations, we show in this paper that this is not the case.
- We present two differential attacks that successfully break about half of the rounds of PRINTcipher, thereby giving the first cryptanalytic result on the cipher.
- In addition, one of the attacks is of independent interest, since it uses a mechanism to compute roots of permutations.
- If an attacker knows the many-round permutation π r , the algorithm can be used to compute the underlying single-round permutation π.
