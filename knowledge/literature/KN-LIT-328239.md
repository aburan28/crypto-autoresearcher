## Contribution
A cube-and-conquer (CDCL + lookahead) SAT approach to INVERTING step-reduced
versions of MD4 and MD5 — i.e., finding a message given a hash — as opposed to
the collision attacks that already break both functions. This is the
"cube-and-conquer SAT approach to inverting hash functions (arXiv 2212.02405)"
named in RQ-MDFIVE-6870c1's provenance block.

## Key claims (as reported, from the arXiv abstract read 2026-08-20)
- MD4 and MD5 are vulnerable to practical collision attacks, yet inverting them
  (finding a message given a hash) is still not realistic.
- Prior work: the 39-step MD4 was inverted in 2007 via SAT + CDCL with
  Dobbertin's constraints; the 28-step MD5 was inverted in 2012 via a CDCL
  solver for one specified hash.
- This work applies Cube-and-Conquer to invert step-reduced MD4 and MD5 using
  two proposed algorithms (one generating inverse problems for MD4 by
  modifying Dobbertin's constraints; one searching cubing cutoff thresholds to
  minimize the estimated conquer-phase runtime).
- Reported results: 40-, 41-, 42-, and 43-step MD4 inverted for the first time;
  28-step MD5 inverted for four hashes (for three of them, for the first time).

## Relevance to this program
This is the SAT/inversion line of MD5 preimage work, distinct from the
meet-in-the-middle / splice-and-cut line (KN-LIT-582d77). It is relevant to
GOAL-MD5-001's method-ceiling audit because it bounds what the SAT-based
inversion method reaches on step-reduced MD5, and it is a candidate
characterization of the obstruction that holds the full-MD5 preimage frontier.
