## Contribution
We describe a new explicit function that given an elliptic curve E defined over Fpn , maps elements of Fpn into E in deterministic polynomial time and in a constant number of operations over Fpn . The function requires to compute a cube root.

## Key claims (as reported)
- As an application we show how to hash deterministically into an elliptic curve.
