## Contribution
Symbolic analysis of cryptographic protocols is dramatically simpler than full-fledged cryptographic analysis. In particular, it is simple enough to be automated.

## Key claims (as reported)
- However, symbolic analysis does not, by itself, provide any cryptographic soundness guarantees.
- Following recent work on cryptographically sound symbolic analysis, we demonstrate how Dolev-Yao style symbolic analysis can be used to assert the security of cryptographic protocols within the universally composable (UC) security framework.
- Consequently, our methods enable security analysis that is completely symbolic, and at the same time cryptographically sound with strong composability properties.
- More specifically, we concentrate on mutual authentication and keyexchange protocols.
