## Contribution

Extends the rigorous subexponentiality range by using higher-dimensional F_q-subspaces V of F_{q^n} as factor base (and disjoint factor bases). It sheds no light on prime-degree binary fields F_{2^n}.

## Key claims (as reported)

- Rigorous subexponential range extended to n up to about log q (per Galbraith-Gaudry survey).

## Relevance to this program

Rigorous subexponential ECDLP for E(F_{q^n}) with n up to about log q (sequel to Diem 2011, KN-LIT-003). Any 'IC is subexponential on some extension-field family' proposal is inside Diem's results; the open part is prime q^1 and prime-degree binary fields.
