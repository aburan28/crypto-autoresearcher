## Contribution
The CBC-MAC or cipher block chaining message authentication code, is a well-known method to generate message authentication codes. Unfortunately, it is not forgery-secure over an arbitrary domain.

## Key claims (as reported)
- There are several secure variants of CBC-MAC, among which OMAC is a widely-used candidate.
- To authenticate an s-block message, OMAC costs (s + 1) block cipher encryptions (one of these is a zero block encryption), and only one block cipher key is used.
- In this paper, we propose two secure and efficient variants of CBC-MAC: namely, GCBC1 and GCBC2.
- Our constructions cost only s block cipher encryptions to authenticate an s-block message, for all s ≥ 2.
