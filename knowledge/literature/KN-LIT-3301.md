## Contribution
We develop new tools to study the relative complexities of secure multi-party computation tasks in the Universal Composition framework. When one task can be securely realized using another task as a black-box, we interpret this as a qualitative, complexity-theoretic reduction between the two tasks.

## Key claims (as reported)
- Virtually all previous characterizations of MPC functionalities, in the UC model or otherwise, focus exclusively on secure function evaluation.
- In comparison, the tools we develop do not rely on any special internal structure of the functionality, thus applying to functionalities with arbitrary behavior.
- Our tools additionally apply uniformly to both the PPT and unbounded computation models.
- Our first main tool is an exact characterization of realizability in the UC framework with respect to a large class of communication channel functionalities.
