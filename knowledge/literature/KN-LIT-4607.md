## Contribution
We prove in a non-black-box way that every bounded list and set commitment scheme is knowledge-binding. This is a new and rather strong security condition, which makes the security definitions for time-stamping much more natural compared to the previous definitions, which assume unpredictability of adversaries.

## Key claims (as reported)
- As a direct consequence, list and set commitment schemes with partial opening property are sufficient for secure time-stamping if the number of elements has an explicit upper bound N .
- On the other hand, white-box reductions are in a sense strictly weaker than black-box reductions.
- Therefore, we also extend and generalize √ the previously known reductions.
- The corresponding new reductions are Θ( N ) times more efficient, which is important for global-scale time-stamping schemes where N is very large.
