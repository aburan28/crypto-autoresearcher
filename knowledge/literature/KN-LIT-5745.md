## Contribution
A perfect algebraic immune function is a Boolean function with perfect immunity against algebraic and fast algebraic attacks. The main results are that for a perfect algebraic immune balanced function the number of input variables is one more than a power of two; for a perfect algebraic immune unbalanced function the number of input variables is a power of two.

## Key claims (as reported)
- Also, for n equal to a power of two, the CarletFeng functions on n + 1 variables and the modified Carlet-Feng functions on n variables are shown to be perfect algebraic immune functions.
