## Contribution
Thesis on an **algebraic approach to code equivalence** — deciding whether two
codes are equivalent under a permutation (or monomial map) of coordinates. Code
equivalence is the problem underlying McEliece key recovery: the public key is
an equivalent presentation of a secret structured code.

## Key claims (as reported)
- Algebraic methods for the code equivalence problem.

## Relevance to this program
Code equivalence is the **right abstraction of the McEliece key-recovery
problem**, and separating it from syndrome decoding is what lets each be studied
properly. Sendrier's support-splitting algorithm ([[KN-LIT-0f43ad]]) is the
classical solution for the unstructured case.

The general lesson this program takes: **name the underlying problem, then
attack the problem rather than the scheme.** A proposal here that describes
itself only in terms of a protocol has usually not yet identified what it is
actually claiming to solve.
