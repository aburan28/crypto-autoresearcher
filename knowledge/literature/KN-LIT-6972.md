## Contribution
This paper studies the concrete security of PRFs and MACs obtained by keying hash functions based on the sponge paradigm. One such hash function is KECCAK, selected as NIST’s new SHA-3 standard.

## Key claims (as reported)
- In contrast to other approaches like HMAC, the exact security of keyed sponges is not well understood.
- Indeed, recent security analyses delivered concrete security bounds which are far from existing attacks.
- This paper aims to close this gap.
- We prove (nearly) exact bounds on the concrete PRF security of keyed sponges using a random permutation.

## Relevance to this program
Relevant to pairing-based reductions and endomorphism speedups (MOV/Frey-Rück special cases, GLV/GLS) that bound which curve classes are safe baselines.
