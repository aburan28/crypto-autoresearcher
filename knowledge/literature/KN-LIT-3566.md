## Contribution
In this paper the benefits of implementation of the Tate pairing computation on dedicated hardware are discussed. The main observation lies in the fact that arithmetic architectures in the extension field GF (36m ) are good candidates for parallelization, leading to a similar calculation time in hardware as for operations over the base field GF (3m ).

## Key claims (as reported)
- Using this approach, an architecture for the hardware implementation of the Tate pairing calculation based on a modified Duursma-Lee algorithm is proposed.
