## Contribution
We provide new two-round multiparty secure computation (MPC) protocols assuming the minimal assumption that two-round oblivious transfer (OT) exists. If the assumed two-round OT protocol is secure against semi-honest adversaries (in the plain model) then so is our tworound MPC protocol.

## Key claims (as reported)
- Similarly, if the assumed two-round OT protocol is secure against malicious adversaries (in the common random/reference string model) then so is our two-round MPC protocol.
- Previously, tworound MPC protocols were only known under relatively stronger computational assumptions.
- Finally, we provide several extensions.
