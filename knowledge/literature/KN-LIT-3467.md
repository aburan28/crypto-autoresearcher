## Contribution
Double-base chains (DBCs) are widely used to speed up scalar multiplications on elliptic curves. We present three results of DBCs.

## Key claims (as reported)
- First, we display a structure of the set containing all DBCs and propose an iterative algorithm to compute the number of DBCs for a positive integer.
- This is the first polynomial time algorithm to compute the number of DBCs for positive integers.
- Secondly, we present an asymptotic lower bound on average log n Hamming weights of DBCs 8.25 for a positive integer n.
- This result answers an open question about the Hamming weights of DBCs.
