## Contribution

Proves the van Oorschot-Wiener parallel-collision-search trade-off optimal up to polylog factors for finding C collision pairs in a random function with S bits of memory. Also explains why unconditional bounds for downstream applications would require complexity-theory breakthroughs.

## Key claims (as reported)

- T^2*S = Omega~(C^2*N) for S = O~(C), matching PCS.

## Relevance to this program

Tight T²·S = Θ̃(C²·N) time–space bound for finding C collisions; parallel collision search is optimal. Bounds any 'store more DPs to go faster' proposal.
