## Contribution

Optimised multi-GPU elliptic-curve method (ECM) using state-of-the-art EC and multiprecision arithmetic. Included as a recent calibrated data point for EC point-arithmetic throughput on consumer GPUs, since rho steps use the same kernels.

## Key claims (as reported)

- RTX 2080 Ti: 214 thousand ECM stage-1 trials/s at B1 = 8,192 with 192-bit moduli; 2,781 trials/s at B1 = 50,000.

## Relevance to this program

ECM on GPUs: modern CUDA big-integer EC arithmetic; relevant engineering prior art for prime-field GPU rho kernels.
