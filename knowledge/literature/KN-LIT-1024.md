## Contribution
We show there exist polynomial bounds on torsion of elliptic curves which come from a fixed geometric isogeny class. More precisely, for an elliptic curve E0 defined over a number field F0 , for each ǫ > 0 there exist constants cǫ := cǫ (E0 , F0 ), Cǫ := Cǫ (E0 , F0 ) > 0 such that for any elliptic curve E/F geometrically isogenous to E0 , if E(F ) has a point of order N then and one also has N ≤ cǫ · [F : Q]1/2+ǫ , #E(F )[tors] ≤ Cǫ · [F : Q]1+ǫ .
