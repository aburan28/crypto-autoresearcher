## Contribution
Group Diffie-Hellman schemes for password-based key exchange are designed to provide a pool of players communicating over a public network, and sharing just a human-memorable password, with a session key (e.g, the key is used for multicast data integrity and confidentiality). The fundamental security goal to achieve in this scenario is security against dictionary attacks.

## Key claims (as reported)
- While solutions have been proposed to solve this problem no formal treatment has ever been suggested.
- In this paper, we define a security model and then present a protocol with its security proof in both the random oracle model and the ideal-cipher model.
