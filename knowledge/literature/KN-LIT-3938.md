## Contribution
We construct the first four-round non-malleable commitment scheme based solely on the black-box use of one-to-one one-way functions. Prior to our work, all non-malleable commitment schemes based on blackbox use of polynomial-time cryptographic primitives require more than 16 rounds of interaction.

## Key claims (as reported)
- A key tool for our construction is a proof system that satisfies a new definition of security that we call non-malleable zero-knowledge with respect to commitments.
- In a nutshell, such a proof system can be safely run in parallel with any (potentially interactive) commitment scheme.
- We provide an instantiation of this tool using the MPC-in-the-Head approach in combination with BMR.
