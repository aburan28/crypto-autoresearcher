## Contribution
We present a structural attack against the Sidelnikov cryptosystem [8]. The attack creates a private key from a given public key.

## Key claims (as reported)
- Its running time is subexponential and is effective if the parameters of the Reed-Muller code allow for efficient sampling of minimum weight codewords.
- For example, the length 2048, 3rd-order Reed-Muller code as proposed in [8] takes roughly an hour to break on a stock PC using the presented method.
