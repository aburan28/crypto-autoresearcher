## Contribution
We put forward new techniques for designing signature schemes. As a result, we present practical signature schemes based on the CDH, the RSA, and the SIS assumptions.

## Key claims (as reported)
- Our schemes compare favorably with existing schemes based on these assumptions.
- Our core idea is the use of tag-based signatures.
- Concretely, each signatures contains a tag which is uniformly chosen from a suitable tag set.
- Intuitively, the tag provides a way to embed instances of computational problems.

## Relevance to this program
Relevant to pairing-based reductions and endomorphism speedups (MOV/Frey-Rück special cases, GLV/GLS) that bound which curve classes are safe baselines.
