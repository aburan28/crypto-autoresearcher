## Contribution
KEA is a Diffie-Hellman based key-exchange protocol developed by NSA which provides mutual authentication for the parties. It became publicly available in 1998 and since then it was neither attacked nor proved to be secure.

## Key claims (as reported)
- We analyze the security of KEA and find that the original protocol is susceptible to a class of attacks.
- On the positive side, we present a simple modification of the protocol which makes KEA secure.
- We prove that the modified protocol, called KEA+, satisfies the strongest security requirements for authenticated key-exchange and that it retains some security even if a secret key of a party is leaked.
- Our security proof is in the random oracle model and uses the Gap Diffie-Hellman assumption.
