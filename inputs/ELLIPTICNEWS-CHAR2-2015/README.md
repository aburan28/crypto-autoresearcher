# ELLIPTICNEWS-CHAR2-2015

Retrieval receipt for Steven Galbraith's ellipticnews post of 2015-04-13,
"Elliptic curve discrete logarithm problem in characteristic two", and its
comment thread (Semaev 2015-04-20, Kosters 2015-05-02, Gaudry 2015-05-05).
Knowledge entry: `knowledge/literature/KN-LIT-e77232.md`.

`provenance.json` records the URL, HTTP status, byte count and sha256 of the
page as fetched on 2026-09-05. The page bytes are **not** vendored here: the
text is a third-party blog post with no stated license, so this package is a
receipt that a read happened and what was read, in the sense of
`tools/build_source_index.py` section 2, not a frozen copy. Re-fetch the URL
to re-read; a different sha256 means the page changed after this read.
