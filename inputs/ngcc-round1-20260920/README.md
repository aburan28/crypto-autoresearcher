# NGCC Round 1 target roster

Official first-round candidate list for the Chinese Institute of Commercial
Cryptography Standards (ICCS) Next-generation Commercial Cryptographic
Algorithms (NGCC) program, published 2026-09-20.

Retrieved 2026-09-30 from the public harness
`https://github.com/ngcc-dev/ngcc-harness` (`main` blobs named in
`candidates.yaml`). The five CSVs under `source/` are unmodified copies.
`candidates.yaml` is their join: 34 signatures, 41 KEMs, 9 key-exchange
protocols, and 35 hash functions, 119 rows.

This directory names attack targets. It does not record a vulnerability, a
security verdict, or evidence. Published findings about these candidates are
indexed separately in `paper_mentions.yaml`, which cites IACR ePrint
2026/2266 and does not reproduce any attack.

The campaign that owns this roster is `GOAL-NGCC-6c8a52` /
`RQ-NGCC-f52138`. NGCC is a non-ECC area
(`orchestration/research-priority.yaml`).
