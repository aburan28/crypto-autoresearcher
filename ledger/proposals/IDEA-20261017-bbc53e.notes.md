## 1. The coincidence-harvest cost law

Notation: N group order; U unknown-log base points; S stored sums (table size); h points per sum;
kappa = coincidence-rate excess over a matched random base (Part C's kappa_rel); c in [0.92, 1.0]
the stopping constant (relations at stop / U; README: 0.92 at m=3; 3-uniform 2-core threshold 0.818).

* Independent relations from S sums: R = kappa * S^2 / (2N), by pair counting (H1).
* Need R >= c U. Table construction costs S. Therefore S = sqrt(2 c U N / kappa) and T ~ S.
* Pollard rho: T_rho ~ sqrt(pi N / 2) group additions (units differ by a constant; the exponent
  comparison is the claim).
* Crossing rho in time: sqrt(2cUN/kappa) < sqrt(pi N/2)  <=>  kappa > 4cU/pi ~ 1.27 c U.

For the tail-table family at kappa = 1: S = B^h with U = B gives B^(2h-1) ~ N, so B = N^(1/(2h-1))
and T = N^(h/(2h-1)): 2/3, 3/5, 4/7 for h = 2, 3, 4. These are the README's measured ladder at the
odd arities m = 2h-1 (0.66, 0.60, 0.58).

## 3. The weighted-base plant

F_0: U points with unknown logs. F' = {c P : P in F_0, 1 <= |c| <= c_0}, |F'| = 2 c_0 U = B'.
Cost with lookups (engine TT model): T = B'^h + U * (m! N / B'^m) * B'^(m-h) = B'^h + m! N B'^(1-h) U/B'
= B'^h + m! N B'^(1-h) / (2 c_0).
Minimising over B': B'^(2h-1) = m! N / (2 c_0), T ~ (m! N / (2 c_0))^(h/(2h-1)).
With c_0 = N^gamma: tau = (h/(2h-1)) (1 - gamma). U = B'/(2c_0) = N^((1 - 2h gamma)/(2h-1)).
The plant is valid while U >= 4 (relations have support >= h+1 distinct indices); gamma = 1/(2h)
gives U = 1 and tau = 1/2: baby-step giant-step in one dimension, the generic floor.
At h=2: gamma 0.05 -> 0.633, 0.10 -> 0.600, 0.15 -> 0.567 (U = N^0.133 ~ 20 at N=2^32).

The plant is a log-domain generalized AP with unknown generators and a known coefficient range. It
is the textbook multi-generator BSGS/rho trade, not a new attack. Its use is as a known-answer
instrument: kappa_eff = 2 c_0 is exactly known, so the translation (ii) is tested end to end on the
engine's own counters. The unshared control (a random base of the same size B' with U = B') must
show NO saving; if it does, the saving is a size effect.

Redundancy caveat: sums such as c P_i + c' P_i = (c+c') P_i collide with single weights. The table
is therefore restricted to distinct indices. Distinct nonzero difference vectors v with
sum v_i u_i = 0 are the real relations; one v can arise from many pairs when its support is
smaller than 2h, which lowers the independent count below kappa S^2/(2N). H1's multiplicity
histogram measures this.

## 4. Relation to the per-attempt threshold of IDEA-20260808-812554

Per-attempt solver model: T = U * (m! N / B^m) * c_att. Rho parity needs c_att <= B^(m-1) / (m! sqrt(N)),
which at B = N^(1/m) is B^((m-2)/2) (m=3: B^(1/2); m=5: B^(3/2)). 812554 states the same threshold as
a solver exponent sigma and adds the linear-algebra constraint beta < 1/4. The coincidence-harvest
law above is the dual: the cost is paid in table size, and the threshold lands on kappa >= U instead of
c_att <= B^((m-2)/2). Both say the sub-rho regime needs the base to be cheaper per relation than the
birthday rate by a factor about U.
