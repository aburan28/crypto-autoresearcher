## (M) carry identity
For integers a, k with p not dividing a: (a+kp)^(p-1) = a^(p-1) (1+kp/a)^(p-1).
Mod p^2, (1+kp/a)^(p-1) = 1 + (p-1)kp/a = 1 - kp/a. So
(a+kp)^(p-1) - 1 = (a^(p-1)-1) - a^(p-2) k p, divide by p:
q(a+kp) = q(a) - k a^(p-2) = q(a) - k/a mod p.
q is additive on integers prime to p (q(xy)=q(x)+q(y)), hence q(g^d)=d q(g) for the
UNREDUCED integer power. Writing g^d = a + k_d p with a the residue gives
q(a) = d q(g) + k_d / a. Success iff p | k_d (given q(g) != 0 mod p).
k_d = 0 iff g^d < p. Beyond, k_d is a huge integer, p | k_d with probability ~1/p.
Check on the bdae69 grid: recompute k_d exactly with Python ints; no new p-adic code.
(The first-order claim does not use the Teichmuller lift at all, it is the integer lift.)

## (E) window
Rational reconstruction: x mod p has a unique a/c with |a|<=A, 0<c<=C if 2AC<p. Take
A=C=sqrt(p/2). x(dG)=a'/s'^2 with h_x = log max(|a'|, s'^2). It is reconstructed
iff max(|a'|,s'^2) < sqrt(p/2), i.e. h_x(dG) < (1/2) log p - small.
Silverman: h_x(dG) = 2 hhat(dG) + O(1) = 2 d^2 hhat(G) + O(1) in the convention hhat =
(1/2) lim h_x(nP)/n^2. Edge: 2 d^2 hhat <= (1/2) log p, d_max = sqrt(log p /(4 hhat)).
For hhat(G)~0.1, p~10^4: d_max ~ 4.8; p ~ 2^96: d_max ~ 12. Polylog.
Cannot be sharpened by choosing G: Lang-type lower bounds hhat >= c log|Delta|.

## Where the coordinator's remark is right
A section computed inside E(F_p) (naive, Hensel, Teichmuller-style) reduces at every
addition, so no carry-free regime exists. A section computed inside E(Q) delays the
reduction to the end; the carry-free regime is the height window. The F_p^* naive
section is of the second kind (integers). So 'no elliptic analogue' is true only for the
first kind.
