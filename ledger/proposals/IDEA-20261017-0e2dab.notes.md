## Reachable set in the paper's random-z experiment (V in ker Tr, t even)
S_3(x1,x2,z)=0 is, in x2, (x1+z)^2 x2^2 + x1 z x2 + (x1^2 z^2+B) = 0. Put x2=(x1 z/(x1+z)^2) w:
w^2+w = (x1+z)^2 (x1^2 z^2+B)/(x1 z)^2 = (x1+z)^2 + B(1/z+1/x1)^2.
Solvable iff Tr(x1+z)+Tr(b/z+b/x1)=0 (Tr(B y^2)=Tr(b y)), i.e. tau(x1)=tau(z) with
tau(x)=Tr(x)+Tr(b/x): x1 and z are of the same curve type (E_a if tau=Tr(a), twist if
tau=Tr(a)+1).
Parity: for V in ker Tr both factor-base points have class pi=Tr(a_curve), the sum has pi=0,
so Tr(z)=Tr(a_curve); with tau(z)=Tr(a_curve) this gives Tr(b/z)=0. Same conclusion for the twist
(a'=a+tau0, Tr(tau0)=1). So reachable z = {Tr(b/z)=0}, half of F_q, independent of A.
Mean on the reachable half = 2*mu. P=(1-e^{-2mu})/2: mu=.5 -> .3161; dense: .3935.

## Newton criterion for the window
p_j=Tr(alpha^j)=power sums of the roots of f. f=x^n+g, deg g=s: p_j=0 for 1<=j<n-s,
p_0=n mod 2. n=40 even so p_0=0; s<=20 gives p_j=0 for j<=19: window (k=20) in ker Tr. A
random irreducible f has s ~ n-O(1) and p_1=c_{n-1}: unconfined with prob 1/2 from p_1 alone.
MAGMA default f for GF(2^40) is not known to this program; it is not asserted.
