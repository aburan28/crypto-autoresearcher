## 1. The ring map psi2 and the defect identity

Z[alpha] = Z[X]/(X^d - c), p = m^d - c prime, gcd(d*c, p) = 1.

- N(alpha - m) = prod_j (alpha_j - m) = (-1)^d prod_j (m - alpha_j) = (-1)^d (m^d - c) = (-1)^d p, with alpha_j
  the d roots of X^d = c. So pi = alpha - m has norm +-p and (pi) is the degree-1 prime (p, alpha - m): the prime is
  principal. (Z[alpha] may not be the maximal order; the index divides a power of d*c, prime to p.)
- pi * pitilde = -p in Z[alpha] with pitilde = sum_{i<d} alpha^i m^(d-1-i), because (alpha-m)*sum = alpha^d - m^d
  = c - m^d = -p. pitilde mod pi = d*m^(d-1), a unit mod p.
- Z[alpha]/(pi^2) has order p^2, and p has valuation 1 in it, so it is Z/p^2 as a ring. Hence psi2 exists with
  alpha -> m~ = m + p*t, (m + p t)^d = m^d + d m^(d-1) p t = c + p(1 + d m^(d-1) t) mod p^2, so
  t0 = -1/(d m^(d-1)) mod p (also -m/(d c), since m^d = c mod p).
- d = 1 check: psi2 is integer reduction Z -> Z/p^2, t0 = -1, m~ = m - p = c. The defect is the integer carry.
- For v in Z[alpha] with v = pi*w: psi2(v) = psi2(pi) psi2(w) = (m~ - m) psi2(w) = p t0 w(m) mod p^2, so
  (psi2(v))/p mod p = t0 * w(m) mod p. This is the identity of claim (A).
- Size of w: w = -v*pitilde/p, coefficients of pitilde are <= m^(d-1), so |w_j| <= d*V*m^(d-1)/p ~ d*V/m.
  The set {w(m)} is a d-digit box of volume (2dV/m + 1)^d.

## 2. Counting for S_3 (claim A numbers)

S_3 has total degree 4 in (x1, x2, x3). With A,B in the digit box and x_i digits <= H, V <= C*H^4
(C depends on d only). |D| = H^d, so the box volume is (C H^4/m)^d = C^d |D|^4 / p. Relations in D exist
when |D|^3 > p; compactness needs |D|^4/p < p. So the window is p^(1/3) < |D| < p^(1/2).
For a uniform defect the chance of landing in the box is |D|^4/p^2.
If A or B is full size (digits ~ m), V ~ m^2 and the box is the whole fundamental domain: claim (B).

## 3. Why the chain leaves the box (claim C)

Let phi(x) = N(x)/D(x) be the x-only doubling map (rational, F_p coefficients). One step: the defect is
t0*w/D(m), a digit box divided by the known unit D(m). For two steps the first defect is multiplied by
phi'(x1), a value of a rational function at a point of F_p with no small-digit structure; so
Delta_2 = delta_2 + phi'(x1)*delta_1 has a full-size weight on a small digit vector, which spreads over F_p.
The weights are a function of the chain, and for a DLP chain the chain is the secret scalar's schedule, so
the weights are unknown to a decoder. That is why a knapsack/LLL decoder is not available: it needs known
weights J_j and small unknown w_j with density d*L*log W / log p below about 0.94 (Lagarias-Odlyzko and
CJLOSS thresholds, recalled).
