## The envelope gap (a qualification of d1494b INV-3'')
Cauchy-Schwarz: T_S - sM = <1_S - s, c - mu>, |.| <= sqrt(N s(1-s)) * sqrt(N Delta mu), so |rho_S - 1| <= sqrt(Delta (1-s)/(s mu)). That is a bound of order 1 at fixed s, not 1+o(1) and not N^(-1/2). Taking s = c N^(-2d) it permits rho - 1 up to N^d / sqrt(c mu) while Delta stays 1. d1494b's sentence "a measured bounded Delta closes the whole grammar of representation-decidable predicates at once" is therefore true for slices of density bounded below (the pre-registered 1/8 and 1/32) and not for thin slices. The thin-slice regime is where an exponent-moving lift would have to live (rho ~ N^d needs s <= N^(-d) by rho <= 1/s). The tail class S = {c >= k} has density about e^-mu mu^k/k! and lift about k/mu with Delta = 1, so no moment bound of order 2 excludes it; only a complexity restriction does.

## Occam (union) bound
Class C_S of at most 2^S predicates fixed independently of the random base. For each, T_S - sM has variance about s M Delta (1-s). Bernstein/Gaussian tail: P(rho_pi - 1 > t) <= exp(-t^2 s mu N / (2 Delta (1-s)(1 + t/3...))). Union over 2^S: with probability 1-eps, max rho_pi - 1 <= sqrt(2 (S ln2 + ln(1/eps)) (1-s) Delta / (s mu N)) up to the Bernstein correction. Numbers: N=2^20, s=1/8, mu=1.04, Delta=1: S=64 bits gives sqrt(2*64*0.693*0.875/(1.363e5)) = 0.0238; S=3.2e5 (a GNN with 1e4 weights of 32 bits) gives 1.69, vacuous. Lift N^d at s = c N^(-2d): need (N^d)^2 <= 2 S ln2 (1-s) Delta / (c N^(-2d) mu N), i.e. S >= c mu N / (2 ln2 Delta (1-s)) ~ 0.72 c mu N bits. Independent of d: the class must be as long as the count table.
