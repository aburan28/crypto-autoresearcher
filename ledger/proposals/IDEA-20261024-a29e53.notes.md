## Why the L-polynomial test is the right object

`W = Res_{K/F_q} E` has Frobenius `F_q` with `F_q^n = pi_K` acting on `V_l(W)`; the characteristic polynomial is
`(T^n - pi)(T^n - pibar) = T^(2n) - t T^n + Q`. So `L_W(T) = 1 - tT^n + Q T^(2n)`, `N_i = q^i + 1` for
`n nmid i`, `N_n = Q + 1 - n t`. A genus-`n` curve `C/F_q` with that `L` has `Jac(C)` isogenous to `W` (Tate), and
then `J(C)_K` is isogenous to `E x E^s x ... x E^(s^(n-1))`, so `C_K` admits non-constant maps to `E`, of some
degree. The GHS cover is the case with an explicit map of degree `2^(n-1)`. Existence in the class does not give a
map of small degree, and the transfer needs an explicit isogeny; that is the unmeasured quantity.

## Torelli plus Serre at n = 3

If `T^6 - tT^3 + Q` is irreducible over `Q`, `W` is simple (CM by the sextic field `Q(pi_q)`), so every
principally polarised variety in the class is indecomposable. A ppav of dimension 3 which is a Jacobian over
`F-bar_q` is the Jacobian of a curve over `F_q` or its `-1` twist (Serre, appendix to Lauter; recalled). So at
least one of the classes `t`, `-t` holds a Jacobian, and for hyperelliptic curves both do. That is the source of
the 100% pair prediction. The n = 3 case is the only one where Torelli is dominant (`dim M_3 = dim A_3 = 6`); for
`n = 4` it is a hypersurface and for `n = 5` it has codimension 3 in `A_5`, so no such argument exists.

## The density exponent

`dim M_n = 3n - 3`. Genus-`n` curves with prescribed first `n-1` coefficients of `L` equal to zero: the
coefficient `c_i` has spread `~ q^(i/2)`, so the chance is `q^(-n(n-1)/4)`. The remaining coefficient `c_n = -t`
takes about `q^(n/2)` values, one class each. Per class: `q^(3n-3 - n(n-1)/4 - n/2) = q^((-n^2+11n-12)/4)`.
Values: n = 2: 1.5, n = 3: 3, n = 5: 4.5, n = 7: 4, n = 11: -3. The zero is at `n = (11 + sqrt 73)/2 = 9.77`. Naive;
the classes of Res E have special structure (`L` is a function of `T^n`) which can correlate the coefficients.
This is why the n = 5 exponent is stated and not tested.

## Enumeration plan

- Genus 2, `q <= 11`: `y^2 = f(x)` with `f` squarefree of degree 5 or 6, about `q^6` forms; `N_1, N_2` from
  `x in F_q, F_{q^2}`.
- Genus 3 hyperelliptic: `y^2 = f(x)`, `deg f in {7, 8}`, `q^9` forms at `q <= 7` (4.0e7); characteristic 2 uses
  `y^2 + hy = f`.
- Genus 3 plane quartics: `q^15` forms; `q = 2` 32 768, `q = 3` 14 348 907 (exhaustive), `q = 4` 1.07e9
  (exhaustive in a few core-hours), `q = 5` 3.05e10 (fixed-seed sample). Filter on `N_1 = q + 1` first
  (`q^2 + q + 1` points), then `N_2` over `F_{q^2}`, then `N_3`; smoothness checked over `F_{q^k}`, `k <= 3`,
  for the survivors only.
- Equivalent forms under `PGL_3(F_q)` are counted with multiplicity; the per-class comparison uses counts of forms
  divided by `|PGL_3(F_q)|` only for the slope, otherwise presence/absence.

## What each outcome means

- Coverage of odd classes at 100% of pairs: the GHS floor 13 is a property of the (2,...,2) construction, and
  the real descent obstruction at `n = 3` is the explicit isogeny (Tian). Existence is generic there.
- Missing odd classes: either the simplicity or indecomposable-ppav premise fails for them, or the class has a
  non-Torelli obstruction; record the class and its `(t, #E(K) mod 8)`.
- Slope far from 3: the density heuristic, and with it the extrapolation to `n = 5, 7`, is unreliable.
