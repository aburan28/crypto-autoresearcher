## 1. Facts used (all from the handoff or one-line consequences)

- pi = v*w - 1 on the crater (trace t = v - 2, N(pi) = 5v^2 - v + 1 = p).
- On G = E(F_p), pi acts as 1, so v*w = 2 on G and lambda = 2 * v^{-1} mod N.
  Check: lambda^2 - lambda + 5 = (4 - 2v + 5v^2)/v^2 = N/v^2 = 0 mod N,
  using N = N(pi - 1) = N(vw - 2) = 5v^2 - 2v + 4.
- ord(lambda) = 849671142308806 = (N-1)/7, even, so the unique involution -1
  of F_N^* lies in <lambda>. In F_N^*/{+-1} (order (N-1)/2 = the number of
  x-values) lambda has order (N-1)/14, hence exactly 7 cycles of that length
  (7 * 424835571154403 = 2973848998080821 = (N-1)/2).
- The 7-class of x(tP) is t mod <lambda>, an element of the order-7 quotient
  F_N^*/<lambda>: a 7th-power residue character of log_P(T). Computing it by
  walking costs ~(N-1)/14 steps; no cheaper route is known to the author.

## 2. Cost accounting of the arc (m = 2)

Let L be the arc length and c the number of arcs (distinct x0), base size cL.
Unknowns: c. Relations needed: c + 1 (c unknown logs plus k).
Per attempt (random target a*P + b*Q): MITM costs cL lookups (for each arc
element a, form T - e*w^a P0 and look it up). Success probability per attempt
about 2 (cL)^2 / N (capped at 1).
Total ~ (c + 1) * cL * N / (2 (cL)^2) = N (c + 1) / (2 c L).
- c = 1: ~ N / L; memory L; T*M ~ N (the BSGS tradeoff curve).
- c = |V|, L = 1 (ordinary base): ~ N / 2, independent of memory: the
  known naive prime-field cost (KR-IC-5931ee).
So arcs trade the (memory-independent) N/2 for the BSGS curve. This is a
relabelling of BSGS, not an advance; rho has T = 0.886 sqrt(N) at M = O(1).

## 3. Generation vs lift

R = N5(x) / h(x)^2 with deg N5 = 5, deg h = 2 (h = kernel polynomial of w,
whose two roots are x-values of the twist's 5-torsion: Frobenius acts as -1 on
E[w] because pi = vw - 1 = -1 mod w). One evaluation: ~5 + 2 + 2 mults plus
one inversion (batchable): ~12 mults. A lift_x costs a square-root
exponentiation (~1.5 log2 p ~ 80 mults) and succeeds with probability 1/2.
x-only arcs lose the y-coordinate; the point-level arc needs the y-map of w
(y * rational function), same order of cost.

## 4. Why nothing exponent-moving survives

Any decomposition test is a sparse-representation problem in F_N:
t = c * sum e_j lambda^{a_j}. Lattice approaches need t, i.e. need k; they
apply in the log domain (GLV-style) and not to points. Point-level search has
only the MITM exponent. The scalar-multiplicity phenomenon is independent of
CM: the fake-endomorphism control ([c] for a random unit c) must give the same
rank 1, as in 5dfe4a.

## 5. What would change the verdict

(i) A rank above 1 at prime N. (ii) An arc search below 0.5 sqrt(N) ops.
(iii) A cheap invariant of x predicting the 7-class (an efficiently computable
character of log k would be a partial-information leak). All three are
falsification conditions of the record.
