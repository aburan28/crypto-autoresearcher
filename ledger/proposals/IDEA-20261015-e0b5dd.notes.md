# Notes for IDEA-20261015-e0b5dd (floor bases through the v-isogeny)

Derivations; nothing measured.

## 1. Why every kernel is rational and every neighbour is a floor

pi + 1 = vw on the crater, so pi = -1 modulo v End: Frobenius acts as the
scalar -1 on E[v] = (Z/v)^2. Every subgroup C of E[v] (v + 1 of them) is
Galois-stable, hence the quotient isogeny phi_C: E -> E/C is defined over F_p.
The crater has class number h(-19) = 1, so it is the unique top vertex of the
v-volcano and all v + 1 neighbours lie one level down; their Frobenius order
Z[pi] = Z + v Z[w] has conductor v in O_K (given). The floor has about
v - (-19/v) vertices; v + 1 edges land on it.

## 2. Structure on the twist half

E'(F_p): order p + 1 + t = 5v^2; pi' = -pi = 1 - vw, so pi' - 1 = -vw is
divisible by v in End and E'[v] is contained in E'(F_p) = Z/v x Z/5v.
The twist phi' of phi has the same x-map phi_x and kernel C' (the twist of C)
inside E'[v] = E'(F_p)[v], of order v and F_p-rational. Therefore
phi': E'(F_p) -> E'_f(F_p) has image of order 5v^2 / v = 5v (odd, so no
2-torsion and (5v - 1)/2 nonzero x-values). Hence phi_x maps the twist-type
half of F_p (all x with f(x) a non-residue; no x has f(x) = 0 because there
is no 2-torsion) v-to-1 onto (5v - 1)/2 values:
(5 * 34489703 - 1)/2 = 86,224,257, while the E-type half (N - 1)/2 values
maps bijectively onto the E_f-type values.
Side remark (unused): the floor's twist has End = Z[pi'] and cyclic group of
order 5v^2, DLP-easy by Pohlig-Hellman on the prime power v^2; neither twist
is the ECDLP group.

## 3. Push and membership costs

Evaluating phi_x at one point: Velu O(v) ~ 3.4e7 field operations, or
sqrt-Velu O(sqrt v) ~ 5.9e3 (times a constant). A base of B = (6N)^{1/3}
~ 3.3e5 (6N = 3.57e16): ~2e9 ~ 2^31 operations, against rho ~ 0.886 sqrt(N)
~ 6.8e7 ~ 2^26. Membership of a floor point Y in phi(S) without storing phi(S):
phi-hat(Y) = [v] P, so P = [v^{-1}] phi-hat(Y) (a scalar multiplication,
~log N doublings) and then test x(P) < B: cost sqrt(v) + log N per query.
Exponent: B sqrt(v) = N^{1/3} * N^{1/4} = N^{7/12} (v ~ sqrt(N/5)), above 1/2.

## 4. Overlap statistic

S = crater E-type small-x base of size B (all lift), S_f the floor analogue.
phi_x(S) is B elements of the (N-1)/2 E_f-type abscissae; S_f is B elements of
the same set. Under independence the expected intersection is
B^2 / ((N-1)/2) = 2 B^2/(N-1); with B = c sqrt(N) that is ~2 c^2 (c = 8:
~128). Over-dispersion or a ratio far from 1 would mean the pull-back of the
floor window correlates with the crater window. Permutation null: replace phi_x
by a random bijection between the two abscissa sets.

## 5. Why this is not a Weil-regime gap

The count of x in [0,B) with phi_x(x) in [0,B') differs from B B'/p by an
error that Weil-type bounds control only by deg * sqrt(p) (times logs), which
exceeds the window size p^{1/3} for every degree including 2. So equidistribution
at the factor-base scale is empirical for every isogeny degree, EV-ICI-0bdaaa's
included; the conductor edge is not special on that axis. What is special is
the exact image structure on the twist half and the rational kernel.
