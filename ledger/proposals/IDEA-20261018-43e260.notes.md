## 1. Setting
E_{a,b}: Y^2 + XY = X^3 + aX^2 + b over F = F_{2^N}, b != 0 (ordinary). Semaev S_3 (KR-IC-5a43e5, used in
IDEA-20260916-71ab94):
  S_3(x1,x2,x3) = (x1x2 + x1x3 + x2x3)^2 + x1x2x3 + b.
With x3 = r: S_3 = x1^2 x2^2 + r x1 x2 + r^2 (x1^2 + x2^2) + b. Coefficients of S_3 lie in F_2[b]; a does not occur.

## 2. Exact statements
(T) Twist. E_{a,b} and E_{a+d,b}, Tr(d)=1, are the two quadratic twists. Traces t and -t. Same S_3. The point count
    is #E = q + 1 + (-1)^{Tr a} K(sqrt b), K(c) = sum_{x != 0} (-1)^{Tr(x + c/x)} (derived: for x != 0 put y = xw,
    w^2 + w = x + a + b/x^2, two solutions iff Tr(x + a + b/x^2) = 0; x = 0 gives one point). K(sqrt b) = K(b)
    (Frobenius invariance). So the isogeny class (trace) is a level set of K(b) up to the twist sign, and the
    b-set of class t equals the b-set of class -t.
(G) Galois. sigma(x) = x^2 is an F_2-linear field automorphism. Since S_3 has F_2[b] coefficients,
    sigma(S_3(x1,x2,x3; b)) = S_3(sigma x1, sigma x2, sigma x3; sigma b). So solutions of Sigma(b; V, r) map
    bijectively to solutions of Sigma(sigma b; sigma V, sigma r), by an F_2-linear map on the bit vectors.
    This extends to the chained system when every constant (V, R_X) is mapped too. The Macaulay spaces map onto each
    other because a linear substitution is a filtered automorphism of F_2[z]/(z_i^2 + z_i): z_i^2 = z_i turns
    (sum a_j z_j)^2 into sum a_j z_j, so the field equations are preserved, and degrees do not drop (inverse is
    filtered). Hence r(d), the fall profile, first fall and last fall (spec of EXP-DREG-dd668d) are equal.
    Grevlex solving degree is not invariant (depends on the variable order).
(V) Edges. An ordinary curve in characteristic 2 has E[2](Fbar) = Z/2, so exactly one subgroup of order 2 is
    etale: the kernel of the unique separable 2-isogeny, which is the Verschiebung E -> E^(1/2), j -> j^(1/2),
    b -> b^(1/2). The inseparable degree-2 isogeny is Frobenius, b -> b^2. Both are F-rational. So every
    F-rational degree-2 Velu edge of EXP-DREG-dd668d (kernel (0, s), s^2 = a6) lands on a sigma-conjugate.

## 4. Independent-orbit count on larger fields
Level sets of K partition F* (2^N - 1 values of b). Lachaud-Wolfmann (recalled, unverified): K takes the values
= -1 mod 4 in [-2^{N/2+1}+1, 2^{N/2+1}+1], that is about 2^{N/2} values, so the mean b-set has about 2^{N/2} elements
and about 2^{N/2}/N sigma-orbits for N prime. Estimates, not enumerations:
 N = 9 : ~23 sets, ~23 b each, ~2.5 orbits (and subfield b in F_8).
 N = 11: ~45 sets, ~45 b each, ~4 orbits.
 N = 13: ~90 sets, ~90 b each, ~7 orbits.
 N = 15: ~181 sets, ~181 b each, ~12 orbits (composite N: F_8 and F_32 subfield b are special).
An F_4 or F_16 census therefore has no power; N >= 13 has ~7 independent systems per average class, still below the
8 per arm that IDEA-20260922-881df9 asks for. Exact set sizes come from one Walsh-Hadamard transform of
c(lambda) = (-1)^{Tr(1/lambda)}; no sampling is needed.

## 5. What the test must show before a class gap is believed
 a. Matched pair: max_d |r_d(b) - r_d(sigma b)| = 0 for (V, r) -> (sigma V, sigma r). Blocking.
 b. Unmatched pair (same V, r, b vs sigma b), V polynomial-basis, N in {7, 11}: expected nonzero sometimes. The size is
    the "factor-base position" confound.
 c. Order floor: grevlex solving degree over 8 random GL images of ONE system (fixed variable order after the
    substitution). Its range nu is the bar: a class gap <= nu is order noise.
 d. T11-type support-matched null run through the same pipeline, to show the floor is not elliptic-specific.

## 6. Which of the two conditions
Neither. This fixes how many independent class members exist and what range zero means. It is the precondition for
testing condition 2 (a gap growing with n) at all.
