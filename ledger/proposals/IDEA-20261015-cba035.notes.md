## 1. Family algebra (all from the handoff identities)

With v = t + 2:
- p = 5t^2 + 19t + 19 = 5v^2 - v + 1.  Check: 5(t+2)^2 - (t+2) + 1
  = 5t^2 + 20t + 20 - t - 2 + 1 = 5t^2 + 19t + 19.
- trace(pi) = t = v - 2, N = p + 1 - t = 5v^2 - 2v + 4 = 5t^2 + 18t + 20.
- 4p = t^2 + 19 v^2 (the D=-19 representation), t^2 - 4p = -19 v^2.
- pi = -1 + v w with w^2 - w + 5 = 0: trace -2 + v = t, norm 1 - v + 5v^2 = p.
- N = N(pi - 1) = N(vw - 2) = 4 - 2v + 5v^2.  Twist order p + 1 + t = 5v^2.
- v ~ sqrt(p/5) ~ 0.447 sqrt(p): maximal conductor for this trace
  (v^2 = (4p - t^2)/19 and t^2 ~ p/5 give v^2 ~ p/5).

## 2. Congruence conditions on t (necessary, cheap)

- mod 2: p = t^2 + t + 1 is odd for all t; N = t^2 mod 2, so N is odd iff t
  is odd. Hence t odd, and v = t + 2 odd.
- mod 3: p = 2t^2 + t + 1 takes the values 1, 1, 2 for t = 0, 1, 2 (never 0);
  N = 2t^2 + 2 takes 2, 1, 1 (never 0). No restriction from 3.
- mod 5: p = 4(t + 1) so t != -1; N = 3t so t != 0.
- mod 19: p = 5t^2 so t != 0 mod 19.
The Executor sieves exactly; these only make the sieve efficient.

## 3. Member counts (Bateman-Horn, to be replaced by the exact sieve)

#{t <= X : p(t), N(t) prime} ~ C * Int_2^X dt / (ln p(t) ln N(t)), where
C = prod_q (1 - w(q)/q) / (1 - 1/q)^2, w(q) = #{t mod q : p(t) N(t) = 0 mod q}.
At X = 2^15 (p ~ 2^32): X / (ln p)^2 ~ 66, so the unsieved integral is ~66
and C (order 2-6 from the local conditions) scales it. The v-prime sub-arm
divides by ln v ~ 10, i.e. tens of members up to p ~ 2^32 and single digits
per octave at 20-24 bits. This is why the record gates every cell on its
member count: the family arm is small at toy size and the null arms must be
sized to match it, not the other way around. All figures here are heuristic
orders of magnitude, not counts.

## 4. Null construction

N-A (D=-19, other conductor): sample (a, b) with a^2 + 19 b^2 = 4p', p' prime,
N' = p' + 1 - a prime, b != a + 2, same bit-size and N-range as the family
cell. Cornacchia gives (a, b) from p'. This keeps the crater endomorphism ring
and class number 1 but loses the maximal-conductor relation b = a + 2.
N-B: random prime-order curves y^2 = x^3 + ax + b over primes of the same size.

(4p = t^2 + |D| v^2, v = t + c) to see whether E3 is specific to D=-19.

## 5. Why yield cannot be the signal

KN-FIND-007: sum over targets of c_D(r) = binom(B + m - 1, m) for any base, so
the mean per-target yield is identical for every base of size B. Hence M0 is
an exact check and M1/M2 carry the information. Coverage obeys
coverage <= min(1, mean) (EV-FBG-001), so M1 deviations are bounded by ~1.58
at the frozen operating point.

## 6. qr_window positive control

For a Weierstrass x, f(x) = x^3 + ax + b is a quadratic residue exactly when x
is the abscissa of a point of E(F_p); nonresidues are abscissae of the twist.
Scanning candidates x = 0, 1, 2, ... and keeping only residues yields one
point per scanned candidate; an unfiltered window pays for every candidate
but only half lift. The predicted scan-efficiency ratio is 2, with sampling
noise ~ 1/sqrt(B). If the instrument does not return 2.0 +- 0.05 it cannot
see structure and the run is void.
