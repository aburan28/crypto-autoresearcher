## Why the held-out axis is new
79ff48 and EXP-RELN-82f487 hold out TARGETS inside one fixed base per arm. For a random base the counts of distinct targets are uncorrelated (Cov = -M/N^2), so a model can only gain through D itself (its lookup capacity); for a structured base it can also learn D-specific geometry. Neither is "structure of the curve". A predicate that works on a FRESH base from the same family, given only public descriptors (x(R), window offset a), is base-universal. lift(held-out target, same base) - lift(held-out base) = the D-specific (advice) part, in the sense of the Corrigan-Gibbs-Kogan preprocessing bound recalled in 94676a.

## Pooled power
One base, density s, N targets, mean mu, dispersion Delta: SD(rho) = sqrt((1-s) Delta / (s mu N)). N=2^20, s=1/8, mu=1.04, Delta=1: sqrt(0.875/(0.125*1.04*1.0486e6)) = 2.5e-3. Pooling K' independent bases divides by sqrt(K'): K'=16 held-out windows gives 6.3e-4, K'=32 gives 4.5e-4. Three curves multiply K' again. This is replication averaging; what is new is that the quantity averaged is base-universal.

## Interaction table and routing
Row sums fixed: sum_u T[u,k] = M for each k. Under H0 T[u,k] ~ Gaussian(s_u M, s_u M Delta_k). Test statistic chi2_int = sum (T - row_k * col_u / total)^2 / (expected variance), (U-1)(K-1) dof, divide by dof to compare with 1 +- 3 sqrt(2/dof). A routing rule is a function g: u -> k; the routed yield is sum_u T[u, g(u)]; the interaction test bounds it simultaneously for all K^U rules (the max over rules of the routed excess is at most the sum over u of the positive row residuals, each Gaussian). Yield-only: solve cost per window not measured.

## Exponent accounting (m=3, MITM s = Theta(B))
Window routing: per-attempt cost c*B, yield mu_B (1+eta). Fixed union base L = K B: cost c*L = cKB, yield mu_L = C(L+2,3)/N ~ K^3 mu_B. Cost per relation: routing cB/(mu_B(1+eta)); union cB/(K^2 mu_B). Routing wins iff 1+eta > K^2. Conservation on the union: sum_R c_{route(R)}(R) <= sum_R c_union(R) = K^3 M_B, so 1+eta <= K^3. K = 32 gives threshold 1024. Linear algebra: routing has U = KB unknowns, same as the union, so no gain there. Memory: one pair table B^2/2 per window, K B^2/2 if all resident, versus (KB)^2/2 for the union.

## Z/N positive control
Z/N, window [a, a+w): sumset of 3 elements is [3a+3, 3a+3w], c_k(r) = c_0(r - 3a_k) with c_0 piecewise quadratic. In cells of r and windows k the interaction is diagonal; the routed lift equals (number of windows) times the in-support density ratio, and the held-out-base predicate must use a to see it. Without the feature a the held-out-base lift is 1 by symmetry: that is the intended "advice versus structure" demonstration (D-advice = the position a).
