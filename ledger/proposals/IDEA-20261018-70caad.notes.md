## 1. The system
F = F_{2^N} = F_2[z]/(p), V = span(1, z, ..., z^{k-1}) (polynomial basis), r in F*. Unknown (x1, x2) in V x V, i.e.
2k boolean variables u. S_3(x1, x2, r) + 0 = F_r(x1, x2) + b with
  F_r(x1, x2) = x1^2 x2^2 + r x1 x2 + r^2 (x1^2 + x2^2).
Descend with a basis {lambda_j} of F over F_2: generator g_j(u) = Tr(lambda_j F_r) (degree 2: bilinear in (x1-bits,
x2-bits) plus linear), RHS bit btilde_j = Tr(lambda_j b). b -> btilde is an F_2-linear bijection.
Because S_3's only b-dependence is the additive constant, the system is F_r(u) = b: a fixed quadratic map with RHS b.
Every curve of the field (all 2^N - 1 values of b, every class) is a right-hand side of ONE map. (KN: this is the
"b-pencil" remark of IDEA-20261017-5f29b6 notes, there for batching, here for the class question.)

## 2. Exact facts
F1 (affine pencil). Macaulay matrix M_d(btilde): rows m * f_j, f_j = g_j + btilde_j, m square-free monomial of degree
   <= d - 2, reduced in F_2[u]/(u_i^2 + u_i); columns square-free monomials of degree <= d. The row m*f_j equals
   m*g_j plus btilde_j at column m. So M_d(btilde) = M_d(0) + sum_j btilde_j U_j(d), U_j 0/1, EXACT.
F2 (top-form data b-independent). The degree-2 parts of g_j and the top parts of the field equations do not involve
   b. A combination of generators is constant (top form = b-dependent constant) only for lambda in Lambda_0, the
   combinations whose bilinear AND linear part vanish. For those, Tr(lambda b) = 1 puts 1 in the ideal at degree 2
   (UNSAT, no relation), Tr(lambda b) = 0 drops the generator. Otherwise Dubois-Gama first fall degree (min degree of a
   non-trivial syzygy of the top forms) is the same for every b. The Macaulay-span meter first_fall(b) >= that value,
   and exceeds it only if the fall element is already in V_{d-1}, which depends on the b-part of degree <= d-2.
F3 (ceiling). rank M_d(btilde) <= rho_d := rank of M_d(t) over F_2(t_1..t_N), for every btilde in F_2^N
   (minors specialise). Also rank M_d(b) <= N_d - HF_{S_b}(d) for SAT b, S_b the solution set, N_d = number of
   square-free monomials of degree <= d, HF_S(d) = dim of the restriction of degree <= d polynomials to S.
   So deficit delta_d(b) := rho_d - r_d(b) >= 0 always. A "favourable" classmate can only TIE the ceiling on the rank
   side; any gain over a generic member comes from fibre size s(b) = abs(S_b) (yield), not from rank.
   Caveat: rho_d is the F_2(t)-generic rank; the F_2-point maximum rho_hat_d <= rho_d can be smaller. Census reports both.
F4 (fibre size is free). s(b) for all b at once = histogram of u -> F_r(x1, x2) over the 2^{2k} points. No Macaulay.
F5 (Galois). sigma b with sigma V, sigma r is an isomorphic system (draft-1). With V fixed it is NOT; the census at
   fixed (V, r) therefore mixes curve and factor-base position. Controls: repeat with 8 targets r and, at N = 9, a
   second V (a random F_2-subspace of the same dimension).

## 4. Statistic and nulls
Per class (b-set B_kappa = {b : K(b) = kappa}, union of sigma-orbits; the t and -t classes share it):
  T_d(B) = mean over B of delta_d(b); also mean D_Mac, mean s.
N1: random unions of full sigma-orbits with the same multiset of orbit sizes (preserves Galois structure).
N2: stratum-matched resampling: each b in B replaced by a b' from the same (orbit size, s(b) in {0,1,2,3+}) stratum
    (preserves yield). If a class is extreme under N1 but not N2, the effect is mediated by yield (relation density).
N3 (dimension-matched structure null, per the 845d35 lesson): a random bilinear-plus-linear pencil of the same shape
    (N equations, 2k variables, bilinear in two blocks, random linear parts) with the same Lambda_aff dimension.
    A "deficit" that N3 shows equally is dimension-forced, not elliptic.
Planted positives: pseudo-classes = top decile of s(b) and top decile of delta_4, size-matched to the real classes.
    They must be flagged by the same pipeline at percentile <= 2.5 % (power gate); otherwise the cell is inconclusive.
Decision: count classes with two-sided percentile <= 5 % (expected ~1 of 23 at N = 9) and a KS test of the percentile
list for uniformity. "Class effect" needs >= 5 of ~23 (N = 9) or >= 7 of ~45 (N = 11) under N2 AND a KS p < 0.01.
Power remark: ~23 / ~45 classes with ~23 / ~45 b each cannot see shifts below ~0.5 sigma of the class mean; any
effect large enough to matter for an exponent must be of constant relative size, which is visible.

## 5. Heuristics
H1 corank law (classical): P(corank = c) -> alpha 2^{-c^2} / prod_{i<=c}(1 - 2^{-i})^2, alpha = prod_{i>=1}(1 - 2^{-i})
   = 0.2888 for a uniform random matrix over F_2 (Kolchin; Brent-McKay; recalled). Imitated: delta_d(b) after removing
   dimension-forced rank. Validation: histogram of delta_d over all b vs law, tail merged at c >= 3; same for N3.
H2 exchangeability of class membership given (orbit structure, s(b)): K has a flat Fourier spectrum
   (K(b) = sum_{lambda != 0} (-1)^{Tr(1/lambda)} (-1)^{Tr(lambda b)}), and Katz-type equidistribution (recalled).
   This is the null itself, not an assumption of the conclusion: the test rejects it or fails to.

## 6. Which of the two conditions
Neither fully. It tests whether ANY class-dependent degree advantage exists at fixed N (a necessary condition for
"advantage grows with n"). Two or three rungs (N = 9, 11, 13 sub-sample) are not a slope; growth stays unmeasured.
Walk is not charged because no attack is claimed; the scan cost of a favourable member is priced in draft-4.
