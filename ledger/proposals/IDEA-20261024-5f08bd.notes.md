## From orbit patterns to genus

Prime `n >= 5`, `x in K \ F_q` (orbit exactly `n`), `B' = {sigma^a x : a in S}`, `|S| = 4`. The union of the `n`
shifts is the whole orbit, `r = n`. The span of the indicator vectors is the ideal of `R = F_2[x]/(x^n - 1)`
generated by `s_S = sum_{a in S} x^a`, of dimension `n - deg gcd(s_S, x^n - 1) = #{zeta in mu_n : s_S(zeta) != 0}`
(`x^n - 1` is squarefree over `F_2` for odd `n`). `s_S(1) = 4 = 0`, so `m <= n - 1`. Then
`g = 2^(m-2)(n-4) + 1`. With `Z(S) = {zeta != 1 : s_S(zeta) = 0}`, stable under squaring, `m = n - 1 - |Z(S)|`,
and `e(n) = max_S |Z(S)|`.

Baseline: `n = 5`: `m = 4`, `g = 5`. `n = 7`: `S = {0,2,3,4}` has `s_S = (x+1)(x^3+x+1)`, `Z(S)` = the three roots
of `x^3+x+1`, `m = 3`, `g = 2 * 3 + 1 = 7`. `n = 11`: 2 is primitive, so `Z(S)` is empty or everything;
everything means `Phi_n | s_S`, impossible for weight 4 < n. So `m = 10`, `g = 2^8 * 7 + 1 = 1793`; `n = 13`:
`2^10 * 9 + 1 = 9217`. Both equal the sibling study's table.

## The Newton lemma

Let `u_1..u_4` be distinct in `F-bar_2`, `e_i` their elementary symmetric functions, `p_k` power sums.
`p_1 = e_1`. With `e_1 = 0`: `p_3 = e_1^3 + e_1 e_2 + e_3 = e_3` (characteristic 2). So `p_1 = p_3 = 0` gives
`e_1 = e_3 = 0`, and `prod (t - u_j) = t^4 + e_2 t^2 + e_4 = (t^2 + e_2^(1/2) t + e_4^(1/2))^2` has repeated
roots. Contradiction. For `u_j = zeta^(a_j)`: `s_S(zeta) = 0 = s_S(zeta^3)` is impossible. If `3 in <2>` then
`zeta^3` is a Frobenius conjugate of `zeta`, so `zeta in Z(S)` implies `zeta^3 in Z(S)`, a contradiction; `Z(S)` is
empty. This covers `n = 5, 11, 13, 19, 23, 29, 37, 53, 59, 61, ...` (for `n = 23`, `3 = 2^8 mod 23`). For `n = 17`,
`<2> = {1,2,4,8,16,15,13,9}` does not contain 3, but the cyclic code with zeros `{0} union <2>` is the `[17,8,6]`
even-weight QR subcode with no weight-4 word, so `e = 0` by distance.

## When e(n) > 0

`e(n) > 0` iff four distinct elements of `mu_n` sum to 0 in `F_{2^o}`, `o = ord_n(2)`. Poisson mean `C(n,4)/2^o`.
Examples: `n = 7` (`o = 3`, mean 35/8): yes. `n = 31` (`o = 5`, mean 31465/32): yes, the even-weight Hamming code
`[31,25,4]`. `n = 73` (`o = 9`, mean ~2000): expected yes. `n = 17` (mean 9) and `n = 23` (mean 4.3): no, because of
perfect-code structure. `n = 47` (`o = 23`): mean 0.02, no. These are estimates; the exhaustive table decides.
Two cosets `C_i, C_j` in `Z(S)` need `p_i = p_j = 0`; for `(1, 5)` this forces `e_1 = e_2 = 0`, i.e. the four points
form an `F_4`-line (a coset of `lambda F_4`), which needs `o` even.

## Cross-characteristic

Hess: `g = 2^t - 2^(t-s1) - 2^(t-s2) + 1`, `s_i = deg Ord_{gamma_i}`, `t = deg lcm`. For `s1 = s2 = t` this is
`2^t - 1`. If `n = 2^t - 1` is prime and `Ord_gamma` is a primitive degree-`t` polynomial dividing `x^n - 1`, then
`g = n`, at `n = 7` (`t = 3`), `31` (`t = 5`), `127`, `8191`. In odd characteristic the same cyclic module (the
simplex code of dimension `t`) would have to be generated by a vector of weight exactly 4, and its nonzero words
have weight `2^(t-1)`, equal to 4 only for `t = 3`. So the two characteristics meet at `n = 7` and separate from
`n = 31` on. The genus count in the Artin-Schreier world is not a function of weights, which is the structural
point; whether a Hess family at `n = 31` exists with useful density is not claimed.
