## Validity of factor-base-only relations
Sum of P_0..P_t = O with all P_i in F gives sum eps_i log(hP_i) = 0 (h cofactor), homogeneous in the
B unknown logs. Kernel is 1-dimensional when the relation graph is connected; log scale fixed by

negligible.

## Counts (polynomial system S_{t+1} = 0 over V^{t+1}; rationality is an extra Tr condition)
Primitive: ordered tuples with a relation ~ 2^{t-1}|V|^{t+1}/2^n for generic tuples (each t-tuple
has <= 2^{t-1} candidate x_0 values). c_t absorbs sign and rationality factors.
Trivial, t+1 = 4: S_4(x,x,y,y) = 0 identically (P - P + Q - Q). Tuples with some matching equal:
|A1 u A2 u A3| = 3|V|^2 - 3|V| + |V| = 3|V|^2 - 2|V| (pairwise intersections are the all-equal
tuples, |V| each, triple intersection the same). At (n,l) = (8,3): 3*64-16 = 176 against

primitive (t-1)-relation: ~ |V|^t/N per pair choice, a factor |V| below primitive.
Requirement: relations >= |V| => |V|^t >= N/c_t. Trivial/useful = |V|^{(t-1)/2}.
Output-size time bound for even t+1: |V|^{(t+1)/2} >= (N/c)^{(t+1)/(2t)}; t=3 gives N^{2/3}, the same
