## Reduction of Smart's ratio to the defect function
Any set section s of E(Z/p^2) -> E(F_p) on <P> is s_tor(R) + (point of the formal group Ehat(pZ/p^2) = F_p),
so sections <-> arbitrary functions delta: <P> -> F_p. [n] s(R) = [n] delta(R) (torsion killed), logarithm is
the identity on pZ/p^2 to first order, so psi(R) = log([n]s(R))/n = p*delta(R) mod p^2. Smart's ratio
psi(Q)/psi(P) = delta(Q)/delta(P). Success for scalar d: delta(dP) = d*delta(P) with d the integer
representative in [0,n). Classes: delta = f|_<P> with f in L(kO).

## Why the maximum is not Weil-level
Weil/Kohel-Shparlinski-type bounds (recalled via IDEA-20260905-b6154d) give |rho - 1/p| <= C k log n / sqrt(p)
for the full-value event after expanding d*f(P) into group characters (L1 norm ~ log n). That allows rho of
order k log p / sqrt(p), which is the same order as the break-even line of IDEA-20261016-0bacee. The exhaustive census is the
cheap way to see which side of the allowance the true maximum sits on. Heuristic count: p^k functions, each N
roughly Poisson(1); the maximum of p^k independent Poisson(1) is about k log p / loglog p. Interpolation (k-1
prescribed d's) gives k-1 deterministically but requires knowing which d's.
