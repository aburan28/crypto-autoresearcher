## Degree-2 functions and torsors

A degree-2 function `f: E -> P^1` over `K` has a polar divisor `D` of degree 2, `D in Pic^2(E)(K)`; with
origin `O`, `Pic^2 ~ E` by the sum, so `D <-> T = sum(D) in E(K)`. Ramification points of `|D|` are
`{P : 2P = T}`, a torsor under `E[2]`. Translation by `Q in E(K)` carries `f_{T+2Q}` to `f_T` (same cover up to a
`K`-automorphism of the curve), so the covers are indexed by `E(K)/2E(K)`, of size `|E(K)[2]|`.
`T = 0` is `x`. The explicit `f_T = (y + y_T)/(x - x_T)` has polar divisor `O + T`.

## Frobenius type of the torsor

`F` = `K`-Frobenius acts on the torsor by `P -> F(P) = P + c`, `c in E[2]` defined modulo `(F-1)E[2]`.

- `E[2]` of order 3 (odd `#E(K)`): `F - 1` is invertible on `E[2]` (since `F^2 + F + 1 = 0`), `H^1 = 0`, only
  `T = 0`, type `(1,3)` (the point `O` fixed, the three other points a 3-cycle).
- `F` a transposition (`E(K)[2] = Z/2`): `H^1 = E[2]/(F-1)E[2]` has order 2. `T != 0`: `c` represents the
  nonzero class, `F^2(P) = P + c + F(c) = P + T_2 != P`, so `F` is a 4-cycle.
- `F = 1` (split): `H^1 = E[2]`; `T != 0` gives `F(P) = P + c`, `c != 0`, type `(2,2)`.

## Orbit cases for T != 0 (tau^n restricts to F on B')

Let `n` be an odd prime, `tau` the structure, so `tau^n` acts on `B'` as `F`.

- 4-cycle: the `tau`-orbit of a branch point has size `4` or `4n`. Size 4 means `B'` is `tau`-stable, `j in F_q`,
  `g = 1`. Size `4n`: the `n` shifts of `B'` tile the orbit, `m = n`, `r = 4n`, `g = (n-1) 2^n + 1`.
- `(2,2)`, pairs `P_1, P_2` each `{b, tau^n b}`: each pair is `tau`-stable (orbit 2) or has orbit `2n`.
  Both stable: `g = 1`. One stable: `m = n`, `r = 2n + 2`, `g = 2^(n-1)(n-1) + 1`. Both of size `2n` and distinct
  orbits: `m = n`, `r = 4n`, `g = (n-1) 2^n + 1`. Both in one orbit of `Z/2n`, `P_2 = tau^k P_1`: the generator is
  `s = (x^n+1)(x^k+1)` in `F_2[x]/((x^n+1)^2)`, with `x^n s = s`, annihilator `((x^n+1)/(x+1))`, so
  `m = n - 1`, `r = 2n`, `g = 2^(n-3)(2n-4) + 1 = 2^(n-2)(n-2) + 1`, giving 3, 25, 161 at `n = 3, 5, 7`.

The module is over `F_2[x]/((x^n-1)^2)`, which is not semisimple; this is the first place the program meets a
non-semisimple cyclic module.
