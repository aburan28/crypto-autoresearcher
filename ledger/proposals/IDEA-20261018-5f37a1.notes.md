## 1. Why the orbit-class null is the right null
- Group H = <tau,-1> of order 2n acts freely on G minus {O} (r prime, n odd prime, -1 not in <lambda>). Target classes N_c = (r-1)/(2n). N19: (262543-1)/38 = 6909, matching RUN-KIC-234d11.
- H acts freely on distinct m-subsets of a base closed under H when m is odd and m < n (a fixed subset would be a union of H-orbits of size >= 2). So M_c = C(2nK, m)/(2n) for distinct points. N19, K=4, m=3: C(152,3)/38 = 573,800/38 = 15,100. With repeated points allowed (the protocol's SYMMETRY note says points may repeat): C(154,3)/38 = 15,708.
- Occupancy of M_c uniform throws into N_c bins: mean N_c(1-(1-1/N_c)^M_c); var = N(N-1)(1-2/N)^M + N(1-1/N)^M - N^2 (1-1/N)^(2M), about N e^-lam (1-(1+lam)e^-lam).
- Element-level null: M = 2n M_c throws into r bins, same lam, variance of the fraction f(lam)/r versus class null f(lam)/N_c: variance ratio 2n, sd ratio sqrt(2n).
- Sparse regime (lam << 1): occupied = M_c - collisions, collisions ~ Poisson(M_c^2/(2 N_c)), so sd = M_c/sqrt(2 N_c) and relative sd = 1/sqrt(2 N_c). Log-blind selection gain is z times that; log-aware perfect dispersal gains lam/2 relative. At design scale N_c >= 2^120 both are negligible for log-blind (< 2^-59), log-aware headroom (1.58x at lam = 1, KN-FIND-007) needs logs.

## 4. Design break-even
Support cache for pool P: P^3/6 triple types (multisets: C(P+2,3), 9139 at P = 37) times 4 n^2 anchored sums = 1.3e7 additions at N19. Break-even number of attacked curves L* = C_design / (relative gain x C_attack) with relative gain <= 1.5 percent. Per-curve advice only pays if L* is below the number of curves the attacker will face; for standard curves (K-163..K-571) L is at most 5, so the log-blind coverage design cannot repay itself unless C_design is far below C_attack.
