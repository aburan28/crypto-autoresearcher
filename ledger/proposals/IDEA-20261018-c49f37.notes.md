# draft-3 notes (IDEA-20261018-c49f37): the class couples to the descended system through one Fourier family

Status: hand derivation, nothing executed (no shell). Identities are exact; numeric envelopes are labelled.

## 1. Objects
F = F_{2^N}, psi_lambda(b) = (-1)^{Tr(lambda b)}. V subset F an F_2-subspace of dimension k, r in F*.
F_r(x1,x2) = x1^2 x2^2 + r x1 x2 + r^2 (x1^2 + x2^2) (so that S_3(x1,x2,r) = F_r + b).
Fibre size s(b) := #{(x1,x2) in V^2 : F_r(x1,x2) = b}. Mean s_bar = 2^{2k-N} (b over all F).
Class function: K(b) = sum_{x != 0} (-1)^{Tr(x + b/x^2)}, with #E_{a,b} = 2^N + 1 + (-1)^{Tr a} K(b)
(draft-1 derivation; K(sqrt b) = K(b)). Class of trace t = level set {K = -(-1)^{Tr a} t}.

## 2. Exact identities
(I1) Walsh expansion. s(b) = 2^{-N} sum_lambda psi_lambda(b) W(lambda), W(lambda) = sum_{x1,x2 in V} (-1)^{Tr(lambda F_r)}.
(I2) Form of W. Tr(lambda F_r(x1,x2)) = Tr(c x1 x2) + Tr(kappa x1) + Tr(kappa x2), with mu = lambda^{1/2}, c = mu + lambda r,
     kappa = mu r (use Tr(y^2) = Tr(y)). Then W(lambda) = |V| * sum_{x2 in V, c x2 + kappa in V^perp} (-1)^{Tr(kappa x2)}
     in {0, +-2^{2k - rho_c}}, rho_c = rank of the bilinear form Tr(c x1 x2) on V x V (V^perp = trace dual of V).
(I3) Class character. With lambda = x^{-2}: K(b) = sum_{lambda != 0} (-1)^{Tr(1/lambda)} psi_lambda(b). Flat: every coefficient
     has modulus 1.
(I4) Parseval. For b uniform over F (b = 0 is one point in 2^N, correction O(2^-N)):
       Cov(K, s) = 2^{-N} sum_{lambda != 0} (-1)^{Tr(1/lambda)} W(lambda),
       Var(s)    = 2^{-2N} sum_{lambda != 0} W(lambda)^2,   Var(K) = 2^N - 1.
(I5) Pushforward form of the class yield. Y(kappa) := sum_{b : K(b) = kappa} s(b) = #{u in V^2 : K(F_r(u)) = kappa}. One pass over
     2^{2k} points and one table K (Walsh transform, N 2^N operations) give the relation yield of EVERY class of the field.
(I6) Trace term. lambda_0 = r^{-2}: mu = r^{-1}, c = mu + lambda_0 r = 0, kappa = mu r = 1, so Tr(lambda_0 F_r) = Tr(x1) + Tr(x2) and
     W(lambda_0) = 2^{2k} if V is in ker Tr, else 0 (trace-parity confinement, H-SEMBIN-83a856). It is the only rank-0 term when V.V = F.

## 3. Envelope (heuristic H1, not a theorem)
Polynomial-basis V: Tr(c x1 x2) has Hankel Gram matrix (Tr(c z^{i+j})), i,j < k, entries s_m = Tr(c z^m), m <= 2k-2.
If 2k-1 <= N and r not in V.V = span(1..z^{2k-2}), then c in the hyperplane {Tr(rc) = 0} gives uniform Hankel
sequences, and Daykin's count (# k x k Hankel over F_q of rank j = q^{2j-2}(q^2-1) for 1 <= j < k, 1 for j = 0, and
q^{2k-2}(q-1) for j = k; sum for rank <= j equals q^{2j}) gives, for q = 2,
  sum_H 2^{-2 rank H} = 1 + (k-1) 3/4 + 1/4 = (3k+2)/4.
lambda -> c is 2-to-1 onto the hyperplane, so sum_{lambda != 0} W^2 <= 2 * 2^{N-2k} * 2^{4k} * (3k+2)/4, and
  Var(s) <= s_bar (3k+2)/2        (upper envelope: consistency indicators in I2 only lower it).
Poisson would be Var = s_bar. Overdispersion factor at most (3k+2)/2 (N = 11, k = 6: 10).
When N = 2k-1 (draft-2 cells) r is always in V.V and c lies in a hyperplane of the Hankel space: Daykin is only approximate;
the exact variance is the I4 sum, one pass over lambda.
Random-sign argument for the covariance: sum_lambda (-1)^{Tr(1/lambda)} W(lambda) has the size of sqrt(sum W^2) if the signs are
pseudo-random, so the correlation coefficient of K and s is of order 2^{-N/2}, except the trace term (I6), which adds
+-s_bar to Cov when V is in ker Tr. First-order class effect on yield: E[s | K = kappa] - s_bar ~ Cov kappa / Var(K), at most
~s_bar 2^{-N/2+1} for the trace term. Everything beyond is nonlinear coupling, which is what I5 measures.
Power: a class of h ~ 2^{N/2} curves has sampling s.d. of its mean yield ~ sqrt(Var(s)/h); at N = 11 that is ~30 % of s_bar,
at N = 21 ~ 3 %. The N-scaling is what gives the test power.

## 4. First-fall closure (T1), with the closure standard of docs/inventor-protocol.md section 4
Obstruction: in Sigma(N,k,V,r,b) the curve parameter occurs only as additive constants btilde_j = Tr(lambda_j b). Argument:
the top homogeneous part of every non-constant element of the span of generators is b-free; a span element is constant only on
Lambda_0 (bilinear and linear parts both vanish), where Tr(lambda b) = 1 makes the ideal the unit ideal (no relation) and
Tr(lambda b) = 0 removes the element. Hence the Dubois-Gama first fall degree is identical for every b with a nonempty fibre,
in particular for all members of every class, for each fixed (N,k,V,r). The Macaulay-span meter first_fall(b) >= that value.
So "some isogenous member keeps a strictly slower growth of FIRST-FALL degree" is false for this system family by construction;
a measurement would only reproduce it.
Forward guidance (classes that remain): (i) last fall / solving degree through the b-part of lower degree: draft-2;
(ii) relation yield (s(b), I5): this draft; (iii) presentations in which the curve is NOT a constant: odd characteristic (a, b in
coefficients), base-field curves with x_i in F_q (b confined to an l-dimensional subspace of the N-dimensional RHS), chained
presentations whose block structure changes how b enters.

## 5. The scaling measurement (the part with growth in N)
For N = 9, 11, ..., 21 (k = (N+1)/2, V = polynomial window, 4 targets r): compute
  (a) tail of s over b: P(s >= j), max_b s(b)/s_bar, versus Poisson(s_bar) and the envelope of section 3;
  (b) class yield ratio m(kappa) = Y(kappa) / (V^2 mass of the class) and its dispersion across classes, divided by the sampling
      s.d. sqrt(Var(s)/(h_kappa s_bar^2)); the ratio R_N should stay ~1 under H2; growth of R_N with N is the coupling;
  (c) the exact Cov(K, s) (I4) against the direct enumeration (identity check, difference must be 0 up to the b = 0 term).
Cost: 2^{2k} = 2^{N+1} evaluations of F_r per target, 2^N for K: N = 21 is ~4e6 operations. No Macaulay.

## 6. Condition mapping
Tests condition 2 on the YIELD channel with a real N-scaling (9..21). Condition 1 (cheap walk) is priced in draft-4.
Exponent bookkeeping: a yield factor Y on a class-reachable family cuts decomposition attempts by Y: exponent-relevant only if
Y grows like 2^{cN}; the second-moment envelope alone does not exclude that for rare families (Chebyshev with density 2^{-N/2}
allows x ~ 2^{N/4} sqrt(1.5k / s_bar)); hence the tail measurement (a) is the real test.
