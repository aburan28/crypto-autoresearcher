## Spectrum at n = 7 (sketch)

Lemma M: the span is the cyclic `F_2[x]/(x^n - 1)`-module generated by
`1_{B'}`, so `m = deg d` for a divisor `d` of `x^n - 1`. Over `F_2`:

- `x^3 - 1 = (x+1)(x^2+x+1)`: `m in {1, 2, 3}` (matches the n = 3 census).
- `x^5 - 1 = (x+1)(x^4+x^3+x^2+x+1)`: `m in {1, 4, 5}` (matches n = 5).
- `x^7 - 1 = (x+1)(x^3+x+1)(x^3+x^2+1)`: `m in {1, 3, 4, 6, 7}`.

`n = 7` is the first prime with `ord_n(2) < n - 1`, so the first with an
intermediate span (`m = 3, 4`).

## Candidate floor 7 (split 2-torsion)

Take `x in K \ F_q` (sigma-orbit of size 7) and `B' = {sigma^i x : i in S}`
with `|S| = 4`. Each orbit point lies in exactly 4 translates, so
`(x+1) | 1_S(x)`. If moreover a cubic factor `f` divides `1_S(x)`, then
`1_S = (x+1) f` up to rotation, which has weight 4:

- `(x+1)(x^3+x+1) = x^4+x^3+x^2+1`, `S = {0, 2, 3, 4}`;
- `(x+1)(x^3+x^2+1) = x^4+x^2+x+1`, `S = {0, 1, 2, 4}`.

Each generates the `[7, 3, 4]` simplex code, so `m = 3`, `r = 7`,
`g = 2 * 3 + 1 = 7`, equal to the Lemma D0 bound `g >= n`. All four branch
points are then `K`-rational, which needs `E(K)[2] = (Z/2)^2`. Open at
design: that such a `B'` is the branch set of some `E` (a Mobius image of
`x(E[2])` and infinity — any 4 distinct points are, up to twist), and that
no non-split configuration reaches 7.

## Candidate odd-order floor 193

Odd `#E(K)`: one `K`-rational root `a` and three roots `theta` of an
irreducible cubic over `K`, so `theta in F_{q^21}`, sigma-orbit 3 or 21.
By analogy with Prop. O5 (n = 5: orbit 3 plus orbit 5, `m = 5`, `r = 8`,
`g = 33`), the smallest case is theta-orbit 3 and `a`-orbit 7:
`r = 10`, `m = 7`, `g = 2^5 * 6 + 1 = 193`, for `j not in F_q`. Unproved.

## Configuration count behind H1

patterns, against about `2 q^7` curves: a rate near `q^-3` among split
curves, as the n = 5 study conjectured for genus 5. A count, not a
derivation.

## Cost of the full structure scan

`(Q^3 - Q)/(q^3 - q)` structures per model, `Q = q^7`: about `4.4e8` at
`q = 3`, about `4e12` at `q = 5`. The n = 5 panel E ran about `2.5e8` per
model; so `q = 3` is a sampled (or, with the gcd fast path, possibly
