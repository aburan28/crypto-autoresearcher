## Setup
R = R_A (x) R_B, Boolean rings on disjoint variable sets. Cumulative Macaulay rows of the A-generators:
m_A m_B f_A with deg m_A + deg f_A + deg m_B <= D. Boolean reduction never mixes m_B with f_A
(disjoint variables). Let U_A^c = span{m_A f_A : deg m_A + deg f_A <= c} inside R_A (increasing in c)
and R_B^{<=w} the monomials of degree <= w (increasing in w).
S_A(D) = sum_c U_A^c (x) R_B^{<=D-c}.
Any two partial flags in a finite-dimensional space admit a common adapted basis. Take e_i adapted to
{U_A^c} and {R_A^{<=w}} with levels a_A(i) (least c with e_i in U_A^c, infinity if none) and
w_A(i) (monomial level); g_k likewise for B with levels b_B(k), w_B(k). Then in the basis e_i (x) g_k
S_A(D) = span{(i,k) : a_A(i) + w_B(k) <= D},  S_B(D) = span{(i,k) : w_A(i) + b_B(k) <= D}.
Both are coordinate subspaces, so dim(S_A + S_B) = #{(i,k): either condition}. QED (modulo the
adapted-basis lemma, standard Bruhat/Zassenhaus).
N_A(a,w) = #{i : a_A(i) = a, w_A(i) = w} = second difference of dim(U_A^a cap R_A^{<=w}); computable
from one degree-graded echelon form of the block (columns ordered by degree).

## 1-D formula and why it fails with falls
Treating the intersection as sum_{a+b<=D} (new rows of A at level a)(new rows of B at level b) is the
same count with w replaced by a. Since w(i) <= a(i) for row-space vectors, equality holds iff no
row-space basis vector has w < a, i.e. iff there are no degree falls (fall_dim = 0) in the cumulative
space. With falls the 1-D count exceeds the exact one. KN-FIND-006 reports falls in the real systems
(deficit(3) = 1), so the real block should separate the two formulas; that is a prediction.

## k-fold version
For 2^h leaf blocks (all identical): dim = #{(i_1..i_k): exists j with a(i_j) + sum_{l != j} w(i_l) <= D},
a union of k coordinate subspaces; evaluate by dynamic programming over the table N(a,w).
