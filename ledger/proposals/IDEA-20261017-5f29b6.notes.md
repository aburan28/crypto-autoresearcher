## Affinity
S_3 = (x1x2+x1x3+x2x3)^2 + x1x2x3 + b = x3^2 (x1+x2)^2 + x3 (x1x2) + x1^2x2^2 + b (char 2).
For fixed x1,x2 this is A x3^2 + B x3 + C: x3 -> x3^2 and x3 -> x3 are F_2-linear, so the
descended components are affine in the n bits of x3. By symmetry the same holds for each
single argument. In the chained/balanced presentations x_R enters one block only, so
M_D(r) = M_0 + sum_i r_i M_i exactly (also stated as Lemma "affine pivot forms" in
experiments/EXP-CERTBIN-4e92d7/derivation-note-replay-forms.md, verified there per instance).
Direct S_{t+1}: degree 2^{t-1} in x_R as a field polynomial; r^j has bit-degree popcount(j),
j < 2^{t-1} gives <= t-1; so the pencil is a degree-(t-1) Veronese pencil with
sum_{k<=t-1} C(n,k) blocks (n^2/2 for t=3).

## Why NF is linear
RREF carrier: each pivot column has a single 1. NF(v) = v + sum_p v[col_p] rref_p is F_2-linear.
Hence NF(M_D(r)) = NF(M_0) + sum r_i NF(M_i). Non-RREF carriers need back-substitution
first (cost charged to precompute).

## Zero-compute kernel lemma
M(delta) = delta^2 (u+x)^2 + delta u x. For delta != 0 it vanishes at (u,x) iff delta = ux/(u+x)^2
(u != x). Elements of the Macaulay row space lie in the ideal, hence vanish on the structural
solution set. So M(delta) in the row space forces ux/(u+x)^2 = delta on every structural solution.
With >= 2 solutions of distinct ratio (true for |V| >= 4 and t >= 3) no nonzero delta qualifies.
This closes "translation periods from the rows"; it does not close periods of the refutation
indicator that arise from the reduced system's global rank structure (that is IDEA-20261017-845d35).

## Cross-curve remark (not a separate idea)
b enters each block only as a constant vector: every structural generator is F(.) + b with F
curve-independent, so M_D(b) is also affine in b with sparse unit-vector perturbations and the
top-degree matrix H_D is b-independent. Curves are right-hand sides of one map; the twist pair
(a, a+delta with Tr delta = 1) has identical S_3 (a does not appear). The pencil argument
applies verbatim to b (a Gray-code walk over curves updates a carrier at about 1/n of a rebuild).
