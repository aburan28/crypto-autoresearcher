## 1. Stability and orbit structure
- x in S_d iff x^d = 1. (x^2)^d = 1 and (1/x)^d = 1, so S_d is closed under tau (x -> x^2 on x-coordinates) and, for curves y^2 + xy = x^3 + a x^2 + 1, under translation by T = (0,1) (x(P+T) = 1/x(P)).
- S_d = mu_d is cyclic of order d; with generator g, x = g^i, tau acts as i -> 2i and T as i -> -i on Z/d. For e | d, e > 1, ord_e(2) divides n and exceeds 1, so equals n; it is odd, hence -1 is not in <2> mod e. All non-identity orbits of <2,-1> have size 2n. For prime d = 2kn + 1 there are k classes (d = 263, n = 131: k = 1, one orbit of 262).

Inversion maps the G-points of S_d to the partner coset (Tr(1/x) = Tr(x) + Tr(a)), so the G-base is not T-closed; the partner base is its image under translation by T. ## 3. Mechanism of the possible interaction (E2)
S_3 = (x1 x2 + x1 x3 + x2 x3)^2 + x1 x2 x3 + b. For x_i in S_d the product x1 x2 x3 is in S_d, so solutions need e2^2 + b in S_d. Heuristically this is generic: for fixed (x1,x2) the equation is quadratic in x3 and a root must land in S_d (probability d/2^n), the same as for any set of density d/2^n. A measured deviation (|z| > 3 against random stable unions) would be the first evidence of multiplicative-additive interaction in a base; a null result is a controlled null.

## 4. Why the lane is not a SAT lane
The descended system uses n bits per block (x is not confined to an l-dimensional space) with degree wt(d) membership equations; KR-IC-5765d2 and the exhaustive-core law do not apply as stated. The lane is for exact meet-in-the-middle and table attacks where only the set matters and description plus enumeration cost is charged.
