## 1. The identities

Base D, h-sum count vector c(R) over N' admissible targets (nonzero sums), M = sum_R c(R) the number of
h-tuples counted (conservation, KN-FIND-007), mu = M/N', Var = (1/N') sum (c - mu)^2, Delta = Var/mu.

Coincidences (EXP-PFDR-ca5e01 convention at h = 2): C(D) = sum_R binom(c(R), 2) = (sum c^2 - M)/2
= (N'(Var + mu^2) - N' mu)/2 = (N' mu / 2)(Delta + mu - 1).

(I1) kappa = C(D)/C(null) = (Delta_D + mu - 1)/(Delta_null + mu - 1) when the null has the same M (ca5e01
builds nulls of the same b, so the same number of pairs). For a Poisson null Delta_null = 1 and
kappa - 1 = (Delta_D - 1)/mu.

(I2) IDEA-20261017-3079bc: nu = E[c(c-1)]/E[c] = (E c^2 - mu)/mu = (Var + mu^2 - mu)/mu = Delta - 1 + mu.
So nu/nu_null = kappa at h = t. The 3079bc detector is a sampled, zero-background estimate of kappa for
binary bases at t = 4..12; the PFDR census is the exhaustive estimate at h = 2 on prime fields.

(I3) Parity mixture (H-SEMBIN-83a856, IDEA-20261017-e9f824): half the targets have c = 0, half have
Poisson(2 mu). E c = mu. E c^2 = (1/2)(2mu + 4mu^2) = mu + 2mu^2. Var = mu + mu^2. Delta = 1 + mu.
kappa = (1 + mu + mu - 1)/(1 + mu - 1) = 2 exactly, independent of mu. Coverage: fraction of targets with
c > 0 is (1 - e^(-2mu))/2 against 1 - e^(-mu) for the null, ratio (1 + e^(-mu))/2 -> 1 as mu -> 0 (the
e9f824 dose-response). General index d: Delta = 1 + (d - 1) mu, kappa = d, coverage ratio
(1 - e^(-d mu))/(d (1 - e^(-mu))). This is the d(V) of IDEA-20261017-3db2a8 read as kappa.

(I4) Parseval (IDEA-20261018-71a901 notes): g = c - mu on the n on-curve x-classes, sum_s abs(Phi_s)^2
= p sum g^2 = p n mu Delta. So Delta fixes the total spectral energy; the periodogram distributes it. A
peak at one s with Delta within band is "energy moved, not added": lift <= 1.8 sqrt(I Delta/(mu N)).
Therefore the periodogram is strictly finer than Delta and the harness is hierarchical: Delta (how much),
I_s (where in frequency), zero fraction (how the mass sits on targets).
