## 1. The identity
Notation: B base points, r group order, m summands, lam_p = B^m/(m! r) expected unordered solutions per target, lam_H = B^m/r expected ordered Horner solutions (lam < 1 regime). Exhaustive-core law: refuting one instance costs c 2^(ml) conflicts when nothing is pruned, and c 2^(ml)/m! when lex symmetry breaking removes the m! orderings (WDSat claims this; KN-LIT-92b022 abstract).
- plain, no SB: cost per attempt C = c 2^(ml); relations per attempt lam_p. Cost per relation C/lam_p = m! c 2^(ml) r/B^m.
- plain + SB: C/m!; relations per attempt lam_p. Cost per relation c 2^(ml) r/B^m.
- Horner: C; relations per attempt lam_H = m! lam_p. Cost per relation c 2^(ml) r/B^m.
Equal for plain+SB and Horner; both m! cheaper than plain without SB. The product-law budget column of KN-FIND-aa2efc/IDEA-20260926-197ecf carries m! in the numerator (attempts per relation) and credits Horner with removing it; if oracle budgets C are quoted per unbroken plain attempt, the credit is real relative to that column and zero relative to a column that already credits SB to the oracle.

## 2. MITM analogue (exact)
Split m = 2h. Plain unordered: tables of h-subsets C(B,h) about B^h/h!. Each m-subset solution is found C(m,h) times; matches per probe pass lam_p C(m,h); probes C(B,h). Probes per found solution = (B^h/h!)/(lam_p C(m,h)) = r h!/B^h. Table size times probes per solution = r.
Horner ordered: tables B^h, probes B^h, solutions lam_H, probes per solution r/B^h, product r. Same product; ordered trades table size (x h!) for time (/h!). Exactly the S T = r law of KR-RHO-ea34b8 type tradeoffs; no free lunch beyond the table/time exchange.

## 3. What would make Horner genuinely better
(E2) The rotated node blocks interact differently with learned clauses or branching so conflicts per refutation are below c 2^(ml) (a structural effect not captured by the exhaustive-core law). Test statistic: Horner conflicts per target divided by plain conflicts per target (without SB) must be about 1 under the identity; below 0.67 at two cells is a gain. Also (E3) SB under-delivers: WDSat reports m! only at its own encoding; a generic lex comparator in CaDiCaL may deliver less, in which case the Horner advantage is m!/(SB factor) and 197ecf stands in that range.

## 6. Exponent-first aside (hand derivation, unverified)
For a base of size r^beta, arity m, oracle cost r^gamma, relations needed r^beta, linear algebra r^(2 beta): total exponent max(beta + gamma + 1 - m beta, 2 beta) while lam <= 1 (m beta <= 1). With a meet-in-the-middle oracle gamma = m beta/2: optimum at beta = 1/m, total exponent 1/2 + 1/m (memory exponent 1/2), above rho's 1/2 for every m. The two-term optimum of IDEA-20260829-b5a2c8 (B* = (N D)^(1/(m+1))) is valid only when the per-attempt cost D does not exceed the total T, equivalently lam <= 1; for D = B^(m/2) it is violated for every m >= 3. A sub-sqrt exponent therefore needs an oracle with gamma < 1/2 - 1/m (m >= 5), i.e. beating meet-in-the-middle by r^(1/m); KR-IC-5765d2 (SAT: constant factors only), KR-IC-1fcdbc (measured far slower) and KR-IC-889857 (disputed) are the rows that stand against it; the Frobenius quotient changes constants by (2n)^a only.
