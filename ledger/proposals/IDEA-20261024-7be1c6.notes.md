## (a) Split curves are the interior vertices of the 2-volcano

`E(K)[2] = E[2]` iff `(pi-1)/2` is an endomorphism of `E`; for ordinary `E` every endomorphism commutes with
`pi`, so it is defined over `K`. `alpha = (pi-1)/2` has trace `(t-2)/2` and norm `#E(K)/4`, so it is an algebraic
integer iff `4 | #E(K)` (then `t` is even because `Q+1` is even). `Z[alpha]` is an order of index 2 over `Z[pi]`.
The classes with `End(E) = O` number `h(O)` for each order `Z[pi] <= O <= O_K` (Waterhouse, Schoof; recalled;
units of `Z[i]`, `Z[omega]` add twist classes with other traces). So
`N_split(t) = sum_{O >= Z[alpha]} h(O)`, and `h(O_f) = h(O_K) f prod_{p|f}(1 - (d_K/p)/p) / [O_K^* : O_f^*]`.
In the 2-isogeny graph of the class, vertices have degree 3 except at the floor of a volcano of depth
`v_2(f_pi) >= 1`, where they have degree 1 (and depth 0 volcanoes have degree at most 2). A vertex has degree 3
iff all three 2-isogenies are `K`-rational iff `F` acts trivially on `E[2]` iff the curve is split. So the
split curves are the non-floor vertices, and every floor vertex is adjacent to one. `4 | #E(K)` forces
`f_pi` even (a discriminant argument), so the depth is at least 1. To be checked at design.

## (b) The exponent

Classes: traces `t` with `|t| <= 2 q^(n/2)` and `t = Q + 1 mod 4`: about `q^(n/2)`. Floor curves: `n = 5`, the
sibling counts about `5 (q^5 - q)/(q^3 - q)` structures, times 2 twists, so about `10 q^2`. Hits per class
`~ 10 q^2 / q^(5/2) = 10 q^(-1/2)`: 4.5 at `q = 5`, 3.8 at `q = 7`, 3.0 at `q = 11`, 2.8 at `q = 13` (rough; two
twists share a class when `t` and `-t` both have `4 | #E`). At `q = 3` the sibling data have 15 classes with
`4 | #E` and 20 genus-5 curves on themselves, i.e. 1.3 per class: the constant is not 10, which is why the fit
is made on `q >= 5` and `lambda_n` is fitted, not assumed. For `n = 7`: floor curves `~ c q^4`, classes `q^(3.5)`,
hits per class `c q^(1/2)`.

## (c) The shape-bias alternative

If the law of 3c71a9 holds, `q = 3 mod 4` forces `8 | #E(K)` for genus 5. `v_2` is an isogeny invariant, so a
class with `v_2(#E(K)) = 2` is empty of floor curves regardless of `N_split`. In the sibling data at `q = 3`
(read after deriving): genus 5 on 40 curves with `v_2 = 3`, 40 with `v_2 = 4`, none with `v_2 = 2`. The test
separates the uniform model from the shape-biased model: under the uniform model about 1 - exp(-lambda) of the
`v_2 = 2` classes would be hit.

## Not done here

The walk. Reaching a hit from a given `E` by a random walk needs about `q^3` class members if hits have
density `q^-3`, and a class has `q^(n/2)` members; at `n = 5` that is more than the class, which is the same fact
as (b). Mixing (H2) is stated only so the two are not conflated. No cost is claimed.
