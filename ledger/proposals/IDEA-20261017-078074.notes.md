## 1. What is measured and why it is cheap

A = {c_1 P_1 + ... + c_r P_r : |c_i| <= T}. Build: a scalar multiples (or r(2T+1) multiples plus a^1
group additions). Labels X = {x(Q) : Q in A}. The statistic is the label-sum coincidence count
#{(u1,u2,u3,u4) in X^4 : u1 + u2 = u3 + u4 mod p} minus the trivial ones (u1,u2) = (u3,u4) or (u4,u3),
and |X + X|. Both need only a^2 modular additions and a sort, with no group law and no discrete log.
At p = 2^256 and a = 2^12 that is 2^24 big-integer additions per set.

## 2. Expected values under the random-set model

Ordered nontrivial coincidences ~ a^4 / p. At p = 2^20, a = 2^10: 2^40 / 2^20 = 2^20 ordered tuples
(~2^17 distinct), a relative sd of ~0.3% per set. At p = 2^256, a = 2^12: 2^48 / 2^256 = 2^-208. The
real-curve claim is therefore exactly zero, with no statistics: one verified coincidence would be
(by this model) a 2^208-to-one event and would be re-derived before anything else is read.

## 3. Trivial equalities to remove

* x-map is 2-to-1: c P and -c P share a label. Use c in [0, T] or deduplicate labels.
* j = 0 (secp256k1): x(beta Q) = beta x(Q) for the cube root of unity beta in F_p. If lambda P is in A the
  label set is closed under multiplication by beta, not under addition, so it creates no additive coincidence,
  but orbit duplicates must be removed. Flag, do not hide.
* Small multiples: x(2P) is a rational function of x(P) of degree 4; no additive relation follows.

## 4. The dichotomy, and what a failure would buy

For A subset of E(F_p) let K_G(A) = |A + A| / |A| and K_L(A) = |x(A) + x(A)| / |A|. Sum-product results on E
(Ahmadi-Shparlinski; recalled, not read) say, above roughly p^(1/2) points, that both cannot be small. 077f12
tests windows (K_L small by construction, is K_G random?). This idea tests log-GAPs (K_G small by construction,
is K_L random?). A log-GAP with small K_L would be a base with the weighted-base saving of IDEA-20261017-bbc53e
(kappa_eff = 2 c_0, an unknown shared among 2 c_0 members) AND a label-defined membership test, which is the
KN-OPEN-020 'implicit membership' route. Even then it prices at tau = (h/(2h-1))(1 - gamma), never below 1/2,
unless kappa exceeds U (bbc53e). So a failure of this probe is a structural finding, not an exponent claim.

## 5. Choi's theorem, scope

arXiv:2510.03828 (abstract only read): E/Q, rank r >= 1; a d-dimensional proper GAP in Q containing the
x-coordinates of a positive proportion rho of a set of rational points holds at most A(E,d,rho)^r of them.
This is the char-0 statement that label-additive structure and the group law are rigid. The F_p version is
open and fails at full size. This probe checks the finite-field analogue on the side of log-GAPs; 077f12
checks it on the side of label-GAPs. Neither proves anything about a real curve beyond the sizes run.
