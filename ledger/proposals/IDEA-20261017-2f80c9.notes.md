## 1. Setting

p = m^d - c, pi = alpha - m generates the degree-1 prime of Z[alpha]; the kernel lattice of Z[alpha] -> F_p has the
basis alpha^i (alpha - m) (i < d-1) and c - m alpha^(d-1): entries <= max(m, |c|), determinant p. Every x in F_p has a
Babai lift with digits <= m/2; for H below lambda_1/2 the lift of an element of the box D_H is unique and the box
covers H^d distinct residues. Membership "x in D_H" is a polynomial-time round-off.

## 2. (A) Rotation quotient

Sigma_rot: x -> m x (alpha-multiplication = cyclic digit shift twisted by c). For a factor-base translation R the map
P -> P + R sends x(P) to x(P+R) = rational function of degree 2 in x(P) with y(P) entering; the class [x(P)] = {m^i x(P)}
does not determine x(P+R)'s class: the d' = ord(m) points of the class have unrelated images (the images of the
d' points are d' unrelated field elements, the classes of which coincide with probability d'/p). So branching
b >= 1 - O(d'/p), loss L = log2 d' bits per step: for c = 1 (Mersenne, m = 2^k) d' = d <= 521, L <= 9.0 bits of 521,
and the object dissolves at the first translation step. For c != +-1, ord(m) = d * ord(c) is of the order of p and
the quotient is not a finite canonicalisation: alpha-shifts scale by c, so the only available canonical form is
"normalise the lowest non-zero digit position", a loss of log2 d. Neither is a block system of the translation group;
this is the same conclusion as IDEA-20260901-863e36 for a Gamma not inside the stabiliser of the map.

## 3. (B) Implicit norm-smooth factor base

F_B = {x in F_p : the Babai lift of x has B-smooth norm <= Y}. Y = p^(1/2) means H^d ~ p^(1/2), so F_B is a
smooth-norm subset of a p^(1/2)-size digit box: |F_B| ~ p^(1/2) * rho(u). A relation R = P_1 + P_2 with both x
in F_B: P_1 enumerated over F_B (amortised O(1) by lattice enumeration of smooth norms), accepted when
x(R - P_1) passes the membership test: success probability |F|/p per trial, so p/|F| trials per relation. The table needs
|F| relations: |F| * p/|F| = p. With |F| larger the linear algebra dominates: max(|F|, p/|F|) >= sqrt(p) per
relation, p for the table. Norm smoothness is multiplicative in the lift, the group law is not: nothing makes
P_1 + P_2 = R respect the smooth structure. This is the enumerate-and-test bound of KR-IC-5931ee restated for an
implicit-membership base and charged under KN-OPEN-020; the special form changes the membership cost only.

## 4. (C) Ideal Coppersmith: what the volume bound says

Cohn-Heninger (arXiv:1008.1284, Thm 1.3, read on ar5iv 2026-10-17): K of degree n, f monic of degree delta in
O_K[x], I a proper ideal; all w in O_K with |w|_i < lambda_i (all embeddings) and N(gcd(f(w)O_K, I)) > N(I)^beta are found
if prod lambda_i < N(I)^(beta^2/delta) (exponential in n^2 time), or if prod lambda_i < (2+o(1))^(-n^2/2) N(I)^(beta^2/delta)
(polynomial time). With beta = 1 and I = pi: prod lambda_i < p^(1/delta), no dependence on n beyond the loss factor.

Coefficient box versus embedding box. A digit vector with |a_i| <= H has embeddings
|sigma_j(x)| <= sum_i H |alpha_j|^i. For small c (|alpha_j| ~ 1) this is ~ H, and prod lambda_j ~ H^d d^d. For a
random-base ring, |alpha_j| = c'^(1/d) and prod lambda_j ~ H^d c'^(d-1). So with the same embedding bound
p^(1/delta) the special ring admits coefficient volume H^d ~ p^(1/delta) and the random-base ring only
p^(1/delta)/c'^(d-1). The special form therefore restores the d = 1 volume and does not exceed it; this is the
Coppersmith-side reading of "the SNFS norm is smaller by m^(d-1)".

Hybrid. For a relation we need both x_1, x_2 in a box with V^2 >= p (a root exists). Coppersmith handles roots with
(V1 V2) <= p^(1/delta_eff); guessing the rest costs G = V^2/p^(1/delta_eff), with V = p^(1/2): G = p^(1 - 1/delta_eff).
delta_eff for S_3 (degree 2 per variable, total degree 4) lies in [2,4] in the Jochemsz-May accounting (heuristic;
measured by the planted-root scan), so G in [p^(1/2), p^(3/4)] per relation.
