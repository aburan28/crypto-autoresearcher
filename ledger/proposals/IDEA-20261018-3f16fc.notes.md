## 1. Accounting identity (exponent-first)
Index-calculus attack on the favourable member b*: T(b*) = W(b*) + T_IC(b*), W = walk to b*, T_IC = relation collection plus
linear algebra on E_{b*}. Rho baseline 0.886 sqrt(#G) ~ 2^{N/2} group ops (KR-RHO-13bf67). Transport is exact (KR-RHO-755e35).
 W = (t_mix + 1/delta) c_step, delta = density of the favourable family inside the class, c_step = cost of one ell-isogeny step
   (roots of Phi_ell(j, Y) over F_{2^N}; for ell = 3 a quartic: about 16N + small field multiplications, vs about 12 for one
   point addition, so c_step / c_op = O(10..30), to be MEASURED, not assumed).
 T_IC(b) = (#attempts per relation) x (#relations ~ |FB|) x (Macaulay cost c(D)) + LA, attempts ~ 1/s(b) for small s.
   c(D) ~ N_D^{omega'}, N_D = sum_{i<=D} C(2k, i), omega' <= 3 (dense) or ~2.4.
 Gain of degree D - Delta over D: factor rho_Delta = (N_D / N_{D-Delta})^{omega'}; N = 11, k = 6, D = 5: N_5/N_4 = 1586/794 ~ 2.0,
   so Delta = 1 is a factor ~2^{omega'} ~ 8 (dense), a polynomial constant. Exponent change needs Delta = Theta(D), i.e. a
   constant FRACTION of the degree, or yield inflation 2^{Omega(N)}.
 Walk <= rho needs delta >= c_step 2^{-N/2} (c_step in group ops): with c_step ~ 30 this is delta >= 0.65 at N = 11, 0.03 at N = 20.
 So at the toy sizes of draft-2 and draft-3 the economic condition (cheap walk) is vacuous; the toy tests can only settle whether
 a structural advantage exists, not whether it pays. This is stated, not hidden.
 Total: T(b*) < rho requires delta >= c_step 2^{-N/2} AND T_IC(b*) < 2^{N/2}; the second is not known to hold for ANY binary
 curve of prime degree (KR-IC-1fcdbc), so a gap on a rare family is useful only if it makes T_IC cross rho, i.e. gamma large in
 T_IC(b*) <= 2^{-gamma N} T_IC(b_typ).

## 2. Ceiling attainment (consequence of F3 of draft-2)
Rank side: r_d(b) <= rho_hat_d for all b. Let phi_d = fraction of b attaining rho_hat_d. If phi_d >= phi_0 then a class with m
independent sigma-orbits has NO attaining member with probability (1 - phi_0)^m. With the corank law (alpha = 0.2888 for the
generic-rank event) phi_0 ~ 0.29 per independent rank condition: P(no attaining member) = 0.25 (m = 4), 0.09 (m = 7), 0.016 (m = 12)
per condition. The favourable member on the rank side is therefore a typical member, not a rare one, whenever phi_0 is constant;
the walk buys no rank-side gain. Rare families on the rank side are RANK-DEFICIENT (worse), because specialisation can only lower
rank.
Yield side: Var(s) <= s_bar (3k+2)/2 (draft-3 envelope) gives overdispersion O(k) only; the tail histogram of draft-3 decides.

## 3. Two regimes of how the curve enters (scope map)
 R-free : curve over the whole field, b a free N-bit right-hand side (draft-2). Favourable families are affine/determinantal
          loci of the pencil; class contains ~2^{N/2} b.
 R-base : curve over F_q = F_{2^l}, extension F_{q^n}, x_i in F_q (Gaudry/Joux-Vitse regime). b lies in an l-dimensional
          subspace of the N = ln bit RHS; the b-set of a class over F_{q^n} meets it in about h q^{1-n} points, i.e. a class
          contains a base-field curve with probability about q^{1-n/2} for h ~ q^{n/2}. Not measured here; the degree growth in
          that regime comes from m, n (Joux-Vitse), not from the curve.
 Odd characteristic: (a, b) both enter polynomially; the exceptional locus is an algebraic curve in the (a,b)-plane;
          covered for prime fields by RQ-DREG-c8ae8d proposals; untouched here.

## 4. Mixing-time heuristic (re-randomisation, per the exemplar profile)
Random walks on the ell-isogeny graph of a class mix in O(log h) steps under GRH (Jao-Miller-Venkatesan, recalled), on the
horizontal level; so after t_mix the walk is a uniform class member and the hitting time of a density-delta family is 1/delta.
Validation: at N = 9, 11, 13 build the ell = 3, 5 graphs on each class from Phi_ell roots, compute the second singular value
against the Ramanujan value 2 sqrt(ell)/(ell+1) (normalised), and the simulated hitting time of the top-decile-deficit set of
draft-2 against 1/delta. Graph over the 2-isogeny is useless in characteristic 2 (draft-1: sigma-cycles).

## 5. Which of the two conditions
Both, by construction: condition 1 (cheap walk) is priced by W; condition 2 (gap grows with N) by the rank-attainment and yield
tails. Outcome table:
 - phi_d constant and yield tail light: no rank gain, yield gain O(k): ECDLP exponent unchanged; the lane's remaining value is
   building blocks (nulls, orbit counts).
 - phi_d decays with N (rare attainers) or the yield tail grows like 2^{cN}: a real family exists, the break-even table above
   says what density and gain would pay.
