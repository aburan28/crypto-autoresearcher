# IDEA-20261024-3c71a9 - notes (sketch derivation, not evidence)

Everything below is a hand derivation made while proposing. It is to be proved or refuted at
`/design-experiment`, before any panel. Nothing here is a result.

## Setting

`K = F_{q^n}`, `q` odd, `n` an odd prime, `sigma` the `q`-Frobenius, `N = N_{K/F_q}`.
`x in K \ F_q` has orbit exactly `n` (no intermediate field, which is where prime `n` enters).
`B' = {e_i = sigma^{a_i} x}`, four distinct points; `E_c : y^2 = c prod (X - e_i)`, all four branch
points `K`-rational, so `E_c[2]` is rational. `c` and `c d` (`d` a nonsquare of `K`) are the two `K`-twists
with the same branch set, hence the same genus.

## Step 1: squares in K are norms

`N: K^* -> F_q^*` is onto and `N(g^k) = h^k` with `h = N(g)` a generator of `F_q^*` for a generator `g`. So
`z` is a square in `K` iff `N(z)` is a square in `F_q`, for every `n`. The `n`-odd content is only
`N(-z) = -N(z)`.

## Step 2: orbit differences

`N(sigma^i x - sigma^k x) = N(x - sigma^{k-i} x) =: c_{k-i}`, and `c_{-j} = N(sigma^j x - x) = -c_j`.

## Step 3: the Jacobian and its halvable 2-torsion

For the quartic `w^2 = c f(X)` with roots `e_i`, the resolvent roots
`theta_1 = e1e2+e3e4`, `theta_2 = e1e3+e2e4`, `theta_3 = e1e4+e2e3` satisfy
`theta_1-theta_2 = (e1-e4)(e2-e3)`, `theta_1-theta_3 = (e1-e3)(e2-e4)`, `theta_2-theta_3 = (e1-e2)(e3-e4)`.
The Jacobian is `Y^2 = prod (X - rho_i)` with `rho_i = kappa c theta_i` (kappa a universal constant, recalled,
to be fixed at design). A 2-torsion point `(rho_i, 0)` lies in `2E(K)` iff both `rho_i - rho_j`, `rho_i - rho_k`
are squares in `K`.

## Step 4: n = 5, B' = {e_1..e_4} = {sigma^1 x, ..., sigma^4 x}

`N(d_12 d_34) = c_1^2`, `N(d_13 d_24) = c_2^2`, `N(d_14 d_23) = c_3 c_1 = -c_1 c_2`. Put `u = chi_q(N(kappa c))`,
`s = chi_q(-c_1 c_2)`, `eps = chi_q(-1)`. With the orientation `rho_1-rho_2 ~ u s`, `rho_1-rho_3 ~ u`,
`rho_2-rho_3 ~ u`:

- `P_1` halvable iff `u = 1` and `s = 1`;
- `P_2` halvable iff `u = 1` and `eps s = 1`;
- `P_3` halvable iff `eps u = 1`.

| eps | u | s | halvable | `|E(K)[4]|` |
| --- | --- | --- | --- | --- |
| -1 | 1 | 1 | P_1 | 8 |
| -1 | 1 | -1 | P_2 | 8 |
| -1 | -1 | any | P_3 | 8 |
| 1 | 1 | 1 | all | 16 |
| 1 | 1 | -1 | P_3 | 8 |
| 1 | -1 | any | none | 4 |

Reading: at `eps = -1` every curve has exactly order 8 (`Z/2 x Z/4` at the 4-level), consistent with
`mu_4 not in K`. At `eps = +1` the twist flip `u -> -u` (multiplying `c` by a nonsquare `d` has
`chi_q(N d) = -1`) sends a `u = 1` curve to a `u = -1` curve with the same `s`, so exactly one twist of each pair
has order 4. `#E(K)[4] = 4 |H|`, `H` the subgroup of halvable 2-torsion points.

## Consistency with the sibling data (read after deriving; not used to fit)

At `q = 3` (`eps = -1`): sibling reports genus 5 only with `#E(K)[4] = 8`, 20 of 60 such curves, 0 of 21 with 4.
The class minima by `v_2`: genus 5 reached for `v_2 = 3` (40) and `v_2 = 4` (40), never for `v_2 = 2`. The law needs
`8 | #E(K)` at `eps = -1`, and `v_2` is an isogeny-class invariant, so `v_2 = 2` classes cannot contain a
genus-5 curve there. This matches; it is a necessary-condition match, not a test.

## What the out-of-sample tests are

(a) `q = 5, 9, 13`: order-4 curves appear, one per twist pair, and 16 appears. (b) `n = 7`, pattern
`S = {0,2,3,4}`: differences `N(d_ik) = c_{a_k - a_i}` with `c_1, c_2, c_3` (three sign bits plus eps);
the three Plucker products give a table to be derived. (c) `eps = -1` at `q = 7, 11` separates the law from
characteristic 3.

## Enumeration cost

Configurations `5 (q^5 - q)/(q^3 - q)` at `n = 5`: 130 at `q = 5`, 250 at `q = 7`, 410 at `q = 9`, 610 at
`q = 11`, 850 at `q = 13`; each with two twists. `F_{q^5}` has at most 371 293 elements at `q = 13`.
`#E(K)` and the group structure follow from point counting over `K` and a cofactor search.

## What would show the idea is wrong

A genus-5 curve at `eps = -1` with `|E(K)[4]| != 8` (the Plucker or kappa bookkeeping is wrong), or an
`eps = +1` panel in which order 4 does not occur (then the twist-flip argument fails).
