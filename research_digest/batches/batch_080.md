# Batch 080 digest

## Overview
- Two clear sub-batches: a ~2008 CHES-style cluster (filenames 515402xx–515404xx) on side-channel/fault attacks and compact crypto hardware, and a Crypto-2008 cluster (515700xx) on theory — MPC, hash-function provable security, and public-key primitives.
- Heavy representation from Bochum, K.U. Leuven/COSIC, and IAIK Graz groups; recurring authors include Preneel, Paar, Rechberger, Verbauwhede, Ostrovsky, Vaikuntanathan.
- Notable papers: Bernstein–Lange–Farashahi "Binary Edwards Curves" (complete addition formulas in characteristic 2); the KeeLoq DPA break (Eisenbarth et al.); Biham–Carmeli–Shamir "Bug Attacks"; Coron–Patarin–Seurin ROM/ideal-cipher equivalence; Peikert–Vaikuntanathan lattice NISZK.
- ECC-specific content is sparse in this batch: only Binary Edwards Curves, the EC Diffie–Hellman hardcore-bits paper, and the GF(2^m) bit-serial multiplier; most content is symmetric crypto, side channels, and generic MPC/theory.
- Anomalies: two 1-page invited-talk abstracts (51540441.pdf Intel platform security; 53500055.pdf Yao complexity-crypto talk), one file with garbled glyph extraction (51570297.pdf), and one unusually short filename (530.pdf).

## Papers
- **51540224.pdf** — Attacking State-of-the-Art Software Countermeasures—A Case Study for AES (Stefan Tillich, Christoph Herbst). Applies advanced DPA methods to break a masked/time-randomized AES software implementation on a smart card, refining the attacks; effort is ~100x that of attacking an unprotected implementation.
- **51540240.pdf** — Binary Edwards Curves (Daniel J. Bernstein, Tanja Lange, Reza Rezaeian Farashahi). New curve shape over characteristic-2 fields giving the first complete addition and doubling formulas for ordinary binary elliptic curves, plus efficient differential-addition formulas for Montgomery ladders.
- **51540262.pdf** — A Real-World Attack Breaking A5/1 within Hours (Timo Gendrullis, Martin Novotný, Andy Rupp). Hardware attack on GSM's A5/1 cipher using COPACOBANA; recovers the 64-bit internal state from 64 known keystream bits in ~6 hours average.
- **51540279.pdf** — Hash Functions and RFID Tags: Mind the Gap (Bogdanov, Leander, Paar, Poschmann, Robshaw, Seurin). Surveys options for on-tag hash functions for RFID, showing the difficulty of lightweight hash design and urging caution about assuming hashes in RFID protocols.
- **51540296.pdf** — A New Bit-Serial Architecture for Field Multiplication Using Polynomial Bases (Arash Reyhani-Masoleh). Proposes a serial-output bit-serial GF(2^m) multiplier for polynomial bases with one-cycle latency, targeting area-constrained ECC hardware like smart cards.
- **51540311.pdf** — A Very Compact Hardware Implementation of the MISTY1 Block Cipher (Dai Yamamoto, Jun Yajima, Kouichi Itoh). Compact ASIC design of MISTY1 via optimized FO/FI implementations, achieving 3.95 Kgates — the smallest known at the time.
- **51540327.pdf** — Light-Weight Instruction Set Extensions for Bit-Sliced Cryptography (Philipp Grabher, Johann Großschädl, Dan Page). Generic instruction-set extensions that speed up bit-sliced software crypto while retaining small memory footprint and timing-attack resistance; demonstrated on DES, Serpent, AES, PRESENT, SHA-1.
- **51540342.pdf** — Power and Fault Analysis Resistance in Hardware through Dynamic Reconfiguration (Nele Mentens, Benedikt Gierlichs, Ingrid Verbauwhede). Uses FPGA dynamic reconfiguration to port software-style countermeasures to hardware and to randomize physical block placement, raising resistance to power and fault attacks.
- **51540359.pdf** — RFID and its Vulnerability to Faults (Michael Hutter, Jörn-Marc Schmidt, Thomas Plos). Empirically shows commercial HF/UHF RFID tags are highly vulnerable to global and laser-induced faults during memory writes, enabling blocked or corrupted writes while tags report success.
- **51540376.pdf** — Perturbating RSA Public Keys: an Improved Attack (Alexandre Berzati, Cécile Canovas, Louis Goubin). New fault attack on RSA public-key elements under a natural fault model, more efficient than prior attacks, with experimental confirmation on GMP; argues public keys need protection too.
- **51540392.pdf** — Divided Backend Duplication Methodology for Balanced Dual Rail Routing (Karthik Baddam, Mark Zwolinski). Circuit-routing method accounting for coupling capacitance to balance dual-rail precharge logic against DPA, validated on AES in 130nm and on FPGA.
- **51540408.pdf** — Using Subspace-Based Template Attacks to Compare and Combine Power and Electromagnetic Information Leakages (F.-X. Standaert, C. Archambeau). Compares power vs EM side channels, studies their combination, and evaluates PCA/Fisher LDA for dimensionality reduction in template attacks.
- **51540423.pdf** — Mutual Information Analysis: A Generic Side-Channel Distinguisher (Gierlichs, Batina, Tuyls, Preneel). Introduces an information-theoretic distinguisher using mutual information between measurements and hypothetical leakage, working without knowledge of the leakage function; validated on DPA-resistant logic.
- **51540441.pdf** — A Vision for Platform Security (Ernie Brickell). One-page invited-talk abstract reviewing Intel's new platform security capabilities; not a research paper.
- **51570001.pdf** — The Random Oracle Model and the Ideal Cipher Model are Equivalent (Jean-Sébastien Coron, Jacques Patarin, Yannick Seurin). Shows a 6-round Feistel network constructs an ideal cipher from a random oracle (5 rounds insufficient), settling the open direction of ROM/ICM equivalence.
- **51570021.pdf** — Programmable Hash Functions and Their Applications (Dennis Hofheinz, Eike Kiltz). Introduces programmable hash functions that embed solved/unsolved discrete-log instances, enabling black-box proofs under adaptive attacks and short standard-model signatures from strong RSA and bilinear assumptions.
- **51570039.pdf** — One-Time Programs (Shafi Goldwasser, Yael Tauman Kalai, Guy N. Rothblum). Defines one-time (and k-time) programs executable on a single input that self-destruct afterward, enabling applications beyond obfuscation such as electronic cash and temporary transfer of cryptographic ability.
- **51570057.pdf** — Adaptive One-way Functions and Applications (Omkant Pandey, Rafael Pass, Vinod Vaikuntanathan). Proposes new strong complexity-theoretic assumptions abstracting random-oracle properties, resolving open problems including non-malleable commitments and non-malleable zero knowledge.
- **51570075.pdf** — Bits Security of the Elliptic Curve Diffie–Hellman Secret Keys (Dimitar Jetchev, Ramarathnam Venkatesan). Proves least significant bits of ECDH secrets are hardcore via random self-reducibility across isogenous curves (assuming GRH), with a refinement of Lenstra's isogeny-class size bounds.
- **51570093.pdf** — Improved Bounds on Security Reductions for Discrete Log Based Signatures (Sanjam Garg, Raghav Bhaskar, Satyanarayana Lokam). Strengthens the Paillier–Vergnaud negative result: any algebraic ROM reduction from discrete log to forging Schnorr signatures must lose at least a q_h^{2/3} factor.
- **51570109.pdf** — Circular-Secure Encryption from Decision Diffie-Hellman (Boneh, Halevi, Hamburg, Ostrovsky). Constructs the first public-key encryption scheme provably circular-secure (safe under key-cycle encryption) under DDH without random oracles.
- **51570127.pdf** — Public-Key Locally-Decodable Codes (Brett Hemenway, Rafail Ostrovsky). Defines public-key encryption that is also a locally decodable code, built generically from semantically secure PKE plus PIR, yielding linear-size ciphertexts with sublinear decoding.
- **51570145.pdf** — Key-Recovery Attacks on Universal Hash Function based MAC Algorithms (Helena Handschuh, Bart Preneel). Gives key-recovery and universal-forgery attacks on several universal-hash-based MACs using verification queries, showing such MACs are less robust than conventional primitives.
- **51570163.pdf** — Cryptanalysis of the GOST Hash Function (Mendel, Pramstaller, Rechberger, Kontak, Szmidt). Presents the first collision attack on the GOST 34.11-94 hash (~2^105 compression evaluations) plus improved preimage and second-preimage attacks (~2^192).
- **51570180.pdf** — Preimages for Reduced SHA-0 and SHA-1 (Christophe De Cannière, Christian Rechberger). Develops new techniques (reversed inversion, P3graphs) yielding shortcut preimage attacks on up to 45 steps of SHA-1 and 50 steps of SHA-0 out of 80.
- **51570204.pdf** — On the Power of Power Analysis in the Real World: A Complete Break of the KeeLoq Code Hopping Scheme (Eisenbarth, Kasper, Moradi, Paar, Salmasizadeh, Manzuri Shalmani). First successful DPA on commercial KeeLoq products, cloning remotes from ten power traces and recovering manufacturer keys; key cloning even possible by eavesdropping two messages.
- **51570222.pdf** — Bug Attacks (Eli Biham, Yaniv Carmeli, Adi Shamir). Shows that rare hardware multiplication bugs (like the Pentium FDIV bug) can fully leak secret keys of RSA (even with OAEP), Pohlig–Hellman, and ECC, sometimes with a single chosen ciphertext.
- **51570242.pdf** — Scalable Multiparty Computation with Nearly Optimal Work and Resilience (Damgård, Ishai, Krøigaard, Nielsen, Smith). First general MPC protocol whose total work grows only polylogarithmically in the number of players, with resilience against an active adaptive adversary corrupting nearly half the players.
- **51570262.pdf** — Cryptographic Complexity of Multi-party Computation Problems: Classifications and Separations (Manoj Prabhakaran, Mike Rosulek). Develops UC-framework tools to classify and separate MPC tasks, rederiving known impossibility results and completing the combinatorial characterization of two-party SFE.
- **51570280.pdf** — Cryptanalysis of MinRank (Jean-Charles Faugère, Françoise Levy-dit-Vehel, Ludovic Perret). New modeling and Gröbner-basis attack on the MinRank problem underlying multivariate cryptography, solving Courtois's challenges and giving a polynomial-time attack when the rank defect is constant.
- **51570297.pdf** — (title unreadable, ?). Extracted text is garbled glyph/font-encoding output (e.g. "/C6/CT/DB..."); appears to be a paper on cache attacks mentioning Intel Core 2, but content cannot be reliably determined.
- **51570317.pdf** — Dynamic Threshold Public-Key Encryption (Cécile Delerablée, David Pointcheval). Generalizes threshold PKE to dynamic join, dynamic recipient sets, and dynamic thresholds with constant-size ciphertexts, proven secure under a new bilinear Diffie–Hellman-exponent assumption.
- **51570335.pdf** — On Notions of Security for Deterministic Encryption, and Efficient Constructions Without Random Oracles (Boldyreva, Fehr, O'Neill). Proposes a slightly weakened but practical security notion for deterministic PKE and gives CPA/CCA constructions without random oracles building on the Peikert–Waters framework.
- **51570377.pdf** — Communication Complexity in Algebraic Two-Party Protocols (Rafail Ostrovsky, William E. Skeith III). Characterizes which two-party protocols can be realized with low communication from black-box homomorphic encryption, providing lower bounds covering essentially all known homomorphic cryptosystems.
- **51570395.pdf** — Beyond Uniformity: Better Security/Efficiency Tradeoffs for Compression Functions (Martijn Stam). Conjectures a general collision-resistance bound for multi-call compression functions and gives constructions beating the Rogaway–Steinberger bounds by dropping the uniformity assumption.
- **51570413.pdf** — Compression from Collisions, or why CRHF Combiners have a Long Output (Krzysztof Pietrzak). Proves an essentially tight lower bound on the output length of black-box combiners for collision-resistant hash functions, matching the Canetti et al. construction.
- **51570433.pdf** — Constructing Cryptographic Hash Functions from Fixed-Key Blockciphers (Phillip Rogaway, John Steinberger). Designs compression functions from fixed-key permutations with near-optimal collision/preimage security in the ideal-cipher model, e.g. a 2n-to-n bit function with N^0.5 collision security.
- **51570451.pdf** — Distributed Private Data Analysis: Simultaneously Solving How and What (Amos Beimel, Kobbi Nissim, Eran Omri). Studies combining secure function evaluation with differential privacy, showing when jointly choosing what and how to compute beats the sequential paradigm for sums, thresholds, and medians.
- **51570469.pdf** — New Efficient Attacks on Statistical Disclosure Control Mechanisms (Cynthia Dwork, Sergey Yekhanin). Simplifies and sharpens Dinur–Nissim-style attacks on low-distortion statistical-database privacy mechanisms, with an attack revealing each secret bit after only a fixed number of queries.
- **51570482.pdf** — Efficient Secure Linear Algebra in the Presence of Covert or Computationally Unbounded Adversaries (Payman Mohassel, Enav Weinreb). Secure protocols for matrix singularity, rank, and linear systems with O(n^{2+1/t}) communication, secure against covert adversaries or unbounded adversaries controlling under a third of parties.
- **51570500.pdf** — Collusion-Free Protocols in the Mediated Model (Joël Alwen, abhi shelat, Ivan Visconti). Builds collusion-free protocols over a filtering/rerandomizing mediated channel, with security gracefully degrading to standard privacy if the mediator is corrupted; constructs commitments and ZK proofs of knowledge.
- **51570518.pdf** — Efficient Constructions of Composable Commitments and Zero-Knowledge Proofs (Yevgeniy Dodis, Victor Shoup, Shabsi Walfish). Dramatically improves efficiency of GUC-secure commitments and zero knowledge: constant-round GUC ZK from dense Omega-protocols and the first constant-rate GUCC scheme.
- **51570538.pdf** — Noninteractive Statistical Zero-Knowledge Proofs for Lattice Problems (Chris Peikert, Vinod Vaikuntanathan). First NISZK proofs for cryptographically useful non-factoring problems, covering SIVP and coSVP with efficient provers and proofs of knowledge.
- **51570556.pdf** — A Framework for Efficient and Composable Oblivious Transfer (Peikert, Vaikuntanathan, Waters). General "dual-mode cryptosystem" framework yielding round-optimal, universally composable OT from DDH, quadratic/composite residuosity, or worst-case lattice assumptions.
- **51570574.pdf** — Founding Cryptography on Oblivious Transfer – Efficiently (Yuval Ishai, Manoj Prabhakaran, Amit Sahai). Efficient compiler, via "MPC in the head," transforming honest-majority MPC protocols into ones secure without an honest majority in the OT-hybrid model.
- **530.pdf** — Verifier-Local Revocation Group Signature Schemes with Backward Unlinkability from Bilinear Maps (Toru Nakanishi, Nobuo Funabiki). Group signatures with verifier-local revocation that additionally preserve backward unlinkability, fixing a deficiency of the Boneh–Shacham scheme, using bilinear maps.
- **53500019.pdf** — Strongly Multiplicative and 3-Multiplicative Linear Secret Sharing Schemes (Zhang, Liu, Chee, Ling, Wang). Introduces 3-multiplicative LSSS, relates it to strongly multiplicative LSSS, and applies it to cut unbounded fan-in multiplication round complexity from five to four.
- **53500037.pdf** — Graph Design for Secure Multiparty Computation over Non-Abelian Groups (Xiaoming Sun, Andrew Chi-Chih Yao, Christophe Tartary). Extends Desmedt et al.'s black-box group MPC results using percolation theory, achieving t-private n-product computation for t up to ~n/(2+epsilon) with O(n^3) communication.
- **53500055.pdf** — Some Perspectives on Complexity-Based Cryptography (Andrew Chi-Chih Yao). One-page invited-talk abstract surveying complexity-based cryptography and open questions; not a research paper.
- **53500056.pdf** — A Modular Security Analysis of the TLS Handshake Protocol (P. Morrissey, N.P. Smart, B. Warinschi). Modular provable-security analysis of the TLS handshake, formally modeling pre-master/master/application keys and proving generic composition results for TLS key derivation.
