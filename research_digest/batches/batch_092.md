# Batch 092 digest

## Overview
- Dominated by ~2011-era conference papers (EUROCRYPT/FSE/LNCS-style extracts): heavy symmetric cryptanalysis (SHA-3 candidates ECHO, BLAKE, Keccak, Luffa, SHAvite-3, Hamsi; block ciphers PRINTcipher, GOST, PRESENT; stream ciphers Grain-128, RC4, Hummingbird-1, knapsack generator).
- A strong public-key cluster opens the batch: KDM-secure encryption (Malkin/Teranishi/Yung; Applebaum), Lewko–Waters HIBE/ABE works, threshold/revocation schemes (Wee), deniable encryption (Dürmuth–Freeman).
- Later papers shift to secure computation and delegation: verifiable computation, memory delegation, web-model MPC, BGW multiplication, IPS compiler, 1/p-secure MPC.
- Notable leakage/side-channel cluster at the end: leakage-resilient ZK, key evolution under space-bounded leakage, MIA evaluation, generic side-channel distinguishers.
- Notable individual papers: Isobe's first single-key attack on full GOST; Dinur–Shamir dynamic cube attacks on Grain-128; EasyCrypt computer-aided proofs.
- Anomalies: 667slides.pdf is a slide deck (Krawczyk AWS Crypto 2023 talk), not a research paper; 679.pdf is an unusually short filename but a real paper. No obvious duplicates (two PRINTcipher papers are distinct works).

## Papers
- **66320511.pdf** — Efficient Circuit-Size Independent Public Key Encryption with KDM Security (Malkin, Teranishi, Yung). KDM-secure PKE for functions computable by modular arithmetic circuits, with parameters independent of circuit size and number of users.
- **66320531.pdf** — Key-Dependent Message Security: Generic Amplification and Completeness (Benny Applebaum). First generic KDM amplification theorem, boosting projection-KDM security to any fixed polynomial-time function class without extra assumptions.
- **66320551.pdf** — Unbounded HIBE and Attribute-Based Encryption (Lewko, Waters). HIBE/ABE without setup-fixed depth or attribute bounds, proven secure via nested dual system encryption under static assumptions.
- **66320571.pdf** — Decentralizing Attribute-Based Encryption (Lewko, Waters). Multi-authority ABE with no central authority or coordination, achieving collusion resistance via dual system encryption techniques.
- **66320591.pdf** — Threshold and Revocation Cryptosystems via Extractable Hash Proofs (Hoeteck Wee). Unifying framework for non-interactive threshold encryption/signatures and broadcast encryption from factoring, supporting ad-hoc groups.
- **66320611.pdf** — Deniable Encryption with Negligible Detection Probability: An Interactive Construction (Dürmuth, Freeman). First sender-deniable PKE with a single encryption algorithm and negligible detection probability, from quadratic residuosity or trapdoor permutations.
- **667slides.pdf** — The Joy of Cryptography: A Personal Journey (Hugo Krawczyk). Conference slide deck (AWS Crypto 2023 retrospective talk), not a research paper.
- **67330001.pdf** — Differential Cryptanalysis of Round-Reduced PRINTcipher: Computing Roots of Permutations (Abdelraheem, Leander, Zenner). First cryptanalysis of PRINTcipher: differential attacks breaking about half the rounds via a permutation-root technique.
- **67330018.pdf** — Search for Related-key Differential Characteristics in DES-like Ciphers (Biryukov, Nikolić). First automatic search algorithms for best related-key differential characteristics in DES, DESL, and s2DES.
- **67330035.pdf** — Multiple Differential Cryptanalysis: Theory and Practice (Blondeau, Gérard). Formalizes multiple differential cryptanalysis with complexity/success-probability analysis, validated on reduced PRESENT (attack on 18 rounds).
- **67330055.pdf** — Fast Correlation Attacks: Methods and Countermeasures (Willi Meier). Survey of two decades of fast correlation attacks on LFSR-based stream ciphers and resulting design criteria.
- **67330068.pdf** — Analysis of Reduced-SHAvite-3-256 (Minier, Naya-Plasencia, Peyrin). First independent analysis of tweaked SHAvite-3-256: rebound/Super-Sbox distinguishers to 8 rounds and free-start collisions to 7.
- **67330090.pdf** — An Improved Algebraic Attack on Hamsi-256 (Dinur, Shamir). Algebraic second-preimage attack on Hamsi-256 beating generic attacks for practical message sizes via fast low-degree polynomial evaluation.
- **67330109.pdf** — Practical Near-Collisions and Collisions on Round-Reduced ECHO-256 Compression Function (Jean, Fouque). Collision attack on 4-round ECHO-256 compression function in 2^52, with practical near-collisions, also fixing flaws in prior analyses.
- **67330131.pdf** — On Cipher-Dependent Related-Key Attacks in the Ideal-Cipher Model (Albrecht, Farshim, Paterson, Watson). Shows a generic related-key attack exploiting short cipher descriptions, separating ideal-cipher model RKD security from standard-model security.
- **67330151.pdf** — On the Security of Hash Functions Employing Blockcipher Postprocessing (Chang, Nandi, Yung). Proves Davies-Meyer-type output transforms preserve pseudorandom-oracle property when the hash is preimage-aware plus a new "computable message awareness" notion.
- **67330172.pdf** — Breaking Grain-128 with Dynamic Cube Attacks (Dinur, Shamir). New dynamic cube attack recovering full Grain-128 key with 207 initialization rounds, plus best-known attacks on fuller versions.
- **67330193.pdf** — Cryptanalysis of the Knapsack Generator (Knellwolf, Meier). Guess-and-determine attacks on the Rueppel–Massey knapsack stream-cipher generator; practical for small RFID-relevant instances, and a recent variant shown insecure.
- **67330204.pdf** — Attack on Broadcast RC4 Revisited (Maitra, Paul, Sen Gupta). Disproves Mantin–Shamir: finds biases toward zero in RC4 keystream bytes 3–255, yielding distinguishers and extended broadcast plaintext recovery.
- **67330224.pdf** — Boomerang Attacks on BLAKE-32 (Biryukov, Nikolić, Roy). High-probability differentials enable boomerang attacks on 8-round BLAKE-32 keyed permutation and practical distinguishers on the compression function.
- **67330258.pdf** — Higher-Order Differential Properties of Keccak and Luffa (Boura, Canteaut, De Cannière). New degree bound for iterated permutations yields zero-sum partitions of size 2^1575 for full Keccak-f and distinguishers on Luffa.
- **67330277.pdf** — Cryptanalysis of PRESENT-like Ciphers with Secret S-boxes (Borghoff, Knudsen, Leander, Thomsen). Practical break of a 2009 PRESENT variant with key-dependent S-boxes; extrapolates to ~28 rounds.
- **67330297.pdf** — A Single-Key Attack on the Full GOST Block Cipher (Takanori Isobe). First key-recovery attack on full GOST for all key classes, via a new reflection-meet-in-the-middle framework, in 2^225 time.
- **67330313.pdf** — The Software Performance of Authenticated-Encryption Modes (Krovetz, Rogaway). Benchmarks CCM, GCM, OCB across platforms; OCB substantially fastest, with algorithmic trims proposed; contradicts earlier GCM≈OCB claims.
- **67330334.pdf** — Cryptanalysis of Hummingbird-1 (Saarinen). Chosen-IV/chosen-message attack recovering the full 256-bit key of lightweight cipher Hummingbird-1, demonstrated on a real implementation.
- **67330350.pdf** — The Additive Differential Probability of ARX (Velichkov, Mouha, De Cannière, Preneel). First efficient linear-time algorithm (via extended S-functions) to compute additive differential probability of addition-rotation-XOR sequences.
- **67330367.pdf** — Linear Approximations of Addition Modulo 2^n−1 (Zhou, Feng, Wu). Explicit/iterative correlation formulas for linear approximations of k-input addition mod 2^n−1, motivated by ZUC stream cipher analysis.
- **67330386.pdf** — Meet-in-the-Middle Preimage Attacks on AES Hashing Modes and an Application to Whirlpool (Yu Sasaki). Open-key MITM preimage attacks on 7-round AES in Davies-Meyer/MMO/Miyaguchi-Preneel hashing modes, reaching best round counts.
- **67330405.pdf** — Known-Key Distinguishers on 11-Round Feistel and Collision Attacks on Its Hashing Modes (Sasaki, Yasuda). Rebound-based known-key distinguishers on 11-round SP Feistel ciphers, converted to collision attacks on MMO/MP hashing modes.
- **679.pdf** — Universally Convertible Directed Signatures (Laguillaumie, Paillier, Vergnaud). Solves the 1993 open problem of universal conversion for directed signatures efficiently using bilinear-map "xyz-trick", secure in ROM.
- **68410001.pdf** — Leftover Hash Lemma, Revisited (Barak, Dodis, Krawczyk, Pereira, Pietrzak, Standaert, Yu). Reduces entropy loss and seed length of LHL-based extractors in key-derivation and other important settings.
- **68410021.pdf** — Random Oracle Reducibility (Baecher, Fischlin). Defines reductions between random oracles of different schemes, enabling hierarchical comparison of ROM-based assumptions and transfer of uninstantiability results.
- **68410039.pdf** — Time-Lock Puzzles in the Random Oracle Model (Mahmoody, Moran, Vadhan). Negative result: rules out random-oracle time-lock puzzles requiring more parallel solving time than generation time.
- **68410051.pdf** — Physically Uncloneable Functions in the Universal Composition Framework (Brzuska, Fischlin, Schröder, Katzenbeisser). Models PUFs (with their non-programmability) in UC, yielding UC-secure oblivious transfer, commitments, and key exchange.
- **68410071.pdf** — Computer-Aided Security Proofs for the Working Cryptographer (Barthe, Grégoire, Heraud, Zanella Béguelin). Introduces EasyCrypt, compiling game-based proof sketches into verified CertiCrypt proofs; applied to Cramer-Shoup and hashed ElGamal.
- **68410091.pdf** — Optimal Verification of Operations on Dynamic Sets (Papamanthou, Tamassia, Triandopoulos). Authenticated data structures via bilinear-map accumulators and accumulation trees for verifiable outsourced set operations with optimal complexities.
- **68410110.pdf** — Verifiable Delegation of Computation over Large Datasets (Benabbas, Gennaro, Vahlis). First practical verifiable computation for high-degree polynomials under DDH with adaptive security, plus a verifiable database primitive.
- **68410128.pdf** — Secure Computation on the Web: Computing without Simultaneous Interaction (Halevi, Lindell, Pinkas). Initiates client-server secure computation where clients connect once non-simultaneously, with feasibility results and practical protocols.
- **68410147.pdf** — Memory Delegation (Chung, Kalai, Liu, Raz). Delegating computation on huge/streaming data to the cloud while the delegator keeps only a short certificate and runs sublinear in input length.
- **68410165.pdf** — Automatic Search of Attacks on Round-Reduced AES and Applications (Bouillaguet, Derbez, Fouque). Automated tools finding guess-and-determine/MITM attacks on AES, improving attacks on Alpha-MAC, Pelican-MAC, LEX, and fault attacks.
- **68410184.pdf** — How to Improve Rebound Attacks (Naya-Plasencia). General algorithmic improvements to the list-merging bottleneck of rebound attacks, lowering complexities of many SHA-3 candidate analyses.
- **68410202.pdf** — A Cryptanalysis of PRINTcipher: The Invariant Subspace Attack (Leander, Abdelraheem, AlKhzaimi, Zenner). New invariant-subspace weak-key attack breaking full PRINTcipher for a significant key fraction, with implications for other attack types.
- **68410219.pdf** — The PHOTON Family of Lightweight Hash Functions (Guo, Peyrin, Poschmann). Sponge-based AES-like lightweight hash family, most compact known (~1120 GE for 64-bit collision resistance) via serial mix-column generation.
- **68410237.pdf** — Perfectly-Secure Multiplication for any t < n/3 (Asharov, Lindell, Rabin). Full specification and proof of BGW perfect multiplication, a new step for n/4 ≤ t < n/3, plus an efficient bivariate-sharing protocol.
- **68410255.pdf** — The IPS Compiler: Optimizations, Variants and Concrete Efficiency (Lindell, Oxman, Pinkas). Improves and analyzes the IPS semi-honest-to-malicious compiler, including a covert-adversary variant and concrete efficiency study.
- **68410273.pdf** — 1/p-Secure Multiparty Computation without Honest Majority and the Best of Both Worlds (Beimel, Lindell, Omri, Orlov). Multiparty 1/p-secure (partially fair) protocols for general functionalities with polynomial-size ranges and constant party count.
- **68410293.pdf** — Leakage-Resilient Zero Knowledge (Garg, Jain, Sahai). Defines and constructs ZK proofs secure when the verifier obtains bounded leakage on the prover's entire state during execution; gives LR-NIZK and applications.
- **68410311.pdf** — A Comprehensive Evaluation of Mutual Information Analysis Using a Fair Evaluation Framework (Whitnall, Oswald). Fair, generic framework evaluating MIA-based DPA, identifying scenarios where mutual information outperforms other distinguishers.
- **68410330.pdf** — Key-Evolution Schemes Resilient to Space-Bounded Leakage (Dziembowski, Kazana, Wichs). Leakage-resilient key-evolution schemes where only the space of the leakage computation is bounded, avoiding pre-computation attacks.
- **68410348.pdf** — Generic Side-Channel Distinguishers: Improvements and Limitations (Veyrat-Charvillon, Standaert). New non-parametric copula-based distinguisher for high-dimensional leakages, plus experiments showing limits of generic attacks against protected devices.
