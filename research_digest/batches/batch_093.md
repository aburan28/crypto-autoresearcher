# Batch 093 digest

## Overview
- Two clear venue blocks: a Crypto 2011 (6841xxxx) theory cluster — post-quantum crypto, FHE, leakage resilience, deniable/OPE encryption — and a CHES 2011 (6917xxxx) hardware cluster — side-channel attacks/countermeasures, PUFs, lightweight ciphers, pairing/ECC implementations.
- Notable theory papers: Brakerski-Vaikuntanathan Ring-LWE FHE, Coron et al. integer FHE with shorter keys, Hanrot-Pujol-Stehlé BKZ dynamical-systems analysis, Bernstein-Lange-Peters ball-collision decoding, Abe et al. optimal structure-preserving signatures.
- Notable applied papers: Bernstein et al. Ed25519 high-speed signatures; Fan-Gierlichs-Vercauteren combined fault+side-channel ECC attack; Oswald-Paar DESFire key recovery; lightweight designs spongent, LED, Piccolo.
- Anomalies: 68410481 is a Tor invited-talk abstract (2p), and 69170274 is a 1-page EMC standardization presentation abstract — neither is a full research paper.
- ECC-relevant content is mostly implementation- and attack-oriented (Ed25519, binary-field scalar multiplication, fault/SCA on ECC, pairing hardware), not ECDLP-hardness results.

## Papers
- **68410367.pdf** — Cryptography with Tamperable and Leaky Memory (Kalai, Kanukurthi, Sahai). Constructs signature and encryption schemes secure when all memory is both arbitrarily leaky and tamperable, repeatedly and continually.
- **68410385.pdf** — Merkle Puzzles in a Quantum World (Brassard, Høyer, Kalach, Kaplan, Laplante, Salvail). Gives quantum-resistant Merkle-style key-agreement schemes and bounds on quantum eavesdropper effort, partially restoring security lost to Grover-type attacks.
- **68410405.pdf** — Classical Cryptographic Protocols in a Quantum World (Hallgren, Smith, Song). Shows classical two-party SFE of any polynomial function remains feasible against quantum adversaries under assumptions such as quantum-hard LWE.
- **68410423.pdf** — Position-Based Quantum Cryptography: Impossibility and Constructions (Buhrman et al.). Proves position verification is impossible against adversaries sharing arbitrary entanglement, via instantaneous non-local quantum computation, plus positive constructions.
- **68410441.pdf** — Analyzing Blockwise Lattice Algorithms using Dynamical Systems (Hanrot, Pujol, Stehlé). Proves BKZ can be terminated after polynomially many SVP calls while still returning near-Hermite-quality bases, giving first reasonable complexity bounds.
- **68410461.pdf** — Pseudorandom Knapsacks and the Sample Complexity of LWE Search-to-Decision Reductions (Micciancio, Mol). Proves bounded knapsack functions pseudorandom from one-wayness over general groups, yielding sample-preserving LWE search-to-decision reductions.
- **68410481.pdf** — Tor and circumvention: lessons learned (Dingledine). Abstract of an invited talk on Tor, bridge relays, and censorship events in 2011; not a research paper.
- **68410483.pdf** — Fully Homomorphic Encryption over the Integers with Shorter Public Keys (Coron, Mandal, Naccache, Tibouchi). Shrinks DGHV integer-FHE public keys from Õ(λ^10) to Õ(λ^7) via quadratic-form encryption, with first implementation.
- **68410501.pdf** — Fully Homomorphic Encryption from Ring-LWE and Security for Key Dependent Messages (Brakerski, Vaikuntanathan). Simple RLWE-based somewhat-homomorphic scheme, bootstrapped to FHE, proven secure for encrypting functions of its own secret key.
- **68410521.pdf** — Bi-Deniable Public-Key Encryption (O'Neill, Peikert, Waters). First noninteractive public-key schemes where sender and receiver can simultaneously fake randomness; includes a lattice-based construction.
- **68410539.pdf** — Better Security for Deterministic Public-Key Encryption: The Auxiliary-Input Setting (Brakerski, Segev). Formalizes deterministic PKE security when adversaries hold auxiliary information about the plaintext, with new constructions.
- **68410557.pdf** — The Collision Security of Tandem-DM in the Ideal Cipher Model (Lee, Stam, Steinberger). Fixes a flawed FSE 2009 analysis and proves birthday-bound collision resistance for the Tandem-DM double-block-length hash.
- **68410575.pdf** — Order-Preserving Encryption Revisited (Boldyreva, Chenette, O'Neill). Characterizes exactly what ideal order-preserving encryption leaks, and gives stronger-secure range-query schemes for known databases.
- **68410593.pdf** — A New Variant of PMAC: Beyond the Birthday Bound (Yasuda). PMAC Plus, a rate-1 three-key blockcipher MAC with O(2^{2n/3}) security versus PMAC's birthday bound.
- **68410607.pdf** — Authenticated and Misuse-Resistant Encryption of Key-Dependent Data (Bellare, Keelveedhi). Maps out AE security for key-dependent messages/headers, rules out three variants, and gives the cheap RHtE transform for the achievable one.
- **68410627.pdf** — Round Optimal Blind Signatures (Garg, Rao, Sahai, Schröder, Unruh). First two-move blind signature scheme in the standard model, from DDH and sub-exponentially hard one-to-one OWFs; concurrently secure.
- **68410646.pdf** — Optimal Structure-Preserving Signatures in Asymmetric Bilinear Groups (Abe, Groth, Haralambiev, Ohkubo). Proves 3 group elements are necessary and constructs matching optimal pairing-based structure-preserving signatures.
- **68410664.pdf** — Constant-Rate Oblivious Transfer from Noisy Channels (Ishai et al.). Realizes n OT instances with only O(n) bits over a binary symmetric channel, settling the constant-rate question for malicious security.
- **68410682.pdf** — The Torsion-Limit for Algebraic Function Fields and Its Application to Arithmetic Secret Sharing (Cascudo, Cramer, Xing). Uses function-field torsion limits to build asymptotically good arithmetic secret sharing schemes for efficient information-theoretic MPC.
- **68410703.pdf** — Public-Key Identification Schemes Based on Multivariate Quadratic Polynomials (Sakumoto, Shirai, Hiwatari). MQ-based zero-knowledge identification schemes that avoid the Isomorphism-of-Polynomials assumption; parallel repetition gives active-attack security.
- **68410721.pdf** — Inverting HFE Systems is Quasi-polynomial for All Fields (Ding, Hodges). First closed formula bounding HFE degree of regularity, implying quasi-polynomial inversion complexity for fixed field and moderate degree.
- **68410740.pdf** — Smaller decoding exponents: ball-collision decoding (Bernstein, Lange, Peters). New information-set decoding variant with exponentially better exponent than Stern's algorithm, tightening concrete security estimates for McEliece-type systems.
- **68410758.pdf** — McEliece and Niederreiter Cryptosystems That Resist Quantum Fourier Sampling Attacks (Dinh, Moore, Russell). Shows Goppa-code McEliece/Niederreiter hidden-subgroup instances cannot be solved by coset-state measurements, blocking the main quantum speedup route.
- **69170001.pdf** — An Exploration of Mechanisms for Dynamic Cryptographic Instruction Set Extension (Grabher et al.). FPGA-based LEON3 study of runtime-reconfigurable instruction set extensions for algorithm-agile cryptographic hardware.
- **69170017.pdf** — FPGA-based True Random Number Generation using Circuit Metastability with Adaptive Feedback Control (Majzoobi, Koushanfar, Devadas). TRNG using delay-line-induced flip-flop metastability with feedback monitoring, passing NIST tests on Virtex-5.
- **69170033.pdf** — Generic Side-Channel Countermeasures for Reconfigurable Devices (Güneysu, Moradi). FPGA-specific DPA countermeasure set (noise, random delays, S-box scrambling) resisting first-order attacks even with 100M traces.
- **69170064.pdf** — Higher-Order Glitches Free Implementation of the AES using Secure Multi-Party Computation Protocols (Prouff, Roche). First countermeasure simultaneously resisting glitches and higher-order SCA, adapting BGW MPC as a masking scheme for AES.
- **69170080.pdf** — Protecting AES with Shamir's Secret Sharing Scheme (Goubin, Martinelli). Masking AES with Shamir sharing instead of Boolean masking, claiming first-order security comparable to 3rd–4th order Boolean masking at better efficiency.
- **69170109.pdf** — Software implementation of binary elliptic curves: impact of the carry-less multiplier (Taverne et al.). Re-evaluates binary-field arithmetic and scalar multiplication around Intel's PCLMULQDQ instruction, with state-of-the-art results for Koblitz and random curves.
- **69170125.pdf** — High-speed high-security signatures (Bernstein, Duif, Lange, Schwabe, Yang). Ed25519: Edwards-curve signatures at 2^128 security doing ~108k signs/s on one CPU, with full software side-channel defenses.
- **69170143.pdf** — To Infinity and Beyond: Combined Attack on ECC using Points of Low Order (Fan, Gierlichs, Vercauteren). Combined fault+side-channel attack turning valid input points into low-order points, breaking SCA-resistant ECC with a single query.
- **69170160.pdf** — Random Sampling for Short Lattice Vectors on Graphics Cards (Schneider, Göttert). First parallel GPU implementation of SSR lattice reduction, raising sampled short vectors from ~5,200 to >120,000 per second.
- **69170176.pdf** — Extreme Enumeration on GPU and in Clouds (Kuo et al.). GPU/MapReduce extreme-pruning enumeration wins the dimension-120 SVP Challenge and prices SVP instances in cloud-computing dollars.
- **69170193.pdf** — Modulus Fault Attacks Against RSA-CRT Signatures (Brier, Naccache, Nguyen, Tibouchi). Lattice-based key recovery from faults injected into the RSA modulus, defeating classic Boneh et al. countermeasures with 5–45 faults, laser-validated.
- **69170208.pdf** — Breaking Mifare DESFire MF3ICD40: Power Analysis and Templates in the Real World (Oswald, Paar). Practical non-invasive power/template attacks recovering the full 112-bit 3DES key of DESFire contactless smartcards.
- **69170224.pdf** — Information Theoretic and Security Analysis of a 65-nanometer DDSLL AES S-box (Renauld, Kamel, Standaert, Flandre). Evaluates dual-rail AES S-box in 65nm, finding about one order of magnitude security gain and questioning dual-rail guarantees at nanoscale.
- **69170257.pdf** — Extractors Against Side-Channel Attacks: Weak or Strong? (Medwed, Standaert). Implements and attacks a hardware randomness extractor; masking works, but extractors leak many more samples than block ciphers.
- **69170274.pdf** — Standardization Works for Security regarding the Electromagnetic Environment (Tominaga). One-page presentation abstract on ITU-T K.84 and EM-emission leakage standards; not a research paper.
- **69170275.pdf** — Meet-in-the-Middle and Impossible Differential Fault Analysis on AES (Derbez, Fouque, Leresteux). First practical fault attacks on AES one round earlier than prior work, needing 10 (or 5) faults at ~2^40 complexity.
- **69170291.pdf** — On the Power of Fault Sensitivity Analysis and Collision Side-Channel Attacks in a Combined Setting (Moradi et al.). Combines FSA with collision attacks to break DPA-protected AES ASIC cores without any hypothetical leakage model.
- **69170311.pdf** — spongent: A Lightweight Hash Function (Bogdanov et al.). Sponge hash family with PRESENT-type permutation; smallest published hardware footprints (from 738 GE) at several security levels.
- **69170327.pdf** — The LED Block Cipher (Guo, Peyrin, Poschmann, Robshaw). Ultra-compact hardware block cipher with no key schedule and AES-like provable bounds against related- and single-key attacks.
- **69170343.pdf** — Piccolo: An Ultra-Lightweight Blockcipher (Shibutani et al.). 64-bit generalized-Feistel cipher for 80/128-bit keys at 683/758 GE, with analysis against related-key differential and MITM attacks.
- **69170359.pdf** — Lightweight and Secure PUF Key Storage Using Limits of Machine Learning (Yu, M'Raihi, Sowell, Devadas). PUF key storage with a 69-register ECC codec, with a min-entropy security argument against machine-learning adversaries.
- **69170375.pdf** — Recyclable PUFs: Logically Reconfigurable PUFs (Katzenbeisser et al.). PUFs with stateful control logic that randomize challenge/response behavior after deployment, enabling securely reusable access tokens; formal model and proofs.
- **69170391.pdf** — Uniqueness Enhancement of PUF Responses Based on the Locations of Random Outputting RS Latches (Yamamoto et al.). Ternary-output Butterfly PUF using random-output latch locations, raising entropy from 116 to 192.7 bits across 40 FPGAs.
- **69170408.pdf** — MECCA: A Robust Low-Overhead PUF using Embedded Memory Array (Krishna, Narasimhan, Wang, Bhunia). SRAM-cell-based PUF exploiting read/write reliability variation, under 1% overhead with ~49.9% inter-die Hamming distance.
- **69170422.pdf** — FPGA Implementation of Pairings using Residue Number System and Lazy Reduction (Cheung et al.). RNS + lazy-reduction pairing hardware computing a 126-bit optimal ate pairing in 0.573 ms, twice prior FPGA speed.
- **69170443.pdf** — High Speed Cryptoprocessor for ηT Pairing on 128-bit Secure Supersingular Elliptic Curves over Characteristic Two Fields (Ghosh, Roy Chowdhury, Das). First 128-bit ηT pairing hardware in characteristic two, 190 µs on Virtex-6 via a 1223-bit Karatsuba multiplier.
- **69170459.pdf** — Fast Multi-Precision Multiplication for Public-Key Cryptography on Embedded Microprocessors (Hutter, Wenger). Operand-caching multiplication needing only 2,395 cycles for 160-bit on ATmega128, 10–23% faster than prior work for ECC/RSA.
