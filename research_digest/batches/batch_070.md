# Batch 070 digest

## Overview
- Dominated by mid-2000s conference cryptography: the 4004xxxx files look like Eurocrypt 2006 proceedings and the 3958xxxx files like PKC 2006, mostly Springer LNCS format.
- Strong recurring themes: secure protocol design without random oracles (signatures, IBE, group signatures, aggregate signatures), key-exchange security (KEA, SAS, password-based group KE, twist-augmented), and secure two-party computation / oblivious transfer foundations.
- Notable heavy hitters: Cheon's Strong Diffie-Hellman analysis, Nguyen-Regev's parallelepiped attack on GGH/NTRUSign, Groth-Ostrovsky-Sahai perfect NIZK, Gentry's standard-model IBE, Joux-Lercier function field sieve, Bellare-Rogaway triple encryption.
- Several lattice / number-theoretic cryptanalysis papers (NTRU symplectic lattices, FFS medium prime case, polynomial equivalence, braid groups).
- Anomalies: 40040511.pdf is font-encoded garbage (unreadable glyph codes); 40040048.pdf is explicitly not a refereed research paper (industry talk note); 40040362.pdf is a position essay rather than a technical result.

## Papers
- **39580294.pdf** — Inoculating Multivariate Schemes Against Differential Attacks (Jintai Ding, Jason E. Gower). Adds a few "Plus" perturbation polynomials to the PMI cryptosystem, yielding PMI+, which resists differential attacks at low cost.
- **39580306.pdf** — Random Subgroups of Braid Groups: An Approach to Cryptanalysis of a Braid Group based Cryptographic Protocol (Myasnikov, Shpilrain, Ushakov). Experiments show most small random subgroups equal the whole braid group, impacting security of the Anshel-Anshel-Goldfeld key exchange.
- **39580319.pdf** — High-order Attacks against the Exponent Splitting Protection (Frédéric Muller, Frédéric Valette). Reveals statistical imbalance between exponent-splitting shares and exploits it in higher-order side-channel, safe-error, and fault attacks.
- **39580335.pdf** — New Online/Offline Signature Schemes Without Random Oracles (Kaoru Kurosawa, Katja Schmidt-Samoa). Builds standard-model online/offline signatures from trapdoor commitments under strong RSA plus a new hash-function assumption, avoiding prime generation for signers.
- **39580352.pdf** — Anonymous Signature Schemes (Yang, Wong, Deng, Wang). Formally defines signer anonymity for digital signatures, constructs such schemes, and applies them to anonymous key exchange.
- **39580369.pdf** — The Power of Identification Schemes (Kaoru Kurosawa, Swee-Huay Heng). Proves equivalence between ID schemes and trapdoor commitments; yields efficient online/offline signatures and the first IB ID-scheme secure against concurrent man-in-the-middle without random oracles.
- **39580384.pdf** — Security Analysis of KEA Authenticated Key Exchange Protocol (Kristin Lauter, Anton Mityagin). Shows NSA's KEA protocol is vulnerable to a class of attacks, then proposes and proves KEA+ secure under the Gap Diffie-Hellman assumption in the random oracle model.
- **39580401.pdf** — SAS-Based Authenticated Key Agreement (Sylvain Pasini, Serge Vaudenay). Surveys and proposes a three-move Diffie-Hellman key agreement authenticated by a single short authenticated string (SAS), secure in the random oracle model; targets secure peer-to-peer VoIP.
- **39580419.pdf** — The Twist-AUgmented Technique for Key Exchange (Chevassut, Fouque, Gaudry, Pointcheval). Uses elliptic-curve twists to extract key material from DH exchanges in the standard model, avoiding random oracles and extractors for key derivation.
- **39580436.pdf** — Password-based Group Key Exchange in a Constant Number of Rounds (Abdalla, Bresson, Chevassut, Pointcheval). Proposes password-authenticated group Diffie-Hellman key exchange running in a constant number of rounds, improving scalability for grid/distributed settings.
- **39580452.pdf** — Conditional Oblivious Cast (Cheng-Kang Chu, Wen-Guey Tzeng). Introduces a three-party primitive releasing a message only when a predicate over the receivers' secrets holds; gives schemes for equality, inequality, and greater-than predicates.
- **39580468.pdf** — Efficiency Tradeoffs for Malicious Two-Party Computation (Payman Mohassel, Matthew Franklin). Analyzes committed-input and equality-checker defenses for Yao's garbled circuits against malicious adversaries, and designs cheaper protocols under a weaker k-leaked security model.
- **39580485.pdf** — On Constructing Certificateless Cryptosystems from Identity Based Encryption (Benoît Libert, Jean-Jacques Quisquater). Shows generic certificateless encryption compositions are CCA-insecure in the strongest model, fixes them, and gives an efficient pairing-based scheme.
- **39580502.pdf** — Building Better Signcryption Schemes with Tag-KEMs (Tor E. Bjørstad, Alexander W. Dent). Constructs insider-secure hybrid signcryption from tag-KEMs, including a new Chevallier-Mames-based scheme with the tightest known security reductions.
- **39580519.pdf** — Security-Mediated Certificateless Cryptography (Sherman S.M. Chow, Colin Boyd, Juan Manuel González Nieto). Introduces mediated certificateless cryptography enabling instant key revocation without key escrow; gives a generic construction and an efficient pairing-based scheme.
- **39580536.pdf** — k-times Anonymous Authentication with a Constant Proving Cost (Isamu Teranishi, Kazue Sako). k-times anonymous authentication where per-authentication cost is independent of k, plus a publicly verifiable variant with O(log k) exponentiations.
- **40040001.pdf** — Security Analysis of the Strong Diffie-Hellman Problem (Jung Hee Cheon). Given auxiliary powers g^{α^i}, computes the secret α in roughly O(√(p/d)) operations, weakening strong-DH-based schemes such as Boldyreva's blind signature.
- **40040012.pdf** — Cryptography in Theory and Practice: The Case of Encryption in IPsec (Kenneth G. Paterson, Arnold K.L. Yau). Demonstrates practical plaintext-recovery attacks on encryption-only IPsec configurations, including the Linux kernel implementation.
- **40040030.pdf** — Polynomial Equivalence Problems: Algorithmic and Theoretical Aspects (Jean-Charles Faugère, Ludovic Perret). Studies theoretical and practical complexity of the Isomorphism of Polynomials problem underlying C* and other multivariate schemes.
- **40040048.pdf** — Alien vs. Quine, The Vanishing Circuit And Other Tales From The Industry's Crypt (Vanessa Gratzer, David Naccache). Not a refereed research paper: a talk note presenting one embedded-security anecdote from the smart-card industry.
- **40040059.pdf** — Hiding Secret Points amidst Chaff (Ee-Chien Chang, Qiming Li). Constructs secure sketches hiding noisy point-sets with a provable entropy-loss bound, motivated by biometric and multimedia representations.
- **40040074.pdf** — Parallel and Concurrent Security of the HB and HB+ Protocols (Jonathan Katz, Ji Sun Shin). Proves the LPN-based HB/HB+ RFID authentication protocols secure under parallel and concurrent executions, answering an open question of Juels and Weis.
- **40040089.pdf** — Polling with Physical Envelopes: A Rigorous Analysis of a Human-Centric Protocol (Tal Moran, Moni Naor). Human-executable polling protocols using physical envelopes, allowing repudiation while enabling accurate statistics, proven UC-secure.
- **40040110.pdf** — QUAD: a Practical Stream Cipher with Provable Security (Côme Berbain, Henri Gilbert, Jacques Patarin). Stream cipher iterating a multivariate quadratic system whose security provably reduces to the hardness of the MQ problem.
- **40040130.pdf** — How to strengthen pseudo-random generators by using compression (Aline Gouget, Hervé Sibert). Proposes a general model for compression components strengthening LFSR-based stream ciphers against algebraic attacks, identifying an optimal rate/security tradeoff construction.
- **40040148.pdf** — Efficient Computation of Algebraic Immunity for Algebraic and Fast Algebraic Attacks (Armknecht, Carlet, Gaborit, Künzli, Meier, Ruatta). Gives O(D²) algorithms to compute algebraic immunity of Boolean functions, improving on prior O(D³) methods for assessing stream-cipher resistance.
- **40040166.pdf** — VSH, an Efficient and Provable Collision-Resistant Hash Function (Scott Contini, Arjen K. Lenstra, Ron Steinfeld). Hash function provably collision-resistant assuming hardness of finding very smooth modular square roots, with collision-finding as hard as NFS factoring asymptotically.
- **40040184.pdf** — Herding Hash Functions and the Nostradamus Attack (John Kelsey, Tadayoshi Kohno). Herding attack letting an attacker commit to a hash then herd any chosen message prefix to it; distinguishes Damgård-Merkle hashes from random oracles.
- **40040202.pdf** — Optimal Reductions between Oblivious Transfers using Interactive Hashing (Claude Crépeau, George Savvides). Reduces k-bit string OT to (1+ε)k bit OTs via interactive hashing and privacy amplification — asymptotically optimal and a twofold improvement.
- **40040223.pdf** — Oblivious Transfer is Symmetric (Stefan Wolf, Jürg Wullschleger). Shows bit OT from A to B can be perfectly obtained from a single reversed instance, resolving a 1991 open problem of Crépeau and Sántha.
- **40040234.pdf** — Symplectic Lattice Reduction and NTRU (Nicolas Gama, Nick Howgrave-Graham, Phong Q. Nguyen). Shows NTRU lattices are proportional to symplectic lattices and that standard orthogonalization techniques are compatible with symplecticity, suggesting adapted reduction algorithms.
- **40040255.pdf** — The Function Field Sieve in the Medium Prime Case (Antoine Joux, Reynald Lercier). Efficient L(1/3) function-field-sieve variant for discrete logs in F_{q^n} with medium q, with security implications for torus-based and pairing-based schemes.
- **40040273.pdf** — Learning a Parallelepiped: Cryptanalysis of GGH and NTRU Signatures (Phong Q. Nguyen, Oded Regev). Reduces GGH/NTRUSign key recovery from signature leakage to learning a hidden parallelepiped and solves it, breaking real-life parameters.
- **40040291.pdf** — The Cramer-Shoup Encryption Scheme is Plaintext Aware in the Standard Model (Alexander W. Dent). Proves the Cramer-Shoup hybrid scheme plaintext-aware in the standard model, answering a conjecture of Bellare and Palacio.
- **40040310.pdf** — Private Circuits II: Keeping Secrets in Tamperable Circuits (Ishai, Prabhakaran, Sahai, Wagner). First feasibility results for circuits that protect internal secrets even when an adversary tampers with an unbounded number of wires.
- **40040330.pdf** — Composition Implies Adaptive Security in Minicrypt (Krzysztof Pietrzak). Shows sequential composition of non-adaptively secure PRFs yields weak adaptive security in Minicrypt, a positive result impossible under public-key assumptions.
- **40040342.pdf** — Perfect Non-Interactive Zero Knowledge for NP (Jens Groth, Rafail Ostrovsky, Amit Sahai). Constructs the first perfect NIZK argument system for any NP language and the first UC-secure NIZK against adaptive adversaries.
- **40040362.pdf** — Language Modeling and Encryption on Packet Switched Networks (Kevin S. McCurley). Position essay arguing existing security models miss real communication features, questioning whether any meaningful definition of "secure encryption" exists for the Internet.
- **40040377.pdf** — A Provable-Security Treatment of the Key-Wrap Problem (Phillip Rogaway, Thomas Shrimpton). Formalizes key-wrap as deterministic authenticated encryption (equivalent to pseudorandom injections) and gives the SIV construction as a standards alternative.
- **40040397.pdf** — Luby-Rackoff Ciphers from Weak Round Functions? (Maurer, Oswald, Pietrzak, Sjödin). Investigates Feistel-network security against CPA distinguishers when round functions are far weaker than pseudorandom.
- **40040415.pdf** — The Security of Triple Encryption and a Framework for Code-Based Game-Playing Proofs (Mihir Bellare, Phillip Rogaway). Proves triple encryption strictly stronger than single/double encryption in the ideal-cipher model, with a code-based game-playing proof framework.
- **40040433.pdf** — Compact Group Signatures Without Random Oracles (Xavier Boyen, Brent Waters). First efficient group signature provably secure without random oracles, with signatures logarithmic in group size, via bilinear groups and Groth-Ostrovsky-Sahai NIZK.
- **40040451.pdf** — Practical Identity-Based Encryption without Random Oracles (Craig Gentry). Fully secure standard-model IBE with short parameters and a tight reduction to a decisional BDHE variant; also yields anonymous IBE.
- **40040472.pdf** — Sequential Aggregate Signatures and Multisignatures Without Random Oracles (Lu, Ostrovsky, Sahai, Shacham, Waters). First aggregate signature, multisignature, and verifiably encrypted signature schemes secure without random oracles, built from Waters' signature.
- **40040493.pdf** — Our Data, Ourselves: Privacy via Distributed Noise Generation (Dwork, Kenthapadi, McSherry, Mironov, Naor). Distributed protocols for generating shared Gaussian/exponential noise, secure against malicious parties, enabling distributed differentially-private databases.
- **40040511.pdf** — Unreadable: the extract is raw font-encoded glyph codes (e.g. /C7/D2 /D8...), not decodable text; cannot identify title or content.
- **40040529.pdf** — Efficient Binary Conversion for Paillier Encrypted Values (Berry Schoenmakers, Pim Tuyls). Protocols converting a Paillier encryption of an integer into encryptions of its bits, extending the Cramer-Damgård-Nielsen secure-computation framework.
- **40040546.pdf** — Information-Theoretic Conditions for Two-Party Secure Function Evaluation (Crépeau, Savvides, Schaffner, Wullschleger). Gives a simple information-theoretic security definition for secure function evaluation provably equivalent to standard simulation-based definitions.
- **40040563.pdf** — Unclonable Group Identification (Ivan Damgård, Kasper Dupont, Michael Østergaard Pedersen). Introduces group identification that prevents users from sharing/cloning their identities while preserving anonymity; realizable from any one-way function.
- **40040581.pdf** — Fully Collusion Resistant Traitor Tracing With Short Ciphertexts and Private Keys (Dan Boneh, Amit Sahai, Brent Waters). Traitor tracing with O(√N) ciphertexts and O(1) private keys via private linear broadcast encryption in composite-order bilinear groups.
