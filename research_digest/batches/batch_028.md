# Batch 028 digest

## Overview
- This batch is dominated by Eurocrypt/TCC-style 2021-era theory cryptography: MPC round complexity and scaling, zero-knowledge/batch verification, and lattice/FHE constructions.
- A notable isogeny/post-quantum cluster: UC-secure CSIDH OT, hidden-shift attacks on SIDH, twin-smooth-integer sieving for B-SIDH/SQISign, and isogeny-based Delay Encryption.
- Only two elliptic-curve-adjacent implementation papers: Koblitz-curve window-τNAF precomputation (126960004) and the Hidden Number Problem / ECDSA key-recovery paper (126960172).
- Several high-impact cryptanalysis results: ROS problem breaks blind/threshold signatures (126960077), passive key-recovery attacks on CKKS (126960098), and the LUOV nested subset differential attack (126960034).
- Quantum-crypto theory appears repeatedly: post-quantum MPC, quantum software leasing, ROM-vs-QROM separations, and a refutation of the quantum-lightning hardness assumption.
- No anomalies: all 50 files are genuine research-paper first pages; no duplicates, slides, or garbage detected.

## Papers
- **12550232.pdf** — FHE-Based Bootstrapping of Designated-Prover NIZK (Brakerski, Garg, Tsabary). Tree-based transformation turning single-statement DP-NIZK into unbounded ZK using leveled FHE, with new ABS and homomorphic signature constructions.
- **12550233.pdf** — Secure Massively Parallel Computation for Dishonest Majority (Fernando, Komargodski, Liu, Shi). Compilers giving semi-honest security against all-but-one corruptions for MPC protocols in the massively parallel computation model, from LWE and PKI.
- **12550234.pdf** — Batch Verification and Proofs of Proximity with Polylog Overhead (G. Rothblum, R. Rothblum). Interactive proofs verifying k unique-witness NP statements with polylogarithmic-in-k communication via progress on interactive proofs of proximity.
- **12550240.pdf** — Mr NISC: Multiparty Reusable Non-Interactive Secure Computation (Benhamouda, Lin). New hybrid model where reusable input encodings enable single-message on-the-fly computation; constructions from pairings with UC security.
- **12550245.pdf** — Security analysis of SPAKE2+ (Shoup). Proves a SPAKE2+ variant is a UC-secure asymmetric PAKE under CDH in the random oracle model, also giving the first UC proof for SPAKE2.
- **12550248.pdf** — The Resiliency of MPC with Low Interaction: The Benefit of Making Errors (Applebaum, Kachlon, Patra). Shows 3-round statistically secure MPC tolerating up to n/3 active corruptions, and that higher thresholds require 4 rounds.
- **12550251.pdf** — On the Round Complexity of the Shuffle Model (Beimel, Haitner, Nissim, Stemmer). Studies what differentially private computations are achievable in two rounds of the shuffle model, building on key establishment from one shuffle round.
- **12550252.pdf** — On Average-Case Hardness in TFNP from One-Way Functions (Hubáček, Kamath, Král, Slívová). Investigates whether OWFs imply average-case TFNP hardness, giving new positive and negative/black-box results.
- **12550261.pdf** — Information-Theoretic 2-Round MPC without Round Collapsing (Lin, Liu, Wee). Simpler 2-round adaptively secure MPC for arithmetic NC1 with black-box field access, avoiding the round-collapsing framework.
- **12550263.pdf** — Public-Coin Zero-Knowledge Arguments with (almost) Minimal Time and Space Overheads (Block, Holmgren, Rosen, Rothblum, Soni). Public-coin ZK arguments with prover time/space within polylog of the verification cost, via a space-efficient multilinear polynomial commitment.
- **12550268.pdf** — Universal Composition with Global Subroutines (Badertscher, Canetti, Hesse, Tackmann, Zikas). Shows how global setup (PKI, CRS, blockchains) can be modeled within plain UC, simplifying GUC/EUC-style frameworks.
- **126960001.pdf** — Secure Software Leasing (Ananth, La Placa). Defines SSL, a weakening of quantum copy-protection, and gives the first provably secure anti-piracy construction for a subclass of evasive circuits.
- **126960004.pdf** — Pre-Computation Scheme of Window τNAF for Koblitz Curves Revisited (Yu, Xu). New μτ̄-operation formulas roughly halve precomputation cost for window-τNAF scalar multiplication on Koblitz curves.
- **126960008.pdf** — Analysing the HPKE Standard (Alwen, Blanchet, Hauck, Kiltz, Lipp, Riepel). Formal analysis of HPKE's authenticated mode via new APKE/AKEM definitions, proving DH-AKEM secure under Gap-DH with CryptoVerif verification.
- **126960020.pdf** — Compact, Efficient and UC-Secure Isogeny-Based Oblivious Transfer (Lai, Galbraith, Delpech de Saint Guilhem). First practical UC-secure malicious OT from CSIDH isogenies, based on a new reciprocal CSIDH assumption proven equivalent to CSIDH.
- **126960029.pdf** — One-way functions and malleability oracles: Hidden shift attacks on isogeny-based protocols (Kutas, Merz, Petit, Weitkämper). Shows an abelian group action on the SIDH key space enabling quantum subexponential hidden-shift attacks on unbalanced parameters.
- **126960030.pdf** — Improved Linear Approximations to ARX Ciphers and Attacks Against ChaCha (Coutinho, Souza Neto). New technique yielding first explicit linear approximations for 3–4-round ChaCha, improving differential-linear attacks.
- **126960034.pdf** — The Nested Subset Differential Attack (Ding, Deaton, Vishakha, Yang). Practical attack fully breaking half of LUOV parameter sets, forging signatures in under 210 minutes for level-I parameters.
- **126960035.pdf** — On the Power of Multiple Anonymous Messages: Frequency Estimation and Selection in the Shuffle Model of DP (Ghazi, Golowich, Kumar, Pagh, Velingker). Tight (up to polylog) error and communication bounds for counting problems in the shuffle model of differential privacy.
- **126960038.pdf** — Rotational Cryptanalysis From a Differential-linear Perspective (Liu, Sun, Li). Extends differential-linear cryptanalysis with rotational-XOR differentials, giving practical distinguishers for round-reduced FRIET, Xoodoo, and Alzette.
- **126960039.pdf** — Black-Box Non-Interactive Non-Malleable Commitments (Garg, Khurana, Lu, Waters). First black-box construction of non-interactive non-malleable commitments with CCA security, replacing sub-exponential NIWIs with hinting PRGs.
- **126960045.pdf** — Efficient Bootstrapping for Approximate Homomorphic Encryption with Non-Sparse Keys (Bossuat, Mouchet, Troncoso-Pastoriza, Hubaux). More precise, faster full-RNS CKKS bootstrapping that is 128-bit secure without sparse secret keys.
- **126960046.pdf** — Sieving for twin smooth integers with solutions to the Prouhet-Tarry-Escott problem (Costello, Meyer, Naehrig). PTE-based sieve for finding twin smooth integers, speeding parameter generation for B-SIDH and SQISign.
- **126960050.pdf** — Order-C Secure Multiparty Computation for Highly Repetitive Circuits (Beck, Goel, Jain, Kaptchuk). MPC with total complexity O(|C|) independent of party count for repetitive circuits, practical for ML-training-like workloads.
- **126960052.pdf** — Abuse Resistant Law Enforcement Access Systems (Green, Kaptchuk, Van Laer). Formalizes and constructs UC-secure lawful-access systems with prospective and retrospective surveillance that resist operator abuse.
- **126960057.pdf** — Alibi: A Flaw in Cuckoo-Hashing based Hierarchical ORAM Schemes and a Solution (Falk, Noble, Ostrovsky). Identifies a subtle security flaw in stash-based cuckoo-hashing hierarchical ORAM (affecting 5+ follow-up protocols) and fixes it.
- **126960066.pdf** — A 2^{n/2}-Time Algorithm for √n-SVP and √n-Hermite SVP (authors not visible, ?). New analysis of a 2^{n/2}-time sieve solving approximate SVP to the Minkowski limit, improving time-approximation tradeoffs for basis reduction.
- **126960071.pdf** — Multi-Source Non-Malleable Extractors and Applications (Goyal, Srinivasan, Zhu). Defines multi-source non-malleable extractors and constructs them against overlapping joint tampering, with cryptographic applications.
- **126960077.pdf** — On the (in)security of ROS (Benhamouda, Lepoint, Loss, Orrù, Raykova). Polynomial-time ROS algorithm leading to practical concurrent attacks on Schnorr blind signatures, FROST, MuSig variants, and related e-cash/credential schemes.
- **126960085.pdf** — New Lattice Two-Stage Sampling Technique and its Applications to Functional Encryption (Lai, Liu, Wang). Generalized two-stage sampling yielding simulation-secure FE with succinct ciphertexts and new adaptive IB/AB-FE for inner products.
- **126960088.pdf** — Tightly-Secure Authenticated Key Exchange, Revisited (Jager, Kiltz, Riepel, Schäge). Efficient AKE with constant security loss under standard Single-Bit-Guess security, from DDH and RSA-subgroup assumptions via non-committing KEMs.
- **126960092.pdf** — Public-Coin Statistical Zero-Knowledge Batch Verification against Malicious Verifiers (Kaslasi, Rothblum, Vasudevan). Public-coin, malicious-verifier SZK batch verification for NISZK with communication (k+poly(m))·polylog.
- **126960098.pdf** — On the Security of Homomorphic Encryption on Approximate Numbers (Li, Micciancio). Practical passive key-recovery attacks on CKKS in major HE libraries, showing IND-CPA is inadequate for approximate encryption and proposing stronger definitions.
- **126960101.pdf** — Post-Quantum Multi-Party Computation (Agarwal, Bartusek, Goyal, Khurana, Malavolta). First constant-round MPC secure against malicious quantum adversaries, from quantum LWE assumptions, with quantum multi-key FHE as a byproduct.
- **126960108.pdf** — Indistinguishability Obfuscation from Simple-to-State Hard Problems (Gay, Jain, Lin, Sahai). Builds FE and iO from Boolean constant-degree PRGs plus binary-error LWE, simplifying prior assumption sets.
- **126960109.pdf** — Aggregatable Distributed Key Generation (Gurkan, Jovanovic, Maller, Meiklejohn, Stern, Tomescu). DKG with aggregatable publicly verifiable transcripts, cutting verification from O(n²) to O(n log n), with relaxed security definitions and experiments.
- **126960113.pdf** — Structured Encryption and Dynamic Leakage Suppression (George, Kamara, Moataz). Dynamic query-equality suppression framework yielding the first fully dynamic (almost) zero-leakage structured encryption schemes.
- **126960118.pdf** — Decentralized Multi-Authority ABE for DNFs from LWE (Datta, Komargodski, Waters). First decentralized multi-authority ABE for DNF policies secure solely under LWE, with no central authority or global coordination.
- **126960121.pdf** — LogStack: Stacked Garbling with O(b log b) Computation (Heath, Kolesnikov). Reduces stacked garbling branch computation from O(b²) to O(b log b) and space to O(log b) with no communication increase.
- **126960126.pdf** — Delay Encryption (Burdges, De Feo). New "time-lock IBE" primitive instantiated from supersingular isogeny chains and pairings, with applications to auctions and voting.
- **126960128.pdf** — High-Precision Bootstrapping of RNS-CKKS Using Optimal Minimax Polynomial Approximation and Inverse Sine (Lee, Lee, Lee, Kim, No). Improves RNS-CKKS bootstrapping message precision well beyond the prior ~20-bit limit via better approximation of modular reduction.
- **126960137.pdf** — Classical vs Quantum Random Oracles (Yamakawa, Zhandry). Separates ROM from QROM with natural signature/PKE schemes secure only classically, plus lifting theorems transferring ROM security to QROM for Fiat-Shamir-type schemes.
- **126960139.pdf** — Security Analysis of Quantum Lightning (Roberts). Disproves Zhandry's hardness assumption underlying the proposed quantum lightning scheme, invalidating its security proof without breaking the construction itself.
- **126960142.pdf** — Leakage Resilient Value Comparison With Application to Message Authentication (Dobraunig, Mennink). Formal treatment of side-channel-protected comparison of secret values (e.g., MAC tag checks) using already-present protected primitives.
- **126960144.pdf** — The More The Merrier: Reducing the Cost of Large Scale MPC (Gordon, Starin, Yerukhimovich). Packed-secret-sharing MPC whose per-party cost decreases with party count, up to 10× faster than prior large-scale protocols.
- **126960154.pdf** — Message-recovery Laser Fault Injection Attack on the Classic McEliece Cryptosystem (Cayrel, Colombier, Drăgoi, Menu, Bossuet). Laser faults force syndrome computation over integers, reducing decoding to linear programming for real-time message recovery.
- **126960155.pdf** — Dynamic Ad Hoc Clock Synchronization (Badertscher, Gaži, Kiayias, Russell, Zikas). Clock synchronizers for dynamic/unknown-participation settings, integrated into a new proof-of-stake protocol Ouroboros Chronos.
- **126960172.pdf** — On Bounded Distance Decoding with Predicate: Breaking the "Lattice Barrier" for the Hidden Number Problem (Albrecht, Heninger). Lattice algorithms augmented with predicates recover DSA/ECDSA keys from side-channel instances previously deemed unsolvable.
- **126960181.pdf** — The Mother of All Leakages: How to Simulate Noisy Leakages via Bounded Leakage (Almost) for Free (Brian, Faonio, Obremski, Ribeiro, Simkin, Skórski, Venturi). Shows common noisy-leakage models can be simulated by a single bounded-leakage query via a new "dense leakage" model.
- **126960187.pdf** — Ciminion: Symmetric Encryption Based on Toffoli-Gates over Large Finite Fields (Dobraunig, Grassi, Guinet, Kuijsters). MPC/FHE/ZK-friendly cipher minimizing field multiplications using Toffoli gates with a lightweight linear layer.
