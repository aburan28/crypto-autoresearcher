# Batch 024 digest

## Overview
- This batch appears to be a large contiguous slice of CRYPTO 2020 papers (uniform ~30-page Springer LNCS format, consecutive submission IDs 12171119–12171355).
- Dominant topics: secure multiparty computation (MPC with identifiable abort, FaF-security, synchronous/async fallback, covert security, reverse firewalls), zero-knowledge (NIZK, ZAPs, Spartan zkSNARK, lattice product proofs, Fiat–Shamir analyses), and theoretical foundations (functional encryption, FE amplification, hinting PRGs, incompressible encodings).
- Notable for ECC/isogeny relevance: 12171224 breaks DDH for class group actions (CSIDH) using genus theory — an important result against isogeny-based cryptography.
- Side-channel/leakage papers are well represented (leakage-resilient key exchange, random probing, timing attack on FO transformation/FrodoKEM, leakage-resistance modes guide).
- Post-quantum cryptanalysis appears: LUOV signature attack, algebraic lattice reduction over cyclotomics, measure-and-reprogram for QROM Fiat–Shamir, lattice blind signatures.
- No anomalies: all 50 entries are genuine research papers; no duplicates or non-paper content found.

## Papers
- **12171119.pdf** — New Techniques for Zero-Knowledge: Leveraging Inefficient Provers to Reduce Assumptions, Interaction, and Trust (Ball, Dachman-Soled, Kulkarni). Transforms NIZK with inefficient provers in the URS model to ZAPs via Nisan–Wigderson designs, yielding fine-grained NIZKs and offline NIZK applications.
- **12171121.pdf** — Black-box Use of One-way Functions is Useless for Optimal Fair Coin-Tossing (Maji, Wang). Proves one-way functions alone cannot yield optimal fair coin tossing, addressing the open question of whether oblivious transfer is necessary.
- **12171124.pdf** — Two-Sided Malicious Security for Private Intersection-Sum with Cardinality (Miao, Patel, Raykova, Seth, Yung). Private intersection-sum protocol with malicious security for both parties, built on a new shuffled distributed oblivious PRF and batched sigma protocols.
- **12171125.pdf** — Cryptanalysis of The Lifted Unbalanced Oil Vinegar Signature Scheme (Ding, Deaton, Schmidt, Vishakha, Zhang). New attack on NIST second-round candidate LUOV exploiting its lifted structure to reduce direct attacks to a subfield, falling below targeted security levels.
- **12171131.pdf** — Amplifying the Security of Functional Encryption, Unconditionally (Jain, Korb, Manohar, Sahai). Unconditionally amplifies any ε-secure FE scheme for P/poly to full security, preserving compactness, via new set-homomorphic secret sharing.
- **12171136.pdf** — Slide Reduction, Revisited—Filling the Gaps in SVP Approximation (Aggarwal, Li, Nguyen, Stephens-Davidowitz). Generalizes slide reduction to arbitrary block sizes via DBKZ, giving faster provably correct algorithms for approximate SVP in the crypto-relevant regime.
- **12171139.pdf** — Overcoming Impossibility Results in Composable Security using Interval-Wise Guarantees (Jost, Maurer). Proposes interval-wise composable security statements in Constructive Cryptography that evade the simulator commitment problem for adaptive security.
- **12171145.pdf** — Anonymous Tokens with Private Metadata Bit (Kreuter, Lepoint, Orrù, Raykova). Extends Privacy Pass with a private metadata bit (PMBTokens) secure under DDH/CTDH, plus techniques to remove NIZKs while keeping unlinkability.
- **12171150.pdf** — Mode-Level vs. Implementation-Level Physical Security in Symmetric Cryptography (Bellizia, Bronchain, Cassiers, Grosso, Guo, Momin, Pereira, Peters, Standaert). Practical guide translating leakage-resistance proof assumptions into implementation requirements, framing security as mode-level vs implementation-level tradeoff.
- **12171152.pdf** — Leakage-Resilient Key Exchange and Two-Seed Extractors (Li, Ma, Quach, Wichs). Information-theoretic non-interactive key exchange when both parties' states have leaked, via new two-seed extractors without fresh randomness.
- **12171157.pdf** — Fast and Secure Updatable Encryption (Boyd, Davies, Gjøsteen, Jiang). SHINE: highly efficient updatable encryption schemes (one exponentiation updates) under a new confidentiality notion implying prior ones, with ciphertext integrity.
- **12171158.pdf** — Fiat-Shamir for Repeated Squaring with Applications to PPAD-Hardness and VDFs (Lombardi, Vaikuntanathan). Constructs a hash family proving Fiat–Shamir soundness for Pietrzak's iterated-squaring proof from sub-exponential LWE, with PPAD/VDF consequences.
- **12171159.pdf** — Scalable Pseudorandom Quantum States (Brakerski, Shmueli). Shows any quantum-secure one-way function implies pseudorandom quantum states with security parameter independent of qubit count, resolving the scalability question.
- **12171162.pdf** — MPC with Friends and Foes (Alon, Omri, Paskin-Cherniavsky). Introduces FaF-security, requiring privacy even against coalitions of honest parties in addition to the malicious adversary, and studies its feasibility.
- **12171165.pdf** — Stacked Garbling: Garbled Circuit Proportional to Longest Execution Path (Heath, Kolesnikov). Stacked garbling eliminates communication for untaken conditional branches; 2PC communication scales with longest execution path, compatible with free XOR/half-gates.
- **12171174.pdf** — Shorter Non-Interactive Zero-Knowledge Arguments and ZAPs for Algebraic Languages (Couteau, Hartmann). Pairing-based framework compiling Σ-protocols into short NIZKs and the first two-round statistical WI arguments from pairing assumptions.
- **12171177.pdf** — Handling Adaptive Compromise for Practical Encryption Schemes (Jaeger, Tyagi). Definitional framework for multi-user security under adaptive key compromise; fixes buggy analyses of BurnBox and Cash et al.'s searchable encryption.
- **12171182.pdf** — Quantifying the Security Cost of Migrating Protocols to Practice (Patton, Shrimpton). Extends MRH indifferentiability to interactive protocols to relate reference and standardized protocol security; applies to a SPAKE2-in-TLS 1.3 extension.
- **12171186.pdf** — Random Probing Security: Verification, Composition, Expansion and New Constructions (Belaïd, Coron, Prouff, Rivain, Taleb). First framework for the random probing leakage model, with the VRAPS verification tool and new masked constructions.
- **12171199.pdf** — Better Concrete Security for Half-Gates Garbling (in the Multi-Instance Setting) (Guo, Katz, Wang, Weng, Yu). Shows concrete multi-instance attacks breaking AES-based half-gates instantiations, and gives provably better instantiations of the garbling hash.
- **12171202.pdf** — The Summation-Truncation Hybrid: Reusing Discarded Bits for Free (Gunsing, Mennink). STH recycles truncated PRP output bits via summation to gain free extra output at truncation-level security; improves GCM-SIV key derivation.
- **12171203.pdf** — The Memory-Tightness of Authenticated Encryption (Ghoshal, Jaeger, Tessaro). Tight memory-sensitive AE security bounds for GCM/CAU and impossibility results for generic memory-tight lifting of confidentiality plus integrity.
- **12171204.pdf** — Incompressible Encodings (Moran, Wichs). Comprehensive study of incompressible encodings: constructions from DCR or LWE in the CRS model, negative results, and applications to proofs of replicated storage.
- **12171209.pdf** — Efficient Constant-Round MPC with Identifiable Abort and Public Verifiability (Baum, Orsini, Scholl, Soria-Vazquez). First efficient dishonest-majority MPC with identifiable abort in constant rounds using only black-box primitives.
- **12171210.pdf** — New Constructions of Hinting PRGs, OWFs with Encryption, and more (Goyal, Vusirikala, Waters). More efficient constructions of hinting PRGs and OWF-with-encryption primitives escaping inefficiencies of the "missing block" framework.
- **12171221.pdf** — Generically Speeding-Up Repeated Squaring is Equivalent to Factoring (Rotem, Segev). Proves sharp sequentiality and pseudorandomness thresholds for all generic-ring delay functions; speeding up repeated squaring generically equals factoring.
- **12171222.pdf** — Always Have a Backup Plan: Fully Secure Synchronous MPC with Asynchronous Fallback (Blum, Liu-Zhang, Loss). Tight feasibility results: MPC tolerating ts<n/2 synchronous and ta<n/3 asynchronous corruptions exists iff ta+2ts<n.
- **12171223.pdf** — Fast Reduction of Algebraic Lattices over Cyclotomic Fields (Kirchner, Espitau, Fouque). Polynomial-time module-lattice reduction over cyclotomics exploiting towers and symplectic geometry; implementation reduces dimension-4096 instances with 6675-bit integers in 4 days.
- **12171224.pdf** — Breaking the decisional Diffie–Hellman problem for class group actions using genus theory (Castryck, Sotáková, Vercauteren). Genus theory characters reveal secret ideal class parity from public curves, breaking DDH for CSIDH/CRS-style isogeny actions whenever the class number is even.
- **12171232.pdf** — Lower Bounds for Encrypted Multi-Maps and Searchable Encryption in the Leakage Cell Probe Model (Patel, Persiano, Yeo). Proves Ω(lg n) overhead for dynamic encrypted multi-maps hiding even decoupled key-equality patterns, matching known constructions.
- **12171245.pdf** — Collusion Resistant Watermarkable PRFs from Standard Assumptions (Yang, Au, Yu, Xu). Generic upgrade of watermarkable PRFs to collusion resistance from standard assumptions, previously only known from iO.
- **12171246.pdf** — A key-recovery timing attack on post-quantum primitives using the Fujisaki–Okamoto transformation and its application on FrodoKEM (Guo, Johansson, Nilsson). Shows FO ciphertext-comparison leakage enables key recovery; demonstrates full key extraction against FrodoKEM's reference implementation at all security levels.
- **12171251.pdf** — Lattice-Based Blind Signatures, Revisited (Hauck, Kiltz, Loss, Nguyen). Points out flaws/attacks in prior lattice blind signatures and gives a new three-round scheme provably secure from standard SIS in the ROM.
- **12171265.pdf** — Verifiable Registration-Based Encryption (Goyal, Vusirikala). Strengthens registration-based encryption (key-escrow-free IBE alternative) to remain secure against a dishonest key accumulator via verifiability.
- **12171281.pdf** — Nearly Optimal Robust Secret Sharing against Rushing Adversaries (Manurangsi, Srinivasan, Vasudevan). Robust secret sharing for n=2t+1 against rushing adversaries with near-optimal m+O(λ·polylog) share size and polynomial-time reconstruction.
- **12171284.pdf** — Security Analysis and Improvements for the IETF MLS Standard for Group Messaging (Alwen, Coretti, Dodis, Tselekounis). Analyzes TreeKEM in the IETF MLS group messaging standard, identifying security gaps and proposing improved constructions with FS/PCS guarantees.
- **12171294.pdf** — Practical Product Proofs for Lattice Commitments (Attema, Lyubashevsky, Seiler). Practical 9KB lattice ZK argument for multiplicative relations over Baum et al. commitments, extended to split cyclotomic rings for packing-based applications.
- **12171297.pdf** — Out of Oddity – New Cryptanalytic Techniques against Symmetric Primitives Optimized for Integrity Proof Systems (Beyne, Canteaut, Dinur, Eichlseder, Leander, Leurent, Naya-Plasencia, Perrin, Sasaki, Todo, Wiemer). Low-complexity distinguishers, collision, and preimage attacks against STARK-friendly hashes GMiMC and HadesMiMC.
- **12171303.pdf** — The Measure-and-Reprogram Technique 2.0: Multi-Round Fiat-Shamir and More (Don, Fehr, Majenz). Extends QROM Fiat–Shamir security to multi-round proofs, improves bounds, and proves the quadratic security loss optimal via Grover-based attacks.
- **12171304.pdf** — Spartan: Efficient and general-purpose zkSNARKs without trusted setup (Setty). First transparent zkSNARKs for NP with sub-linear verification for non-uniform statements and a time-optimal prover, via computation commitments and SPARK.
- **12171307.pdf** — Private Set Intersection in the Internet Setting From Lightweight Oblivious PRF (Chase, Miao). Fast two-party PSI from a lightweight multi-point OPRF over OT extension, best balance of computation/communication at moderate bandwidths.
- **12171319.pdf** — Time-Space Tradeoffs and Short Collisions in Merkle–Damgård Hash Functions (Akshima, Cash, Drucker, Wee). Studies auxiliary-input collision attacks finding short collisions in Merkle–Damgård, proving qualitative jumps in optimal advantage by collision length.
- **12171324.pdf** — Functional Encryption for Attribute-Weighted Sums from k-Lin (Abdalla, Gong, Wee). FE for weighted sums over encrypted databases with compact parameters, unbounded collusion simulation security, from the k-linear assumption in bilinear groups.
- **12171326.pdf** — Reverse Firewalls for Actively Secure MPCs (Chakraborty, Dziembowski, Nielsen). Multiparty reverse-firewall protocol secure against active functionality-preserving corruptions of up to n−1 parties, extending Eurocrypt 2015 two-party passive results.
- **12171330.pdf** — Guaranteed Output Delivery Comes Free in Honest Majority MPC (Goyal, Song, Zhu). Information-theoretic honest-majority MPC with guaranteed output delivery at O(Cnφ) communication, matching the best semi-honest protocols.
- **12171343.pdf** — Improved Differential-Linear Attacks with Applications to ARX Ciphers (Beierle, Leander, Todo). Framework improvements for differential-linear cryptanalysis yielding significantly better attacks on Chaskey and ChaCha.
- **12171344.pdf** — Order-Fairness for Byzantine Consensus (Kelkar, Zhang, Goldfeder, Juels). Initiates formal study of transaction order-fairness in consensus and presents Aequitas, the first protocols achieving it alongside consistency and liveness.
- **12171348.pdf** — A Classification of Computational Assumptions in the Algebraic Group Model (Bauer, Fuchsbauer, Loss). Taxonomy of AGM assumptions: extended Uber families reduce to q-DL, with meta-reduction separations; one-more DL provably falls outside.
- **12171352.pdf** — Non-Malleable Secret Sharing against Bounded Joint-Tampering Attacks in the Plain Model (Brian, Faonio, Obremski, Simkin, Venturi). Non-malleable secret sharing tolerating p-time joint tampering in the plain model from one-to-one one-way functions.
- **12171355.pdf** — Black-Box Transformations from Passive to Covert Security with Public Verifiability (Damgård, Orlandi, Simkin). First generic black-box compilers upgrading passively secure two-party protocols to covert security with public verifiability at constant overhead.
