# Batch 077 digest

## Overview
- Dominated by theory-of-cryptography papers (2007–2008 era, TCC/ASIACRYPT/PKC-style LNCS proceedings): secure MPC, zero-knowledge, and definitional work on encryption security notions.
- Strong cluster of encryption-signature theory: non-malleability, plaintext awareness, CCA2 variants, designated-verifier/proxy/certificateless schemes, plus lattice- and multivariate-based constructions.
- Cryptanalysis cluster: attacks on Tiger, GRINDAHL, Edon80, ℓ-IC (SFLASH-style), known-key AES/Feistel distinguishers, and DLP with low-Hamming-weight exponents.
- Elliptic-curve relevance is modest but present: Galbraith–Verheul on the vector decomposition problem on pairing-friendly curves, Longa–Miri composite EC operations, Boyen's compact EC encryption, Montgomery-multiplication hardware.
- Anomalies: one non-research invited talk (Cryptographic Test Correction, 49390088.pdf) that is light/anecdotal in tone; no duplicates or garbage files detected.

## Papers
- **48330282.pdf** — Multi-Party Indirect Indexing and Applications (Franklin, Gondree, Mohassel). Multi-party generalization of Naor-Nissim indirect indexing enabling RAM simulation with polylog overhead; improves MPC communication complexity.
- **48330299.pdf** — Two-Party Computing with Encrypted Data (Choi, Elbaz, Juels, Malkin, Yung). New online secure-computation model on pre-published encrypted inputs with malicious security, emulating 1978 Rivest-Adleman-Dertouzos computing with encrypted data.
- **48330316.pdf** — Known-Key Distinguishers for Some Block Ciphers (Knudsen, Rijmen). Known-key distinguishers for 7-round AES and 7-round Feistel ciphers; poses open problem of defining security against such attacks.
- **48330343.pdf** — On Tweaking Luby-Rackoff Blockciphers (Goldenberg, Hohenberger, Liskov, Schwartz, Seyalioglu). Builds tweakable blockciphers directly from Luby-Rackoff constructions, sometimes beating prior generic constructions.
- **48330360.pdf** — Secure Protocols with Asymmetric Trust (Damgård, Desmedt, Fitzi, Nielsen). Introduces MPC model where each party trusts a personalized adversary structure; gives bounds for broadcast, VSS, MPC, plus a composition theorem.
- **48330379.pdf** — Simple and Efficient Perfectly-Secure Asynchronous MPC (Beerliová-Trubíniová, Hirt). Asynchronous MPC with O(n³) field elements per multiplication, perfect security against active adversary at optimal t<n/4.
- **48330396.pdf** — Efficient Byzantine Agreement with Faulty Minority (Beerliová-Trubíniová, Hirt, Riser). Improves information-theoretic Byzantine agreement with trusted setup for t<n/2, drastically cutting prior O(n¹⁷κ) communication.
- **48330413.pdf** — Information-Theoretic Security Without an Honest Majority (Broadbent, Tapp). Six IT-secure multiparty protocols (veto, vote, anonymous transmission, etc.) tolerating arbitrary corruptions, with abort possible by one cheater.
- **48330430.pdf** — Black-Box Extension Fields and the Inexistence of Field-Homomorphic One-Way Permutations (Maurer, Raub). Generalizes black-box field extraction to extension fields; efficient representation algorithm, with implications for DLP/CDH generic reductions.
- **48330447.pdf** — Concurrent Statistical Zero-Knowledge Arguments for NP from One Way Functions (Goyal, Moriarty, Ostrovsky, Sahai). Transforms any honest-verifier SZK argument into a concurrent one using only OWFs; first concurrent SZK for all NP from OWFs.
- **48330463.pdf** — Anonymous Quantum Communication (Brassard, Broadbent, Fitzsimons, Gambs, Tapp). First IT-secure protocol for anonymous quantum state transmission against active adversaries with any number of corruptions.
- **48330477.pdf** — Authenticated Key Exchange and Key Encapsulation in the Standard Model (Okamoto). First standard-model two-pass AKE as efficient as MQV, eCK-secure under DDH/TCR/PRF; also a CCA-secure (CPCA) KEM.
- **48330488.pdf** — Miniature CCA2 PK Encryption: Tight Security Without Redundancy (Boyen). ElGamal-compact CCA2-secure cryptosystem under gap-DH in ROM with tight reduction; 320-bit ciphertexts at 80-bit security on elliptic curves.
- **48330505.pdf** — Bounded CCA2-Secure Encryption (Cramer, Hanaoka, Hofheinz, Imai, Kiltz, Pass, shelat, Vaikuntanathan). Introduces q-bounded CCA2 security; black-box construction from any CPA-secure scheme, with short-ciphertext DDH instantiation.
- **48330522.pdf** — Relations Among Notions of Non-Malleability for Encryption (Pass, shelat, Vaikuntanathan). Characterizes indistinguishability-based vs simulation-based non-malleability definitions and their behavior under composition.
- **48330539.pdf** — Cryptanalysis of the Tiger Hash Function (Mendel, Rijmen). Pseudo-near-collision for full Tiger (2⁴⁷ work) and pseudo-collision for 23 of 24 rounds, extending prior reduced-round attacks.
- **48330554.pdf** — Cryptanalysis of GRINDAHL (Peyrin). First cryptanalysis of the RIJNDAEL-style hash GRINDAHL; 256-bit version not collision resistant, collisions in ~2¹¹² work.
- **48330572.pdf** — A Key Recovery Attack on Edon80 (Hell, Johansson). Key-recovery attack on eSTREAM hardware finalist Edon80 at ~2⁶⁹ operations, first break of the quasigroup-based stream cipher.
- **492.pdf** — Identity-Based Hierarchical Strongly Key-Insulated Encryption and Its Application (Hanaoka, Hanaoka, Shikata, Imai). IBE with non-interactive decryption-key renewal via HIBE extension; CCA security under strong key-exposure model in ROM.
- **49390001.pdf** — Total Break of the ℓ-IC Signature Scheme (Fouque, Macario-Rat, Perret, Stern). Efficient forgery and full key recovery on the PKC 2007 multivariate ℓ-IC scheme using SFLASH-style differential tools plus Gröbner bases.
- **49390018.pdf** — Recovering NTRU Secret Key From Inversion Oracles (Mol, Yung). Reduces NTRU secret-key recovery to black-box inversion of the NTRU one-way function, even without decryption failures; links collisions to decryption failures.
- **49390038.pdf** — Solving Systems of Modular Equations in One Variable (May, Ritzenhofen). Improved polynomial-time solving of univariate modular equation systems, beating Håstad+Coppersmith RSA broadcast attacks via better polynomial modeling.
- **49390049.pdf** — Relations Among Notions of Plaintext Awareness (Birkett, Dent). Introduces simplified PA2I notion, proves equivalence to PA2 under mild requirements, confirming Dent's conjecture that PA2 implies PA1+.
- **49390068.pdf** — Completely Non-Malleable Encryption Revisited (Ventre, Visconti). Extends Fischlin's complete non-malleability with game-based NM-CPA*/CCA1*/CCA2* definitions and constructions.
- **49390088.pdf** — Cryptographic Test Correction (Levieil, Naccache). Invited-talk-style piece on shifting multiple-choice exam correction burden to examinees via cheat-resistant answer formats; informal, admits no fully satisfactory solution.
- **49390102.pdf** — Off-Line/On-Line Signatures: Theoretical aspects and Experimental Results (Catalano, Di Raimondo, Fiore, Gennaro). Unifies Even-Goldreich-Micali and Shamir-Tauman paradigms; shows two-trapdoor chameleon hashing is a full one-time signature; includes experiments.
- **49390122.pdf** — Construction of Universal Designated-Verifier Signatures and Identity-Based Signatures from Standard Signatures (Shahandashti, Safavi-Naini). Generic UDVS and IBS constructions from a broad class of standard signatures, with extensions to hierarchical and ring variants.
- **49390142.pdf** — Proxy Signatures Secure Against Proxy Key Exposure (Schuldt, Matsuura, Paterson). Enhanced proxy-signature security model capturing realistic attacks; generic construction from sequential aggregate signatures; identity-based extension.
- **49390163.pdf** — Lattice-Based Identification Schemes Secure Under Active Attacks (Lyubashevsky). 3-move ID scheme secure under active attacks based on worst-case SVP hardness; more efficient ideal-lattice variant.
- **49390181.pdf** — Efficient Simultaneous Broadcast (Faust, Käsper, Lucks). ν-SimCast simultaneous broadcast protocol for t<n/2 in partially synchronous model; O(n) efficiency gain, DDH-based, standard model, useful for coin-flipping.
- **49390198.pdf** — SAS-Based Group Authentication and Key Agreement Protocols (Laur, Pasini). Generalizes short-authenticated-string message authentication to groups; transforms passively secure group key agreement into actively secure ones.
- **49390215.pdf** — An Optimized Hardware Architecture for the Montgomery Multiplication Algorithm (Huang, Gaj, Kwon, El-Ghazawi). Hardware Montgomery multiplier in ~n clock cycles (vs 2n for Tenca-Koç) via precomputed partial results; Verilog-verified, radix-4 extension.
- **49390230.pdf** — New Composite Operations and Precomputation Scheme for Elliptic Curve Cryptosystems over Prime Fields (Longa, Miri). Faster dP+Q composite EC operations and low-cost one-inversion precomputation; up to 6.2% scalar-multiplication savings with fractional wNAF.
- **49390249.pdf** — Online-Untransferable Signatures (Liskov, Micali). Signature schemes untransferable even against online transfer attacks during verification, using a PKI and general assumptions without random oracles.
- **49390269.pdf** — Security of Digital Signature Schemes in Weakened Random Oracle Models (Numayama, Isshiki, Tanaka). Formalizes weakened random-oracle models (collision/preimage oracles) and separates FDH signature variants' security across them.
- **49390289.pdf** — A Digital Signature Scheme based on CVP∞ (Plantard, Susilo, Win). GGH-style lattice signature using l∞-norm vector reduction, aiming for better cryptanalysis resistance and shorter signatures.
- **49390309.pdf** — An analysis of the vector decomposition problem (Galbraith, Verheul). Shows VDP on practical supersingular elliptic curves is equivalent to CDH; relates VDP to co-CDH and 2-DL problems on pairing-friendly curves.
- **49390329.pdf** — A Parameterized Splitting System and its Application to the Discrete Logarithm Problem with Low Hamming Weight Product Exponents (Kim, Cheon). New tool attacking DLP with LHWP exponents; breaks modified GPS identification in 2⁶¹·⁶ time (vs expected 2⁷⁸).
- **49390346.pdf** — Certificateless Encryption Schemes Strongly Secure in the Standard Model (Dent, Libert, Paterson). First certificateless encryption strongly secure in the standard model; generic construction plus concrete Waters-IBE-based scheme.
- **49390363.pdf** — Unidirectional Chosen-Ciphertext Secure Proxy Re-Encryption (Libert, Vergnaud). First unidirectional CCA-secure proxy re-encryption in the standard model from bilinear-map assumptions, solving a CCS'07 open problem.
- **49390382.pdf** — Public Key Broadcast Encryption with Low Number of Keys and Constant Decryption Time (Liu, Tzeng). Three public-key broadcast encryption schemes: O(1) public keys, O(log N) private keys, O(r) headers, and first O(1) decryption time; BDH-based.
- **49480001.pdf** — Incrementally Verifiable Computation or Proofs of Knowledge Imply Time/Space Efficiency (Valiant). Composable non-interactive proof system with near-constant verifier time/space; knowledge assumptions yield time/space efficiency.
- **49480014.pdf** — On Seed-Incompressible Functions (Halevi, Myers, Rackoff). Introduces seed-incompressibility as a relaxation of random-oracle security; SI-PRFs impossible but SI correlation intractability suffices for collision-resistant hashing.
- **49480032.pdf** — Asymptotically Efficient Lattice-Based Digital Signatures (Lyubashevsky, Micciancio). Signatures from worst-case ideal-lattice SVP with near-linear key/signature size and signing time; essentially optimal performance/security trade-off.
- **49480050.pdf** — Basing Weak Public-Key Cryptography on Strong One-Way Functions (Biham, Goren, Ishai). Merkle-puzzle-style key agreement from exponentially strong OWFs, secure against quadratic-gap adversaries; amplification via hard-core predicates.
- **49480068.pdf** — Which Languages Have 4-Round Zero-Knowledge Proofs? (Katz). If a language has a 4-round black-box CZK proof with negligible soundness error, its complement is in MA; NP-complete languages lack such proofs.
- **49480084.pdf** — How to Achieve Perfect Simulation and A Complete Problem for Non-interactive Perfect Zero-Knowledge (Malka). Error-shifting technique gives first complete problem for NIPZK and first hard problem for public-coin PZK.
- **49480102.pdf** — General Properties of Quantum Zero-Knowledge Proofs (Kobayashi). Proves equivalence properties (honest-verifier, public-coin, perfect completeness) for quantum ZK unconditionally, with 3-message public-coin transformations.
- **49480120.pdf** — The Layered Games Framework for Specifications and Analysis of Security Protocols (Herzberg, Yoffe). Game-based layered protocol composition framework; fundamental lemma lets stacks of protocols compose into a single secure protocol.
- **49480138.pdf** — Universally Composable Multi-Party Computation with an Unreliable Common Reference String (Goyal, Katz). UC-secure MPC when either honest majority holds or the CRS is well-formed; such protocols exist iff s+t<n.
