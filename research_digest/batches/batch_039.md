# Batch 039 digest

## Overview
- This batch is remarkably homogeneous: all 50 files appear to be papers from a single top-tier conference proceedings (uniform ~30-page extended-paper format, Springer-style abstracts), consistent with CRYPTO 2022; the corpus skews heavily to theory/foundations and post-quantum crypto rather than ECC/ECDLP.
- Dominant themes: post-quantum/lattice-based primitives (SNARKs, ZK proofs, blind/multi-signatures, OT), secure computation (MPC, garbling, ORAM, oblivious retrieval), and symmetric cryptanalysis (differential/linear theory, ARX, sponge and Merkle-Damgård time-space tradeoffs).
- Notable high-impact papers: "Breaking Rainbow Takes a Weekend on a Laptop" (Beullens' practical key recovery killing a NIST PQC finalist) and "Nova: Recursive Zero-Knowledge Arguments from Folding Schemes" (foundational folding-scheme IVC work).
- One elliptic-curve-relevant item: 135070137 accelerates the Delfs–Galbraith algorithm for the general supersingular isogeny problem (isogeny-based crypto); otherwise ECC/ECDLP content is minimal in this batch.
- Anomalies: none serious — all 50 are genuine research papers; the only oddity is a stray "?" character artifact in the author block of 135070245 (Signal Double Ratchet analysis).
- No duplicates detected in this batch.

## Papers
- **135070115.pdf** — Oblivious Message Retrieval (Zeyu Liu, Eran Tromer). Untrusted servers detect messages for recipients using FHE plus sparse random linear codes, producing compact digests; ~$1 per million messages scanned.
- **135070124.pdf** — More Efficient Dishonest Majority Secure Computation over Z2k via Galois Rings (Escudero, Xing, Yuan). First dishonest-majority MPC over Z2k using Galois ring extensions plus RMFEs, beating SPDZ2k-style approaches.
- **135070128.pdf** — Locally Verifiable Signature and Key Aggregation (Goyal, Vaikuntanathan). Aggregate signatures where membership of one message is verifiable in time independent of N; constructions from RSA and bilinear DH inversion.
- **135070133.pdf** — Efficient NIZKs and Signatures from Commit-and-Open Protocols in the QROM (Don, Fehr, Majenz, Schaffner). Tight online extractability of commit-and-open Fiat-Shamir in the QROM, improving provable post-quantum security of Picnic.
- **135070137.pdf** — Accelerating the Delfs–Galbraith Algorithm with Fast Subfield Root Detection (Corte-Real Santos, Costello, Shi). Faster supersingular-curve-to-subfield isogeny search via cheap subfield root detection; large practical speedup of supersingular isogeny problem attack.
- **135070138.pdf** — On Time-Space Tradeoffs for Bounded-Length Collisions in Merkle-Damgård Hashing (Ghoshal, Komargodski). Characterizes preprocessing adversaries finding B-block collisions in MD hashing in the random oracle model.
- **135070139.pdf** — An Algebraic Framework for Silent Preprocessing with Trustless Setup and Active Security (Abram, Damgård, Orlandi, Scholl). Unifies HSS and PCF constructions group-theoretically; first class-group-based two-party HSS for branching programs.
- **135070142.pdf** — Lower Bound on SNARGs in the Random Oracle Model (Haitner, Nukrai, Yogev). Tight Ω(log(t/ε)·log t) length lower bound for ROM-SNARGs under randomized ETH, matching Chiesa–Yogev.
- **135070143.pdf** — Maliciously Secure Massively Parallel Computation for All-but-One Corruptions (Fernando, Gelles, Komargodski, Shi). Compiles MapReduce-style algorithms to maliciously secure protocols tolerating n−1 corruptions.
- **135070144.pdf** — Rotational Differential-Linear Distinguishers of ARX Ciphers with Arbitrary Output Linear Masks (Niu, Sun, Liu, Li). Efficient algorithm computing rotational differential-linear correlations for arbitrary output masks, partially solving an EUROCRYPT 2021 open problem.
- **135070148.pdf** — Low Communication Complexity Protocols, Collision Resistant Hash Functions and Secret Key-Agreement (Cohen, Naor). Connects breaking communication lower bounds under adversarially chosen inputs to distributional CRH existence.
- **135070184.pdf** — Constructive Post-Quantum Reductions (Bitansky, Brakerski, Kalai). Studies when classical security reductions become constructive quantum reductions; positive for decision assumptions, negative for search ones.
- **135070193.pdf** — Lattice-Based SNARKs: Publicly Verifiable, Preprocessing, and Recursively Composable (Albrecht, Cini, Lai, Malavolta, Thyagarajan). First lattice SNARK that is publicly verifiable, log-time verifier, and recursion-friendly, via new lattice vector commitments.
- **135070195.pdf** — Formal Verification of Saber's Public-Key Encryption Scheme in EasyCrypt (Hülsing, Meijers, Strub). Machine-checked IND-CPA security and correctness proofs for Saber PKE in EasyCrypt.
- **135070204.pdf** — Threshold Signatures with Private Accountability (Boneh, Komlo). TAPS: threshold signatures publicly anonymous but traceable by a tracing key; efficient Schnorr-based constructions.
- **135070211.pdf** — Practical Statistically-Sound Proofs of Exponentiation in any Group (Hoffmann, Hubáček, Kamath, Klein, Pietrzak). Statistically sound PoE for unknown-order groups with much less repetition than Block et al., useful for VDFs.
- **135070218.pdf** — Multimodal Private Signatures (Nguyen, Guo, Susilo, Yang). Anonymous signatures where an opening authority learns only signer-chosen partial identity information, generalizing group/ring signatures.
- **135070222.pdf** — Batch Arguments for NP and More from Standard Bilinear Group Assumptions (Waters, Wu). First non-interactive batch arguments for NP from standard bilinear assumptions; corollaries include sublinear-CRS RAM SNARGs.
- **135070231.pdf** — PI-Cut-Choo and Friends: Compact Blind Signatures via Parallel Instance Cut-and-Choose (Chairattana-Apirom, Hanzlik, Loss, Lysyanskaya, Wagner). Improved transform yielding concurrently secure blind signatures with compact communication and tighter bounds.
- **135070234.pdf** — Some Easy Instances of Ideal-SVP and Implications on the Partial Vandermonde Knapsack Problem (Boudgoust, Gachon, Pellet-Mary). Ideals with many automorphisms give easy SVP instances; polynomial-time attacks on special partial Vandermonde knapsack parameters.
- **135070237.pdf** — Beyond the Csiszár–Körner Bound: Best-Possible Wiretap Coding via Obfuscation (Ishai, Korb, Lou, Sahai). Computational wiretap coding is possible iff Bob's channel is not degraded, assuming VBB obfuscation of evasive functions.
- **135070238.pdf** — Syndrome Decoding in the Head: Shorter Signatures from Zero-Knowledge Proofs (Feneuil, Joux, Rivain). MPC-in-the-head ZK proof for syndrome decoding yielding shorter code-based post-quantum signatures than Stern-style protocols.
- **135070244.pdf** — Candidate Witness Encryption from Lattice Techniques (Tsabary). New lattice-trapdoor hardness assumption yielding a witness encryption candidate whose technique does not imply iO.
- **135070245.pdf** — A More Complete Analysis of the Signal Double Ratchet Algorithm (Bienstock, Fairoze, Garg, Mukherjee, Raghuraman). New UC definition provably achieved by Signal's Double Ratchet, capturing CCA-after-compromise guarantees missed by prior analyses.
- **135070255.pdf** — Constructing and Deconstructing Intentional Weaknesses in Symmetric Ciphers (Beierle, Beyne, Felke, Leander). Explains how GEA-1's secret 40-bit weakness was constructed and generalizes the MALICIOUS backdoor framework.
- **135070256.pdf** — On Codes and Learning with Errors over Function Fields (Bombar, Couvreur, Debris-Alazard). Function-field LWE analogue giving first search-to-decision reductions for structured codes, via Carlitz extensions.
- **135070257.pdf** — Statistically Sender-Private OT From LPN and Derandomization (Bitansky, Freizeit). Two-message SSP OT from LPN (low-noise regime) plus Nisan-Wigderson derandomization; plausibly post-quantum.
- **135070258.pdf** — Provably Secure Reflection Ciphers (Beyne, Chen). First provable-security analysis of reflection ciphers like Prince in the ideal permutation model, plus generic key-length extension.
- **135070262.pdf** — Lattice-Based Zero-Knowledge Proofs and Applications: Shorter, Simpler, and More General (Lyubashevsky, Nguyen, Plançon). More efficient Module-SIS/LWE proofs of short-vector knowledge via direct ℓ2-norm proofs without CRT tricks.
- **135070264.pdf** — log*-Round Game-Theoretically-Fair Leader Election (Komargodski, Matsuo, Shi, Wu). O(log* n)-round approximately fair leader election tolerating (1−o(1))n-sized coalitions; simpler than prior work.
- **135070271.pdf** — Cryptography from Pseudorandom Quantum States (Ananth, Qian, Yuen). Builds commitments and pseudo one-time encryption from pseudorandom state generators via new pseudorandom function-like states.
- **135070278.pdf** — Breaking Rainbow Takes a Weekend on a Laptop (Beullens). New key-recovery attacks on NIST PQC finalist Rainbow; SL1 secret key recovered in ~53 hours on a laptop.
- **135070286.pdf** — Post-Quantum Simulatable Extraction with Minimal Assumptions: Black-Box and Constant-Round (Chia, Chung, Liang, Yamakawa). Constant-round black-box ε-simulatable 2PC against quantum adversaries from post-quantum semi-honest OT.
- **135070287.pdf** — Snapshot-Oblivious RAMs: Sub-Logarithmic Efficiency for Short Transcripts (Du, Genkin, Grubbs). New primitive securing fixed-length access transcripts, bypassing ORAM lower bounds; constant bandwidth overhead instantiation.
- **135070290.pdf** — SoftSpokenOT: Quieter OT Extension From Small-Field Silent VOLE in the Minicrypt Model (Roy). First OT extension beating IKNP communication in Minicrypt, ~5× LAN speedup; also fixes flaws in prior VOLE work.
- **135070291.pdf** — A New Approach to Efficient Non-Malleable Zero-Knowledge (Kim, Liang, Pandey). Instance-based non-malleable commitments yield first practically efficient plain-model NMZK for NP from symmetric primitives.
- **135070294.pdf** — Time-Space Tradeoffs for Sponge Hashing: Attacks and Limitations for Short Collisions (Freitag, Ghoshal, Komargodski). Studies preprocessing-aided short-collision attacks on sponge (SHA-3-style) hashing with random permutation.
- **135070302.pdf** — Authenticated Garbling from Simple Correlations (Dittmer, Ishai, Lu, Ostrovsky). Constant-round malicious 2PC realizing authenticated garbling from VOLE/multiplication-triple correlations, cutting cost to ~1.3 garbled circuits.
- **135070305.pdf** — Public-Key Watermarking Schemes for Pseudorandom Functions (Yang, Yu, Au, Susilo). Solves the open problem of public-key watermarkable PRFs from lattice assumptions up to iO, with various tradeoffs.
- **135070312.pdf** — On the Impossibility of Key Agreements from Quantum Random Oracles (Austrin, Chung, Chung, Fu, Lin, Mahmoody). Classical-query attacks on quantum key agreement over a random oracle; full result under a polynomial-influence conjecture.
- **135070313.pdf** — Multi-Input Attribute Based Encryption and Predicate Encryption (Agrawal, Yadav, Yamada). Formalizes miABE/miPE; first two-input key-policy ABE for NC1 from LWE and pairings.
- **135070316.pdf** — Differential Cryptanalysis in the Fixed-Key Model (Beyne, Rijmen). Quasidifferential trail framework putting differential and linear cryptanalysis on equal footing; invalidates some published attacks on RECTANGLE, Speck, etc.
- **135070321.pdf** — Gossiping for Communication-Efficient Broadcast (Tsimos, Loss, Papamanthou). Gossip-based Byzantine broadcast: first subcubic single-sender BC and new adaptive-secure parallel broadcast protocols.
- **135070323.pdf** — MuSig-L: Lattice-Based Multi-Signature With Single-Round Online Phase (Boschini, Takahashi, Tibouchi). First lattice multi-signature with PPK-model security, concurrent security, one-round online phase, and key aggregation from Module-SIS/LWE.
- **135070327.pdf** — Orion: Zero Knowledge Proof with Linear Prover Time (Xie, Zhang, Song). ZK argument with O(N) prover time and O(log² N) proof size; fastest succinct-system prover, via lossless expander testing.
- **135070331.pdf** — Short Leakage Resilient and Non-malleable Secret Sharing Schemes (Chandran, Kanukurthi, Obbattu, Sekar). LRSS and NMSS with much improved share sizes, including optimal share/leakage size for threshold LRSS.
- **135070332.pdf** — A New Framework For More Efficient Round-Optimal Lattice-Based (Partially) Blind Signature via Trapdoor Sampling (del Pino, Katsumata). First two-round lattice blind signature with ~100 KB signatures, unbounded signing, standard assumptions.
- **135070333.pdf** — (Nondeterministic) Hardness vs. Non-Malleability (Ball, Dachman-Soled, Loss). First explicit non-malleable codes against polysize-circuit tampering from a derandomization assumption not known to imply one-way functions.
- **135070334.pdf** — Nova: Recursive Zero-Knowledge Arguments from Folding Schemes (Kothapalli, Setty, Tzialla). Introduces folding schemes for IVC without SNARKs; constant recursion overhead and fastest-in-literature prover.
- **135070349.pdf** — Superposition Meet-in-the-Middle Attacks: Updates on Fundamental Security of AES-like Hashing (Bao, Guo, Shi, Tu). Superposition-state MITM technique in an MILP framework improving preimage attacks on AES-like hash constructions.
