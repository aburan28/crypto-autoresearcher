# Batch 015 digest

## Overview
- All 50 files are genuine cryptography research papers, circa 2019; filename blocks 114420xxx and 114760xxx correspond to Springer LNCS volumes for PKC 2019 and Eurocrypt 2019 respectively.
- Dominant themes: advanced encryption/functional primitives (IBE/HIBE, ABE/ABS, PRE, IBBE, functional encryption, registration-based encryption) and NIZK/zero-knowledge proof systems (several LWE-based or CDH-based NIZK constructions, Aurora SNARG, QA-NIZK).
- Strong post-quantum presence: lattice-based RIBE, KEMs in the QROM, decryption-failure attacks on NIST candidates, masked binomial sampling, NTRU key generation, isogeny signatures (SeaSign), Picnic multi-target attacks.
- Notable papers: Aurora (transparent SNARG for R1CS), Leurent–Peyrin chosen-prefix collisions for full SHA-1, Zhandry's quantum lightning, Wesolowski's VDF, De Feo–Galbraith SeaSign.
- Side-channel/subversion topics appear (masking at arbitrary orders, kleptographic/cliptographic signatures with offline watchdog), but no ECDLP or elliptic-curve-specific cryptanalysis in this batch.
- No anomalies: no non-paper files, no obvious duplicates; all extracts are first pages with title/abstract intact, though all are truncated mid-text at ~1500 chars.

## Papers
- **114420156.pdf** — Lossy Algebraic Filters With Short Tags (Benoît Libert, Chen Qian). New LAF family with tag size linear in n, secure in asymmetric bilinear groups; shortens Hofheinz's KDM-CCA ciphertexts and improves fuzzy extractors, with an almost tightly secure variant.
- **114420159.pdf** — Adaptively Single-key Secure Constrained PRFs for NC1 (Attrapadung, Matsuda, Nishimaki, Yamada, Yamakawa). First standard-model adaptively single-key secure CPRF for NC1 without complexity leveraging, from IO and subgroup hiding, via a new partitionable CPRF notion.
- **114420163.pdf** — Lattice-based Revocable (Hierarchical) IBE with Decryption Key Exposure Resistance (Katsumata, Matsuda, Takayasu). First lattice-based RHIBE with DKER, avoiding key re-randomization via a generic RIBE-with-DKER construction.
- **114420168.pdf** — Efficient Attribute-Based Signatures for Unbounded Arithmetic Branching Programs (Datta, Okamoto, Takashima). First ABS for arithmetic branching programs; fully secure, unbounded policy size and attribute multi-use, constant public parameters, under DLIN in prime-order bilinear groups.
- **114420172.pdf** — Key Encapsulation Mechanism with Explicit Rejection in the Quantum Random Oracle Model (Jiang, Zhang, Ma). Generic IND-CCA KEM transforms with explicit rejection in the QROM, improving security reductions relevant to NIST PQC submissions.
- **114420175.pdf** — Function Private Predicate Encryption for Low Min-Entropy Predicates (Patranabis, Mukhopadhyay, Ramanna). Zero/non-zero inner-product encryption from prime-order pairings achieving attribute and computational function privacy under Matrix DDH for super-logarithmic min-entropy predicates.
- **114420180.pdf** — Sub-logarithmic Distributed Oblivious RAM with Small Block Size (Kushilevitz, Mour). Multi-server ORAM with O(log N/log log N) overhead and ~log² N block size, secure against m−1 server collusion, without heavy server computation.
- **114420190.pdf** — Identity-based Broadcast Encryption with Efficient Revocation (Ge, Wei). Revocable IBBE from asymmetric prime-order pairings with constant-size ciphertexts, decryption-key-exposure resistance, semi-adaptive security; implemented in Charm.
- **114420193.pdf** — Decryption Failure Attacks on IND-CCA Secure Lattice-Based Schemes (D'Anvers, Guo, Johansson, Nilsson, Vercauteren, Verbauwhede). Framework for key recovery via decryption failures with failure boosting; attacks NIST candidate ss-ntru-pke.
- **114420201.pdf** — Adaptively Secure Proxy Re-encryption (Fuchsbauer, Kamath, Klein, Pietrzak). Lifts PRE security from selective to adaptive without exponential loss, using the Jafargholi et al. framework.
- **114420202.pdf** — Hunting and Gathering – Verifiable Random Functions from Standard Assumptions with Short Proofs (Kohl). First VRF with exponential input space, full adaptive security under constant-size assumptions, and logarithmic-size proofs, from decision linear in symmetric bilinear groups.
- **114420216.pdf** — Efficiently Masking Binomial Sampling at Arbitrary Orders for Lattice-Based Crypto (Schneider, Paglialonga, Oder, Güneysu). First binomial sampler with provable side-channel security at arbitrary masking orders, for LWE-based KEMs.
- **114420217.pdf** — Efficient Invisible and Unlinkable Sanitizable Signatures (Bultel, Lafourcade, Lai, Malavolta, Schröder, Thyagarajan). Answers a PKC'17 open question: sanitizable signatures simultaneously invisible and unlinkable, built from signatures on equivalence classes.
- **114420224.pdf** — Upper and Lower Bounds for Continuous Non-Malleable Codes (Dachman-Soled, Kulkarni). Impossibility of 2-split-state CNMC for one-bit messages from falsifiable assumptions; constructions from injective OWFs and a 4-split-state multi-bit scheme.
- **114420232.pdf** — What about Bob? The Inadequacy of CPA Security for Proxy Reencryption (Cohen). Shows CPA-secure PRE can leak Alice's secret key to Bob after one honest reencryption; proposes stronger honest-reencryption-attack (HRA) security.
- **114420235.pdf** — Break-glass Encryption (Scafuro). Formalizes encryption whose ciphertexts can be broken exactly once, detectably, without trusted parties; feasibility construction using hardware tokens.
- **114420236.pdf** — Short Discrete Log Proofs for FHE and Ring-LWE Ciphertexts (del Pino, Lyubashevsky, Seiler). ~1.25KB proofs of FHE ciphertext well-formedness via Pedersen commitments and inner-product proofs, exploiting lattice polynomial structure.
- **114420238.pdf** — Towards Non-Interactive Zero-Knowledge for NP from LWE (Rothblum, Sealfon, Sotiraki). Reduces NIZK for all NP under LWE to NIZK for decisional Bounded Distance Decoding, via prover-assisted oblivious ciphertext sampling.
- **114420239.pdf** — Additively Homomorphic IBE from Higher Residuosity (Clear, McGoldrick). First group-homomorphic IBE supporting addition modulo a superpolynomial integer, extending Boneh–LaVigne–Sabin under the e-th residuosity assumption.
- **114420242.pdf** — Decentralizing Inner-Product Functional Encryption (Abdalla, Benhamouda, Kohlweiss, Waldner). Compilers decentralizing multi-client inner-product FE key generation and removing per-party ciphertext restrictions; instantiations from prior CRYPTO/ASIACRYPT 2018 schemes.
- **114420244.pdf** — Registration-Based Encryption from Standard Assumptions (Garg, Hajiabadi, Mahmoody, Rahimi, Sekar). Constructs RBE from standard assumptions (CDH or LWE), resolving an open problem from TCC'18, plus anonymous RBE for anonymous messaging.
- **114420247.pdf** — Non-Interactive Keyed-Verification Anonymous Credentials (Couteau, Reichle). First standard-model NIKVAC without pairings; efficient, attribute-based, multi-show unlinkable, with anonymity revocation, from algebraic MACs and DVNIZK.
- **114420252.pdf** — Shorter Quadratic QA-NIZK Proofs (Daza, González, Pindado, Ràfols, Silva). Aggregated quasi-adaptive NIZK for quadratic equations; ~50% shorter proofs and linear-size CRS versus ASIACRYPT'15, under less standard assumptions.
- **114420254.pdf** — Tightly secure hierarchical identity-based encryption (Langrehr, Pan). First tightly secure HIBE from standard (Matrix DH) assumptions, solving a CRYPTO 2014 open problem; implies first tightly secure identity-based signatures.
- **114420255.pdf** — Zero-Knowledge Elementary Databases with More Expressive Queries (Libert, Nguyen, Tan, Wang). Mercurial commitments yield ZK-EDBs supporting range queries (even super-polynomial ranges) and richer membership statements.
- **114420256.pdf** — Group Signatures with Selective Linkability (Garms, Lehmann). New group signature type allowing flexible, post-hoc selective linking of signature subsets without fully trusted central party.
- **114420260.pdf** — Obfuscating Simple Functionalities from Knowledge Assumptions (Beullens, Wee). Obfuscation of point functions and wildcard pattern matching under the new KOALA knowledge assumption; tighter analysis, attacks showing tightness, improved efficiency.
- **114420263.pdf** — Let a Non-Barking Watchdog Bite: Cliptographic Signatures with an Offline Watchdog (Chow, Russell, Tang, Yung, Zhao, Zhou). Subversion-resilient signatures testable by one-time offline watchdog; first scheme in the complete-subversion model, based on full-domain hash.
- **114420270.pdf** — Publicly Verifiable Proofs from Blockchains (Scafuro, Siniscalchi, Visconti). Publicly verifiable witness-indistinguishable proofs from any Σ-protocol assuming only a generic blockchain, with interactive prover but non-interactive verification.
- **114420272.pdf** — Efficient Non-Interactive Zero-Knowledge Proofs in Cross-Domains without Trusted Setup (Backes, Hanzlik, Herzberg, Kate, Pryvalov). NIZK combining algebraic and circuit statements without trusted setup or interaction, improving on CRYPTO 2016/2018 works.
- **114420273.pdf** — Improved Security Evaluation Techniques for Imperfect Randomness from Arbitrary Distributions (Matsuda, Takahashi, Murakami, Hanaoka). Generalizes Dodis–Yu via Rényi divergence to quantify security degradation when ideal non-uniform randomness is replaced by real-world distributions.
- **114420276.pdf** — More Efficient Algorithms for the NTRU Key Generation using the Field Norm (Pornin, Prest). Two new algorithms solving the NTRU equation fG−gF=q using field norms in towers, ~Õ(n) faster and more compact, enabling embedded key generation.
- **114760106.pdf** — Symbolic Encryption with Pseudorandom Keys (Micciancio). Polynomial-time decision procedure for computational indistinguishability of symbolic expressions using encryption and PRGs; fully abstract symbolic patterns with completeness.
- **114760107.pdf** — bison: Instantiating the Whitened Swap-Or-Not Construction (Canteaut, Lallemand, Leander, Neumann, Wiemer). First practical block cipher instance of Whitened Swap-Or-Not, with strong provable arguments against differential attacks.
- **114760134.pdf** — Efficient verifiable delay functions (Wesolowski). Trapdoor VDF from groups of unknown order (RSA groups, class groups); output and proof are single group elements with very efficient verification.
- **114760135.pdf** — Revisiting Non-Malleable Secret Sharing (Badrinarayanan, Srinivasan). First threshold non-malleable secret sharing with rate > 0 (Θ(1/(t log² n))) against per-share independent tampering, improving prior rate tending to zero.
- **114760142.pdf** — Continuous Non-Malleable Codes in the 8-Split-State Model (Aggarwal, Döttling, Nielsen, Obremski, Purwanto). First efficient information-theoretic continuously non-malleable code in a constant (8) split-state model.
- **114760148.pdf** — Quantum Lightning Never Strikes the Same State Twice (Zhandry). Introduces quantum lightning (no-cloning even for adversarially generated states), applications to decentralized currency, Either/Or results, and quantum money from quantum-secure IO.
- **114760150.pdf** — Aurora: Transparent Succinct Arguments for R1CS (Ben-Sasson, Chiesa, Riabzev, Spooner, Virza, Ward). Transparent, plausibly post-quantum SNARG for R1CS with O(log² n) proof size via a univariate sumcheck IOP; <250 kB proofs, with libiop library.
- **114760156.pdf** — Multi-Target Attacks on the Picnic Signature Scheme and Related Protocols (Dinur, Nadler). Multi-target key-recovery attacks on Picnic/ZKB++ recovering κ-bit keys in ~2^(κ−7)/S given S signatures, beating claimed security by factor 2^7·S.
- **114760159.pdf** — Correlated-Source Extractors and Cryptography with Correlated-Random Tapes (Goyal, Song). New correlated-source extractors enabling zero-knowledge and MPC that remain secure when parties reuse correlated random tapes across executions.
- **114760187.pdf** — Verifier-on-a-Leash: new schemes for verifiable delegated quantum computation, with quasilinear resources (Coladangelo, Grilo, Jeffery, Vidick). Classical-verifier delegation of quantum computation to two entangled provers with O(g log g) total resources; blind and constant-round variants.
- **114760189.pdf** — Reversible Proofs of Sequential Work (Abusalah, Kamath, Klein, Pietrzak, Walter). New PoSW in the random permutation model based on skip lists; reversible computation enables applications like proofs of replication, plus sloth embedding for fast verification.
- **114760191.pdf** — Towards Optimal Robust Secret Sharing with Security Against a Rushing Adversary (Fehr, Yuan). Robust secret sharing with overhead O(κ n^ε) secure against rushing adversaries, nearly closing the gap between Bishop et al. and Cevallos et al.
- **114760195.pdf** — Designated-verifier pseudorandom generators, and their applications (Couteau, Hofheinz). Generic NIZK construction refining the hidden-bits model; yields first fully secure CDH-based designated-verifier NIZK and a simpler LWE-based NIZK.
- **114760196.pdf** — A Note on the Communication Complexity of Multiparty Computation in the Correlated Randomness Model (Couteau). First generic information-theoretic MPC in the correlated randomness model with communication sublinear in circuit size for a large function class.
- **114760197.pdf** — Efficient Ratcheting: Almost-Optimal Guarantees for Secure Messaging (Jost, Maurer, Mularczyk). Secure messaging constructions bridging efficient Signal-like protocols and optimally secure but impractical ones, approaching optimal security efficiently.
- **114760201.pdf** — From Collisions to Chosen-Prefix Collisions: Application to Full SHA-1 (Leurent, Peyrin). Techniques converting collision attacks into chosen-prefix collisions via birthday search and multi-block clustering; applied to full SHA-1, threatening certificates and protocols.
- **114760208.pdf** — SeaSign: Compact isogeny signatures from class group actions (De Feo, Galbraith). Isogeny signatures combining CSIDH class group actions with Fiat-Shamir with aborts; <1 kB signatures at 128-bit security, though signing/verification are expensive.
- **114760209.pdf** — Linear Equivalence of Block Ciphers with Partial Non-Linear Layers: Application to LowMC (Dinur, Kales, Promitzer, Ramacher, Rechberger). Redesigns LowMC's linear layers preserving specification while improving performance, addressing the linear-algebra bottleneck in MPC/FHE/ZK applications.
