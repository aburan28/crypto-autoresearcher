# Batch 050 digest

## Overview
- Batch consists of recent IACR-conference-style papers (Crypto/Eurocrypt 2023 era, Springer LNCS front pages), dominated by theory-of-cryptography topics: MPC, consensus/Byzantine agreement, zkSNARKs, and idealized-model analyses (GGM/AGM).
- Strong MPC cluster: broadcast-optimal 4-round MPC, DORAM, YOSO, friends-and-foes security, rational MPC, delayed-party MPC over star networks.
- zkSNARK/proof-system cluster: simulation-extractable SNARK compilation (two related papers, 14369117 and 14369136), distributed-prover interactive proofs, LVD-SNARGs, Schwartz-Zippel mod N for Bulletproofs.
- Post-quantum/lattice/code-based threads: LWE NIKE multi-user security, Ideal-SVP worst-to-average reductions, dual attacks in coding theory, rank decoding/LRPC, lattice Bulletproofs commitments.
- Symmetric-key and QROM results: key-alternating cipher bounds, beyond-birthday MAC forgeries, quantum-secure compressing PRFs, IND-1-CCA KEMs, tight AKE in QROM.
- Anomalies: none — all 50 files are genuine research-paper first pages; extracted text has character-encoding mojibake (ORCID/accents mangled) but is readable. No elliptic-curve/ECDLP-specific papers in this chunk.

## Papers
- **14369110.pdf** — Broadcast-Optimal Four-Round MPC in the Plain Model (Ciampi, Damgård, Ravi, Siniscalchi, Xia, Yakoubov). Characterizes which security guarantees (selective/unanimous/identifiable abort) are feasible for 4-round broadcast-optimal MPC without setup.
- **14369111.pdf** — On the Cost of Post-Compromise Security in Concurrent Continuous Group-Key Agreement (Auerbach, Cueto Noval, Pascual-Perez, Pietrzak). Studies communication cost of concurrent updates with post-compromise security in TreeKEM-style CGKA underlying MLS.
- **14369112.pdf** — CASE: A New Frontier in Public-Key Authenticated Encryption (Agrawal, Agrawal, Prabhakaran, Raghunath, Singla). Introduces Completely Anonymous Signed Encryption with sender and receiver anonymity, a COA security definition, and a standard-model construction.
- **14369113.pdf** — Generic-Group Lower Bounds via Reductions Between Geometric-Search Problems: With and Without Preprocessing (Auerbach, Hoffmann, Pascual-Perez). Transfers GGM lower bounds between problems by reducing to geometric search problems, reproving AGM-style results.
- **14369115.pdf** — Distributed-Prover Interactive Proofs (Das, Fernando, Komargodski, Shi, Soni). Initiates dpIPs where a cluster of machines holding a massive dataset jointly proves statements to a single verifier, formalized via the MPC model.
- **14369117.pdf** — From Polynomial IOP and Commitments to Non-malleable zkSNARKs (Faonio, Fiore, Kohlweiss, Russo, Zajac). Gives conditions to compile simulation-extractable zkSNARKs from polynomial IOPs; proves KZG commitments satisfy a relaxed simulation-extractability notion.
- **14369120.pdf** — Simplex Consensus: A Simple and Fast Consensus Protocol (Chan, Pass). Presents a framework for consensus efficiency analysis and a simple partially synchronous protocol tolerating f < n/3 faults with improved confirmation times.
- **14369122.pdf** — DORAM revisited: Maliciously secure RAM-MPC with logarithmic overhead (Falk, Noble, Ostrovsky, Shtepel, Zhang). First maliciously UC-secure 3-party DORAM with O((κ+D) log N) communication per query and small constants.
- **14369125.pdf** — Round-Robin is Optimal: Lower Bounds for Group Action Based Protocols (Cozzo, Giunta). Proves any passively secure black-box distributed group-action computation over hard homogeneous spaces needs rounds at least the threshold, so round-robin is optimal.
- **14369126.pdf** — Rigorous Foundations for Dual Attacks in Coding Theory (Meyer-Hilfiger, Tillich). Analyzes dual decoding attacks without independence assumptions, finding flaws in the CDMT22 attack's claimed complexity for chosen parameters.
- **14369127.pdf** — Security with Functional Re-Encryption from CPA (Dodis, Halevi, Wichs). Shows funcCPA security (re-encryption oracle instead of decryption) is achievable black-box from CPA-secure encryption, placing it closer to CPA than CCA.
- **14369129.pdf** — On One-way Functions and Sparse Languages (Liu, Pass). Proves equivalence between existence of one-way functions and hard-on-average sparse languages under samplable high-entropy distributions, generalizing IRS (STOC'22).
- **14369130.pdf** — Beyond MPC-in-the-Head: Black-Box Constructions of Short Zero-Knowledge Proofs (Hazay, Venkitasubramaniam, Weiss). Extends MPC-in-the-head to game-based homomorphic primitives, yielding black-box compilers from FHE/FE/randomized encodings to ZKPs.
- **14369131.pdf** — On the Multi-User Security of LWE-based NIKE (Langrehr). Shows single-user security does not generically imply multi-user security with non-negligible correctness error, but the LWE NIKE is multi-user secure for fixed honest user sets.
- **14369133.pdf** — Counting Unpredictable Bits: A Simple PRG from One-way Functions (Mazor, Pass). Gives a PRG-from-OWF construction with a simple self-contained proof via Goldreich-Levin, also improving invocation/seed efficiency by O(log² n).
- **14369136.pdf** — How to Compile Polynomial IOP into Simulation-Extractable SNARKs: A Modular Approach (Kohlweiss, Pancholi, Takahashi). Factors SIM-EXT into knowledge soundness + weak unique response + trapdoor-less ZK for PIOP-compiled SNARKs under mild assumptions.
- **14369142.pdf** — On the Impossibility of Surviving (Iterated) Deletion of Weakly Dominated Strategies in Rational MPC (Blömer, Bobolz, Bröcher). Shows most secret-reconstruction protocols are not weak-domination stable, and proves impossibility under authenticated shares or large coalitions.
- **14369144.pdf** — Locally Verifiable Distributed SNARGs (Aldema Tshuva, Boyle, Cohen, Moran, Oshman). Introduces computationally bounded distributed certification (LVD-SNARGs), a SNARG analog for network properties with short certificates and low communication.
- **14369145.pdf** — Concurrent Asynchronous Byzantine Agreement in Expected-Constant Rounds, Revisited (Cohen, Forghani, Garay, Patel, Zikas). Gives first information-theoretic multi-valued oblivious common coin with optimal t < n/3 resilience in the asynchronous setting.
- **14369146.pdf** — Combinatorially Homomorphic Encryption (Ishai, Kushnir, Rothblum). Defines homomorphic encryption via communication-complexity advantage of holding a ciphertext, capturing prior notions and deriving known implications.
- **14369148.pdf** — Non-Interactive Anonymous Router with Quasi-Linear Router Computation (Fernando, Shi, Soni, Vanjani, Waters). Builds NIAR with sub-quadratic router computation and adaptive-corruption security from iO and OWFs, improving Shi–Wu (Eurocrypt'21).
- **14369150.pdf** — Searching for ELFs in the Cryptographic Forest (Fischlin, Rohrbach). Shows extremely lossy functions cannot be built black-box from random-oracle-derivable (secret-key) primitives, but ELFs themselves don't imply public-key crypto.
- **14369153.pdf** — Algebraic Group Model with Oblivious Sampling (Lipmaa, Parisella, Siim). Proposes AGMOS, an AGM variant with oblivious group-element sampling; separates it from AGM via knowledge-of-exponent assumptions and KZG extractability.
- **14369154.pdf** — Lower Bounds on Assumptions Behind Registration-Based Encryption (Hajiabadi, Mahmoody, Qi, Sarfaraz). Studies minimal assumptions for black-box constructions of registration-based encryption, the key-escrow-free IBE alternative.
- **14369155.pdf** — Multilinear Schwartz-Zippel mod N and Lattice-Based Succinct Arguments (Bünz, Fisch). Proves a composite-modulus Schwartz-Zippel lemma, showing Bulletproofs stays knowledge-sound with lattice (SIS) or unknown-order-group commitments.
- **14369157.pdf** — Security Proofs for Key-Alternating Ciphers with Non-Independent Round Permutations (Yu, Wu, Yu, Cao, Dong). Simplifies KAC security proofs and proves the first tight bound for t-round key-alternating cipher with a single permutation.
- **14369158.pdf** — Three Party Secure Computation with Friends and Foes (Alon, Beimel, Omri). Studies FaF security where malicious parties must not help semi-honest coalitions learn extra information, in the three-party setting.
- **14369163.pdf** — Cryptography from Planted Graphs: Security with Logarithmic-Size Messages (Abram, Beimel, Ishai, Kushilevitz, Narayanan). Achieves O(log n)-message PSM protocols, forbidden-graph secret sharing, and secure 3-party computation from planted-graph-style assumptions.
- **14369167.pdf** — Ideal-SVP is Hard for Small-Norm Uniform Prime Ideals (Felderhoff, Pellet-Mary, Stehlé, Wesolowski). Gives a worst-case to average-case reduction for Ideal-SVP under the uniform distribution over small-norm prime ideals.
- **14369168.pdf** — Revocable Cryptography from Learning with Errors (Ananth, Poremba, Vaikuntanathan). Builds quantum key-revocable PRFs, encryption, and FHE from LWE via revocable Dual-Regev encryption and no-cloning.
- **14369170.pdf** — Lower Bounds on Anonymous Whistleblowing (Quach, Tyner, Wichs). Extends lower bounds for anonymous transfer (leaking anonymously in a public non-anonymous discussion), narrowing the gap with known upper bounds.
- **14369173.pdf** — On Black-Box Verifiable Outsourcing (Agarwal, Alamati, Khurana, Raghuraman, Rindal). Defines oracle-aided batch verification of computation; gives protocols for random-self-reducible functions and impossibility for general functions.
- **14369174.pdf** — Taming Adaptivity in YOSO Protocols: The Modular Way (Canetti, Kolby, Ravi, Soria-Vazquez, Yakoubov). Provides a modular framework proving adaptive end-to-end security for YOSO-style MPC with short-lived stateless parties.
- **14369175.pdf** — Randomized Functions with High Round Complexity (Basu, Khorasgani, Maji, Nguyen). Falsifies the conjecture extending Chor-Kushilevitz-Beaver to randomized functions, constructing binary-input functions of arbitrary round complexity with five outputs.
- **14369177.pdf** — Improved Polynomial Secret-Sharing Schemes (Beimel, Farràs, Lasri). Studies secret sharing with sharing/reconstruction by low-degree polynomials, improving efficiency beyond linear schemes for general access structures.
- **14438006.pdf** — On Quantum Secure Compressing Pseudorandom Functions (Bhaumik, Cogliati, Ethan, Jha). Characterizes 2n-to-n-bit PRFs from n-bit PRFs; proves three-round candidates (TNT, LRQ, LRWQ) quantum-secure up to 2^{n/4} queries.
- **14438009.pdf** — Post-Quantum Security of Key Encapsulation Mechanism against CCA Attacks with a Single Decapsulation Query (Jiang, Ma, Zhang). Proves IND-1-CCA security of TH/TRH KEMs in ROM and QROM with tighter reductions than prior FO-based results.
- **14438013.pdf** — Forgery Attacks on Several Beyond-Birthday-Bound Secure MACs (Shen, Standaert, Wang). One-query, nonce-respecting, probability-1 forgeries against nPolyMAC, CWC+, PolyMAC, PDM*MAC and others, disproving their claimed bounds.
- **14438018.pdf** — Blockwise Rank Decoding Problem and LRPC Codes: Cryptosystems with Smaller Sizes (Song, Zhang, Huang, Wu). Introduces blockwise ℓ-RD and ℓ-LRPC generalizations, shows ℓ-RD remains exponentially hard, enabling smaller rank-based cryptosystems.
- **14438022.pdf** — Scalable Multi-party Private Set Union from Multi-Query Secret-Shared Private Membership Test (Liu, Gao). Builds scalable MPSU mostly from symmetric-key operations via secret-shared shuffle and mq-ssPMT, plus frameworks for other set operations.
- **14438023.pdf** — MPC With Delayed Parties Over Star-Like Networks (Gama, Heydari Beni, Orsini, Smart, Zajonc). Honest-majority actively secure MPC over relay-based star topologies tolerating adversarially delayed straggler parties.
- **14438027.pdf** — Short Concurrent Covert Authenticated Key Exchange (Short cAKE) (Eldefrawy, Genise, Jarecki). Covert (steganographic) mutual authenticated key exchange secure under concurrent composition with minimal message count.
- **14438040.pdf** — Homomorphic polynomial evaluation using Galois structure and applications to BFV bootstrapping (Okada, Player, Pohmann). Evaluates degree-d polynomials in ~3 log d multiplications using Galois automorphisms, yielding ~1.6× faster BFV bootstrapping in SEAL.
- **14438047.pdf** — Pseudorandomness of Decoding, Revisited: Adapting OHCP to Code-Based Cryptography (Bombar, Couvreur, Debris-Alazard). Adapts the lattice OHCP framework to codes via an Oracle Comparison Problem, giving decision-to-search reductions for decoding.
- **14438048.pdf** — Practically Efficient Private Set Intersection From Trusted Hardware with Side-Channels (Dörre, Mechler, Müller-Quade). Two-party PSI using TEEs whose security provably survives side-channel leakage and passive TEE corruption.
- **14438051.pdf** — Unconditionally Secure Multiparty Computation for Symmetric Functions with Low Bottleneck Complexity (Eriguchi). First unconditionally secure MPC for any symmetric function with bottleneck complexity sublinear in the number of players.
- **14438054.pdf** — More Insight on Deep Learning-aided Cryptanalysis (Bao, Lu, Yao, Zhang). Explains neural differential distinguishers' edge over DDT-based ones via explicit bit-correlation rules in modular-addition differential propagation.
- **14438055.pdf** — Robust Decentralized Multi-Client Functional Encryption: Motivation, Definition, and Inner-Product Constructions (Li, Wei, Guo, Susilo, Chen). Introduces RDMCFE tolerating unresponsive clients, with inner-product constructions.
- **14438061.pdf** — Quantitative Fault Injection Analysis (Feldtkeller, Güneysu, Schaumont). Uses quantitative information-flow to build an automated vulnerability metric for hardware circuits under fault injection, enabling implementation comparison.
- **14438062.pdf** — Tighter Security for Generic Authenticated Key Exchange in the QROM (Pan, Wagner, Zeng). Removes square-root loss for KEM-based AKE in the QROM via new parameter lossy encryption; also gives first tightly multi-user IND-CCA KEM in QROM.
