# Batch 102 digest

## Overview
- This batch is almost entirely Crypto 2013 proceedings papers (LNCS vols. 8042/8043), spanning symmetric cryptanalysis, secure computation, lattices, and quantum security — essentially no elliptic-curve/ECDLP content.
- Dominant themes: secure two-party/multi-party computation with cut-and-choose optimizations (MiniLEGO, Lindell, Huang-Katz-Evans, Mohassel-Riva), and the 2013 multilinear-map wave (CLT integer multilinear maps, ABE for circuits, full-domain hash, identity-based aggregate signatures).
- Notable landmark papers: Gennaro-Gentry-Parno-Raykova "Quadratic Span Programs and Succinct NIZKs" (foundational for SNARKs/zkSNARKs), Ben-Sasson et al. "SNARKs for C" (first practical zk-SNARK implementation), and Ducas et al. "Lattice Signatures and Bimodal Gaussians" (BLISS).
- Symmetric side: improved meet-in-the-middle attacks on AES (Derbez-Fouque-Jean, Canteaut et al. sieve-in-the-middle), differential/linear links (Blondeau-Nyberg), and real-time Bluetooth E0 cryptanalysis.
- Quantum security is a recurring thread: Boneh-Zhandry appear twice (quantum-secure MACs; quantum-secure signatures/CCA), plus Unruh's everlasting MPC and Dupuis-Fawzi-Wehner's noisy-storage results.
- Anomaly: 78810606.pdf extracted as hex character-code garbage (font-encoding failure) — title/content unrecoverable from the extract.

## Papers
- **78810368.pdf** — Improved Key Recovery Attacks on Reduced-Round AES in the Single-Key Setting (Derbez, Fouque, Jean). Improves meet-in-the-middle attacks on AES: best attacks on 7-round AES-128, 8-round AES-192/256, and 9-round AES-256.
- **78810385.pdf** — New Links Between Differential and Linear Cryptanalysis (Blondeau, Nyberg). Uses the Chabaud-Vaudenay link to compute truncated differential probabilities from linear correlations; first multiple differential attack with LLR test on PRESENT.
- **78810402.pdf** — Towards Key-Length Extension with Optimal Security: Cascade and Xor-cascade Encryption (Jooyoung Lee). Proves near-optimal security bounds for l-cascade and XOR-cascade encryption, approaching the κ+n bit key-length-extension limit.
- **78810443.pdf** — Limitations of the Meta-Reduction Technique: The Case of Schnorr Signatures (Fischlin, Fleischhacker). Shows via meta-reductions that Schnorr signature security cannot be reduced to discrete log without programming the random oracle.
- **78810460.pdf** — Practical Signatures From Standard Assumptions (Böhl, Hofheinz, Jager, Koch, Seo, Striecks). Tag-based signature technique yields practical schemes from CDH, RSA, and SIS assumptions.
- **78810484.pdf** — Locally Computable UOWHF with Linear Shrinkage (Applebaum, Moses). First UOWHF with linear shrinkage plus constant input and output locality, based on one-wayness of random local functions.
- **78810501.pdf** — Amplification of Chosen-Ciphertext Security (Lin, Tessaro). Shows weak CCA security and correctness can be simultaneously amplified to full CCA security when α² > β, via a new CCA hardcore lemma.
- **78810518.pdf** — Circular Chosen-Ciphertext Security with Compact Ciphertexts (Hofheinz). First KDM-CCA-secure public-key encryption with compact ciphertexts, using "lossy algebraic filters."
- **78810535.pdf** — MiniLEGO: Efficient Secure Two-Party Computation From General Assumptions (Frederiksen, Jakobsen, Nielsen, Nordholt, Orlandi). Gate-level cut-and-choose LEGO protocol using only Minicrypt primitives via an XOR-homomorphic commitment from OT.
- **78810555.pdf** — How to Hide Circuits in MPC: An Efficient Framework for Private Function Evaluation (Mohassel, Sadeghian). Framework splitting PFE into oblivious extended permutations and private gate evaluation; best PFE constructions for several MPC settings.
- **78810572.pdf** — Multi-Party Computation of Polynomials and Branching Programs without Simultaneous Interaction (Gordon, Malkin, Rosulek, Wee). Optimally private one-pass server-mediated protocols for polynomials and read-once branching programs.
- **78810589.pdf** — Quantum-Secure Message Authentication Codes (Boneh, Zhandry). First MACs existentially unforgeable under quantum chosen-message (superposition) attacks; four-wise independence suffices for one-time security.
- **78810606.pdf** — Title unrecoverable (?). Anomaly: extract is hex character-code garbage from a font-encoding failure; not summarizable.
- **78810623.pdf** — Quadratic Span Programs and Succinct NIZKs without PCPs (Gennaro, Gentry, Parno, Raykova). Introduces QSPs/QAPs yielding succinct NIZKs of 7 group elements for Circuit-SAT; foundational for practical SNARKs and verifiable computation.
- **78810645.pdf** — Zero-knowledge Argument for Polynomial Evaluation with Application to Blacklists (Bayer, Groth). Logarithmic-communication SHVZK argument for polynomial evaluation under discrete log; enables anonymous blacklisting.
- **78810662.pdf** — Resource-Restricted Indifferentiability (Demay, Gaži, Hirt, Maurer). Generalizes indifferentiability to account for simulator resources; proves memory lower bounds for domain extension of public random functions.
- **78810682.pdf** — On Concurrently Secure Computation in the Multiple Ideal Query Model (Goyal, Jain). Unconditional lower bounds: some two-party functionalities cannot be realized in the MIQ model with constant ideal queries or constant rounds.
- **78810699.pdf** — Universally Composable Secure Computation with (Malicious) Physically Uncloneable Functions (Ostrovsky, Scafuro, Visconti, Wadia). Extends UC PUF model to adversarially manufactured "malicious" PUFs.
- **78810716.pdf** — How to Garble RAM Programs (Lu, Ostrovsky). Garbled RAM from one-way functions with size polynomial in security parameter times running time; first polylog garbled binary search.
- **80420110.pdf** — A Dynamic Tradeoff Between Active and Passive Corruptions in Secure Multi-Party Computation (Hirt, Maurer, Lucas). MPC protocol with security scaling smoothly between passive t<n and active t<n/2 corruption thresholds.
- **80420126.pdf** — New Techniques for SPHFs and Efficient One-Round PAKE Protocols (Benhamouda, Blazy, Chevalier, Pointcheval, Vergnaud). New SPHF instantiation on Cramer-Shoup ciphertexts removes SS-NIZK proofs; most efficient known one-round PAKE.
- **80420131.pdf** — On the Indifferentiability of Key-Alternating Ciphers (Andreeva, Bogdanov, Dodis, Mennink, Steinberger). Shows the 5-round key-alternating cipher (AES-like structure) is indifferentiable from an ideal cipher.
- **80420133.pdf** — Fast Cut-and-Choose Based Protocols for Malicious and Covert Adversaries (Lindell). Garbled-circuit cut-and-choose 2PC needing far fewer circuits than prior work for 2^-40 cheating probability.
- **80420136.pdf** — Hardness of SIS and LWE with Small Parameters (Micciancio, Peikert). SIS stays hard for moduli near β·n^δ; LWE stays hard with small (even binary) errors given few samples.
- **80420149.pdf** — Efficient Secure Two-Party Computation Using Symmetric Cut-and-Choose (Huang, Katz, Evans). Both parties generate circuits, cutting the number needed by 3× at equal security; ~3× faster in experiments.
- **80420150.pdf** — Practical Multilinear Maps over the Integers (Coron, Lepoint, Tibouchi). CLT13: multilinear maps over integers (DGHV-like) with leftover-hash-lemma randomization; one-round 7-party Diffie-Hellman in <40 s.
- **80420152.pdf** — Time-Optimal Interactive Proofs for Circuit Evaluation (Thaler). Refines GKR protocol so the prover runs in O(S) for regular circuits — constant-factor overhead over plain evaluation.
- **80420153.pdf** — Attribute-Based Encryption for Circuits from Multilinear Maps (Garg, Gentry, Halevi, Sahai, Waters). First ABE for general circuits from multilinear maps, key-policy and ciphertext-policy variants.
- **80420154.pdf** — Secure Signatures and Chosen Ciphertext Security in a Quantum Computing World (Boneh, Zhandry). Defines quantum chosen-message/chosen-ciphertext models; compilers for quantum-secure signatures plus Lamport/Merkle security.
- **80420157.pdf** — Bounds in Shallows and in Miseries (Blondeau, Bogdanov, Leander). Quantitatively connects expected differential probability bounds to fixed-key behavior, revisiting security arguments of prominent designs.
- **80420165.pdf** — Garbled Circuits Checking Garbled Circuits: More Efficient and Secure Two-Party Computation (Mohassel, Riva). Fully secure 2-output 2PC with O(t|C|) symmetric operations in the random oracle model; refined covert-security notion.
- **80420166.pdf** — Optimal Coding for Streaming Authentication and Interactive Communication (Franklin, Gelles, Ostrovsky, Schulman). Constant-rate error correction and efficient authentication for infinite data streams over noisy channels.
- **80420169.pdf** — Accuracy-Privacy Tradeoffs for Two-party Differentially Private Protocols (Goyal, Mironov, Pandey, Sahai). General accuracy upper bounds for two-party DP Boolean functions; tight characterization for AND and XOR.
- **80420172.pdf** — Real Time Cryptanalysis of Bluetooth Encryption with Condition Masking (Zhang, Xu, Feng). Conditional-correlation attacks on Bluetooth E0 recovering the key in seconds on a PC with modest data/memory.
- **80420177.pdf** — Secret Sharing, Rank Inequalities and Information Inequalities (Martín, Padró, Yang). Negative result: information inequalities on bounded variables yield only polynomial lower bounds on secret-sharing share size.
- **80420181.pdf** — Encoding Functions with Constant Online Rate or How to Compress Garbled Circuits Keys (Applebaum, Ishai, Kushilevitz, Waters). Randomized encodings with online rate independent of the security parameter, compressing garbled-circuit online keys.
- **80420182.pdf** — Achieving the Limits of the Noisy-Storage Model Using Entanglement Sampling (Dupuis, Fawzi, Wehner). New min-entropy tool yielding high-order entropic uncertainty relations; proves optimality of bounded-quantum-storage schemes.
- **80420191.pdf** — Sieve-in-the-Middle: Improved MITM Attacks (Canteaut, Naya-Plasencia, Vayssière). MITM variant sieving through a middle sbox; combined with bicliques improves attacks on PRESENT, DES, PRINCE, and AES.
- **80420193.pdf** — Non-Malleable Codes from Two-Source Extractors (Dziembowski, Kazana, Obremski). First information-theoretic split-state non-malleable code for one-bit messages, leakage-resilient, from flexible two-source extractors.
- **80420202.pdf** — Everlasting Multi-Party Computation (Unruh). Defines everlasting quantum-UC; shows secure communication and general MPC with everlasting security using signature cards as setup.
- **80420210.pdf** — Lattice Signatures and Bimodal Gaussians (Ducas, Durmus, Lepoint, Lyubashevsky). BLISS: bimodal-Gaussian rejection sampling shrinks lattice signatures; efficiency competitive with RSA/ECDSA.
- **80420212.pdf** — Learning with Rounding, Revisited (Alwen, Krenn, Pietrzak, Wichs). New LWR-to-LWE reduction for polynomial modulus; lossy-mode property yields deterministic encryption and weak-key results.
- **80420213.pdf** — Functional Encryption: New Perspectives and Lower Bounds (Agrawal, Gorbunov, Vaikuntanathan, Wee). First impossibility of simulation-secure FE under unbounded collusions; Ω(q) ciphertext-size lower bound for q collusions.
- **80420214.pdf** — SNARKs for C: Verifying Program Executions Succinctly and in Zero Knowledge (Ben-Sasson, Chiesa, Genkin, Tromer, Virza). Implemented publicly verifiable zk-SNARK proving TinyRAM/C program executions; O(|x|) verification.
- **80420217.pdf** — Limits of Provable Security for Homomorphic Encryption (Bogdanov, Lee). Compact homomorphic bit-encryption for sensitive functions cannot be proven secure beyond AM∩coAM via general reductions.
- **80420222.pdf** — Fully, (Almost) Tightly Secure IBE and Dual System Groups (Chen, Wee). First fully secure IBE with security loss independent of the number of key queries, from DLIN via dual system groups.
- **80420228.pdf** — Counter-cryptanalysis (Stevens). New paradigm detecting cryptanalytic-collision artifacts to block MD5/SHA-1 forgery while preserving backwards compatibility.
- **80420229.pdf** — Linearly Homomorphic Structure-Preserving Signatures and Their Applications (Libert, Peters, Joye, Yung). Homomorphic SPS enabling verification of outsourced computation and first constant-size non-malleable commitments to group elements.
- **80420230.pdf** — Full Domain Hash from (Leveled) Multilinear Maps and Identity-Based Aggregate Signatures (Hohenberger, Sahai, Waters). Standard-model BLS-like signatures from GGH multilinear maps; first unrestricted identity-based aggregate signatures.
- **80420231.pdf** — Function-Private Identity-Based Encryption: Hiding the Function in Functional Encryption (Boneh, Raghunathan, Segev). Formalizes function privacy for IBE/FE so decryption keys hide their identities under unpredictability assumptions.
