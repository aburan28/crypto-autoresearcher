# Batch 016 digest

## Overview
- This batch is a coherent run of EUROCRYPT 2019 proceedings papers (uniform ~28–32 page lengths, sequential file IDs), dominated by theoretical cryptography rather than elliptic-curve/ECDLP work.
- Heavy clusters: lattice/post-quantum cryptography (G6K sieving, ideal-lattice SVP, gadget toolkit, LPN hardness, lattice group signatures, rank-metric Durandal, PQ misuse attacks) and secure computation (MPC, PSI, HSS, NIZKs, ORAM, differential privacy).
- Blockchain topics recur: private proof-of-stake, consensus via herding, state channels, Mimblewimble formalization, blockchain-hybrid secure computation.
- Notable pair: 114760253 builds iO from constant-degree expanding polynomials over R, while 114760350 (Barak et al.) breaks exactly those candidates with sum-of-squares/SDP attacks — a live build-then-break storyline.
- Only one elliptic-curve-relevant paper: 114760273 (quantum circuits for CSIDH isogeny evaluation, Bernstein–Lange–Martindale–Panny); a few others use DH-type assumptions (CDH/DDH/k-Lin).
- No anomalies: all 50 entries are genuine research-paper first pages; no duplicates or non-paper files detected.

## Papers
- **114760210.pdf** — The General Sieve Kernel and New Records in Lattice Reduction (Albrecht, Ducas, Herold, Kirshanova, Postlethwaite, Stevens). Introduces G6K, an abstract stateful sieve machine unifying and improving lattice sieving/BKZ strategies, with an optimized open-source implementation and new reduction records.
- **114760223.pdf** — On Finding Quantum Multi-collisions (Liu, Zhandry). Gives tight Θ(N^{1/2(1−1/2^{k−1})}) quantum query bounds for finding k-collisions in compressing hash functions, resolving the problem for constant k.
- **114760234.pdf** — Worst-Case Hardness for LPN and Cryptographic Hashing via Code Smoothing (Brakerski, Lyubashevsky, Vaikuntanathan, Wichs). First worst-case-to-average reduction for (very high-noise) LPN via a mildly hard nearest-codeword problem, with hashing applications.
- **114760235.pdf** — Session Resumption Protocols and Efficient Forward Security for TLS 1.3 0-RTT (Aviram, Gellert, Jager). Formalizes session resumption and builds forward-secure, replay-resilient 0-RTT resumption from puncturable PRFs, deployable server-side without protocol changes.
- **114760238.pdf** — Private Anonymous Data Access (Hamlin, Ostrovsky, Weiss, Wichs). Defines PANDA, combining PIR-like privacy with ORAM-like polylog server work so many anonymous clients can read a server database.
- **114760239.pdf** — Minicrypt Primitives with Algebraic Structure and Applications (Alamati, Montgomery, Patranabis, Roy). Shows homomorphic variants of OWFs/weak PRFs imply CRHFs, signatures, PKE, NIKE, and more, unifying lattice-style "noisy" assumptions.
- **114760241.pdf** — Approx-SVP in Ideal Lattices with Pre-processing (Pellet-Mary, Hanrot, Stehlé). Gives heuristic pre-processing/query algorithm for approximate SVP on ideal lattices of arbitrary number fields, with classical and quantum cost trade-offs.
- **114760243.pdf** — DLCT: A New Tool for Differential-Linear Cryptanalysis (Bar-On, Dunkelman, Keller, Weizman). Introduces the Differential-Linear Connectivity Table to capture subcipher dependency, improving differential-linear attacks on block ciphers.
- **114760245.pdf** — Covert Security with Public Verifiability: Faster, Leaner, and Simpler (Hong, Katz, Kolesnikov, Lu, Wang). Constructs an efficient publicly verifiable covert two-party computation protocol from off-the-shelf primitives with small certificates.
- **114760251.pdf** — Beyond Birthday Bound Secure MAC in Faulty Nonce Model (Dutta, Nandi, Talnikar). Proves nEHtM MAC beyond-birthday-bound secure with graceful degradation under nonce misuse, yielding the CWC+ AE scheme.
- **114760253.pdf** — How to Leverage Hardness of Constant-Degree Expanding Polynomials over R to Build iO (Jain, Lin, Matt, Sahai). Constructs D-restricted functional encryption from SXDH and uses it toward iO from constant-degree polynomial hardness assumptions.
- **114760257.pdf** — Lower Bounds for Differentially Private RAMs (Persiano, Yeo). Proves Ω(log(nb/c)) bandwidth lower bounds for differentially private RAM, showing it cannot bypass ORAM lower bounds.
- **114760258.pdf** — On ELFs, Deterministic Encryption, and Correlated-Input Security (Zhandry). Builds deterministic PKE for constant numbers of correlated unpredictable messages from exponential DDH via new trapdoored extremely lossy functions.
- **114760259.pdf** — An Algebraic Approach to Maliciously Secure Private Set Intersection (Ghosh, Nilges). PSI from oblivious linear function evaluation via randomized polynomial addition, achieving information-theoretic malicious security and optimal communication.
- **114760269.pdf** — Distributed Differential Privacy via Shuffling (Cheu, Smith, Ullman, Zeber, Zhilyaev). Initiates analysis of the shuffled model of differential privacy, showing accuracy gains over the local model for sum queries.
- **114760273.pdf** — Quantum Circuits for the CSIDH: Optimizing Quantum Evaluation of Isogenies (Bernstein, Lange, Martindale, Panny). Analyzes and optimizes per-query quantum circuit cost of CSIDH isogeny evaluation, correcting over-optimistic attack-cost claims, with computer-verified simulation.
- **114760278.pdf** — Proof-of-Stake Protocols for Privacy-Aware Blockchains (Ganesh, Orlandi, Tschudi). Formal study of private PoS; shows feasibility of private PoS and gives a privacy-preserving Ouroboros Praos via anonymous VRFs.
- **114760281.pdf** — Consensus through Herding (Chan, Pass, Shi). New consensus paradigm inspired by herding, yielding state machine replication with small bandwidth and confirmation time under adaptive corruptions.
- **114760291.pdf** — Attacks Only Get Better: How to Break FF3 on Large Domains (Hoang, Miller, Trieu). Speeds up Durak–Vaudenay attack on NIST FPE standard FF3 from O(N^5) to O(N^{17/6}), practically breaking PIN/SSN encryption.
- **114760292.pdf** — Compact Adaptively Secure ABE for NC1 from k-Lin (Kowalczyk, Wee). First compact adaptively secure KP/CP-ABE for NC1 under k-Lin with polynomial loss, resolving a Lewko–Waters open problem.
- **114760297.pdf** — Unbounded Dynamic Predicate Compositions in Attribute-Based Encryption (Attrapadung). Transformations composing ABE into unbounded dynamically-specified policies (span programs, branching programs, DFA), yielding first fully secure unbounded KP-ABE for non-monotone span programs.
- **114760299.pdf** — Building an Efficient Lattice Gadget Toolkit: Subgaussian Sampling and More (Genise, Micciancio, Polyakov). New gadget matrices and subgaussian sampling algorithms plus RNS LWE decoding, implemented in PALISADE.
- **114760301.pdf** — Locality-Preserving Oblivious RAM (Asharov, Chan, Nayak, Pass, Ren, Shi). First ORAM preserving data-access locality with polylog overhead; studies locality/bandwidth/leakage trade-offs.
- **114760307.pdf** — Durandal: A Rank Metric Based Signature Scheme (Aragon, Blazy, Gaborit, Hauteville, Zémor). Adapts Schnorr–Lyubashevsky signatures to rank metric with EUF-CMA proof; ~4 kB signatures competitive with Dilithium.
- **114760309.pdf** — Founding Secure Computation on Blockchains (Choudhuri, Goyal, Jain). Studies blockchain-hybrid model: black-box ZK impossible against blockchain-active adversaries, gives tight round bounds, and concurrent secure computation.
- **114760312.pdf** — Uncovering Algebraic Structures in the MPC Landscape (Agarwal, Anand, Prabhakaran). Links information-theoretic MPC computability for aggregating functionalities to "commuting permutation systems", with new protocols and separations.
- **114760313.pdf** — New Techniques for Obfuscating Conjunctions (Bartusek, Lepoint, Ma, Zhandry). Simpler and broader conjunction obfuscation: generic-group VBB for all pattern sizes, plus standard-model security from LPN.
- **114760314.pdf** — Non-Malleable Codes Against Bounded Polynomial Time Tampering (Ball, Dachman-Soled, Kulkarni, Lin, Malkin). Efficient plain-model NMCs computationally secure against any fixed polynomial-time tampering, from derandomization-style assumptions.
- **114760319.pdf** — Computationally Volume-Hiding Structured Encryption (Kamara, Moataz). First volume-hiding encrypted multi-maps avoiding naïve padding, using PRFs and planted-densest-subgraph hardness.
- **114760325.pdf** — Tight Time-Memory Trade-offs for Symmetric Encryption (Jaeger, Tessaro). Shows memory-bounded adversaries gain less against CTR/OFB-style encryption via a generalized switching lemma (under a combinatorial conjecture).
- **114760328.pdf** — New Techniques for Efficient Trapdoor Functions and Applications (Garg, Gay, Hajiabadi). Shorter-image TDFs yielding first CDH deterministic encryption for block sources and DDH lossy TDFs with linear image size.
- **114760330.pdf** — Designated Verifier/Prover and Preprocessing NIZKs from Diffie-Hellman Assumptions (Katsumata, Nishimaki, Yamada, Yamakawa). Builds preprocessing NIZKs (capturing CRS/DV/DP variants) from pairing-free DH assumptions, answering Kim–Wu.
- **114760331.pdf** — Indistinguishability Obfuscation Without Multilinear Maps: New Methods for Bootstrapping and Instantiation (Agrawal). New bootstrapping paths toward iO, working around lower bounds on block-local PRGs needed by the Lin–Tessaro framework.
- **114760333.pdf** — Multi-Party Virtual State Channels (Dziembowski, Eckey, Faust, Hesse, Hostáková). First full state-channel network supporting virtual multi-party channels with constant worst-case time complexity.
- **114760336.pdf** — Group Signatures without NIZK: From Lattices in the Standard Model (Katsumata, Yamada). First standard-model lattice group signatures without NIZKs, from LWE/SIS, achieving CCA-selfless anonymity and full traceability.
- **114760343.pdf** — Reusable Designated-Verifier NIZKs for all NP from CDH (Quach, Rothblum, Wichs). First reusable DV-NIZKs for NP from CDH (no bilinear maps), with soundness against provers learning verification outcomes.
- **114760344.pdf** — Misuse Attacks on Post-Quantum Cryptosystems (Baetu, Durak, Huguenin-Dumittan, Talayhan, Vaudenay). Key-recovery attacks on nine weak NIST PQ submissions under key reuse, classical (plaintext-checking) and quantum (CCA).
- **114760349.pdf** — An Analysis of NIST SP 800-90A (Woodage, Shumow). Security analysis of HASH-DRBG and HMAC-DRBG: robustness proofs with caveats, forward-security failure without optional input, and state-leakage pitfalls.
- **114760350.pdf** — Sum-of-Squares Meets Program Obfuscation, Revisited (Barak, Hopkins, Jain, Kothari, Sahai). SDP/low-rank-recovery attacks breaking recent degree-2 polynomial iO candidates (Ananth–Jain–Sahai, Agrawal) over the reals.
- **114760351.pdf** — On Quantum Advantage in Information Theoretic Single-Server PIR (Aharonov, Brakerski, Chung, Green, Lai, Sattath). Shows input purification is the essential quantum attack on single-server PIR and defines "anchored privacy" under which sublinear protocols are secure.
- **114760352.pdf** — Efficient Circuit-based PSI with Linear Communication (Pinkas, Schneider, Tkachenko, Yanai). First circuit-based PSI with linear communication via batched oblivious programmable PRFs, over 10x communication improvement.
- **114760353.pdf** — Incremental Proofs of Sequential Work (Döttling, Lai, Malavolta). Incremental PoSW constructions reducing prover storage to log N and time to N, from hash functions in the random-oracle model.
- **114760361.pdf** — Two Round Information-Theoretic MPC with Malicious Security (Ananth, Choudhuri, Goel, Jain). First two-round plain-model information-theoretic MPC tolerating any t < n/2 malicious corruptions.
- **114760362.pdf** — Simple Schemes in the Bounded Storage Model (Guan, Zhandry [extract: "Zhandary"]). Simple unconditionally secure key agreement, commitment, and OT in the bounded storage model from Raz's parity-learning lower bound.
- **114760365.pdf** — The Double Ratchet: Security Notions, Proofs, and Modularization for the Signal Protocol (Alwen, Coretti, Dodis). Clean modular definition of secure messaging (forward/post-compromise security, immediate decryption) with a provably secure generalized Signal protocol.
- **114760367.pdf** — Distributional Collision Resistance Beyond One-Way Functions (Bitansky, Haitner, Komargodski, Yogev). Builds constant-round statistically hiding commitments from distributional CRHFs, separating them from one-way functions and showing a loose equivalence.
- **114760368.pdf** — Homomorphic Secret Sharing from Lattices Without FHE (Boyle, Kohl, Scholl). Direct 2-party HSS for branching programs from lattice encryption without FHE, via distributed decryption and share-conversion tricks.
- **114760371.pdf** — Aggregate Cash Systems: A Cryptographic Investigation of Mimblewimble (Fuchsbauer, Orrù, Seurin). Formalizes Mimblewimble as an "aggregate cash system" with security definitions and proofs for Pedersen+Schnorr/BLS instantiations.
- **114760378.pdf** — Ring Signatures: Logarithmic-Size, No Setup — from Standard Assumptions (Backes, Döttling, Hanzlik, Kluczniak, Schneider). First log-size ring signatures without trusted setup or random oracles, extended to linkable ring signatures.
- **114760382.pdf** — (R)CCA Secure Updatable Encryption with Integrity Protection (Klooß, Lehmann, Rupp). Ciphertext-independent updatable encryption achieving (R)CCA security and plaintext integrity, strengthening prior CPA-only schemes.
