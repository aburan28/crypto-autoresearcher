# Batch 007 digest

## Overview
- Two coherent venue clusters: files 10529xxx are CHES 2017 papers (side-channel attacks/defenses, lightweight and efficient implementations), and files 10624xxx are ASIACRYPT 2017 papers (~30p LNCS format, provable security, cryptanalysis, post-quantum).
- Dominant themes: side-channel analysis and countermeasures (blind SCA, horizontal attacks on ECC, masking, leakage assessment, CNN profiling), lightweight symmetric crypto (PRESENT, GIFT, Gimli, SKINNY, bit-serial hardware), and post-quantum crypto (NTRU, isogenies, LWE/RLWE, MQ signatures, code-based Niederreiter).
- ECC-relevant highlights: systematic horizontal attacks on ECC scalar multiplication (10529167), Kummer-line scalar multiplication over prime fields (106240107), isogeny-based attacks and signatures (106240108, 106240124), and qDSA signatures on Montgomery/Kummer arithmetic (106240214).
- Notable results: complete break of RSA-1024 in Libgcrypt via left-to-right sliding-window leakage (10529194); CacheZoom cache attacks on SGX enclaves (10529203); Grover+Simon quantum attack on the FX construction (106240174).
- No anomalies: all 50 extracts are genuine research-paper first pages; no duplicates, slides, or non-paper content detected.

## Papers
- **10529156.pdf** — Bit-Sliding: A Generic Technique for Bit-Serial Implementations of SPN-based Primitives (Jean, Moradi, Peyrin, Sasdrich). Proposes "bit-sliding," a generic method for 1-bit-datapath ASIC implementations of SPN ciphers (AES, PRESENT, SKINNY) that minimizes area without costly scan flip-flops.
- **10529164.pdf** — Improved Blind Side-Channel Analysis by Exploitation of Joint Distributions of Leakages (Clavier, Reynaud). Improves leakage-only (blind) attacks using maximum-likelihood comparison of joint leakage distributions, beating prior distance-based methods and working against first-order masking.
- **10529167.pdf** — A Systematic Approach to the Side-Channel Analysis of ECC Implementations with Worst-Case Horizontal Attacks (Poussier, Zhou, Standaert). Systematic worst-case evaluation of ECC scalar multiplication against horizontal attacks using linear-regression leakage characterization, validated on Cortex-M4/A8 for ECDSA/ECDH.
- **10529174.pdf** — Making Password Authenticated Key Exchange suitable for resource-constrained industrial control devices (Haase, Labrique). CHES 2017 paper tailoring the PACE PAKE protocol for an ARM Cortex-M0+ Bluetooth LE transceiver in industrial control settings, addressing offline-attack threats.
- **10529176.pdf** — Faster Homomorphic Function Evaluation using Non-Integral Base Encoding (Bonte, Bootland, Bos, Castryck, Iliashenko, Vercauteren). Encodes reals via non-integral base expansions to slow coefficient growth in somewhat-homomorphic encryption, yielding ~13x speedup for smart-grid load forecasting.
- **10529185.pdf** — PRESENT Runs Fast: Efficient and Secure Implementation in Software (Reis, Aranha, López). Table-free bitsliced software implementation of PRESENT with novel permutation decomposition; ~8x faster than FELICS on Cortex-M3, plus fastest masked variant.
- **10529188.pdf** — Fast Leakage Assessment (Reparaz, Gierlichs, Verbauwhede). Simple technique accelerating the heavy computations of leakage assessment ~500-fold over CHES 2015 work, enabling exact arithmetic and information-theoretic evaluation.
- **10529193.pdf** — Convolutional Neural Networks with Data Augmentation against Jitter-Based Countermeasures (Cagli, Dumas, Prouff). End-to-end CNN profiling attack that removes trace realignment and point-of-interest selection, using data augmentation to defeat jitter/desynchronization countermeasures.
- **10529194.pdf** — Sliding right into disaster: Left-to-right sliding windows leak (Bernstein, Breitner, Genkin, Groot Bruinderink, Heninger, Lange, van Vredendaal, Yarom). Shows left-to-right sliding-window exponentiation in Libgcrypt leaks enough bits for full RSA-1024 key recovery despite constant-time belief.
- **10529198.pdf** — Generalized Polynomial Decomposition for S-boxes with Application to Side-Channel Countermeasures (Goudarzi, Rivain, Vergnaud, Vivek). Generalizes S-box decomposition methods minimizing multiplications over F_2^lambda, giving new trade-offs for masked block-cipher implementations.
- **10529203.pdf** — CacheZoom: How SGX Amplifies The Power of Cache Attacks (Moghimi, Irazoqui, Eisenbarth). High-resolution cache side-channel tracking nearly all SGX enclave memory accesses, recovering AES T-table keys with very few measurements.
- **10529207.pdf** — Gimli: a cross-platform permutation (Bernstein et al.). Introduces Gimli, a 384-bit permutation designed for high security and performance across CPUs from AVR microcontrollers to servers, FPGAs, and ASICs with side-channel protection.
- **10529214.pdf** — Novel Bypass Attack and BDD-based Tradeoff Analysis Against all Known Logic Locking Attacks (Xu, Shakya, Tehranipoor, Forte). Hardware-security paper: a "bypass attack" defeats SAT-resistant logic locking, restoring circuit functionality with wrong keys; BDD analysis of security/overhead trade-offs.
- **10529219.pdf** — FPGA-based Key Generator for the Niederreiter Cryptosystem using Binary Goppa Codes (Wang, Szefer, Niederhagen). First FPGA key-generation for code-based Niederreiter at ≥128-bit post-quantum security, using a parameterized Gaussian systemizer and Gao-Mateer additive FFT.
- **10529225.pdf** — High-speed key encapsulation from NTRU (Hülsing, Rijneveld, Schanck, Schwabe). AVX2-optimized, timing-protected CCA2-secure KEM from textbook NTRU at 128-bit post-quantum security, competitive with newer lattice schemes.
- **10529227.pdf** — GIFT: A Small Present Towards Reaching the Limit of Lightweight Encryption (Banik, Pandey, Peyrin, Sasaki, Sim, Todo). Redesigns PRESENT into GIFT, a smaller, faster lightweight cipher fixing PRESENT's linear-hull weakness and outperforming SIMON/SKINNY in round-based hardware.
- **10529228.pdf** — Blockcipher-based Authenticated Encryption: How Small Can We Go? (Chakraborti, Iwata, Minematsu, Nandi). COFB, an AE mode using only n/2 bits of mask state beyond the block cipher, provably secure to nearly the birthday bound with the smallest known footprint.
- **106240107.pdf** — Kummer for Genus One over Prime Order Fields (Karati, Sarkar). Develops Kummer-line scalar multiplication over prime fields with SIMD-friendly parallel ladder steps; three 128-bit-security Kummer lines with public Intel implementations.
- **106240108.pdf** — Faster Algorithms for Isogeny Problems using Torsion Point Images (Petit). Exploits torsion-point images given in supersingular-isogeny protocols to speed up solving the underlying problems, giving heuristic polynomial-time key recovery on two De Feo-Jao-Plût variants.
- **106240112.pdf** — How to Use Metaheuristics for Design of Symmetric-Key Primitives (Nikolić). Applies simulated annealing and genetic algorithms to optimize security-relevant components of SKINNY and AES-round-based constructions, showing metaheuristics aid automatic cipher design.
- **106240122.pdf** — Symmetrically and Asymmetrically Hard Cryptography (Biryukov, Perrin). Unified framework for time-, code-, and memory-hardness of primitives, introduces asymmetric hardness with secret-enabled cheap evaluation, and the first asymmetrically memory-hard function Diodon.
- **106240124.pdf** — Identification Protocols and Signature Schemes Based on Supersingular Isogeny Problems (Galbraith, Petit, Silva). Identification protocol and Fiat-Shamir/Unruh signatures based on the endomorphism-ring computation problem, with very small keys and analysis of the quaternion isogeny algorithm.
- **106240137.pdf** — Efficient Scalable Constant-Round MPC via Garbled Circuits (Ben-Efraim, Lindell, Omri). New BMR-type garbled circuits evaluable with constant per-gate cost using key-homomorphic PRFs from DDH or Ring-LWE, fixing quadratic scaling in party count.
- **106240138.pdf** — Analyzing Multi-Key Security Degradation (Luykx, Mennink, Paterson). Establishes sufficient conditions under which multi-key security degradation beyond the folklore linear-in-keys bound can be analyzed and bounded for internet-scale deployments like TLS.
- **106240152.pdf** — Full-State Keyed Duplex With Built-In Multi-User Support (Daemen, Mennink, Van Assche). Generalizes the full-state keyed duplex to natively support multiple instances, with stronger adaptive security bounds largely independent of instance count.
- **106240162.pdf** — On the Untapped Potential of Encoding Predicates by Arithmetic Circuits and Their Applications (Katsumata). Formalizes predicate encodings as arithmetic circuits, yielding improved bilinear-map VRFs with poly-log assumptions/sizes and a lattice-based predicate encryption scheme.
- **106240163.pdf** — Maliciously Secure Oblivious Linear Function Evaluation with Constant Overhead (Ghosh, Nielsen, Nilges). UC-secure OLE in the OT-hybrid model needing only 16 OTs per OLE via noisy encodings, plus the most efficient oblivious polynomial evaluation as application.
- **106240165.pdf** — An Existential Unforgeable Signature Scheme based on Multivariate Quadratic Equations (Shim, Park, Koo). MQ signature scheme ELSA with a hidden quadratic layer cutting secret-key size 88% versus Rainbow; EUF-CMA proof in ROM and very fast signing.
- **106240173.pdf** — Linear Cryptanalysis of DES with Asymmetries (Bogdanov, Vejre). Revisits Matsui's DES linear attack, showing right keys are inequivalent under multi-trail approximations and wrong-key correlations are non-random, refining attack-complexity models.
- **106240174.pdf** — Grover Meets Simon – Quantumly Attacking the FX-construction (Leander, May). First combination of Grover's and Simon's algorithms to break the FX key-whitening construction in the quantum-CPA setting at essentially Grover cost, negating its quantum security gain.
- **106240179.pdf** — More Efficient Universal Circuit Constructions (Günther, Kiss, Schneider). Modular generic embedding for k-way Valiant universal circuits plus a hybrid 2-way/4-way construction minimizing concrete UC size for private function evaluation.
- **106240182.pdf** — Two-Round PAKE from Approximate SPH and Instantiations from Lattices (Zhang, Yu). Framework reducing Katz-Vaikuntanathan three-round PAKE to two rounds via splittable CCA-secure PKE with non-adaptive ASPH, instantiated from LWE.
- **106240183.pdf** — Optimal-Rate Non-Committing Encryption (Canetti, Poburinnaya, Raykova). First constant-rate (1+o(1)) non-committing encryption in the CRS model with perfect correctness, from one-way functions and indistinguishability obfuscation.
- **106240193.pdf** — Authenticated Encryption in the Face of Protocol and Side Channel Leakage (Barwell, Martin, Oswald, Stam). Adds continuous leakage to nonce-based AE, proves composition under protocol and side-channel leakage, and gives a misuse-resistant leakage-resilient pairing-based construction.
- **106240194.pdf** — Collisions and Semi-Free-Start Collisions for Round-Reduced RIPEMD-160 (Liu, Mendel, Wang). First collision attack on round-reduced RIPEMD-160 (30 steps, 2^67 complexity) plus a 36-step semi-free-start collision, solving the step differential probability problem.
- **106240198.pdf** — Revisiting the Expected Cost of Solving uSVP and Applications to LWE (Albrecht, Göpfert, Virdia, Wunderer). Empirical lattice-reduction study reconciling two conflicting uSVP cost estimates for LWE, showing several published security estimates need revision.
- **106240203.pdf** — Non-Interactive Multiparty Computation Without Correlated Randomness (Halevi, Ishai, Jain, Komargodski, Sahai, Yogev). NI-MPC tolerating arbitrary collusion with only PKI plus a common random string, from sub-exponentially secure indistinguishability obfuscation and DDH.
- **106240206.pdf** — Quantum Multicollision-Finding Algorithm (Hosoyamada, Sasaki, Xagawa). New quantum l-collision algorithm with rigorously proven query complexity O(N^((3^{l-1}-1)/(2·3^{l-1}))), matching the tight l=2 bound and improving prior bounds.
- **106240214.pdf** — qDSA: Small and Secure Digital Signatures with Curve-based Diffie–Hellman Key Pairs (Renes, Smith). EdDSA-like signatures computed entirely on Kummer quotients sharing Curve25519 DH keys; tiny footprint implementations on AVR and Cortex-M0 with Kummer point compression.
- **106240217.pdf** — Improved Conditional Cube Attacks on Keccak Keyed Modes with MILP Method (Li, Bi, Dong, Wang). MILP model for selecting ordinary cube variables improves EUROCRYPT 2017 conditional cube key-recovery attacks on Keccak keyed modes.
- **106240219.pdf** — Coded-BKW with Sieving (Guo, Johansson, Mårtensson, Stankovski). Combines coded-BKW with lattice sieving to solve LWE in 2^0.895n for Regev parameters, improving the best known asymptotic complexity.
- **106240220.pdf** — Beyond Hellman's Time-Memory Trade-Offs with Applications to Proofs of Space (Abusalah, Alwen, Cohen, Khilko, Pietrzak, Reyzin). Constructs functions provably requiring S^k·T ∈ Ω(N^k) to invert, going beyond Hellman's trade-offs to enable simpler proofs of space.
- **106240224.pdf** — Automatic Search of Bit-Based Division Property for ARX Ciphers and Word-Based Division Property (Sun, Wang, Wang). SAT-based automatic search for bit-level division property of ARX ciphers (via CNF encoding) and word-level division property for specific ciphers.
- **106240227.pdf** — Cycle Slicer: An Algorithm for Building Permutations on Special Domains (Miracle, Yilek). Cycle Slicer algorithm improving format-preserving-encryption domain targeting and domain completion, analyzed via refined Markov-chain matching-exchange techniques.
- **106240233.pdf** — Large Modulus Ring-LWE ≥ Module-LWE (Albrecht, Deo). Reduces Module-LWE (rank d, modulus q) to Ring-LWE with modulus q^d, showing polynomial-time equivalence and suggesting hardness be classified by module rank.
- **106240234.pdf** — Consolidating Inner Product Masking (Balasch, Faust, Gierlichs, Paglialonga, Standaert). More efficient inner-product masking algorithms with reduced randomness, secure in the t-probing model, cutting execution time by ~60% in practice.
- **106240239.pdf** — Strengthening Access Control Encryption (Badertscher, Matt, Maurer). Strengthens the ACE security definition (CCA security, sanitizer-fault resilience) and constructs a scheme provably meeting it under standard assumptions.
- **106240250.pdf** — Low Cost Constant Round MPC Combining BMR and Oblivious Transfer (Hazay, Scholl, Soria-Vazquez). Two actively secure constant-round BMR garbling protocols with free-XOR, needing one secure F2 multiplication per AND gate; up to 9-party AES/SHA-256 experiments 60x faster.
- **106240252.pdf** — ABE with Tag Made Easy: Concise Framework and New Instantiations in Prime-order Groups (Chen, Gong). Generic tag-based ABE framework extending JR-IBE, compatible with attribute-hiding predicate encodings, yielding new efficient prime-order instantiations.
- **106240254.pdf** — Oblivious Hashing Revisited, and Applications to Asymptotically Efficient ORAM and OPRAM (Chan, Guo, Lin, Shi). Exposes and patches incompleteness in oblivious Cuckoo hashing, then gives a conceptually simple O(log^2 N / log log N)-overhead ORAM/OPRAM avoiding it.
