# Batch 069 digest

## Overview
- Dominated by two LNCS proceedings volumes: 3876xxxx files are TCC 2006 papers (zero-knowledge, MPC, commitments, randomness, complexity), 3958xxxx files are PKC 2006 papers (signatures, encryption, cryptanalysis, DLP).
- Notable papers: Bernstein's Curve25519 speed-record ECDH; Dwork–McSherry–Nissim–Smith "Calibrating Noise to Sensitivity" (foundational differential privacy); Mantin's practical RC4/WEP attack; Bleichenbacher–May small CRT-exponent RSA attack; Commeine–Semaev Number Field Sieve DLP algorithm.
- Strong zero-knowledge theme: concurrent ZK without assumptions, NIZK from homomorphic encryption, ZK with restricted random oracles, plus MPC/dispute-control and VSS results.
- Cryptanalysis of discrete-log-based systems appears repeatedly: NFS for DLP in F_p, attack on a proof of knowledge of discrete log, error correction in the exponent.
- Anomalies: 7 files have broken extraction — 38760080 (ASCII-code-per-character encoding, partially decodable), 38760286 / 38760486 / 38760565 (garbled CID-font garbage), 39580015 / 39580192 (math-symbol-only fragments), 39580243 (no text extracted).

## Papers
- **38760001.pdf** — Concurrent Zero Knowledge without Complexity Assumptions (Micciancio, Ong, Sahai, Vadhan). Unconditional concurrent statistical ZK proofs for problems like Graph Isomorphism and approximate lattice SVP/CVP, no one-way functions needed.
- **38760021.pdf** — Interactive Zero-Knowledge with Restricted Random Oracles (Yung, Zhao). Studies ZK in a restricted random-oracle model; gives a 2-round protocol for some languages and concurrent security for modified Feige-Shamir in the bare public-key model.
- **38760041.pdf** — Non-Interactive Zero-Knowledge from Homomorphic Encryption (Damgård, Fazio, Nicolosi). Compiles Sigma-protocols into NIZK arguments via homomorphic encryption without random oracles; yields non-interactive threshold RSA and efficient NIZK for NP.
- **38760060.pdf** — Ring Signatures: Stronger Definitions, and Constructions without Random Oracles (Bender, Katz, Morselli). Proposes stronger anonymity/unforgeability definitions for ring signatures and gives standard-model constructions.
- **38760080.pdf** — Efficient Blind and Partially Blind Signatures Without Random Oracles (Okamoto, decoded from ASCII-code dump). New efficient bilinear-map signature scheme secure in the standard model, applied to blind and partially blind signatures.
- **38760100.pdf** — Key Exchange Using Passwords and Long Keys (Kolesnikov, Rackoff). New key-exchange model combining passwords and stored long keys; shows a flaw in Halevi–Krawczyk protocols and gives a simple secure protocol with denial-of-access protection.
- **38760120.pdf** — Mercurial Commitments: Minimal Assumptions and Efficient Constructions (Catalano, Dodis, Visconti). Builds trapdoor mercurial commitments (key for zero-knowledge sets) from any trapdoor bit commitment, closing an assumption gap.
- **38760145.pdf** — Efficient Collision-Resistant Hashing from Worst-Case Assumptions on Cyclic Lattices (Peikert, Rosen). Generalized knapsack function made collision-resistant under worst-case cyclic-lattice assumptions, giving near-linear-time hash functions (SWIFFT line).
- **38760167.pdf** — On Error Correction in the Exponent (Peikert). Decoding Reed-Solomon codes given only group elements g^w_i; unique decoding reduces to CDH, but bounded-distance decoding is as hard as discrete log.
- **38760184.pdf** — On the Relation Between the Ideal Cipher and the Random Oracle Models (Dodis, Puniya). Shows Luby-Rackoff with superlogarithmic rounds instantiates an ideal cipher from random oracles in the honest-but-curious model.
- **38760207.pdf** — Intrusion-Resilience via the Bounded-Storage Model (Dziembowski). Achieves session-key generation and authentication that stay secure after malware infection, assuming bounded data exfiltration.
- **38760226.pdf** — Perfectly Secure Password Protocols in the Bounded Retrieval Model (Di Crescenzo, Lipton, Walfish). Formal model where adversary retrieves bounded private memory; gives password authentication secure against offline dictionary attacks.
- **38760246.pdf** — Polylogarithmic Private Approximations and Efficient Matching (Indyk, Woodruff). First two-party private l2-distance approximation with polylogarithmic communication, plus sublinear-communication private approximate near-neighbor protocols.
- **38760266.pdf** — Calibrating Noise to Sensitivity in Private Data Analysis (Dwork, McSherry, Nissim, Smith). Adds noise scaled to a query function's global sensitivity to preserve privacy; foundational differential-privacy mechanism needing less noise than prior work.
- **38760286.pdf** — Garbled CID-font extraction; only math fragments (bit decomposition, O(l log l)) visible. Title and content not recoverable (?).
- **38760306.pdf** — Efficient Multi-Party Computation with Dispute Control (Beerliová, Hirt). Active MPC with optimal t < n/2 security communicating only O(n^2) field elements per multiplication via a new dispute-control technique.
- **38760330.pdf** — Round-Optimal and Efficient Verifiable Secret Sharing (Fitzi, Garay, Gollakota, Rangan, Srinathan). First efficient three-round perfect VSS protocol, matching the known round lower bound, via three-round weak VSS.
- **38760344.pdf** — Generalized Environmental Security From Number Theoretic Assumptions (Malkin, Moriarty, Yakovenko). Concurrently composable secure computation in the gES framework from a new relativized discrete-log assumption, replacing non-standard hash assumptions.
- **38760361.pdf** — Games and the Impossibility of Realizable Ideal Functionality (Datta, Derek, Mitchell, Ramanathan, Scedrov). Shows bit commitment and some group-signature notions admit no realizable ideal functionality under game-based definitions.
- **38760381.pdf** — Universally Composable Symbolic Analysis of Mutual Authentication and Key-Exchange Protocols (Canetti, Herzog). Cryptographically sound Dolev-Yao symbolic analysis: a symbolic criterion iff UC-security for a class of public-key protocols.
- **38760405.pdf** — Resource Fairness and Composability of Cryptographic Protocols (Garay, MacKenzie, Prabhakaran, Yang). Defines resource-fair protocols (all parties get output with similar resources invested) with UC-like composability, circumventing fairness impossibility.
- **38760430.pdf** — Finding Pessiland (Wee). Oracle separation: a 2-round polylog-communication argument system for NP exists relative to an oracle with no one-way functions, so such arguments don't black-box imply OWFs.
- **38760447.pdf** — Pseudorandom Generators from One-Way Functions: A Simple Construction for Any Hardness (Holenstein). More randomness-efficient PRG constructions from one-way functions, improving the HILL O(n^8) seed cost when the OWF is exponentially hard.
- **38760466.pdf** — On the Complexity of Parallel Hardness Amplification for One-Way Functions (Lu). Lower bounds on black-box non-adaptive hardness amplification and PRG-from-OWF constructions by constant-depth circuits.
- **38760486.pdf** — Garbled CID-font extraction with letters interspersed with spaces; fragments suggest a construction from one-way permutations (hard-core bits) (?). Not reliably summarizable.
- **38760506.pdf** — Secure Computation with Partial Message Loss (Koo). MPC model intermediate between guaranteed and unreliable delivery; guarantees output to honest parties losing only a small fraction of messages.
- **38760526.pdf** — Communication Efficient Secure Linear Algebra (Nissim, Weinreb). Secure Gaussian elimination on encrypted matrices with ~O(k^2) communication, yielding efficient protocols for subspace intersection and linear systems.
- **38760546.pdf** — Threshold and Proactive Pseudo-Random Permutations (Dodis, Yampolskiy, Yung). O(1)-round threshold/proactive PRP via a distributed Luby-Rackoff construction with shared key and input; plus oblivious PRF protocols.
- **38760565.pdf** — Garbled CID-font extraction; mentions pairing/short-signature-like fragments (?) but title and content not reliably recoverable. Not summarizable.
- **38760585.pdf** — Chosen-Ciphertext Security from Tag-Based Encryption (Kiltz). Shows selective-tag TBE suffices for the CHK transformation; efficient TBE from Decisional Linear in gap groups gives CCA-secure encryption with fast decryption.
- **38760605.pdf** — Separating Sources for Encryption and Secret Sharing (Dodis, Pietrzak, Przydatek). Separates imperfect random sources usable for one-bit encryption from those usable for 2-out-of-2 secret sharing; extraction strictly implies encryption.
- **390.pdf** — A Practical Attack on the Fixed RC4 in the WEP Mode (Mantin). Practical RC4 key-recovery using Jenkins' correlation even when the first 256 keystream bytes are discarded; also improved IV-after-key and fault attacks.
- **39580001.pdf** — New Attacks on RSA with Small Secret CRT-Exponents (Bleichenbacher, May). Improves polynomial-time attack on unbalanced RSA to q < N^0.468 via Coppersmith's method, and attacks balanced RSA when dp, dq are small relative to N/e.
- **39580015.pdf** — Math-only fragment defining Generalized Reed-Solomon codes GRS_{n,k}(alpha, x) and their duals; title and authorship not recoverable (?).
- **39580028.pdf** — Cryptanalysis of an Efficient Proof of Knowledge of Discrete Logarithm (Kunz-Jacques, Martinet, Poupard, Stern). Attack on Bangerter–Camenisch–Maurer PKC 2005 protocol letting the verifier recover the full secret after few iterations.
- **39580045.pdf** — Efficient Polynomial Operations in the Shared-Coefficients Setting (Mohassel, Franklin). Constant-round MPC protocols for polynomial multiplication, division, interpolation and gcd using threshold homomorphic encryption, with set-operation applications.
- **39580060.pdf** — Generic On-line/Off-line Threshold Signatures (Crutchfield, Molnar, Turner, Wagner). Converts any threshold signature to on-line/off-line form via hash-sign-switch and distributed key generation; proven under one-more-DL.
- **39580077.pdf** — Linear Integer Secret Sharing and Distributed Exponentiation (Damgård, Thorbek). Introduces linear integer secret sharing for any access structure and uses it for distributed exponentiation, implying distributed RSA with arbitrary exponents.
- **39580093.pdf** — Encoding-Free ElGamal Encryption Without Random Oracles (Chevallier-Mames, Paillier, Pointcheval). ElGamal variant avoiding plaintext-to-group encoding or hashing, keeping standard-model security and boosting encryption ratio.
- **39580107.pdf** — Parallel Key-Insulated Public Key Encryption (Hanaoka, Hanaoka, Imai). Key-insulated PKE with two independent helper keys alternately updating the decryption key, reducing helper-key exposure risk.
- **39580124.pdf** — Provably Secure Steganography with Imperfect Sampling (Lysyanskaya, Meyerovich). Models covertext distribution as a stateful Markov process to weaken sampling assumptions; shows insufficient state knowledge is catastrophic.
- **39580141.pdf** — Collision-resistant No More: Hash-and-sign Paradigm Revisited (Mironov). Modifies DSA, PSS-RSA and Cramer-Shoup to use target-collision-resistant hashing keyed by a signature component, avoiding CR-hash dependence.
- **39580158.pdf** — Higher Order Universal One-Way Hash Functions from the Subset Sum Assumption (Steinfeld, Pieprzyk, Wang). Proves subset-sum hash is a kth-order UOWHF under the subset-sum assumption, enabling Merkle-Damgård domain extension.
- **39580175.pdf** — An Algorithm to Solve the Discrete Logarithm Problem with the Number Field Sieve (Commeine, Semaev). NFS algorithm for DLP in F_p* with L_p[1/3, 1.9018] precomputation and much cheaper individual-log stage.
- **39580192.pdf** — Math-only fragment on elliptic-curve l-isogenies, multiplication-by-l maps and Weierstrass forms; title and authorship not recoverable (?).
- **39580209.pdf** — Curve25519: new Diffie-Hellman speed records (Bernstein). High-security Montgomery-curve ECDH with record speeds, free key compression/validation and constant-time timing-attack protection.
- **39580231.pdf** — Strongly Unforgeable Signatures Based on Computational Diffie-Hellman (Boneh, Shen, Waters). Efficient strongly unforgeable signature scheme in the standard model from plain CDH in bilinear groups, weakening prior strong assumptions.
- **39580243.pdf** — No text extracted from the PDF; cannot summarize.
- **39580260.pdf** — Identity-Based Aggregate Signatures (Gentry, Ramzan). Aggregate signatures where verification needs no signer public keys — only who-signed-what plus two constant-length tags.
- **39580277.pdf** — On the Limitations of the Spread of an IBE-to-PKE Transformation (Kiltz). Shows simplifying the CHK transform applied to the second Boneh-Boyen IBE nearly converges to the Boyen–Mei–Waters scheme, so both instantiations yield essentially one scheme.
