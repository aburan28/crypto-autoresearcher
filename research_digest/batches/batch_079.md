# Batch 079 digest

## Overview
- Strongly symmetric-crypto / FSE-2008-era batch: hash function cryptanalysis dominates (SHA-0, step-reduced SHA-256, MD4 preimage, HAVAL, GOST, LASH, Snefru, LAKE, SWIFFT), plus stream-cipher attacks (RC4, KeeLoq, Salsa20/ChaCha/Rumba, Trivium, self-shrinking generator, FCSR entropy).
- Second large cluster: side-channel/fault attacks and countermeasures and hardware implementation (second-order SCA protection, AES collision/power attacks, RSA-CRT fault countermeasures, ECC on FPGA/GPU, TRNGs, PUF fuzzy extractors) — largely CHES 2008 vintage, many Ruhr-University Bochum authors.
- Small theory cluster at the front: tamper-proof-hardware UC commitments (Moran–Segev; Chandran–Goyal–Sahai), point-function obfuscation (Canetti–Dakdouk), isolated proofs of knowledge (Damgård–Nielsen–Wichs).
- Only one pairing/identity-based paper (512.pdf, Barreto et al. IB signcryption); essentially no ECDLP content in this batch.
- Anomalies: 49650468.pdf extracted as hex-escaped text (title decodable); 50860338.pdf and 51540196.pdf are PDF glyph-encoded (unreadable); 50860388.pdf has no extractable text.

## Papers
- **49650468.pdf** — Detection of Algebraic Manipulation with Applications to Robust Secret Sharing and Fuzzy Extractors (Cramer, Dodis, Fehr, Padró, Wichs). Text hex-escaped but title decodable; abstract truncated. Algebraic manipulation detection codes applied to robust secret sharing and fuzzy extractors.
- **49650486.pdf** — Obfuscating Point Functions with Multibit Output (Ran Canetti, Ronny Ramzi Dakdouk). Constructs obfuscators for multibit-output point functions, identifies composition weaknesses in existing obfuscation definitions, and proposes composition-preserving notions.
- **49650506.pdf** — Isolated Proofs of Knowledge and Isolated Zero Knowledge (Ivan Damgård, Jesper Buus Nielsen, Daniel Wichs). Defines ℓ-isolated proofs of knowledge where the prover may leak at most ℓ bits to an environment, and constructs such protocols for any NP relation.
- **49650524.pdf** — David and Goliath Commitments: UC Computation for Asymmetric Parties Using Tamper-Proof Hardware (Tal Moran, Gil Segev). UC commitment protocols where only one party (Goliath) needs to create tamper-proof hardware tokens, with variants for unbounded and efficient settings.
- **49650542.pdf** — New Constructions for UC Secure Computation using Tamper-proof Hardware (Nishanth Chandran, Vipul Goyal, Amit Sahai). New UC-secure multi-party computation constructions in Katz's tamper-proof hardware token model, avoiding trusted setup.
- **50860001.pdf** — Collisions for Step-Reduced SHA-256 (Ivica Nikolić, Alex Biryukov). Differential attack yielding full collisions for 21-step SHA-256 and semi-free-start (near-)collisions for 23- and 25-step versions.
- **50860017.pdf** — Collisions on SHA-0 in one hour (Stéphane Manuel, Thomas Peyrin). Improved boomerang-based differential attack with a new 2-block perturbation vector; finds SHA-0 collisions at ~2^33.6 operations, about one hour on a PC.
- **50860036.pdf** — The Hash Function Family LAKE (Jean-Philippe Aumasson, Willi Meier, Raphael C.-W. Phan). New HAIFA-based hash family with nested feed-forward and wide-pipe compression; proposes 256- and 512-bit instances.
- **50860052.pdf** — SWIFFT: A Modest Proposal for FFT Hashing (Lyubashevsky, Micciancio, Peikert, Rosen). FFT-based parallelizable compression functions with SHA-256-competitive speed and provable security from worst-case ideal-lattice hardness.
- **50860068.pdf** — A Unified Approach to Related-Key Attacks (Eli Biham, Orr Dunkelman, Nathan Keller). Framework combining prior related-key attack flavors into a round-count-independent attack; first attack on 8-round IDEA and on 4r-round IDEA.
- **50860088.pdf** — Algebraic and Slide Attacks on KeeLoq (Nicolas T. Courtois, Gregory V. Bard, David Wagner). Multiple attacks on the KeeLoq car-access cipher, including a slide-algebraic SAT-solver attack (~2^53) — first full-round algebraic break of a real-life block cipher.
- **50860106.pdf** — A Meet-in-the-Middle Attack on 8-Round AES (Hüseyin Demirci, Ali Aydın Selçuk). 5-round AES distinguisher extended to meet-in-the-middle attacks on 7-round AES-192 and 8-round AES-256, with time-memory tradeoffs.
- **50860118.pdf** — Block Ciphers Implementations Provably Secure Against Second Order Side Channel Analysis (Rivain, Dottax, Prouff). Two new masking countermeasures against second-order SCA with proofs in a strong model, applicable efficiently to AES and other block ciphers.
- **50860138.pdf** — SQUASH — A New MAC With Provable Security Properties for Highly Constrained Devices Such As RFID Tags (Adi Shamir). Simple square-based challenge-response MAC for RFID tags, provably at least as secure as Rabin encryption in this application.
- **50860152.pdf** — Differential Fault Analysis of Trivium (Michal Hojsík, Bohuslav Rudolf). First differential fault analysis of an NLFSR-based stream cipher; recovers Trivium's internal state and key with ~43 single-bit faults.
- **50860168.pdf** — Accelerating the Whirlpool Hash Function using Parallel Table Lookup and Fast Cyclical Permutation (Hilewitz, Yin, Lee). New Whirlpool software implementation using PTLU ISA extensions and a cyclical permutation algorithm, achieving 8.8–13.9× speedups.
- **50860185.pdf** — Second Preimage Attack on 3-Pass HAVAL and Partial Key-Recovery Attacks on HMAC/NMAC-3-Pass HAVAL (Lee, Chang, Kim, Sung, Hong). New differential path enabling second-preimage attack on 3-pass HAVAL and partial key recovery on HMAC/NMAC-HAVAL.
- **50860204.pdf** — Cryptanalysis of LASH (Steinfeld, Contini, Matusiewicz, Pieprzyk, Guo, Ling, Wang). Time-memory tradeoff collision (~2^{4x/11}) and preimage attacks on LASH exploiting the all-zero IV, plus PRF and generalized-birthday attacks.
- **50860224.pdf** — A (Second) Preimage Attack on the GOST Hash Function (Mendel, Pramstaller, Rechberger). Pseudo-preimage on GOST's compression function extended via multicollision and meet-in-the-middle on the checksum to ~2^225 (second) preimage attack.
- **50860235.pdf** — Guess-and-determine Algebraic Attack on the Self-Shrinking Generator (Blandine Debraize, Louis Goubin). Guess-and-determine attack with SAT-solver equation solving on SSG with low-weight (≤5) feedback polynomials, beating prior tradeoffs.
- **50860255.pdf** — New Form of Permutation Bias and Secret Key Leakage in Keystream Bytes of RC4 (Subhamoy Maitra, Goutam Paul). Shows S[S[y]] biases after RC4's KSA and builds a framework of keystream-byte biases toward secret-key linear combinations, including at bytes 256–257.
- **50860272.pdf** — Efficient Reconstruction of RC4 Keys from Internal States (Eli Biham, Yaniv Carmeli). Algorithm recovering RC4 keys from internal states orders of magnitude faster than prior work; 40-bit keys in ~0.02 s with 86.4% success.
- **50860292.pdf** — An Improved Security Bound for HCTR (Debrup Chakraborty, Mridul Nandi). Improves HCTR's tweakable SPRP security bound from cubic to 4.5σ²/2^n, rehabilitating it for practical use.
- **50860307.pdf** — How to Encrypt with a Malicious Random Number Generator (Seny Kamara, Jonathan Katz). New security notions for encryption when random coins are faulty or adversarially influenced, with two concrete schemes and generic transformations.
- **50860320.pdf** — A One-Pass Mode of Operation for Deterministic Message Authentication — Security beyond the Birthday Barrier (Kan Yasuda). One-pass, deterministic, single-keyed domain-extension mode for PRF-based MACs with beyond-birthday-barrier security.
- **50860338.pdf** — (?) Hash-function paper, title unreadable: text extracted as PDF glyph codes; mentions a 512-bit hash algorithm and the NIST SHA-3 competition. Anomaly: undecodable extraction.
- **50860348.pdf** — Entropy of the Internal State of an FCSR in Galois Representation (Andrea Röck). Analyzes entropy loss in Galois-representation FCSRs, giving an algorithm to compute final entropy and showing entropy never drops below main-register size.
- **50860368.pdf** — Bit-Pattern Based Integral Attack (Z'aba, Raddum, Henricksen, Dawson). Extends integral cryptanalysis to bit-based ciphers via bit-pattern notation; first integral attacks on Noekeon and PRESENT, plus reduced-round Serpent.
- **50860388.pdf** — No text extracted from first page; content cannot be identified. Anomaly.
- **50860404.pdf** — Impossible Differential Cryptanalysis of CLEFIA (Tsunoo, Tsujihara, Shigeri, Saito, Suzaki, Kubo). New 9-round impossible differentials for CLEFIA enabling the strongest known attacks on 12–14-round reduced CLEFIA.
- **50860419.pdf** — MD4 is Not One-Way (Gaëtan Leurent). First preimage attack on an MD4-family member: 2^96 on the compression function, extended to 2^102 on full MD4.
- **50860436.pdf** — Improved Indifferentiability Security Analysis of chopMD Hash Function (Donghoon Chang, Mridul Nandi). Tighter indifferentiability bound for chopMD, proving security beyond birthday complexity, plus a new n-bit hash design principle.
- **50860452.pdf** — New Techniques for Cryptanalysis of Hash Functions and Improved Attacks on Snefru (Eli Biham). Applies modern differential techniques to Snefru with near-zero memory, giving a preimage attack on 2-pass Snefru; remarks on padding of Snefru/MD4.
- **50860470.pdf** — On the Salsa20 Core Function (Hernandez-Castro, Tapiador, Quisquater). Finds invariants in Salsa20's quarterround allowing 2^31 collisions for the full 20-round core and shows lack of second-preimage resistance.
- **50860479.pdf** — New Features of Latin Dances: Analysis of Salsa, ChaCha, and Rumba (Aumasson, Fischer, Khazaei, Meier, Rechberger). Neutral-bits differential method breaks 256-bit Salsa20/8 and 6–7-round ChaCha; collision attack on 3-round Rumba reduced to 2^79.
- **512.pdf** — Efficient and Provably-Secure Identity-Based Signatures and Signcryption from Bilinear Maps (Barreto, Libert, McCullagh, Quisquater). Faster-than-prior pairing-based identity-based signcryption and signature schemes with random-oracle security proofs.
- **51540001.pdf** — Attack and Improvement of a Secure S-box Calculation Based on the Fourier Transform (Coron, Giraud, Prouff, Rivain). Breaks a CHES 2006 Fourier-transform DPA countermeasure with first-order DPA, then proposes and proves a fixed version.
- **51540017.pdf** — Collision-based Power Analysis of Modular Exponentiation Using Chosen-message Pairs (Homma, Miyamoto, Aoki, Satoh, Shamir). Chosen-message collision power attacks defeating all standard RSA exponentiation methods, validated on FPGA and PowerPC.
- **51540031.pdf** — Multiple-Differential Side-Channel Collision Attacks on AES (Andrey Bogdanov). Binary/ternary voting collision detection combined with linear/algebraic key recovery; outperforms CPA on AES with far fewer traces, even without known S-box.
- **51540047.pdf** — Time-Area Optimized Public-Key Engines: MQ-Cryptosystems as Replacement for Elliptic Curves? (Bogdanov, Eisenbarth, Rupp, Wolf). Hardware MQ-scheme implementations (e.g., amended TTS) with far better time-area product than ECC; proposes systolic small-field MQ framework.
- **51540064.pdf** — Ultra High Performance ECC over NIST Primes on Commercial FPGAs (Tim Güneysu, Christof Paar). DSP-block-based FPGA architecture for ECC over NIST primes P-224/P-256, achieving very high point-multiplication throughput on Virtex-4.
- **51540081.pdf** — Exploiting the Power of GPUs for Asymmetric Cryptography (Robert Szerwinski, Tim Güneysu). GPU acceleration of RSA, DSA, and ECC: 813 1024-bit exponentiations/s and 1412 P-224 point multiplications/s on an Nvidia 8800GTS.
- **51540098.pdf** — High-performance Concurrent Error Detection Scheme for AES Hardware (Satoh, Sugawara, Homma, Aoki). Round-function-splitting concurrent error detection for AES hardware with low size/speed overhead; 90-nm implementations at 2.2–3.2 Gbps.
- **51540111.pdf** — A Lightweight Concurrent Fault Detection Scheme for the AES S-boxes Using Normal Basis (Mozaffari-Kermani, Reyhani-Masoleh). Low-overhead parity-based fault detection for composite-field AES S-boxes using normal basis, outperforming polynomial-basis designs on FPGA.
- **51540128.pdf** — RSA with CRT: A New Cost-Effective Solution to Thwart Fault Attacks (David Vigilant). Low-cost software countermeasure for RSA-CRT signature fault attacks suited to constrained embedded devices; extends to other modular-exponentiation schemes.
- **51540144.pdf** — A Design for a Physical RNG with Robust Entropy Estimators (Wolfgang Killmann, Werner Schindler). Noisy-diode physical RNG design with a stochastic model and theorem giving tight lower bounds on entropy per bit, applied to a prototype.
- **51540162.pdf** — Fast Digital TRNG Based on Metastable Ring Oscillator (Vasyltsov, Hambardzumyan, Kim, Karpinskyy). All-digital TRNG exploiting ring-oscillator metastability for high throughput; passes AIS.31 and FIPS 140-1/2 tests.
- **51540179.pdf** — Efficient Helper Data Key Extractor on FPGAs (Bösch, Guajardo, Sadeghi, Shokrollahi, Tuyls). First efficient FPGA fuzzy-extractor implementations for PUF-based key generation/IP protection, with new Reed–Muller and Golay decoder architectures.
- **51540196.pdf** — (?) Pollard kangaroo/lambda-method elliptic-curve paper (authors incl. Jean-François ?): text extracted as PDF glyph codes, undecodable; title guess only. Anomaly.
- **51540210.pdf** — Recovering Secret Keys from Weak Side Channel Traces of Differing Lengths (Colin D. Walter). Hidden-Markov-model prefix-parallel trace combination enabling ECC key recovery from misaligned, low-SNR side-channel traces with feasible search.
