# Batch 010 digest

## Overview
- This batch is a coherent run of what appear to be EUROCRYPT 2018 papers (sequential IDs 10822186–10822378, 18–40 pages each); all 50 are legitimate research papers, no garbage, statements, or slides.
- Dominant themes: secure computation/MPC round complexity (concurrent black-box MPC, garbled RAM, OT-from-MPC, topology-hiding), zero-knowledge/proof systems (SNARGs, SWI, SZK transformations, proofs of sequential work), and random-oracle-model foundations (QROM Fiat-Shamir, correlation intractability, global random oracles).
- Strong secondary threads: symmetric cryptanalysis (boomerang connectivity table, cube attacks, GCM forgeries, CTR missing-difference), lattice cryptography (GLP masking, SVP sieving, RLWE/PLWE reductions, Gaussian sampling), and blockchain consensus (Ouroboros Praos, rational-protocol-design Bitcoin).
- Only one paper touches elliptic curves directly (10822193, supersingular isogeny graphs / endomorphism rings) — ECDLP/ECC content is nearly absent; this batch is mostly theory cryptography.
- Notable named results: OPAQUE asymmetric PAKE, Ouroboros Praos PoS blockchain, Overdrive SPDZ improvements, and the refutation of the Lin–Tessaro iO candidate (10822365).
- Anomalies: none — every file parsed as a valid crypto paper with coherent title/abstract; no duplicates detected.

## Papers
- **10822186.pdf** — A New Approach to Black-Box Concurrent Secure Computation (Garg, Kiyoshima, Pandey). Builds concurrently composable secure computation with black-box primitives via constant-round super-polynomial-simulation OT, avoiding CCA-secure commitments.
- **10822188.pdf** — Quasi-Optimal SNARGs via Linear Multi-Prover Interactive Proofs (Boneh, Ishai, Sahai, Wu). First quasi-optimal SNARG for circuit satisfiability from concrete assumptions, via a quasi-optimal linear MIP plus a cryptographic compiler.
- **10822193.pdf** — Supersingular Isogeny Graphs and Endomorphism Rings: Reductions and Solutions (Eisenträger, Hallgren, Lauter, Morrison, Petit). Proves heuristic polynomial reductions between isogeny path-finding and endomorphism ring computation, with applications to the Charles–Goren–Lauter hash.
- **10822196.pdf** — A Concrete Treatment of Fiat-Shamir Signatures in the Quantum Random-Oracle Model (Kiltz, Lyubashevsky, Schaffner). Gives a generic tight-reduction framework for Fiat-Shamir signature security in the QROM using lossy identification schemes.
- **10822203.pdf** — On the Gold Standard for Security of Universal Steganography (Berndt, Liśkiewicz). Resolves Hopper's problem: builds SS-CCA-secure universal steganography for all memoryless channels and shows it is best possible.
- **10822206.pdf** — Masking the GLP Lattice-Based Signature Scheme at Any Order (Barthe, Belaïd, Espitau, Fouque, Grégoire, Rossi, Tibouchi). First masked (side-channel-protected) implementation of a lattice-based signature scheme at arbitrary masking order.
- **10822211.pdf** — Shortest Vector from Lattice Sieving: a Few Dimensions for Free (Ducas). Improves SVP sieving by reducing dimension-n sieving to calls in dimension n−Θ(n/log n), giving ~10× speedups in practice.
- **10822214.pdf** — Masking Proofs are Tight and How to Exploit it in Security Evaluations (Grosso, Standaert). Shows tightness of masking security proofs simplifies side-channel evaluation of masked implementations to near-unprotected-case analysis.
- **10822219.pdf** — Boomerang Connectivity Table: A New Cryptanalysis Tool (Cid, Huang, Peyrin, Sasaki, Song). Introduces the BCT to systematically capture dependencies between differential characteristics in boomerang attacks on block ciphers.
- **10822222.pdf** — Naor-Reingold Goes Public: The Complexity of Known-key Security (Soni, Tessaro). Two-call constructions of public-seed PRPs and correlation-intractable ciphers from Naor–Reingold, matching secret-key complexity.
- **10822224.pdf** — Fuzzy Password-Authenticated Key Exchange (Dupont, Hesse, Pointcheval, Reyzin, Yakoubov). Defines UC fuzzy PAKE enabling key agreement from noisy low-entropy secrets such as biometrics.
- **10822227.pdf** — Simple Proofs of Sequential Work (Cohen, Pietrzak). Simpler, publicly verifiable proofs of sequential work in the random oracle model, motivated by blockchain PoW alternatives.
- **10822239.pdf** — Bloom Filter Encryption and Applications to Efficient Forward-Secret 0-RTT Key Exchange (Derler, Jager, Slamanig, Striecks). Introduces Bloom filter encryption to build practical forward-secret 0-RTT key exchange, improving on impractical puncturable encryption.
- **10822242.pdf** — Efficient Circuit-based PSI via Cuckoo Hashing (Pinkas, Schneider, Weinert, Wieder). Circuit-based private set intersection with near-linear comparisons using two-dimensional Cuckoo hashing variants.
- **10822243.pdf** — Homomorphic SIM²D Operations: Single Instruction Much More Data (Castryck, Iliashenko, Vercauteren). Generalizes CRT packing for homomorphic encryption via Laurent polynomial encoding, increasing plaintext packing capacity.
- **10822244.pdf** — Unforgeable Quantum Encryption (Alagic, Gagliardoni, Majenz). Defines ciphertext unforgeability, CCA security, and authenticated encryption for quantum data, with constructions from one-time authentication plus classical pseudorandomness.
- **10822245.pdf** — Improving the Linear Programming Technique in the Search for Lower Bounds in Secret Sharing (Farràs, Kaced, Martín, Padró). New LP technique yielding optimal information ratios for linear secret sharing on all 5-participant and graph-based 6-participant access structures.
- **10822247.pdf** — Efficient Maliciously Secure Multiparty Computation for RAM (Keller, Yanai). First concretely efficient garbled-circuit-based actively secure RAM computation with dishonest majority, using SPDZ authenticated shares.
- **10822252.pdf** — On the Ring-LWE and Polynomial-LWE Problems (Rosca, Stehlé, Wallet). Gives low-loss (non-uniform) reductions among dual/primal Ring-LWE and Polynomial-LWE variants.
- **10822253.pdf** — Optimal Forgeries Against Polynomial-Based MACs and GCM (Luykx, Preneel). New forgery attacks matching Bernstein's PRP-based bounds, settling optimality of attacks on polynomial MACs like GCM and Poly1305.
- **10822257.pdf** — Collision Resistant Hashing for Paranoids: Dealing with Multiple Collisions (Komargodski, Naor, Yogev). Introduces Multi-CRH (hard to find k-way collisions) and shows it suffices for commitments and succinct arguments with interaction.
- **10822259.pdf** — Non-malleable Randomness Encoders and their Applications (Kanukurthi, Obbattu, Sekar). Relaxes non-malleable codes to randomness encoding, achieving rate-1/2 in the 2-split-state model with tamper-resilience applications.
- **10822261.pdf** — The Communication Complexity of Private Simultaneous Messages, Revisited (Applebaum, Holenstein, Mishra, Shayevitz). Finds a gap in the FKN 3k lower bound for PSM protocols and repairs it with additional requirements.
- **10822267.pdf** — Correlation Cube Attacks: From Weak-Key Distinguisher to Key Recovery (Liu, Yang, Wang, Lin). New cube-attack variant using conditional correlations, enabling key recovery on round-reduced Trivium.
- **10822268.pdf** — Overdrive: Making SPDZ Great Again (Keller, Pastro, Rotaru). SHE-based SPDZ preprocessing that beats MASCOT (6× LAN, 20× WAN for two parties) plus improved zero-knowledge proofs of plaintext knowledge.
- **10822280.pdf** — Statistical Witness Indistinguishability (and more) in Two Messages (Tauman Kalai, Khurana, Sahai). First two-message statistical WI arguments for NP, plus statistical SPS-ZK, from quasi-polynomially hard two-message OT.
- **10822287.pdf** — Updatable Encryption with Post-Compromise Security (Lehmann, Tackmann). Strong security models for ciphertext-independent updatable encryption, showing prior schemes fail post-compromise security, with new constructions.
- **10822293.pdf** — More Efficient (Almost) Tightly Secure Structure-Preserving Signatures (Gay, Hofheinz, Kohl, Pan). Structure-preserving signatures with almost-tight reduction, smaller signatures/keys and lower security loss than Abe et al.
- **10822295.pdf** — Memory Lower Bounds of Reductions Revisited (Wang, Matsuda, Hanaoka, Tanaka). Shows memory-tightness loss is unavoidable for large classes of black-box reductions from multi-challenge security without running-time sacrifice.
- **10822297.pdf** — Faster Gaussian Sampling for Trapdoor Lattices with Arbitrary Modulus (Genise, Micciancio). Linear-complexity preimage sampling for MP12 trapdoors at any modulus, plus quasi-linear ring-setting perturbation sampling.
- **10822298.pdf** — Exploring the Boundaries of Topology-Hiding Computation (Ball, Boyle, Malkin, Moran). Shows topology-hiding broadcast on tiny graphs implies OT, and proves leakage-vs-round tradeoff lower bounds for fail-stop THC.
- **10822304.pdf** — Fiat-Shamir and Correlation Intractability from Strong KDM-Secure Encryption (Canetti, Chen, Reyzin, Rothblum). Constructs correlation-intractable hash for all sparse relations from strong KDM-secure encryption (e.g., ElGamal), instantiating Fiat-Shamir soundness.
- **10822308.pdf** — Another Step Towards Realizing Random Oracles: Non-Malleable Point Obfuscation (Komargodski, Yogev). Standard-model point-function obfuscator achieving the non-malleability property of random oracles.
- **10822313.pdf** — Revisiting AES-GCM-SIV: Multi-user Security, Faster Key Derivation, and Better Bounds (Bose, Hoang, Tessaro). Multi-user security analysis of AES-GCM-SIV showing security comparable to single-user setting, with improved bounds and cheaper key derivation.
- **10822314.pdf** — Untagging Tor: A Formal Treatment of Onion Encryption (Degabriele, Stam). Formalizes onion encryption security including circuit hiding, analyzes Tor's proposal 261 against tagging attacks.
- **10822317.pdf** — k-Round Multiparty Computation from k-Round Oblivious Transfer via Garbled Interactive Circuits (Benhamouda, Lin). Establishes that k-round OT is necessary and complete for k-round MPC (semi-honest any k≥2; malicious k≥5).
- **10822318.pdf** — The Missing Difference Problem, and its Applications to Counter Mode Encryption (Leurent, Sibleyras). Gives Õ(2^{n/2}) message-recovery attacks on CTR mode via the missing difference algorithmic problem.
- **10822321.pdf** — The Wonderful World of Global Random Oracles (Camenisch, Drijvers, Gagliardoni, Lehmann, Neven). New global random-oracle definitions enabling GUC-secure proofs of practical primitives (PKE, commitments, Schnorr signatures).
- **10822333.pdf** — Short, Invertible Elements in Partially Splitting Cyclotomic Rings and Applications to Lattice-Based Zero-Knowledge Proofs (Lyubashevsky, Seiler). Shows small-coefficient elements are invertible in cyclotomic rings even when Xⁿ+1 splits into many factors, improving lattice ZK parameters.
- **10822336.pdf** — But Why Does it Work? A Rational Protocol Design Treatment of Bitcoin (Badertscher, Garay, Maurer, Tschudi, Zikas). Analyzes Bitcoin via rational protocol design, showing revenue-maximizing miner incentives can replace the honest-majority assumption.
- **10822337.pdf** — An Efficiency-Preserving Transformation from Honest-Verifier Statistical Zero-Knowledge to Statistical Zero-Knowledge (Hubáček, Rosen, Vald). Unconditional round- and efficiency-preserving HVSZK→SZK transformation via instance-dependent SZK proofs for NP.
- **10822340.pdf** — The Complexity of Multiparty PSM Protocols and Related Models (Beimel, Kushilevitz, Nissim). Improved k-party PSM upper bounds, e.g., O(poly(k)·N^{k/2}) generally and O(N) for k=3.
- **10822341.pdf** — Full Indifferentiable Security of the Xor of Two or More Random Permutations Using the χ² Method (Bhattacharya, Nandi). Proves full n-bit indifferentiable security of XORP[k] for any k via the chi-squared method.
- **10822354.pdf** — Unbounded ABE via Bilinear Entropy Expansion, Revisited (Chen, Gong, Kowalczyk, Wee). Simpler adaptively secure unbounded ABE with constant-size public parameters under static assumptions, via a bilinear entropy expansion lemma.
- **10822355.pdf** — Anonymous IBE, Leakage Resilience and Circular Security from New Assumptions (Brakerski, Lombardi, Segev, Vaikuntanathan). Anonymous IBE from CDH via blind garbled circuits and blind batch encryption; also first high-rate leakage-resilient and KDM-secure PKE.
- **10822357.pdf** — Non-Malleable Codes from Average-Case Hardness: AC⁰, Decision Trees, and Streaming Space-Bounded Tampering (Ball, Dachman-Soled, Kulkarni, Malkin). Framework for NMCs against tampering classes with average-case hardness; first efficient constructions for AC⁰, decision trees, and streaming adversaries.
- **10822359.pdf** — OPAQUE: An Asymmetric PAKE Protocol Secure Against Pre-Computation Attacks (Jarecki, Krawczyk, Xu). Formalizes Strong aPAKE resisting pre-computation attacks upon server compromise; UC constructions from oblivious PRFs.
- **10822365.pdf** — Limits on Low-Degree Pseudorandom Generators (Or: Sum-of-Squares Meets Program Obfuscation) (Barak, Brakerski, Komargodski, Kothari). Bounds output length of block-local PRGs via SoS, refuting assumptions behind the Lin–Tessaro iO candidate.
- **10822372.pdf** — On the Complexity of Simulating Auxiliary Input (Chen, Chung, Liao). Improved Õ(2^ℓ ε⁻²)-overhead leakage simulation lemma with matching black-box lower bound.
- **10822378.pdf** — Ouroboros Praos: An Adaptively-Secure, Semi-Synchronous Proof-of-Stake Blockchain (David, Gaži, Kiayias, Russell). PoS blockchain secure against fully adaptive corruption in semi-synchronous networks, using forward-secure signatures and new VRFs.
