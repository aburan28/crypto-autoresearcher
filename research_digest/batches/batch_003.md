# Batch 003 digest

## Overview
- Dominated by 2016-era IACR ePrint papers (Crypto/Asiacrypt/TCC/Eurocrypt style), covering provable-security constructions, cryptanalysis, and post-quantum candidates.
- Direct ECC/ECDLP relevance: bit security of elliptic-curve Diffie–Hellman (101740346), extended Tower NFS threatening pairing key sizes (101740373), supersingular isogeny security analysis (10031307), and Ideal-SVP on structured lattices (10210116).
- Heavy presence of functional/attribute-based encryption, structure-preserving signatures, non-malleable/leakage-resilient codes, MPC round/complexity results, and obfuscation-based primitives (several UT-Austin/Aarhus groups recur).
- Notable cryptanalysis results: key recovery on QC-MDPC, zeroizing attacks on iO over CLT13, LP attack on binary-matrix LWE, improved k-list/SVP sieving.
- No duplicates, garbage, or non-paper content found; all 50 extracts are legitimate research paper first pages.

## Papers
- **10031302.pdf** — Cryptographic Applications of Capacity Theory: On the Optimality of Coppersmith's Method (Chinburg, Hemenway, Heninger, Scherr). Uses capacity theory to prove Coppersmith's N^{1/d} bound for univariate polynomial congruences is optimal, ruling out improved auxiliary polynomials.
- **10031305.pdf** — A Key Recovery Attack on MDPC with CCA Security Using Decoding Errors (Guo, Johansson, Stankovski). Recovers QC-MDPC secret keys in minutes by correlating iterative decoding failures with the key's distance spectrum.
- **10031307.pdf** — On the Security of Supersingular Isogeny Cryptosystems (Galbraith, Petit, Shani, Ti). Gives an active attack on isogeny encryption, reduces scheme security to endomorphism-ring computation, and proves first bit-security results for isogeny key exchange.
- **10031309.pdf** — Verifiable Functional Encryption (Badrinarayanan, Goyal, Jain, Sahai). Defines verifiable FE guaranteeing output correctness against malicious authorities/encryptors; shows simulation-based security impossible but gives indistinguishability-based compiler.
- **10031311.pdf** — How to Obtain Fully Structure-Preserving (Automorphic) Signatures from Structure-Preserving Ones (Wang, Zhang, Matsuda, Hanaoka, Tanaka). Generic conversion from SPS to FSPS via new trapdoor-signature and auxiliary-key primitives, yielding automorphic instantiations.
- **10031312.pdf** — A Tale of Two Shares: Why Two-Share Threshold Implementation Seems Worthwhile—and Why It Is Not (Chen, Farmani, Eisenbarth). Builds two-share TI of Simon/Present; compact but slower, and exhibits strong second-order leakage despite first-order resistance.
- **10031327.pdf** — A Shuffle Argument Secure in the Generic Model (Fauzi, Lipmaa, Zajac). Random-oracle-less NIZK shuffle argument for mix-nets with standard soundness in the generic bilinear group model and 3.5× faster verification.
- **10031332.pdf** — Efficient and Provable White-Box Primitives (Fouque, Karpman, Kirchner, Minaud). First incompressible white-box block-cipher constructions with provable security, efficient and competitive with prior heuristic designs.
- **10031343.pdf** — Cryptographic Reverse Firewall via Malleable Smooth Projective Hash Functions (Chen, Mu, Yang, Susilo, Guo, Zhang). Introduces malleable SPHFs to build generic reverse firewalls resisting exfiltration from compromised machines.
- **101740001.pdf** — LP Solutions of Vectorial Integer Subset Sums – Cryptanalysis of Galbraith's Binary Matrix LWE (Herold, May). Breaks Galbraith's binary-matrix LWE variant via (integer) linear programming in fractions of a second, including weak large-challenge instances.
- **101740014.pdf** — Improved Algorithms for the Approximate k-List Problem in Euclidean Norm (Herold, Kirshanova). Configuration-search plus LSH techniques improve BLS sieving, cutting 3-sieve SVP complexity from 2^0.4812n to 2^0.3962n.
- **101740039.pdf** — Zeroizing Attacks on Indistinguishability Obfuscation over CLT13 (Coron, Lee, Lepoint, Tibouchi). Polynomial-time zeroizing attack recovering CLT13 secret parameters from obfuscated branching programs, breaking most single-input iO over CLT13.
- **101740057.pdf** — Cut Down the Tree to Achieve Constant Complexity in Divisible E-Cash (Pointcheval, Sanders, Traoré). First divisible e-cash scheme without the binary-tree structure, achieving constant-time spending with standard-model security.
- **101740086.pdf** — Asymptotically Tight Bounds for Composing ORAM with PIR (Abraham, Fletcher, Nayak, Pinkas, Ren). Sub-logarithmic O(log^d N) ORAM bandwidth using d-ary trees and XOR-based two-server PIR, with matching lower bounds.
- **101740116.pdf** — Predictable Arguments of Knowledge (Faonio, Nielsen, Venturi). Initiates study of PAoKs where prover answers are predictable from verifier randomness; characterizes them and gives laconic one-bit constructions.
- **101740146.pdf** — Removing Erasures with Explainable Hash Proof Systems (Abdalla, Benhamouda, Pointcheval). Explainable projective hashing yields efficient UC-secure PAKE and OT against semi-adaptive and adaptive corruptions without erasures.
- **101740170.pdf** — Scalable Multi-Party Private Set-Intersection (Hazay, Venkitasubramaniam). Star-topology multi-party PSI protocols with communication linear in input sizes (semi-honest) and a maliciously secure variant.
- **101740197.pdf** — Tightly Secure IBE under Constant-size Master Public Key (Chen, Gong, Weng). IBE with constant-size master public key and tighter reduction in composite-order bilinear groups, partially solving Chen–Wee open problems.
- **101740222.pdf** — Separating IND-CPA and Circular Security for Unbounded Length Key Cycles (Goyal, Koppula, Waters). Assuming iO and leveled HE, builds IND-CPA scheme insecure for every key-cycle length, ruling out free circular security.
- **101740237.pdf** — Structure-Preserving Chosen-Ciphertext Security with Shorter Verifiable Ciphertexts (Libert, Peters, Qian). Publicly verifiable structure-preserving CCA2 encryption under SXDH with under 40 group elements per ciphertext, plus an improved RCCA scheme.
- **101740267.pdf** — Non-Malleable Codes with Split-State Refresh (Faonio, Nielsen). Split-state non-malleable codes allowing independent part refreshes, tolerating unbounded tampering and leakage over the system lifetime under XDH.
- **101740297.pdf** — Tight Upper and Lower Bounds for Leakage-Resilient, Locally Decodable and Updatable Non-Malleable Codes (Dachman-Soled, Kulkarni, Shahverdi). Proves super-constant locality is inherent for leakage-resilient locally decodable/updatable NMCs under rewind attacks, with tight bounds.
- **101740320.pdf** — Fully Leakage-Resilient Codes (Faonio, Nielsen). Defines FLRCs where the encoding process itself leaks; gives split-state impossibility results plus feasibility via inner-product codes and a CRS compiler.
- **101740346.pdf** — On the Bit Security of Elliptic Curve Diffie–Hellman (Shani). First bit-security result for ECDH over prime fields: about 5/6 of the most (or least) significant bits of the shared key's x-coordinate are as hard as the whole key.
- **101740373.pdf** — Extended Tower Number Field Sieve with Application to Finite Fields of Arbitrary Composite Extension Degree (Kim, Jeong). Generalizes exTNFS to arbitrary composite extension degrees at best known asymptotic complexity; warns pairing key sizes need updating.
- **101740395.pdf** — Provably Secure NTRU Instances over Prime Cyclotomic Rings (Yu, Xu, Wang). IND-CPA-secure NTRUEncrypt variant over prime cyclotomic rings with reductions from worst-case ideal-lattice problems in the standard model.
- **101740421.pdf** — Equivalences and Black-Box Separations of Matrix Diffie-Hellman Problems (Villar). Algebraic criteria for tight black-box reductions among MDDH problems; separates problems by parameter count and studies equivalence classes.
- **101750001.pdf** — Dual System Framework in Multilinear Settings and Applications to Fully Secure (Compact) ABE for Unbounded-Size Circuits (Attrapadung). Generic dual-system framework over composite-order multilinear encodings yielding fully secure, succinct KP/CP-ABE for unbounded circuits.
- **101750032.pdf** — CCA-Secure Inner-Product Functional Encryption from Projective Hash Functions (Benhamouda, Bourse, Lipmaa). Generic IND-FE-CCA inner-product FE from homomorphic projective hash functions, instantiated under DCR, DDH, and MDDH.
- **101750062.pdf** — Bounded-Collusion Attribute-Based Encryption from Minimal Assumptions (Itkis, Shen, Varia, Wilson, Yerukhimovich). Bounded-collusion ABE from plain semantically secure PKE with much smaller parameters; secret-key size independent of collusion bound.
- **101750084.pdf** — Access Control Encryption for Equality, Comparison, and More (Fuchsbauer, Gay, Kowalczyk, Orlandi). Polylogarithmic-complexity ACE for equality/comparison/interval predicates from SXDH or in the generic group model.
- **101750114.pdf** — Deterring Certificate Subversion: Efficient Double-Authentication-Preventing Signatures (Bellare, Poettering, Stebila). Efficient DAPS from trapdoor identification with tight reductions; signing two same-prefix messages reveals the key, deterring rogue CA certificates.
- **101750144.pdf** — Chameleon-Hashes with Ephemeral Trapdoors and Applications to Invisible Sanitizable Signatures (Camenisch, Derler, Krenn, Pöhls, Samelin, Slamanig). New chameleon-hash notion where the main trapdoor alone cannot find collisions, with applications to invisible sanitizable signatures.
- **101750174.pdf** — Improved Structure Preserving Signatures under Standard Bilinear Assumptions (Jutla, Roy). Shortens Kiltz–Pan–Wee SPS to six group elements with two (optimal) pairing equations and improves the reduction loss to Q log Q.
- **101750203.pdf** — Chosen-Ciphertext Secure Fully Homomorphic Encryption (Canetti, Raghuraman, Richelson, Vaikuntanathan). Three CCA1-secure FHE schemes via multi-key identity-based FHE (from LWE or iO) and a fully compact SNARK-based scheme.
- **101750231.pdf** — Circuit-Private Multi-Key FHE (Chongchitmate, Ostrovsky). Multi-key FHE secure against malicious users without trusted setup; malformed keys/ciphertexts leak nothing about the server's computation.
- **101750261.pdf** — FHE Over the Integers: Decomposed and Batched in the Post-Quantum Regime (Benarroch, Brakerski, Lepoint). Third-generation FHE over the integers from decisional AGCD without the noise-free assumption, with batched ciphertexts.
- **101750292.pdf** — Ceremonies for End-to-End Verifiable Elections (Kiayias, Zacharias, Zhang). Models e-voting as ceremonies including human participants, and analyzes Helios, characterizing behaviors preserving E2E verifiability and privacy.
- **101750322.pdf** — A Modular Security Analysis of EAP and IEEE 802.11 (Brzuska, Jacobsen). Reduction-based analysis proving EAP secure as a 3P-AKE under channel binding, yielding the first provable security result for IEEE 802.11 with upper-layer authentication.
- **101750352.pdf** — On the Computational Overhead of MPC with Dishonest Majority (Nielsen, Ranellucci). Achieves poly-logarithmic computational overhead for MPC with any constant fraction of honest parties, extending prior c < 1/2 results.
- **101750379.pdf** — Better Two-Round Adaptive Multi-Party Computation (Canetti, Poburinnaya, Venkitasubramaniam). Two-round adaptively secure MPC needing only non-programmable CRS and polynomial iO, plus a RAM-complexity variant of the GP protocol.
- **101750409.pdf** — Constant Round Adaptively Secure Protocols in the Tamper-Proof Hardware Model (Hazay, Polychroniadou, Venkitasubramaniam). Constant-round adaptive UC-secure computation with stateless tokens from one-way functions, avoiding obfuscation; corollaries in the global ROM.
- **101750439.pdf** — Constrained Pseudorandom Functions for Unconstrained Inputs Revisited: Achieving Verifiability and Key Delegation (Datta, Dutta, Mukhopadhyay). Fixes/strengthens the Deshpande et al. CPRF security proof and builds first verifiable and delegatable constrained PRFs for unbounded inputs from PKE.
- **101750469.pdf** — Constraining Pseudorandom Functions Privately (Boneh, Lewi, Wu). Introduces private constrained PRFs whose constrained keys hide the constraint; constructions from iO and from concrete assumptions for bit-fixing/puncturing.
- **101750499.pdf** — Universal Samplers with Fast Verification (Koppula, Poelstra, Waters). Universal samplers augmented with cheap sample verification via one-time signatures, security from sub-exponential iO and puncturable PRFs.
- **10210107.pdf** — Faster Secure Two-Party Computation in the Single-Execution Setting (Wang, Malozemoff, Katz). Maliciously secure 2PC using ρ garbled circuits and O(ρ+κ) public-key ops under DDH; computes AES in 65 ms, 22× faster than prior work.
- **10210108.pdf** — Quantum Authentication and Encryption with Key Recycling (Fehr, Salvail). Information-theoretic encryption with quantum ciphertexts allowing safe key reuse when no eavesdropping is detected, using only BB84 qubit prepare/measure.
- **10210111.pdf** — Depth-Robust Graphs and Their Cumulative Memory Complexity (Alwen, Blocki, Pietrzak). Constructs DAGs with asymptotically optimal cumulative pebbling complexity Ω(n²/log n) for data-independent memory-hard functions via depth-robustness.
- **10210113.pdf** — Computational Integrity with a Public Random String from Quasi-Linear PCPs (Ben-Sasson et al.). SCI: first implemented scalable PCP system (PCPPs plus proof composition) giving publicly verifiable computational integrity without secret setup.
- **10210116.pdf** — Short Stickelberger Class Relations and Application to Ideal-SVP (Cramer, Ducas, Wesolowski). Uses short Stickelberger class relations to advance quantum attacks on Ideal-SVP in cyclotomic fields, probing the hardness gap underlying Ring-LWE/SIS-based schemes.
