# Batch 096 digest

## Overview
- Batch is dominated by ~2011–2012 public-key cryptography papers (PKC/Eurocrypt-era style): FHE over the integers (DGHV compression, bootstrapping, approximate-GCD cryptanalysis) and lattice-based crypto (LWE/Ring-LWE, trapdoors, PRFs, signatures) form the largest cluster.
- A second major theme is signature security reductions: tight proofs, optimal loss factors (FDH, Schnorr, Waters signatures), and RSA-based space-efficient schemes.
- Key exchange is well represented: PAKE via OT, single-round UC PAKE, CK+-secure AKE from factoring/codes/lattices, plus private set operations (PSI, set union, policy-enhanced PSI).
- Definitional/foundational results recur: selective-opening security separations, circular/KDM security, related-key-attack resilience, leakage resilience.
- Notably absent: elliptic-curve crypto and ECDLP papers — anomalous for this corpus; only one side-channel paper (Moradi, collision attacks).
- Anomaly: 72930354.pdf extracted as hex-escaped text ("NTRUCCA: How to Strengthen NTRUEncrypt to Chosen-Ciphertext Security..."); content otherwise decodable. No duplicates or non-paper files found.

## Papers
- **72370423.pdf** — Statistical Tools Flavor Side-Channel Collision Attacks (Amir Moradi). Extends multi-query side-channel collision attacks using higher-order moments and probability density functions instead of only leakage means.
- **72370441.pdf** — Public Key Compression and Modulus Switching for FHE over the Integers (Coron, Naccache, Tibouchi). Shrinks DGHV public keys from 802 MB to ~10 MB, adds modulus switching, and improves the approximate-GCD attack.
- **72370461.pdf** — Fully Homomorphic Encryption with Polylog Overhead (Gentry, Halevi, Smart). Batched/packed FHE evaluation of wide arithmetic circuits in time t·polylog(λ) using efficient routing of plaintext slots.
- **72370479.pdf** — Multiparty Computation with Low Communication, Computation and Interaction via Threshold FHE (Asharov et al.). Threshold FHE from (Ring-)LWE yields maliciously UC-secure MPC in 2–3 rounds.
- **72370497.pdf** — Faster Algorithms for Approximate Common Divisors (Chen, Nguyen). New PACD/GACD algorithms with square-root improvement over exhaustive search, breaking published FHE challenges over the integers.
- **72370515.pdf** — Decoding Random Binary Linear Codes in 2n/20: How 1+1=0 Improves Information Set Decoding (Becker, Joux, May, Meurer). Representation techniques improve ISD to 2^0.0494n.
- **72370533.pdf** — Optimal Security Proofs for Full Domain Hash, Revisited (Kakvi, Kiltz). Shows Coron's qs loss impossibility needs certified permutations, giving a tight RSA-FDH reduction under the Phi-Hiding assumption.
- **72370550.pdf** — On the Exact Security of Schnorr-Type Signatures in the Random Oracle Model (Seurin). Proves the Forking Lemma's qh loss is essentially optimal for algebraic reductions under OMDL.
- **72370568.pdf** — Tightly-Secure Signatures From Lossy Identification Schemes (Abdalla, Fouque, Lyubashevsky, Tibouchi). General transform from lossy ID schemes to tightly-secure signatures, with DL, lattice, and subset-sum instantiations.
- **72370587.pdf** — Adaptively Attribute-Hiding (Hierarchical) Inner Product Encryption (Okamoto, Takashima). First adaptively secure, fully attribute-hiding IPE (and hierarchical variant) under DLIN, via extended dual system encryption.
- **72370605.pdf** — Scalable Group Signatures with Revocation (Libert, Peters, Yung). Standard-model revocable group signatures using the Naor-Naor-Lotspiech broadcast framework, avoiding per-user history tracking.
- **72370623.pdf** — Incremental Deterministic Public-Key Encryption (Mironov, Pandey, Reingold, Segev). Initiates deterministic PKE where small plaintext changes cause small ciphertext changes, suited to large storage systems.
- **72370640.pdf** — Standard Security Does Not Imply Security Against Selective-Opening (Bellare, Dowsley, Waters, Yilek). Shows standard hiding/binding does not give SOA security, and gives IND-CPA schemes insecure under selective opening.
- **72370658.pdf** — Detecting Dangerous Queries: A New Approach for Chosen Ciphertext Security (Hohenberger, Lewko, Waters). Introduces detectable CCA security as an abstraction from which CCA-secure schemes are built.
- **72370677.pdf** — Security of Symmetric Encryption in the Presence of Ciphertext Fragmentation (Boldyreva, Degabriele, Paterson, Stam). Formal models for fragmented-delivery attacks (SSH-like), with constructions adding boundary hiding and DoS robustness.
- **72370695.pdf** — Trapdoors for Lattices: Simpler, Tighter, Faster, Smaller (Micciancio, Peikert). New strong lattice trapdoors enabling efficient LWE inversion and SIS preimage sampling, improving signatures and CCA encryption.
- **72370713.pdf** — Pseudorandom Functions and Lattices (Banerjee, Peikert, Rosen). Direct low-depth lattice-based PRF constructions via a new deterministic error-generation ("derandomization") for LWE.
- **72370731.pdf** — Lattice Signatures Without Trapdoors (Lyubashevsky). Fiat-Shamir-style lattice signatures based on SIVP/LWE via rejection sampling, with small keys and the most practical ring variant.
- **72930001.pdf** — Better Bootstrapping in Fully Homomorphic Encryption (Gentry, Halevi, Smart). Simpler bootstrapping using a modulus near a power of two, combined with SIMD for quasi-linear time.
- **72930019.pdf** — Polly Cracker, revisited, revisited (Herold). Analyzes all parameter settings of PCN, proving equivalence to LWE variants in some and giving a key-recovery attack in one; also fixes proof flaws.
- **72930037.pdf** — Ring-LWE in Polynomial Rings (Ducas, Durmus). Simple transformation removing the dual ring R∨ from Ring-LWE with only slight noise growth, easing theory and implementation.
- **72930055.pdf** — On Homomorphic Encryption and Chosen-Ciphertext Security (Hemenway, Ostrovsky). Builds IND-CCA-secure schemes from any homomorphic encryption with weak cyclic properties, simply and efficiently.
- **72930069.pdf** — Waters Signatures with Optimal Security Reduction (Hofheinz, Jager, Knapp). Encoding modification achieves O(q) loss for Waters signatures, with matching lower bound for re-randomizable schemes.
- **72930087.pdf** — Strong Security from Probabilistic Signature Schemes (Schäge). Defines target randomness security and transforms such schemes into strongly secure signatures, instantiated efficiently under RSA.
- **72930105.pdf** — Space Efficient Signature Schemes from the RSA Assumption (Yamada, Hanaoka, Kunihiro). Several RSA-based schemes trading shorter public keys/signatures against signing efficiency.
- **72930123.pdf** — The Construction of Ambiguous Optimistic Fair Exchange from Designated Confirmer Signature without Random Oracles (Huang, Wong, Susilo). Interactive AOFE from standard DCS without special properties, with a new DCS construction.
- **72930141.pdf** — Efficient Implementation of a CCA2-secure Variant of McEliece Using Generalized Srivastava Codes (Cayrel, Hoffmann, Persichetti). Quasi-dyadic McEliece with Fujisaki-Okamoto CCA2 conversion, no constant-weight encoding; embedded implementation included.
- **72930159.pdf** — Solving Underdetermined Systems of Multivariate Quadratic Equations revisited (Thomae, Wolf). Linear change of variables gives gradual complexity reduction for underdetermined MQ systems over even-characteristic fields.
- **72930176.pdf** — Public-Key Identification Schemes Based on Multivariate Cubic Polynomials (Sakumoto). Zero-knowledge identification from the cubic (MC) problem, with efficiency comparable to MQ-based schemes and active-attack security.
- **72930194.pdf** — Public-Key Cryptography from New Multivariate Quadratic Assumptions (Huang, Liu, Yang). First PKE provably secure under an MQ assumption, with near-optimal additive ciphertext overhead.
- **72930210.pdf** — Anonymous Broadcast Encryption: Adaptive Security and Efficient Constructions in the Standard Model (Libert, Paterson, Quaglia). Defines ANOBE and builds collusion-resistant anonymous BE from anonymous PKE or weakly secure IBE.
- **72930228.pdf** — Outsider-Anonymous Broadcast Encryption with Sublinear Ciphertexts (Fazio, Perera). First sublinear-ciphertext BE with receiver anonymity, under adaptive corruptions in CPA and CCA settings.
- **72930246.pdf** — Verifiable Predicate Encryption and Applications to CCA Security and Anonymous Predicate Authentication (Yamada et al.). Verifiability of predicate decryption yields generic CPA-to-CCA conversion and deniable predicate authentication.
- **72930264.pdf** — Public Key Encryption Against Related Key Attacks (Wee). Efficient RKA-resilient PKE (linear shifts) from factoring, BDDH, and LWE in the standard model with constant overhead.
- **72930282.pdf** — Functional Encryption for Threshold Functions (or Fuzzy IBE) from Lattices (Agrawal, Boyen, Vaikuntanathan, Voulgaris, Wee). LWE-based fuzzy IBE in CPA and CCA variants, selectively secure in the standard model.
- **72930300.pdf** — Variants of Waters' Dual System Primitives Using Asymmetric Pairings (Ramanna, Chatterjee, Sarkar). Simplifies Waters 2009 dual-system IBE with tags in asymmetric pairings, shortening ciphertexts and keys under standard assumptions.
- **72930318.pdf** — From Selective to Full Security: Semi-Generic Transformations in the Standard Model (Abdalla, Fiore, Lyubashevsky). Admissible-hash transform upgrading selective-secure WIBE to fully secure (H)IBE, extending to the CML leakage model.
- **72930336.pdf** — Circular and KDM Security for Identity-Based Encryption (Alperin-Sheriff, Peikert). First LWE-based IBE circular-secure for affine key-dependent messages, via dual-style cryptosystem and all-but-d trapdoors.
- **72930354.pdf** — NTRUCCA: How to Strengthen NTRUEncrypt to Chosen-Ciphertext Security in the Standard Model (Steinfeld, Ling, Pieprzyk, Tartary, Wang) (?). Extraction hex-encoded; title and authors recovered by decoding. (anomaly: hex-escaped extraction)
- **72930372.pdf** — Generating Provable Primes Efficiently on Embedded Devices (Clavier, Feix, Thierry, Paillier). Pocklington-based constructive prime generators for smartcards, matching probable-prime speeds with tamper resistance.
- **72930390.pdf** — Password-based Authenticated Key Exchange (Pointcheval). Short survey (9p) of PAKE settings, security notions, and protocols from Bellovin-Merritt onward.
- **72930399.pdf** — Constant-Round Multi-Party Private Set Union Using Reversed Laurent Series (Seo, Cheon, Katz). First constant-round efficient multi-party private set union, with statistical security in the semi-honest setting.
- **72930414.pdf** — Policy-Enhanced Private Set Intersection: Sharing Information While Enforcing Privacy Policies (Stefanov, Shi, Song). PSI enriched with policy enforcement at minimal overhead, secure against malicious adversaries under CBDH.
- **72930432.pdf** — Efficiently Shuffling in Public (Parampalli, Ramchen, Teague). Precomputed (obfuscated) Paillier shuffles on permutation networks yield polylog-time distributed mixnets for voting.
- **72930450.pdf** — Efficient Password Authenticated Key Exchange via Oblivious Transfer (Canetti, Dachman-Soled, Vaikuntanathan, Wee). OT-based PAKE framework giving UC-secure adaptive security and CDH/factoring instantiations without random oracles.
- **72930468.pdf** — Strongly Secure Authenticated Key Exchange from Factoring, Codes, and Lattices (Fujioka, Suzuki, Xagawa, Yoneyama). Generic CCA-KEM-to-AKE transform giving first CK+-secure standard-model AKE from factoring, codes, or LWE.
- **72930486.pdf** — Relatively-Sound NIZKs and Password-Based Key-Exchange (Jutla, Roy). Relatively-sound NIZKs from smooth projective hash functions enable efficient CCA2 encryption and constant-cost single-round UC PAKE.
- **72930504.pdf** — Multi-Location Leakage Resilient Cryptography (Juma, Vahlis, Yung). Models leakage from replicated cryptographic operations across locations, building multi-location leakage-resilient signatures with near-optimal leakage bounds.
- **72930522.pdf** — On definitions of selective opening security (Böhl, Hofheinz, Kraschewski). Counterexamples show indistinguishability- and simulation-based selective opening notions do not imply each other.
- **72930540.pdf** — New Definitions and Separations for Circular Security (Cash, Green, Hohenberger). Introduces weak circular security relaxation and gives separations showing it is not implied by standard CPA security.
