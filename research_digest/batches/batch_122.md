# Batch 122 digest

## Overview
- Batch is two coherent conference blocks: files 9783xxxx are FSE 2016 papers (symmetric cryptanalysis, block/stream ciphers, MAC modes), and 9813xxxx are CHES 2016 papers (side-channel attacks, masking, hardware implementations).
- Dominant themes: automatic cryptanalysis tooling (SAT/MILP/key-bridging/division property) applied to NSA lightweight ciphers Simon and Speck, and masking countermeasures with d+1 shares and leakage detection.
- Notable papers: CacheBleed (Yarom–Genkin–Heninger) breaking OpenSSL "constant-time" RSA; DCA attack (Bos et al.) defeating commercial white-box AES; Flush+Gauss+Reload, the first cache attack on lattice-based BLISS signatures.
- ECC content is thin: only FourQ-on-FPGA and a Koblitz-curve software implementation touch elliptic curves; both are implementation speed records rather than ECDLP theory.
- Anomaly: one applied password-cracking systems paper (WPA2 FPGA cluster) and one hardware-security paper on SAT attacks against logic locking sit slightly outside pure crypto; no duplicates or non-paper content found.

## Papers
- **97830041.pdf** — A MAC Mode for Lightweight Block Ciphers (Luykx, Preneel, Tischhauser, Yasuda). Proposes LightMAC, a parallelizable MAC whose security bound is independent of message length, enabling far more data per key on small-block ciphers like PRESENT.
- **97830061.pdf** — Cryptanalysis of the Full Spritz Stream Cipher (Banik, Isobe). Distinguishing attacks on full Spritz via short/long-term keystream biases, plus an improved state-recovery attack exploiting weak states.
- **97830077.pdf** — Attacks against Filter Generators Exploiting Monomial Mappings (Canteaut, Rotella). Shows monomial equivalence of LFSR filter generators preserves algebraic resistance but weakens correlation resistance, enabling new divide-and-conquer and fast correlation attacks.
- **97830097.pdf** — Lightweight MDS Generalized Circulant Matrices (Liu, Sim). Reduces the search space for lightweight MDS matrices via new circulant properties, and introduces cyclic matrices yielding record-low XOR counts and first involutory MDS instances.
- **97830117.pdf** — On the Construction of Lightweight Circulant Involutory MDS Matrices (Li, Wang). Constructs the first circulant involutory MDS matrices by using non-commutative matrix entries over F2, with XOR lower bounds and matching constructions for 4x4 and 5x5 cases.
- **97830136.pdf** — Optimizing S-box Implementations for Several Criteria using SAT Solvers (Stoffelen). Uses SAT solvers to optimize S-box circuits for gate count, nonlinear gates, and depth across CAESAR candidates, with a new depth-optimization method and public tooling.
- **97830156.pdf** — Verifiable side-channel security of cryptographic implementations: constant-time MEE-CBC (Almeida, Barbosa, Barthe, Dupressoir). Reports a Lucky-13-style timing bug in AWS s2n and presents a methodology for formally proving timing security of MEE-CBC implementations.
- **97830176.pdf** — White-Box Cryptography in the Gray Box (Sasdrich, Moradi, Güneysu). First FPGA white-box AES implementation evaluated under a gray-box SCA attacker; shows white-box encoding alone does not stop side-channel leakage and analyzes leakage sources.
- **97830195.pdf** — Detecting flawed masking schemes with leakage detection tests (Reparaz). Simulation-based method using leakage-detection tests on high-level code to catch first- to third-order masking flaws early; finds a new second-order flaw in a table-recomputation scheme.
- **97830215.pdf** — There is Wisdom in Harnessing the Strengths of your Enemy: Customized Encoding to Thwart Side-Channel Attacks (Maghrebi, Servant, Bringer). Builds leakage-model-tailored encoding functions via stochastic profiling, outperforming fixed Hamming-weight encodings when the leakage model deviates from ideal.
- **97830235.pdf** — Automatic Search for Key-Bridging Technique: Applications to LBlock and TWINE (Lin, Wu, Zheng). Algorithm to automatically find key-bridging relations, improving impossible-differential and zero-correlation attacks on 23-round LBlock and 23/25-round TWINE.
- **97830255.pdf** — MILP-Based Automatic Search Algorithms for Differential and Linear Trails for Speck (Fu, Wang, Guo, Sun, Hu). First MILP model for differential/linear search on ARX ciphers by linearizing modular addition, applied to the Speck family.
- **97830275.pdf** — Automatic Search for the Best Trails in ARX: Application to Block Cipher Speck (Biryukov, Velichkov, Le Corre). Adapts Matsui's branch-and-bound trail search to ARX, giving optimal differential/linear trail bounds for Speck and two new ARX designs with provable bounds.
- **97830297.pdf** — Stream ciphers: A Practical Solution for Efficient Homomorphic-Ciphertext Compression (Canteaut, Carpov, Fontaine, Lepoint, Naya-Plasencia, Paillier, Sirdey). Uses additive stream ciphers for hybrid homomorphic transciphering; evaluates Trivium and proposes Kreyvium, a 128-bit-security Trivium variant.
- **97830317.pdf** — Efficient Design Strategies Based on the AES Round Function (Jean, Nikolić). Systematic search for AES-round-based MAC/AE building blocks; fastest construction runs at 0.125 cycles/byte on Skylake, five times faster than AES-128.
- **97830337.pdf** — Bit-Based Division Property and Application to Simon Family (Todo, Morii). Introduces bit-based division property for non-S-box ciphers, proving the experimental 15-round integral characteristic of Simon32 valid for all keys.
- **97830357.pdf** — Algebraic Insights into the Secret Feistel Network (Perrin, Udovenko). Introduces the high-degree indicator matrix to distinguish secret Feistel networks even under unknown affine whitening, plus an ANF-recovery attack on the last round function.
- **97830378.pdf** — Integrals Go Statistical: Cryptanalysis of Full Skipjack Variants (Wang, Cui, Chen, Sun, Wen, Bogdanov). Proposes statistical integral distinguishers using partial input sets to cut data complexity, applying them to attack full Skipjack variants.
- **97830395.pdf** — Note on Impossible Differential Attacks (Derbez). Shows Boura et al.'s generic complexity formula can underestimate attack cost; in particular the FSE'15 attack on 25-round TWINE-128 exceeds exhaustive search complexity.
- **97830407.pdf** — Improved Linear Hull Attack on Round-Reduced Simon with Dynamic Key-guessing Techniques (Chen, Wang). Combines linear hulls with dynamic key guessing to attack more rounds of every Simon variant than previously known.
- **97830429.pdf** — Modeling Random Oracles under Unpredictable Queries (Farshim, Mittelbach). Introduces Interactive Computational Extractors extending UCE, proves random oracles ICE-secure, and shows attacks on HMAC/NMAC under the notion.
- **97830450.pdf** — Practical Order-Revealing Encryption with Limited Leakage (Chenette, Lewi, Weis, Wu). First efficient ORE from pseudorandom functions with simulation-based security against a precise leakage profile; ciphertexts only ~1.6x plaintext size.
- **97830470.pdf** — Strengthening the Known-Key Security Notion for Block Ciphers (Cogliati, Seurin). Introduces multiple-known-keys indifferentiability; proves 9-round iterated Even-Mansour achieves the stronger notion versus 1 round for the single-key case.
- **97830509.pdf** — Key Recovery Attack against 2.5-round pi-Cipher (Boura, Chakraborti, Leurent, Paul, Saha, Soleimany, Suder). Guess-and-determine key recovery on 2.5-round pi-Cipher variants (e.g., 2^72 time on pi16-Cipher096), showing thin security margin in the CAESAR candidate.
- **97830528.pdf** — Cryptanalysis of Reduced NORX (Bagheri, Huang, Jia, Mendel, Sasaki). State/key recovery attacks on 2-round (of 4) NORX32/NORX64, an internal-differential attack in parallel mode, and a practical keystream distinguisher.
- **97830548.pdf** — Analysis of the Kupyna-256 Hash Function (Dobraunig, Eichlseder, Mendel). Rebound attacks on the Ukrainian standard Kupyna-256 despite its modular constant additions: compression-function collisions up to 7 rounds and hash collisions up to 5 rounds.
- **98130105.pdf** — Towards Easy Leakage Certification (Durvaux, Standaert, Merino Del Pozo). Simpler leakage-certification test than Eurocrypt 2014's, trading some heuristic assumptions for much easier implementation, and clarifying information loss from wrong leakage models.
- **98130106.pdf** — Differential Computation Analysis: Hiding your White-Box Designs is Not Enough (Bos, Hubain, Michiels, Teuwen). Software analogue of DPA using binary-instrumentation traces; extracts keys automatically from public white-box AES implementations without reverse engineering.
- **98130108.pdf** — Efficient High-Speed WPA2 Brute Force Attacks using Scalable Low-Cost FPGA Clustering (Kammerstetter, Muellner, Burian, Kudera, Kastner). Low-cost FPGA cluster for WPA2 password recovery matching high-end commercial systems' performance at amateur-affordable cost.
- **98130111.pdf** — QcBits: Constant-Time Small-Key Code-Based Cryptography (Chou). Constant-time, bitsliced QC-MDPC McEliece/Niederreiter decryption with new speed records on Cortex-M4 and Haswell at 80-bit security.
- **98130115.pdf** — Faster Evaluation of SBoxes via Common Shares (Coron, Greuet, Prouff, Zeitoun). Masking optimization reusing common shares to cut finite-field multiplications; AES SBox drops from 4 to ~2.8 nonlinear multiplications, ISW-proven secure, ~20% practical speed-up.
- **98130130.pdf** — CacheBleed: A Timing Attack on OpenSSL Constant Time RSA (Yarom, Genkin, Heninger). Shows scatter-gather is not constant time; cache-bank-conflict attack recovers a 4096-bit RSA key from OpenSSL 1.0.2f after 16,000 decryptions.
- **98130140.pdf** — Efficient Fuzzy Extraction of PUF-Induced Secrets: Theory and Applications (Delvaux, Gu, Verbauwhede, Hiller, Yu). Derives tighter min-entropy-loss bounds than the (n-k) bound for biased/correlated PUF responses, and debunks a reusability claim of reverse fuzzy extractors.
- **98130141.pdf** — FourQ on FPGA: New Hardware Speed Records for Elliptic Curve Cryptography over Large Prime Characteristic Fields (Järvinen, Miele, Azarderakhsh, Longa). First FourQ FPGA implementations, 2-2.5x faster than Curve25519 on the same Zynq device, with constant-time execution.
- **98130142.pdf** — A High Throughput/Gate AES Hardware Architecture by Compressing Encryption and Decryption Datapaths (Ueno, Morioka, Homma, Aoki). AES hardware unifying encryption/decryption datapaths via operation reordering and register retiming, efficient for non-parallelizable CBC mode.
- **98130146.pdf** — Software implementation of Koblitz curves over quadratic fields (Oliveira, López, Rodríguez-Henríquez). Fast timing-protected scalar multiplication on Koblitz curves over F4m using redundant-trinomial reduction and vector instructions; fastest reported Koblitz-curve timings.
- **98130157.pdf** — Simple Key Enumeration (and Rank Estimation) using Histograms (Poussier, Standaert, Grosso). Histogram-based key-enumeration algorithm combining rank-estimation simplicity with parallelizability, minimizing distributed key-testing bandwidth, with open-source implementation.
- **98130159.pdf** — EnCounter: On Breaking the Nonce Barrier in Differential Fault Analysis with a Case-Study on PAEQ (Saha, Roy Chowdhury). Internal-differential fault attack needing only one faulty ciphertext, defeating nonce-based DFA protection; recovers full PAEQ keys for all three key sizes.
- **98130170.pdf** — Masking AES with d+1 Shares in Hardware (De Cnudde, Reparaz, Bilgin, Nikova, Nikov, Rijmen). First glitch-robust AES hardware masked with minimal d+1 shares at first and second order; smallest second-order DPA-resistant AES core to date, S-box 50% smaller.
- **98130173.pdf** — Horizontal Side-Channel Attacks and Countermeasures on the ISW Masking Scheme (Battistello, Coron, Prouff, Zeitoun). Two horizontal template attacks on Rivain-Prouff secure multiplication when noise does not scale with masking order, plus a proven-secure improved variant.
- **98130179.pdf** — Strong Machine Learning Attack against PUFs with No Mathematical Model (Ganji, Tajik, Fäßler, Seifert). PAC-learning framework proving PUF families without known mathematical models are inherently learnable; demonstrated on FPGA Bistable Ring PUFs.
- **98130181.pdf** — No Place to Hide: Contactless Probing of Secret Data on FPGAs (Lohrke, Tajik, Boit, Seifert). Semi-invasive IC-backside attacks using Laser Voltage Probing to read out secret data on 60nm FPGAs, bypassing conventional countermeasures.
- **98130191.pdf** — Cache Attacks Enable Bulk Key Recovery on the Cloud (İnci, Gulmezoglu, Irazoqui, Eisenbarth, Sunar). Prime+Probe attack recovering RSA keys from co-located EC2 instances after reverse-engineering cache-slice selection; finds 55% of scanned users run leakage-prone libraries.
- **98130193.pdf** — Flush, Gauss, and Reload – A Cache Attack on the BLISS Lattice-Based Signature Scheme (Groot Bruinderink, Hülsing, Lange, Yarom). First side-channel attack on a lattice signature scheme; Flush+Reload on BLISS's discrete Gaussian sampler recovers the key from ~3,500 observed signatures.
- **98130201.pdf** — Correlated Extra-Reductions Defeat Blinded Regular Exponentiation (Dugardin, Guilley, Danger, Najm, Rioul). Negative correlation between extra-reductions of consecutive operations breaks blinded regular exponentiation (Square-and-Multiply-Always, Montgomery ladder) in RSA.
- **98130206.pdf** — Reducing the Number of Non-linear Multiplications in Masking Schemes (Pulkus, Vivek). Masking S-boxes over slightly larger fields: DES S-boxes in 3 nonlinear multiplications (25% faster) and AES S-box in 3 over F216, plus a sharp logarithmic upper bound.
- **98130208.pdf** — Mitigating SAT Attack on Logic Locking (Xie, Srivastava). Anti-SAT circuit block forcing exponential SAT-attack iterations to unlock a logic-locked IC, protecting outsourced designs from untrusted foundries.
- **98130218.pdf** — Strong 8-bit Sboxes with Efficient Masking in Hardware (Boss, Grosso, Güneysu, Leander, Moradi, Schneider). Systematic construction of 8-bit S-boxes (Feistel/SPN/MISTY-based) that are both cryptographically strong and natively threshold-implementation friendly.
- **98130221.pdf** — Curious case of Rowhammer: Flipping Secret Exponent Bits using Timing Analysis (Bhattacharya, Mukhopadhyay). Combines Prime+Probe timing with controlled row-buffer hammering to flip bits in a 1024-bit RSA key using only user-level privileges.
- **98130222.pdf** — On the Multiplicative Complexity of Boolean Functions and Bitsliced Higher-Order Masking (Goudarzi, Rivain). Generic method to build low-multiplicative-complexity circuits for any S-box, enabling efficient bitsliced higher-order masking beyond ad-hoc per-cipher designs.
