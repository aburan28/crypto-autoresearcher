# Batch 011 digest

## Overview
- This batch is overwhelmingly a single-venue slice: nearly all 50 papers are CRYPTO 2018 contributions (recent IACR ePrint numbers, uniform 25–32 page lengths, Springer-style formatting).
- Dominant themes: secure multiparty computation (MPC, OT extension, garbled circuits/RAM, SPDZ variants — ~12 papers) and symmetric cryptanalysis (Grain/Trivium stream ciphers, AES, cube/correlation attacks, MAC forgeries — ~10 papers).
- Secondary themes: lattices/post-quantum (NIZKs from lattices, threshold FHE, extreme-pruning lower bounds, BKW tradeoffs, Mersenne PKE, GGH13 obfuscation attacks), zero-knowledge proofs/SNARKs, and searchable encryption.
- Only tangentially ECDLP-relevant for this corpus: the Algebraic Group Model paper (10993298), the optimal distributed discrete-log protocol (10993301), CDH trapdoor functions (10993227), and non-uniform generic-group bounds (10993327).
- Anomalies: none of the files are non-papers; source chunk contained one stray NUL byte (extraction artifact, cleaned before reading); 10993314 has no visible authors in the extract.

## Papers
- **10822401.pdf** — Fast Near Collision Attack on the Grain v1 Stream Cipher (Bin Zhang, Chao Xu, Willi Meier). New cryptanalytic method combining near-collision properties with divide-and-conquer state recovery, applied to a key-recovery attack on eSTREAM finalist Grain v1.
- **10993136.pdf** — Provable Security of (Tweakable) Block Ciphers Based on Substitution-Permutation Networks (Cogliati, Dodis, Katz, Lee, Steinberger, Thiruvengadam, Zhang). First comprehensive provable-security study of SPNs: 3 linear rounds are necessary and sufficient; fewer suffice with non-linear permutation steps.
- **10993138.pdf** — Fast Large-Scale Honest-Majority MPC for Malicious Adversaries (Chida, Genkin, Hamada, Ikarashi, Kikuchi, Lindell, Nof). Information-theoretic malicious-secure MPC for arithmetic circuits with a cheap cheating-verification method costing only about twice the semi-honest protocol.
- **10993150.pdf** — Fast Distributed RSA Key Generation for Semi-Honest and Malicious Adversaries (Frederiksen, Lindell, Osheter, Pinkas). Two constant-round two-party protocols for distributed RSA key generation, using limited-leakage analysis and OT-based multiplication to beat prior state of the art.
- **10993151.pdf** — Cryptanalysis via algebraic spans (Ben-Zvi, Kalka, Tsaban). Introduces an algebraic-span method giving provable polynomial-time cryptanalysis of nonabelian group-based protocols, breaking the Triple Decomposition key exchange.
- **10993158.pdf** — Optimal Forgeries Against Polynomial-Based MACs and GCM (Luykx, Preneel). Settles the gap between Bernstein's EUROCRYPT 2005 bound and known attacks by giving a matching optimal forgery attack on polynomial-based MACs like GCM/Poly1305.
- **10993170.pdf** — Non-Malleable Codes for Partial Functions with Manipulation Detection (Kiayias, Liu, Tselekounis). Non-malleable codes against partial read/write tampering of almost the whole codeword, with manipulation detection, implying efficient AONTs from one-way functions.
- **10993176.pdf** — Two-Round Multiparty Secure Computation Minimizing Public Key Operations (Garg, Miao, Srinivasan). Two-round semi-honest and malicious MPC using only poly(n,λ) two-round OT calls plus cheap one-way-function operations, avoiding per-circuit public-key cost.
- **10993177.pdf** — CAPA: The Spirit of Beaver against Physical Attacks (Reparaz, De Meyer, Bilgin, Arribas, Nikova, Nikov, Smart). Introduces the Tile-Probe-and-Fault leakage model and an SPDZ-inspired countermeasure against higher-order SCA, fault, and combined attacks, with AES/KATAN prototypes.
- **10993180.pdf** — TinyKeys: A New Approach to Efficient Multi-Party Computation (Hazay, Orsini, Scholl, Soria-Vazquez). Dishonest-majority MPC whose efficiency improves with more honest parties, using short symmetric keys and an LPN-style assumption applied to GMW and BMR-style protocols.
- **10993185.pdf** — Improved Division Property Based Cube Attacks Exploiting Algebraic Properties of Superpoly (Wang, Hao, Todo, Li, Isobe, Meier). Extends MILP division-property cube attacks by exploiting algebraic structure of the superpoly, improving key recovery on stream ciphers.
- **10993190.pdf** — Fast Homomorphic Evaluation of Deep Discretized Neural Networks (Bourse, Minelli, Minihold, Paillier). FHE-DiNN framework evaluating discretized neural networks homomorphically with complexity linear in network depth, using refined bootstrapping.
- **10993196.pdf** — A Key-recovery Attack on 855-round Trivium (Fu, Wang, Dong, Meier). Best known key-recovery attack on round-reduced Trivium (2^77 time for 855 rounds) via a Boolean-polynomial nullification technique.
- **10993198.pdf** — Faster Homomorphic Linear Transformations in HElib (Halevi, Shoup). Algorithmic improvements speeding linear maps on packed ciphertexts 30–75×, accelerating thin bootstrapping 6× and shrinking evaluation keys.
- **10993203.pdf** — On the Round Complexity of OT Extension (Garg, Mahmoody, Masny, Meckler). Shows OT extension from one-way functions needs an extra round beyond base OTs or non-black-box usage; result is tight.
- **10993207.pdf** — Constrained PRFs for NC1 in Traditional Groups (Attrapadung, Matsuda, Nishimaki, Yamada, Yamakawa). Constrained PRFs for NC1 circuits and private bit-fixing in pairing-free prime-order groups, from L-DDHI/DDH, using correlated-input secure hashing.
- **10993210.pdf** — Multi-Theorem Preprocessing NIZKs from Lattices (Kim, Wu). First multi-theorem NIZK argument for all of NP from standard lattice assumptions in the preprocessing model.
- **10993213.pdf** — Threshold Cryptosystems From Threshold Fully Homomorphic Encryption (Boneh, Gennaro, Goldfeder, Jain, Kim, Rasmussen, Sahai). Builds threshold FHE from LWE and a "universal thresholdizer" giving threshold PKE, signatures, and PRFs, including first single-round LWE threshold signatures.
- **10993219.pdf** — Improved Key Recovery Attacks on Reduced-Round AES with Practical Data and Memory Complexities (Bar-On, Dunkelman, Keller, Ronen, Shamir). Best known 5-round AES attack (2^22.5) and best practical-data attacks on 7-round AES-192, beating the 18-year-old Square attack record.
- **10993220.pdf** — IND-CCA-secure Key Encapsulation Mechanism in the Quantum Random Oracle Model, Revisited (Jiang, Zhang, Chen, Wang, Ma). Tighter QROM security proofs for generic IND-CCA KEM transforms used in NIST post-quantum candidates, avoiding extra ciphertext hashing.
- **10993222.pdf** — Correcting Subverted Random Oracles (Russell, Tang, Yung, Zhou). A simple construction immunizing subverted random oracles (kleptographic tampering on negligible input fraction) to be indifferentiable from a random function.
- **10993223.pdf** — Lower Bounds on Lattice Enumeration with Extreme Pruning (Aono, Nguyen, Seito, Shikata). First lower bounds on the running time of extreme-pruning enumeration given fixed success probability, refining lattice security estimates.
- **10993227.pdf** — Trapdoor Functions from the Computational Diffie-Hellman Assumption (Garg, Hajiabadi). First trapdoor functions from CDH (open 30+ years), via a generic construction from "recyclable" chameleon encryption.
- **10993231.pdf** — Promise Zero Knowledge and its Applications to Round Optimal MPC (Badrinarayanan, Goyal, Jain, Kalai, Khurana, Sahai). New "promise ZK" notion enabling the first four-round MPC from polynomial DDH and three-round list coin-tossing.
- **10993232.pdf** — Fast Correlation Attack Revisited: Cryptanalysis on Full Grain-128a, Grain-128, and Grain-v1 (Todo, Isobe, Meier, Aoki, Zhang). Finite-field reformulation of fast correlation attacks breaks the full Grain family, including first full-version cryptanalysis of ISO-standardized Grain-128a.
- **10993240.pdf** — Yes, There is an Oblivious RAM Lower Bound! (Larsen, Nielsen). Restores an Ω(lg n) bandwidth lower bound for ORAMs, circumventing Boyle–Naor's caveats about the original Goldreich–Ostrovsky bound.
- **10993247.pdf** — Yet Another Compiler for Active Security or: Efficient MPC Over Arbitrary Rings (Damgård, Orlandi, Simkin). Simple compiler upgrading passively secure MPC to active security at reduced threshold; first constant-overhead active-secure ring MPC, concretely for 3 parties.
- **10993248.pdf** — Non-Malleable Secret Sharing for General Access Structures (Goyal, Kumar). Generic compiler turning any secret sharing scheme into a non-malleable one for the same access structure, secure against unbounded share-wise tampering.
- **10993251.pdf** — Non-Interactive Zero-Knowledge Proofs for Composite Statements (Agrawal, Ganesh, Mohassel). Framework composing Sigma-protocol and SNARK techniques for mixed algebraic/arithmetic statements, with large prover-efficiency gains for credential applications.
- **10993255.pdf** — Rasta: A cipher with low ANDdepth and few ANDs per bit (Dobraunig, Eichlseder, Grassi, Lallemand, Leander, List, Mendel, Rechberger). MPC/FHE-friendly cipher design minimizing both AND-depth and ANDs per bit simultaneously.
- **10993262.pdf** — Hardness of Non-Interactive Differential Privacy from One-Way Functions (Kowalczyk, Malkin, Ullman, Wichs). Shows that under one-way functions no efficient general-purpose non-interactive differentially private algorithm exists for large query families.
- **10993267.pdf** — Adaptive Garbled RAM from Laconic Oblivious Transfer (Garg, Ostrovsky, Srinivasan). Adaptive garbled RAM for persistent databases from laconic OT, previously known only from iO or random oracles; yields constant-round malicious secure RAM computation.
- **10993269.pdf** — Generic Attacks against Beyond-Birthday-Bound MACs (Leurent, Nandi, Sibleyras). Collision-quadruple attacks with O(2^{3n/4}) queries on double-block-state MACs (SUM-ECBC, PMAC+, 3kf9, GCM-SIV2), invalidating one security proof.
- **10993271.pdf** — From Laconic Zero-Knowledge to Public-Key Cryptography (Berman, Degwekar, Rothblum, Vasudevan). Builds PKE from any hard NP language with efficient laconic honest-verifier ZK, unifying PKE constructions from QR, DDH, LWE, etc.
- **10993275.pdf** — A New Public-Key Cryptosystem via Mersenne Numbers (Aggarwal, Joux, Prakash, Santha). PKE based on a low-Hamming-weight approximate-divisibility problem modulo Mersenne primes.
- **10993277.pdf** — Cryptanalyses of Branching Program Obfuscations over GGH13 Multilinear Map from the NTRU Problem (Cheon, Hhan, Kim, Lee). Polynomial-time attacks breaking all recommended-parameter branching-program iO candidates over GGH13, forcing much larger lattice dimensions.
- **10993280.pdf** — SPDZ2k: Efficient MPC mod 2^k for Dishonest Majority (Cramer, Damgård, Escudero, Scholl, Xing). Homomorphic MACs modulo 2^k enable SPDZ-style actively secure MPC over Z_{2^k} with MASCOT-like OT preprocessing.
- **10993289.pdf** — The Curse of Small Domains: New Attacks on Format-Preserving Encryption (Hoang, Tessaro, Trieu). Improved multi-target message-recovery attacks on NIST FF1/FF3 Feistel FPE (with an FF3 odd-domain speedup) and first attacks on non-Feistel FPE.
- **10993296.pdf** — Lattice-Based Zero-Knowledge Arguments for Integer Relations (Libert, Ling, Nguyen, Wang). Lattice-based ZK arguments for integer addition, inequalities, and range/set-non-membership proofs with linear or logarithmic cost.
- **10993298.pdf** — The Algebraic Group Model and its Applications (Fuchsbauer, Kiltz, Loss). Introduces the AGM between standard model and GGM; proves CDH/Strong-DH/LRSW equivalent to DLog there and gives tight reductions for BLS and Groth's SNARK.
- **10993299.pdf** — Searchable Encryption with Optimal Locality: Achieving Sublogarithmic Read Efficiency (Demertzis, Papadopoulos, Papamanthou). First linear-space searchable encryption with constant locality and O(log^γ N) read efficiency, via new allocation bounds and an I/O-efficient ORAM.
- **10993301.pdf** — An Optimal Distributed Discrete Log Protocol with Applications to Homomorphic Secret Sharing (Dinur, Keller, Klein). DDL protocol with error O(M/T²), provably optimal, improving HSS branching-program evaluation from O(S²) to O(S^{3/2}).
- **10993303.pdf** — Tight Tradeoffs in Searchable Symmetric Encryption (Asharov, Segev, Shahaf). Establishes tight space/locality/read-efficiency tradeoffs for SSE within "pad-and-split" and related frameworks, closing gaps between schemes and lower bounds.
- **10993308.pdf** — On the Exact Round Complexity of Secure Three-Party Computation (Patra, Ravi). Settles exact round complexity of honest-majority 3PC: three rounds necessary and sufficient for unanimous abort, with results across abort/fairness/GOD notions and network settings.
- **10993312.pdf** — Dissection-BKW (Esser, Heuer, Kübler, May, Sohler). First time-memory tradeoffs for the BKW algorithm solving LPN/LWE via Dissection, plus a first quantum variant QBKW.
- **10993314.pdf** — Updatable and Universal Common Reference Strings with Applications to zk-SNARKs (authors not visible). Updatable universal CRS model secure if one updater is honest; negative result for private-polynomial CRS and positive construction with quadratic universal CRS.
- **10993319.pdf** — Optimizing Authenticated Garbling for Faster Secure Two-Party Computation (Katz, Ranellucci, Rosulek, Wang). Optimizes Wang et al.'s malicious 2PC: half-gate-compatible authenticated garbling and better AND-triple generation, up to 2.6× communication improvement.
- **10993324.pdf** — Risky Traitor Tracing and New Differential Privacy Negative Results (Goyal, Koppula, Russell, Waters). Relaxed "risky" traitor tracing with (k+4)-element ciphertexts from bilinear groups, plus differential-privacy lower bounds.
- **10993325.pdf** — Towards Bidirectional Ratcheted Key Exchange (Poettering, Rösler). Stronger security definitions for unidirectional and bidirectional ratcheted key exchange (Signal-style messaging) with concurrent two-party operation, plus secure instantiations.
- **10993327.pdf** — Non-Uniform Bounds in the Random-Permutation, Ideal-Cipher, and Generic-Group Models (Coretti, Dodis, Guo). Defines auxiliary-input idealized models capturing preprocessing attacks and derives first non-uniform bounds for applications including discrete logarithms.
