# Batch 103 digest

## Overview
- Batch splits cleanly into two venue runs: Crypto 2013 papers (files 80420xxx, theory: MPC, FHE, obfuscation, assumptions) and CHES 2013 papers (files 80860xxx, applied: side-channel attacks, masking, PUFs, hardware Trojans, embedded implementations).
- Notable theory results: Gentry–Sahai–Waters LWE-based FHE (approximate eigenvector method), Bellare–Hoang–Keelveedhi UCE random-oracle instantiation, and the Krawczyk–Paterson–Wee systematic TLS security analysis.
- Notable applied results: Göloğlu et al.'s Function Field Sieve DLP records in F_2^1971 and F_2^3164, Oliveira et al.'s lambda-coordinates speed records for binary ECC, and Bernstein–Chou–Schwabe's McBits constant-time code-based crypto.
- Side-channel/fault-attack cluster is strong: 384-bit ECDSA nonce-leak attack via Bleichenbacher HNP, fault attacks on MICKEY 2.0 and Tate pairing final exponentiation, SRAM PUF cloning via remanence decay, and dopant-level hardware Trojans.
- Anomaly: 80860135.pdf extracted as raw glyph codes ("/C7/D2...") — content not readable as text.
- Source chunk contained one embedded NUL byte (cleaned before processing); era is uniformly 2013, no duplicates detected.

## Papers
- **80420234.pdf** — On the Security of the TLS Protocol: A Systematic Analysis (Krawczyk, Paterson, Wee). Extracts a KEM from the TLS Handshake to prove full TLS secure in an ACCE-style model, covering RSA PKCS#1v1.5 and Diffie-Hellman modes.
- **80420238.pdf** — Quantum One-Time Programs (Broadbent, Gutoski, Stebila). Shows quantum information alone cannot yield one-time programs, and constructs one-time programs for quantum circuits using one-time memories.
- **80420242.pdf** — Secure Computation Against Adaptive Auxiliary Information (Boyle, Garg, Jain, Kalai, Sahai). Defines and constructs UC-secure two-party/multiparty computation tolerating adversaries that adaptively learn auxiliary information on honest parties' states.
- **80420245.pdf** — Structural Evaluation of AES and Chosen-Key Distinguisher of 9-Round AES-128 (Fouque, Jean, Peyrin). Uses graph-based search of related-key differential characteristics to give a chosen-key distinguisher on 9-round AES-128.
- **80420260.pdf** — Fuming Acid and Cryptanalysis (Strobel, Driessen, Kasper, Leander, Oswald, Schellenberg, Paar). Reverse-engineers the SimonsVoss 3060 G2 digital locking system via chip decapsulation, enabling practical master-key recovery and wireless-only attacks.
- **80420262.pdf** — An Algebraic Framework for Diffie-Hellman Assumptions (Escala, Herold, Kiltz, Ràfols, Villar). Introduces the matrix-DDH framework unifying DDH/k-Lin assumptions, with new generically hard distributions (2-SCasc, 2-ILin) offering shorter descriptions.
- **80420264.pdf** — Limits on the Power of Cryptographic Cheap Talk (Hubáček, Nielsen, Rosen). Shows some two-player games admit no sequentially rational cryptographic implementation of a correlated-equilibrium mediator; classifies needed assumptions.
- **80420268.pdf** — Plain versus Randomized Cascading-Based Key-Length Extension for Block Ciphers (Gaži). Gives generic attacks on plain cascades and matching security proofs for XOR-cascades, tightly characterizing cascade key-length extension.
- **80420271.pdf** — What Information is Leaked under Concurrent Composition? (Goyal, Gupta, Jain). Quantifies security loss under concurrent attacks via leakage-assisted simulation: full security for most sessions, bounded loss on a fixed fraction, with matching lower bounds.
- **80420274.pdf** — Message-Locked Encryption for Lock-Dependent Messages (Abadi, Boneh, Mironov, Raghunathan, Segev). Strengthens MLE security to messages depending on public parameters, with fully randomized and deterministic-component constructions supporting equality tests.
- **80420277.pdf** — Man-in-the-Middle Secure Authentication Schemes from LPN and Weak PRFs (Lyubashevsky, Masny). Builds efficient 3-round MiM-secure authentication from any weak PRF, including LPN/Ring-LPN variants, resolving open problems on lightweight authentication.
- **80420278.pdf** — Efficient Multiparty Protocols via Log-Depth Threshold Formulae (Cohen, Damgård, Ishai, Kölker, Miltersen, Raz, Rothblum). Recursively composes few-party protocols via threshold formulae to get simpler efficient honest-majority MPC and broadcast.
- **80420282.pdf** — On the Function Field Sieve and the Impact of Higher Splitting Probabilities (Göloğlu, Granger, McGuire, Zumbrägel). Binary-field FFS variant achieving L(1/3,(4/9)^{1/3}) complexity; sets DLP records in F_2^1971 and F_2^3164.
- **80420286.pdf** — Leakage-Resilient Symmetric Cryptography Under Empirically Verifiable Assumptions (Standaert, Pereira, Yu). Proposes the "simulatable leakage" assumption as an empirically verifiable basis for standard-model leakage-resilient proofs, applied to a PRG.
- **80420293.pdf** — How to Run Turing Machines on Encrypted Data (Goldwasser, Kalai, Popa, Vaikuntanathan, Zeldovich). Constructs ABE, succinct functional encryption, and reusable garbling for Turing machines/RAMs, avoiding worst-case circuit running-time blowup.
- **80420295.pdf** — On Fair Exchange, Fair Coins and Fair Sampling (Agrawal, Prabhakaran). Studies fair two-party functionalities: fair exchange needs Ω(1/r) error from coin tossing; fair coin tossing is complete for rational fair sampling.
- **80420296.pdf** — Instantiating Random Oracles via UCEs (Bellare, Hoang, Keelveedhi). Introduces Universal Computational Extractor security for keyed hash functions, enabling standard-model instantiation of random oracles for many ROM schemes.
- **80420297.pdf** — Homomorphic Encryption from Learning with Errors: Conceptually-Simpler, Asymptotically-Faster, Attribute-Based (Gentry, Sahai, Waters). The approximate-eigenvector (GSW) FHE scheme: no relinearization or evaluation keys, yielding identity-based and attribute-based FHE.
- **80420300.pdf** — On the Achievability of Simulation-Based Security for Functional Encryption (De Caro, Iovino, Jain, O'Neill, Paneth, Persiano). Compiler lifting IND-secure circuit FE to SIM security, unbounded queries in ROM and adaptive keys in the standard model.
- **80420305.pdf** — Obfuscating Conjunctions (Brakerski, Rothblum). Obfuscates conjunction functions from multilinear maps (GGH/CLT candidates), secure for entropic distributions and against generic adversaries.
- **80420310.pdf** — Highly-Scalable Searchable Symmetric Encryption with Support for Boolean Queries (Cash, Jarecki, Jutla, Krawczyk, Roşu, Steiner). First SSE scheme supporting conjunctive/Boolean search at very large database scale with well-defined leakage.
- **80420312.pdf** — Practical Bootstrapping in Quasilinear Time (Alperin-Sheriff, Peikert). Simple, implementable algebraic FHE bootstrapping in quasilinear time for packed and non-packed ciphertexts.
- **80420315.pdf** — Hard-Core Predicates for a Diffie-Hellman Problem over Finite Fields (Fazio, Gennaro, Perera, Skeith). Proves every bit hard-core for a DH variant over F_{p^2}, extending Boneh–Shparlinski to all bits of elliptic-curve DH.
- **80420316.pdf** — A Uniform Min-Max Theorem with Applications in Cryptography (Vadhan, Zheng). Constructive min-max proof yielding uniform versions of the hardcore lemma, SNARG impossibility, and entropy simulation.
- **80420321.pdf** — Construction of Differential Characteristics in ARX Designs; Application to Skein (Leurent). Algorithm for non-linear ARX differential trails, giving practical free-start/semi-free-start collisions on 20/12 rounds of Skein-256.
- **80420329.pdf** — Improved OT Extension for Transferring Short Secrets (Kolesnikov, Kumaresan). O(log k) improvement in OT extension for short secrets, with a 1-out-of-n OT extension framework, speeding garbled-circuit SFE.
- **80860105.pdf** — Using Bleichenbacher's Solution to the Hidden Number Problem to Attack Nonce Leaks in 384-Bit ECDSA (De Mulder, Hutter, Marson, Pearson). Recovers full 384-bit ECDSA key from smart card via template power analysis of nonce inversion plus FFT/BKZ attack.
- **80860110.pdf** — A Differential Fault Attack on MICKEY 2.0 (Banik, Maitra). First fault attack on eStream cipher MICKEY 2.0, recovering full state with ~2^16.7 single-bit faults.
- **80860111.pdf** — Noninvasive Spoofing Attacks for Anti-lock Braking Systems (Shoukry, Martin, Tabuada, Srivastava). Physical-layer attack injecting spoofed magnetic signals into ABS wheel-speed sensors, demonstrated with a prototype spoofer.
- **80860113.pdf** — Lambda Coordinates for Binary Elliptic Curves (Oliveira, López, Aranha, Rodríguez-Henríquez). New point representation yielding speed records for 128-bit-security binary-field scalar multiplication on Sandy/Ivy Bridge.
- **80860116.pdf** — Block Ciphers that are Easier to Mask: How Far Can we Go? (Gérard, Grosso, Naya-Plasencia, Standaert). Tweaks AES-like S-boxes/round structure for cheap masking, combined into the Zorro cipher.
- **80860121.pdf** — Inverting the Final Exponentiation of Tate Pairings on Ordinary Elliptic Curves Using Faults (Lashermes, Fournier, Goubin). Fault attack making final-exponentiation inversion feasible with 3 independent faults, enabling full pairing attacks.
- **80860123.pdf** — Profiling DPA: Efficacy and Efficiency Trade-offs (Whitnall, Oswald). Analyzes linear-regression profiling for template attacks, quantifying trade-offs between profiling complexity and attack-phase data needs.
- **80860135.pdf** — Not readable: extract is raw PDF glyph codes ("/C7/D2 ..."), so title and content could not be determined from the text.
- **80860153.pdf** — On the Simplicity of Converting Leakages from Multivariate to Univariate (Moradi, Mischke). Implements a glitch-resistant secret-sharing masking scheme on FPGA, then shows simple measurement changes expose exploitable multivariate leakage.
- **80860154.pdf** — A Very High Speed True Random Number Generator with Entropy Assessment (Cherkaoui, Fischer, Fesquet, Aubert). Self-timed-ring jitter TRNG with AIS31-compliant stochastic entropy model, validated on two FPGA families.
- **80860155.pdf** — Masking vs. Multiparty Computation: How Large is the Gap for AES? (Grosso, Standaert, Faust). Compares higher-order masking with MPC-based masking for AES, narrowing the gap via packed secret sharing and analyzing randomness requirements.
- **80860174.pdf** — Pushing the Limits of SHA-3 Hardware Implementations to Fit on RFID (Pessl, Hutter). Lowest-area/lowest-power Keccak ASIC design (2,927 GE), 40% smaller than prior art, suitable for passive RFID tags.
- **80860176.pdf** — An Accurate Probabilistic Reliability Model for Silicon PUFs (Maes). Replaces fixed-error-rate PUF reliability model with a heterogeneous per-cell model matching empirical data, enabling better PUF system design.
- **80860177.pdf** — Improving Modular Inversion in RNS using the Plus-Minus Method (Bigou, Tisserand). RNS modular inversion via extended Euclidean plus-minus trick replacing big comparisons with mod-4 checks; 6–10× faster on FPGA for ECC/RSA.
- **80860180.pdf** — McBits: Fast Constant-Time Code-Based Cryptography (Bernstein, Chou, Schwabe). Record-speed constant-time McEliece/Niederreiter software using additive FFTs and sorting networks, immune to timing attacks.
- **80860187.pdf** — Success through Confidence: Evaluating the Effectiveness of a Side-Channel Attack (Thillard, Prouff, Roche). Studies CPA success-rate formulae and introduces confidence levels using subkey rank evolution to assess attack outcomes.
- **80860188.pdf** — A High Reliability PUF Using Hot Carrier Injection Based Response Reinforcement (Bhargava, Mai). Uses HCI aging to permanently reinforce golden PUF responses in tens of seconds, reducing ECC overhead.
- **80860189.pdf** — Smaller Keys for Code-Based Cryptography: QC-MDPC McEliece Implementations on Embedded Devices (Heyse, von Maurich, Güneysu). Compact QC-MDPC McEliece on FPGA and 8-bit AVR with keys of only 4,800/9,600 bits at 80-bit security.
- **80860190.pdf** — High-Performance Scalar Multiplication using 8-Dimensional GLV/GLS Decomposition (Bos, Costello, Hisil, Lauter). Genus-2 curves over quadratic extensions enabling 8-dimensional scalar decomposition; fast on Ivy Bridge and ARM Cortex-A8.
- **80860192.pdf** — Sleuth: Automated Verification of Software Power Analysis Countermeasures (Bayrak, Regazzoni, Novo, Ienne). Reduces side-channel countermeasure verification to SAT problems, implemented as an LLVM back-end pass that finds classic pitfalls.
- **80860195.pdf** — On the Effectiveness of the Remanence Decay Side-Channel to Clone Memory-based PUFs (Oren, Sadeghi, Wachsmann). Non-invasive SRAM PUF cloning via data remanence decay, validated on 65 nm ASICs; countermeasures and TARDIS improvement discussed.
- **80860199.pdf** — Fides: Lightweight Authenticated Cipher with Side-Channel Resistance for Constrained Hardware (Bilgin, Bogdanov, Knežević, Mendel, Wang). Sponge-like online AE cipher needing only 793 GE at 80-bit security, designed for easy threshold-implementation masking.
- **80860201.pdf** — Leakage-Resilient Symmetric Encryption via Re-keying (Abdalla, Belaïd, Fouque). Proves encryption schemes built by adding a leakage-resilient re-keying layer on top of AES achieve provable side-channel security without changing the cipher.
- **80860203.pdf** — Stealthy Dopant-Level Hardware Trojans (Becker, Regazzoni, Paar, Burleson). Hardware Trojans inserted by flipping transistor dopant polarity, evading optical inspection and golden-chip checks; demonstrated on real targets.
