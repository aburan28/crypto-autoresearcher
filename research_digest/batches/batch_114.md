# Batch 114 digest

## Overview
- Coherent 2015-era batch: mostly Eurocrypt/CRYPTO 2015 papers (file IDs 9056xxxx and 9216xxxx) spanning theory, symmetric cryptanalysis, lattice crypto, and side channels.
- Heavy theory/core-crypto presence: UC frameworks, obfuscation, multilinear maps (both a new construction and its cryptanalysis), ABE/predicate encryption, function secret sharing, FSS/CDS communication complexity.
- Strong side-channel/masking cluster (4 papers): concrete masking security proofs, leakage-resilient circuits, verified higher-order masking, inner-product masking.
- Lattice crypto is prominent: LWE/LWR algorithms, LSH sieving for SVP, weak Ring-LWE instances, lattice AKE, predicate encryption from LWE.
- Notable named results: SPHINCS stateless hash-based signatures, the Bitcoin Backbone protocol, Cheon et al.'s total break of the CLT multilinear map, free-start collisions on 76-step SHA-1, first attack on full MISTY1, Decaf point compression.
- No anomalies: all 50 extracts are genuine research papers; no duplicates detected; only 92160145 lacks visible author names.

## Papers
- **90560210.pdf** — Making Masking Security Proofs Concrete (Duc, Faust, Standaert). Connects Eurocrypt 2014 masking proofs to the Eurocrypt 2009 side-channel evaluation framework via mutual information, with tightness experiments and heuristics for imperfect independent-leakage assumptions.
- **90560211.pdf** — Privacy Amplification in the Isolated Qubits Model (Yi-Kai Liu). Shows strong privacy amplification with a fixed hash function against isolated-qubits adversaries, yielding one-time memories leaking exponentially small information, extended to limited entangling gates.
- **90560212.pdf** — How to Efficiently Evaluate RAM Programs with Malicious Security (Afshar, Hu, Mohassel, Rosulek). First practical malicious-secure 2PC protocols for RAM programs whose overhead over semi-honest matches circuit-based 2PC ratios and does not grow with program running time.
- **90560214.pdf** — SPHINCS: Practical Stateless Hash-Based Signatures (Bernstein et al.). Introduces a stateless post-quantum hash-based signature scheme with 41 KB signatures, 1 KB keys, 2^128 security, and fast vectorized signing.
- **90560217.pdf** — Leakage-Resilient Circuits Revisited (Dachman-Soled, Liu, Zhou). Studies compiling circuits into OCL-secure form, seeking optimal component counts without leak-free hardware assumptions.
- **90560219.pdf** — Mind the Gap: Modular Machine-Checked Proofs of One-Round Key Exchange (Barthe, Crespo, Lakhnech, Schmidt). EasyCrypt formalization of one-round AKE proofs strengthening Kudla–Paterson, giving first CDH-based proofs of Naxos and Nets without Gap oracles.
- **90560232.pdf** — Cryptographic Agents: Towards a Unified Theory of Computing on Encrypted Data (Agrawal, Agrawal, Prabhakaran). Framework unifying IBE, FHE, functional encryption, and obfuscation via schemata with an IND-PRE security definition and composition theorem.
- **90560233.pdf** — Better Algorithms for LWE and LWR (Duc, Tramèr, Vaudenay). Improves the BKW-style LWE algorithm using multidimensional Fourier transforms, simplifying analysis, and gives the first algorithm for LWR with prime q.
- **90560246.pdf** — Hosting Services on an Untrusted Cloud (Boneh, Gupta, Mironov, Sahai). Formalizes secure cloud service schemes where software secrets stay hidden from the executing cloud, constructing them from iO, OWFs, and NIZKs.
- **90560249.pdf** — Fully Structure-Preserving Signatures and Shrinking Commitments (Abe, Kohlweiss, Ohkubo, Tibouchi). Extends structure-preserving signatures so secret keys are group elements too, plus shrinking trapdoor commitments circumventing a known impossibility via relaxed binding.
- **90560252.pdf** — One-out-of-Many Proofs (Groth, Kohlweiss). Logarithmic-communication Sigma protocol proving one commitment in a list opens to zero, yielding small ring signatures and a trusted-setup-free Zerocoin instantiation.
- **90560254.pdf** — Quadratic Time, Linear Space Algorithms for Gram-Schmidt and Gaussian Sampling (Lyubashevsky, Prest). Linear-space lattice Gaussian sampling matching Klein/GPV outputs for ideal lattices, cutting key sizes by Ω(d).
- **90560256.pdf** — How to Obfuscate Programs Directly (Zimmerman). Obfuscates straight-line programs directly via composite-order multilinear maps, needing O(d^2 s^2 + n^2) map operations, with VBB security in a generic hidden-order model.
- **90560260.pdf** — Twisted Polynomials and Forgery Attacks on GCM (Abdelraheem, Beelen, Bogdanov, Tischhauser). Uses twisted (Ore-ring) polynomials as forgery polynomials with controlled roots, giving explicit key-space coverage and an improved key-recovery attack on GCM-like polynomial hashing.
- **90560262.pdf** — Verified Proofs of Higher-Order Masking (Barthe, Belaïd, Dupressoir, Fouque, Grégoire, Strub). Program-verification-based method to automatically check t-order masking security, drastically reducing the variable sets that must be examined.
- **90560281.pdf** — Authenticated Key Exchange from Ideal Lattices (Zhang, Zhang, Ding, Snook, Dagdelen). Practical two-pass AKE from ring-LWE, conceptually similar to HMQV, proven secure in the Bellare–Rogaway model with weak PFS; includes one-pass variant and implementation.
- **90560288.pdf** — The Bitcoin Backbone Protocol: Analysis and Applications (Garay, Kiayias, Leonardos). Extracts Bitcoin's core protocol and proves common-prefix and chain-quality properties, then builds Byzantine agreement and a public transaction ledger on top.
- **90560289.pdf** — Executable Proofs, Input-Size Hiding Secure Computation and a New Ideal World (Chase, Ostrovsky, Visconti). New ideal-world definition generalizing GMW that additionally hides one party's input size in malicious-secure two-party computation.
- **90560290.pdf** — Improved Dual System ABE in Prime-Order Groups via Predicate Encodings (Chen, Gay, Wee). Modular framework for adaptively secure ABE under k-Lin in prime-order groups, improving efficiency and extending to weakly attribute-hiding predicate encryption.
- **90560291.pdf** — A Formal Treatment of Backdoored Pseudorandom Generators (Dodis, Ganesh, Golovnev, Juels, Ristenpart). Shows backdoored PRGs are equivalent to public-key encryption with pseudorandom ciphertexts, building Dual-EC-like constructions without output biases and analyzing immunizers.
- **90560293.pdf** — Inner Product Masking Revisited (Balasch, Faust, Gierlichs). Tweaked inner-product masking offering a security–efficiency tradeoff between Boolean and original IP masking: 4x slower than Boolean, 2x faster than original.
- **90560294.pdf** — End-to-End Verifiable Elections in the Standard Model (Kiayias, Zacharias, Zhang). DEMOS, the first e-voting system with information-theoretic E2E verifiability in the standard model, with privacy under subexponential DDH.
- **90560295.pdf** — Cryptanalysis of the Multilinear Map over the Integers (Cheon, Han, Lee, Ryu, Stehlé). Polynomial-time zeroizing attack totally breaking the CLT multilinear map, publicly recovering all secret quantities.
- **90560300.pdf** — Function Secret Sharing (Boyle, Gilboa, Ishai). Introduces FSS generalizing distributed point functions, with improved DPF constructions and a systematic study of relations to other primitives.
- **92160107.pdf** — Statistical Concurrent Non-malleable Zero-Knowledge from One-way Functions (Kiyoshima). First statistical CNMZK argument for NP from OWFs alone, with ω(log n) rounds under CRHF, near-optimal for black-box simulation.
- **92160114.pdf** — Privacy with Imperfect Randomness (Dodis, Yao). Modular framework proving strong impossibility results for traditional and differential privacy under general imperfect random sources.
- **92160115.pdf** — (Almost) Optimal Constructions of UOWHFs (Yu, Gu, Li, Weng). Optimal black-box UOWHF constructions from 1-to-1 and regular OWFs with Θ(n) key/output length and a single OWF call, improving Naor–Yung and De Santis–Yung.
- **92160119.pdf** — Cryptography with One-Way Communication (Garg, Ishai, Kushilevitz, Ostrovsky, Sahai). Studies secure computation over noisy channels when only one party speaks, showing BEC and BSC differ qualitatively in this one-way setting.
- **92160123.pdf** — Sieving for Shortest Vectors in Lattices Using Angular LSH (Laarhoven). Speeds up SVP sieving via Charikar's angular LSH, achieving heuristic 2^0.3366n time and 2^0.2075n space with practical HashSieve experiments.
- **92160126.pdf** — Multi-Prover Commitments Against Non-Signaling Attacks (Fehr, Fillinger). Strong negative result: any single-round two-prover commitment scheme can be broken by a non-signaling attack.
- **92160127.pdf** — New Multilinear Maps over the Integers (Coron, Lepoint, Tibouchi). New CLT-style candidate with non-linear zero-testing that resists the Cheon et al. attack, at comparable efficiency.
- **92160131.pdf** — A Simpler Variant of Universally Composable Security (Canetti, Cohen, Lindell). SUC, a restricted UC variant for standard MPC tasks with fixed party sets, offering simpler definitions and composition.
- **92160134.pdf** — Integral Cryptanalysis on Full MISTY1 (Todo). First attack on full 8-round MISTY1 with 5 FL layers, using division-property integral characteristics with 2^63.58 chosen plaintexts and 2^121 time.
- **92160137.pdf** — The Iterated Random Permutation Problem with Applications to Cascade Encryption (Minaud, Seurin). Shows distinguishing the r-th power of a random permutation needs Ω(N) queries, implying same-key cipher cascading negligibly degrades PRP security.
- **92160141.pdf** — Links among Impossible Differential, Integral and Zero Correlation Linear Cryptanalysis (Sun et al.). Proves a transition is an impossible differential of a structure iff it is a zero-correlation linear hull of the dual structure, linking the three techniques.
- **92160145.pdf** — Programmable Hash Functions Go Private (?). Introduces asymmetric programmable hash functions over bilinear groups, yielding short standard-model signatures and the first linearly-homomorphic signature with sub-linear public keys.
- **92160151.pdf** — Communication Complexity of Conditional Disclosure of Secrets and ABE (Gay, Kerenidis, Wee). First systematic CDS communication bounds with tight lower bounds for linear reconstruction, explaining ciphertext/key-size tradeoffs in dual-system ABE.
- **92160155.pdf** — Provably Weak Instances of Ring-LWE (Elias, Lauter, Ozman, Stange). Exhibits an explicit family of number fields where Decision Ring-LWE is efficiently broken, extending the EHL Poly-LWE attack with practical code and timings.
- **92160158.pdf** — Quantum Homomorphic Encryption for Circuits of Low T-gate Complexity (Broadbent, Jeffery). Defines and constructs quantum homomorphic encryption built on classical FHE, efficient for Clifford gates with cost scaling in T-gate count/depth.
- **92160159.pdf** — Decaf: Eliminating Cofactors Through Point Compression (Hamburg). Unified point compression for Edwards/twisted-Edwards/Montgomery curves that divides the cofactor by 4, enabling efficient prime-order groups on cofactor-4 curves.
- **92160160.pdf** — Predicate Encryption for Circuits from LWE (Gorbunov, Vaikuntanathan, Wee). Constructs leveled predicate encryption for all polynomial-depth circuits from subexponential LWE.
- **92160165.pdf** — Practical Free-Start Collision Attacks on 76-step SHA-1 (Karpman, Peyrin, Stevens). First free-start collisions on the SHA-1 compression function, reaching 76 steps at ~2^50 cost using GPU implementation.
- **92160170.pdf** — Higher-Order Differential Meet-in-the-Middle Preimage Attacks on SHA-1 and BLAKE (Espitau, Fouque, Karpman). First use of higher-order differentials in MITM preimage attacks, extending SHA-1 preimage attacks to 62 rounds.
- **92160175.pdf** — Cryptanalysis of the Co-ACD Assumption (Fouque, Lee, Lepoint, Tibouchi). Devastating lattice attacks on the Cheon–Lee–Seo homomorphic encryption scheme and the underlying decisional Co-ACD assumption; 128-bit parameters broken in seconds.
- **92160178.pdf** — Secure Computation from Leaky Correlated Randomness (Gupta, Ishai, Maji, Sahai). Resolves how much leakage of correlated (OT) randomness is tolerable, giving privacy-amplification-style recovery of fresh correlations for secure computation.
- **92160179.pdf** — Relational Hash (Mandal, Roy). New primitive letting one verify relations (linear relations, Hamming proximity) between plaintexts from hash pairs, applied to privacy-preserving biometric identification/authentication.
- **92160180.pdf** — New Attacks on Feistel Structures with Improved Memory Complexities (Dinur, Dunkelman, Keller, Shamir). Combines meet-in-the-middle and dissection techniques to attack 5+ round Feistel ciphers with better time–memory tradeoffs.
- **92160181.pdf** — Fast Correlation Attacks over Extension Fields and Cryptanalysis of SNOW 2.0 (Zhang, Xu, Meier). Framework for fast correlation attacks over extension fields with FWT decoding, giving attacks on SNOW 2.0 below 2^164, over 2^49 better than prior best.
- **92160184.pdf** — Concurrent Secure Computation via Non-Black-Box Simulation (Goyal, Gupta, Sahai). Straight-line non-black-box simulation gives first concurrent blind signatures and VRFs in the plain model, circumventing Lindell's black-box impossibility.
- **92160186.pdf** — Efficient Constant Round Multi-Party Computation Combining BMR and SPDZ (Lindell, Pinkas, Smart, Yanai). First concretely efficient fully-secure constant-round MPC via black-box BMR garbling with an SPDZ-based offline phase.
