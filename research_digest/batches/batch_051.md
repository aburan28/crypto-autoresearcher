# Batch 051 digest

## Overview
- This batch is an essentially contiguous run of CRYPTO 2023 (Springer LNCS chapter IDs 14438xxx) papers; venue/era is uniform, ~2023.
- Dominant topics: zero-knowledge proofs / SNARKs / accumulation (Protostar, FRI Fiat-Shamir, Punic, ZK-FEDB), MPC and secret-sharing machinery (ramp hyper-invertible matrices, RMFE, NI-VSS, universal circuits), and post-quantum cryptography (lattice signatures/NTRU, isogeny-based FESTA/CSIDH/pSIDH, code-based LESS/SDitH).
- Strong symmetric-cryptanalysis cluster: ASCON exact security, differential-linear attacks on LEA/Speck, cube attacks, Elisabeth-4 break, MitM on Feistel hashes, HDL attacks.
- Notable papers: Protostar (generic folding for special-sound protocols), Cryptographic Smooth Neighbors (record twin-smooth parameters for SQISign), FESTA (PKE built constructively from the SIDH attacks), Hermes (disproves Bost's conjecture that forward security and I/O efficiency in SSE are incompatible).
- Anomalies: 14438223.pdf has no extracted text (empty extract). No duplicates detected; all 49 remaining items are genuine research-paper first pages.

## Papers
- **14438063.pdf** — Ramp hyper-invertible matrices and their applications to MPC protocols (Liu, Xing, Yang, Yuan). Generalizes hyper-invertible matrices to work over constant-size fields, improving perfectly secure MPC communication assumptions.
- **14438067.pdf** — Universally Composable Auditable Surveillance (Fetzer, Klooß, Müller-Quade, Raiber, Rupp). UC-model treatment of auditable surveillance that forces traceable backdoor use, preventing silent mass surveillance.
- **14438074.pdf** — Practical Round-Optimal Blind Signatures in the ROM from Standard Assumptions (Katsumata, Reichle, Sakai). Two two-round blind signature schemes from pairing assumptions (CDH/DDH/SXDH); first sub-1KB total size from standard assumptions.
- **14438075.pdf** — Cryptographic Smooth Neighbors (Bruno, Corte-Real Santos, Costello, Eriksen, Meyer, Naehrig, Sterner). Optimized Conrey-Holmstrom-McLaughlin implementation finds record twin-smooth pairs, yielding smoother isogeny parameters for SQISign.
- **14438076.pdf** — Hermes: I/O-Efficient Forward-Secure Searchable Symmetric Encryption (Minaud, Reichle). First SSE scheme combining forward security with I/O efficiency, refuting Bost's incompatibility conjecture via client buffering and dummy updates.
- **14438080.pdf** — Exact Security Analysis of ASCON (Chakraborty, Dhar, Nandi). Tight random-permutation-model analysis of Ascon AEAD, improving the usual DT/2c integrity bound and confirming NIST-level security margins.
- **14438084.pdf** — Protostar: Generic Efficient Accumulation/Folding for Special-sound Protocols (Bünz, Chen). Generic folding scheme for special-sound protocols enabling efficient non-uniform IVC for Plonk without trusted setup, pairings, or FFTs.
- **14438086.pdf** — Amortized Functional Bootstrapping in less than 7ms, with O~(1) polynomial multiplications (Liu, Wang). Concretely efficient batched LWE bootstrapping: <5ms per ciphertext, ~10x faster than OpenFHE, supporting arbitrary functions.
- **14438089.pdf** — On the (Im)plausibility of Public-Key Quantum Money from Collision-Resistant Hash Functions (Ananth, Hu, Yuen). First black-box separation: CRHFs cannot build public-key quantum money with classical verification queries.
- **14438094.pdf** — Antrag: Annular NTRU Trapdoor Generation Making Mitaka As Secure As Falcon (Espitau, Nguyen, Sun, Tibouchi, Wallet). New NTRU trapdoor generation for Prest's sampler restoring Mitaka signatures to Falcon-level security.
- **14438100.pdf** — To attest or not to attest, this is the question — Provable attestation in FIDO2 (Bindel, Gama, Guasch, Ronen). Formal analysis of FIDO2 attestation modes, showing poor security/privacy/revocation trade-offs.
- **14438102.pdf** — Sigma Protocols from Verifiable Secret Sharing and Their Applications (Zhang, Chen, Yao, Wang). Generic VSS-based framework unifying and extending Sigma protocols, including composite-statement ZKPs.
- **14438104.pdf** — Solving the Hidden Number Problem for CSIDH and CSURF via Automated Coppersmith (Meers, Nowakowski). Defines commutative-isogeny HNP and recovers shared curves from ~54% (CSIDH) / ~76% (CSURF) of CDH MSBs via automated Coppersmith.
- **14438107.pdf** — Amortized NISC over Z_2^k from RMFE (Lin, Xing, Yao, Yuan). Brings RMFE amortization to non-interactive secure computation via non-malleable RMFE, achieving malicious statistical security in the VOLE-hybrid model.
- **14438121.pdf** — Quantum Attacks on Hash Constructions with Low Quantum Random Access Memory (Dong, Li, Pham, Zhang). Quantum herding attacks on iterative hashes without qRAM, at slightly higher time cost (2^0.46n) than prior qRAM-heavy attacks.
- **14438123.pdf** — Improved Fully Adaptive Decentralized MA-ABE for NC1 from MDDH (Chen, Chu, Gao, Ning, Wang). Shorter-parameter, many-use-attribute decentralized MA-ABE improving Datta-Komargodski-Waters under MDDH in the ROM.
- **14438127.pdf** — SCA-LDPC: A Code-Based Framework for Key-Recovery Side-Channel Attacks on Post-Quantum Encryption Schemes (Guo, Nabokov, Nilsson, Johansson). Models chosen-ciphertext side-channel information as LDPC codes decoded by belief propagation, improving key recovery on PQ KEMs.
- **14438130.pdf** — SDitH in the QROM (Aguilar-Melchor, Hülsing, Joseph, Majenz, Ronen, Yue). Compresses Hypercube-MPCitH code-based signatures to three rounds with tight QROM proofs and proof-of-work size reductions.
- **14438135.pdf** — Fiat-Shamir Security of FRI and Related SNARKs (Block, Garreta, Katz, Thaler, Tiwari, Zając). Proves round-by-round soundness of FRI/batched FRI and FS security of "Plonk-like" delta-correlated protocols (Plonky2, ethSTARK, etc.).
- **14438143.pdf** — Breaking the Size Barrier: Universal Circuits meet Lookup Tables (Disser, Günther, Schneider, Stillger, Wigandt, Yalame). LUT-based universal circuits of size ~1.5ρωn log_ω n, beating prior UCs by 1.12–2.18x for PFE.
- **14438146.pdf** — Differential-Linear Approximation Semi-Unconstrained Searching and Partition Tree: Application to LEA and Speck (Chen, Bao, Yu). New DL-approximation search algorithms plus a partition-tree tool yield improved attacks on ISO standards LEA and Speck.
- **14438156.pdf** — FESTA: Fast Encryption from Supersingular Torsion Attacks (Basso, Maino, Pope). Isogeny-based PKE using SIDH-attack techniques constructively as a trapdoor; IND-CCA in QROM and first standard-model isogeny PKE.
- **14438158.pdf** — CCA-1 Secure Updatable Encryption with Adaptive Security (Chen, Galteland, Liang). First adaptively secure ciphertext-dependent updatable encryption, extending beyond prior selective-security analyses.
- **14438165.pdf** — G+G: A Fiat-Shamir Lattice Signature Based on Convolved Gaussians (Devevey, Passelègue, Stehlé). Schnorr-style lattice signatures via Gaussian convolution—no aborts, ROM/QROM secure, smaller signatures than rejection/flooding approaches.
- **14438166.pdf** — Correlation Cube Attack Revisited: Improved Cube Search and Superpoly Recovery Techniques (Wang, Qin, Wu). Exploits low-degree superpoly factors via variable substitution and better ISoC search, improving key recovery in cube attacks.
- **14438169.pdf** — Cryptanalysis of Elisabeth-4 (Gilbert, Heim Boissier, Jean, Reinhard). Chosen-IV linearization attack breaking full Elisabeth-4's 128-bit claim with 2^88 time, exploiting sparse linear algebra and rank defects.
- **14438170.pdf** — Threshold Structure-Preserving Signatures (Crites, Kohlweiss, Preneel, Sedaghat, Slamanig). First threshold SPS: non-interactive multi-party signing producing standard single-party SPS signatures under a generalized PS assumption.
- **14438173.pdf** — We Are on the Same Side. Alternative Sieving Strategies for the Number Field Sieve (Bouillaguet, Fleury, Fouque, Kirchner). Reanalyzes NFS relation-collection sieving stages, proposing better strategies/parameterization than heuristic Cado-NFS practice.
- **14438176.pdf** — The Pre-Shared Key Modes of HPKE (Alwen, Janneck, Kiltz, Lipp). Formal models (pskPKE/pskAPKE) and security proofs for HPKE's PSK modes under Gap-DH, plus post-quantum instantiations.
- **14438178.pdf** — On Black-Box Knowledge-Sound Commit-And-Prove SNARKs (Lipmaa). Shows the FANA SNARG is flawed; constructs Punic, an efficient commit-and-prove zk-SNARK with semi-adaptive black-box knowledge soundness.
- **14438179.pdf** — Anonymous Counting Tokens (Benhamouda, Raykova, Seth). New primitive issuing anonymous tokens with per-message rate limits (one token per message), with four constructions from factoring or bilinear-map assumptions.
- **14438184.pdf** — A New Formulation of the Linear Equivalence Problem and Shorter LESS Signatures (Persichetti, Santini). Information-set LEP formulation lets provers describe monomial maps only on information sets, drastically shrinking LESS signatures with no new assumptions.
- **14438192.pdf** — Injection-Secure Structured and Searchable Symmetric Encryption (Amjad, Kamara, Moataz). Introduces correlation security generalizing forward privacy; builds first injection-secure multi-map and SSE schemes, plus dynamic volume-hiding multi-maps.
- **14438193.pdf** — Hidden Stabilizers, the Isogeny To Endomorphism Ring Problem and the Cryptanalysis of pSIDH (Chen, Imran, Ivanyos, Kutas, Leroux, Petit). Quantum polynomial-time IsERP algorithm for odd degrees with O(log log p) prime factors, impacting pSIDH security.
- **14438197.pdf** — NEV: Faster and Smaller NTRU Encryption using Vector Decoding (Zhang, Feng, Yan). NTRU variant encoding plaintext in MSBs of multiple coefficients; q=769 gives 615-byte keys/ciphertexts at NIST level 1, standard-model IND-CPA.
- **14438198.pdf** — Efficient Updatable Public-Key Encryption from Lattices (Abou Haidar, Passelègue, Stehlé). First LWE-based UPKE with polynomial modulus-to-noise ratio; generic transforms yield CCA UKEM with Kyber-comparable ciphertext sizes.
- **14438203.pdf** — Distributed Broadcast Encryption from Bilinear Groups (Kolonelos, Malavolta, Wee). First practical, adaptively secure DBE without obfuscation, from standard assumptions in prime-order bilinear groups.
- **14438208.pdf** — The Relationship Between Idealized Models Under Computationally Bounded Adversaries (Zhang, Zhandry). Via computational indifferentiability, shows ROM is strictly milder than GGM, which is strictly milder than GBM.
- **14438211.pdf** — Automated Meet-in-the-Middle Attack Goes to Feistel (Hou, Dong, Qin, Zhang, Wang). New automatic MitM modeling for Feistel-based hash functions, extending tools previously limited to SPN constructions.
- **14438212.pdf** — On the (Im)possibility of Time-Lock Puzzles in the Quantum Random Oracle Model (Afshar, Chung, Hsieh, Lin, Mahmoody). Proves no time-lock puzzles exist from quantum-accessible random oracles when the puzzle generator is classical.
- **14438214.pdf** — Adaptive Distributional Security for Garbling Schemes with O(|x|) Online Complexity (Alpírez Bock, Brzuska, Karanko, Oechsner, Puniamurthy). Identifies when optimal |x|-size online garbling is achievable under distributional security despite AIKW/HW lower bounds.
- **14438215.pdf** — Degree-D Reverse Multiplication-Friendly Embeddings: Constructions and Applications (Escudero, Hong, Liu, Xing, Yuan). Generalizes RMFEs to degree D, shows essential equivalence with Cheon-Lee packing methods, and gives AG-based constructions.
- **14438217.pdf** — Zero-Knowledge Functional Elementary Databases (Zhang, Deng). ZK-EDBs answering general circuit-predicate queries over committed databases without revealing size; proofs linear in record length and circuit size (ROM+GGM).
- **14438218.pdf** — VSS from Distributed ZK Proofs and Applications (Atapoor, Baghery, Cozzo, Pedersen). Very efficient NI-VSS built from ZK proofs on secret-shared data; deals 2048 shares in ~2s, far faster than Pedersen VSS.
- **14438222.pdf** — Registered ABE via Predicate Encodings (Zhu, Zhang, Gong, Qian). First generic black-box registered-ABE construction from predicate encodings under k-Lin; yields prime-order span-program and first ABP Reg-ABE schemes.
- **14438223.pdf** — (no extract) — File contains no extracted text ("[NO TEXT EXTRACTED]"); content cannot be identified from this chunk.
- **14438224.pdf** — Revisiting Higher-Order Differential-Linear Attacks from an Algebraic Perspective (Hu, Peyrin, Tan, Yap). New tools (HATF, DSF) to detect HD/HDL distinguishers with low complexity, effective on quadratic ciphers like Ascon and Xoodyak.
- **14438226.pdf** — Robust Publicly Verifiable Covert Security: Limited Information Leakage and Guaranteed Correctness with Low Overhead (Liu, Lai, Wang, Qin, Yang, Weng). Strengthens PVC security so honest parties keep privacy/correctness guarantees even when covert misbehavior goes undetected.
- **14438237.pdf** — Predicate Aggregate Signatures and Applications (Qiu, Tang). New primitive aggregating signatures while certifying signers satisfy a public predicate; logarithmic size/verification with applications across multi/threshold/ring/attribute signatures.
- **14438239.pdf** — Sender-Anamorphic Encryption Reformulated: Achieving Robust and Generic Constructions (Wang, Chen, Huang, Yung). Reformulates sender-anamorphic encryption as l-sender-AME, enabling robust generic constructions fixing limitations of LWE-based prior schemes.
