# Batch 056 digest

## Overview
- Mixed batch: 9 recent (2026-era) preprints followed by a large block of classic ~2001-era papers (Asiacrypt/Crypto/Eurocrypt, with OCR artifacts like "±" for "ffi") on MPC, RSA/OAEP, signatures, and protocols.
- Dominant classic themes: secure multi-party computation (UC commitments, minimal complete primitives, constant-round MPC, robust MPC, secret reconstruction, asynchronous broadcast), RSA padding analysis (Manger's OAEP attack, Shoup's OAEP reconsideration, Fujisaki-Okamoto-Pointcheval-Stern RSA-OAEP proof), and signature schemes (forward-secure, on-line/off-line, shuffle proofs, NSS cryptanalysis).
- Notable landmark papers: Boneh-Franklin's Identity-Based Encryption from the Weil Pairing (21390212), Boneh-Shparlinski on ECDH bit security (21390200), and Gallant-Lambert-Vanstone endomorphism point multiplication (21390189) — the last two directly relevant to ECDLP/ECC.
- Two braid-group cryptography papers (21390469, 21390485) and two server-aided/hidden-number lattice papers (22480021, 22480036) form small clusters; 22480067 (Lenstra's AES-matching key sizes) is a well-known standards discussion.
- Anomalies: 22480087.pdf has no extractable text (0 pages); 2026-999 is a blockchain-economics (portfolio theory) paper, not cryptography per se; 2026-994 is an AI-verification position paper with a crypto accountability layer.

## Papers
- **2026-991.pdf** — DDYF: Differential Dolev-Yao Fuzzing of Cryptographic Protocols (Gouville, Hirshi, Kremer). Introduces differential Dolev-Yao fuzzing, using a differential oracle across protocol implementations to find logical bugs without manually specifying runtime properties.
- **2026-992.pdf** — Suppressing Hidden Extension-Field Linearity in Rank-Metric Cryptography via Structural Incompatibility (Liao, Li, Yu). Proposes EnGMS masked Gabidulin sub-codes whose dimension mismatch deterministically rules out hidden extension-field linearity, yielding IND-CCA2 PKE and KEMs resistant to structural attacks.
- **2026-993.pdf** — Format-Preserving Encryption Creates a Privacy Attack Surface for Re-Identification (Boesgaard, Larsen). Formalizes information-theoretic leakage of format-preserving de-identification on variable-format data, quantifying re-identification risk on Danish financial datasets.
- **2026-994.pdf** — Super-intelligence Survival Guide: Verification via Proof-Carrying Output (Avni, Yagudaev, Dolev, Yung). Position paper: AI outputs should carry machine-checkable proofs, with a cryptographic accountability layer binding output, proof, and validator identity.
- **2026-995.pdf** — On Local Invariants for Permutation Equivalence (Benčina). Gives an efficiently computable "square class" invariant for (Signed) Permutation Code Equivalence, yielding a distinguisher that breaks the hardness assumption behind a Eurocrypt 2025 updatable PKE.
- **2026-996.pdf** — Topology-Hiding Computation From Key Agreement in Diameter-Two Graphs (Banoun, Boyle, Cohen). Studies whether topology-hiding MPC/broadcast against multiple corruptions is possible from key agreement rather than OT, for diameter-two graph classes.
- **2026-997.pdf** — Miraidon: MinRank Identification (Cartor, Slaughter). New MinRank-based post-quantum signature family from a zero-knowledge proof system, including the first MinRank-based linkable ring signature.
- **2026-998.pdf** — Balanced and Adaptively Secure Asynchronous Common Coin and Byzantine Agreement With Sub-Quadratic Communication (Feng, Mai, Tang). First balanced asynchronous common coin with Õ(√n) per-node communication, tolerating up to 1/2−ε adaptive corruptions without FHE.
- **2026-999.pdf** — Modern Portfolio Theory in the Crypto-Wilderness (Vynyavskyy, Kitzler, Haslhofer, Yaish). Blockchain-economics study reconstructing 116M Ethereum account portfolios to test modern portfolio theory; not a cryptography paper.
- **21.pdf** — Security Evaluation of DPA Countermeasures Using Dual-Rail Pre-charge Logic Style (Suzuki, Saeki). Evaluates MDPL logic against DPA, showing leakage from input-signal delay differences persists despite random masking, confirmed by FPGA measurements.
- **211.pdf** — Quantum Anonymous Transmissions (Christandl, Wehner). Quantum protocol for traceless anonymous transmission of classical bits and qubits, impossible classically; introduces anonymous entanglement.
- **21390001.pdf** — On the (Im)possibility of Obfuscating Programs (Barak, Goldreich, Impagliazzo, Rudich, Sahai, Vadhan, Yang). Landmark impossibility result: virtual-black-box program obfuscation is impossible in general, constructing unobfuscatable function families.
- **21390019.pdf** — Universally Composable Commitments (Canetti, Fischlin). Defines UC security for commitments; shows impossibility in the plain model and gives non-interactive UC commitments in the CRS model.
- **21390040.pdf** — Revocation and Tracing Schemes for Stateless Receivers (Naor, Naor, Lotspiech). Introduces the Subset-Cover framework for broadcast revocation with stateless receivers, plus a traitor-tracing mechanism needing no a-priori traitor bound.
- **21390062.pdf** — Self Protecting Pirates and Black-Box Traitor Tracing (Kiayias, Yung). Models self-protecting pirate decoders and proves Boneh-Franklin and Kurosawa-Desmedt schemes cannot black-box trace superlogarithmic coalitions without linear-size ciphertexts.
- **21390079.pdf** — Minimal Complete Primitives for Secure Multi-Party Computation (Fitzi, Garay, Maurer, Ostrovsky). Identifies complete primitives of minimal player cardinality for MPC with t ≥ n/3 corruptions, proving completeness and minimality.
- **21390100.pdf** — Robustness for Free in Unconditional Multi-Party Computation (Hirt, Maurer). Efficient actively secure MPC for t < n/3 with O(mn²) communication, matching passive-model complexity of the best known protocols.
- **21390118.pdf** — Secure Distributed Linear Algebra in a Constant Number of Rounds (Cramer, Damgård). Constant-round secure protocols for determinant, rank, characteristic polynomial, and linear systems over shared finite-field values.
- **21390136.pdf** — Two-Party Generation of DSA Signatures (MacKenzie, Reiter). Practical two-party protocol for shared DSA signing, proven secure for concurrent execution in the random oracle model.
- **21390154.pdf** — Oblivious Transfer in the Bounded Storage Model (Ding). More efficient 1-out-of-2 OT secure against storage-bounded receivers, improving Cachin-Crépeau-Marcil with exponentially small cheating probability.
- **21390170.pdf** — Parallel Coin-Tossing and Constant-Round Secure Two-Party Computation (Lindell). Constant-round malicious-secure two-party computation for any functionality via constant-round parallel coin-tossing, plus a perfect coin-tossing protocol.
- **21390189.pdf** — Faster Point Multiplication on Elliptic Curves with Efficient Endomorphisms (Gallant, Lambert, Vanstone). The GLV method: decomposes scalars using efficiently computable endomorphisms to speed EC point multiplication by up to 50%.
- **21390200.pdf** — On the Unpredictability of Bits of the Elliptic Curve Diffie-Hellman Scheme (Boneh, Shparlinski). Shows predicting even one bit of the ECDH secret over a family of curves is as hard as computing the whole secret.
- **21390212.pdf** — Identity-Based Encryption from the Weil Pairing (Boneh, Franklin). Landmark first fully functional IBE scheme, CCA-secure in the random oracle model under a bilinear Diffie-Hellman assumption on elliptic curves.
- **21390229.pdf** — A Chosen Ciphertext Attack on RSA OAEP as Standardized in PKCS #1 v2.0 (Manger). Adaptive chosen-ciphertext attack recovering plaintext from PKCS#1 v2.0 RSA-OAEP in about log₂ n oracle queries, exploiting implementation error leakage.
- **21390238.pdf** — OAEP Reconsidered (Shoup). Exposes an unfixable gap in the OAEP security proof via an oracle separation, and proposes OAEP+ with a complete random-oracle proof.
- **21390259.pdf** — RSA-OAEP is Secure under the RSA Assumption (Fujisaki, Okamoto, Pointcheval, Stern). Repairs the OAEP situation by proving RSA-OAEP CCA-secure in the random oracle model under the RSA assumption alone, via partial-domain one-wayness.
- **21390291.pdf** — On-Line Ciphers and the Hash-CBC Construction (Bellare, Boldyreva, Knudsen, Namprempre). Initiates the study of on-line (single-pass, length-preserving) ciphers, giving security definitions, attacks on candidates, and the provably secure HCBC construction.
- **21390309.pdf** — The Order of Encryption and Authentication for Protecting Communications (Krawczyk). Proves encrypt-then-authenticate is the only generically secure composition; shows SSL's authenticate-then-encrypt is generically insecure but safe for CBC/stream ciphers.
- **21390330.pdf** — Forward-Secure Signatures with Optimal Signing and Verifying (Itkis, Reyzin). First forward-secure signature scheme with signing/verification as fast as Guillou-Quisquater (two short-exponent exponentiations), secure in the random oracle model.
- **21390353.pdf** — Improved On-line/Off-line Signature Schemes (Shamir, Tauman). Introduces the hash-sign-switch paradigm using trapdoor hash functions, yielding highly efficient on-line/off-line signatures with enhanced security.
- **21390366.pdf** — An Efficient Scheme for Proving a Shuffle (Furukawa, Sako). Zero-knowledge shuffle-correctness proof needing ~18n exponentiations and 2^11n bits, a building block for universally verifiable mix-nets and voting.
- **21390386.pdf** — An Identity Escrow Scheme with Appointed Verifiers (Camenisch, Lysyanskaya). Group-membership proofs with anonymity and revocability, restricted so only appointed verifiers can be convinced; efficient construction under number-theoretic assumptions.
- **21390406.pdf** — Session-Key Generation using Human Passwords Only (Goldreich, Lindell). Password-only session-key protocols secure against active channel adversaries without random oracles or setup assumptions, limiting attackers to near on-line dictionary guesses.
- **21390431.pdf** — Cryptanalysis of RSA Signatures with Fixed-Pattern Padding (Brier, Clavier, Coron, Naccache). Extends Girault-Misarsky attacks to show RSA fixed-pattern padding is insecure when the pattern is shorter than two-thirds of the modulus.
- **21390439.pdf** — Correlation Analysis of the Shrinking Generator (Golić). Two-stage fast correlation attack on the shrinking generator stream cipher using posterior bit probabilities to reconstruct both LFSR initial states.
- **21390457.pdf** — Nonlinear Vector Resilient Functions (Cheon). Constructs (n+D+1, m, d−1)-resilient functions from linear codes with high algebraic degree and nonlinearity, generalizing resilient function design.
- **21390469.pdf** — New Public Key Cryptosystem using Finite Non Abelian Groups (Paeng, Ha, Kim, Chee, Park). Proposes a public-key scheme on finite non-abelian groups (extending braid-group ideas) with fast encryption and a derived signature scheme.
- **21390485.pdf** — Pseudorandomness from Braid Groups (Lee, Lee, Hahn). Builds provably secure pseudorandom generators and synthesizers from braid-group assumptions (conjugacy one-wayness, decision Ko-Lee).
- **21390503.pdf** — On the Cost of Reconstructing a Secret, or VSS with Optimal Reconstruction Phase (Cramer, Damgård, Fehr). Proves an Ω(nl + kn²) communication lower bound for robust secret reconstruction against t ≤ ⌊(n−1)/2⌋ active corruptions, with a matching upper bound.
- **21390524.pdf** — Secure and Efficient Asynchronous Broadcast Protocols (Cachin, Kursawe, Petzold, Shoup). Formal cryptographic model and protocols for reliable, atomic, and secure causal broadcast in asynchronous Byzantine settings using threshold cryptography.
- **21390542.pdf** — Soundness in the Public-Key Model (Micali, Reyzin). Identifies four distinct soundness notions for interactive proofs in the bare public-key model, proving their separation and analyzing prior protocols' round complexity.
- **21390566.pdf** — Robust Non-Interactive Zero Knowledge (De Santis, Di Crescenzo, Ostrovsky, Persiano, Sahai). Studies NIZK in the multi-party setting, strengthening non-malleable NIZK constructions and robustness under a common random string.
- **22.pdf** — Instruction Set Extensions for Efficient AES Implementation on 32-bit Processors (Tillich, Großschädl). Custom processor instructions for AES on a Leon2 embedded core, achieving ~10× speedup with modest silicon area increase.
- **22480001.pdf** — Cryptanalysis of the NTRU Signature Scheme (NSS) from Eurocrypt 2001 (Gentry, Jonsson, Stern, Szydlo). Breaks NSS: efficient universal forgery plus secret-key recovery from ~tens of thousands of signatures via correlation/transcript analysis.
- **22480021.pdf** — On the Insecurity of a Server-Aided RSA Protocol (Nguyen, Shparlinski). Lattice-based passive attack on the RSA-S1 server-aided signature protocol, factoring the modulus from a single run when a small public exponent is used.
- **22480036.pdf** — The Modular Inversion Hidden Number Problem (Boneh, Halevi, Howgrave-Graham). Defines MIHNP, gives a lattice algorithm when >1/3 of bits are known, and builds efficient algebraic PRNGs and MACs from its assumed hardness.
- **22480052.pdf** — Secure Human Identification Protocols (Hopper, Blum). Defines security goals for human-only authentication without trusted hardware, shows existing schemes fall short, and gives secure-but-impractical feasibility protocols.
- **22480067.pdf** — Unbelievable Security: Matching AES security using public key systems (Lenstra). Derives RSA, finite-field ElGamal, and ECC key sizes matching AES-128/192/256 security levels, commenting on practicality of the huge resulting keys.
