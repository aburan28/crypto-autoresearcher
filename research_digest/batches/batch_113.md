# Batch 113 digest

## Overview
- Dominated by 2015-era public-key cryptography: provable-security constructions for signatures, encryption, key exchange, NIZK, and commitments (mostly PKC/EUROCRYPT/CRYPTO-style papers).
- Heavy post-quantum theme: lattice-based group signatures, trapdoor sampling, LPN encryption, code-based cryptanalysis (BBCRS, binary linear code decoding), and a quantum-money cryptanalysis.
- FHE and garbled-circuit efficiency cluster: FHEW (sub-second bootstrapping), HElib bootstrapping, half-gates garbling, privacy-free garbled circuits, AGCD-based FHE.
- Strong symmetric-cryptanalysis contingent: cube attacks on Keccak, invariant subspace attacks, division property, Even-Mansour related-key analysis, FX-construction tradeoffs, Sbox equivalence.
- DLP-relevant items: improved NFS for GF(p^n) (with a 595-bit GF(p^2) record), Multiple NFS with Conjugation, and a tight generic lower bound for the multiple discrete logarithm problem.
- No anomalies: all 50 files are legitimate research papers; no duplicates, no non-paper content.

## Papers
- **90200157.pdf** — Digital Signatures from Strong RSA without Prime Generation (Cash, Dowsley, Kiltz). Strong-RSA signature scheme secure in the standard model, adapting Hohenberger–Waters prefix signing to avoid generating primes at signing time.
- **90200158.pdf** — Group Signatures from Lattices: Simpler, Tighter, Shorter, Ring-based (Ling, Nguyen, Wang). Lattice-based group signatures with simpler design and weaker assumptions, via a new statistical ZK argument of knowledge of a Boyen signature pair.
- **90200159.pdf** — Public-Key Encryption Indistinguishable Under Plaintext-Checkable Attacks (Abdalla, Benhamouda, Pointcheval). Formalizes IND-PCA, a relaxation of IND-CCA, and gives an efficient DDH-based variant of Cramer–Shoup usable in PAKE schemes.
- **90200160.pdf** — One-Round Key Exchange with Strong Security (Bergsma, Jager, Schwenk). Generic standard-model construction of one-round AKE from NIKKE, signatures, and PRFs, secure even when the attacker learns randomness or long-term keys.
- **90200164.pdf** — Additively Homomorphic UC Commitments with Optimal Amortized Overhead (Cascudo, Damgård, David, Giacomelli, Nielsen, Trifiletti). First UC-secure commitments with linear amortized complexity, from OT preprocessing, a PRG, and a linear code.
- **90200167.pdf** — Low Noise LPN: KDM Secure Public Key Encryption and Sample Amplification (Döttling). First standard-model KDM-secure PKE from low-noise LPN, plus a reduction between bounded- and unbounded-sample LPN via extended LPN.
- **90200171.pdf** — A Profitable Sub-Prime Loan (Lewko, Meiklejohn). Unified dual-pairing-vector-space framework simulating composite-order bilinear group features (projecting, canceling) in prime-order groups, with leakage-resilience applications.
- **90200173.pdf** — A Polynomial-Time Key-Recovery Attack on MQQ Cryptosystems (Faugère, Gligoroski, Perret, Samardjiska, Thomae). Breaks MQQ-SIG and MQQ-ENC multivariate schemes by exploiting shared algebraic structure and a polynomial-time-solvable MinRank problem.
- **90200174.pdf** — Interactive Message-Locked Encryption and Secure Deduplication (Bellare, Keelveedhi). Extends MLE to interactive protocols, giving standard-model privacy for correlated, parameter-dependent messages in cloud deduplication.
- **90200177.pdf** — On the Practical Security of Inner Product Functional Encryption (Agrawal, Agrawal, Badrinarayanan, Kumarasubramanian, Prabhakaran, Sahai). Analyzes inner-product FE under practically feasible attacks and defines achievable security for general usage scenarios.
- **90200181.pdf** — Simple Lattice Trapdoor Sampling from a Broad Class of Distributions (Lyubashevsky, Wichs). Non-Gaussian trapdoor sampling avoiding high-precision arithmetic, trading larger output norm for efficient sampling on constrained devices.
- **90200183.pdf** — Algebraic Cryptanalysis of a Quantum Money Scheme: The Noise-Free Case (Conde Pena, Faugère, Perret). Randomized polynomial-time algorithm solving the Hidden Subspace Problem over F_q, breaking the general-field extension of Aaronson–Christiano quantum money.
- **90200185.pdf** — Faster ECC over F_2^521-1 (Granger, Scott). New multiplication algorithm for the Mersenne prime 2^521−1 giving record constant-time scalar multiplication on NIST P-521 and Edwards E-521 on Haswell.
- **90200190.pdf** — Secure Efficient History-Hiding Append-Only Signatures in the Standard Model (Libert, Joye, Yung, Peters). First history-hiding append-only signature scheme with standard-model security, hiding signing order for applications like ballots and petitions.
- **90200192.pdf** — Making Sigma-protocols Non-interactive without Random Oracles (Chaidos, Groth). Alternative instantiation of the Damgård–Fazio–Nicolosi transformation achieving culpable soundness without complexity leveraging; applied to encrypted-vote validity.
- **90200201.pdf** — A Tamper and Leakage Resilient von Neumann Architecture (Faust, Mukherjee, Nielsen, Venturi). Compiler for RAM computation secure against disk/bus tampering and leakage, assuming only continuous non-malleable codes.
- **90200209.pdf** — Identity-based encryption with (almost) tight security in the multi-instance, multi-ciphertext setting (Hofheinz, Koch, Striecks). IBE with O(k) security loss in a multi-instance, multi-ciphertext model, extending Chen–Wee techniques.
- **90200211.pdf** — Anonymous Transferable E-Cash (Baldimtsi, Chase, Fuchsbauer, Kohlweiss). First efficient fully anonymous transferable e-cash without trusted parties, using malleable signatures and a new double-spending mechanism.
- **90200213.pdf** — A Polynomial-Time Attack on the BBCRS Scheme (Couvreur, Otmani, Tillich, Gauthier-Umaña). O(n^6) key-recovery attack on the BBCRS McEliece variant when rank z=1, breaking all suggested parameters.
- **90200219.pdf** — Predicate Encryption for Multi-Dimensional Range Queries from Lattices (Gay, Méaux, Wee). First LWE-based predicate encryption supporting multi-dimensional range and subset queries, selectively secure and weakly attribute-hiding.
- **90560104.pdf** — Cube Attacks and Cube-attack-like Cryptanalysis on the Round-reduced Keccak Sponge Function (Dinur, Morawiecki, Pieprzyk, Srebrny, Straus). Algebraic cube attacks on keyed Keccak breaking up to 9 of 24 rounds, with practical 6-round attacks verified on a PC.
- **90560105.pdf** — Non-interactive zero-knowledge proofs in the quantum random oracle model (Unruh). NIZK proofs of knowledge from sigma protocols secure against quantum adversaries, via new adaptive quantum random-oracle programming techniques.
- **90560113.pdf** — Generic Hardness of the Multiple Discrete Logarithm Problem (Yun). Proves a tight generic-group lower bound for solving n simultaneous DL instances, via a new "search-by-hyperplane-queries" problem.
- **90560120.pdf** — (Batch) Fully Homomorphic Encryption over Integers for Non-Binary Message Spaces (Nuida, Kurosawa). Integer-based FHE with message space Z_Q for any prime Q, lower-degree decryption circuit, and a batched extension.
- **90560121.pdf** — Privacy-Free Garbled Circuits with Applications to Efficient Zero-Knowledge (Frederiksen, Nielsen, Orlandi). Garbling schemes achieving authenticity without privacy, giving one-ciphertext-per-gate ZK proofs and the first natural separation of GC notions.
- **90560122.pdf** — Improving NFS for the discrete logarithm problem in non-prime finite fields (Barbulescu, Gaudry, Guillevic, Morain). Two new polynomial-selection methods for NFS in GF(p^n), with a record 595-bit GF(p^2) discrete-log computation.
- **90560124.pdf** — A Provable-Security Analysis of Intel's Secure Key RNG (Shrimpton, Terashima). First provable-security model of Intel's ISK-RNG: no backward security, weak RDSEED forward security, stronger bounds for RDRAND.
- **90560130.pdf** — More Efficient Oblivious Transfer Extensions with Security for Malicious Adversaries (Asharov, Lindell, Schneider, Zohner). Faster malicious-secure OT extension with less communication, provable in ROM and in the standard model under correlation robustness.
- **90560131.pdf** — On the behaviors of affine equivalent Sboxes regarding differential and linear attacks (Canteaut, Roué). Shows 2-round MEDP/MELP of SPNs are not invariant under affine Sbox equivalence; new bounds, maximal for involutions.
- **90560136.pdf** — On Computing Nearest Neighbors with Applications to Decoding of Binary Linear Codes (May, Ozerov). Sub-quadratic nearest-neighbor algorithm improving information set decoding of random binary linear codes to 2^0.114n full distance.
- **90560137.pdf** — On the Provable Security of the Iterated Even-Mansour Cipher against Related-Key and Chosen-Key Attacks (Cogliati, Seurin). Bounds for iterated Even–Mansour under xor-induced related-key and chosen-key attacks; three rounds suffice for linear key schedules.
- **90560142.pdf** — The Multiple Number Field Sieve with Conjugation and Generalized Joux-Lercier Methods (Pierrot). Combines MNFS with Conjugation/Generalized Joux–Lercier polynomial selection, giving the best asymptotic medium-characteristic DLP algorithm L(1/3, ~2.156).
- **90560148.pdf** — Cryptanalytic Time-Memory-Data Tradeoffs for FX-Constructions with Applications to PRINCE and PRIDE (Dinur). New TMD tradeoff attacks on FX-constructions reducing the practical security margin of PRINCE and PRIDE below proof estimates.
- **90560152.pdf** — Cryptographic Reverse Firewalls (Mironov, Stephens-Davidowitz). Introduces reverse firewalls that sit between a user's (possibly compromised) machine and the network, preserving functionality, security, and resisting exfiltration.
- **90560155.pdf** — A Generic Approach to Invariant Subspace Attacks: Cryptanalysis of Robin, iSCREAM and Zorro (Leander, Minaud, Rønjom). Generic algorithm detecting invariant subspaces, yielding practical breaks of iSCREAM, Robin, and Zorro via weak key sets of density 2^-32.
- **90560158.pdf** — KDM-CCA Security from RKA Secure Authenticated Encryption (Lu, Li, Jia). Efficient KDM-CCA secure PKE for affine functions under the decisional composite residuosity assumption, using RKA-secure authenticated encryption.
- **90560159.pdf** — FHEW: Bootstrapping Homomorphic Encryption in less than a second (Ducas, Micciancio). New method to homomorphically evaluate bit operations and refresh ciphertexts in ~0.5 s on a PC, versus ~6 minutes in HElib.
- **90560162.pdf** — Fully Homomorphic Encryption over the Integers Revisited (Cheon, Stehlé). Reduction from LWE to AGCD and a new AGCD-based FHE scheme avoiding the Sparse Subset Sum assumption with Õ(λ)-bit ciphertexts.
- **90560171.pdf** — Disjunctions for Hash Proof Systems: New Constructions and Applications (Abdalla, Benhamouda, Pointcheval). Hash proof systems for disjunctions of languages over cyclic/bilinear/multilinear groups, yielding simulation-sound QA-NIZK and one-round group PAKE without ROM.
- **90560176.pdf** — Quasi-Adaptive NIZK for Linear Subspaces Revisited (Kiltz, Wee). Cleaner, improved quasi-adaptive NIZK constructions for linear subspaces inspired by IBE techniques, extended to structure-preserving signatures.
- **90560178.pdf** — Structural Evaluation by Generalized Integral Property (Todo). Introduces the division property generalizing integral distinguishers, improving attacks on Feistel and SPN ciphers with non-bijective or low-degree components.
- **90560182.pdf** — Linear Secret Sharing Schemes from Error Correcting Codes and Universal Hash Functions (Cramer, Damgård, Döttling, Fehr, Spini). Black-box LSSS construction with privacy depending only on code rate, yielding linear-time near-threshold and efficient robust secret sharing.
- **90560183.pdf** — Cryptanalysis of SP Networks with Partial Non-Linear Layers (Bar-On, Dinur, Dunkelman, Lallemand, Keller, Tsaban). Generic differential/linear tools for SP networks with partial non-linear layers, with practical attacks on Zorro and a proposed fix.
- **90560190.pdf** — The Sum Can Be Weaker Than Each Part (Leurent, Wang). Shows the XOR combiner of two narrow-pipe hash functions never provides n-bit preimage resistance, contrary to its PRF/MAC robustness.
- **90560192.pdf** — Cluster Computing in Zero Knowledge (Chiesa, Tromer, Virza). Zero-knowledge proof systems for MapReduce computations where proof generation itself is a distributed cluster computation of similar structure.
- **90560194.pdf** — Semantically Secure Order-Revealing Encryption (Boneh, Lewi, Raykova, Sahai, Zhandry, Zimmerman). First implementable order-revealing encryption with best-possible semantic security from multilinear maps, without obfuscation.
- **90560203.pdf** — Noisy Leakage Revisited (Dziembowski, Faust, Skorski). Alternative leakage model eliminating the non-tightness in the probing-to-noisy-leakage reduction for masking-scheme security proofs.
- **90560204.pdf** — Two Halves Make a Whole: Reducing Data Transfer in Garbled Circuits using Half Gates (Zahur, Rosulek, Evans). Half-gate technique giving 2-ciphertext AND gates compatible with free-XOR, the smallest garbled circuits to date, with up to 25% speedup.
- **90560206.pdf** — Bootstrapping for HElib (Halevi, Shoup). Implementation of recryption for fully packed HElib ciphertexts over extension fields; 1024-element GF(2^16) vectors refreshed in under 5.5 minutes.
- **90560208.pdf** — Resisting Randomness Subversion: Fast Deterministic and Hedged Public-key Encryption in the Standard Model (Bellare, Hoang). First efficient standard-model deterministic/hedged PKE via UCEs plus lossy TDFs, plus unique-ciphertext PKE against algorithm-substitution attacks.
