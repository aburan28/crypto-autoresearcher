# Batch 036 digest

## Overview
- Batch drawn from two consecutive arXiv submission clusters (~2021–2022); content is overwhelmingly PKC/EUROCRYPT-2022-era public-key theory papers.
- Dominant themes: post-quantum cryptography (lattices, isogenies, code-based), zero-knowledge/SNARK constructions, and MPC protocols.
- Strong isogeny thread: Séta encryption, HealS/SHealS, radical isogenies on Montgomery curves, OSIDH attack, torsion-point reductions, and Wesolowski's orientation/endomorphism-ring reductions.
- Lattice-based constructions are pervasive: tight signatures, blind signatures, IPFE, leakage-resilient IBE/ABE, gadget sampling, lockable obfuscation, OLE, and updatable encryption.
- Several SNARK/proof-system papers (Szepieniec, Lipmaa, ECLIPSE, DCR range proofs) plus MPC works (reusable two-round MPC, FaB-DPSS, SPDZ triples, bottleneck complexity).
- No anomalies: all 50 extracts are genuine research-paper first pages; no duplicates, slides, or non-paper content found.

## Papers
- **130900340.pdf** — Security Analysis of CPace (Abdalla, Haase, Hesse). Comprehensive UC security analysis of the CPace PAKE protocol with adaptive corruptions, avoiding idealized treatment of the Map2Pt hash-to-curve function.
- **130900343.pdf** — Modular Design of Role-Symmetric Authenticated Key Exchange Protocols (Xiao, Zhang, Ma). Reunites CK/eCK-style security models for one-round AKE and introduces key-wise recoverable functions to build modular ORKE constructions.
- **130900345.pdf** — Séta: Supersingular Encryption from Torsion Attacks (De Feo et al.). New family of isogeny-based public-key encryption schemes using Petit's torsion attacks on SIDH as trapdoor, with OW-CPA proofs and IND-CCA variant.
- **130900347.pdf** — SHealS and HealS: isogeny-based PKEs from a key validation method for SIDH (Fouotsa, Petit). New countermeasure to the GPST adaptive attack enabling static SIDH keys without k-SIDH overhead, yielding PKE and static-static key exchange.
- **131770011.pdf** — Multitarget Decryption Failure Attacks and their Application to Saber and Kyber (D'Anvers, Batsleer). Improves multitarget failure-boosting attacks and cost models, computing attack costs for all Saber/Kyber parameter sets (Saber quantum security theoretically drops to 145 bits).
- **131770015.pdf** — Polynomial IOPs for Linear Algebra Relations (Szepieniec, Zhang). New polynomial IOPs using monomial coefficient basis for matrix-vector and Hadamard products, yielding SNARKs with succinct verification.
- **131770016.pdf** — Post-quantum Asynchronous Deniable Key Exchange and the Signal Handshake (Brendel, Fiedler, Günther, Janson, Stebila). Builds Signal-like asynchronous deniable key exchange from KEMs plus designated-verifier signatures, preserving deniability and forward secrecy post-quantum.
- **131770019.pdf** — Post-quantum Security of Plain OAEP Transform (Ebrahimi). Proves unmodified OAEP is IND-CCA secure in the quantum random oracle model from quantum partial-domain one-wayness, answering an NTRU open question.
- **131770023.pdf** — Radical Isogenies on Montgomery Curves (Onuki, Moriya). Degree-3 and degree-4 radical isogeny formulas working directly on Montgomery curves, more efficient for CSIDH-type systems; proves an open conjecture for degree 4.
- **131770027.pdf** — Lattice-based Signatures with Tight Adaptive Corruptions and More (Pan, Wagner). First tightly secure multi-user signature schemes from LWE with adaptive corruptions, via dual-mode commitments and sequential OR proofs; isogeny instantiation possible.
- **131770029.pdf** — Towards a Simpler Lattice Gadget Toolkit (Zhang, Yu). Two new gadget sampling algorithms for arbitrary moduli: a floating-point-free Gaussian sampler and a faster subgaussian sampler needing less randomness.
- **131770035.pdf** — Post-Quantum Anonymous One-Sided Authenticated Key Exchange without Random Oracles (Ishibashi, Yoneyama). Generic constructions of anonymous one-sided AKE in ROM and standard model, giving the first isogeny-based standard-model instantiation.
- **131770036.pdf** — Traceable PRFs: Full Collusion Resistance and Active Security (Maitra, Wu). Uses fingerprinting codes to upgrade single-key traceable PRFs to fully collusion-resistant ones, plus a stronger active-security tracing notion.
- **131770037.pdf** — On the security of OSIDH (Dartois, De Feo). New exponential-complexity attack on OSIDH that practically breaks Colò–Kohel's proposed parameters, building on Onuki's work, with discussion of countermeasures.
- **131770046.pdf** — Time-Memory tradeoffs for large-weight syndrome decoding in ternary codes (Karpman, Lefevre). Memory-efficient dissection-based algorithms for the ternary syndrome decoding problem underlying the Wave signature scheme.
- **131770047.pdf** — Efficient Lattice-Based Inner-Product Functional Encryption (Bermudo Mera, Karmakar, Marc, Soleimanian). First RLWE-based inner-product FE scheme, using a multi-hint extended Ring-LWE variant and a ring leftover hash lemma.
- **131770052.pdf** — On Pairing-Free Blind Signature Schemes in the Algebraic Group Model (Kastner, Loss, Xu). Proves security of a modified Abe blind signature and blind Schnorr in AGM+ROM with polynomially many concurrent sessions.
- **131770056.pdf** — Improved Constructions of Anonymous Credentials From Structure-Preserving Signatures on Equivalence Classes (Connolly, Lafourcade, Perez Kempner). Adds signing-key equivalence classes to SPS-EQ-based credentials, achieving signer-hiding anonymous credentials and Mercurial signatures.
- **131770058.pdf** — Lockable Obfuscation from Circularly Insecure Fully Homomorphic Encryption (Kluczniak). Generic lockable obfuscation from IND-CPA FHE with an efficient cycle tester, bypassing iO and multilinear-map approaches.
- **131770064.pdf** — Reusable Two-Round MPC from LPN (Bartusek, Garg, Srinivasan, Zhang). Maliciously secure two-round MPC with reusable first message from LPN, via multiparty silent NISC, without DDH/LWE-style homomorphic assumptions.
- **131770065.pdf** — The Direction of Updatable Encryption Does Matter (Nishimaki). Introduces backward-leak uni-directional key updates, shows it is strictly stronger than bi-directional security, and gives an LWE-based scheme meeting it.
- **131770068.pdf** — KDM Security for the Fujisaki-Okamoto Transformations in the QROM (Kitagawa, Nishimaki). Proves KDM-CPA and KDM-CCA security in the QROM for PKE built from FO-transformed KEMs, without square-root loss.
- **131770070.pdf** — Leakage-Resilient IBE/ABE with Optimal Leakage Rates from Lattices (Lai, Liu, Wang). First adaptively secure lattice IBE and ABE with near-1 leakage rates, via succinct-key identity/attribute-based weak hash proof systems.
- **131770071.pdf** — Fast Batched DPSS and its Applications (Goyal, Kothapalli, Masserova, Parno, Song). Highly optimized batched dynamic proactive secret sharing at threshold 1/2, outperforming prior schemes 6x, with blockchain applications.
- **131770078.pdf** — Efficient Verifiable Partially-Decryptable Commitments from Lattices and Applications (Esgin, Steinfeld, Zhao). Formalizes VPDCs and extends lattice hashed-message commitments with succinct proofs that a trapdoor holder can decrypt part of the message.
- **131770085.pdf** — A Unified Framework for Non-Universal SNARKs (Lipmaa). General template for knowledge-sound, ASE, and subversion-ZK SNARKs over QAP/SAP/QSP languages, proved in a weakened algebraic group model.
- **131770087.pdf** — Making Private Function Evaluation Safer, Faster, and Simpler (Liu, Wang, Yiu). First constant-round actively secure two-party PFE with linear complexity, extended to publicly verifiable covert security.
- **131770088.pdf** — ECLIPSE: Enhanced Compiling method for Pedersen-committed zkSNARK Engines (Aranha et al.). Compiles AHP-based SNARKs (Marlin, PLONK, Sonic) into commit-and-prove SNARKs with proof size succinct in the number of commitments.
- **131770098.pdf** — Rational Modular Encoding in the DCR Setting (Devevey, Libert, Peters). Transposes rational-modular-encoding range proofs to the DCR assumption in the standard model, plus a Paillier-based Naor-Yung CCA2 instantiation.
- **131770103.pdf** — Syndrome Decoding Estimator (Esser, Bellini). Framework unifying ISD algorithms via nearest-neighbor search, with a public estimator tool giving classical and quantum bit-security estimates for code-based NIST candidates.
- **131770104.pdf** — On the Isogeny Problem with Torsion Point Information (Fouotsa, Kutas, Merz, Ti). Generalizes the GPST reduction: recovers secret isogenies in all SIDH-type schemes from endomorphism rings plus torsion images via a linear system.
- **131770107.pdf** — Encapsulated Search Index: Public-Key, Sub-linear, Distributed, and Delegatable (Aronesty et al.). First sub-linear public-key searchable encryption with delegatable and threshold-distributed token generation, commercially deployed.
- **131770114.pdf** — On the Bottleneck Complexity of MPC with Correlated Randomness (Orlandi, Ravi, Scholl). Bottleneck-efficient preprocessing MPC protocols for abelian programs (from OWFs) and selection functions (from linearly homomorphic encryption).
- **131770119.pdf** — Low-Communication Multiparty Triple Generation for SPDZ from Ring-LPN (Abram, Scholl). First multiparty PCG for SPDZ multiplication triples over large prime fields from ring-LPN, enabling silent preprocessing; includes a new 3-party DPF.
- **131770121.pdf** — A New Security Notion for PKC in the Standard Model (Beskorovajnov et al.). Introduces sender-binding encryption and IND-SB-CPA, the weakest notion so far shown to realize secure message transfer with authenticated channels.
- **131770125.pdf** — Count Me In! Extendability for Threshold Ring Signatures (Aranha, Hall-Andersen, Nitulescu, Pagnin, Yakoubov). Adds extendability to threshold ring signatures so signers can join after the fact without prior coordination on the ring.
- **131770127.pdf** — A Note on the Post-Quantum Security of (Ring) Signatures (Chatterjee, Chung, Liang, Malavolta). First blind-unforgeable short signatures beyond Lamport/Winternitz, and fixes definitions for quantum-security of ring signatures.
- **131770128.pdf** — Logarithmic-Size (Linkable) Threshold Ring Signatures in the Plain Model (Haque, Krenn, Slamanig, Striecks). First logarithmic-size threshold ring signatures in the plain model, building on the Backes et al. template, with linkable variants.
- **131770132.pdf** — Financially Backed Covert Security (Faust, Hazay, Kretzler, Schlosser). Covert security with financial punishment for detected cheaters; transformations from PVC protocols with smart-contract-friendly judging.
- **131770133.pdf** — Efficient Lattice-Based Blind Signatures via Gaussian One-Time Signatures (Lyubashevsky, Nguyen, Plançon). Round-optimal 2-round lattice blind signatures (~150KB), currently the most efficient lattice candidate for bounded signature counts.
- **131770139.pdf** — Two-Round Oblivious Linear Evaluation from Learning with Errors (Branco, Döttling, Mateus). Efficient two-round OLE over large fields from LWE, generalizing the Peikert–Vaikuntanathan–Waters oblivious transfer.
- **131770140.pdf** — Lifting Standard Model Reductions to Common Setup Assumptions (Nguyen, Theodorakis, Warinschi). Shows black-box standard-model reductions lift to non-programmable reductions in ROM/ideal-cipher models via a generalized framework.
- **131770146.pdf** — CNF-FSS and its Applications (Bunn, Kushilevitz, Ostrovsky). Introduces CNF-based function secret sharing and CNF-DPF for the multi-party setting with applications including improved MPC-related protocols.
- **132760015.pdf** — Online-Extractability in the Quantum Random-Oracle Model (Don, Fehr, Majenz, Schaffner). Generic straight-line online extraction in the QROM via a new commutator bound on the compressed oracle; applications to commit-and-open sigma protocols.
- **132760030.pdf** — Beyond quadratic speedups in quantum attacks on symmetric schemes (Bonnetain, Schrottenloher, Sibleyras). First quantum key-recovery with more-than-quadratic speedup using classical queries, attacking the 2XOR-Cascade key-length extension in Õ(2^n).
- **132760032.pdf** — Single-Server Private Information Retrieval with Sublinear Amortized Time (Corrigan-Gibbs, Henzinger, Kogan). Hint-based single-server PIR with sublinear amortized server time, adaptive queries, and matching lower bounds on the time/storage tradeoff.
- **132760035.pdf** — Optimal Tightness for Chain-Based Unique Signatures (Guo, Susilo). Meta-reduction proving the q^(1/n) reduction loss of chain-based BLS unique signatures is optimal under any non-interactive assumption.
- **132760039.pdf** — Key Guessing Strategies for Linear Key-Schedule Algorithms in Rectangle Attacks (Dong, Qin, Sun, Wang). New rectangle-attack framework for ciphers with linear key schedules that guesses key cells to filter invalid quartets and lower complexity.
- **132760044.pdf** — Orientations and the supersingular endomorphism ring problem (Wesolowski). Polynomial-time reductions (under GRH) relating oriented-curve class-group action inversion and supersingular endomorphism ring computation, unifying isogeny problem classes.
- **132760045.pdf** — On Building Fine-Grained One-Way Functions from Strong Average-Case Hardness (Brzuska, Couteau). Constructs fine-grained OWFs from a strong "block finding" average-case hardness notion, with oracle separations ruling out weaker assumptions.
