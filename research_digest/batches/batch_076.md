# Batch 076 digest

## Overview
- Dominated by CHES/ASIACRYPT/EUROCRYPT-era (ca. 2007) papers: heavy concentration on side-channel attacks (DPA, EM, fault) and DPA-resistant logic styles (MDPL, masking, dual-rail), plus FPGA/hardware implementations of AES, ECC, pairings, modular exponentiation, and NFS sieving.
- Strong hash-function theme: Merkle-Damgård variants and preservation results (Lucks wide-pipe, ROX, Hirose, Yasuda), hardware-oriented MAME, and MAC constructions (Alpha-MAC attack, Pelican/MT-MAC analysis).
- Notable results: first SNFS kilobit factorization (2^1039-1, Aoki et al.), Bernstein–Lange Edwards-curve formulas, PRESENT ultra-lightweight cipher, Groth's NIZK shuffle and group signatures without random oracles, FPGA Pollard-rho attack on binary ECDLP.
- Four files are corrupted/unextractable (mojibake or hex-encoded font streams): 46220605.pdf, 47270014.pdf, 47270121.pdf, 47270227.pdf.

## Papers
- **46220546.pdf** — Secure Hybrid Encryption from Weakened Key Encapsulation (Dennis Hofheinz, Eike Kiltz). Introduces constrained CCA security for KEMs, yielding hybrid encryption from assumptions strictly weaker than DDH.
- **46220565.pdf** — Scalable and Unconditionally Secure Multiparty Computation (Ivan Damgård, Jesper Buus Nielsen). First unconditionally secure MPC with communication linear in the number of parties per gate; adaptive active security for t < n/3.
- **46220583.pdf** — On Secure Multi-Party Computation in Black-Box Groups (Yvo Desmedt, Josef Pieprzyk, Ron Steinfeld, Huaxiong Wang). Impossibility and constructions for black-box group product computation, reduced to a planar-graph coloring problem.
- **46220605.pdf** — Unreadable garbled text (font/encoding garbage); not summarizable.
- **472.pdf** — A Failure-Friendly Design Principle for Hash Functions (Stefan Lucks). Proposes wide-pipe and double-pipe hash designs that degrade gracefully when compression-function collision resistance fails.
- **47270001.pdf** — A First-Order DPA Attack Against AES in Counter Mode with Unknown Initial Counter (Josh Jaffe). First-order DPA on counter-mode AES without knowing inputs, outputs, or initial counter.
- **47270014.pdf** — Unreadable garbled text (font/encoding garbage); not summarizable.
- **47270028.pdf** — Side Channel Cryptanalysis of a Higher Order Masking Scheme (Jean-Sébastien Coron, Emmanuel Prouff, Matthieu Rivain). Disproves Schramm–Paar higher-order masking claims with practical 3rd-order DPA attacks for any order d.
- **47270045.pdf** — High-Speed True Random Number Generation with Logic Gates Only (Markus Dichtl, Jovan Dj. Golić). Evaluates Galois/Fibonacci ring oscillators via restart experiments, showing much higher entropy rates than classical ring oscillators.
- **47270063.pdf** — FPGA Intrinsic PUFs and Their Use for IP Protection (Jorge Guajardo, Sandeep Kumar, Geert-Jan Schrijen, Pim Tuyls). First intrinsic SRAM-based PUF construction on FPGAs, with IP-protection protocols and fuzzy extractor analysis.
- **47270081.pdf** — Evaluation of the Masked Logic Style MDPL on a Prototype Chip (Thomas Popp, Mario Kirschbaum, Thomas Zefferer, Stefan Mangard). Power measurements of an MDPL 8051 chip show severe DPA leakage due to early propagation; proposes improvements.
- **47270095.pdf** — Masking and Dual-rail Logic Don't Add Up (Patrick Schaumont, Kris Tiri). Shows routing imbalances let attackers recover the mask bit in masked dual-rail logic, defeating the combined countermeasure.
- **47270107.pdf** — DPA-Resistance Without Routing Constraints? A cautionary note about MDPL security (Benedikt Gierlichs). Practical attack on an MDPL AES ASIC exploiting slight PRNG mask bias in a single AND gate.
- **47270121.pdf** — Unreadable hex-encoded glyph stream (broken text extraction); not summarizable.
- **47270135.pdf** — Highly Regular Right-to-Left Algorithms for Scalar Multiplication (Marc Joye). Regular right-to-left scalar multiplication algorithms needing no dummy operations or recoding, suited to constrained devices against implementation attacks.
- **47270148.pdf** — MAME: A Compression Function with Reduced Hardware Requirements (Hirotaka Yoshida, Dai Watanabe, Katsuyuki Okeya, Jun Kitahara, Hongjun Wu, Özgül Küçük, Bart Preneel). Conservative 256-bit hardware hash compression function requiring only 8.1 Kgates.
- **47270166.pdf** — Collision Attacks on AES-based MAC: Alpha-MAC (Alex Biryukov, Andrey Bogdanov, Dmitry Khovratovich, Timo Kasper). Side-channel collision attack recovering Alpha-MAC internal state with 29 measurements, enabling selective forgery.
- **47270181.pdf** — Secret External Encodings Do not Prevent Transient Fault Analysis (Christophe Clavier). Key-recovery fault attack on DES/3DES hidden by secret external encodings, even with double-execution countermeasure.
- **47270195.pdf** — Two New Techniques of Side-Channel Cryptanalysis (Alex Biryukov, Dmitry Khovratovich). Impossible-collision and multiset-collision attacks showing all AES rounds must be masked; breaks the Schramm et al. masking proposal.
- **47270209.pdf** — AES Encryption Implementation and Analysis on Commodity Graphics Processing Units (Owen Harrison, John Waldron). Novel GPU-based AES implementations exploiting new integer support on recent graphics architectures.
- **47270227.pdf** — Unreadable garbled text (font/encoding garbage); not summarizable.
- **47270239.pdf** — Arithmetic Operators for Pairing-Based Cryptography (Jean-Luc Beuchat, Nicolas Brisebarre, Jérémie Detrey, Eiji Okamoto). Compact FPGA coprocessor for the eta_T pairing over F_3^97 using a unified arithmetic operator; generalizes to other characteristics.
- **47270256.pdf** — FPGA Design of Self-Certified Signature Verification on Koblitz Curves (Kimmo Järvinen, Juha Forsten, Jorma Skyttä). FPGA verifier for identity-based self-certified signatures on Koblitz curves reaching 166,000 verifications/second.
- **47270272.pdf** — How to Maximize the Potential of FPGA Resources for Modular Exponentiation (Daisuke Suzuki). Improved Montgomery-multiplier architecture doing 512-bit modular exponentiation in 0.26 ms on minimal Virtex-4 resources, scalable to 2048 bits.
- **47270289.pdf** — TEC-Tree: A Low-Cost, Parallelizable Tree for Efficient Defense against Memory Replay Attacks (Reouven Elbaz, David Champagne, Ruby Lee, Lionel Torres, Gilles Sassatelli, Pierre Guillemin). Tamper-evident counter tree enabling parallel off-chip memory replay protection without Merkle-tree update serialization.
- **47270320.pdf** — Power and EM Attacks on Passive 13.56 MHz RFID Devices (Michael Hutter, Stefan Mangard, Martin Feldhofer). Demonstrates power/EM attacks recovering AES keys from software and hardware RFID prototypes with under 1,000 traces.
- **47270334.pdf** — RFID Noisy Reader: How to Prevent from Eavesdropping on the Communication? (O. Savry, F. Pebay-Peyroula, F. Dehmas, G. Robert, J. Reverdy). Reader-injected noise at the physical layer protects ISO 14443 card-to-reader communication from passive eavesdropping.
- **47270346.pdf** — RF-DNA: Radio-Frequency Certificates of Authenticity (Gerald DeJean, Darko Kirovski). Electromagnetic certificates of authenticity complementing RFIDs with physically unclonable near-field fingerprints.
- **47270364.pdf** — CAIRN 2: An FPGA Implementation of the Sieving Step in the Number Field Sieve Method (Tetsuya Izu, Jun Kogure, Takeshi Shimoyama). First FPGA NFS sieving device; factored a 423-bit integer in ~30 days, targeting up to 768-bit inputs.
- **47270378.pdf** — Collision Search for Elliptic Curve Discrete Logarithm over GF(2^m) with FPGA (Guerric Meurice de Dormale, Philippe Bulens, Jean-Jacques Quisquater). Dedicated FPGA architectures for parallelized Pollard's rho on binary ECDLP, estimating attack cost for short key sizes.
- **47270394.pdf** — A Hardware-Assisted Realtime Attack on A5/2 without Precomputations (Andrey Bogdanov, Thomas Eisenbarth, Andy Rupp). Special-purpose hardware with parallel Gauss-Jordan solver breaks GSM A5/2 in ~1 second from 16 ciphertext frames.
- **47270413.pdf** — Differential Behavioral Analysis (Bruno Robisson, Pascal Manet). Hybrid DPA/safe-error attack using repetitive stuck-at faults recovers full AES keys in simulation.
- **47270427.pdf** — Information Theoretic Evaluation of Side-Channel Resistant Logic Styles (François Macé, François-Xavier Standaert, Jean-Jacques Quisquater). Information-theoretic metric on gate-level simulations to compare DPA-resistant logic styles before fabrication.
- **47270443.pdf** — On the Implementation of a Fast Prime Generation Algorithm (Christophe Clavier, Jean-Sébastien Coron). SPA on Joye–Paillier prime generation leaks parity bits; combined with Coppersmith's theorem factors ~1/1000 of 1024-bit RSA moduli.
- **47270450.pdf** — PRESENT: An Ultra-Lightweight Block Cipher (A. Bogdanov, L.R. Knudsen, G. Leander, C. Paar, A. Poschmann, M.J.B. Robshaw, Y. Seurin, C. Vikkelsoe). 31-round SPN block cipher for RFID/sensor networks requiring only 1570 GE in hardware.
- **48330001.pdf** — A kilobit special number field sieve factorization (Kazumaro Aoki, Jens Franke, Thorsten Kleinjung, Arjen Lenstra, Dag Arne Osvik). First >1024-bit SNFS factorization, of Mersenne number 2^1039 − 1, informing RSA-1024 feasibility estimates.
- **48330014.pdf** — When e-th Roots Become Easier Than Factoring (Antoine Joux, David Naccache, Emmanuel Thomé). With an oracle for roots of special forms, computing e-th roots mod n beats GNFS factoring; addresses the One-More-RSA problem.
- **48330030.pdf** — Faster addition and doubling on elliptic curves (Daniel J. Bernstein, Tanja Lange). Fast explicit formulas for Edwards curves: doubling in 3M+4S, beating the best Jacobian formulas.
- **48330050.pdf** — A Non-Interactive Shuffle with Pairing Based Verifiability (Jens Groth, Steve Lu). First efficient non-interactive zero-knowledge proof of shuffle correctness for mix-nets, using bilinear groups.
- **48330067.pdf** — On Privacy Models for RFID (Serge Vaudenay). Formal privacy model for RFID identification with separation results (strong privacy impossible) and constructions under various adversary classes.
- **48330087.pdf** — Treading the Impossible: A Tour of Set-Up Assumptions for Obtaining Universally Composable Security (Ran Canetti). Survey comparing CRS, key-registration, sunspot, global set-up, and timing assumptions enabling UC-secure protocols.
- **48330111.pdf** — A Simple Variant of the Merkle-Damgård Scheme with a Permutation (Shoichi Hirose, Je Hong Park, Aaram Yun). MD variant adding a permutation before the final block, analyzed via indifferentiability, with simple secure MAC constructions.
- **48330128.pdf** — Seven-Property-Preserving Iterated Hashing: ROX (Elena Andreeva, Gregory Neven, Bart Preneel, Thomas Shrimpton). Shows 11 iterations preserve at most three of seven hash security notions; ROX preserves all seven using a small random oracle.
- **48330162.pdf** — Fully Anonymous Group Signatures without Random Oracles (Jens Groth). Practical bilinear-group group signatures with constant-size keys/signatures, dynamic enrollment, and standard-model security.
- **48330179.pdf** — Group Encryption (Aggelos Kiayias, Yiannis Tsiounis, Moti Yung). Encryption analogue of group signatures hiding the recipient within a group; includes a Paillier-based CCA2 key-private construction.
- **48330198.pdf** — Identity-Based Broadcast Encryption with Constant Size Ciphertexts and Private Keys (Cécile Delerablée). First IBBE with constant ciphertexts and private keys, improving on Boneh–Gentry–Waters efficiency.
- **48330214.pdf** — Boosting Merkle-Damgård Hashing for Message Authentication (Kan Yasuda). Faster-than-MD single-key MAC mode with PRF-based provable security, beating HMAC especially for wide-pipe compression functions.
- **48330231.pdf** — On Efficient Message Authentication Via Block Cipher Design Techniques (G. Jakimoski, K.P. Subbalakshmi). Analyzes ALRED/Pelican-style MACs, constructing AXU hash functions from non-linear permutations for provably secure fast MACs.
- **48330248.pdf** — Symmetric Key Cryptography on Modern Graphics Hardware (Jason Yang, James Goodman). Conventional and bitsliced AES/DES on AMD HD 2900 XT GPUs achieving 3–30 Gbps, 6–60x faster than CPUs.
- **48330265.pdf** — Blind Identity-Based Encryption and Simulatable Oblivious Transfer (Matthew Green, Susan Hohenberger). Formalizes blind IBE key extraction and builds fully simulatable OT from static assumptions like DBDH.
