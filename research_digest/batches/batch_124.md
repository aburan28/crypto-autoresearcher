# Batch 124 digest

## Overview
- Entire batch is theoretical cryptography, mostly TCC 2016-era conference papers (filenames 9815xxxx/9816xxxx and 9985xxxx); all 50 are genuine research papers with clear abstracts.
- Dominant themes: circular/KDM security separations from LWE, indistinguishability obfuscation (attacks on GGH13, FE-to-iO equivalences, proof-of-human-work from iO), and FHE variants (quantum FHE, multi-key multi-hop FHE, spooky encryption).
- Strong zero-knowledge / proof-systems cluster: IOPs (Ben-Sasson–Chiesa–Spooner, foundational for later STARKs), O-SNARKs, 3-message ZK, SZK vs randomized encodings, proofs of small secrets for (Ring-)LWE.
- Notable MPC/protocol papers: TWORAM (2-round ORAM), 3-round concurrent non-malleable commitments, constant-round MPC from BMR+SHE, fair coin-tossing, adaptive garbled circuits (two independent papers).
- Anomaly: despite the corpus being described as ECC/ECDLP-heavy, this batch contains essentially no elliptic-curve or ECDLP content; only one bilinear-pairing paper (Type-I to Type-III conversion) touches curves at all.

## Papers
- **98150616.pdf** — Annihilation Attacks for Multilinear Maps: Cryptanalysis of iO over GGH13 (Miles, Sahai, Zhandry). Introduces annihilation attacks using non-linear polynomials, giving the first polynomial-time cryptanalysis of candidate iO schemes built on GGH13 multilinear maps.
- **98150646.pdf** — Three's Compromised Too: Circular Insecurity for Any Cycle Length from (Ring-)LWE (Alamati, Peikert). Constructs encryption schemes that are CPA/CCA secure yet k-circular insecure for any k >= 2, based on LWE and ring-LWE rather than obfuscation.
- **98150667.pdf** — Circular Security Separations for Arbitrary Length Cycles from LWE (Koppula, Waters). Builds an IND-CPA-secure LWE-based encryption scheme that is not circular secure for arbitrary-length cycles, removing the iO assumption from prior separations.
- **98160001.pdf** — Quantum Homomorphic Encryption for Polynomial-Sized Circuits (Dulek, Schaffner, Speelman). Compact quantum FHE scheme evaluating polynomial-size quantum circuits, built on any classical leveled FHE using garden-hose-style gadgets for T-gate correction.
- **98160031.pdf** — Adaptive Versus Non-Adaptive Strategies in the Quantum Setting (Dupuis, Fehr, Lamontagne, Salvail). Proves a general relation reducing adaptive quantum attacks to non-adaptive ones given bounded side information; applications include 1-bit cut-and-choose bit commitment.
- **98160059.pdf** — Semantic Security and Indistinguishability in the Quantum World (Gagliardoni, Hülsing, Schaffner). Defines quantum indistinguishability notions for symmetric encryption over superpositions of messages, shows impossibility for length-preserving ciphers, and gives a secure construction.
- **98160089.pdf** — Spooky Encryption and its Applications (Dodis, Halevi, Rothblum, Wichs). Constructs encryption supporting "spooky" non-local relations (additive function sharing) across independently keyed ciphertexts, from LWE, with delegation applications.
- **98160119.pdf** — Spooky Interaction and its Discontents: Compilers for Succinct Two-Message Arguments (Dwork, Naor, Rothblum). Gives succinct two-message arguments for NC from standard polynomial-hardness PIR/FHE, analyzing the Kalai–Raz compiler soundness.
- **98160142.pdf** — Adaptively Secure Garbled Circuits from One-Way Functions (Hemenway, Jafargholi, Ostrovsky, Scafuro, Wichs). Modifies Yao's garbling to achieve adaptive security under one-way functions with online cost proportional to circuit width or depth.
- **98160172.pdf** — Rate-1, Linear Time and Additively Homomorphic UC Commitments (Cascudo, Damgård, David, Döttling, Nielsen). First UC commitment scheme for binary strings with rate approaching 1 and linear-time complexity, additively homomorphic, via new linear-time codes and interactive proximity testing.
- **98160202.pdf** — UC Commitments for Modular Protocol Design and Applications to Revocation and Attribute Tokens (Camenisch, Dubovitskaya, Rial). Defines a UC functionality for non-interactive commitments enabling modular hybrid protocol composition, plus UC attribute-token and revocation building blocks.
- **98160232.pdf** — Probabilistic Termination and Composability of Cryptographic Protocols (Cohen, Coretti, Garay, Zikas). Formalizes MPC with probabilistic termination in the UC framework and proves a composition theorem for expected-constant-round hybrid emulation.
- **98160262.pdf** — Concurrent Non-Malleable Commitments (and More) in 3 Rounds (Ciampi, Ostrovsky, Siniscalchi, Visconti). Transforms any 3-round one-left/one-right non-malleable commitment into a 3-round concurrent non-malleable one, matching the round lower bound, from subexponentially secure one-way permutations.
- **98160292.pdf** — Programmable Hash Functions from Lattices (Zhang, Chen, Zhang). Formalizes lattice-based programmable hash functions and uses them for standard-model short signatures and fully secure IBE with small keys under ISIS.
- **98160322.pdf** — Fully Secure Functional Encryption for Inner Products, from Standard Assumptions (Agrawal, Libert, Stehlé). First adaptively (fully) secure inner-product functional encryption, from hash proof systems under standard assumptions like DDH and LWE.
- **98160352.pdf** — Circuit-ABE from LWE: Unbounded Attributes and Semi-Adaptive Security (Brakerski, Vaikuntanathan). LWE-based key-policy ABE supporting unbounded-length attributes with fixed-size parameters, achieving semi-adaptive security via new proof techniques.
- **98160374.pdf** — Design in Type-I, Run in Type-III: Fast and Scalable Bilinear-Type Conversion using Integer Programming (Abe, Hoshino, Ohkubo). IPConv tool converts pairing schemes from symmetric (Type-I) to asymmetric (Type-III) groups automatically via 0-1 integer programming, scaling to thousand-variable schemes.
- **98160404.pdf** — Linicrypt: A Model for Practical Cryptography (Carmer, Rosulek). Defines a model of linear-plus-random-oracle programs where indistinguishability is decidable in polynomial time, enabling sound and complete SAT/SMT-based synthesis (e.g., garbled circuits).
- **98160434.pdf** — On the Relationship between Statistical Zero-Knowledge and Statistical Randomized Encodings (Applebaum, Raykov). Studies SRE vs SZK; shows one-sided-privacy randomized encodings equivalent to NISZK non-uniformly, among other equivalence/separation results.
- **98160463.pdf** — How to Prove Knowledge of Small Secrets (Baum, Damgård, Larsen, Nielsen). Zero-knowledge protocol proving knowledge of short preimages of additively homomorphic functions, yielding improved proofs of plaintext knowledge for (Ring-)LWE cryptosystems.
- **98160485.pdf** — Efficient Zero-Knowledge Proof of Algebraic and Non-Algebraic Statements (Chase, Ganesh, Mohassel). Combines garbled circuits with sigma protocols for efficient ZK proofs over standard RSA/(EC)DSA signatures, enabling privacy-preserving credentials on standard signatures.
- **98160515.pdf** — Fine-Grained Cryptography (Degwekar, Vaikuntanathan, Vasudevan). Constructs crypto primitives computable in NC1 secure against NC1 adversaries under NC1 != parity-L/poly, plus unconditional AC0 PRGs and related results.
- **98160545.pdf** — TWORAM: Efficient Oblivious RAM in Two Rounds (Garg, Mohassel, Papamanthou). ORAM with exactly two rounds of interaction at security-parameter overhead over tree ORAMs; yields 4-round searchable encryption with worst-case sublinear search.
- **98160574.pdf** — Bounded Indistinguishability and the Complexity of Recovering Secrets (Bogdanov, Ishai, Viola, Williamson). Characterizes functions fooled by k-wise indistinguishable distributions via approximate degree; implies efficient secret sharing with high secrecy threshold.
- **98160604.pdf** — Two-Message, Oblivious Evaluation of Cryptographic Functionalities (Döttling, Fleischhacker, Krupp, Schröder). Round-optimal two-message oblivious evaluation of cryptographic functionalities against malicious receivers via non-black-box use of security reductions; first standard-model 2-round OPRF.
- **99850102.pdf** — Designing Proof of Human-work Puzzles for Cryptocurrency and Beyond (Blocki, Zhou). Defines proofs of human-work (hard for computers, feasible for humans, publicly verifiable) from iO and CAPTCHAs; applies to HumanCoin and password protection.
- **99850107.pdf** — Fast Pseudorandom Functions Based on Expander Graphs (Applebaum, Raykov). PRFs from Goldreich-style local one-way functions on expander graphs, computable in linear time or AC0/TC0, via a new search-to-decision reduction.
- **99850108.pdf** — More Efficient Constant-Round Multi-Party Computation from BMR and SHE (Lindell, Smart, Soria-Vazquez). Low-round dishonest-majority MPC combining BMR garbling with somewhat homomorphic encryption, improving rounds and complexity over SPDZ-BMR and Gentry's FHE protocol.
- **99850109.pdf** — Perfectly Secure Message Transmission in Two Rounds (Spini, Zémor). Two-round PSMT protocol for n = 2t+1 channels reducing communication for a 1-bit secret from O(n^3 log n) to O(n^2 log n), resolving a Kurosawa–Suzuki open question.
- **99850114.pdf** — Simultaneous Secrecy and Reliability Amplification for a General Channel Model (Impagliazzo, Jaiswal, Kabanets, Kapron, King, Tessaro). Studies when secrecy and reliability of a general channel can be simultaneously amplified; one-way protocols exist for advantage gap c > 4, impossibility otherwise.
- **99850119.pdf** — Binary AMD Circuits from Secure Multiparty Computation (Genkin, Ishai, Weiss). First fully secure binary AMD circuits protecting against additive wire-tampering attacks, built by composing honest-majority MPC protocols.
- **99850121.pdf** — Standard Security Does Not Imply Indistinguishability Under Selective Opening (Hofheinz, Rao, Wichs). Constructs a CPA/CCA-secure encryption scheme (via Shamir-shared encrypted shares) that provably fails IND-SOA security, settling the question negatively.
- **99850124.pdf** — Semi-Adaptive Security and Bundling Functionalities Made Generic and Easy (Goyal, Koppula, Waters). Generic garbled-circuit transform lifting any selectively secure ABE/FE scheme to semi-adaptive security, assuming only public-key encryption.
- **99850127.pdf** — Public-Key Encryption with Simulation-Based Selective-Opening Security and Compact Ciphertexts (Hofheinz, Jager, Rupp). First SIM-SO secure PKE in the discrete-log setting with constant-size ciphertext overhead.
- **99850128.pdf** — Proof of Space from Stacked Expanders (Ren, Devadas). Simpler, more efficient proof-of-space constructions from stacked expander graphs with tighter provable space-hardness; also strengthens analysis of Balloon hashing.
- **99850129.pdf** — Threshold Secret Sharing Requires a Linear Size Alphabet (Bogdanov, Guo, Komargodski). Proves t-out-of-n threshold secret sharing of one-bit secrets needs share size log(t+1); combined with Kilian–Nisan, shows Shamir's scheme is essentially optimal.
- **99850131.pdf** — Oblivious Transfer from Any Non-Trivial Elastic Noisy Channel via Secret Key Agreement (Cascudo, Damgård, Lacerda, Ranellucci). Information-theoretic OT from any non-trivial elastic binary symmetric channel, closing the parameter gap left by Khurana et al.; also gives receiver-committing commitments.
- **99850134.pdf** — Leakage Resilient One-Way Functions: The Auxiliary-Input Setting (Komargodski). Possibility and impossibility results for one-way functions resilient to auxiliary-input (computationally hiding) leakage; adaptive arbitrary-OWF leakage shown impossible.
- **99850136.pdf** — How to Share a Secret, Infinitely (Komargodski, Naor, Yogev). Secret sharing for an unknown, potentially infinite set of parties; k-threshold scheme with party-t share size ~(k-1) log t, with tight bounds for k=2 via prefix codes.
- **99850143.pdf** — Strong Hardness of Privacy from Weak Traitor Tracing (Kowalczyk, Malkin, Ullman, Zhandry). Shows, from OWFs plus iO, that differentially private accurate query answering is computationally infeasible when either the query family or data universe is exponential.
- **99850148.pdf** — On the (In)security of SNARKs in the Presence of Oracles (Fiore, Nitulescu). Formalizes O-SNARKs (knowledge extraction when provers access oracles), gives impossibility results for general oracles, and fixes proofs for homomorphic/functional signature applications.
- **99850150.pdf** — Post-Quantum Security of the Fujisaki-Okamoto and OAEP Transforms (Ebrahimi Targhi, Unruh). Proves modified Fujisaki–Okamoto hybrid encryption and OAEP secure in the quantum random oracle model.
- **99850154.pdf** — Towards Non-Black-Box Separations of Public Key Encryption and One Way Function (Dachman-Soled). Rules out non-adaptive BBN- reductions (black-box construction, code-accessing reduction) from PKE to one-way functions, pushing separations beyond black-box.
- **99850155.pdf** — 3-Message Zero Knowledge Against Human Ignorance (Bitansky, Brakerski, Kalai, Paneth, Vaikuntanathan). Three-message zero-knowledge argument with soundness against uniform provers, based on key-less collision-resistant hashing and RAM delegation, formalized via human-ignorance reductions.
- **99850156.pdf** — Interactive Oracle Proofs (Ben-Sasson, Chiesa, Spooner). Introduces IOPs combining IPs and PCPs; gives a compiler from public-coin IOPs to non-interactive proofs in the ROM with soundness characterized by state-restoration attacks.
- **99850157.pdf** — Multi-Key FHE from LWE, Revisited (Peikert, Shiehian). First multi-hop multi-key FHE from LWE: outputs of cross-key computation can feed further computations with new keys natively, without bootstrapping.
- **99850160.pdf** — The GGM Function Family is a Weakly One-Way Family of Functions (Cohen, Klein). First hardness demonstration for the GGM PRF construction when the secret key is exposed: weak one-wayness 1/n^(2+eps), with conditions for strong one-wayness.
- **99850167.pdf** — Almost-Optimally Fair Multiparty Coin-Tossing with Nearly Three-Quarters Malicious (Alon, Omri). Fair multiparty coin-tossing protocols approaching the 1/r optimal bias while tolerating up to nearly 3/4 corrupted parties, extending Haitner–Tsfadia techniques.
- **99850169.pdf** — Adaptive Security of Yao's Garbled Circuits (Jafargholi, Wichs). Proves Yao's original garbled circuit construction itself is adaptively secure with 2^O(d) security loss, via nested hybrids — no modification needed (companion to the Hemenway et al. result).
- **99850171.pdf** — Compactness vs Collusion Resistance in Functional Encryption (Li, Micciancio). Generic combiners boosting bounded-key-query FE to collusion-resistant FE, proving compact, weakly compact, and collusion-resistant FE variants all polynomially equivalent as routes to iO.
