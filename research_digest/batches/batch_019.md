# Batch 019 digest

## Overview
- Almost entirely a theory-of-cryptography proceedings batch: the ID clusters (11891146–11891254, 119210105–119210166) look like TCC 2019-style papers, dominated by MPC, FHE/lattice, and zero-knowledge/PIR topics.
- Lattice/post-quantum crypto is the single largest theme: MP-LWE variants, Ring-LWE reductions, approximate trapdoors, hash-and-sign signatures, QROM KEM reductions, tensor isomorphism group actions, pseudorandom quantum states.
- MPC cluster is deep: preprocessing via FSS, MPC over Z/p^k Z, UC security with stateless tokens, topology-hiding computation, solitary-output full security, PEZ protocols.
- Only one paper is directly elliptic-curve related (119210106, isogeny graphs over RSA moduli / class groups); no ECDLP, side-channel, or pairing-implementation papers — pairings appear only as ABE/SPS/QA-NIZK tools.
- Notable heavyweight papers: Gentry–Halevi compressible FHE/PIR (11891159), Coron–Notarnicola CLT13 cryptanalysis (119210133), Coron–Pereira first CLT13 multipartite key-exchange implementation (119210130).
- Anomalies: `119.pdf` (Jakoby–Liśkiewicz) breaks the numeric ID pattern and is an older-era information-theoretic 2PC paper; no duplicates or non-paper files found.

## Papers
- **11891146.pdf** — A Black-Box Construction of Fully-Simulatable, Round-Optimal Oblivious Transfer from Strongly Uniform Key Agreement (Friolo, Masny, Venturi). Black-box maliciously secure OT from strongly uniform key agreement, realizable from LPN/LWE/DDH/RSA with up to two extra rounds.
- **11891148.pdf** — From FE Combiners to Secure MPC and Back (Ananth, Badrinarayanan, Jain, Manohar, Sahai). Introduces functional encryption combiners (secure if any candidate is secure) and studies their connection to secure multiparty computation.
- **11891149.pdf** — Linear-Size Constant-Query IOPs for Delegating Computation (Ben-Sasson, Chiesa, Goldberg, Gur, Riabzev, Spooner). Efficient interactive oracle proofs for algebraic computations (R1CS) with linear proof size, constant queries, near-linear prover time.
- **11891150.pdf** — Tighter Proofs of CCA Security in the Quantum Random Oracle Model (Bindel, Hamburg, Hövelmanns, Hülsing, Persichetti). Improved one-way-to-hiding lemma yields tighter QROM reductions for U-not-perp KEM transform from OW-CPA PKE.
- **11891151.pdf** — Stronger Lower Bounds for Online ORAM (Hubáček, Koucký, Král, Slívová). Proves Omega(log n) bandwidth lower bound for online ORAM even when the adversary cannot map accesses to input operations.
- **11891153.pdf** — Predicate Encryption from Bilinear Maps and One-Sided Probabilistic Rank (Alman, Hui). Predicate encryption for new function classes (sparse disjointness, Hamming distance, inner product mod 2) via one-sided probabilistic rank representations.
- **11891156.pdf** — CPA-to-CCA Transformation for KDM Security (Kitagawa, Matsuda). Shows KDM-CPA security implies KDM-CCA security for bounded circuits via reusable DV-NIZK, first such under LPN.
- **11891159.pdf** — Compressible FHE with Applications to PIR (Gentry, Halevi). High-rate (near rate-1) additive homomorphic encryption from ring-LWE, yielding the first practically efficient single-server PIR.
- **11891160.pdf** — Fully Homomorphic NIZK and NIWI Proofs (Ananth, Deshpande, Kalai, Lysyanskaya). Defines and constructs NIZK/NIWI proofs composable homomorphically over NP statements, from DLIN and a new bilinear-map assumption.
- **11891161.pdf** — A Unified and Composable Take on Ratcheting (Jost, Maurer, Mularczyk). Extends Constructive Cryptography with global event histories to modularize secure-messaging ratcheting components for reuse.
- **11891162.pdf** — General Linear Group Action on Tensors: A Candidate for Post-Quantum Cryptography (Ji, Qiao, Song, Yun). Proposes tensor isomorphism (GL group action on tensors) as a new post-quantum one-way group action foundation, with algorithmic analysis.
- **11891169.pdf** — Adaptively Secure Garbling Schemes for Parallel Computations (Chung, Qian). First adaptively secure garbling from standard public-key assumptions with near-optimal online complexity preserving parallel/PRAM evaluation.
- **11891173.pdf** — Composable and Finite Computational Security of Quantum Message Transmission (Banfi, Maurer, Portmann, Zhu). Gives finite, composable, operational security definitions for computationally secure quantum message encryption/authentication.
- **11891178.pdf** — On the Complexity of Collision Resistant Hash Functions: New and Old Black-Box Separations (Bitansky, Degwekar). New separation: CRH does not black-box imply SZK hardness; simpler coupling-based reproofs of Simon and Asharov–Segev separations.
- **11891182.pdf** — Synchronous Consensus with Optimal Asynchronous Fallback Guarantees (Blum, Katz, Loss). Byzantine agreement tolerating t_s < n/2 faults synchronously and t_a < n/3 asynchronously, shown feasible iff t_a + 2t_s < n.
- **11891185.pdf** — Channels of Small Log-Ratio Leakage and Characterization of Two-Party Differentially Private Computation (Haitner, Mazor, Shaltiel, Silbak). Characterizes two-party protocols via log-ratio (DP-style) leakage, linking small-leakage protocols to OT and differential privacy.
- **11891187.pdf** — Matrix PRFs: Constructions, Attacks, and Applications to Obfuscation (Chen, Hhan, Vaikuntanathan, Wee). Studies PRFs computable by matrix branching programs: constructions, read-c/w attacks, and immunizing the CVW18 IO candidate against zeroizing attacks.
- **11891188.pdf** — On Perfectly Secure 2PC in the OT-Hybrid Model (Alon, Paskin-Cherniavsky). Identifies a large class of client-server functionalities computable with perfect (not just statistical) security in the OT-hybrid model.
- **11891190.pdf** — On Fully Secure MPC with Solitary Output (Halevi, Ishai, Kushilevitz, Makriyannis, Rabin). Shows some single-output functionalities cannot be fully securely computed without honest majority, extending Cleve's technique; positive results for others.
- **11891199.pdf** — Interactive Non-Malleable Codes (Fleischhacker, Goyal, Jain, Paskin-Cherniavsky, Radune). Extends non-malleable codes to interactive protocols, with constructions for split-state and sliding-window tampering and threshold lower bounds.
- **11891202.pdf** — Efficient Information-Theoretic Secure MPC over Z/p^k Z via Galois Rings (Abspoel, Cramer, Damgård, Escudero, Yuan). Information-theoretic MPC over rings Z/p^k Z with field-comparable efficiency; perfect security below 1/3, statistical below 1/2 corruption.
- **11891209.pdf** — New Approaches to Traitor Tracing with Embedded Identities (Goyal, Koppula, Waters). Traitor tracing where user identities are embedded in keys so tracing recovers full identities, improving on the NWZ framework.
- **11891211.pdf** — Secure Computation with Preprocessing via Function Secret Sharing (Boyle, Gilboa, Ishai). FSS-based preprocessing framework for MPC giving exponential efficiency gains for comparison, equality, and bit-decomposition gates.
- **11891223.pdf** — Efficient Private PEZ Protocols for Symmetric Functions (Abe, Iwamoto, Ohta). Shortens PEZ-dispenser string length from O(2^n!) to O(n·n!) and moves from 2^n to n² for symmetric functions via recursive structure.
- **11891227.pdf** — Leveraging Linear Decryption: Rate-1 Fully-Homomorphic Encryption and Time-Lock Puzzles (Brakerski, Döttling, Garg, Malavolta). First rate-(1−o(1)) FHE from LWE and first fully homomorphic time-lock puzzles from standard assumptions.
- **11891230.pdf** — Attribute Based Encryption for Deterministic Finite Automata from DLIN (Agrawal, Maitra, Yamada). First ABE for DFAs from static pairing assumptions (DLIN), via a compiler embedding DFA computation into monotone span programs.
- **11891236.pdf** — (Pseudo) Random Quantum States with Binary Phase (Brakerski, Shmueli). Proves binary-phase random states are statistically Haar-indistinguishable, giving provable pseudorandom quantum states from post-quantum PRFs and efficient t-designs.
- **11891237.pdf** — Lattice Trapdoors and IBE from Middle-Product LWE (Lombardi, Vaikuntanathan, Vuong). Identity-based encryption from MP-LWE matching Ring-LWE efficiency via lattice trapdoors.
- **11891249.pdf** — Permuted Puzzles and Cryptographic Hardness (Boyle, Holmgren, Weiss). Formalizes and analyzes the permuted-puzzle hardness assumption underlying recent doubly efficient PIR candidates.
- **11891250.pdf** — Algebraically Structured LWE, Revisited (Peikert, Pepin). Unifies Ring/Module/Poly/Order/MP-LWE in one framework with simpler, tighter reductions from Ring-LWE, often with no error distortion.
- **11891254.pdf** — Is Information-Theoretic Topology-Hiding Computation Possible? (Ball, Boyle, Cohen, Malkin, Moran). Studies feasibility of IT topology-hiding MPC with honest majority; e.g., topology-hiding broadcast on a 4-node line implies key agreement.
- **119.pdf** — Revealing Additional Information in Two-Party Computations (Jakoby, Liśkiewicz). Disproves Bar-Yehuda et al.'s characterization of privately computable two-party functions via measure E(f), and proposes an alternative leakage measure. (Anomalous older paper; ID breaks the numeric pattern.)
- **119210105.pdf** — Tightly Secure Inner Product Functional Encryption: Multi-Input and Function-Hiding Constructions (Tomida). First tightly secure IPFE from MDDH, extended to function-hiding and multi-input IPFE with a new generic conversion.
- **119210106.pdf** — Hard Isogeny Problems over RSA Moduli and Groups with Infeasible Inversion (Altuğ, Chen). Studies isogeny-graph neighbor-search hardness over RSA moduli and constructs groups with infeasible inversion from ideal class groups without iO.
- **119210107.pdf** — On the Non-Existence of Short Vectors in Random Module Lattices (Nguyen). Bounds short-vector non-existence in module lattices via NTT representation, enabling NTT-friendly tight QROM security for Dilithium-QROM-type signatures.
- **119210120.pdf** — Shorter QA-NIZK and SPS with Tighter Security (Abe, Jutla, Ohkubo, Pan, Roy, Wang). Constant-size (14 group elements) QA-NIZK with tight simulation soundness and shorter structure-preserving signatures under SXDH.
- **119210121.pdf** — Efficient Explicit Constructions of Multipartite Secret Sharing Schemes (Chen, Tang, Lin). Efficient explicit ideal secret-sharing schemes for hierarchical and compartmented multipartite access structures.
- **119210125.pdf** — Middle-Product Learning with Rounding Problem and Its Applications (Bai, Boudgoust, Das, Roux-Langlois, Wen, Zhang). Deterministic MP-LWR assumption, shown as hard as decisional MP-LWE, yielding sampling-free encryption with quasi-optimal sizes.
- **119210126.pdf** — Divisible E-Cash from Constrained Pseudo-Random Functions (Bourse, Pointcheval, Sanders). Complete security model for divisible e-cash and constructions from constrained PRFs with key-homomorphic or delegatable properties.
- **119210130.pdf** — On Kilian's Randomization of Multilinear Map Encodings (Coron, Pereira). Applying Kilian randomization after CLT13 encoding hardens attacks by orders of magnitude; first attack-resistant implementation of 4-party CLT13 key exchange (18 GB params).
- **119210133.pdf** — Cryptanalysis of CLT13 Multilinear Maps with Independent Slots (Coron, Notarnicola). Higher-dimensional lattice attack breaks the GLW14 countermeasure on CLT13 independent slots, recovering secret parameters for a wide parameter range.
- **119210138.pdf** — Perfectly Secure Oblivious RAM with Sublinear Bandwidth Overhead (Raskin, Simkin). First perfectly secure ORAM ("Lookahead ORAM") with worst-case sublinear O(sqrt(N)) bandwidth overhead and O(N) server storage.
- **119210144.pdf** — Indifferentiability of Truncated Random Permutations (Choi, Lee, Lee). Tight indifferentiability bounds for PRF-from-PRP by output truncation, improving Dodis et al. to n/2-bit security for n-to-n/2-bit functions.
- **119210145.pdf** — UC-Secure Multiparty Computation from One-Way Functions Using Stateless Tokens (Badrinarayanan, Jain, Ostrovsky, Visconti). Three-round UC MPC (two-round for 2PC) from one-way functions in the stateless hardware token model with reusable two-round OT.
- **119210153.pdf** — Collusion Resistant Watermarking Schemes for Cryptographic Functionalities (Yang, Au, Lai, Xu, Yu). Initiates collusion attacks on program watermarking (all existing schemes broken) and constructs collusion-resistant schemes.
- **119210155.pdf** — Multi-Key Homomorphic Encryption from TFHE (Chen, Chillotti, Song). First implemented MKHE scheme, generalizing TFHE gate bootstrapping across ciphertexts under different keys with new hybrid-product algorithms.
- **119210158.pdf** — Approximate Trapdoors for Lattices and Smaller Hash-and-Sign Signatures (Chen, Genise, Mukherjee). Relaxed approximate gadget trapdoors halve public-key/signature sizes of hash-and-sign lattice signatures in the ROM.
- **119210161.pdf** — Collision Resistant Hashing from Sub-exponential Learning Parity with Noise (Yu, Zhang, Weng, Guo, Li). General construction of collision-resistant hashing from LPN under several (sub-exponential) parameter regimes, partially answering a long-standing open problem.
- **119210162.pdf** — Non-Committing Encryption with Quasi-Optimal Ciphertext-Rate Based on the DDH Problem (Yoshida, Kitagawa, Tanaka). NCE with O(log λ) ciphertext rate from DDH in the plain model, best rate among DDH-based constructions.
- **119210166.pdf** — Numerical Method for Comparison on Homomorphically Encrypted Numbers (Cheon, Kim, Kim, Lee, Lee). Iterative polynomial-approximation algorithms for min/max/comparison on word-wise HE ciphertexts with quasi-optimal Theta(α log α) complexity.
