# Batch 048 digest

## Overview
- Batch is a coherent slice of CRYPTO 2023 proceedings (Springer LNCS vol. 14085, filenames 1408502xx–1408504xx): all 50 files are genuine research papers, no anomalies, no duplicates.
- Dominant themes: lattice/post-quantum cryptography (LWE/RLWE/MLWE, FHE ring packing, LaBRADOR, Orbweaver, lattice succinct arguments, ISIS cryptanalysis) and secure multi-party computation (HSS from sparse LPN, weighted MPC, network-agnostic MPC/DKG, round-optimal coin tossing, OT conversions).
- Second cluster: zero-knowledge / succinct arguments (Brakedown, projection codes for RAM programs, universal arguments, impossibility of algebraic NIZK in pairing-free groups, Fiat-Shamir-with-aborts analysis).
- Smaller but notable threads: symmetric cryptanalysis (Rubato key recovery, differential MITM on SKINNY/AES-256, ChaCha PNB attack, SPN t-wise independence) and quantum-era primitives (certified deletion, EPR-pair secure computation, tests of quantumness certifying qubits).
- Notable papers: practical Schnorr threshold signatures "Olaf" (FROST + Pedersen DKG without AGM), HMAC dual-PRF analysis, Falcon/Mitaka small-q security reductions, Anemoi ZK-friendly permutations.

## Papers
- **140850241.pdf** — HERMES: Efficient Ring Packing using MLWE Ciphertexts and Application to Transciphering (Bae, Cheon, Kim, Park, Stehlé). Speeds up LWE-to-RLWE ring packing for FHE via bootstrapping/ring switching and a new MLWE-ciphertext method, 41x faster.
- **140850250.pdf** — Tighter QCCA-Secure Key Encapsulation Mechanism with Explicit Rejection in the QROM (Ge, Shan, Xue). Tightens IND-CCA security reductions for explicit-rejection Fujisaki-Okamoto KEM variants in the quantum random oracle model.
- **140850257.pdf** — Accelerating HE Operations from Key Decomposition Technique (Kim, Lee, Seo, Song). Replaces expensive DFT-based key decomposition in homomorphic encryption with cheap small-bound integer ops, cutting DFT cost from quadratic to linear in ciphertext level.
- **140850262.pdf** — Revisiting the Constant-sum Winternitz One-time Signature with Applications to SPHINCS+ and XMSS (Zhang, Cui, Yu). Shows constant-sum WOTS+ is size-optimal among tree-based one-time signatures and fixes a flaw in an older Asiacrypt 1996 DAG-based OTS claim.
- **140850265.pdf** — Cryptanalysis of Symmetric Primitives over Rings and a Key Recovery Attack on Rubato (Grassi et al.). Extends field-based algebraic attacks to symmetric primitives over composite-modulus rings; full key recovery on Rubato for ≥25% of q choices, below claimed security.
- **140850267.pdf** — How to Use (Plain) Witness Encryption: Registered ABE, Flexible Broadcast, and More (Freitag, Waters, Wu). Builds flexible broadcast encryption and registered ABE from plain witness encryption plus LWE, primitives previously known only from iO.
- **140850272.pdf** — Error Correction and Ciphertext Quantization in Lattice Cryptography (Micciancio, Schultz). Unifies high-rate lattice encryption paradigms in one framework, proves information-theoretic rate bounds, and gives a gadget-encoding cryptosystem matching the best known rate.
- **140850297.pdf** — Multi-Party Homomorphic Secret Sharing and Sublinear MPC from Sparse LPN (Dao, Ishai, Jain, Lin). First multi-party HSS for a non-trivial function class (degree log/log log polynomials) from sparse LPN, yielding MPC with slightly sublinear per-party communication.
- **140850298.pdf** — Constant Input Attribute Based (and Predicate) Encryption from Evasive and Tensor LWE (Agrawal, Rossi, Yadav, Yamada). First multi-input ABE for NC1 with constant arity from evasive LWE, advancing Wee's lattice-assumption program.
- **140850299.pdf** — Reusable Secure Computation in the Plain Model (Goyal, Srinivasan, Wang). Four-round two-party computation whose first three rounds can be reused across unbounded sequential executions, amortizing round complexity without trusted setup.
- **140850301.pdf** — The Power of Undirected Rewindings for Adaptive Security (Hofheinz, Kastner, Klein). Replaces lossy guessing arguments in adaptive-security proofs with sequential undirected rewinding, achieving additive rather than multiplicative reduction loss.
- **140850302.pdf** — Learning With Physical Rounding for Linear and Quadratic Leakage Functions (Hoffmann et al.). Formalizes security of key-homomorphic fresh re-keying against side-channel leakage via the LWPR problem; shows serial implementations are insecure without shuffling-like countermeasures.
- **140850303.pdf** — Lattice-based Succinct Arguments from Vanishing Polynomials (Cini, Lai, Malavolta). New lattice commitment from vanishing polynomials enabling first polylog-verifier recursive folding for linear relations, a lattice VDF, and linear-time-prover preprocessing SNARKs.
- **140850304.pdf** — Revisiting Security Estimation for LWE with Hints from a Geometric Perspective (Dachman-Soled, Gong, Hanson, Kippen). Integrates inequality and combined hints into DBDD instances geometrically, improving lattice-reduction-based side-channel security estimates.
- **140850307.pdf** — Correlated Pseudorandomness from the Hardness of Quasi-Abelian Decoding (Bombar, Couteau, Couvreur, Ducros). Introduces quasi-abelian syndrome decoding (QA-SD) to build programmable PCGs for OLE correlations over arbitrary fields, fixing shortcomings of ring-LPN-based predecessors.
- **140850308.pdf** — A Detailed Analysis of Fiat-Shamir with Aborts (Devevey, Fallahpour, Passelègue, Stehlé). Exposes errors in prior analyses of Fiat-Shamir-with-aborts signatures (e.g. Dilithium-style) and gives corrected QROM analyses for bounded and unbounded rejection loops.
- **140850313.pdf** — List Oblivious Transfer and Applications to Round-Optimal Black-Box Multiparty Coin Tossing (Ciampi, Ostrovsky, Siniscalchi, Waldner). Introduces list OT to realize input-less functionalities (coin tossing, key generation) in four rounds with black-box assumptions.
- **140850314.pdf** — Additive Randomized Encodings and Their Applications (Halevi, Ishai, Kushilevitz, Rabin). Studies what functions are computable when parties locally encode inputs and only sums are revealed; characterizes 2-party AREs and gives general feasibility from bilinear groups.
- **140850316.pdf** — Orbweaver: Succinct Linear Functional Commitments from Lattices (Fisch, Liu, Vesely). First plausibly post-quantum functional commitment with quasilinear prover, O(log n) proofs and near-logarithmic verifier, from k-R-ISIS with structured reference string.
- **140850323.pdf** — Cryptography with Weights: MPC, Encryption and Signatures (Garg et al.). Weighted threshold cryptosystems (ramp secret sharing, MPC, encryption, signatures) where share size and overhead scale additively rather than multiplicatively in party weights.
- **140850324.pdf** — Best of Both Worlds: Revisiting the Spymasters Double Agent Problem (Acharya, Hazay, Poburinnaya, Venkitasubramaniam). Compiler giving any statistically semi-honest MPC additional fall-back security against computationally bounded adversaries corrupting nearly all parties; characterizes malicious fall-back feasibility.
- **140850331.pdf** — Simple Tests of Quantumness Also Certify Qubits (Brakerski, Gheorghiu, Kahanamoku-Meyer, Porat, Vidick). Shows existing test-of-quantumness protocols also certify qubits using only post-quantum trapdoor claw-free functions (no adaptive hardcore bit) or quantum FHE.
- **140850335.pdf** — LaBRADOR: Compact Proofs for R1CS from Module-SIS (Beullens, Seiler). Lattice-based recursively amortized proof system proving 2^20-constraint R1CS in 58 KB at 128-bit security, an order of magnitude smaller than hash-based quantum-safe proofs.
- **140850336.pdf** — Differential Meet-In-The-Middle Cryptanalysis (Boura, David, Derbez, Leander, Naya-Plasencia). New technique combining differential and meet-in-the-middle attacks; breaks 25/56 rounds of SKINNY-128-384 and improves two-related-key attacks on AES-256 to 12 rounds.
- **140850342.pdf** — The Query-Complexity of Preprocessing Attacks (Ghoshal, Tessaro). Lower bounds on preprocessing attacks accounting for both offline advice-generation time and online time; analyzes salting benefits and Merkle-Damgård preimage/collision security.
- **140850348.pdf** — On the Impossibility of Algebraic NIZK in Pairing-Free Groups (Giunta). Proves that black-box use of pairing-free groups cannot yield NIZKs for large language classes without external assumptions, explaining the Groth–Sahai / correlation-intractability dichotomy.
- **140850350.pdf** — Finding short integer solutions when the modulus is small (Ducas, Espitau, Postlethwaite). Cryptanalysis of ISIS with anomalously small q via BKZ-reduced q-ary lattice geometry; cuts small-q Falcon security by ~26 bits and forges a small-q Mitaka signature in 15 s.
- **140850352.pdf** — Limits of Breach-Resistant and Snapshot-Oblivious RAMs (Persiano, Yeo). Proves Ω(log n) overhead lower bounds for ORAMs secure against even slightly stronger snapshot/breach adversaries, showing the Crypto'22 single-breach construction cannot be pushed further.
- **140850355.pdf** — New Design Techniques for Efficient Arithmetization-Oriented Hash Functions: Anemoi Permutations and Jive Compression Mode (Bouvier et al.). Proposes Anemoi, a ZK-friendly permutation family efficient across proof systems, plus the Jive compression mode for Merkle hashing.
- **140850356.pdf** — Non-interactive Universal Arguments (Bitansky, Paneth, Shamir, Solomon). Lifting theorem making all existing non-interactive succinct arguments universal (for nondeterministic computations) from polynomial FHE plus a worst-case complexity assumption.
- **140850365.pdf** — Network-Agnostic Security Comes (Almost) for Free in DKG and MPC (Bacho, Collins, Liu-Zhang, Loss). Characterizes network-agnostic DKG feasibility (tight bound ta+2ts<n) and optimizes network-agnostic MPC communication by a linear factor, in plain PKI.
- **140850369.pdf** — Cryptography with Certified Deletion (Bartusek, Khurana). Compiler adding quantum certified deletion to public-key/ABE/FHE/witness/timed-release encryption, plus everlasting security transfer for dishonest-majority secure computation.
- **140850372.pdf** — Succinct Arguments for RAM Programs via Projection Codes (Ishai, Ostrovsky, Shah). Introduces projection codes to build black-box succinct arguments for RAM programs over large committed databases with near-optimal prover/verifier cost.
- **140850373.pdf** — Practical Schnorr Threshold Signatures Without the Algebraic Group Model (Chu, Gerhart, Ruffing, Schröder). Olaf: FROST3 combined with Pedersen-style DKG, proving Schnorr threshold signatures unforgeable without AGM or idealized key generation.
- **140850374.pdf** — Secure Computation with Shared EPR Pairs (Bartusek, Khurana, Srinivasan). One-shot string OT and secure quantum teleportation from sub-exponential LWE in the shared-EPR-pairs model, yielding NIZK for QMA and non-interactive unidirectional secure computation.
- **140850376.pdf** — On Active Attack Detection in Messaging with Immediate Decryption (Barooti, Collins, Colombo, Huguenin-Dumittan, Vaudenay). Formalizes in-band and out-of-band active attack detection for Signal-style messaging with immediate decryption, with a compiler achieving both notions.
- **140850378.pdf** — Brakedown: Linear-time and field-agnostic SNARKs for R1CS (Golovnev, Lee, Setty, Thaler, Wahby). First implemented SNARK with linear-time prover for R1CS, no trusted setup, plausibly post-quantum, working over arbitrary sufficiently large fields.
- **140850379.pdf** — One-Message Secure Reductions: On the Cost of Converting Correlations (Ishai, Kelkar, Narayanan, Zafar). Systematic study of converting one correlated-randomness resource into another with a single unidirectional message, greatly expanding feasible correlation conversions.
- **140850380.pdf** — Anamorphic Signatures: Secrecy From a Dictator Who Only Permits Authentication! (Kutyłowski, Persiano, Phan, Yung, Zawada). Shows hidden "anamorphic" messages can be embedded in signatures even when a dictator permits only authentication, no encryption.
- **140850386.pdf** — Lattice-Based Succinct Arguments for NP with Polylogarithmic-Time Verification (Bootle, Chiesa, Sotiraki). First homomorphic-commitment-based interactive argument for NP with polylog(N) verification from Ring-SIS, departing from the Merkle-tree paradigm.
- **140850388.pdf** — A Framework for Statistically Sender Private OT with Optimal Rate (Branco, Döttling, Srinivasan). Statistical-sender-private two-message OT with rate-1 amortized communication from DDH and LPN, via a new "statistical co-PIR" primitive, avoiding rate-1 FHE.
- **140850390.pdf** — The Pseudorandom Oracle Model and Ideal Obfuscation (Jain, Lin, Luo, Wichs). Introduces the pseudorandom oracle model for non-black-box use of hash functions, and constructs ideal obfuscation in it from functional encryption — impossible in the plain ROM.
- **140850393.pdf** — When Messages are Keys: Is HMAC a dual-PRF? (Backendal, Bellare, Günther, Scarlata). First in-depth analysis of HMAC as a dual-PRF (as assumed by TLS 1.3, MLS, Noise); fully characterizes swap-PRF security via a "feasibility" condition and proves arbitrary-key-length PRF security.
- **140850396.pdf** — Computational Wiretap Coding from Indistinguishability Obfuscation (Ishai, Jain, Lou, Sahai, Zhandry). Shows wiretap coding is feasible for all binary-input discrete memoryless channel pairs where the main channel is not a degradation of Eve's, under standard iO-implying assumptions.
- **140850397.pdf** — Expand-Convolute Codes for Pseudorandom Correlation Generators from LPN (Raghuraman, Rindal, Tanguy). Shows expand-accumulate and silver codes for LPN-based PCGs have smaller minimum distance than believed (concrete attacks on silver), and proposes a new LPN-friendly code.
- **140850399.pdf** — Cuckoo Hashing in Cryptography: Optimal Parameters, Robustness and Applications (Yeo). Cuckoo hashing with quadratically smaller query overhead for a given failure probability, matching lower bounds, plus robust cuckoo hashing against adversaries who know the hash functions.
- **140850403.pdf** — Almost Tight Multi-User Security under Adaptive Corruptions from LWE in the Standard Model (Han, Liu, Wang, Gu). First LWE-based signature and PKE schemes with almost tight multi-user security under adaptive corruptions in the standard model, via probabilistic quasi-adaptive hash proof systems.
- **140850410.pdf** — Moving a Step of ChaCha in Syncopated Rhythm (Wang, Liu, Hou, Lin). Differential cryptanalysis of ChaCha using a "syncopation" technique amplifying PNB-based backward correlations; breaks 7.5 rounds (without last XOR/rotation) and speeds up 6–7 round attacks.
- **140850411.pdf** — Malicious Secure, Structure-Aware Private Set Intersection (Garimella, Rosulek, Singh). First malicious-secure structure-aware PSI via derandomizable function secret sharing with cut-and-choose, plus asymptotic improvements to semi-honest sa-PSI.
- **140850418.pdf** — Layout Graphs, Random Walks and the t-wise Independence of SPN Block Ciphers (Liu, Pelecanos, Tessaro, Vaikuntanathan). Bounds rounds needed for SPNs with random secret S-boxes to be t-wise independent via random walks on layout graphs; concrete bounds for AES-like parameters.
