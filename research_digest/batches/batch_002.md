# Batch 002 digest

## Overview
- This batch is a coherent slice of mainstream provable-security cryptography from roughly 2016 (Eurocrypt/Crypto/Asiacrypt-era): PKE/IBE/ABE, signatures, garbled circuits, MPC, NIZKs, and tight reductions dominate.
- Strong symmetric-crypto presence: Keccak cryptanalysis, CAESAR authenticated-encryption attacks (ELmD, SCREAM), the MiMC and Sparx cipher designs, Simpira permutations, and tweakable blockciphers.
- Notable side-channel/fault cluster: key-rank estimation, statistical fault attacks on AE modes, masked/shuffled implementation attacks, leakage-resilient PRFs, and low-latency SCA-protected ciphers (PRINCE/Midori).
- Post-quantum/lattice cluster: LPN solving, MQDSS signatures, tightly-secure lattice signatures/IBE, dynamic group signatures, FHE bootstrapping (sub-0.1s), and ideal-lattice hardness in all rings.
- Almost no elliptic-curve/ECDLP content; closest is the tower number field sieve paper (discrete log in F_p^n, relevant to pairing key sizes) — anomalous relative to the corpus's stated ECC focus.
- One anomaly: 10031269.pdf's extracted text is garbled font-glyph encoding (undecodable); no duplicates observed in this batch.

## Papers
- **10031136.pdf** — Efficient KDM-CCA Secure Public-Key Encryption for Polynomial Functions (Han, Liu, Lyu). Fixes a broken LLJ EuroCrypt'15 proof; builds first efficient KDM-CCA PKE for affine and bounded-degree polynomial functions via new AIAE primitive from DDH.
- **10031143.pdf** — Linear Structures: Applications to Cryptanalysis of Round-Reduced Keccak (Guo, Liu, Song). Formalizes "linear structures" to linearize Keccak's permutation for up to 3 rounds, extending zero-sum distinguishers and giving preimage attacks up to 4 rounds.
- **10031150.pdf** — Simpira: A Family of Efficient Permutations Using the AES Round Function (title garbled in extract) (Gueron, Mouha). Family of permutations on 128b-bit inputs built solely from AES rounds, achieving near-optimal throughput (under 1 cycle/byte on Skylake) with claimed 2^128 structural security.
- **10031152.pdf** — Balloon Hashing: A Memory-Hard Function Providing Provable Protection Against Sequential Attacks (Boneh, Corrigan-Gibbs, Schechter). First practical password-hashing function with proven memory-hardness in the ROM; techniques also prove security of scrypt and Argon2i.
- **10031153.pdf** — When are Fuzzy Extractors Possible? (Fuller, Reyzin, Smith). Defines fuzzy min-entropy as the measure of ideal fuzzy-extractor security and shows it is sufficient for information-theoretically secure fuzzy extraction from noisy sources.
- **10031160.pdf** — Dual System Encryption Framework in Prime-Order Groups via Computational Pair Encodings (Attrapadung). Generic compiler from pair encodings to fully secure ABE in prime-order bilinear groups under the Matrix Diffie-Hellman assumption, extending dual-system frameworks to computational encodings.
- **10031163.pdf** — Salvaging Weak Security Bounds for Blockcipher-Based Constructions (Shrimpton, Terashima). Introduces the ideal-cipher model under key-oblivious access (ICM-KOA), giving sharp bounds for multi-key blockcipher constructions that are robust to cryptanalysis of the underlying cipher.
- **10031164.pdf** — Efficient IBE with Tight Reduction to Standard Assumption in the Multi-challenge Setting (Gong, Dong, Chen, Cao). Constructs multi-challenge almost-tightly secure IBE achieving high performance without stronger/non-standard assumptions, resolving an efficiency-vs-assumption dilemma.
- **10031165.pdf** — A New Algorithm for the Unbalanced Meet-in-the-Middle Problem (Nikolić, Sasaki). Combines unbalanced interleaving with van Oorschot–Wiener parallel collision search to reduce memory of unbalanced collision search, giving tradeoff T²M = R²N.
- **10031172.pdf** — A General Polynomial Selection Method and New Asymptotic Complexities for the Tower Number Field Sieve Algorithm (Sarkar, Singh). New polynomial selection (Algorithm-C) improves TNFS complexity for discrete log in F_p^n when n is a composite prime power, with implications for pairing-based key sizes.
- **10031173.pdf** — The Kernel Matrix Diffie-Hellman Assumption (Morillo, Ràfols, Villar). Proposes a computational analogue of the MDDH assumption — finding kernel vectors "in the exponent" — with a strict hardness hierarchy, useful for structure-preserving cryptography.
- **10031178.pdf** — Applying MILP Method to Searching Integral Distinguishers Based on Division Property for 6 Lightweight Block Ciphers (Xiang, Zhang, Bao, Lin). Models division-property propagation as linear inequalities, enabling MILP-based integral-distinguisher search on block ciphers larger than 32 bits.
- **10031179.pdf** — Towards Tightly Secure Lattice Short Signature and Id-Based Encryption (Boyen, Li). Gives tightly secure short lattice signatures from SIS plus a PRF, extended to compact IBE with constant security loss from LWE, eliminating query-count dependence in reductions.
- **10031180.pdf** — More Powerful and Reliable Second-level Statistical Randomness Tests for NIST SP 800-22 (Zhu, Ma, Lin, Zhuang, Jing). Shows binomial-based second-level tests in NIST SP 800-22 are flawed and proposes a Q-value metric with correctness proofs and improved detectability.
- **10031185.pdf** — Nonlinear Invariant Attack: Practical Attack on Full SCREAM, iSCREAM, and Midori64 (Todo, Leander, Sasaki). New weak-key attack class distinguishing full SCREAM/iSCREAM/Midori64 with a handful of pairs, extendable to practical ciphertext-only plaintext recovery in CBC/CTR modes.
- **10031189.pdf** — Statistical Fault Attacks on Nonce-Based Authenticated Encryption Schemes (Dobraunig, Eichlseder, Korak, Lomné, Mendel). First practical fault attacks on nonce-based AE modes (GCM, CCM, EAX, OCB, CAESAR candidates) using biased faults on faulty ciphertexts only.
- **10031190.pdf** — Towards Practical Whitebox Cryptography: Optimizing Efficiency and Space Hardness (Bogdanov, Isobe, Tischhauser). Improves the SPACE whitebox cipher design, reducing its prohibitive performance overhead while retaining blackbox-reduced key-extraction and decomposition security.
- **10031191.pdf** — How to Circumvent the Two-Ciphertext Lower Bound for Linear Garbling Schemes (Kempka, Kikuchi, Suzuki). Efficient garbling scheme using under two k-bit elements per AND gate by slightly deviating from the linear garbling model, with applications to semi-private function evaluation.
- **10031200.pdf** — Optimization of LPN Solving Algorithms (Bogos, Vaudenay). Automates generation of optimal LPN-solving algorithms as optimal paths in a graph of algorithmic steps, improving covering-code results from Asiacrypt'14/Eurocrypt'16.
- **10031201.pdf** — From 5-pass MQ-based Identification to MQ-based Signatures (Chen, Hülsing, Rijneveld, Samardjiska, Schwabe). Presents MQDSS, the first signature scheme with a security reduction to the MQ problem, via a new Fiat–Shamir reduction for 5-pass identification; 128-bit post-quantum parameters with timing-protected implementation.
- **10031203.pdf** — Characterisation and Estimation of the Key Rank Distribution in the Context of Side Channel Evaluations (Martin, Mather, Oswald, Stam). Experimentally characterizes the key-rank distribution after side-channel attacks, showing it is distinguisher- and SNR-independent, enabling meaningful risk metrics for evaluations.
- **10031212.pdf** — Constant-Round Asynchronous Multi-Party Computation Based on One-Way Functions (Coretti, Garay, Hirt, Zikas). First constant-round asynchronous MPC protocol from standard assumptions, closing the round-complexity gap with synchronous MPC.
- **10031214.pdf** — Multi-Key Homomorphic Authenticators (Fiore, Mitrokotsa, Nizzardo, Pagnin). Defines and constructs homomorphic authenticators supporting verifiable computation over data authenticated under multiple users' secret keys.
- **10031217.pdf** — Reverse Cycle Walking and Its Applications (Miracle, Yilek). Alternative to cycle walking for small-domain ciphers (format-preserving encryption) that cuts worst-case cipher invocations from O(N) to O(log N) and yields full-domain security.
- **10031229.pdf** — Side-Channel Analysis Protection and Low-Latency in Action – case study of PRINCE and Midori (Moradi, Schneider). Studies challenges of applying masking to fully-unrolled single-cycle low-latency ciphers, with design architectures and practical PRINCE/Midori evaluations.
- **10031233.pdf** — Design Strategies for ARX with Provable Bounds: Sparx and LAX (Dinu, Perrin, Udovenko, Velichkov, Großschädl, Biryukov). Proposes the "long trail strategy" giving ARX ciphers provable single-trail differential/linear bounds for the first time, instantiated as the Sparx cipher family.
- **10031237.pdf** — Unknown-Input Attacks in the Parallel Setting: Improving the Security of the CHES 2012 Leakage-Resilient PRF (Medwed, Standaert, Nikov, Feldhofer). Leakage-resilient PRF exploiting unknown-inputs as key-dependent algorithmic noise in parallel cipher implementations, making side-channel key recovery intractable under mild assumptions.
- **10031238.pdf** — MiMC: Efficient Encryption and Cryptographic Hashing with Minimal Multiplicative Complexity (Albrecht, Grassi, Rechberger, Roy, Tiessen). Block cipher and hash using the x³ round function over GF(p), minimizing multiplicative complexity for MPC/FHE/ZK applications.
- **10031239.pdf** — Reactive Garbling: Foundation, Instantiation, Application (Nielsen, Ranellucci). Generalizes garbling schemes to reactive settings where garbled functions can be linked, partially evaluated, and extended, with new confidentiality security notions.
- **10031242.pdf** — Cliptography: Clipping the Power of Kleptographic Attacks (Russell, Tang, Yung, Zhou). Initiates cryptography in the complete subversion model where all primitives including key generation may be kleptographically subverted, and constructs immunized one-way and trapdoor permutations.
- **10031245.pdf** — Collapse-binding Quantum Commitments without Random Oracles (Unruh). First standard-model construction of collapse-binding commitments (computational binding against quantum adversaries), and shows they imply other quantum commitment security notions.
- **10031246.pdf** — How to Build Fully Secure Tweakable Blockciphers from Classical Blockciphers (Wang, Guo, Zhang, Zhao, Gu). Breaks Mennink's FSE'15 2^n-secure tweakable blockcipher with a 2^(n/2) key-recovery attack, then studies constructions Ẽ[s] built from s blockcipher calls.
- **10031248.pdf** — Taylor Expansion of Maximum Likelihood Attacks for Masked and Shuffled Implementations (Bruneau, Guilley, Heuser, Rioul, Standaert, Teglia). Expands template-attack maximum-likelihood distinguishers by SNR powers into efficient multivariate attacks, yielding a stronger attack on shuffled table recomputation.
- **10031251.pdf** — Universal Forgery and Key Recovery Attacks on ELmD Authenticated Encryption Algorithm (Bay, Ersoy, Karakoç). Breaks CAESAR second-round candidate ELmD with universal forgery attacks and key recovery reducing effective key strength by over 60 bits.
- **10031253.pdf** — Déjà Q All Over Again: Tighter and Broader Reductions of q-Type Assumptions (Chase, Maller, Meiklejohn). Extends the Déjà Q framework so broadcast/ABE/HIBE schemes can rely on static subgroup hiding instead of dynamic q-type assumptions, with log(q)-tight reductions in symmetric and asymmetric composite-order groups.
- **10031255.pdf** — Indistinguishable Proofs of Work or Knowledge (Baldimtsi, Kiayias, Zacharias, Zhang). Introduces PoWorKs, where a prover indistinguishably proves either work performed or witness knowledge, transforming 3-move HVZK protocols, with anti-spam and other applications.
- **10031257.pdf** — Efficient Public-Key Cryptography with Bounded Leakage and Tamper Resilience (Faonio, Venturi). First standard-model signature scheme and first pairing-free PKE secure under bounded leakage and bounded tampering memory attacks, from generic building blocks.
- **10031259.pdf** — Partitioning via Non-Linear Polynomial Functions: More Compact IBEs from Ideal Lattices and Bilinear Maps (Katsumata, Yamada). Adaptively secure IBE with shorter public parameters: an RLWE scheme with weakened assumptions and best space efficiency, plus a bilinear-map scheme.
- **10031269.pdf** — Unreadable: extracted text is garbled font-glyph encoding ("/C0/D3…" codes); title, authors, and content cannot be determined from the extract. Anomaly.
- **10031270.pdf** — NIZKs with an Untrusted CRS: Security in the Face of Parameter Subversion (Bellare, Fuchsbauer, Scafuro). Defines subversion soundness/WI/ZK for NIZKs under maliciously chosen CRS and gives both impossibility results and protocols achieving various goal combinations.
- **10031271.pdf** — Faster Fully Homomorphic Encryption: Bootstrapping in less than 0.1 Seconds (Chillotti, Gama, Georgieva, Izabachène). Replaces GSW internal product with an external GSW×LWE product, speeding FHEW-style bootstrapping to under 0.1s and shrinking keys from 1GB to 24MB.
- **10031272.pdf** — Signature Schemes with Efficient Protocols and Dynamic Group Signatures from Lattice Assumptions (Libert, Ling, Mouhartem, Nguyen, Wang). Signature-with-efficient-protocols enabling the first lattice-based group signature with dynamically growing user populations.
- **10031277.pdf** — Digital Signatures Based on the Hardness of Ideal Lattice Problems in all Rings (Lyubashevsky). Seeks average-case problems allowing efficient signatures whose hardness relates to ideal SVP for every choice of defining polynomial f, removing ring-selection concerns.
- **10031279.pdf** — Selective Opening Security from Simulatable Data Encapsulation (Heuer, Poettering). Proves that KEM/DEM-style PKE with blockcipher-based DEMs (CTR, CBC, CCM) achieves selective-opening security in the ideal cipher model, covering schemes used in practice.
- **10031280.pdf** — Multi-Input Functional Encryption with Unbounded-Message Security (Goyal, Jain, O'Neill). Removes bounded-message and selective-security restrictions of prior MIFE using sub-exponentially secure indistinguishability obfuscation instead of implausible differing-inputs obfuscation.
- **10031283.pdf** — Zero-Knowledge Accumulators and Set Algebra (Ghosh, Ohrimenko, Papadopoulos, Tamassia, Triandopoulos). Introduces cryptographic accumulators with hiding guarantees so accumulation values and proofs leak nothing about dynamic sets, formalized in the real-ideal paradigm.
- **10031286.pdf** — From Identification to Signatures, Tightly: A Framework and Generic Transforms (Bellare, Poettering, Stebila). Unified framework for identification-to-signature transforms, yielding Fiat–Shamir alternatives with tight reductions and shorter signatures from trapdoor identification.
- **10031288.pdf** — Zero-Knowledge Arguments for Matrix-Vector Relations and Lattice-Based Group Encryption (Libert, Ling, Mouhartem, Nguyen, Wang). First group encryption scheme under LWE/SIS lattice assumptions, built on new ZK arguments for quadratic statements about LWE relations.
- **10031291.pdf** — Universal Composition with Responsive Environments (Camenisch, Enderlein, Krenn, Küsters, Rausch). Identifies and fixes the "non-responsiveness problem" in UC models for modeling-related message exchanges between environment, adversary, and functionalities.
- **10031300.pdf** — Selective-Opening Security in the Presence of Randomness Failures (Hoang, Katz, O'Neill, Zaheri). Initiates SOA-secure PKE under low-quality randomness, with efficient nonce-based constructions from lossy TDFs and hedged extensions requiring only joint entropy.
