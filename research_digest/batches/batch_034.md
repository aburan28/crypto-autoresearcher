# Batch 034 digest

## Overview
- Dominated by ~2021-era IACR ePrint-style papers (filenames suggest TCC/ASIACRYPT 2021 submissions): broad theory crypto rather than the corpus's ECDLP core.
- Heavy representation of zero-knowledge/SNARK foundations (Lunar, inner pairing products, compressed Σ-protocols, Gentry-Wichs tightness, Sub-ZK) and MPC/secret-sharing (non-interactive MPC via blockchains, PSM, HSS, regenerating codes, garbling).
- Strong lattice/post-quantum cluster: NTRU fatigue analysis, dual LWE attacks on CRYSTALS, quantum sieving, QR-UOV, LWR-based hybrid encryption, QROM KEM reduction tightness.
- Symmetric cryptanalysis cluster: division property, integral distinguishers, Trivium cube attack, Rasta/Dasta algebraic attacks, AES-like rebound attacks, DBL hash modes, SCM AE mode.
- Most ECC-relevant items: OMDL in the generic group model (blind Schnorr/MuSig2), threshold ECDSA via class groups, and a unified treatment of elliptic-curve special-point side-channel attacks.
- Anomaly: 130420251.pdf (1p) is garbage — a fragment of math symbols with no readable paper content.

## Papers
- **130420245.pdf** — Towards Tight Adaptive Security of Non-Interactive Key Exchange (Hesse, Hofheinz, Kohl, Langrehr). Explores tradeoffs between NIKE key size and reduction loss, giving a simple adaptively secure NIKE with tunable tightness.
- **130420246.pdf** — Polynomial-time targeted attacks on coin-tossing for any number of corruptions (Etesami, Gao, Mahloujifar, Mahmoody). Gives polynomial-time k-replacing attacks showing the O(k/√n) bias bound for majority coin-tossing is tight.
- **130420247.pdf** — On expected polynomial runtime in cryptography (Michael Klooß). Revisits runtime definitions, arguing PPT/EPT are not closed under indistinguishability, and proposes computationally expected polynomial time (CEPT).
- **130420249.pdf** — Relationships between quantum IND-CPA notions (Carstens, Ebrahimi, Tabia, Unruh). Systematizes variants of IND-CPA for symmetric encryption in the quantum setting, proving equivalences, implications, and separations.
- **130420250.pdf** — Blockchains Enable Non-Interactive MPC (Goyal, Masserova, Parno, Song). Uses blockchains so MPC parties need not be simultaneously online, plus results on communication/state complexity and guaranteed output delivery.
- **130420251.pdf** — Not a research paper: one-page fragment of garbled math symbols; no title, authors, or content extractable.
- **130420255.pdf** — Covert Learning: How to Learn with an Untrusted Intermediary (Canetti, Karchmer). Formalizes covert (verifiable) learning models and gives LPN-based algorithms for parities and decision trees resilient to eavesdropping/tampering intermediaries.
- **130420256.pdf** — Multi-party PSM, Revisited: Improved Communication and Unbalanced Communication (Assouline, Liu). Improves k-party Private Simultaneous Messages communication bounds and constructs unbalanced 2-party PSM protocols.
- **130420257.pdf** — Unclonable Encryption, Revisited (Ananth, Kaleoglu). Builds semantically secure reusable unclonable encryption from minimal assumptions and improves the cloning success-probability analysis of Broadbent–Lord.
- **130900013.pdf** — Convexity of division property transitions: theory, algorithms and compact models (Aleksei Udovenko). Exploits convexity of bit-based division property to compactly model large S-boxes (e.g., 16-bit Super-Sboxes) in CNF/MILP for integral cryptanalysis.
- **130900014.pdf** — PrORAM: Fast O(log n) Authenticated Shares ZK ORAM (Heath, Kolesnikov). Zero-knowledge ORAM using 2 log n OTs per access, ≈10× faster than BubbleRAM for large arrays.
- **130900015.pdf** — On the non-tightness of measurement-based reductions for KEM in the quantum random oracle model (Jiang, Zhang, Ma). Shows inherent security loss in measurement-based QROM reductions for FO-transform KEMs used in NIST PQC submissions.
- **130900023.pdf** — Lunar: a Toolbox for More Efficient Universal and Updatable zkSNARKs and Commit-and-Prove Extensions (Campanelli, Faonio, Fiore, Querol, Rodríguez). Introduces Polynomial Holographic IOPs and compilers yielding universal updatable zkSNARKs with strong proof-size/proving-time tradeoffs.
- **130900029.pdf** — Partial Key Exposure Attack on Short Secret Exponent CRT-RSA (May, Nowakowski, Sarkar). Coppersmith-type attack: known LSB fractions of short CRT exponents dp, dq (≥ N^0.122) suffice to factor N.
- **130900030.pdf** — Gladius: LWR based efficient hybrid public key encryption with distributed decryption (Cong, Cozzo, Maram, Smart). New KEM-DEM variant with an LWR-based (Saber-like) KEM designed for fast distributed CCA-secure decryption.
- **130900031.pdf** — Luby-Rackoff Backwards with More Users and More Security (Bhattacharya, Nandi). Proves multi-user PRF security of XORP[3] and an efficient variant, with applications to counter-mode-like constructions.
- **130900035.pdf** — Homomorphic Secret Sharing for Multipartite and General Adversary Structures (Eriguchi, Nuida). HSS for parallel low-degree polynomial evaluation over non-threshold adversary structures with smaller shares and communication.
- **130900038.pdf** — A Practical Key-Recovery Attack on 805-Round Trivium (Ye, Tian). New cube-construction algorithm yielding 1000+ linear superpolies and a practical 2^41.40 key-recovery attack, 21 rounds beyond prior best.
- **130900042.pdf** — tardigrade: An Atomic Broadcast Protocol for Arbitrary Network Conditions (Blum, Katz, Loss). Atomic broadcast tolerating ts corruptions if synchronous and ta if asynchronous with 2ts+ta<n, with optimal tradeoffs.
- **130900044.pdf** — Lattice-Based Group Encryption with Full Dynamicity and Message Filtering Policy (Pan, Chen, Zhang, Susilo). Simpler lattice-based group encryption achieving full dynamicity and message filtering, improving on prior code-based designs.
- **130900048.pdf** — Adaptive Security via Deletion in Attribute-Based Encryption (Goyal, Liu, Waters). Framework of ABE with deletable attributes yielding adaptively secure subset-functionality ABE from the search BDH assumption.
- **130900050.pdf** — Gentry-Wichs Is Tight: A Falsifiable Non-Adaptively Sound SNARG (Lipmaa, Pavlyk). Constructs a non-adaptively sound SNARG for NP from falsifiable assumptions, showing the Gentry–Wichs impossibility is tight.
- **130900051.pdf** — Strong and Tight Security Guarantees against Integral Distinguishers (Hebborn, Lambin, Leander, Todo). Under independent round keys, proves key-dependence of ciphertext sums over any plaintext subset, ruling out integral distinguishers.
- **130900054.pdf** — Proofs for Inner Pairing Products and Applications (Bünz, Maller, Mishra, Tyagi, Vesely). Generalized inner-product argument for pairing languages yielding succinct polynomial commitments and fast aggregation of ~130k Groth16 proofs.
- **130900055.pdf** — Algebraic Attacks on Rasta and Dasta Using Low-Degree Equations (Liu, Sarkar, Meier, Isobe). Exploits a neglected property of the χ operation to break 2 of 3 full Agrasta instances and reduce Rasta/Dasta security margins to ~1 round.
- **130900066.pdf** — Improved Single-Round Secure Multiplication Using Regenerating Codes (Abspoel, Cramer, Escudero, Damgård, Xing). First MPC application of regenerating codes: depth-d circuits in d+O(1) rounds with o(n²) communication per multiplication.
- **130900068.pdf** — A New Variant of Unbalanced Oil and Vinegar Using Quotient Ring: QR-UOV (Furue, Ikematsu, Kiyomura, Takagi). UOV variant with quotient-ring block-matrix public keys, achieving ~85.8 KB keys at NIST level 3, much smaller than Rainbow.
- **130900071.pdf** — Double-Block-Length Hash Function for Minimum Memory Size (Naito, Sasaki, Sugawara). DBL hash modes EXEX-NI/EXEX-I needing only n+k bits of state, indifferentiable to ~n−log n bits.
- **130900073.pdf** — Bit Security as Computational Cost for Winning Games with High Probability (Watanabe, Yasunaga). New bit-security framework via inner/outer adversaries; decision-game bit security characterized by Rényi divergence of order 1/2.
- **130900087.pdf** — Compressed Σ-Protocols for Bilinear Group Arithmetic Circuits and Application to Logarithmic Transparent Threshold Signatures (Attema, Cramer, Rambaud). Compresses Σ-protocols directly over bilinear-group circuits, yielding transparent threshold signatures with logarithmic proofs.
- **130900090.pdf** — Secure and Efficient Software Masking on Superscalar Pipelined Processors (Gigerl, Primas, Mangard). Analyzes masking on a 9-stage RISC-V SweRV core, showing gaps between simple probing-model security and real architectural side-channel leakage.
- **130900093.pdf** — Promise Σ-protocol: How to Construct Efficient Threshold ECDSA from Encryptions Based on Class Groups (Deng, Ma, Zhang, Wang, Song, Xie). Introduces promise Σ-protocols with weaker "promise extractability" to build efficient class-group threshold ECDSA without low-order assumptions.
- **130900095.pdf** — A formula for disaster: a unified approach to elliptic curve special-point-based attacks (Sedlacek, Chi-Domínguez, Jancar, Brumley). Unifies RPA/ZVP/exceptional-procedure attacks on ECC, extends to windowed scalar multiplication, and catalogs exceptional points in EFD formulas.
- **130900096.pdf** — The One-More Discrete Logarithm Assumption in the Generic Group Model (Bauer, Fuchsbauer, Plouviez). Gives the first rigorous GGM proof of OMDL (fixing a flawed prior proof) and of one-more CDH, underpinning blind Schnorr/MuSig2.
- **130900100.pdf** — Onion Routing with Replies (Kuhn, Hofheinz, Rupp, Strufe). First UC framework and constructions for onion routing with manipulation-protected replies, via updatable encryption or SNARGs.
- **130900101.pdf** — Garbling, Stacked and Staggered: Faster k-out-of-n Garbled Function Evaluation (Heath, Kolesnikov, Peceny). Stack-and-stagger technique amortizes garbling over k-of-n branches, ≈7.7× faster than stacked garbling on LAN benchmarks.
- **130900104.pdf** — NTRU Fatigue: How Stretched is Overstretched? (Ducas, van Woerden). Refined analysis locating NTRU's overstretched regime at q ≈ 0.004·n^2.484 with concrete hardness predictions backed by experiments.
- **130900105.pdf** — Public Key Encryption with Flexible Pattern Matching (Bouscatié, Castagnos, Sanders). Searchable public-key encryption supporting variable-size pattern matching over arbitrarily long encrypted streams, improving bilinear-group-based prior work.
- **130900109.pdf** — Toward a Fully Secure Authenticated Encryption Scheme From a Pseudorandom Permutation (Choi, B. Lee, J. Lee, Y. Lee). SCM mode: rate-1/2 block-cipher AE with n-bit security, graceful nonce-misuse degradation, GCM-SIV-comparable speed.
- **130900110.pdf** — Automatic Classical and Quantum Rebound Attacks on AES-like Hashing by Exploiting Related-key Differentials (Dong, Zhang, Sun, Wei, Wang, Hu). Automates classical and quantum rebound collision attacks on AES-like PGV hash constructions.
- **130900114.pdf** — Faster Dual Lattice Attacks for Solving LWE with applications to CRYSTALS (Guo, Johansson). Improved dual attack with new distinguisher and two-step lattice reduction, lowering complexity estimates for Kyber and Dilithium.
- **130900124.pdf** — Balanced Non-Adjacent Forms (Marc Joye). Signed-digit integer recodings minimizing Euclidean weight, with efficient algorithms and applications to reducing LWE/FHE noise variance.
- **130900128.pdf** — Bounded Collusion ABE for TMs from IBE (Goyal, Syed, Waters). Attribute-based encryption for Turing machines from identity-based encryption alone, via Garbled RAM and a new iterated simulation security notion.
- **130900129.pdf** — Efficient Boolean Search over Encrypted Data with Reduced Leakage (Patel, Persiano, Seo, Yeo). CNFFilter encrypted multi-map supporting CNF queries with optimal communication, sublinear search, and less leakage than BIEX.
- **130900133.pdf** — Giving an Adversary Guarantees (Or: How to Model Designated Verifier Signatures in a Composable Framework) (Maurer, Portmann, Rito). Extends Constructive Cryptography to guarantee adversarial capabilities, giving first composable definitions for multi-designated-verifier signatures.
- **130900142.pdf** — Lattice sieving via quantum random walks (Chailloux, Loyer). Quantum-walk-based SVP sieving improving Laarhoven's heuristic runtime to 2^0.2570d+o(d), with time-memory tradeoffs.
- **130900145.pdf** — Verifiably-Extractable OWFs and Their Applications to Subversion Zero-Knowledge (Fauzi, Lipmaa, Siim, Zając, Ødegaard). Studies OWFs with public image verification and generic two-way constructions between them and Sub-ZK NIZKs.
- **130900147.pdf** — Digital Signatures with Memory-Tight Security in the Multi-Challenge Setting (Diemert, Gellert, Jager, Lyu). First signature schemes fully tight in time, success probability, and memory in the multi-challenge setting, via canonical reductions.
- **130900149.pdf** — On Time-Lock Cryptographic Assumptions in Abelian Hidden-Order Groups (van Baarsen, Stevens). Formalizes hardness assumptions in multi-generator abelian hidden-order groups and generalizes the algebraic group model to them, for class-group time-lock crypto.
- **130900150.pdf** — Redeeming Reset Indifferentiability and Applications to Post-Quantum Security (Zhandry). Revives (weak) reset indifferentiability: ideal ciphers imply random oracles, and generic groups yield post-quantum symmetric-key constructions.
