This additive review note preserves every original run, validator, decision, evidence and hypothesis record. It qualifies their presentation and distinguishes an archived claim from the checks performed in this PR review.

The review verified 51 file hashes in seven producer run manifests, 58 available validator-artifact hash entries and 40 source comparisons against the recorded launch commits. It read all 54 producer rows and independently recomputed the 35 per-cell summaries; replay of the analysis on these retained rows matched the committed review criteria and four summary files. These are retained-artifact checks. The original solver experiments and historical independent validations were not rerun.

[pr2424-archive-audit.json](pr2424-archive-audit.json) lists five missing original solver inputs named in two archived crash-reproduction SHA256SUMS files. The two chain inputs for `run03_L4_i0_p65551` and all three inputs for `run04_L4_i0_p262271` are absent from the reviewed Git tree. The available first-case dense input and the recorded stdout, metadata and hashes remain useful evidence, but the archive does not contain all original bytes needed for direct replay of those exact historical input files. Recovering original bytes with the listed hashes would close this custody gap. Regenerated files would require separate provenance and cannot silently replace the originals. The historical manual execution claim is not disproved by their absence.

At m=3 the paired chain/dense medians are 1.338, 1.862, 2.271 and 1.940 for L=3..6. Their reported 95% bootstrap intervals include [1.106, 1.576] at L=3 and [2.184, 2.351] at L=5. These intervals are disjoint, so the report's description of a ratio flat within the intervals is not supported. The finite observations show slower chain solves in the measured cells and no monotone increase across all four cells; they establish neither a constant ratio nor an asymptotic trend. Singular has jointly completed comparisons at L=3,4 only, not at all four msolve cells.

At m=4 the L=3 and L=4 cells have one degenerate target each. L=4's Singular arms each have five timeouts plus one `degenerate_target`, and RUN-03's msolve arms each have five `rc-11` failures plus one `degenerate_target`. Statements that all six solves timed out or crashed should be read with these exact counts. RUN-04's `A_drl_ms` has four timeouts, one `rc-9` and one degenerate target; a kill is not a timeout. The literal frozen stopping rule requires every instance to time out, whereas the report's retirement comparison excludes degenerate targets. No additional cell was skipped by this difference because L=4 ends the grid. The observed slower medians in both jointly completed cells support the first comparison clause independently of the retirement interpretation; no scientific status is changed here.
