# Full-point certificate interface for k11 binary inputs — 2026-10-17

## Purpose and binding

The [weighted](2026-10-17-binary-torsion-k11-xcnf.md) and [same-width local random](2026-10-17-binary-torsion-k11-local-control-xcnf.md) bases now have four target-channel XCNF files each. A Boolean assignment to those formulas is not by itself an elliptic-curve relation. The [new interface](../../tools/icperf_binary_k11_root_certificate.py) binds either manifest to its base and archived target chain, accepts a complete signed-DIMACS solver model or a primary assignment, and invokes the earlier [full-point certificate check](../../tools/icperf_binary_root_certificate.py) on the selected raw target channel. It verifies exact coordinate membership, all seven field equations, curve lifts, all 256 point-sign choices, the raw curve sum, and the projected prime-subgroup coefficient row. It rejects incomplete or contradictory primary model literals.

The interface changes no archived formula or earlier certificate. It supports both `weighted` and `local_random` and channel `0..3`, binds source and input hashes in its output, and records failed predicates for invalid assignments. The [diagram](2026-10-17-binary-k11-root-certificate.svg) and [PDF](2026-10-17-binary-k11-root-certificate.pdf) show the acceptance path.

## Independent correctness controls

The [synthetic control record](../../research/icperf_binary_k11_root_certificate_20261017/synthetic_controls.json) constructs eight known base points separately for each k11 base. Its target is the sum of those points, **separate from the archived evaluation target**. For each base and all four channel labels, the direct checker accepts one sign mask and one distinct projected row; flipping the first primary bit fails. The [independent Sage replay](../../tools/icperf_binary_k11_root_certificate_sage_verify.py) reconstructs both synthetic targets, checks the seven torsion-coordinate equations, all 256 sign masks per base, subgroup projection and the bit-flip control from [its own record](../../research/icperf_binary_k11_root_certificate_20261017/sage_replay.json). Eight all-zero primary assignments against the archived channels fail the field equations, and the DIMACS parser accepts one complete three-bit model while rejecting a contradictory literal. These are correctness tests, not solver observations or relation-yield samples.

## Remaining measurement

There is no supplied satisfying assignment for either k11 base on the archived target, and no full-width solver trial. The checker cannot infer signs from a polynomial root without enumerating them; it will reject a root whose lifts do not sum to the exact raw target. Poles and exceptional algebraic branches can create roots of the coordinate equations, so every returned root still needs this full-point filter. A complete experiment must freeze the solver, target schedule, memory and stopping rules; retain all attempts and costs; verify distinct useful rows and final rank; complete linear algebra and target work; and compare whole-problem cost against the baseline and matched rho. The [full-width IC measurement problem](../../problems/full-width-ic-arity-grid-unmeasured.md) remains open. No canonical performance graph changes.
