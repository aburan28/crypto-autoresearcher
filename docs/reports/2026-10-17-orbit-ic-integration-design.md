## Why this is the next measurable integration

The latest reviewed complete N53 Koblitz comparator in this checkout, [RUN-KIC-a15078](../../research/cold_arm_composition_ic_20260921/REPORT.md), has median cold IC wall 3.0809126245 s and paired IC/strengthened-rho median 3.2945816805. It already uses a signed Frobenius-orbit factor base with 75 columns and density 1/256. Its internal medians are setup 0.7615440415 s and query kernel 1.844755585 s, with query nested inside collection; those component medians must not be added. The [Coordinator decision](../../ledger/decisions/DEC-20260921-6648da.md) accepts the finite composition receipt and makes no program-baseline transition.

A distinct reviewed finite decomposition result, [RUN-KIC-ba86d9](../../research/pair_reuse_20260922/REPORT.md), reduced complete **512-query point-decomposition job** wall time on N23/K16: orbit-canonical normal-x / expanded-table paired median 0.6468878314, fixed-panel bootstrap interval [0.6384838473, 0.6562119807]. The N19/K4 512-query cell was near parity at 1.0031933978. At N23/K16 the table phase became cheaper while the query phase became slightly slower; the representation's value depends on the number of queries per build. The [reviewed decision](../../ledger/decisions/DEC-20260922-38ca94.md) explicitly leaves relation generation, rank, target extraction, final verification, and a matched full-IC comparison open. These N23 and N53 figures are **different curves, factor bases, workloads, and panels**. Neither is a multiplier for the other.

The [previous baseline assessment](2026-10-16-elite-factor-base-baseline.md) records the missing 50–63-bit prime/ordinary-binary end-to-end rows and the `m=8` implementation gap. The first discriminating step here is therefore an N53 *same-base* integration, which isolates table representation before selecting a new base. A target-blind elite-base search follows only after that representation has a correctness and complete-cost comparison. This ordering gives a concrete, short path to a new complete-cost row without treating point-decomposition speed as an attack-cost result.

## Proposed frozen experiment: two isolated comparisons

| Gate | Exact question | Required control and stopping rule |
| --- | --- | --- |
| **A. N53 compatibility** | Does the orbit-canonical pair table preserve the accepted N53 factor-base point set, pair-sum support, and witnesses under its actual subgroup and cofactor? | Rebuild the same 75-column base from committed inputs. Compare complete pair-sum support and deterministic first-hit witnesses with the expanded table on a bounded public panel, including infinity, sign, repeated-point, torsion, and subgroup-projection cases. Independent group replay must agree on every admitted row. A mismatch is an implementation defect; stop before timing. N23 correctness does not discharge this gate. |
| **B. Same-base complete solve** | With the N53 base fixed, does the new representation reduce a cold single-target IC cost on unseen same-point targets? | Freeze a new, disjoint public-known-answer scalar panel and all seeds before launch. Run baseline IC, canonical-table IC, and strengthened rho in serial fresh processes with balanced arm order. Charge base/table construction, every relation attempt and failed lookup, useful-rank completion, linear algebra, target descent/extraction, certificates, verification, I/O, CPU, peak RSS, and external wall. Use identical correctness and stopping rules. Preserve every timeout/failure as censored or invalid, never as a zero-cost or UNSAT row. |
| **C. Target-blind base selection** | At fixed realized base size and representation, can a chosen orbit base improve useful relations and complete cost? | Select candidates using training targets and a frozen objective; commit each recipe, rejected candidate, setup cost, and source digest before viewing the holdout panel. Compare selected and fixed bases on the same unseen points. Record orbit coverage, distinct relation yield, duplicate rows, rank growth, memory, and cold and genuinely amortized setup. A coverage or sparsity gain alone advances only its own column. |

The Coordinator must specify sample counts, fixed target derivation, process order, resource envelope, stop/censor rules, write scopes, all raw artifact paths, independent replay, and decision impact before approval. The existing N53 result is a comparator, but a new head-to-head baseline arm on the **new panel** is needed; ratios across prior panels cannot be multiplied. Every new complete-cost advantage needs `claims/*.json` passing `python3 -m tools.progress_fidelity validate` and independent evidence review before prose calls it a measured IC improvement. The primary complete-cost comparison is paired IC candidate/baseline on identical targets; the paired strengthened-rho gap remains beside it. Report cold one-target cost and any `T`-target amortization with actual reuse separately:

`C_cold = C_base-selection + C_base-build + C_table-build + C_relation + C_rank/LA + C_target + C_verify + C_I/O`.

For a `T`-target claim, state exactly which base/table and matrix artifacts are reusable, charge their construction once, and verify every target independently. Do not divide training search or failed candidate costs away without a declared reuse population.

## Scope of the larger grid

The requested 50–63-bit `m=2..8` prime, Koblitz, and ordinary-binary grid remains a separate program. The immediate N53 gate exercises the accepted Koblitz arity and cannot establish a cross-family or high-arity result. In the [baseline assessment](2026-10-16-elite-factor-base-baseline.md), prime complete solves reach only 32 bits, the ordinary-binary 50–63-bit complete pipeline is absent, and `m=8` lacks a measured engine. For each family and arity, freeze equal realized base sizes and compare a target-blind elite base with the current base through relation yield, solver work, rank, target extraction, and full `S`; include a matched rho arm. A direct `S_8` polynomial describes **seven** summands plus the target; `m=8` summands need direct `S_9` or an equivalent chain. Direct `S_8` construction, monomial support, degree and memory are valuable capacity observations, with chained `S_3` as a distinct formulation. A stopped construction is censored implementation evidence, not an algebraic impossibility result.

For a candidate base that reduces degree of regularity or system density, keep a same-point-set linear-coordinate-change control: basis re-encoding can alter a particular solver trajectory without changing the mathematical factor base. Also compare same-size random and current bases. Count base generation and rejected seeds. A candidate is promoted from structural diagnostics to a complete-cost trial only after planted correctness, unplanted relation yield, and useful-rank controls work at its declared cell.

## Next action and graph custody

The immediate Coordinator action is to freeze **Gate A plus Gate B** as one bounded N53 protocol, with Gate C a separately preregistered successor whose holdout is not disclosed during selection. Gate A is the cheapest falsifier: if exact support or inverse witness transport fails on the accepted base, correct the representation before running a performance panel. If exact semantics pass and whole-job cost falls, a fresh complete-IC paired trial can measure the improvement; if query overhead erases table savings, the result ranks base design and query filtering ahead of further compression at that workload. This design memo supplies neither an approved contract nor a new run.
