`conf` is WDSat's own printed counter (the paper's 'conflicts': one count per branch point opened, i.e. per decision; the patched build's `nodes` counter equals it on every row where `nodes_eq_conf` is true, and `fails` = failed branch inferences = conf + 1 on UNSAT runs). `law` = 2^(m l)/m!. Chained cells: `family` chained_S3 (this pilot's exporter); `trimoska_S4`: the vendored published S_4 instances (`inputs/TRIMOSKA-ECICB-2024/upstream/benchmarks`), solver-build control.
