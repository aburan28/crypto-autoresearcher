## 1. The D1 structural argument — independent re-derivation

This is the item the batch turns on, so it is done first and from scratch.

### 1.1 What D1 claims

> "The MAXIMUM Z over all 6541 planted OBJ-PLANT-SMOOTH values is 4.957 at bits 16
> and 4.643 at bits 20, while the null's tenth-largest Z is about 6.061 and 5.762.
> OBJ-PLANT-ROUGH is bounded by Z < 2 BY CONSTRUCTION. **NO PLANTED VALUE AT ANY
> RUNG OF EITHER LADDER CAN ENTER THE TOP TEN OF THE Z DISTRIBUTION.** The only
> effect a plant can have on T_deep is to EVICT null samples from that tail, which
> pushes T_deep slightly DOWN" — and "RAISING GAMMA OR THE REPLICATE COUNT WOULD
> NOT CHANGE THIS."

### 1.2 The rough family — the claim is genuinely structural, and I confirm it

Derived from `build_rough_replacement` source, not from the table. The replacement
is `q * r` with `q` drawn in `(p, v // 64]` and `r <= v // q`. Since `v <= X = p²`,
`r <= p² / q < p² / p = p < q`. Therefore `P_max(q·r) = q` exactly and

```
Z = ln(q·r) / ln(q) = 1 + ln r / ln q  <  2 .
```

Unconditional, no sampling involved. The fallback path returns `(0, [])` and leaves
the original **null** sample in place, so it introduces no planted value at all.
**The rough family cannot occupy the deep tail. Confirmed.**

### 1.3 The smooth family — the claim is NOT structural, and it is false as written

`build_smooth_replacement` returns a product of primes drawn uniformly from
`primes_upto(Bsm(u=4))` — 256 at bits 16, 1024 at bits 20 — multiplied in while the
product stays `<= v`. So

```
Z = ln(m) / ln(max drawn prime)
```

and the only bound available a priori is `Z <= ln(p²) / ln 2 ≈ 32` (bits 16). **`Z`
here is a random variable with an upper tail, not a bounded quantity.** Whether any
plant reaches the null deep tail is an empirical question about that tail, and it
has to be measured, not asserted.

I measured it. Regenerating every planted value at every rung of the smooth ladder
on the driver's own `calib_plant_smooth` stream (index `g_i*1000 + k`, bases =

against **~0.05 insertions per replicate**. The eviction-to-insertion ratio is about
**10 : 1**, which is why all 28 measured shifts are small and predominantly
negative. That is a **measured near-disjointness of supports**, not a structural
impossibility, and the honest phrase is "the frozen ladder places negligible mass
above the null deep-tail threshold, by a measured factor of ten".

This is recorded as blocking defect **RTB-054-2**. It does **not** overturn
STRIKE-1: 0 of 28 plant rung-cell rows carry a movement flag for `STAT-TAIL-DEEP`

absolute shift over all 28 is 0.3379820826156079 null sd. What fails is the
justification text — which matters precisely because CERT-LPF-1 forbids reporting
the inertness as "low power" and D1 was the only thing distinguishing the two.

known by construction) and runs in seconds. It is the same check STRIKE-2 makes
correctly, applied to the statistic STRIKE-1 is about. Recording that histogram as
a machine-readable array in the calibration package is the forward fix.
