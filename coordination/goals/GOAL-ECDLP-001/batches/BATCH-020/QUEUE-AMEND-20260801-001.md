Companion record: `ledger/corrections/CORR-20260801-001.yaml`.

## Why

Merge `da6f4fdafd` resolved an ID collision with `origin/main`, which had
independently taken `DEC-20260731-009..012`. This branch's BATCH-019/BATCH-020
decisions were renumbered to `DEC-20260731-018..021`; the BATCH-020 opening
decision moved from `DEC-20260731-010` to `DEC-20260731-019`. That merge also
rewrote two artifacts that describe already-committed history — the
TASK-20260731-041 snapshot receipt and this queue's TASK-20260731-041 `archive`
block — so they no longer matched the attested commit
`cac4d8b459a44f1561d3f47835562824f7767765` (parent
`5e2d33458d749dd2ccc5aed829805d2cbc5f5cbf`). `tools/research_dispatch.py`
therefore rejected the archive receipt and blocked all BATCH-020 dispatch.

## Change

Every *as-committed* declaration belonging to the completed
TASK-20260731-040 / TASK-20260731-041 pair is restored to
`ledger/decisions/DEC-20260731-010.yaml` / `DEC-20260731-010`:

- `declared_commit_sets.TASK-20260731-041_snapshot`;
- TASK-20260731-040: `write_scope`, `artifact_paths`, handoff `deliverables`,
  handoff `artifact_paths`, handoff `objective`;
- TASK-20260731-041: `archive.path_sha256` key (value unchanged,
  `b76b7f91...`), `archive.record_ids`, handoff `objective`, and the handoff
  commit-message constraint;
- new `archive.remap_note` string recording the
  `DEC-20260731-010` -> `DEC-20260731-019` mapping, pointing at
  `CORR-20260801-001`, and stating the reading convention below.

The extension past the archive block was forced by `research_dispatch.py`,
which derives an archive task's expected commit scope from the *source* task's
`artifact_paths` and requires the attested commit message to contain every
`archive.record_ids` entry. `cac4d8b4`'s message contains `DEC-20260731-010`.
