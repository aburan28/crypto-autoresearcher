## Setup: the Semaev m-fold cover

Fix a short Weierstrass curve `E/F_p`: `y² = f(x) = x³ + Ax + B`, p > 3,
non-singular (4A³ + 27B² ≠ 0).

The m-th Semaev summation polynomial `S_m(x_1,...,x_{m-1}, T)` is defined
recursively:

```
S_3(x_1, x_2, T) = (x_1-x_2)²T² - 2[(x_1+x_2)(x_1x_2+A)+2B]T + [(x_1x_2-A)²-4B(x_1+x_2)]

S_m = Res_X( S_{m-1}(x_1,...,x_{m-2}, X),  S_3(x_{m-1}, T, X) )   for m ≥ 4.
```

Two equivalent covers:

**(Cover A)** Fix Q_x = c. View S_m(x_1,...,x_{m-1}, c) = 0 as a polynomial
system in (x_1,...,x_{m-1}); for index calculus we ask for solutions in FB^{m-1}.

**(Cover B)** Fix x_2,...,x_{m-1} generically. View S_m(x_1, x_2,...,x_{m-1}, c)
as a polynomial in x_1 of degree `d = deg_{x_1} S_m = 2^{m-2}`. The Galois group
G ⊆ S_d permutes the roots in x_1.

Both covers carry the same arithmetic: the 2^{m-2} roots of S_m in x_1 (or
equivalently in T) for generic parameters are the x-coordinates
`{x(ε_1 P_1 + ε_2 P_2 + ... + ε_{m-1} P_{m-1})}` for sign vectors
(ε_1,...,ε_{m-1}) ∈ {±1}^{m-1}, counted up to the equivalence
(ε_1,...,ε_{m-1}) ~ (-ε_1,...,-ε_{m-1}) (since x(-R) = x(R) on Weierstrass
curves). This gives exactly `2^{m-2}` distinct roots.

**Convention:** Label the `2^{m-2}` roots by fixing ε_1 = +1 and letting
(ε_2,...,ε_{m-1}) range over {±1}^{m-2}:

```
r_{ε_2,...,ε_{m-1}} = x(P_1 + ε_2 P_2 + ... + ε_{m-1} P_{m-1})
```

## Case m = 3: monodromy is S_2 (full symmetric on 2 solutions)

`S_3(x_1, x_2, T)` is quadratic in T with discriminant

```
disc_T S_3 = 16 · f(x_1) · f(x_2).
```

This is a polynomial identity over Z[x_1, x_2, A, B], independently proved:
- Symbolically by sympy (VAL-20260802-b68edf §V-6, from the protocol's S_3
  coefficient block).
- By brute-force grid evaluation at (x_1,x_2,A,B) ∈ [-3,3]^4 (exceeds the
  total-degree bound; RT-20260802-1b4130 §3 check 1).
- By exhaustive p^2 enumeration on 12 curves at p ∈ {211,431,809,1601}
  (RT-20260802-1b4130 §3 check 2).

**Group-theoretic conclusion (stronger than the density argument):**
Over k̄ = F̄_p, f(x_1)·f(x_2) factors as the product of SIX distinct linear
factors (since f has three distinct roots e_1, e_2, e_3 for non-singular E):

```
f(x_1)f(x_2) = ∏_{i=1}^3 (x_1 - e_i) · ∏_{j=1}^3 (x_2 - e_j).
```

This is squarefree in the UFD k̄[x_1,x_2] — six distinct irreducibles each
of multiplicity 1 — hence NOT a square in the fraction field k̄(x_1,x_2).

Therefore `S_3(x_1, x_2, T)` is **irreducible** over k̄(x_1,x_2) as a
polynomial in T, and the geometric (and arithmetic) monodromy group is the
**full S_2 = C_2**, for every non-singular E, at every p > 3.

**Scope of this result:**

- No exceptional locus of any kind: the bound is curve-independent.
- The imprimitivity / block-system half of KN-OPEN-009 is **vacuous at m = 3
  for degree-theoretic reasons**: a transitive group of degree 2 is primitive
  by definition. Its only block systems are the two trivial ones ({all roots}
  and {singletons}). The mechanism KN-OPEN-009 asks about cannot exist at
  m = 3, regardless of the curve. (Source: RT-20260802-1b4130, O-1.)

This is stated here as prior established fact (from GOAL-MONO-001 BATCH-003),
not as new work.

## General m: the monodromy group is C_2^{m-2} (imprimitive for m ≥ 4)

### Splitting field determination

Fix parameters x_2,...,x_{m-1}, c = Q_x as independent transcendentals over
F_p. Let y_i² = f(x_i) and y_c² = f(c). By the chord-and-tangent formula each
root r_{ε_2,...,ε_{m-1}} is an explicit rational function of
(x_1,...,x_{m-1}, y_2,...,y_{m-1}, y_c).

Claim: The splitting field of S_m (as a polynomial in x_1) over
F_p(x_2,...,x_{m-1},c) is exactly

```
K = F_p(x_2,...,x_{m-1}, c,  y_2,...,y_{m-1}, y_c).
```

**Upper bound** (roots ⊂ K): Each root `r_ε = x(P_1 + ε_2 P_2 + ... +
ε_{m-1} P_{m-1})` involves applying the addition formula up to m-2 times;
each application uses y_i (to select the sign ε_i), so every root lies in K.

**Lower bound** (K generated by roots): The difference
`r_{+ε} - r_{-ε}` (root with ε_i flipped) equals a specific rational
combination of the group-law formula that involves y_i explicitly; hence each
y_i is in the splitting field.

Since x_2,...,x_{m-1},c are independent transcendentals, f(x_i) and f(c) are
not squares in F_p(x_2,...,x_{m-1},c), and the quadratic extensions
F_p(·,y_i) and F_p(·,y_c) are independent (their discriminants involve
different variables). Therefore:

```
Gal(K / F_p(x_2,...,x_{m-1},c)) = C_2^{m-1}
```

generated by σ_2,...,σ_{m-1},σ_c, where σ_i flips y_i.

### The central element and the faithful quotient

The element `σ_all = σ_2 · σ_3 · ... · σ_{m-1} · σ_c` acts on every root by

```
r_{ε_2,...,ε_{m-1}}  →  x(P_1 - ε_2 P_2 - ... - ε_{m-1} P_{m-1} - C)
                     =  x(-(P_1 + ε_2 P_2 + ... + ε_{m-1} P_{m-1} + C))⁻¹
```

Wait — with the convention that C has x-coord c and x(-R) = x(R) on Weierstrass
curves, σ_all maps every root to itself:

```
σ_all: r_ε  ↦  x(-(ε_2 P_2 + ... + ε_{m-1} P_{m-1} + P_1))
             =  x(ε_2 P_2 + ... + ε_{m-1} P_{m-1} + P_1)  =  r_ε.
```

So σ_all lies in the kernel of the action on roots. The monodromy group acting
**faithfully** on the 2^{m-2} roots is the quotient:

```
G_mono = C_2^{m-1} / ⟨σ_all⟩  ≅  C_2^{m-2}.
```

### Explicit action

In terms of generators {σ_2,...,σ_{m-1}} (with σ_c redundant: σ_c = σ_2·...·σ_{m-1}
in the quotient), the action on the label (ε_2,...,ε_{m-1}) ∈ {±1}^{m-2} is:

- **σ_i (i = 2,...,m-1):** flips the i-th component.
  `(ε_2,...,ε_i,...,ε_{m-1}) → (ε_2,...,-ε_i,...,ε_{m-1})`.
- **σ_c:** flips all components simultaneously.
  `(ε_2,...,ε_{m-1}) → (-ε_2,...,-ε_{m-1})`.
  (σ_c = σ_2·...·σ_{m-1} consistent.)

This is the **regular representation** of C_2^{m-2} acting on its own
underlying set.

### Summary table

| m | deg in x_1 | Monodromy group | Primitive? |
|---|---|---|---|
| 3 | 2 | S_2 = C_2^1 | Yes (trivially) |
| 4 | 4 | C_2^2 (Klein V_4) | No |
| 5 | 8 | C_2^3 | No |
| 6 | 16 | C_2^4 | No |
| m | 2^{m-2} | C_2^{m-2} | No (m ≥ 4) |

For m ≥ 4: C_2^{m-2} is abelian, acts transitively on 2^{m-2} elements via the
regular representation, and is **imprimitive** — it preserves multiple
nontrivial block partitions. For example, the subgroup ⟨σ_2⟩ ≅ C_2 partitions
the roots into blocks by the sign of ε_2:

```
Block₊ = {r_ε : ε_2 = +1}   (size 2^{m-3})
Block₋ = {r_ε : ε_2 = -1}   (size 2^{m-3})
```

### No exceptional locus

The argument is independent of the curve (the extension K/F_p(params) depends
only on f having three distinct roots, i.e., E non-singular) and independent
of the prime p > 3. Therefore:

**The monodromy group is exactly C_2^{m-2} for every non-singular curve
E/F_p (p > 3), for every m ≥ 3. There is no exceptional locus.**

## Connection to exceptional loci and relation rate

### The factor-base locus (where index calculus operates)

**Critical fact (from RT-20260802-1b4130, O-9; verified m=4 by direct construction):**
If x_1,...,x_{m-1} are x-coordinates of F_p-rational points P_1,...,P_{m-1} on E,
then S_m(x_1,...,x_{m-1},T) **splits completely over F_p**:

```
S_m(x_1,...,x_{m-1},T) = (x_1-x_{m-1})^2 · ∏_{ε} (T - x(ε_1 P_1 + ... + ε_{m-1} P_{m-1}))
                                                              modulo a leading coefficient.
```

Every root is the x-coordinate of a rational point, hence lies in F_p. The
Frobenius cycle type is the **identity permutation** on all 2^{m-2} roots.

This holds at every m, for every non-singular E/F_p, unconditionally.

Verified computationally for m=4: S_4 = Res_X(S_3(x1,x2,X), S_3(x3,T,X)) on
E/F_211 (A=37, B=57), 193 triples of rational x-coordinates — 193/193 fibers
split completely with root set exactly {x(±P1±P2±P3)}.

**Consequence for KN-OPEN-009:**
The "Chebotarev/Frobenius cycle-type census on the generic locus" (the quantity
KN-OPEN-009 proposed measuring to detect deviant relation rates) is IDENTICALLY
TRIVIAL on the factor-base locus. The generic-locus Chebotarev distribution
(C_2^{m-2} cycle types) is irrelevant for index-calculus relation counting,
which operates entirely on the factor-base locus where the cycle type is always
the identity.

### The universal constant factor (Corollary E of RUN-MONO-4b50b6-001)

The probability that a factor-base pair (x_1, x_2) ∈ FB^2 (x_1 ≠ x_2)
satisfies S_3(x_1, x_2, c) = 0 for a given c is:

```
P(split | x_1,x_2 ∈ FB, x_1 ≠ x_2) = 1    (exactly; for all curves, all p > 3)
```

The quasirandom prediction `freq_split · (W_eff/p)^2` understates this by a
factor of `2(1 - 1/W_eff)` (≈ 1.5 at W_eff = 4; approaches 2 as W_eff → ∞).
Verified: 1196/1196 off-diagonal factor-base pairs split on 105 curves across
p ∈ {211,431,809,1601}. (RT-20260802-1b4130, O-8; VAL-20260802-b68edf, V-11.)

This enhancement factor is:
- **Universal**: same for every curve family.
- **Constant**: does not move an exponent (for fixed m).
- **Already accounted for by the group law**: it follows from the fact that
  E(F_p) is closed under addition, not from any monodromy argument.

### Imprimitive structure vs. resolvent decomposition

The block system of C_2^{m-2} acting on the 2^{m-2} roots corresponds exactly
to the recursive resultant construction of S_m. The "blocks" (e.g., roots with
ε_2 = +1 vs. ε_2 = -1) are the two branches of S_{m-1} that appear when
resolving the resultant step. Explicitly, over the extension F_p(x_{m-1},y_{m-1}):

```
S_m  =  P_+(x_1,...,x_{m-2},T)  ·  P_-(x_1,...,x_{m-2},T)
```

where P_+ collects roots with ε_{m-1} = +1 and P_- with ε_{m-1} = -1, each
of degree 2^{m-3} in x_1. This is precisely S_{m-1}(x_1,...,x_{m-2}, T±...) —
a consequence of the recursion, not additional structure.

The conclusion is: **the imprimitivity of C_2^{m-2} is already fully exploited
by the standard recursion. There is no hidden block structure beyond what
the resultant construction already uses.**

## Conclusion: does imprimitive monodromy exist for any curve family?

**Monodromy group:** The geometric monodromy of the m-th Semaev cover is
exactly C_2^{m-2} for all non-singular E/F_p (p > 3), for all m ≥ 3.

**Imprimitivity:** C_2^{m-2} is imprimitive for m ≥ 4. This imprimitivity is
UNIVERSAL — it applies to every curve, with no exceptional locus.

**Exceptional locus:** There is no curve family with SMALLER monodromy group.
C_2^{m-2} is already the minimum: the quadratic extensions y_i²=f(x_i) are
independent for generic parameters, so the Galois group cannot be smaller
without additional algebraic dependencies among the factor-base x-coordinates.

**Higher relation rate from imprimitivity:** No. The imprimitivity says that
the roots split into blocks under the Galois action, but:

1. It does NOT increase the number of roots (still 2^{m-2} generically).
2. It is universal, so no curve family benefits differentially.
3. The relevant locus (factor-base) always gives complete splitting regardless
   of imprimitivity structure.
4. The block structure = the recursion structure; no new algorithm arises from
   "resolving" the blocks beyond what the recursive resultant already does.

**Resolution of KN-OPEN-009 for this question:**

- "Is the monodromy the full symmetric group S_{2^{m-2}}?" — **No, for m ≥ 4.**
- "Is the monodromy imprimitive?" — **Yes, always, for all curves, for m ≥ 4.**
- "Is there an exceptional locus with SMALLER monodromy?" — **No.**
- "Does imprimitivity give a curve family with systematically higher relation
  rate?" — **No.** The factor-2 enhancement is universal and already known.

**What remains genuinely open** (within KN-OPEN-009's stated scope):

1. Whether the imprimitive resolvent decomposition (P_+ · P_- factorization)
   can be exploited algorithmically to speed up S_m solution search for
   index-calculus relations — this is an algorithmic question, not a
   monodromy question.
2. The Chebotarev distribution over the GENERIC locus (not the factor-base
   locus) — the theoretical prediction is C_2^{m-2} cycle types, which is a
   well-posed measurement but one that is decoupled from the relation-rate
   question for prime-field ECDLP.

## Impact on ECDLP index calculus

### What this closes

The monodromy analysis definitively answers the following sub-questions of
KN-OPEN-009 for prime-field ECDLP (F_p, prime-order E):

| Question | Answer | Basis |
|---|---|---|
| Monodromy group for m=3? | S_2 (full, no exc. locus) | disc=16f(x1)f(x2), squarefree |
| Monodromy group for m≥4? | C_2^{m-2} (imprimitive, universal) | Galois theory of splitting field |
| Exceptional locus (smaller monodromy)? | Does not exist | Argument is curve-independent |
| Curve family with deviant relation rate? | No (enhancement is universal, constant) | RT-O9, Cor-E |
| Is generic-locus Frobenius census relevant to relation rate? | No | Factor-base locus = identity cycle always |

### What this does not close

- The algorithmic utility of the C_2^{m-2} block structure for faster solving.
- The monodromy question for HIGHER-GENUS COVERS (e.g., GHS-style attacks,
  Diem's approach for F_{q^n}): the analysis here is specific to prime fields
  and the Semaev cover in the ECDLP setting.
- The m≥4 Chebotarev census on the generic locus (theoretical interest, but
  decoupled from prime-field ECDLP relation rates per the above).

### Cost and scope summary

The "imprimitive monodromy" direction (round-2 C2 in the research program) is
**not vacuous** — C_2^{m-2} IS imprimitive — but the imprimitive structure is
already the recursive construction. No speedup over the recursive resultant
arises from exploiting it in a new way, absent a fundamentally different
algorithm for solving the resulting (still-degree-2^{m-3}) sub-polynomials.

The "exceptional curve sieve" direction (round-2 A1) is **closed at the
monodromy level**: there are no exceptional curves with smaller monodromy.
The only curve-invariant that affects relation counting is whether E(F_p) has
large prime order (affects the factor-base size relative to p) — which is a
separate question from monodromy.
