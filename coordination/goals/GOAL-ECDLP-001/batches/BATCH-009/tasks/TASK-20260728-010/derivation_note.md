## D1. The genuine rank bound for family `J0` is 2, not 3

For an elliptic curve `E/F_p` with `j = 0` and `p = 1 mod 3`, `E` is ordinary
with complex multiplication by an order in `Q(zeta_3)`. `End(E)` is therefore an
**order in an imaginary quadratic field, a Z-module of rank 2**. The efficiently
computable maps the contract uses are `1`, `phi` and `phi^2`, where `phi` is the
`zeta_3`-twist and satisfies

```
phi^2 + phi + 1 = 0   in End(E).
```

So `{1, phi, phi^2}` are three *distinct* elements spanning a Z-module of
**rank 2**, and they satisfy the Z-linear relation `1 + phi + phi^2 = 0` in
`End(E)` itself — before any reduction modulo `N`.

In `EXP-ENDO-001` the parameter `r` is a **coordinate count**: the lattice lives
in `Z^(2r)` with one coordinate per `phi_i` per side. A coordinate count must be
a count of Z-independent generators, not of distinct elements. Setting
`genuine_r_bound: 3` for `J0` counts distinct scalars. The correct value is 2.

**Where this note differs from RT-20260728-001.** B1 asks for
`genuine_r_bound: 2` "for BOTH CM families". That is not right for `J1728`:
`End(E)` there contains `Z[i]` with `i^2 = -1`, rank 2, generated by `1` and
`i`, and the contract already sets `genuine_r_bound: 2` for it. The defect is
confined to `J0`, where the bound must fall from 3 to 2. `J1728` and `GEN` are
correct as frozen. The correction is smaller than the review states and is
therefore stated smaller here.

**The contract states the relation and then contradicts it.** Its own
`synthetic_rank_rule` reads:

> on a prime-order subgroup of a j = 0 curve the efficiently computable scalars
> are generated by 1 and lambda with lambda^2 + lambda + 1 = 0 mod N, so at most
> three distinct scalars exist and the third satisfies lambda_3 = -1 - lambda_2.

"generated by 1 and lambda" is the rank-2 statement. `lambda_3 = -1 - lambda_2`
is the relation. The record contains its own correction and did not apply it.

## D2. On family `J0` at every rank `r >= 3`, the first minimum of `W_r` is exactly 1

Let `N >= 3` be the prime subgroup order and let `lambda_2, lambda_3` be the two
roots of `L^2 + L + 1 = 0 mod N` as the contract specifies, with
`lambda_1 = 1`. By Vieta's formulas applied to a monic quadratic over the field
`Z/N`,

```
lambda_2 + lambda_3 = -1  mod N        (sum of roots = -(coefficient of L))
lambda_2 * lambda_3 =  1  mod N        (product of roots = constant term)
```

Hence, identically and for every such `N`:

```
lambda_1 + lambda_2 + lambda_3 = 1 + (-1) = 0  mod N.
```

Now take `r >= 3` and the integer vector

```
w = (a | b),   a = (1, 1, 1, 0, ..., 0),   b = (0, 0, ..., 0)   in Z^(2r).
```

Then `A(a) = lambda_1 + lambda_2 + lambda_3 = 0 mod N` and `B(b) = 0`, so
`A(a) + k*B(b) = 0 mod N` **for every `k`**. Therefore `w` is in `W_r(k)` for
every `k`. Its infinity norm is `1`. Every nonzero integer vector has infinity
norm at least `1`. Therefore

```
lambda_1^inf( W_r(k) ) = 1   exactly,
for family J0, every r >= 3, every prime N >= 3 and every k in [1, N-1].
```

Prediction P2 of `H-ENDO-001` and STEP 3 of the contract predict
`lambda_1^inf = about N^(1/(2r))`, i.e. `log_N(lambda_1^inf) = 1/(2r)`:
`1/6` at `r = 3` and `1/8` at `r = 4`. The true value is `log_N(1) = 0`, for
every field size. **P2 is false on family `J0` at `r >= 3`**, which is
precisely the region the contract labels *genuine*.

This does not depend on the curve, the instance, the seed, the implementation or
the field size, and no measurement can change it.

**Consequences inside the frozen protocol**, had it executed:

1. Success criterion S2 regresses `log_N(first minimum)` on `1/(2r)` over cells
   solved by exact enumeration. The `J0` cells at `r in {3, 4}`, over 4 field
   sizes and 5 seeds — **40 cells** — would enter that regression at `y = 0`
   against predicted `1/6` and `1/8`. They are not removed by the
   exact-enumeration restriction: with first minimum 1, enumeration terminates
   immediately.
2. The P-side enumeration map `a -> A(a)` is non-injective on the box by the
   same relation, so the list of *distinct scalar images* is strictly smaller
   than the list of coefficient vectors. Whether that shows up in the measured
   cost depends on an enumeration convention the contract never pins, which is
   objection B4 of `RT-20260728-001`.
3. Heuristic HEUR-1 of `H-ENDO-001` transfers a random-lattice model to `W_r`.
   `W_r` at `J0`, `r >= 3` contains the sublattice
   `{(t, t, t, 0, ..., 0)} + {(0, ..., 0 | u, u, u, 0, ..., 0)}` of norm-`t`
   and norm-`u` vectors. No random-lattice model predicts a first minimum of 1
   at determinant `N`. HEUR-1 is false there.

**Upgrade path to a counterexample certificate.** Fix any prime `p = 1 mod 3`
with a `j = 0` curve `y^2 = x^3 + b` having a prime-order subgroup of order
`N >= 3`. Compute the two roots of `L^2 + L + 1 mod N`; check
`lambda_1 + lambda_2 + lambda_3 = 0 mod N`; build a basis of `W_3(k)` for a
driver-chosen `k`; compute the infinity-norm first minimum by exact enumeration
and confirm it is 1; and confirm `(1,1,1,0,0,0)` is in the lattice by checking
the congruence directly. That instantiation, packaged so independent code
re-checks it, is the level-1 artifact. This session has no shell and produced no
numeric instance; **no instance is asserted here and none is fabricated.**

## D3. The part of `W_r` an attacker can construct is exactly the part that carries no information about `k`

This claim is new in this note.

Define the **eigenvalue relation lattice**

```
R_r = { c in Z^r : sum_i c_i * lambda_i = 0 mod N }.
```

`R_r` is computable by an attacker: it depends only on `N` and on the
`lambda_i`, all of which are public. Since `lambda_1 = 1` is a unit, the map
`c -> A(c)` is onto `Z/N`, so `R_r` has index `N` in `Z^r`.

**(i) `R_r x R_r` is contained in `W_r(k)` for every `k`.** If `A(a) = 0` and
`B(b) = 0` then `A(a) + k*B(b) = 0` for every `k`.

**(ii) The intersection of `W_r(k)` over all `k` is exactly `R_r x R_r`.** Let
`(a, b)` lie in `W_r(k)` for `k = 1` and for `k = 2` (both are in `[1, N-1]`
whenever `N >= 3`). Then `A + B = 0` and `A + 2B = 0` mod `N`, so `B = 0` and
then `A = 0`. With (i), `intersection_k W_r(k) = R_r x R_r`.

So the **`k`-independent part of the witness lattice is exactly `R_r x R_r`**,
an index-`N^2` sublattice of `Z^(2r)` and an index-`N` sublattice of `W_r(k)`.

**(iii) Vectors of `R_r x R_r` yield no discrete logarithm.** A witness
`(a, b)` in `R_r x R_r` has `B(b) = 0`, which is not invertible mod `N`. The
contract's own control `CTRL-CERT` says: "where the Q-side coefficient
combination B = sum b_i lambda_i is invertible mod N the recovered
k = -A/B mod N is checked". When `B = 0` there is nothing to recover. Such a
vector is a true relation among the `phi_i(P)` and `phi_i(Q)` separately and
tells the attacker nothing about `k`.

**Conclusion.** Every vector of `W_r` that an attacker can write down without
already knowing `k` lies in `R_r x R_r` and carries zero information about `k`.

**Why this matters for D2.** The short vectors that make the `J0`, `r >= 3`
first minimum collapse to 1 lie in `R_r x R_r`. The collapse is therefore a
collapse of the *information-free* sublattice, and would be, if measured,
maximally misleading: it is shortness in exactly the coordinates that cannot
help. Generically — when the `lambda_i` admit no small integer relation —
`R_r` has determinant `N` in dimension `r` and its first minimum is around
`N^(1/r)`, which is *larger* than the `N^(1/(2r))` that `W_r` as a whole
attains. The constructible part is generically the longer one, and in the
degenerate case it is the shortest possible one; in neither case is it useful.

## D4. The pinned determinant is not what makes shortness unexploitable; non-constructibility is

The contract's STEP 5 offers this dichotomy:

> If the measurement contradicts STEP 4 - if rho(r) falls with r - then either
> the determinant is not pinned or the balanced split is not the best
> decomposition, and either is a genuine structural finding rather than an
> implementation improvement.

There is a third and operative explanation the dichotomy omits.

**`W_r(k)` is not attacker-constructible.** Its defining congruence has
coefficient vector `(lambda_1, ..., lambda_r, k*lambda_1, ..., k*lambda_r)`,
whose second half involves the unknown `k`. By D3(ii), the largest part of it
that can be written down without `k` is `R_r x R_r`, which by D3(iii) is useless.

**Constructing it would already solve the problem.** Suppose a basis of
`W_2(k)` were available. It is a rank-4 integer lattice of determinant `N`. LLL
runs in polynomial time and returns a nonzero vector of infinity norm
`O(N^(1/4))` up to a dimension-4 Hermite factor. Any resulting witness
`(a, b)` with `B(b)` invertible mod `N` gives `k = -A(a)/B(b) mod N`
immediately, checkable by `[k]P = Q`. So *being able to write down `W_2`* is
equivalent, up to polynomial work, to *solving the ECDLP instance*.

Therefore the determinant being pinned at `N` — STEP 2, correct — is not the
reason the lane is barred. The lane is barred one step earlier, at the
construction of the object to be searched. A `confirmed` verdict on this
contract would have attached a true observation (the cost does not fall with
`r`) to a false mechanism (the determinant is why).

**Scope, stated narrowly.** D4 is a statement about the class of attacks that
construct and then reduce `W_r` **as defined in EXP-ENDO-001 STEP 1**. It is not
a statement about ECDLP, not about endomorphism-assisted attacks in general, and
not an impossibility claim of any kind. The known correct way endomorphisms
help — the automorphism-quotient Pollard rho at about
`0.886 * sqrt(N/|Aut|)` (Wiener-Zuccherato; Duursma-Gaudry-Morain) — is
untouched by any of D1-D4, is a constant-factor improvement of at most
`sqrt(6)`, and is outside target class under the target-result profile.

   enumerated first minimum. This is the certificate upgrade. (D2)
5. Is `intersection_k W_r(k) = R_r x R_r` exactly, by the `k = 1, 2` argument?
   Is the index bookkeeping `N`, `N^2`, `N` right? (D3)
6. Does every vector of `R_r x R_r` have `B = 0`, and does `CTRL-CERT` therefore
   exclude it? (D3)
7. Does constructing `W_2` plus LLL plus `k = -A/B` really solve the instance —
   i.e. is D4's reduction valid in the direction stated? (D4)
8. **Attack the scope.** Is D4 being over-read as an impossibility claim about
