## The run protocol (exact order)
1. **Build the MD4 instrument.** `harness/run_md4_calib.py`:
   a standalone MD4 written from the RFC 1320 text
   (`inputs/rfc1320-md4.txt`, the ONLY specification input; record its
   sha256 — as recorded by RANK 1 — in the manifest), NOT imported from
   any library (Python's hashlib has no MD4 — do not add a dependency). The SAME search structure as the frozen
   MD5 instrument `harness/run_md5_calib.py` (do not modify it; it is
   the structural template): bounded deterministic birthday
   enumeration, meet table over the low digest bits (ruled width),
   16-step round fragments, --seed, --variant-shift N (cyclic shift of
   the 64 round constants), --deadline, run_wrapped charging.
   **Smoke-verify first**: all RFC 1320 section 3 test vectors must
   pass on the standalone MD4, recorded in the report. A vector that
   fails is a BUILD DEFECT: record it, do not proceed to the runs
   (record the defect and stop; a wrong MD4 measuring MD4 is the
   recall-tell shape this whole campaign exists to avoid).
2. **Seal the input manifests** (before each run): { rfc1320-md4.txt
   sha256, declared budget (900 s / 4 GB), seed 0, instrument file
   sha256, variant-shift N }. The CONSUMPTION check is DECLARED N/A for
   MD4 (there is no MD4 quarantined payload) — but run the
   completeness check: intersect each manifest sha256 set with the MD5
   quarantine MANIFEST's sha256 list (e44a3fed...); record the
   intersection (must be empty; the MD5 payload is untouched).
3. **Run the MD4 TARGET** — `harness/run_md4_calib.py UNMODIFIED
   after the smoke pass`, `--seed 0`, `--variant-shift 0`,
   `--deadline 900`, wrapped in `run_wrapped` (wrapper-measured
   wall_seconds). 4 GB. 1 run. The 900 s wall is HARD (SC-7): a halted
   run is a complete, admissible observation; cost = ceiling on halt.
   Do NOT continue past the wall.
4. **Run the MD4 NULL OBJECT** — IDENTICAL instrument, IDENTICAL
   everything, EXCEPT `--variant-shift 16`: T-prime[i] = T[(i+16) mod 64]
   over RFC 1320 section 3's 64 round constants. SEQUENTIAL after the
   target (same machine state; no concurrent-load distortion of the
   wall-clock comparison).
5. **Report.** md4-control-run-report.yaml:

   - the build record: standalone MD4 vector pass/fail table, instrument
