- **Does not supersede:** any measurement, artifact, or hash in that commit. The

## What the commit message claimed

> the queue declared the producer's artifact_paths as manifest.yaml and
> raw-result.json only, and the SNAP archive block carries no commit_paths

## What is actually true

Both halves are false.

1. `TASK-20260726-DREG-CTRLB-SNAP` carries a **task-level** `commit_paths` key
   with **9 entries** — the 8 producer receipt files plus this batch's
   `snapshot/snapshot_commit_receipt.json`.
2. The two-path list I quoted is the **producer** task's (`...-P1`)
   `artifact_paths`, which names `manifest.yaml` and `raw-result.json` as its
   headline deliverables. That is a different field on a different task.

**Cause of the error:** the Coordinator queried `archive.commit_paths` and read
the resulting `None` as "not declared". `commit_paths` sits at task level, a
sibling of `archive`, not inside it. The conclusion was asserted as fact in a
commit message without being checked against the file.

## Effect on what was committed

None on the artifacts. Reconciling the declared list against `8302c83a`:

| | |
|---|---|
| Declared and committed | 8 of 9 |
| Declared, not committed | `snapshot/snapshot_commit_receipt.json` (see `SNAP-DEV-1`) |
| Committed, not declared | `chunk-coverage.log` (see `SNAP-DEV-2`) |

So the snapshot was **not** the improvised scope decision the message described.
It was, to within one omission and one addition, exactly the declared list. The
reasoning offered for the scope — that the artifact policy requires command,
environment and stdout/stderr — remains correct as a justification for the
declared list; it was simply not needed, because the queue already declared those
files.

## Remedies applied

- `snapshot/snapshot_commit_receipt.json` is created and committed in the
  immediately following Coordinator commit, recording `commit_sha`, `parent_sha`,
  per-path SHA-256 for all nine files, and both deviations. It cannot live inside
  `8302c83a` itself, since its own contents depend on that commit's identity.
- `chunk-coverage.log` is retained rather than reverted: it is a genuine receipt
  of the same run within the producer's declared `write_scope`, and removing a
  committed run artifact would be worse for the record than documenting the
  expansion. Logged as `SNAP-DEV-2`.

## Standing instruction for later batches

Read `commit_paths` from the task, not from `archive`. Before writing any claim
about the frozen contract into a commit message, re-read the contract and quote
it; do not restate a query result as a fact about the queue.

`RUN-DREG-001-CTRLB-N12-D6`'s measurement, the pre-registered bracket, the
