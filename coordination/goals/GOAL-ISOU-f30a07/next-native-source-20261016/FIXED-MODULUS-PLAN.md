## Context contract and correctness obligations

Use an immutable context borrowing both the exact field and the exact trimmed modulus for its lifetime. Methods receive operands only; callers cannot pass a different modulus/field with the cached inverse. No `RefCell`, shared mutable state, mutable lazy cache, or clone of the full modulus is needed. Explicitly reject a zero modulus at context construction; do not silently normalize malformed trailing-zero input. Production h has already passed monicity/degree/squarefree guards. Constant and shorter moduli use the original division path.

For modulus length L >= 128, compute the reciprocal of the reversed modulus to **L coefficients** once. Store formal-series precision including zero coefficients; never polynomial-trim this inverse. Each eligible reduction uses exactly the prefix `count = a.len() - L + 1`. Retain the old fast-path predicate and quotient/remainder construction, including the degree assertion. For all other dividend lengths use unchanged `divrem`. This covers the entire old fast path, including dividend length 2L-1; sizing only for ordinary reduced-product degrees would miss part of that contract. For L < 128 do not construct a reciprocal.

Formal obligation, to be documented beside the code: for degree d modulus m with nonzero leading coefficient, its reverse B has nonzero constant coefficient and therefore a unique formal inverse modulo X^k. Newton's update G -> G(2-BG) doubles correct precision because B G(2-BG) = 1-(1-BG)^2. The unique prefix of a precision-L inverse equals the separately computed precision-count inverse. Reversal with exactly count coefficients yields the same quotient, so a-qm has degree less than d. The IDC1 evaluation of the scalar identity is a finite-field supplement; it does not prove uniqueness of formal inverses or all-size reduction correctness. Native exact coefficient residual tests in each tested actual field, the algebraic derivation, and independent `divrem` comparisons cover those distinct obligations. Do not label an evaluated certificate a proof over all integer coefficients.

Create one context after reference degree/squarefree checks and before selected torsion. Reuse it for all fixed-h reductions in selected torsion, numerator/denominator products and final xg reduction, and composition powers/giant products/final reduction. Leave the complete `invmod` and GCD routines unchanged. Keep check order and error categories. A shared acceptance helper may take a reduction strategy, provided reference operations still call the preserved functions and reviewers can mechanically verify every check remains; do not duplicate or relax the admission algorithm.
