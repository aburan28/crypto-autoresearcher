CONCLUSION: g6k 0.1.2 CANNOT BE BUILT on Apple Silicon (arm64).
Root cause: g6k's sieve kernels (bgj1_sieve.cpp, bdgl_sieve.cpp, etc.) include
<immintrin.h> which provides x86/x64 SIMD intrinsics (AVX, SSE, etc.). This header
explicitly rejects non-x86 architectures with '#error "This header is only meant to
be used on x86 and x64 architecture"'. No workaround exists without patching g6k's
source to either remove SIMD or add ARM NEON equivalents, which is outside the scope
of a reproduction task.
