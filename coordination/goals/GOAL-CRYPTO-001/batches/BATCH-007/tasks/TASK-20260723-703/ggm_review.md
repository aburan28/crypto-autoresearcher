## Simulability gaps

### Public equations are not a complete oracle specification

A public equation determines a fiber or relation. It does not determine which
root, lift, normalization, branch, random sample, or stateful answer is
returned. Exact simulation requires:

1. the evaluation data available for an opaque handle;
2. a complete output-selection and randomness law;
3. the provenance of every coordinate, coefficient, and advice item; and
4. preservation of the full joint answer distribution.

If selection uses a concrete coordinate of an opaque composite handle, the
interface enters the coordinate-encoding seam. If it uses target-fitted advice,
it assumes hidden information. The short public-equation argument in the
snapshot does not independently discharge these interface quantifiers; it
relies on the cited prior theorem. This is not a surviving family, but it is a
limit on how broadly that paragraph can be reused.

The additive vanishing argument is also narrower than a universal simulation
theorem. It excludes homomorphisms from the prime-order subgroup into finite
additive \(p\)-primary targets. It does not classify nonlinear cocycles,
multi-point predicates, torsors, branch distributions, or arbitrary
source-bearing outputs. The producer appropriately leaves the nonadditive case
uninstantiated; that boundary must be retained.

### The two-world test is one-sided

`NS-TX-PRIME-001` is a useful sufficient certificate against a frozen
simulator. It is not a necessary condition for non-simulability:

- a difference may occur only in a complete adaptive transcript rather than a
  fixed formal query sequence;
- oracle state or correlated randomness may distinguish joint answers even
  when each answer marginal looks simulable;
- a small per-answer gap can accumulate over the allowed query budget; and
- exact simulation is refuted by any distributional mismatch, while an
  approximate lower-bound transfer needs a total statistical-distance budget.

Accordingly, failure to produce two secrets with the stated
inverse-polylogarithmic verified gap cannot be interpreted as a simulator
construction. For an adaptive oracle, the proof must couple transcript trees
over algorithm coins, oracle coins, random encodings, equality collisions, and
all side information. The \(O(1)\) extra group queries must be totaled across
all augmented answers before applying a collision bound.

Conditions 1--3 of the producer's criterion concern simulator separation.
Condition 4 and the \(\lambda,\mu,\tau\) requirements concern usefulness and
campaign admission. These should remain separate. A concrete-coordinate oracle
can be non-simulable but useless for source relations; failing the utility gate
does not make it generic.

## Cheapest adequate gate

The symbolic relabelled-transcript gate is appropriate only after an exact
oracle exists. With no oracle, its current result is necessarily vacuous. The
cheapest present gate is a typed-oracle admission card freezing:

- domain, codomain, output length, and equality semantics;
- lift/root/branch selection, state, and randomness;
- point, coordinate, coefficient, preprocessing, and advice provenance;
- target timing and target-uniformity; and
- exact source-certificate and miss semantics.

For a candidate that passes that card:

1. construct a full adaptive joint-transcript simulator, or exhibit a coupled
   two-world distinguisher;
2. separately require exact signed source replay and the identical operation
   on a fresh scalar-blind masked target; and
3. only then charge setup, failures, relation collection, output, independent
   rank, factor-log recovery, target descent, verification, traffic, and peak
   memory.

The cheapest discriminating mutation is a public-equation branch-selection
pair. Use the same public constrained-lift equation with two valid outputs.
Oracle A selects by a public formal rule. Oracle B selects through a declared
predicate of the concrete target coordinate or encoding. A should simulate; B
must either produce a relabelling gap or be rejected as a coordinate/advice
oracle. This zero-compute control isolates the missing selection-law
quantifier.

  serial memory.
- Baby-step giant-step: \(N^{1/2+o(1)}\) group operations and
  \(N^{1/2+o(1)}\) stored group elements.
- Closest specialized baseline: undefined until a family and oracle are typed.
  For a constructively simulated jet interface it is the underlying generic
  method with simulation overhead. For an encoding-only interface it is
  ordinary concrete-coordinate arithmetic followed by rho or BSGS.
