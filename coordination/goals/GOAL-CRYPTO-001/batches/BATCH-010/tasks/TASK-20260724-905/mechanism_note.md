## Closest attempted mechanism and why it does not instantiate

The only concrete remaining seam is a non-arithmetic-progression support
family whose exact relation matrix is group-circulant or has constant
displacement rank because a growing public action permutes factor-base
occurrences and covariantly transforms complete signed relations.

No checked source defines that action. The obvious sources of covariance do
not instantiate it:

1. Origin-fixing automorphisms of an elliptic curve in characteristic other
   than 2 or 3 have order 2, 4, or 6. They can change constants, but not an
   exponent; the matched rho baseline receives the same symmetry accounting.
2. The \(p\)-power Frobenius fixes \(E(\mathbb F_p)\) pointwise. The useful
   orbit mechanism in the literature belongs to extension-field/subfield
   curves and is outside this prime-field question.
3. A scalar or translation orbit needs exact orbit indexing. In a prime-order
   subgroup, a nontrivial translation has a full order-\(N\) orbit; compactly
   unranking an arbitrary point in that orbit is the original discrete-log
   problem or an order-\(N\) table. If scalar labels or source indices are
   supplied, the proposal imports the missing oracle. Known endomorphism
   eigenvalues can also turn orbit columns into dependent columns rather than
   \(\Theta(B)\) independent factor logs.
4. An arbitrary column permutation after rows are collected can manufacture
   an attractive matrix ordering without providing relation yield,
   covariance, source replay, or blind descent.

These observations do not prove that every combinatorial support action comes
from one of those sources. That missing classification is the residual; an
adjective such as “non-AP,” “circulant,” or “equivariant” is not an
instantiated mechanism.

## Cheapest decisive gate

The future zero-compute gate is
`support_action_covariance_classification_gate`.

For one exact support claim, freeze:

1. factor-base occurrences, signs, and duplicate-label semantics;
2. action generators, orbit size, and target-independent advice;
3. the transformed target and exact row-covariance identity;
4. orbit indexing and source unranking;
5. known-log relation targets and the identical fresh scalar-blind masked
   target operation; and
6. every coefficient, branch, state, randomness, and verification rule.

First prove covariance symbolically. Then classify the action as a bounded
origin-fixing automorphism, prime-field Frobenius identity,
scalar/translation orbit, source relabelling, post-relation matrix ordering,
or a genuinely different action. Every orbit-index, coefficient-construction,
source-replay, and matrix-generation operation must be expanded.

The gate passes only if a growing genuinely different action is proved,
returns exact signed source occurrences with zero certificate failures,
preserves \(\Theta(B)\) independently verified factor-log rank, supports the
same fresh masked-target descent, and satisfies

\[
  \tau\le 0.25,\qquad \lambda\le 0.45,\qquad \mu\le 0.45 .
\]

A pass creates only an unfiled theorem candidate for independent review. The
gate fails if the action is absent, bounded, Frobenius-trivial,
scalar/source-indexed, backend-only, covariance-invalid, rank-collapsing, or
has any missing or above-threshold cost. Failure warrants no fixture.

Controls are the bounded automorphism classification, pointwise prime-field
Frobenius, a translation/scalar-orbit index charge, random column
permutations, the AP negative, finite isotypic decomposition, exact signed
source replay, and identical blind-target use.

This gate is cheaper and more decisive than a toy displacement-rank
experiment: a measured matrix cannot define a missing public action or prove
its coefficient and source provenance.

## Predictions and outcome meanings

- If the exact growing action is absent, the no-candidate disposition remains.
  If present, it advances only to covariance and provenance review.
- If orbit size is \(N^{o(1)}\), only subpolynomial savings are available. A
  positive orbit-size exponent is necessary but not sufficient.
- Any covariance failure means the low-rank matrix is an ordering artifact.
- Rank below \(\Theta(B)\) after orbit quotient means the action traded matrix
  size for dependent factor-log columns.
- Any \(\tau>0.25\), \(\lambda>0.45\), \(\mu>0.45\), unknown exponent, or
  certificate failure rejects the interface.

The no-candidate disposition is falsified only by one explicit action passing
all those conditions. A toy low-rank trend, bounded symmetry, or untyped
exception does not falsify it.
