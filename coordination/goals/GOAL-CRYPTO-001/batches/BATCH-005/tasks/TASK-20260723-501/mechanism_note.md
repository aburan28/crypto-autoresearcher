## Established facts, derivation, and speculation

Established facts are kept separate from the residual conjecture.

1. Shoup's generic-group lower bound places generic prime-order discrete
   logarithm at \(\Omega(\sqrt N)\) group operations, and Pollard rho matches
   the \(N^{1/2+o(1)}\) exponent with small serial memory.
2. EV-CRYPTO-002 closes only the named compact \(z_R\) admission sheet. It
   does not prove all compact nonlinear representations impossible.
3. EV-CRYPTO-004 leaves the published defect-scaled hyperplane-signature cost
   claim inconclusive. Renaming its zero-minor locator does not create a new
   operation.
4. P1552 and P1553 give the narrowest current normal form: five factor decks
   plus a known-log or masked target become a six-list Abel--Jacobi
   source-location problem. The exact determinant and pair-wedge predicates
   are known, but no endpoint-derived source locator meets the charged
   rectangle.
5. Independent cohort reviews through exact canonical idea ID 410 found no
   later active or theorem-deferred survivor.

The cost derivation uses \(B=N^{1/5}\). A first generic campaign collision
costs \(B^{5/2+o(1)}=N^{1/2+o(1)}\), already only equal to rho and insufficient
for the \(\Theta(B)\) independent relations needed for factor logs. The
current explicit complete campaign and target controls cost
\(B^{3+o(1)}=N^{0.60+o(1)}\). Optimistic sparse factor-log linear algebra costs
\(B^{2+o(1)}=N^{0.40+o(1)}\), so the downstream solve cannot repair the
collection and descent exponents.

The remaining speculation is narrow: an explicit coordinate-sensitive,
noncharacter, endpoint-derived restricted-existence operator might avoid the
represented \(B^3\) separator while retaining exact signed source replay.
No such operation, coefficient provenance, or complete cost proof was found.
Its logical possibility is not evidence that it exists.

## Fully charged current frontier

For the narrow six-list frontier, the best explicit control has the following
optimistic accounting:

| Stage | Charged control | \(N\)-exponent |
|---|---:|---:|
| Factor decks | \(B^{1+o(1)}\) work | 0.20 |
| Source-labelled pair preprocessing | \(B^{2+o(1)}\) work/state | 0.40 |
| First generic campaign hit | \(B^{5/2+o(1)}\) work | 0.50 |
| Complete explicit relation campaign | \(B^{3+o(1)}\) work/state | 0.60 |
| Optimistic sparse factor-log solve | \(B^{2+o(1)}\) work, \(B^{1+o(1)}\) memory | 0.40 / 0.20 |
| Current explicit blind descent | \(B^{3+o(1)}\) work, reusable \(B^{2+o(1)}\) pair state | 0.60 / 0.40 |
| Verify \(\Theta(B)\) constant-arity rows | \(B^{1+o(1)}\) group work | 0.20 |
| Verify final scalar certificate | \(O(\log N)\) group work | 0 |

The materialized explicit control therefore has work and peak-state exponent
0.60. Even granting an unproved streaming schedule that keeps only
\(B^{2+o(1)}\) pair state, collection and descent remain \(N^{0.60+o(1)}\).
No rank is credited until the rows are independently verified; no
target-dependent setup is amortized across fresh targets; failed branches,
source output, ambiguity, bit memory, memory traffic, and final verification
remain charged.

Pollard rho costs \(N^{1/2+o(1)}\) group operations and \(N^{o(1)}\) serial
memory. Thus the known explicit frontier loses in work. An absent source
operator cannot be assigned zero cost.

For any successor, the complete work and memory exponents must be filled as

\[
\lambda=\max(a,\ \beta+\delta+q-r+o,\ \ell,\
\delta_t+q_t+o_t+u,\ \beta),
\]

\[
\mu=\max(a_m,\ q_m,\ \beta+o,\ \ell_m,\ u),
\qquad \beta=\tfrac15,\quad 0\le r\le o.
\]

Here preprocessing, relation retries and output, verified rank, factor-log
linear algebra, masked descent, ambiguity, and memory are separate charged
terms. Campaign admission requires \(\lambda,\mu\le0.45\), and the fresh
masked query must fit \(B^{5/4+o(1)}=N^{0.25+o(1)}\). Equality with rho is not
an advantage.

## Exactly one cheapest decisive gate

The only proposed next research action is the theorem-only
`explicit_operation_and_full_cost_admission_sheet`.

For one future candidate, the sheet must state the exact public operation,
coefficient provenance, generic-prime typing, restricted-existence semantics,
signed source recovery, and identical known-log and masked-target use. It must
then charge preprocessing, relation probability and retries, independent
rank, factor-log linear algebra, blind descent, output, ambiguity,
verification, bit time, memory, memory traffic, and all failed branches.

The controls are semantic rename rejection, source-label permutation,
generic-encoding erasure, known-log versus masked-target parity, and exact
certificate reverification.

The outcomes are fixed in advance:

- If an explicit semantically distinct operation is proved on every admitted
  stratum and complete \(\lambda,\mu\le0.45\) with the required online bound,
  it becomes a proposal for independent theorem review only.
- If the operation is unnamed, imports source advice, omits a stage, or has
  complete work or memory at least \(N^{1/2+o(1)}\), retain
  `NO_ADMISSIBLE_NEXT_MECHANISM` and perform no toy or cryptographic run.

This is decisive at zero compute because the present uncertainty is an absent
identity and absent cost proof. A toy fixture cannot manufacture either.
