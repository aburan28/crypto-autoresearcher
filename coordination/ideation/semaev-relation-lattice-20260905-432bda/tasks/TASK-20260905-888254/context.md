One avenue I think is especially interesting for your autoresearcher is to search for unexpectedly short relation lattices generated by Semaev decompositions.

Suppose a decomposition produces coefficient vectors c_i = (c_{i1}, ..., c_{im}). Construct an augmented matrix containing (c_i, a_i, b_i). You then get modular constraints c_i . l - a_i - b_i x = 0 (mod n). Now study the integer lattice of dependencies between these rows.

For random relations, you'd expect the shortest vector length to follow roughly random-lattice heuristics. But suppose certain curves or certain Semaev tree representations produce anomalously short vectors: lambda_1(L) << det(L)^{1/d}. That would be interesting because it says the relation system contains algebraic dependencies far stronger than random modular linear algebra predicts.

Then the question becomes: can those short dependencies reduce effective relation-generation entropy? That's not presently a known ECDLP attack, but it is a legitimate structural experiment.
