1. What sympy's GF(2**4) actually is
   GF(2**4)          -> GF(16)
   characteristic    -> 16
   is it a field?    -> in F_16 every nonzero element is invertible;
      in Z/16, 2 is a zero divisor:  2 * 8 mod 16 = 0
   so GF(2**4) is Z/16, NOT F_16.

2. The same fact, shown by an element that must be invertible in a field
   2^-1 in sympy GF(2**4) raised: NotInvertible zero divisor
   In the real F_16 = F_2[z]/(z^4+z+1), every nonzero element has an inverse.

3. What DOES work: GF(2) resultants (prime field, so sympy is correct here)
   Res_X(f,g) over GF(2) = Y**6 + Y**4 + Y**2 + Y
   degree in Y           = 6

   CONCLUSION: sympy is usable over the PRIME field F_2 only.
   Any F_{2^n} arithmetic must be implemented explicitly (see preflight_resultant.py).
