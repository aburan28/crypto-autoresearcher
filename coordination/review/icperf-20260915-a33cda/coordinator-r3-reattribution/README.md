## Why the placement is different from the fix

A producer's filed artifacts are its report. The R1-R5 reviewer's own R5 verdict
**breaks partly on custody** — it cites the epoch-1 `manifest.yaml` being edited in
place by a concurrent session and `bench.py` changing after the run and during review.
Editing that reviewer's artifacts after it filed adds a third instance of the same
thing, to the reviewer that raised it. The finding is worth keeping; the mechanism is
not, so the finding is kept additively and the report stays as filed.

The directory is Coordinator-owned rather than a sibling inside
`TASK-20260915-3f4b52/`, because that directory is the reviewer's declared write scope
and a Coordinator writing into it is the same ownership error in the other direction.
