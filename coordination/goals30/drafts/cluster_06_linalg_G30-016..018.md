## G30-016: Calibrated sparse/structured linear-algebra benchmark module over F_p
- **Cluster:** 06 LINALG
- **Type:** infrastructure
- **Long-term chain:** Every index-calculus end-to-end claim currently dies on "full cost charging" (closed failure reason 3) because Gröbner/LA cost is never converted into rho-comparable units. This module provides the verified sparse-LA solver/benchmark substrate that applies G30-001's GOE cost ruler (the sole canonical cost model, owned there): it gates G30-017 and any future LA-bearing attack goal, which gate any sub-rho end-to-end claim, which is the only path to a cryptographically relevant break.
- **Mechanism:** Add `harness/linalg.py` implementing (i) Wiedemann and block-Krylov (Lanczos-style) solvers for sparse systems over F_p in pure Python/sympy, (ii) a cost-accounting layer that converts solver field multiplications/additions into group-op equivalents by applying G30-001's GOE calibration constants — this goal does NOT commission an independent field-op→GOE cost model — and (iii) a benchmark suite over synthetic sparse matrices (controlled density 2–6 nonzeros/row) and real relation matrices harvested from EXP-SEMAEV-001-scale toy systems. Solver output is correctness-verified (A·x = b check) on every run; manifests record which G30-001 calibration-constant version was used so cost conversions are auditable, not assumed.
- **Quantified prediction:** With G30-001's GOE calibration constants applied, the LA submodule's cost model predicts measured wall time within a factor ≤ 2 across matrix orders 64–1024 and densities 2–6; both solvers return verified solutions on ≥ 95% of benchmark instances at orders ≤ 512.
- **Test boundary / scope:** Dense-baseline comparison up to order 256; sparse solvers at orders {64, 128, 256, 512, 1024}, densities {2, 4, 6}, primes of 8–32 bits (matching harness/toycurve.py range), seeds 1–4 per cell. No curve or attack claims are made by this goal.
- **Primary metric:** cost-model relative error |predicted − measured| / measured (median across cells) / **Secondary metrics:** verified-solution rate; group-op-equivalent cost per solve vs matrix order (scaling exponent); Wiedemann vs block-Krylov crossover order.
- **Controls:** sympy dense solve as ground truth for orders ≤ 256; per-run GOE conversion checked against G30-001's calibration constants (themselves calibrated on harness/rho.py group ops on identical hardware); trivially-consistent and inconsistent systems both included to detect silent wrong answers.
- **Falsification criteria:** The module is rejected if the cost model misses by > 2× on any two full size cells, or if either solver fails verification on > 5% of instances at order ≤ 512 — an uncalibrated or unreliable ruler must not be admitted into evidence chains.
- **Negative-outcome value:** If calibration is impossible within 2× in pure Python, the Coordinator stops commissioning LA-cost-bearing attack goals under this harness and either commissions a compiled-backend capability or re-scopes all future end-to-end claims to report raw field-op counts with no rho comparison.
- **Budget:** wall_clock 8h, memory 4 GiB, max_runs 40
- **Stopping rule:** Stop at the first of: (a) all 15 order×density cells × 4 seeds completed with verified solutions and calibration recorded; (b) falsification criterion met — record the failing cells and halt; (c) budget exhausted.
- **Harness dependency:** NEW capability — harness/linalg.py solver/benchmark submodule only; the group-op-equivalent cost model and calibration constants (cartography_harness.md gap 4) are owned and commissioned by G30-001 and consumed here. Uses existing toycurve.py/rho.py (via G30-001's calibration) and runner.py for immutable manifests.
- **Claim tier:** infrastructure
- **Dependencies:** G30-001 (hard — sole owner of the GOE cost model and calibration constants this submodule consumes; no independent field-op→GOE cost model is commissioned here)
- **Revision note (2026-07-23 review):** Rescoped from commissioning its own field-op→GOE cost model to an LA solver/benchmark submodule consuming G30-001's GOE calibration constants, added G30-001 as a hard dependency, and retained the ≤2× predictive-accuracy gate.

## G30-017: Designed relation supports → low-displacement-rank matrices, net of relation-probability penalty
- **Cluster:** 06 LINALG
- **Type:** attack-probe
- **Long-term chain:** KN-OPEN-006 asks whether structured relation matrices beat generic sparse LA; if yes at toy scale with the penalty charged, it gates a scaling study of structured solves inside a full index-calculus pipeline, which gates any sub-rho end-to-end attempt. If no, it closes the structured-LA branch and protects the program from crediting uncharged LA speedups (closed failure reason 3).
- **Mechanism:** Restrict relation collection to designed supports: factor-base relations whose nonzero column patterns follow arithmetic-progression or banded supports, inducing displacement rank r ≪ n (Toeplitz/Hankel-like structure) in the relation matrix. Solve with a structured solver (displacement-rank-aware elimination layered on G30-016 primitives) and with generic Wiedemann on the same matrix. Crucially, measure empirically the per-trial relation probability α_structured/α_generic under fresh-seed random targets: restricting supports lowers hit probability, so the end-to-end cost is (collection cost)/α + solve cost. Credit the structured approach ONLY if total group-op-equivalent cost, penalty included, beats the generic pipeline.
- **Quantified prediction:** Structured solve shows a 2–5× LA-stage speedup at orders 128–512, but the measured relation-probability penalty is ≥ 10×, so net end-to-end structured cost ≥ 3× the generic pipeline — i.e. we predict the structured branch FAILS the net test at toy scale; the goal exists to measure the actual penalty magnitude, which is currently unknown.
- **Test boundary / scope:** Toy curves 10/12/14 bits (harness/toycurve.py), factor bases of size 14 and 16 (mirroring the historical saturation regime), relation matrices of orders {128, 256, 512}, seeds 1–6 per cell, AP-support strides {1, 2, 3} plus banded-width {4, 8} designs.
- **Primary metric:** net end-to-end group-op-equivalent cost ratio, structured pipeline / generic sparse-LA pipeline, penalty fully charged / **Secondary metrics:** measured displacement rank vs design parameter; LA-stage-only speedup; α_structured/α_generic per design; relation-collection cost share of total.
- **Controls:** Same-instance generic Wiedemann solve as the LA baseline; matched harness/rho.py runs on identical instances and seeds as the end-to-end reference; relation probabilities measured on fresh seeds disjoint from solver-benchmark seeds; trivial-ideal control (from semaev.py convention) distinguishes "no relation" from cheap solve.
- **Falsification criteria:** The positive claim (structured wins) is falsified if net ratio ≥ 1 in every cell — the predicted outcome. The negative claim (structured loses) is falsified — and the branch reopens — if net ratio ≤ 0.5 with verified relations in ≥ 2 cells across at least 2 bit sizes.
- **Negative-outcome value:** On failure (predicted), the Coordinator closes the structured-LA branch of KN-OPEN-006 at tested scope, records the measured penalty law α(design) as a KN-FIND entry, and redirects LINALG effort to rank-origin questions (G30-018) and away from solver engineering. On unexpected success, commission a replication cell before any scaling study.
- **Budget:** wall_clock 12h, memory 8 GiB, max_runs 60
- **Stopping rule:** Stop at the first of: (a) all design cells × 6 seeds completed; (b) net ratio ≤ 0.5 verified in 2 cells (early reopen trigger — halt and report for replication); (c) budget exhausted — report censored cells explicitly.
- **Harness dependency:** G30-016's harness/linalg.py (solver + cost model); generalized parameterized EXP runner (cartography_harness.md gap 3) or a bounded one-off driver under runner.py immutability rules.
- **Claim tier:** toy
- **Dependencies:** G30-016

## G30-018: Origin of the 14/16 rank saturation — search for source constructions touching free columns [6,7]/[6,16] pre-insertion
- **Cluster:** 06 LINALG
- **Type:** barrier
- **Long-term chain:** The chronic rank saturation is the single most-repeated structural obstruction in the closed direct-source index-calculus family (NR-1078/1079/1086; ECFG-NR-1384..1396). Certifying WHY columns [6,7]/[6,16] stay free either (a) yields a proven local obstruction that permanently closes the direct-source branch and steers the program toward representation-change directions (KN-OPEN-003), or (b) finds a crack — a construction producing independent target-residual classes pre-insertion — which would reopen the only branch with a known linear-algebra endgame.
- **Mechanism:** Enumerate a parameterized family of NEW source constructions — never re-sorted existing pools — each generating relations from scratch on fresh seeds: (i) scalar-shifted targets Q' = Q + [t]P for t in a small lattice; (ii) alternate x-coordinate residue representations (signed, Montgomery, projectivized); (iii) negation-split and packet-free factor-base embeddings; (iv) stride-selected subgroup generators. For each construction, build the pre-packet-insertion relation matrix and compute the rank of the subspace of independent target-residual classes that touch columns [6,7] (size-14 base) or [6,16] (size-16 base). The diagnostic question is purely structural: does ANY construction produce rank ≥ 1 (and ideally 2) on the historically free column set before packet insertion adds artificial rows.
- **Quantified prediction:** Across all tested constructions, the independent-class rank on the free columns stays ≤ 1 of 2 needed, with 0 being the modal outcome — i.e. we predict the saturation is construction-invariant within this family, suggesting a representation-level (not search-level) obstruction.
- **Test boundary / scope:** Toy curves 10/12/14 bits, factor bases of exactly 14 and 16 elements (matching the historical saturation regime), seeds 1–8 per cell, ≤ 8 construction families × ≤ 4 parameter settings each. All relations independently verified by the toycurve.py certificate verifier; unverified relations invalidate the run.
- **Primary metric:** pre-insertion independent target-residual rank on free columns [6,7]/[6,16], per construction family (0, 1, or 2 of 2) / **Secondary metrics:** rank vs relations-collected saturation curve per family; column-touch frequency distribution; fraction of families whose rank profile is statistically indistinguishable from the historical pool (χ² on touch profiles, fresh seeds).
- **Controls:** Historical-pool rank profile (14/16) as the matched baseline, reproduced from scratch on control seeds before any new construction is scored (guards against harness drift); fresh-window seeds disjoint across families; no multiplicity crediting — duplicate/coset-equivalent relations are counted once per the anti-duplication rules.
- **Falsification criteria:** The barrier claim (no construction escapes) is falsified by any single construction family achieving verified pre-insertion rank 2/2 on the free columns in ≥ 2 seeds — this reopens the direct-source branch. The goal is inconclusive (not negative) if control seeds fail to reproduce the 14/16 saturation, indicating harness drift.
- **Negative-outcome value:** On barrier confirmation (predicted), the Coordinator records a scoped negative closing the direct-source escape route within this construction family, promotes a KN-FIND on construction-invariance of the free-column obstruction, and re-weights LINALG/representation effort toward KN-OPEN-003 directions. On falsification, commission an immediate replication + scaling cell — a verified rank escape is a critical finding requiring independent review-xhigh review.
- **Budget:** wall_clock 16h, memory 4 GiB, max_runs 80
- **Stopping rule:** Stop at the first of: (a) all construction families × parameter settings × 8 seeds completed; (b) any verified rank-2/2 escape (halt, preserve artifacts, trigger replication); (c) control-seed reproduction failure (halt as inconclusive, report drift); (d) budget exhausted.
- **Harness dependency:** Existing harness/toycurve.py (instances + certificate verifier) and runner.py immutability; NEW bounded construction-enumeration driver (or gap-3 generalized runner if commissioned); no Sage required.
- **Claim tier:** toy
- **Dependencies:** none (independent of G30-016/017; consumes closed-family records NR-1078/1086 read-only as baselines, never as re-sorted evidence)
