## G30-005: Execute and close EXP-DREG-003 — confirmatory D6-at-n=12 cell for the dreg-linear-law diagnosis

- **Type:** measurement
- **Long-term chain:** DEC-20260722-007 adopted the dreg-linear-law diagnosis (D6 null failure at n=9 = d_reg degeneracy, not instrument defect; d_reg(n) = Θ(n), c* ≈ 0.238) and commissioned EXP-DREG-003 as the confirmatory cell, but the directory is empty — the diagnosis has never been executed inside the shared harness. - **Mechanism:** Run the commissioned D6-at-n=12 cell with the G30-004 backend: build the boolean chained Semaev (t=3) system at n=12 and its T11-certified support-matched semi-regular random null; measure exact full-column Macaulay ranks at probe degree D=6 for both. Binary Weil-descent family — a recorded negative control for the prime-field target; NO prime-field or crypto-scale claim. Subset-column coranks excluded as evidence (pre-registered artifact per h012 finding iv).
- **Primary metric:** null D6 calibration residual |rank_null − sr_pred| (predicted exactly 0) / **Secondary metrics:** sem D6 quotient (ncols − rank_sem); support-matched sem−null deficit and its confound interval; d_reg(12) read from the closed-form law vs observed null collapse degree (D7 spot-check if budget allows); wall/peak-RSS per cell.

## G30-006: Prime-field Semaev first-fall / solving-degree growth census, m ∈ {2,3,4}, 8–20-bit ladder (KN-OPEN-002)

- **Cluster:** 02 GROEBNER
- **Type:** measurement
- **Long-term chain:** KN-OPEN-002 — how first-fall degree and true solving degree grow for PRIME-FIELD summation-polynomial systems — is the load-bearing empirical assumption under every prime-field index-calculus cost projection the program will ever make (the first-fall-degree heuristic underlies Gaudry/Diem-style complexity claims, and KN-OPEN-001's "prime-field IC vs rho" cannot be costed without it). This census gates any future prime-field attack-probe goal: if d_ff is constant and d_reg tracks the semi-regular null, the prime-field Gröbner degree axis is scoped-closed as an attack route and effort flows to representation/symmetry (KN-OPEN-003) or barrier work (D1–D3); if d_ff itself grows, a literature assumption the program currently trusts is broken at toy scale — a durable KN-FIND that changes which external complexity claims are admissible as priors.
- **Mechanism:** For each m ∈ {2,3,4} and each field size on the 8–20-bit ladder, build the prime-field Semaev point-decomposition system (summation polynomial S_{m+1} with factor-base constraints, extending harness/semaev.py's measure_s3_decomposition pattern to m=3,4 per harness gap #2) over ≥ 3 deterministic toycurve.py curves with ≥ 4 seeds per cell, and measure with the G30-004 backend: first-fall degree d_ff (first degree where the Macaulay matrix drops rank below the semi-regular prediction) and true solving degree d_reg (degree of the last non-trivial Hilbert-function step / F5 top degree). Compare each cell against a support-matched random semi-regular null over the same F_p. Fit the PRE-REGISTERED model set to the ladder — no post-hoc model selection.
- **Quantified prediction:** (i) d_ff is constant across the ladder: d_ff ≤ 3 for m=2,3 and ≤ 5 for m=4 at every size 8–20 bits (first-fall constancy; a slope fit on log2(p) has 95% CI containing 0); (ii) d_reg grows at most linearly in bit size b with fitted slope ≤ 0.25 and tracks the support-matched null within bootstrap CIs at every rung (deficit(n) shows no growth — mirroring the decelerating 1322/1862/1999 pattern already recorded on the boolean axis); (iii) net effect: zero non-generic degree deficit, i.e., no sub-rho signal from the prime-field degree axis at toy scale.
- **Test boundary / scope:** Prime fields of b ∈ {8, 10, 12, 14, 16, 18, 20} bits; m ∈ {2, 3, 4}; ≥ 3 curves and ≥ 4 seeds per (m, b) cell; factor base sized by the standard ~p^{1/(m+1)}-ish toy convention already used in EXP-SEMAEV-001 (factor base 14 at 8–12 bits, scaled per rung and recorded per cell); per-run cap 3600s / 8 GiB. Toy tier throughout — 20 bits is the top rung, no 40–64-bit extension (gap #6 explicitly out of scope).
- **Primary metric:** d_reg(b, m) measured by the F4/F5 backend (NOT the max-degree proxy), vs the pre-registered fit set / **Secondary metrics:** d_ff(b, m); support-matched null deficit per cell; groebner_seconds and peak-RSS distributions (not best-runs); trivial-ideal rate per cell; matched rho group-ops at the same bit sizes for context (cost conversion only via a stated cost model — incomparable op types never equated, per harness evidence rules).
- **Controls:** Support-matched random semi-regular null over F_p for every measured cell (same monomial support, randomized coefficients); trivial-ideal control distinguishing "no decomposition found" from "cheap solve" (mandatory per harness evidence rules); matched rho baseline (harness/rho.py, Teske walk) run on identical instances for cost-context; held-out prediction rule: fit models on rungs b ≤ 16 ONLY, then score predictive error on b ∈ {18, 20} — model selection by held-out error, not in-sample fit; distributions across seeds reported, never best-run.
- **Falsification criteria:** (i) d_ff slope on log2(p) excludes 0 at 95% CI for any m — first-fall constancy fails at toy scale (a genuine, reportable negative on the literature heuristic); (ii) the sem-vs-null deficit GROWS with b (growth-exponent CI excludes 1 from below) or any cell shows d_reg(sem) < d_reg(null) with non-overlapping CIs — a non-generic degree drop, i.e., an attack-positive signal requiring escalation to independent review-xhigh review before any further claim; (iii) the pre-registered fit set is unanimously rejected by held-out error at b ∈ {18, 20} — the growth law is outside the registered model class and must be reported as unmodeled, not curve-fit post hoc.
- **Negative-outcome value:** Confirmation of the prediction (constant d_ff, null-tracking d_reg) is itself the decision-relevant outcome: it scoped-closes the prime-field Gröbner degree axis as an attack route at toy scale, earns a KN-FIND entry, and redirects the program's Gröbner budget to KN-OPEN-003/006 and the D1–D3 barrier line. Falsification mode (i) downgrades the program's trust in first-fall-degree priors imported from the literature, changing how external index-calculus complexity claims are weighted in idea generation. Falsification mode (ii) is the only branch that keeps a degree-axis attack-probe goal alive — so the census cannot run without changing at least one downstream decision.
- **Budget:** wall_clock 96h, memory 32 GiB, max_runs 220
- **Stopping rule:** Stop when every (m, b) cell is either measured with ≥ 4 seeds or recorded as censored with its reason (budget-censored cells are never extrapolated from; a censored top rung truncates the ladder honestly at the last measured rung); then the pre-registered fit comparison on held-out rungs is computed and frozen. Hard stop at max_runs or wall budget; m=4 cells that exceed the per-run cap are recorded censored, not retried at larger budgets.
- **Harness dependency:** G30-004 backend (gap #1, #5); gap #2 (measure_sm_decomposition generalized to m=3,4 with factor-base ideal systems — owned and commissioned under G30-026, consumed by this goal); gap #3 (generalized parameterized EXP runner replacing hard-coded run.py). Cost-model conversion (gap #4) NOT required — rho comparison is context-only.
- **Claim tier:** toy
- **Dependencies:** G30-004 (backend); G30-005 (depends on G30-005 completion — the known-answer calibration rehearsal for the backend before the census trusts it on open cells); G30-026 (owner of the measure_sm_decomposition generalization to m=3,4)
