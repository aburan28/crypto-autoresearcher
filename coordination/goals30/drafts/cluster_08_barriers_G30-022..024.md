## G30-022: D1 quasirandomness barrier — anomalous factor base implies GAP structure in log space
- **Cluster:** BARRIERS
- **Type:** barrier
- **Long-term chain:** This goal formalizes and toy-tests the D1 barrier ("a factor base with anomalous relation yield must carry additive/GAP structure in discrete-log space, contradicting quasirandomness of logs"). A confirmed D1 gates every structured-factor-base direction (H-FB3-001 family, RT-1476-SUBRES-A1): it tells the program exactly which factor bases can possibly beat generic rates and certifies that random/haphazard bases cannot. A refuted D1 removes the only known principled restriction on factor-base design, reopening the search space — either outcome changes which attack goals get budget, which is the barrier's protective function.
- **Mechanism:** Formalize the implication as a quantitative toy assertion: for a fixed prime-order subgroup of a toy curve and a fixed relation model (S_3 summation triples over an x-coordinate factor base), define the factor base's log-space additive energy E(log B) and doubling constant sigma(log B) inside Z/nZ (computable at toy scale because the full log table is enumerable). Then partition factor bases of identical size into (i) GAP-structured constructions (log sets chosen as arithmetic progressions, generalized arithmetic progressions of rank 2, and Bohr-set analogues) and (ii) seeded uniform random sets. Measure the actual S_3 relation yield per base per target by exhaustive triple counting over the enumerable toy group — no certificate-pool re-sorting, fresh instances only. The D1 prediction is that relation-yield excess over the uniform baseline is monotone in log-space additive energy and vanishes for quasirandom bases.
- **Quantified prediction:** Rank-2 GAP-structured bases achieve a relation-yield ratio >= 2.0x over size-matched uniform bases at 12-16 bits, and the yield-vs-additive-energy correlation across all tested bases is Spearman rho >= 0.7; uniform bases cluster at ratio 1.0 +/- 0.2 with no base exceeding 1.5x.
- **Test boundary / scope:** Toy curves from harness/toycurve.py at 8, 10, 12, 14, 16 bits; seeds 1-4 per bit size (independent curve+target instances); factor-base sizes B in {14, 20, 28} chosen to give expected uniform triple yields in [5, 200] so the ratio is well-conditioned; 3 GAP-structure families x 4 random controls per cell. No reuse of any EXP-SEMAEV-001 pools or certificates.
- **Primary metric:** relation-yield ratio (S_3 triple count of candidate base / median triple count of size-matched uniform bases on the same instance) / **Secondary metrics:** log-space additive energy E(log B), doubling constant sigma(log B), Spearman correlation yield-vs-E, per-cell yield distributions (not best-runs), matched rho group-op count on the same instances for cost context.
- **Controls:** Size-matched uniform random factor bases on identical instances (4 per cell, fresh seeds); matched Pollard-rho baseline (harness/rho.py) on every instance so yield ratios are never equated with attack cost without the KN-OPEN-006 cost model; held-out rule: GAP constructions are frozen before seeing any yield data on a given instance, and each cell's headline number is computed on seeds disjoint from the seeds used to pick construction parameters; trivial-yield control cell (factor base deliberately missing the target's summation support) to distinguish "no relations" from measurement failure.
- **Falsification criteria:** (i) any quasirandom/uniform base (additive energy within the uniform null band) sustains relation-yield ratio >= 2.0x on >= 25% of its instances; or (ii) GAP-structured bases across all families and sizes show median ratio <= 1.1x; or (iii) yield-vs-additive-energy Spearman rho < 0.3. Any one kills the toy-scale D1 implication as formalized.
- **Negative-outcome value:** If falsified, the D1 barrier is downgraded from "protective theorem" to "unverified heuristic": the structured-factor-base gate on H-FB3-001 and SUBRES-A1 is removed and those attack goals are judged on direct yield only, while factor-base design search is widened beyond GAP families. If confirmed, the program gains a certified screening law — any future factor-base proposal must show anomalous log-space structure to be worth a run — which de-prioritizes all quasirandom-base proposals permanently at zero further compute.
- **Budget:** wall_clock 8h, memory 4GiB, max_runs 48
- **Stopping rule:** Stop when all 20 instance cells (5 bit sizes x 4 seeds) have complete yield tables for all 7 bases each, or at the 48-run cap; stop early at the first bit size where the GAP families' median ratio and the uniform null band are separated by >= 4 pooled standard errors with the correlation criterion met, provided >= 3 bit sizes are complete.
- **Harness dependency:** Existing toycurve.py + rho.py suffice for instances, log tables (toy groups are enumerable), and the matched baseline; relation yield is pure enumeration needing no Groebner call. Run registration uses the single EXP-registry API owned by G30-025 (cartography_harness.md gap item 3) — this goal does NOT commission a generalized runner. The exhaustive S_3 triple counter must SHARE the enumeration core module with G30-010's H016 counter; G30-022 adds only the additive-combinatorics layer (a small new pure-Python energy/doubling/Spearman metrics module as a harness library).
- **Claim tier:** toy
- **Dependencies:** G30-025 (EXP-registry registration API); G30-010 (shared enumeration core for the S_3 triple counter); informs the live H-FB3-001 batch and gates RT-1476-SUBRES-A1 follow-on work.
- **Revision note (2026-07-23 review):** Removed the self-commissioned generalized EXP runner in favor of G30-025's registry API, and added the requirement that the S_3 triple counter share G30-010's enumeration core (G30-022 contributes only the additive-combinatorics layer).

## G30-023: D3 Massey/cd(F_p)=1 barrier — obstruction certificate and geometric-class Frobenius-descent loophole probe
- **Cluster:** BARRIERS
- **Type:** barrier
- **Long-term chain:** D3 asserts that cohomological dimension cd(F_p)=1 kills the higher Massey-type operations that cohomology-flavored non-generic descent proposals (source-linear complexes in the P1511-P1513 family, all currently not reproduced) would need; the only recorded loophole is classes of geometric origin where Frobenius descent might supply extra structure. Formalizing the obstruction as a computable toy invariant gates every future cohomological-descent idea before it consumes a batch: if the loophole probe comes back empty, that family is closed with a certificate instead of another failed attack run; if it returns a nonzero operation, a narrowly scoped new direction opens.
- **Mechanism:** Build a toy relation complex per instance: vertices = factor-base points, edges/triangles = verified S_2/S_3 relations from fresh toy instances, coefficients in F_l (l = group order, toy sizes). The Massey-type invariant is PINNED PRE-RUN to the following exact sparse-linear-algebra definition (frozen before any run; any later redefinition creates a new experiment record, not a reinterpretation): let C^1 -> C^2 -> C^3 be the relation cochain complex truncated at degree 3, with d_1 and d_2 stored as exact sparse matrices over F_l (sympy/sparse-list representation); fix a deterministic basis B of ker(d_2) (integer-referee-free: row-reduced echelon basis over F_l); let T be the triple-product matrix whose columns are the cochains a*b*c restricted to B, for ordered triples (a,b,c) in B with d_2-compatible supports; then the invariant is mu := dim_{F_l} ker(d_2) - rank([d_1 | T]), i.e., the dimension of the quotient of ker(d_2) by the column span of the concatenated matrix [d_1 | T], computed by exact sparse Gaussian elimination over F_l. Phase 1 (barrier): measure mu on relation sets sampled generically — D3 formalized predicts it vanishes identically beyond the generic rank predicted by the complex's Euler characteristic. Phase 2 (loophole probe): construct geometric-class relation sets by pulling relations through explicit Frobenius-equivariant toy covers (small cyclic/elliptic covers over the same base field where the Frobenius action on the fiber is exactly computable), and test whether Frobenius descent produces a nonzero invariant where the generic sets gave zero.
- **Quantified prediction:** Phase 1: the Massey-type invariant is zero (dimension 0 beyond Euler-characteristic forced rank) on >= 95% of generic relation sets across all cells. Phase 2: at least one Frobenius-descended geometric construction yields invariant dimension >= 1 in at least 30% of its instances at 12-16 bits; magnitude expectation is a defect dimension of 1-3, i.e., detectable but small.
- **Test boundary / scope:** Toy curves 8, 10, 12, 14, 16 bits, seeds 1-4; factor-base size 14-28 (shared instance generator with G30-022 but independent relation census); generic sets = 6 seeded random relation subsamples per instance; geometric sets = 2 explicit cover constructions (cyclic degree-2 and degree-3 toy covers) per instance where computable within budget. Complex truncated at degree 3; all linear algebra exact over F_l.
- **Primary metric:** dimension of the Massey-type defect invariant (generic vs geometric-class) / **Secondary metrics:** rank profile of d_2, d_3 vs generic-null prediction, triple-product matrix rank, per-cell zero-rate, Frobenius-descent success indicator, wall time per complex (scaling proxy).
- **Controls:** Generic-null control: random cochain complexes with matched Betti numbers and boundary ranks must reproduce the same vanishing (distinguishes "D3 vanishing" from "everything vanishes at toy size"); positive control: a deliberately augmented complex with a hand-inserted nontrivial triple product must be detected as nonzero (validates the linear algebra); held-out rule: cover parameters chosen before inspecting any invariant values, with Phase-2 headline numbers on seeds disjoint from construction-tuning seeds; matched rho baseline on all instances for cost context only — no cost comparison is claimed for a barrier result.
- **Falsification criteria:** Barrier side: generic relation sets show nonzero defect invariant on > 10% of instances with the null control staying at its predicted rate — the cd(F_p)=1 obstruction as formalized does not bind, and cohomological descent is reopened. Loophole side: all geometric-class constructions return invariant dimension 0 on every instance — the Frobenius-descent loophole is closed at toy scope. Either is a terminal, decision-bearing outcome.
- **Negative-outcome value:** If the loophole probe is empty, the program permanently closes the cohomological/Massey descent family (including any revival of P1511-P1513-style source-linear complexes) with an explicit toy certificate, freeing all future batches from that frontier. If generic sets violate vanishing, the D3 barrier theorem as stated is wrong at toy scale and must be re-derived before it is used to gate anything — barrier claims are themselves evidence and can fail.
- **Budget:** wall_clock 6h, memory 2GiB, max_runs 30
- **Stopping rule:** Stop when both phases complete all cells or at 30 runs; stop Phase 2 early (declaring loophole closed at tested scope) after 3 consecutive bit sizes x all seeds with zero nonzero invariants and passing positive controls; any single positive-control failure invalidates the affected runs (status completed_invalid) and halts interpretation until the linear algebra is fixed.
- **Harness dependency:** To-be-commissioned: a pure-Python exact relation-complex module (boundary matrices over F_l via sympy/sparse lists) — no Sage, consistent with harness constraints; run registration uses the single EXP-registry API owned by G30-025 (gap item 3) — this goal does NOT commission or reuse any goal-specific runner. Existing toycurve.py and semaev.py provide instances and verified S_2/S_3 relations; certificate discipline per runner.py applies to every relation used.
- **Claim tier:** toy
- **Dependencies:** G30-025 (EXP-registry registration API); G30-022 (shared instance census only — logically independent, can run in parallel); decision output interacts with the not-reproduced P1511-P1513 block and conjecture B1 (relations as AG-code words) as the natural home for the relation-complex formalism.
- **Revision note (2026-07-23 review):** Pinned the exact sparse-linear-algebra definition of the Massey-type invariant pre-run in the goal text, and replaced the claim of reusing G30-022's runner with a dependency on G30-025's single EXP-registry API (only the instance census is shared with G30-022).

## G30-024: RITT-B3 functional indecomposability of the iteration map f_m beyond PH-trivial divisors
- **Cluster:** BARRIERS
- **Type:** barrier
- **Long-term chain:** Composition-based descent shortcuts assume the summation/iteration map f_m can be written as g o h with nontrivial factors, letting a descent stop at an intermediate variety of lower degree; RITT-B3 conjectures f_m is functionally indecomposable apart from already-known PH-trivial divisors. Certifying indecomposability at small m closes this shortcut family before anyone spends a batch on it; refuting it — finding one genuine new decomposition — is itself attack-positive evidence that would be handed to an attack cluster as a fresh descent route. Either terminal outcome reallocates budget correctly, which is the barrier's purpose.
- **Mechanism:** For m = 2, 3, 4, construct f_m explicitly: the m-th Semaev/summation iteration map in univariate-reduced form (resultant elimination of intermediate variables down to a one-variable map over F_p where feasible at toy degree, else the known explicit forms for S_2 and the S_3 resultant path already in harness/semaev.py). Apply a functional-decomposition checker: enumerate candidate degree divisors d | deg(f_m) beyond the PH-trivial list, and test decomposability (i) symbolically over Q/its algebraic closure via standard univariate decomposition algorithms (sympy-based: coefficient-matching and Ritt/body-factor tests), and (ii) modulo each toy prime p — indecomposability over Q-bar does not imply indecomposability mod p, and an accidental mod-p decomposition is exactly the kind of shortcut an attack would exploit, so both must be measured and reported separately.
- **Quantified prediction:** Zero nontrivial decomposition factors beyond the PH-trivial list for m = 2, 3, 4 over Q-bar, and zero accidental decompositions mod p across >= 90% of the tested toy primes per m (allowing a small rate of prime-specific accidents, predicted <= 10%, which are recorded individually rather than averaged away).
- **Test boundary / scope:** m in {2, 3, 4}; toy primes from harness/toycurve.py fields at 8-16 bits (>= 12 distinct primes per m); decomposition degrees enumerated over all divisors of deg(f_m) with the PH-trivial divisor list frozen in the experiment record before any run; symbolic check over Q once per m, modular checks per (m, p) pair.
- **Primary metric:** count of verified nontrivial decompositions f_m = g o h with neither factor on the frozen PH-trivial list (split: over Q-bar vs mod p) / **Secondary metrics:** checker runtime per (m, p), per-prime accident rate, degree profiles of any factor found, positive-control detection rate.
- **Controls:** Positive controls: constructed composites f = g o h of matched degrees (including composites whose factors are PH-trivial) must be detected 100% — a miss invalidates the checker for that run (completed_invalid, superseded per immutability rules); random-map baseline: random same-degree rational maps must come back indecomposable at the predicted generic rate, confirming the checker is not trivially reporting "decomposable" or "indecomposable" everywhere; frozen-list rule: the PH-trivial divisor list is fixed pre-run so no post-hoc reclassification can convert a positive into "trivial."
- **Falsification criteria:** Discovery and independent re-verification of a single decomposition f_m = g o h (over Q-bar, or mod p at a rate > 25% of tested primes for one m) with both factors non-PH-trivial and deg g, deg h >= 2. A verified positive is not a failure of the goal — it is the barrier breaking, and it triggers Coordinator review for a new attack-cluster direction rather than a negative close-out.
- **Negative-outcome value:** If indecomposability holds at all tested (m, p), the composition-based descent shortcut family is closed at tested scope with a machine-checked certificate, and any future proposal in that family must first exhibit a decomposition at m <= 4 to be scheduled — a permanent, cheap gate. If a decomposition is found, the program gains a concrete, falsifiable attack lead (explicit factor maps) that no amount of polling existing pools would have produced; either way the decision to fund or block composition-descent work is settled by evidence.
- **Budget:** wall_clock 8h, memory 4GiB, max_runs 36
- **Stopping rule:** Stop when all (m, p) cells have a verdict with passing positive controls, or at 36 runs; stop the symbolic phase for a given m after one verified nontrivial decomposition (that m's outcome is decided; remaining budget moves to the next m); any checker version change voids prior verdicts for re-run under the immutability policy.
- **Harness dependency:** To-be-commissioned: a pure-Python univariate functional-decomposition module (sympy coefficient algebra + resultant-based elimination, reusing semaev.py's resultant path); no Sage dependency, matching harness constraints. Existing toycurve.py supplies primes/curves; runner.py supplies immutability and manifest discipline; Sage-environment capture (gap item 5) is not required since no Sage is used.
- **Claim tier:** toy
- **Dependencies:** none within G30; logically independent of G30-022/G30-023 (may run fully in parallel). Output feeds the RITT-B3 / BAR-RITT-D3 open frontier recorded in cartography_closed.md and gates any composition-based proposal in future attack clusters.
