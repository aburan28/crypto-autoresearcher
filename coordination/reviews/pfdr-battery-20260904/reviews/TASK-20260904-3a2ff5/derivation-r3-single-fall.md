# Derivation note (R3) — the single-fall identity d_lf = d_ff for the digit closure

Red Team, TASK-20260904-3a2ff5, EXP-PFDR-cbdefb. **DERIVATION, NEVER PROVED**
(docs/claims-and-verification.md, "Refutation artifacts", item 2). Every line is
elementary linear algebra over F_p; an independent reader should be able to check
each one without running anything. Scope: m = 2, d = 2, the frozen convention
`cbdefb-closure-v1`, squarefree digit ring, p odd. Nothing below is asymptotic in s
except where the s-dependence is stated explicitly.

## 0. Notation

p an odd prime, n >= 1, B = F_p[a_1..a_n]/(a_i^2 - a_i). Evaluation at {0,1}^n gives an
F_p-algebra isomorphism B -> F_p^{{0,1}^n} (dimensions agree and a^2 - a splits with
distinct roots). B_{<=D} = span of squarefree monomials a^T with |T| <= D;
N_D = sum_{j<=D} C(n, j); B_{<=n} = B.

F a finite subset of B; I = ideal_B(F); Z = { z in {0,1}^n : f(z) = 0 for all f in F }.
ev_Z : B_{<=D} -> F_p^Z the restriction map; r_D = rank ev_Z|B_{<=D};
e(Z) = min { D : r_D = |Z| } (the INTERPOLATION DEGREE of Z).

V_{F,D} is the frozen convention of `stage1-closure-convention.md` section 1:
W_0(D) = V_{F,D-1} + span{ m f : f in F, m a squarefree monomial, deg m <= D - deg f };
W_{t+1} = W_t + sum_i a_i (W_t cap B_{<=D-1}); V_{F,D} = the fixed point.
FALL AT D <=> dim(V_{F,D} cap B_{<=D-1}) > dim V_{F,D-1}.
fall_dim(D) = dim(V_{F,D} cap B_{<=D-1}). d_ff = least D with a fall; d_lf = largest.

## 1. Lemma 0 (containment)

V_{F,D} is contained in I cap B_{<=D}, for every D.

Proof. Each generator m f of W_0(D) lies in I; V_{F,D-1} lies in I by induction; each
closure step multiplies an element of I by a variable and stays in I; every element
constructed lies in B_{<=D} by construction. []

## 2. Lemma 1 (the ideal is the vanishing ideal; dimension formula)

I = I(Z) := { g in B : g|_Z = 0 }, and dim(I cap B_{<=D}) = N_D - r_D.

Proof. Under the evaluation isomorphism B = product over {0,1}^n of copies of F_p, every
ideal is the set of tuples supported on a fixed subset S of coordinates, i.e. is I(Y)
with Y the complement of S. The ideal generated by F is contained in I(Z); for each
z not in Z some f in F has f(z) != 0, so the support of the ideal contains the
complement of Z; hence the ideal equals I(Z). The second claim is
I(Z) cap B_{<=D} = ker(ev_Z|B_{<=D}), of dimension N_D - r_D. []

(This is the frozen convention's own section-3 statement "in B every ideal is radical";
it is what makes the ideal-side certificate legitimate at all.)

## 3. Lemma 2 (interpolation degree)

e(Z) <= max(0, |Z| - 1). If |Z| <= 3 and p is odd, then e(Z) <= 1.

Proof. First claim: for z in Z and each w in Z \ {z} choose a coordinate i(w) with
z_{i(w)} != w_{i(w)} and set lambda_w = (a_{i(w)} - w_{i(w)}) / (z_{i(w)} - w_{i(w)}),
an affine function that is 1 at z and 0 at w. The product over w != z has degree
<= |Z| - 1, is 1 at z and 0 on Z \ {z}; the |Z| such products restrict to the standard
basis of F_p^Z, so r_{|Z|-1} = |Z|.

Second claim: it suffices that the vectors (1, z), z in Z, are linearly independent in
F_p^{1+n} (then r_1 = |Z|). For |Z| <= 2 this is clear. For |Z| = 3, a dependency
c_1(1,z_1) + c_2(1,z_2) + c_3(1,z_3) = 0 with sum c_j = 0 and not all c_j = 0 forces
c_3 != 0 (else z_1 = z_2); write z_3 = mu z_1 + nu z_2 with mu + nu = 1. At any
coordinate where z_1 and z_2 agree, z_3 agrees too; at a coordinate where z_{1i} = 1,
z_{2i} = 0 we get z_{3i} = mu, and where z_{1i} = 0, z_{2i} = 1 we get z_{3i} = 1 - mu.
Since z_1 != z_2 at least one such coordinate exists, and z_{3i} in {0,1} forces
mu in {0,1} (p odd), i.e. z_3 = z_2 or z_3 = z_1. Contradiction. []

Observed in the package (m = 2, the cells that use certificate route C1+C2, i.e. s = 4
and s = 5): |Z| <= 4 on the Semaev and non-curve arms and |Z| <= 2 on NULL-1 / NULL-2, so
e(Z) <= 3 on those arms. NULL-3 is the exception: its block-factored generator has
|Z| = 135 at s = 4 and 348 at s = 5, for which the crude bound e(Z) <= |Z| - 1 says
nothing useful; Lemma 3 is therefore ESTABLISHED for the Semaev, non-curve, NULL-1 and
NULL-2 arms and only VERIFIED NUMERICALLY for NULL-3 (all 30 recorded C2 checks hold, and
an independently constructed n = 10 system with |Z| = 386 also satisfies C2 at
D = 8, 9, 10; `r2_certificate.json`, key `planted_late_C2`). Directly computed for the
declared instance (p = 4099, a = 3245, b = 455, x_R = 1960, s = 4): Z = {35, 50},
e(Z) = 1 (`r2_certificate.json`, key `e_of_Z_semaev_s4`).

## 4. Lemma 3 (the frozen certificate's C2 identity is automatic)

For every D with D >= e(Z) + 2,
  I cap B_{<=D} = (I cap B_{<=D-1}) + sum_i a_i (I cap B_{<=D-1}).

Proof. Put e = e(Z), J = I cap B_{<=D-1}, U = J + sum_i a_i J. "U contained in
I cap B_{<=D}" is clear. For any g in B_{<=D-1} pick L_g in B_{<=e} with
L_g|_Z = g|_Z (possible by definition of e); since e <= D-1, g - L_g lies in J, so

  (i)  B_{<=D-1} is contained in J + B_{<=e}.

For a monomial a^T with |T| = D >= 1 pick i in T and put T' = T \ {i}; then
a^T = a_i (a^{T'} - L) + a_i L with L = L_{a^{T'}} in B_{<=e}; the first summand lies in
a_i J (using deg a^{T'} = D-1 <= D-1) and a_i L lies in B_{<=e+1}. With (i),

  (ii) B_{<=D} = U + B_{<=e+1}.

Since e + 1 <= D - 1 we have I cap B_{<=e+1} contained in J, hence in U. So the
surjection B_{<=e+1} -> B_{<=D}/U (from (ii)) kills I cap B_{<=e+1} and factors through
B_{<=e+1} / (I cap B_{<=e+1}), which has dimension r_{e+1} = |Z|. Therefore
dim(B_{<=D}/U) <= |Z|. But U is contained in I cap B_{<=D}, of codimension r_D = |Z|
(Lemma 1, D >= e), so dim(B_{<=D}/U) >= |Z|. Equality, hence U = I cap B_{<=D}. []

CONSEQUENCE FOR THE INSTRUMENT. The frozen completeness certificate

## 5. Lemma 4 (saturation propagates; there is no second fall)

If V_{F,D_0} = I cap B_{<=D_0} for some D_0 >= e(Z) + 1, then V_{F,D} = I cap B_{<=D}
for every D >= D_0, and NO fall occurs at any D > D_0 (at any degree, not only up to
D_max).

Proof. Induction on D > D_0. By hypothesis V_{F,D-1} = I cap B_{<=D-1} = J. Every
element of V_{F,D-1} has degree <= D-1, so at level D the whole of V_{F,D-1} is in the
fall space of W_0(D) and the first closure pass adds sum_i a_i J. Hence
V_{F,D} contains J + sum_i a_i J = I cap B_{<=D} by Lemma 3 (D >= D_0 + 1 >= e + 2).
With Lemma 0, V_{F,D} = I cap B_{<=D}. Then
V_{F,D} cap B_{<=D-1} = I cap B_{<=D-1} = V_{F,D-1}: no fall at D. []

IMPLEMENTATION CHECK (read line by line in `closure.py`, sha256
63475db53f5d34859d638327a7082834da0b81209059d0b871bab5b4e32cfb98). The code does not
re-multiply rows of V_{F,D-1} whose pivot lies below `degree_start[D-1]`, on the ground
that they were multiplied at level D-1. Sound: for such a row g, deg g <= D-2, so
a_i g has degree <= D-1 and was inserted at level D-1. In the dense engine an already
processed row can be REWRITTEN by the RREF update; this is harmless because a row whose
pivot is below `top_start` has zero entries in the whole degree-D block, so it is only
ever reduced against other FALLEN rows, each of which is itself processed. In the sparse
engine `Echelon.add` never modifies an existing pivot row at all
(`harness/macaulay_fp/linalg.py`). So both engines realise the convention's fixed point.

## 6. Theorem A (the single-fall identity, per draw)

Let a system have its first fall at d_ff with d_ff >= e(Z) + 2, and suppose

  (SAT)  fall_dim(d_ff) = dim(I cap B_{<=d_ff - 1}).

Then V_{F,d_ff} = I cap B_{<=d_ff} and d_lf = d_ff: no fall occurs at any degree above
d_ff, for any D_max.

Proof. (SAT) plus Lemma 0 give V_{F,d_ff} cap B_{<=d_ff-1} = I cap B_{<=d_ff-1} = J.
The closure at level d_ff multiplies its whole fall space by every variable, so
V_{F,d_ff} contains J + sum_i a_i J = I cap B_{<=d_ff} (Lemma 3); with Lemma 0,
equality. Apply Lemma 4 with D_0 = d_ff. []

Equivalently, the recorded per-degree diagnostic `V_complete_at_D` at D = d_ff is
already the conclusion "V_{F,d_ff} = I cap B_{<=d_ff}", so Lemma 4 alone finishes.

## 8. Consequence for HEUR-002, and the cheapest test of the open step

(a) HEUR-002 ("there exists D_0 depending on (m, d) but not on s with d_lf <= D_0") does
NOT need the d_lf ladder at all: d_lf >= d_ff by definition, so any growth of d_ff in s
refutes it. The refutation therefore rests on H-PFDR-4148b8's d_ff law and on P3's exact
reproduction, and inherits exactly their conditionality. The d_lf ladder's own
contribution is the OTHER direction -- that d_lf does not exceed d_ff -- which is what
Theorem A gives.

(b) The measured solving degree. `V_complete_at_D` at D = d_ff says the closure has
computed the whole degree-<= d_ff part of I(Z), which contains I(Z) cap B_{<=1}: with
|Z| = 1 the solution is then read off by linear algebra. So D_0(s) = 4 + floor(s/2) is a
SOLVING degree, not merely a first-fall degree, at the tested s. EXP-PFDR-c04716's cost
table needs D_0 <= 6 at 256 bits, omega = 2 (H-PFDR-06fd60); 4 + floor(s/2) <= 6 iff
s <= 5, so the requirement is exceeded from s = 6 on. Column counts and exponents are in

linear-algebra exponent about B^{3.9} at s = 4, 5 and tending to B^{4H(1/4)} = B^{3.245}
at omega = 2; sigma > 1 by a wide margin at every s, so no exponent moves. Scope: m = 2,
d = 2 only. c04716's table starts at m = 3, so this is a consequence for the LANE, not a
recomputation of that table.
