## 1. Coefficient recurrence and recovery sign

Work in the prime-order subgroup generated by `G`, with order `r`, and let

\[
Q=[a]G,\qquad 1\le a\le r-1.
\]

Track each state as

\[
R=[A]G+[B]Q=[A+aB]G,
\]

with all scalar arithmetic modulo `r`. For start `s`, the frozen initialization
is `(A_0,B_0)=(s,0)`. The three transition recurrences are

\[
\begin{array}{c|c|c}
\text{branch}&R'& (A',B')\\ \hline
+G & R+G & (A+1,B)\\
+Q & R+Q & (A,B+1)\\
2R & [2]R & (2A,2B).
\end{array}
\]

Suppose the first repeated point has an earlier occurrence
`(A_old,B_old)` and a later occurrence `(A_new,B_new)`. Point equality gives

\[
[A_{old}-A_{new}]G+[B_{old}-B_{new}]Q=O,
\]

so

\[
A_{old}-A_{new}+a(B_{old}-B_{new})\equiv0\pmod r.
\]

Therefore

\[
a(B_{new}-B_{old})\equiv A_{old}-A_{new}\pmod r,
\]

and, when `B_new-B_old` is nonzero modulo `r`, the recovered coefficient is

\[
\boxed{\hat a=(A_{old}-A_{new})(B_{new}-B_{old})^{-1}\bmod r.}
\]

The sign in the frozen statement is correct. Swapping the labels `old` and
`new` negates both displayed differences and leaves the quotient unchanged.

If `B_new-B_old=0`, collision equality forces
`A_old-A_new=0` because `G` has order `r`; the two coefficient pairs coincide
modulo `r` and the collision yields no equation for `a`. It is fruitless and
must have `z_s=0`.

With exact subgroup arithmetic and the stated recurrences, every nonzero-
denominator candidate equals `a` and verifies. A nonzero-denominator candidate
that fails `[hat a]G=Q` is therefore evidence of an invalid certificate path or
arithmetic inconsistency, not a useful collision.

## 2. Verification charge

\[
\boxed{v_s=\ell(\hat a)+\operatorname{wt}(\hat a)}

## 3. Charged work per useful collision

Fix one held-out cell `(curve,seed,u)` and one arm `alpha`. Let the start set be

\[
S=\{0,1,\ldots,r-1\}.
\]

For each start, `w_{alpha,s}` is the number of transition additions/doublings
through the first repeated point, `v_{alpha,s}` is the verification charge just
derived, and `z_{alpha,s}` is one exactly when the nonzero-denominator candidate
verifies. Define

\[
W_\alpha=\sum_{s\in S}(w_{\alpha,s}+v_{\alpha,s}),\qquad
Z_\alpha=\sum_{s\in S}z_{\alpha,s}.
\]

Then

\[
C_\alpha=\begin{cases}
W_\alpha/Z_\alpha,&Z_\alpha>0,\\
+\infty,&Z_\alpha=0.
\end{cases}
\]

This charges every fruitless start in the numerator. It is also the exact
uniform-start restart cost: one uniformly sampled attempt has expected work
`W_alpha/r` and success probability `Z_alpha/r`, so expected work through the
first success is

\[
\frac{W_\alpha/r}{Z_\alpha/r}=\frac{W_\alpha}{Z_\alpha}.
\]

The equality includes different costs on successful and failed attempts; it
does not assume those costs are equal.

This primary cost counts abstract group additions and doublings. It does not
include fixture construction, subgroup enumeration, shuffle construction,
partition-query overhead, scalar inversion, field-operation constants, CPU,
wall-clock time, or memory. Those are separate diagnostics and cannot be
inferred from `C_alpha`.

## 4. Seven-arm pooled null cost

Let arm `0` be the coordinate arm and arms `j=1,...,7` be the occupancy-matched
null shuffles. The coordinate cost is

\[
C_{coord}=W_0/Z_0
\]

when `Z_0>0`. The frozen pooled-null formula is

\[
W_{null}=\sum_{j=1}^7 W_j,\qquad
Z_{null}=\sum_{j=1}^7 Z_j,
\]

\[
\boxed{C_{null}=W_{null}/Z_{null}}
\]

when `Z_null>0`. Because each arm enumerates the same `r` starts, this is the
restart cost for choosing uniformly from the seven arms and uniformly from its
starts. It includes the work of a zero-yield arm in `W_null`.

When every `Z_j>0`, direct pooling is a success-weighted mean of arm costs:

\[
C_{null}=\frac{\sum_j Z_j C_j}{\sum_j Z_j}.
\]

It is not the unweighted mean `(1/7) sum_j C_j`. If any `Z_j=0`, the direct
pooled formula remains the only meaningful expression because `0 times
infinity` makes the weighted-mean rewrite undefined.

\[

## 8. Relabeling assumptions

Let `pi` be a bijection of the finite state set. A relabeling preserves the
diagnostic only when the entire transition system is conjugated:

\[
F^\pi=\pi\circ F\circ\pi^{-1},
\]

each start `R_s` becomes `pi(R_s)`, and the transition's coefficient-action
label is carried with it. Then the relabeled orbit is exactly `pi(R_t)`.
Injectivity preserves the first repeated indices, while the carried action
labels preserve every coefficient pair, denominator, candidate, `w_s`, `v_s`,
and `z_s`. The primary costs are identical.

Relabeling state names alone while recomputing branch labels or leaving the
action table attached to old names is not this conjugacy. In particular, an
occupancy-matched shuffle preserves only the three bucket counts. It changes
which action is applied at a state and generally changes the transition graph;
it is a null arm, not an invariance transformation.

For curve coordinates, `(x,y) -> (u^2 x,u^3 y)` with nonzero `u` transports
the equation and is a group isomorphism. Transporting `G` and `Q` preserves
coefficient relations and scalar verification. But recomputing
`c(R)=integer(x(R)) mod 3` in the new coordinates need not transport the old
partition. Therefore group isomorphism does not imply equal coordinate-arm
costs across `u=1,2,3`; the protocol correctly keeps them separate. Abstract
group-operation counts are preserved by a faithful isomorphism, while CPU and
field-operation costs require their own measurements.
