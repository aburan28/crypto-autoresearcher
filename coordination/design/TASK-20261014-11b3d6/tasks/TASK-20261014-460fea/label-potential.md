# Label/potential obligation

`blocked_by: O1/CompleteBasisAtEndpoint`. A real complete-ring KeyGen is not available for the declared walk law. Accordingly no `EdgeLabel(pp,e)` or `RingPotential(pp,E,W_E,C)` is asserted. Their names are required interfaces, not oracles used in an algorithm.

After O1 is discharged, O2 needs exactly one explicit additive group `G`, public polynomial `EdgeLabel` on each actual encoded edge, and polynomial `RingPotential` using only `(pp,E,W_E,C)`. It must exhibit two supported walks with distinct sums and prove every admitted closed-walk sum is zero, including parallel-edge and automorphism identifications. A public coboundary `h(head)-h(tail)` is a zero-circulation control but yields a public endpoint value; the zero label fails nontriviality. A path hash is not endpoint invariant without a same-endpoint collision theorem. None of these controls is this candidate's label.

Acceptance requires typed evaluation, normalization at `E`, total validation, bit/runtime/memory and failure bounds, and an identical-public-data comparison with a sender lacking `W_E`. Full-ring necessity additionally requires excluding public, one-evaluator, finite-action, path/cache, compressed and opaque substitutes on the same distribution. Those are separate O4 obligations.
