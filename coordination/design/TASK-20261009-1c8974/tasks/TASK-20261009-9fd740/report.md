## F3 — bounded odd nonbacktracking cycles

Fix an odd bound `B_3(lambda)` before seeing the endpoint and search only odd
lengths

```text
D_3(lambda) = {d : 1 <= d <= B_3(lambda), d odd}.
```

For a chosen length `d`, the frozen graph convention gives exactly

```text
(ell + 1) ell^(d-1)
```

nonbacktracking words: `ell+1` first edges and `ell` later edges after excluding
only the transported immediate dual. Thus the complete searched domain has

```text
W_3(lambda) = (ell+1) sum_{d in D_3(lambda)} ell^(d-1)
```

words. The route is admitted only when this number is polynomial. A fixed odd
bound is one specialization when `ell` is polynomially bounded.

The public enumerator starts from the supplied `E`, orders outgoing kernel
lines by their canonical public `Norm`/`Canon` step bytes, and traverses words
by increasing length and then lexicographic step bytes. It never consumes the
erased endpoint-generating walk, a torsion label or basis, an orientation, or
an ideal. A complete version of this route must discharge
`F3-PUBLIC-LINE-ENUM`: polynomial-bit-cost enumeration of exactly the frozen
geometric kernel lines, normalized step construction, and dual-marker
transport from public curve data.

For every closing word, the route emits all typed `VELU_STEP` nodes and their
ordered composition. It returns the lexicographically first descriptor that
`A_eval` accepts, or `0x00` if none exists.

### Typing and non-scalarity

All adjacent targets and sources are exact canonical byte matches, and the
last target must equal the input `E`. The resulting map therefore has type
`E -> E`.

If the word length is odd, its degree is `ell^d`, which is not an integer
square. `DEGREE_NOT_SQUARE` is therefore a public certificate that the map is
not `[a]`, since `deg([a])=a^2`. Nonbacktracking is not itself treated as a
non-scalarity proof: a longer relation could still be scalar.

### Exact law, success, and retries

For a fixed `E`, let `Z_3(E)` be the searched words whose normalized target is
`E` and whose compiled descriptor passes `A_eval`. A uniformly chosen searched
word has exact return-and-accept probability

```text
|Z_3(E)| / W_3(lambda).
```

The enumerating sampler is deterministic. If `Z_3(E)` is nonempty, it returns
the first descriptor with probability one; otherwise it returns `0x00` with
probability one. Its induced semantic law is also a point mass, while allowing
that several cycle programs may denote the same map.

The candidate quantifiers are exactly

```text
q_3(lambda)  = 1,
G_3(lambda)  = {E : Z_3(E) is nonempty},
nu_3(lambda) = Pr_{E <- D_ER(lambda)}[Z_3(E) is empty].
```

On `G_3`, one call succeeds and retries are unnecessary. Outside `G_3`, retrying
the deterministic algorithm never helps and cannot be replaced by resampling
the challenge. What is missing is `F3-ODD-CYCLE-MASS`: a theorem that the exact
`nu_3` above is negligible for the fixed admissible bound. No such result is
in the frozen packet.

### Cost and support

With `C_line`, `C_step`, and `C_verify` denoting worst-case public line
enumeration, normalized-step construction, and verification costs, a charged
upper bound is

```text
T_3 <= (1+B_3 W_3) C_line + B_3 W_3 C_step + W_3 C_verify,
```

plus fixed loop/comparison work. Depth-first traversal uses one path, incoming
marker, candidate descriptor, and verifier workspace rather than retaining all
words. The degree bound is explicit:

```text
log2(deg(alpha)) <= B_3 ceil(log2 ell),
```

which must be dominated by the declared `Lambda_PW,3(n)`.

The route publicly enumerates its complete bounded witness family. Its returned
byte support and semantic support have size at most one for each `E`, so
conditional output min-entropy is zero. This does not violate the relation,
but the route cannot be described as having hidden or broad support.

## F4 — bounded rational-map/interpolation search

Fix positive constants `c_S`, `c_D`, and `c_q`, and set

```text
S_4 = n^c_S bytes,
D_4 = min(p-1, n^c_D),
b_4 = ceil(log2(S_4+1)),
R_4 = 1 + b_4 + 8 S_4,
q_4 = lambda^c_q.
```

One coin string in `{0,1}^R_4` contains a mode bit, a claimed payload length,
and exactly `S_4` payload bytes. Out-of-range lengths and nonzero bytes after
the claimed payload are failures. These rejects remain in the denominator.

In rational-map mode, the payload must already be canonical `DER-ENDO-v1`
bytes with exactly one used `EXPLICIT_MAP` node, source and target equal to
`E`, verified degree at most `D_4`, and a valid frozen non-scalarity
certificate. Noncanonical coefficient tuples are rejected rather than
silently normalized.

In interpolation mode, the payload is a canonical list of public point pairs
and a degree. A fixed monomial order and deterministic row-reduction rule
either produce one normalized reduced rational map or reject. The result is
compiled to `EXPLICIT_MAP`; interpolation is not smuggled in as a new opcode.
The compiler uses the first applicable certificate in the fixed order
`INSEP_NOT_SQUARE`, `DEGREE_NOT_SQUARE`, `DEGREE_ONE_NOT_PM_ONE`, and rejects
if none applies. Agreement with sampled pairs is never sufficient: the global
map identity, degree, source, target, and certificate must all pass `A_eval`.

### Exact byte and semantic law

For a fixed `E`, let `m_4(E,d)` be the number of raw coin strings returning
canonical descriptor bytes `d`, and let

```text
A_4(E) = sum_d m_4(E,d),
a_4(E) = A_4(E) / 2^R_4.
```

Then the one-call law is exactly

```text
Pr[Samp_4=d | E]    = m_4(E,d) / 2^R_4,
Pr[Samp_4=0x00 | E] = 1 - a_4(E).
```

For a semantic map `alpha`, sum `m_4(E,d)` over all returned byte strings
denoting `alpha`. This explicitly charges multiple interpolation transcripts,
cross-mode collisions, and distinct programs for one semantic map.

After `K` independent same-curve attempts, the exact first-success law is

```text
Pr[first d by K | E]
  = (m_4(E,d)/2^R_4) * (1-(1-a_4(E))^K)/a_4(E),
Pr[FAIL after K | E] = (1-a_4(E))^K,
```

for `a_4(E)>0`.

The frozen quantifiers become

```text
G_4(lambda)  = {E : a_4(E) >= lambda^-c_q},
nu_4(lambda) = Pr_{E <- D_ER(lambda)}[a_4(E) < lambda^-c_q].
```

If `nu_4` were negligible, the prescribed retry cap would be
`ceil(lambda^c_q kappa ln 2)` with same-curve failure at most `2^-kappa`.
The missing theorem `F4-BOUNDED-DESCRIPTOR-DENSITY` is exactly the assertion
that this `nu_4` is negligible, counting the whole raw denominator and all
transcript multiplicities. The inspected sources do not provide it.

### Cost and support

One trial parses at most `S_4` bytes, performs bounded deterministic field and
polynomial linear algebra when interpolation mode is selected, compiles at
most one bounded descriptor, and calls `A_eval`. This is polynomial under the
frozen evaluator/arithmetic requirements. Polynomial one-trial time does not
make the search space polynomial: exhaustive enumeration costs exactly
`2^R_4` parser/compiler/verifier calls before duplicate outputs are coalesced.

The byte support satisfies

```text
0 <= |B_4(E)| <= A_4(E) <= 2^R_4.
```

Conditional byte min-entropy is exactly

```text
-log2(max_d m_4(E,d)/A_4(E))
```

when `A_4(E)>0`; no positive lower bound is established. The bounded family is
finite and proper. It is publicly enumerable by exhaustive search, but not
therefore polynomially enumerable. The absence of a different polynomial
enumerator is not inferred.

## Proof-search map

Both families pass `P0` through `P3` at the level of returned outputs:

- `P0`: the endpoint law, coin/search domain, failure byte, DER grammar, and
  byte/semantic laws are explicit;
- `P1`: only `Pi`, `E`, and independent coins/public computation are used;
- `P2`: every return is an `A_eval`-verified `E -> E` descriptor; and
- `P3`: every return has a verified public non-scalarity certificate.

Both first fail open at `P4`. F3 lacks `F3-ODD-CYCLE-MASS` and still owes the
polynomial public-line-enumerator cost theorem. F4 lacks
`F4-BOUNDED-DESCRIPTOR-DENSITY`. Neither gap may be filled by a heuristic.

At `P5`, any accepted bounded output is a OneEnd answer for that same endpoint.
At `P6`, no EndRing conclusion follows: the frozen source packet says the
Page--Wesolowski reduction queries its bounded OneEnd oracle on internally
generated curves, while the candidate guarantees concern only high mass under
`D_ER`. `P7` support and enumeration are accounted above. `P8` is enforced:
the analysis stops before binding, complete-ring reconstruction, recovery, or
PKE.
