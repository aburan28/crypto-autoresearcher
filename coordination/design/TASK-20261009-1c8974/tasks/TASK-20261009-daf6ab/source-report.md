## Result

The packet freezes one campaign distribution, `D_ER`, and one public
endomorphism descriptor/verifier contract. It also resolves the main source
ambiguity: Page--Wesolowski proves

```text
EndRing <= OneEnd_lambda
```

in expected time polynomial in `log(p)` and `lambda(log p)` (Theorem 7.2),
whereas the obvious reverse problem reduction is

```text
OneEnd <= EndRing.
```

These arrows use the conventional meaning “the problem on the left is solved
with an oracle for the problem on the right.” A procedure that outputs one
non-scalar endomorphism is a OneEnd procedure; it is not itself a full-ring
reconstruction.

Most importantly, the frozen sampler guarantee is weaker than the oracle
premise in Theorem 7.2. It requires inverse-polynomial conditional success for
all but negligible mass of curves sampled from `D_ER`. The published reduction
queries its bounded OneEnd oracle on curves generated by its own internal
random walks and treats that oracle as solving OneEnd on each query. Neither a
law identity nor per-query coverage follows from the `D_ER` guarantee. Thus:

```text
accepted Samp output on E  =>  bounded OneEnd answer for that E
D_ER high-mass Samp        !=  automatic PW24 EndRing oracle
```

The missing distribution/query-coverage bridge is explicit and remains open.

## Exact campaign input law

For security parameter `lambda`, public parameters fix the prime, a canonical
model of `F_(p^2)`, a public supersingular start curve `E0`, the prime `ell`,
walk length `L`, a quotient normalization, curve canonicalization, and the
evaluator.

The first edge is exactly uniform among the `ell+1` geometric cyclic kernel
lines. Each later edge is exactly uniform among the `ell` lines remaining after
excluding only the dual of the immediately previous edge. Kernel lines are the
edges, so parallel edges and distinct paths reaching the same canonical model
retain their multiplicity. The endpoint is canonicalized and everything else
is erased: path, kernels, maps, intermediate curves, orientations, ideals,
torsion labels, incoming-edge marker, and ring witnesses.

`D_ER` is the resulting law on canonical endpoint bytes. This is a definition
for this campaign, not a literature claim and not a standard EndRing hardness
distribution. In particular it is not silently replaced by a uniform law on
isomorphism classes or conditioned on prime-field, exceptional, or cyclic
endpoints.

## Output and evaluator grammar

`Samp(Pi,E;rho)` receives only the public parameters, endpoint, and independent
coins. It returns the unique failure byte or a canonical `DER-ENDO-v1`
descriptor. The descriptor is a typed evaluator DAG whose primitive nodes are
explicit rational maps, relative Frobenius, normalized Vélu steps, explicit
isomorphisms, scalar multiplication, and ordered composition. Every primitive
stores explicit source, target, degree data, and canonical field bytes.

The fixed evaluator must check syntax, rational-map identities, source/target
typing, total and inseparable degree, final `E -> E` typing, and one public
non-scalarity certificate. Certificates admitted by the frozen grammar are a
non-square inseparable degree, non-square total degree, a degree-one explicit
automorphism different from `+1` and `-1`, or a verified nonzero characteristic
discriminant. Scalar multiplication, an immediate dual backtrack, the scalar
`p^2`-Frobenius slice, and a lone incorrectly typed `p`-power map are rejection
controls.

Canonical syntax is not semantic canonicalization: two valid DAGs may denote
the same isogeny. Each candidate must therefore state both its exact byte-level
output law and its induced semantic-map law.

The source distinction is deliberate. Page--Wesolowski Definition 2.1 requires
a polynomial-size descriptor and polynomial point evaluation. The frozen 2026
Definition 2.1 also exposes validity, curves, and degree. The campaign adds
canonical bytes and a public non-scalarity certificate; those extra properties
must not be attributed to Page--Wesolowski.

## Quantifiers and cost

Each candidate must instantiate polynomials `q,R,T,M,Lambda_PW` and negligible
`nu`. Define the good set by conditional coin success:

```text
G_lambda = { E : Pr_rho[Verify(E,Samp(Pi,E;rho))=1] >= 1/q(lambda) }.
```

The required outer statement is

```text
Pr_{E <- D_ER(lambda)}[E in G_lambda] >= 1 - nu(lambda).
```

The two probabilities cannot be collapsed into average success. Retrying uses
fresh coins on the same `E`, never a resampled endpoint. On a good curve,
`ceil(q(lambda)*kappa*ln(2))` trials give failure at most `2^-kappa`, total time
equal to the cap times `T`, and peak memory `M` plus output storage. Every
accepted output must also satisfy
`log(deg(alpha)) <= Lambda_PW(log p)`; without this bounded-degree premise,
Theorem 7.2's polynomial cost statement is not available.

## Algebra typing supported by the sources

- Relative Frobenius: a separable `phi:E -> E^(p)` followed by
  `Frob_p:E^(p) -> E^(p^2)=E` is an endomorphism. Its inseparable degree is
  `p`, which cannot be the square inseparable degree of a scalar. A raw
  coordinatewise `p`-power map starts at `E` and lands at `E^(p)` in general;
  it is not an `E -> E` endomorphism without a typed return map.
- Dual control: for `phi:E -> E'`, both dual compositions are multiplication
  by `deg(phi)`. A two-edge immediate dual backtrack is therefore scalar.
- Exceptional positive controls: Page--Wesolowski records exactly two
  exceptional geometric isomorphism classes in characteristic not 2 or 3,
  with automorphism-group sizes 6 and 4. Direct substitution on the standard
  models identifies the usable controls: `(x,y)->(zeta*x,y)` on `j=0` and
  `(x,y)->(-x,i*y)` on `j=1728`. This types a supplied exceptional
  automorphism; it says nothing about the mass of those classes under `D_ER`.
- Normalized composition: Vélu formulas provide an explicit quotient map for
  a supplied finite kernel. The campaign then records the explicit isomorphism
  to its canonical target and requires exact target/source byte matching in
  every composition. This is a syntax convention, not semantic uniqueness.
