## M1: connecting-module norm lift (P1)

Try to use the quaternion order to find a degree-D element of Hom(E,C) with
f(P)=X. Given an evaluated Hom basis, the norm and point constraint define a
finite lattice problem; under N>4D there is at most one valid degree-D map.
End(E), however, acts on a connecting module and does not supply its evaluated
basis. The algorithm stops at constructing an evaluated Hom(E,C) anchor.
Supplying that anchor, a connecting ideal or a calibrated Deuring realization
changes the secret or supplies an unproved oracle. The public-Hom control
executes the same remaining computation publicly. Fixed rank supplies neither
the basis nor a general polynomial bounded-norm enumeration algorithm.

## M2: transported torsion endomorphism (P1)

Compute the four source-ring matrices on E[N], then solve the finite linear
congruence for an integral alpha with alpha(P)=Q. If
gamma=phi_s alpha dual(phi_s) were evaluable on C, then
gamma(X)=[D]phi_s(Q), and D inverse modulo N gives the missing image.
This is a typed conditional formula. It does not evaluate gamma on C from
source End(E) and one point. The missing arrow is transport of the operator to
the ciphertext curve, not smooth-torsion discrete logarithms. Publishing that
evaluated transport supplies the same public formula. Requesting End(C), the
connecting map or its ideal is an additional unresolved operation.
This attempts one transported operator, distinct from M1's whole module.

## M3: quaternion ideal-class endpoint lift (P2)

Try to identify a cyclic norm-D source ideal whose evaluated Deuring
realization has the ciphertext endpoint. Its coefficient t suffices only if
every endpoint-compatible t has the same residue modulo 2^k. Recovering the
fresh mask is unnecessary: given t, its quotient map and a corresponding mask

enumeration is not a polynomial algorithm; matching ideal classes to C by an
oracle is connecting-ideal/path recovery under another interface.
Separately, the complete endpoint fiber has no proved low-k separation.
