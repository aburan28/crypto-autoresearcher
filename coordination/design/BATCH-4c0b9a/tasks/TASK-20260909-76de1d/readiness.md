## What this package defines

This package defines a future public-input gate that recomputes the least
positive `k` satisfying `p^k mod r = 1` within a declared finite cap. It also
defines typed accounting labels (`forced`, `measured`, and `unavailable`) and
synthetic controls that must reject a false asserted `k`, mixed labels, and
toy-to-cryptographic scope substitution.

The design uses no primary-source fact about MOV, Smart, L-functions,
anomalous curves, supersingular curves, generic curves, or any curve family.
Those names are recalled search pointers only, with no citation support in this
task.
