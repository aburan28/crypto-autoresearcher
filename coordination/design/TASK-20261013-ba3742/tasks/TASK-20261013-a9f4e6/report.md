## Result

The source-derived transcript is narrower than an arbitrary adaptive walk but
stronger than the existing `D_ER` sampler contract. Every Page--Wesolowski
oracle query is an endpoint of a fresh 2-isogeny walk from the original input
curve `E`; the start does not move to the preceding endpoint. The transcript is
still adaptive: the first loop stops according to the ring generated by prior
answers, and in the second loop the current factor `N`, walk length `k_2(p,N)`,
number of iterations, and stopping event depend on the preceding answers.

Three and only three interfaces were examined:

1. A pointwise-total public sampler would be sufficient, including with
   singleton per-curve support, but no such constructor is present in the
   frozen packet or the four prior sampler families.
2. A transcript-conditional law compiler has an exact success-loss formula,
   but needs a bound for every conditional Page--Wesolowski query law, not a
   marginal bound for independent `D_ER` samples. No such law certificate or
   complete stopping tail is frozen.
3. A reduction-local route can push an initial-curve endomorphism forward along
   the fresh outer walk. It is correctly typed, but pulling it back in the
   surrounding `Rich` call gives exactly a scalar multiple of the same initial
   endomorphism. For singleton support the generated ring has rank at most two.
   This is a scoped obstruction to that path-correlated compiler, not a
   universal impossibility result.

No interface is an admitted survivor. No PKE was designed and no EndRing
security claim follows.

## Source-derived transcript

The matched source is Page and Wesolowski, *The Supersingular Endomorphism Ring
and One Endomorphism Problems are Equivalent*, EUROCRYPT 2024, Springer
version of record, SHA-256
`55c054a8b4e75041fc2aef62438ac1bd5071f34fec7dea298bafecd6a62280ff`
(`retrieved`; inspected completely for this producer). The frozen campaign
packet and hashes are listed in `adaptive-bridge.yaml`.

Algorithm 3 sets

```text
k_1 = ceil(log(12*9*(1+sqrt(3))*sqrt(p+13)) / log(3/(2*sqrt(2))))
```

and begins with `R=Z`. Until `R` has rank four, it repeatedly performs

```text
phi_j : E -> C_j       fresh length-k_1 2-isogeny walk
beta_j <- O(C_j)       bounded non-scalar endomorphism of C_j
alpha_j = dual(phi_j) o beta_j o phi_j
R <- ring generated by R and alpha_j.
```

It then saturates at 2 and at the ramified prime, computes the current index,
and partially factors it. While the index is not one, a current odd non-cube
factor `N` determines

```text
k_2(p,N) = ceil(12*log(4100000*(log N)^12*N^2*sqrt(p+13))).
```

The algorithm makes three fresh calls with

```text
gamma_j = Reduce_N(beta_j),
alpha_j = dual(phi_j) o gamma_j o phi_j,
```

then uses the lattice generated by `1,alpha_1,alpha_2,alpha_3` to refine the
factorization or enlarge `R`. Thus, conditional on a reachable prefix `tau`,
the next query curve has law

```text
mu_tau = endpoint law of a fresh length-k(tau) 2-walk from E.
```

The frozen source proves expected polynomial time. It does not give a `FAIL`
semantics for `O`, a deterministic total-query cap, explicit complete tail, or
an explicit memory polynomial. A bridge adding abort must account for those
items rather than inherit them silently.

The exact quantifier order needed here is:

```text
for every valid p,E,
  for every prefix tau reachable from prior valid answers and fresh coins,
    for C <- mu_tau,
      answer the OneEnd relation on C with the declared conditional loss.
```

The existing sampler contract instead says that, for a fixed good-set
predicate under one campaign endpoint law,

```text
Pr_{C<-D_ER}[ Pr_rho[valid(C,S(C;rho))] >= 1/q ] >= 1-nu.
```

Changing the order requires a proof.

### I1: pointwise-total direct sampler

Assume a public algorithm `S(Pi,C;rho)` halts within declared time and memory,
returns only publicly verified bounded non-scalar descriptors on `C`, and has
success at least `1/q(n)` for every supersingular `C`. Repeating on the same
curve gives a Las Vegas oracle with expected at most `q` attempts, or a capped
oracle whose failure after `m=ceil(q*kappa*ln 2)` attempts is at most
`2^-kappa`.

This would instantiate the source oracle. It need not have high-entropy
support: Page--Wesolowski explicitly randomizes even a deterministic oracle.
But it is an interface condition, not a construction. Prior families F1--F4
cover relative Frobenius, exceptional automorphisms, short cycles, and bounded
map search; their reviewed evidence supplies no all-curve constructor. Using
one of those restricted families here would only rename its earlier gap.

### I2: transcript-conditional law compiler

Let

```text
B = { C : Pr_rho[S(Pi,C;rho) is valid] < 1/q }.
```

The `D_ER` contract gives `D_ER(B)<=nu`. For each reachable prefix `tau`, the
compiler instead needs `mu_tau(B)<=epsilon_tau`. One sufficient certificate is

```text
TV(mu_tau,D_ER) <= delta_tau,
epsilon_tau <= nu + delta_tau.
```

That certificate must address the different start curves, Page--Wesolowski's
fresh ordinary 2-walks, the campaign's fixed nonbacktracking `ell`-walk,
adaptive lengths, canonical endpoint multiplicities, and exceptional weights.
The frozen packet does not provide this identity or domination theorem.

For a deterministic call cap `Q_max`, a tower/union bound gives

```text
Pr[any abort]
 <= Pr[Q>Q_max]
    + sum_{j<=Q_max} sup_{reachable tau of length j-1}
        (epsilon_tau + 2^(-kappa_j)).
```

No independence among queries is used. The missing conditional masses and the
missing explicit full stopping tail prevent a completed loss and cost claim.

### I3: reduction-local path pushforward

The reduction knows its fresh outer path `phi:E->C`. If a sampler succeeds on
the original `D_ER` challenge curve, a tempting answer is

```text
beta_C = phi o alpha o dual(phi) : C -> C.
```

This is public-local and correctly typed; it does not use the erased path that
generated `E`. It also preserves non-scalarity. But the surrounding `Rich`
call computes

```text
dual(phi) o beta_C o phi
 = dual(phi) o phi o alpha o dual(phi) o phi
 = [deg(phi)^2] alpha.
```

The answer depends on the particular outer path, whereas Theorem 4.2 models
`O(C)` by a distribution determined by `C` and fresh oracle coins. For a
deterministic or singleton-support base sampler, all pulled-back answers lie in
`Z*alpha`; the ring generated with `Z` has rank at most two, so the first loop
does not terminate. Fresh base samples would require a new spanning-support
theorem absent from the `D_ER` OneEnd contract. Therefore this exact interface
breaks, without implying that every reduction-local interface breaks.

## Cost and representation boundary

For any base attempt, the complete bridge cost must include sampler,
verification, rejected attempts, random-walk construction, duals,
composition, `Reduce_N`, saturation, partial factoring, serialization, and
output storage. If `phi` has degree `2^k`, transporting `gamma` gives

```text
deg(dual(phi) o gamma o phi) = 2^(2k) deg(gamma).
```

Memory must include sampler/verifier workspace, retained path and descriptor
bytes, ring/lattice state, and factorization state. The source theorem's
expected polynomial-time statement is not an explicit memory or concrete-cost
bound. Nothing in this zero-run report is measured.

## Limitations and next obligation

This is a bounded search over three declared interfaces. The failure of I3 is
an exact calculation for a path-correlated pushforward; the open status of I1
and I2 is not evidence of impossibility. The report does not establish
security, insecurity, novelty, practicality, concrete parameters, or a
universal limitation on public OneEnd sampling.

The next discriminating obligation is one of:

- instantiate I1 with a uniform public all-curve sampler and complete bounds;
  or
- prove I2's conditional `mu_tau` bad-mass and full stopping-tail bounds for
  the exact ordinary/nonbacktracking walk laws.

If neither is supplied, a successor should rerank a materially different
recipient mechanism rather than reuse I3's outer path correlation. Independent
J1--J3 review remains necessary before any official conclusion.
