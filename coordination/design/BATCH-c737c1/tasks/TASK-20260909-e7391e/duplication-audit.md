# Duplication audit: enumerated transport-chain cost accounting screen

**Status:** inconclusive. This audit is a scope statement, not a repository or
literature search.

## Proposed mechanism

The draft provides a fail-closed bookkeeping interface for a *finite,
source-bound future catalogue* of transport implementations and their ordered
compositions. The central output is a bounded accounting record or
`UNESTIMABLE`; it is neither an implementation nor a mathematical transport
bound.

## Search status

No repository-wide duplicate search was run, no live experiment records were
read, and no literature source was retrieved. It would be false to mark this
idea novel, known, adapted, dominated, or non-duplicative on that basis.

## Required duplicate-resolution evidence

Before a Coordinator could determine overlap or promotion, a future audit must
compare source-bound records at the following fields:

1. exact implementation inventory and immutable source snapshot;
2. component vector dimensions and unit schema;
3. ordered composition and overhead rule;
4. controls for small degree, composition, random walk, and unenumerated
   algorithms;
5. output scope and explicit absence of universal, curve, deployment, or
   ECDLP claims.

Until that comparison exists, `dominated_by` and `sota_delta` are **unknown**.
No novelty or priority conclusion follows from this BATCH-local design.
