**Labels.**

- **mnt5/2 and mnt5/3: proved.**
  1. psi_5 of a floor neighbour E' is 1+1+5+5, so Frobenius is not a scalar on
     E'[5].
  2. Write pi = c0 + f_pi·omega. Since v_5(f_pi) = 1, (f_pi/5)·omega is not in
     End(E') (otherwise pi - c0 would kill E'[5]). Hence 5 divides the
     conductor of End(E'), and every element is a + b omega with 5 | b.
  3. For such an element the norm is a^2 + ab + 53 b^2 ≥ (53 - 1/4)·25 > 55
     when b ≠ 0, and a^2 = 55 has no integer solution.
  4. So E' has no endomorphism of degree 55, and no [11, 5] chain can exist on
     it.

  The same factorisation gives the 5-power torsion over F_{p^2}. #E(F_{p^2})
  has 5-part 5^3. It is non-cyclic on crater curves, where all 12 x-coordinates
  of E[5] are rational. It is cyclic on floor curves, where only 2 are.
  E(F_p)[5^∞] is trivial on every curve in the class (h = 1, n prime).
- **mnt3/1 and mnt3/3 (H = 3): proved modulo the volcano structure theorem.**
  Here the failing neighbours sit at level 1, which is not the floor. The levels
  come from the BFS distance to the floor, which relies on the volcano structure
  theorem (Kohel 1996; Fouquet-Morain 2002; recalled, not retrieved, and not
  needed for the mnt5 proof). At level ≥ 1 the order has 5 | b, so the norm is
  a^2 + ab + 35 b^2 > 35 when b ≠ 0, and no norm-35 element exists. The
  exhaustive search **observes** 0 closed walks on every level-1 neighbour.

**Material finding: an omitted input-format cost in the one-shot column.**

- The conversion prices the forward step's output as a Jacobian point
  (`Z' = psi`, then the `Z/u` tail).
- `sweep_curve` prices the neighbour's chain endomorphism as on E, with the
  affine-input shortcut for the first step (`first=True`). For example, [11, 5]
  costs 61 = 29 + 31 + 1 on both E and E'.
- In the route, the GLV input on E' is the Jacobian image Q = φ(P), so that
  shortcut is not available.
- curvesweep's table and main loop use full Jacobian additions and do not
  depend on the input format. The chain's first step is the only term affected.

There are two ways to evaluate psi(Q). The cheaper of the two is the minimum
extra cost:

- the chain on a Jacobian input: +47 for [11, 5] and [11, 3, 7]; +29 for
  [7, 5] and [7, 5, 5];
- psi_E on the affine P followed by one more forward step: +32. This works
  because the isogeny is horizontal, so it commutes with the CM action on the
  crater curves verified in joint A3.

- **Scalar sets.** Over the 64 points, the wNAF length and nonzero totals are:
  - target: k 14240/2421, k' 14228/2417, a modelled fmul effect of -0.07 %;
  - control: k 16265/2755, k' 16289/2781, +0.26 %, which works *against*
    A1/A2.

  Both are negligible beside the measured 6.8 % and 8.0 % savings.
- **dbl-2007-bl.** As written it computes XX, YY, YYYY, ZZ, (X+YY)^2, ZZ^2, M^2
  and (Y+Z)^2 (8 S), **a·ZZ^2 (`fmul(F, &t, &t, a)`, line 111)**, and M·(S - T),
  for 10 fmul. **The multiplication by a is included.** dbl-2001-b is 5 S + 3 M
  = 8 fmul and is correct (3·alpha, 8·beta, 8·gamma^2).
- **Dead code and order effects.**
  - Every result's x goes into a `volatile` sink, in every arm, so no scalar
    multiplication can be eliminated.
  - y is stored only in rep 0, so the compiler may drop the y-normalisation in
    later reps. This affects all arms equally.
  - The arm order rotates as (rep + slot) mod 4. Offset 0 occurs 11 times and
    the others 10 times (disclosed in the spec).
- **A2 is priced conservatively.** Its identity-isomorphism steps run as full
  s = 0 homogenised steps, about 6 fmul each where 1 suffices: about 10 extra
  fmul, roughly 0.3 %, against A2. The forward steps do not exploit the affine
  first input.
- **Recompile and fresh-point run.** I compiled the committed bench.c at `-O2`,
  and separately at `-O2 -march=native`. Each curve got 5 fresh validator
  points (seed 0x35D325), with:
  - P' computed by **my own** Velu route to an a = -3 model;
  - k' = k·c;
  - route polynomials taken from the committed input header;
  - reps = 1, with timings ignored (not re-timed).

  Result: **5/5 correct for every arm on both curves, at both flag sets.**
  Perturbing one input scalar makes A0 fail against the reference, as a
  negative control of the check should.

### B4. Contention: visible, symmetric, not material to any gate

I flagged a repetition when any arm exceeds 1.10 times that arm's median:

- **Target.** 17/41 repetitions are flagged. The bursts fall at reps 2-3, 8-14
  and 20-21, are 1.2-1.8x, and hit all arms. Outliers by arm: A0 11, A1 11,
  A2 13, A3 14. By slot: 10/14/14/11.
- **Control.** 19/41 are flagged, with bursts at reps 4-5, 24-27, 30-34 and 37,
  up to 1.88x. By arm: 11/11/12/10. By slot: 7/11/13/13.
- **Individual ratios.** Per-repetition ratios range from 0.50 to 1.85, so some
  bursts are shorter than one repetition and hit single arms. The median over
  41 paired repetitions absorbs them.
- **Drift.** On clean repetitions, A0's OLS slope is +0.025 %/rep (target) and
  +0.073 %/rep (control). The ratio slopes are at most 0.0011 per repetition.
  Half-run medians (reps 0-19 vs 20-40):

  - control A2/A0 0.930 / 0.921.

  - target: A1/A0 0.9334 [0.9239, 0.9423]; A2/A0 0.9681 [0.9638, 0.9710];
    A3/A0 0.9987 [0.9944, 1.0062];

**Judgement.** Contention shows as bursty outliers. It does not show as drift or
as an imbalance between arms. The paired, rotated design and the median absorb
it. A run on a single shared host stays a limitation. The spec's own
independent-runner replication is the remedy.
