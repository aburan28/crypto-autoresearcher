# Development red team v1

## Decision

`REVISE`. Preserve the verified artifact and its two post-result audits. Do not freeze or launch the canonical configuration.

## Objections and resolutions

### The random-label null did not preserve sign symmetry

The x-only routers identify `P` and `-P`; the original random label hashes full point encodings. This can reduce occupied buckets and route triples without revealing addition locality.

**Resolution:** the eight-seed fiber-null audit hashes only public x-fibers. Zero of 54 repaired comparisons passes the joint payload/D4-read/D5-read gate. The apparent signal is not promoted.

### The materialized baseline was stored but not queried

The raw document included materialized-D4 payload metrics but did not execute its online path on the matched targets required by the contract.

**Resolution:** the separate materialized-baseline audit executes all scheduled supported D5 targets. No router dominates it in both advice and online group operations. This repair is additive; the verified raw artifact remains unchanged.

### Factor-base logs were supplied by exhaustive toy audit

The experiment holds the relation/rank layer fixed instead of rerunning it. Exhaustive logs are private audit material and would be invalid as an attack primitive.

**Resolution:** logs are used only after a public router returns a factor witness; no scalar index is passed to a public router or serialized as advice. The result is a join preflight, not a new end-to-end attack. Any promoted successor must reconnect the verified relation solver.

### Coordinate hash arithmetic is omitted

Legendre-vector routing performs exponentiations, and all routers perform coordinate work that is absent from the attack cost vector.

**Resolution:** omission favors the candidate. Because every candidate already loses the strong baselines, charging this work can only strengthen the scoped negative. No positive performance claim is permitted.

### Payload bits are a lower estimate

The fixed-width model omits dictionary metadata, allocator overhead, cache misses, and hardware bandwidth.

**Resolution:** canonical serialized bytes and Python deep bytes are also recorded. Equal-advice BSGS uses the favorable lower payload, so the no-win conclusion is conservative.

### The scalar control is not an algorithm

Computing scalar intervals for arbitrary targets is the DLP.

**Resolution:** it is marked `positive_control_only`; its purpose is to show that the locality metric reacts to an addition-compatible representation. It cannot pass a routing gate.

### One seed cannot support scaling or promotion

All observations use one curve per size and one original full-point null draw.

**Resolution:** the artifact is explicitly noncanonical. The repaired fiber null adds eight router draws but not new curves. No exponent or family-wide claim is made.

### Replay is not fully independent

The verifier imports the generator for exact full-document replay.

**Resolution:** after replay it separately implements affine arithmetic and independently recomputes curve orders, subgroup checks, D2/D4/D5 supports, factor witnesses, and recovered challenge scalars. This verifies the arithmetic surface but is not an independent human or sub-agent review.

## Narrowest valid result

`NEGATIVE RESULT / TOY-EVIDENCE`: on one seed at 10-14 bits, unary coordinate bucket relations provide a storage/query tradeoff but no joint advantage over symmetry-matched random fibers, exact materialized D4, equal-advice fixed-base BSGS, or rho.
