# Exploratory artifacts

`precanonical-20260718/` contains the unmanifested development runs used before
the canonical EXP-DREG validation packages were created.  They are retained as
exploratory implementation evidence only and must not be used in fits or a
hypothesis verdict.

The development checks produced the frozen ranks at `n=12, D=5` under two
column partitions and at `n=15, D=5` under one partition.  The later canonical
runs reproduce those ranks with commands, environment, resource receipts,
source snapshots, full checkpoint hashes, and manifests.

This directory was moved intact from `/private/tmp/exp-dreg-validation` to the
external research volume after the macOS data volume reached ENOSPC.  The move
preserved the exploratory files while recovering system-volume working space;
no research artifact was deleted.
