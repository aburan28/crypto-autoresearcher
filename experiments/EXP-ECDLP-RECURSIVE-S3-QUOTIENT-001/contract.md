# Experiment contract: recursive S3 quotient preflight

## Status and execution boundary

`CONJECTURE`, `MODEL-BOUND`, `REJECTED_SCOPED`.

This contract is a theory and barrier preflight. It authorizes no generator,
canonical run, or development evidence run. Any implementation requires a
distinct theory review, literature review, red-team review, frozen source
commit, and explicit development authorization.

The predecessor `EXP-ECDLP-OUTER-TRANSLATOR-001` exactly recovered registered
five-leaf witnesses but failed workspace, online, amortization, same-map-null,
and trend gates. This successor may reuse its finite-orbit oracle and verifier;
it may not optimize or relabel the same explicit `G_Q`/`H_Q` loop.

## Candidate

Exploit repeated exact structure in source-labeled recursive EC-addition states
to quotient the `S2 -> S3` transition system before any target-conditioned
compatibility polynomial or full-state mask is constructed.

The research question is deliberately two-sided:

1. `POSITIVE`: a stable quotient supplies a non-generic fixed-curve compiler
   primitive;
2. `NEGATIVE`: near-singleton refinement matching a same-map random control is
   concrete coordinate-expansion evidence for this structured model.

Neither outcome is an ECDLP exponent result.

## Mathematical objects

Let `F` be a finite sign-complete factor base on an odd prime-order curve over
`F_p`. Repeated leaves are allowed. Let `S2=F+F` and `S3=S2+F`, each retaining
all exact point support, a canonical first witness, and an audit-only complete
witness multiplicity count.

For each layer, form orientation-aware x-orbit states:

- one state for every finite pair `{P,-P}`, with both orientations and witness
  involutions retained;
- one explicit identity sentinel when present;
- no hidden scalar index.

Each accepted source root carries its public branch and map parameters. A
transition from an `S2` orbit and a factor fiber records the exact set of `S3`
orbits reached by all valid orientations, plus identity routes and exact leaf
witness lifts. Hashes may index records, but class equality requires complete
record equality.

The complete cleared `f3(x(S2),phi_b(t),Z)` coefficient tuple reduced over the
accepted source-root polynomial is a registered injective negative control. By
`theory.md`, its leading coefficient already separates all finite states when a
branch has two distinct mapped x-values. It must not initialize a candidate
quotient or count as evidence of recursive expansion.

A mathematically distinct non-partition representation has not yet been
specified. The registered quotient and a low-dimensional linear-profile module
are both closed by `theory.md`. This contract authorizes no implementation.

## Theory-review v1 obstruction

The theory reviews established four restricted state-separation barriers:

1. the denominator-cleared leading-in-Z `f3` coefficient is injective on finite
   state x-coordinates for any non-pole branch with two distinct mapped x-values;
2. in a prime-order group, exact oriented compatibility behavior over every
   target separates states whenever the complement set is nonempty and proper;
3. the complete unordered two-orientation compatibility multiplicity over every
   target separates x-orbits under the same assumptions;
4. over `Q` or `C`, every complete oriented translation profile is linearly
   independent, and the x-orbit multiplicity profiles have full column rank.

Therefore a singleton partition under the original initial and terminal colors
would be tautological, not evidence about coordinate expansion. The x-orbit
classification leaves no nontrivial classes under complete all-target
orientation multiplicities. A successor must change representation to an
implicit operator that distinguishes states without storing a full
member-discrimination vector.

## Rejected exact quotient

Compute a layered coarsest stable partition:

1. run the full coefficient observation only as an injective negative control;
   a candidate initial color requires a separate theorem showing it is
   non-injective without losing exact query semantics;
2. refine an `S2` color by the complete source-labeled multiset of successor
   `S3` colors and witness-orientation actions;
3. refine `S3` terminal colors by the exact symbolic addition descriptor needed
   to test compatibility with arbitrary affine targets; this registered exact
   all-target terminal semantics is an injective negative control by
   `theory.md`, not a candidate compression mechanism;
4. repeat until no class splits;
5. independently prove representative invariance by affine EC addition over
   every state, source root, orientation, and identity route.

A candidate class would be valid only if every representative had identical labeled
successor classes, terminal observation, orientation action, and witness-lift
behavior. Approximate clusters, low-rank embeddings, hashes, sampled equality,
or target-specific merging are diagnostics and cannot enter the exact quotient.

## Query boundary

The candidate query receives only public target coordinates and quotient
advice. It must recover exact compatibility roots and signed factor witnesses
without constructing any of the following:

- explicit `G_Q` or `H_Q`;
- one target-conditioned coefficient, bit, or class entry per full D2 x-orbit;
- a hidden compatibility mask or D3 key table outside disclosed advice;
- target scalar material.

The output roots and witnesses are charged. If the exact output itself has
`Theta(|D2_x|)` size, report that as an output obstruction rather than hiding it
from workspace.

## Controls

### Positive controls

1. Duplicate every semantic state label once while preserving identical
   transitions; exact refinement must merge each duplicate pair and recover the
   original quotient.
2. Split one true class with a redundant public label; dropping that label must
   restore the class without changing compatibility or witnesses.

These validate partition refinement only and cannot support a coordinate claim.

### Negative controls

1. Give every duplicate one altered successor or orientation action; refinement
   must split it.
2. Use random unique symbolic observations with the same state and degree
   counts; refinement should remain singleton.
3. Delete an identity transition, swap a witness orientation, mutate a source
   pole, or collide two hash keys with unequal full records; independent replay
   must reject each mutation.

### Matched coordinate controls

- `x_interval` is compared with randomized accepted roots under the identical
  map `x=t`;
- `square_map` is compared with randomized accepted roots under the same
  `x=t^2+c` map and branch sizes;
- each Mobius branch is compared with randomized non-pole roots under the same
  `(t+d)/(t+e)` parameters and branch sizes;
- every comparison uses identical curves, factor-base cardinality, target
  schedule, orientation policy, and quotient implementation.

No map-confounded row may satisfy a coordinate gate.

## Baselines

- full unquotiented S2/S3 transition system;
- exact D2+D3 complement lookup with symmetry-compressed D3 advice;
- predecessor explicit root-product translator as a negative implementation
  control only;
- equal-advice fixed-base BSGS and Pollard rho as disclosed arithmetic scales;
- map-matched randomized transition systems.

## Metrics

Report separately by curve, family, layer, and control:

- full orbit states, identity sentinels, exact quotient classes, class-size
  distribution, refinement rounds, and singleton fraction;
- source-labeled transition edges before and after quotienting;
- exact symbolic observation coefficients and construction operations;
- orientation actions, witness bytes, and identity-route bytes;
- offline EC additions, field operations, logical reads/writes, canonical bytes,
  Python retained bytes, and process-level wrapper RSS;
- target-specific live entries, coefficient slots, masks, output roots,
  witnesses, memory traffic, and weighted field work;
- exact support probability and solved-target count;
- independent-target projections and actual shared batch work, kept separate;
- fitted slopes over all three sizes, with undefined slopes failing closed.

Full audit state, scalar indices, complete witness universes, and brute target
masks are verifier-only and segregated from eligible advice and query work.

## Functional gate

1. Every affine state, transition, orientation, identity route, and witness
   independently replays.
2. Every quotient class is stable under complete labeled transitions and
   terminal observations.
3. Quotient and full-state queries return identical complete root sets and
   signed witnesses on supported and family-independent uniform targets.
4. Positive controls merge exactly as planted; every negative/mutation control
   is rejected.
5. Requested target cardinality is realized exactly.

Failure invalidates the implementation, not the hypothesis.

## Historical continuation gate

One fixed coordinate family may continue only if, on both seeds at every size:

1. the functional gate passes;
2. both S2 and S3 quotient class ratios are at most `0.8` of their full orbit
   counts;
3. quotient class count, transition advice, or exact query work is at most
   `0.8` of the corresponding map-matched random control without support loss;
4. total target-independent advice is at most `0.8` symmetry-compressed D3;
5. largest target-specific live state, including roots and witnesses, is at most
   `0.8|D2_x|`, and no omitted full-state mask or coefficient vector exists;
6. online weighted field work is at most `0.8` scalar exact D2+D3 for inversion
   weights `10,50,100`;
7. any preprocessing differential amortizes within `B` supported targets;
8. class-count, live-state, and online-work slopes do not worsen toward their
   unquotiented baselines.

The gate is conjunctive over both seeds, all three sizes, exact cardinality, and
same-map controls. A pass only authorizes a compiled-query successor. It does
not authorize relation collection, a canonical run, or an ECDLP claim.

## Falsification and barrier outcome

Record a scoped `NEGATIVE RESULT` for this exact quotient semantics if classes
remain above `0.8` of full states, match the random control, require a full
target-conditioned vector, or lose witness composability. Preserve separately:

- any exact nontrivial classes;
- which observation or transition first separates them;
- output-size lower bounds witnessed by dense root sets;
- a candidate restricted theorem stating conditions under which terminal
  observations force singleton classes.

The next positive question after singleton refinement is not another partition
heuristic or exact low-rank profile. It is whether a full-rank structured
transform, nonlinear first-witness branch predicate, or sparse-reporting
multipoint operator can remain exact without reconstructing the same full
state.

## Proof and disproof tracks

### Proof track

- Prove that stable classes induce a well-defined partial operation on quotient
  states and exact witness lifts.
- Bound class count, transition advice, and query work for an infinite curve
  family rather than one toy instance.
- Relate the quotient to the structured generic-group escape parameter without
  asserting that a unary coordinate predicate alone instantiates that model.

### Disproof track

- Show that terminal symbolic addition observations separate all finite x
  orbits under explicit assumptions.
- Construct collisions that split after one orientation or identity refinement.
- Show that dense compatibility output alone forces linear target workspace.
- Compare class and refinement distributions with map-matched random controls.
