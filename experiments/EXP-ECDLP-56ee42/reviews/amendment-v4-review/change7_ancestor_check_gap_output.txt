=== Conclusion ===
git merge-base --is-ancestor checks DAG reachability only. It never
inspects file existence or content at the cited sha. A task card
author who cites ANY earlier ancestor commit (a typo, a stale
copy-paste, or a wrong-but-plausible-looking sha from the same
branch's history) passes V4-CHG-7's 'mechanical' check exactly as
cleanly as the correct citation would -- exit code 0 either way.
