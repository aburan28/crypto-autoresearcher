# Prospective wider Solinas comparison

This extension follows RUN-ECDLP-a24605 and excludes all its sampled moduli. It adds a 36-bit stratum, doubles the independent S prime count to 72, quadruples unconditional models per prime to 128, and uses four distinct random controls per S prime. The unchanged attack kernel counts setup/search/verification separately. Every family claim uses 99.9% marginal block-bootstrap intervals; a reserved three-family primary Bonferroni interval is also reported. Exact identities, incomplete matches and every raw result are retained. This is a toy experiment and does not define the requested P1-19/P2-4 names.

Source changes and the contract are committed before any new prime selection or attack. Original sources and results are preserved.
