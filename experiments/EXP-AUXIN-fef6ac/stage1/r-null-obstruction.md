# r_null construction is empty

For odd r, (r-1)/2 and (r+1)/2 are consecutive integers. The only consecutive primes are (2,3), giving r=5, which is not > 2^16. Therefore the idea's r_null search has empty range. This is a defect of the null construction, not a Cheon-split observation.
