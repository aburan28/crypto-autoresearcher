# Red-Team Review: TYPED-TT-BATCHED-RELATION-TRANSCRIPT-V1

## Required objections

- A predicted zero is not a witness. Every selected candidate must replay the
  recursive five-addition sum directly on typed points.
- Support must be compared with an independently rebuilt materialized D4
  query, including the selected `a_index` set and all target rows.
- Relation rank is not support size. Insert all candidate equations into an
  independently counted quotient basis and report the final rank.
- The first target builds the adaptive row space. Charge its source and field
  work in both modes; do not report only the later batch saving.
- Shared source sums reduce group additions but do not remove target predicate,
  reconstruction, matrix, or individual-log work.
- The reused locator remains an exact toy construction with source-advice
  precomputation. It is not a generic ECDLP algorithm or an exponent result.

## Mutation and control requirements

- Verify direct source-reference values at every pivot query.
- Compare shared and separated target streams and row-space ranks.
- Run all four public coordinate families across all three generated curves.
- Require strict width-`B+1` source-add savings and zero support/rank mismatch.

## Decision boundary

A valid result establishes only a fixed-curve witness-bearing batching signal.
The next gate is independent sparse linear algebra, held-out target descent,
memory bandwidth, and a matched Pollard-rho cost model.
